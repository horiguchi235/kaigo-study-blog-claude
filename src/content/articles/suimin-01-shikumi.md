**この記事のポイント**

1. **いちばん深い眠りはノンレム睡眠**、**夢を見るのはレム睡眠**。体内時計を合わせる最強の因子は**日光**、眠りを促すホルモンは**メラトニン**。
2. 高齢者の睡眠は「**中途覚醒・早朝覚醒が増え、深い眠りが減り、睡眠時間は短くなる**」。
3. 睡眠障害は症状で見分ける：**脚を動かすと楽＝レストレスレッグス**、**寝ている間に脚がぴくぴく＝周期性四肢運動障害**、**いびきが途切れる＝睡眠時無呼吸**。

## ① 睡眠のしくみ【こころとからだのしくみ】

### レム睡眠とノンレム睡眠

| | **ノンレム睡眠** | **レム睡眠** |
|---|---|---|
| 眠りの深さ | **いちばん深い眠り**を含む | 浅い |
| 脳 | **脳が休む** | 脳は活動している |
| 体 | 筋肉はある程度働く | **筋肉の緊張がなくなる** |
| 目 | — | **速い眼球運動**（Rapid Eye Movement） |
| 夢 | — | **夢を見る** |
| 役割 | **成長ホルモン**の分泌 | **記憶を整理・定着**させる |
| 出る順 | **入眠はノンレムから** | ノンレムの後に出る |

- ノンレム → レムの組み合わせを**約90分**ごとに繰り返す（30分・60分は×）
- 明け方に近づくほどレム睡眠が長くなる

### 体内時計

| ○ | × |
|---|---|
| 体内時計は脳の**視床下部（視交叉上核）**にある | 松果体・下垂体（松果体はメラトニンを出す場所） |
| 24時間に合わせる最も強力な因子は**日光** | 食事・運動・仕事・入浴 |
| 眠りを促すホルモンは**メラトニン** | コルチゾール（朝に増え目覚めを促す）・インスリン |
| 睡眠中は**体温が下がる** | 体温が上がる |

### 高齢者の睡眠

| ○ | × |
|---|---|
| **中途覚醒**が多くなる | 夜間の睡眠時間が長くなる |
| **早朝覚醒**が多くなる | 早朝覚醒が少なくなる |
| **深い眠り（深睡眠）が減る**、眠りが浅い | 眠りが深くなる・ノンレムやレムが増える |
| **睡眠周期が不規則**になる | 熟眠感が増える・寝つきが早くなる |
| 睡眠時間は**短く**なる。65歳で**約6時間** | 長いほど健康的 |

## ② 睡眠障害と睡眠に影響する薬・習慣【こころとからだのしくみ】

### 不眠の4タイプ

| タイプ | 中身 |
|---|---|
| 入眠障害 | **寝つけない** |
| 中途覚醒 | 夜中に**何度も目が覚める** |
| 早朝覚醒 | 朝早く目が覚め、**もう眠れない** |
| **熟眠障害** | 時間は十分なのに**ぐっすり眠った感じがしない** |

### そのほかの睡眠障害

| 障害 | 特徴 |
|---|---|
| **睡眠時無呼吸症候群** | 寝ている間に呼吸が止まる。**いびきが途切れる**。原因に**肥満**。日中の眠気 |
| **レストレスレッグス症候群**（むずむず脚症候群） | 夕方〜夜に**脚がむずむず**して眠れない。**脚を動かすと楽になる**。**入眠障害**の原因 |
| **周期性四肢運動障害** | 寝ている間に**脚がぴくぴく**動く。本人は気づかず、**日中に眠い** |
| **レム睡眠行動障害** | **夢の中の行動がそのまま出る**（大声・激しい動き）。レビー小体型認知症に多い |
| **概日リズム睡眠障害** | **夕方に強い眠気**で寝てしまい、**深夜に目が覚める** |

### 睡眠に影響する薬・習慣

| 原因 | 影響 |
|---|---|
| **抗ヒスタミン薬**（かぜ薬・アレルギー薬） | **夜十分寝ても日中に強い眠気**。覚醒作用は× |
| **就寝前の飲酒** | 寝つきはよくても**眠りが浅くなる** |
| **就寝前の夜食** | 消化のために眠りが浅くなる |
| カフェイン・ニコチン | 覚醒作用 |
| **高齢者の睡眠薬** | **翌朝まで作用が残る**（持ち越し）、**ふらつき・転倒**、依存、**アルコールと一緒は危険** |

> 大切な人を亡くした後の寂しさ・無力感・不眠・食欲不振などの反応 ＝ **グリーフ（悲嘆）**。
