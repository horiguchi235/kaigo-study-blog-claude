| こころとからだのしくみ | 21問 | ①睡眠のしくみ ②睡眠障害と薬 |

**結論を3行で**

1. **いちばん深い眠りはノンレム睡眠**、**夢を見るのはレム睡眠**。体内時計を合わせる最強の因子は**日光**、眠りを促すホルモンは**メラトニン**。
2. 高齢者の睡眠は「**中途覚醒・早朝覚醒が増え、深い眠りが減り、睡眠時間は短くなる**」。
3. 睡眠障害は症状で見分ける：**脚を動かすと楽＝レストレスレッグス**、**寝ている間に脚がぴくぴく＝周期性四肢運動障害**、**いびきが途切れる＝睡眠時無呼吸**。

## ① 睡眠のしくみ【こころとからだのしくみ】

### レム睡眠とノンレム睡眠

| | **ノンレム睡眠** | **レム睡眠** |
|---|---|---|
| 眠りの深さ | **いちばん深い眠り**を含む（第24・27回） | 浅い |
| 脳 | **脳が休む** | 脳は活動している |
| 体 | 筋肉はある程度働く | **筋肉の緊張がなくなる** |
| 目 | — | **速い眼球運動**（Rapid Eye Movement） |
| 夢 | — | **夢を見る**（第33回） |
| 役割 | **成長ホルモン**の分泌 | **記憶を整理・定着**させる（第37回） |
| 出る順 | **入眠はノンレムから** | ノンレムの後に出る |

- ノンレム → レムの組み合わせを**約90分**ごとに繰り返す（30分・60分は×）
- 明け方に近づくほどレム睡眠が長くなる

### 体内時計

| ○ | × |
|---|---|
| 体内時計は脳の**視床下部（視交叉上核）**にある | 松果体・下垂体（松果体はメラトニンを出す場所） |
| 24時間に合わせる最も強力な因子は**日光**（第30回） | 食事・運動・仕事・入浴 |
| 眠りを促すホルモンは**メラトニン**（第28回） | コルチゾール（朝に増え目覚めを促す）・インスリン |
| 睡眠中は**体温が下がる** | 体温が上がる |

### 高齢者の睡眠（第26・29・31・33回）

| ○ | × |
|---|---|
| **中途覚醒**が多くなる | 夜間の睡眠時間が長くなる |
| **早朝覚醒**が多くなる | 早朝覚醒が少なくなる |
| **深い眠り（深睡眠）が減る**、眠りが浅い | 眠りが深くなる・ノンレムやレムが増える |
| **睡眠周期が不規則**になる | 熟眠感が増える・寝つきが早くなる |
| 睡眠時間は**短く**なる。65歳で**約6時間**（第38回） | 長いほど健康的 |

## ② 睡眠障害と睡眠に影響する薬・習慣【こころとからだのしくみ】

### 不眠の4タイプ

| タイプ | 中身 |
|---|---|
| 入眠障害 | **寝つけない** |
| 中途覚醒 | 夜中に**何度も目が覚める** |
| 早朝覚醒 | 朝早く目が覚め、**もう眠れない** |
| **熟眠障害** | 時間は十分なのに**ぐっすり眠った感じがしない**（第30回） |

### そのほかの睡眠障害

| 障害 | 特徴 |
|---|---|
| **睡眠時無呼吸症候群** | 寝ている間に呼吸が止まる。**いびきが途切れる**。原因に**肥満**（第27回）。日中の眠気 |
| **レストレスレッグス症候群**（むずむず脚症候群） | 夕方〜夜に**脚がむずむず**して眠れない。**脚を動かすと楽になる**（第31回）。**入眠障害**の原因 |
| **周期性四肢運動障害** | 寝ている間に**脚がぴくぴく**動く。本人は気づかず、**日中に眠い**（第37回） |
| **レム睡眠行動障害** | **夢の中の行動がそのまま出る**（大声・激しい動き）。レビー小体型認知症に多い |
| **概日リズム睡眠障害** | **夕方に強い眠気**で寝てしまい、**深夜に目が覚める**（第36回） |

### 睡眠に影響する薬・習慣

| 原因 | 影響 |
|---|---|
| **抗ヒスタミン薬**（かぜ薬・アレルギー薬） | **夜十分寝ても日中に強い眠気**（第32回）。覚醒作用は× |
| **就寝前の飲酒** | 寝つきはよくても**眠りが浅くなる**（第36回） |
| **就寝前の夜食** | 消化のために眠りが浅くなる（第34回） |
| カフェイン・ニコチン | 覚醒作用 |
| **高齢者の睡眠薬** | **翌朝まで作用が残る**（持ち越し）、**ふらつき・転倒**、依存、**アルコールと一緒は危険**（第35回） |

> 大切な人を亡くした後の寂しさ・無力感・不眠・食欲不振などの反応 ＝ **グリーフ（悲嘆）**（第35回）。

<details>
<summary>✏️ 解いてみよう（第37回・事例）</summary>

76歳の男性。数週間、日中に「眠い」と訴える。毎日15時にコーヒー1杯とたばこ1本、21時に就寝。夜間に観察すると、睡眠中に下肢がぴくぴく動くことがたびたびあった。起床後、手足の異常は「特にない」という。睡眠障害の原因として最も適切なものはどれ？

1. ニコチン摂取
2. レム睡眠行動障害
3. レストレスレッグス症候群
4. カフェイン摂取
5. 周期性四肢運動障害

<details class="answer">
<summary>正解を見る</summary>

**正解：5**　本人は気づかないうちに脚が動き、眠りが浅くなって日中に眠くなります。3は「脚がむずむずして眠れない」と本人が自覚します。
</details>
</details>
