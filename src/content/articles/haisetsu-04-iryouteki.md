**この記事のポイント**

1. 介護福祉職は「**本人がする医療的なことを支える**」立場。カテーテルを入れるなど、本人や看護師の代わりはしない。
2. ストーマのパウチは**1/3〜1/2**たまったら処理する。**装具を外して入浴してもよい**。
3. 市販の使い捨て浣腸は介護福祉職も使える。<strong>39〜40℃</strong>に温め、**左側を下にして**、**ゆっくり**注入する。

---

**医行為**＝医師や看護師などの医療職でなければ行えない行為。ただし国の通知で「医行為ではない」と示されたものは、介護福祉職も行えます。この記事に出てくる行為を整理すると次のとおりです。

| ○ 介護福祉職もできる（医行為ではない） | × 介護福祉職はしない（医行為） |
|---|---|
| 自己導尿の**補助**（カテーテルの準備・体位の保持） | 他人の尿道にカテーテルを入れる導尿 |
| ストーマのパウチにたまった**排泄物を捨てる** | 状態が不安定なストーマの管理 |
| ストーマ装具の**交換**（ストーマと周りの皮膚が安定しているとき） | 膀胱留置カテーテルの挿入・抜去 |
| **市販の使い捨てグリセリン浣腸器**での浣腸 | 指で便をかき出す**摘便** |

- 根拠は2005年（平成17年）の通知（医行為ではない行為の一覧）と、ストーマ装具の交換についての2011年（平成23年）の通知です

## ① 自己導尿

脊髄損傷などで自力の排尿が難しい人が、**自分で**尿道にカテーテルを入れて尿を出す方法です。

| ○ 介護福祉職がすること | × しないこと |
|---|---|
| **座位**で行えるよう環境を整える | 利用者と一緒にカテーテルを持って挿入する |
| 座位が不安定なら**体を支える** | 導尿中、ずっとそばで見ている（プライバシー） |
| 尿の色や量を**観察**し、異常があれば看護師へ | 「尿の観察は自分でして」と任せきりにする |

- 決まった時間に自分でカテーテルを入れて排尿する方法を**間欠的自己導尿**といいます
- 再利用型のカテーテルは、使ったあと水で洗い、**専用ケースの消毒液に入れて保管**するのが一般的です（乾かしておくのではない）。管理の方法は医療職の指導に従います

## ② ストーマ（人工肛門・人工膀胱）

<photo name="haisetsu-04__stoma" caption="ストーマ装具（パウチ）。肌に貼る**面板**と袋。袋は**3分の1〜2分の1**たまったら捨て、面板の交換は**入浴後**など皮膚が清潔なときに。">

お腹に作った排泄口のことです。便が出る**消化管ストーマ**（結腸・回腸）と、尿が出る**尿路ストーマ**があります。

- ストーマには肛門のような括約筋がないので、**自分の意思で排泄をコントロールできない**
- パウチ（袋）は、排泄物が**1/3〜1/2**たまったら処理する（重みで外れたり漏れたりするのを防ぐ）
- 入浴は、**装具を外しても、着けたままでもよい**。ストーマから湯が入ることはない
- ストーマの周りは**こすらず**、やさしく洗う
- ウエストをベルトで締めつける服は避ける。ラジオ体操などの**運動はしてよい**。食物繊維のとりすぎ（れんこん・ごぼうなど）は便がつまる原因になる

便のかたさは、腸のどこにストーマをつくったかで変わります（大腸の順番は[排泄①「便秘の種類と自然排便の介助」](../haisetsu-01-benpi/)の①）。

| ストーマの場所 | 便の性状 | 注意 |
|---|---|---|
| **回腸**（小腸の終わり） | **水っぽい** | **脱水に注意**して水分をとる（水分を控えるのは×） |
| 横行結腸 | 泥状〜やわらかい | — |
| 下行結腸・S状結腸 | **かため**（ふつうの便に近い） | — |

## ③ 浣腸（市販の使い捨てグリセリン浣腸器）

市販の使い捨てグリセリン浣腸器を使う浣腸は、**医行為ではない**ため、介護福祉職も行えます。

| ポイント | ○ | × |
|---|---|---|
| 温度 | **39〜40℃**（体温より少し高め） | 冷たいまま／熱すぎる |
| 姿勢 | **左側を下にした横向き**（左側臥位） | **立位**（腸を傷つける危険） |
| 注入 | **ゆっくり** | すばやく |
| 注入後 | **少し我慢してから**排便してもらう | すぐに排便させる |
| 出なかったら | 看護師に報告 | 自己判断でもう1本入れる |

- 「市販の使い捨て浣腸器」の条件（通知）：挿入部の長さが5〜6cm程度以内、グリセリン濃度50％、成人用で40g程度以下

> 左側臥位にする理由：直腸からS状結腸は体の左側にあるので、左を下にすると液が自然に奥へ流れます。排泄①の「消化管の順番」とつながる知識です。

## ④ 膀胱留置カテーテル

尿道から膀胱に管を入れたままにして、尿を袋（蓄尿バッグ）にためる方法です。挿入・抜去は医療職が行います。

| ○ 介護福祉職が気をつけること | × |
|---|---|
| 蓄尿バッグは**膀胱より低い位置**に置く（尿が膀胱へ逆流すると感染の原因になる） | 膀胱より高い位置に置く／床に直接置く |
| 管が折れたりねじれたりしていないか確認する | — |
| 男性はカテーテルを**上向きにして下腹部に固定**する（陰茎のつけ根の尿道が傷つくのを防ぐ） | — |
| 医師の指示の範囲で、十分な水分をとってもらう（尿の流れをよくして感染を防ぐ） | 水分を控える |
| バッグにはカバーをかけ、人目に配慮する | — |
| 抜いてしまう心配があっても、介護職の判断で**ミトンなどを使わない**（身体拘束にあたる） | ミトンや抑制帯で手を固定する |

## ひっかけパターン集（医療的な排泄ケアで「ほぼ×」）

| 選択肢の表現 | なぜ× |
|---|---|
| 介護福祉職がカテーテルを挿入する／一緒に持つ | 本人が行う行為。介護福祉職は支える側 |
| ストーマがあると入浴・公衆浴場は避ける | 入浴できる。生活を制限しない |
| 回腸ストーマの人は水分を控える | 脱水の危険がある |
| 浣腸は立位で／すばやく注入 | 腸を傷つける危険がある |
| 自己判断で浣腸を追加する | 看護師に報告・相談する |
| 蓄尿バッグを膀胱より高く置く | 尿が逆流して感染の原因になる |
| 介護福祉職が摘便をする | 医行為なので行わない |
