**この記事のポイント**

1. 認知症ケアの軸は**その人らしさ**（パーソン・センタード・ケア）と**本人の意思決定**。BPSDを「なくす」こと自体は目的ではない。
2. **日付・季節・場所を伝える＝リアリティ・オリエンテーション**、**昔の写真・音楽＝回想法**。
3. ユマニチュードは「**見る・話す・触れる・立つ**」。バリデーションは**ミラーリング・カリブレーション**で動きや感情に合わせる。

## ① 認知症ケアの考え方

| 考え方・ツール | ○ 正しい説明 | × よく出る誤り |
|---|---|---|
| **パーソン・センタード・ケア**（キットウッド） | 認知症の人の<strong>「その人らしさ」を支える</strong> | BPSDをなくす／特別な存在として保護する／マニュアルをつくる |
| **ひもときシート** | 言動の**背景要因を分析**して本人を理解するツール。**評価的理解 → 分析的理解（8つの視点）→ 共感的理解**の順。介護者の視点から**本人の視点**へ切り替える | 最初に分析的理解／介護者側の視点でとらえる |
| **認知症ライフサポートモデル** | **本人の自己決定を支える**。多職種が**共通の目標**をもち、早期から終末期まで継続して支える | 職種ごとに目標設定／終末期の介入モデル／施設入所を促す |
| **意思決定支援ガイドライン**（2018年） | **身振りや表情の変化も意思表示**として読み取る。支援者は**職種を限らない**。意思は変わるので**繰り返し確認** | 家族の意思を支援する／一度決めたら最後まで同じ／看取り期から開始 |
| グループホームのケア | **なじみの関係**、**力を発揮できる場面**、**家庭的な環境**、**地域との交流** | BPSDの治療に焦点を当てる |

### パーソン・センタード・ケアの心理的ニーズ

キットウッドは、認知症の人の心理的ニーズを、中心にある**愛**と、それを囲む5つで表しました。

| ニーズ | 意味 |
|---|---|
| くつろぎ（やすらぎ） | 緊張や不安がなく、心地よくいられる |
| 自分らしさ（アイデンティティ） | 自分が誰で、どう生きてきたかを大切にされる |
| 結びつき（愛着） | 人や物とのつながりを感じられる |
| たずさわること | 意味のある活動や役割に参加できる |
| 共にあること | 仲間の一員として受け入れられる |

- **認知症ケアマッピング（DCM）**＝ケアの場面を観察し、本人がよい状態か・よくない状態かを記録して、パーソン・センタード・ケアの実践を見直す方法

### ひもときシートの3段階

| 段階 | すること |
|---|---|
| ① 評価的理解 | まず**介護者が困っていること**・どうしたいかを書き出す（介護者の視点） |
| ② 分析的理解 | **8つの視点**（病気・薬の影響、痛みや便秘など体の不調、音や光などの環境、関わり方など）で、言動の**原因・背景を探る** |
| ③ 共感的理解 | **本人の気持ちになって**考え、本人にとっての意味やニーズを見つける（本人の視点） |

### 意思決定支援の3段階（ガイドライン）

意思形成支援（判断に必要な情報をわかりやすく伝える）→ 意思表明支援（思いを言葉や表情で表せるよう支える）→ 意思実現支援（決めたことを生活の中で実現する）

**胃ろうをつくるかどうか**（重度の認知症）：主治医・家族・後見人が単独で決めるのではなく、**本人の意向や価値観を把握し、本人にとっての最善を関係者で判断する**。

## ② ケアの技法・非薬物療法

3つの技法は「**RO＝今の現実に合わせる**」「**回想法＝過去を語る**」「**バリデーション＝本人の現実に合わせる**」と覚えます。

<photo name="ninchishocare-01__ro-kaisou" caption="左はリアリティ・オリエンテーション（季節の絵やカレンダーで日付・季節・場所を伝える）、右は回想法（昔の写真や道具を手に思い出を語り合う）の場面です。">

| 技法 | 中身 | 試験の見分け方 |
|---|---|---|
| **リアリティ・オリエンテーション（RO）**（現実見当識訓練） | 名前・日付・場所などをくり返し伝え、**見当識に働きかける** | **日付・季節・天気・場所を伝える**。ホワイトボードに日付と季節の絵を描き「今日は6月22日」と伝える |
| 24時間RO（非定型RO） | 日常の**ふだんの会話の中で**、さりげなく伝え続ける | 第34回の正解 |
| クラスルームRO（定型RO） | **少人数のグループ**で、**決まった時間**に行う | — |
| **回想法** | **昔の写真・音楽・道具**を使って**楽しい思い出**を語ってもらい、記憶を活性化（グループでも個別でも） | **豊かな情動**をもたらす。楽しい思い出の手がかりを準備し、**同じ場所**で行う。事実と違っても否定しない |
| ライフレビュー | **つらい体験も含めて人生全体**を振り返り、意味づけて整理する | 回想法と混同しやすい |
| **バリデーション** | 認知症の人の体験している現実を**共感して受け入れる** | 技法：**ミラーリング（動きを鏡のように合わせる）・カリブレーション（感情に合わせる）**、センタリング（介護者が精神を集中）、リフレージング（言葉を繰り返す）、レミニシング（思い出話） |
| **ユマニチュード** | 4つの柱「**見る・話す・触れる・立つ**」 | **立つ＝立位をとる機会をつくる** |
| タッチング | 肩や背中から優しくゆっくり触れる | — |
| 音楽療法 | 歌う・簡単な楽器を鳴らす・音楽に合わせて体を動かす。緊張や不安をやわらげ、自発性や体力を引き出す | — |
| 運動療法 | 初期は体を動かして心の活動を高め、進んだあとは関節を動かす訓練などで日常生活の力を保つ | — |

> 薬だけでなく、こうした**非薬物療法**を組み合わせることで、生活の質（QOL）を高めます。

### ユマニチュードの4つの柱

| 柱 | ○ | × |
|---|---|---|
| 見る | **正面から、近く、同じ高さで、長く**見る | 離れた位置からさりげなく見守る |
| 話す | **低めの穏やかな声**で、前向きな言葉を | 高いトーンの大きな声 |
| 触れる | **広い面積で、ゆっくり**触れる | 指先で軽く触れる |
| 立つ | **立つ機会をつくる**（1日20分程度） | — |

> オートフィードバック＝**自分が行っているケアを実況する**ように話すこと（ケアの評価ではない）。
