## ① 浴室での介助【生活支援技術】

### 片麻痺の人の浴槽の出入り

| 場面 | ○ | × |
|---|---|---|
| 浴槽に入る | **健側の足から**（健側で湯温を確かめられる） | 麻痺側から入る |
| 湯につかる | 手すりや浴槽の縁につかまり、ゆっくり | — |
| 浴槽の中 | **足で浴槽の壁を押して**姿勢を安定させる（第36回） | 後ろに寄りかかって足を伸ばす（体が浮いて沈む） |
| 浴槽から出る | **浴槽の縁やバスボードにいったん座る**（第26回） | 真上に立ち上がる（前かがみで立つ） |
| 介護者の位置 | 麻痺側について支える | — |

### 用具と環境

- 移乗台・シャワーチェアーは**浴槽の縁と同じ高さ**にする
- シャワー用車いすは**段差に注意**して移動する（第34回）
- 入浴用介助ベルトは**腰部**に装着する
- 手すりは浴槽の出入りのために**水平と垂直**の両方をつける（第37回）
- 浴室の入口は**引き戸**が使いやすい（開き戸は×）
- 第38回：頸髄損傷（C5）で電動車いすを使う人 → **入浴用リフト**

### シャワー浴・特殊浴槽

- 湯温は**介護福祉職が先に**確かめてから利用者に確かめてもらう
- かけるときは**足元（末梢）から**
- 利用者が陰部を洗うときは、**背部に立って見守る**（プライバシーへの配慮、第34回）
- 寒いと言われても熱いシャワーはかけない。水分は**浴室内で**拭いてから脱衣室へ
- 特殊浴槽（ストレッチャー式）：**背部は側臥位**にして洗う（第36回）、固定ベルトはつけたまま、首までつからない

### 認知症の人の入浴

- 時間をかければ自分でできる人には、**衣服を着る順番に合わせて声をかける**（第35回）。代わりに洗う・着せるは×

一般浴（個浴）で、右片麻痺の利用者が移乗台に座っている。安全に入浴するための助言として最も適切なものはどれ？

1. 「浴槽に入るときは、右足から入りましょう」

## ② 部分浴（手浴・足浴）【生活支援技術】

| ポイント | ○ | × |
|---|---|---|
| 効果 | 手浴は温めて指を動かすことで**拘縮予防**、足浴は**安眠**につながる | 足浴で目が覚める |
| 支え方 | 洗う側の**足関節・手関節を支えて**洗う | — |
| 椅座位の足浴 | **足底が容器の底についている**ことを確認 | — |
| 衣服 | ズボンは**まくる** | ズボンを脱がせて下肢を出す |
| 湯温の確認 | 介護福祉職 → 利用者の順 | 利用者が先 |
| 終わったら | 泡は**洗い流し**、指の間まで**よく拭いて乾かす** | 自然乾燥 |
| 時間 | 長すぎない | 長いほど良い・30分以上 |

## ③ 清拭・洗髪・陰部洗浄【生活支援技術】

### 全身清拭

| ポイント | 正解 |
|---|---|
| 湯の温度 | 洗面器には熱めの湯（**50〜55℃程度**）を準備（40℃は×） |
| 拭く方向 | 四肢は**末梢から中枢**へ |
| 目 | **目頭から目尻**へ（1回ごとにタオルの面を変える） |
| 腹部 | 腸の走行に沿って**時計回り**（「の」の字） |
| 背部 | **健側を下**にした側臥位で拭く（患側を下にすると圧迫・痛み） |
| 水分 | 拭いたら**その都度、乾いたタオルで**拭き取る |
| 環境 | 窓を閉め、室温を暖かく |

### ベッド上の洗髪（ケリーパッド）

1. 洗う前に**ブラッシング**しておく
2. 膝は軽く**曲げて**楽な姿勢に（伸ばしたままは×）
3. 湯は少しずつかけ、**指の腹**で洗う（爪を立てない）
4. **すすぐ前に、タオルで泡を拭き取る**（すすぎの湯が少なくて済む。第25回・第31回・第35回）
5. ドライヤーは**頭皮から離して**使う

### 陰部洗浄

- 両下肢は**バスタオルで包む**（保温とプライバシー、第38回）
- 湯は**ぬるま湯**（38℃前後）。滅菌手袋は不要（使い捨て手袋）
- 女性は**前から後ろへ**。終わったら**乾いたタオルで**水分を拭く（蒸しタオルは×）

<details>
<summary>✏️ 解いてみよう（第32回）</summary>

清拭の介護として、最も適切なものはどれ？

1. 目のまわりは目尻から目頭に向かって拭く
2. 背部は患側を下にして拭く
3. 腹部は臍部から恥骨部に向かって拭く
4. 両下肢は末梢から中枢に向かって拭く
5. 皮膚についた水分は最後にまとめて拭く

<details class="answer">
<summary>正解を見る</summary>

**正解：4**　末梢から中枢へ拭くと、血液やリンパの流れを助けます。1は逆（目頭→目尻）、2は逆（健側を下）、5は「その都度」が正解です。
</details>
