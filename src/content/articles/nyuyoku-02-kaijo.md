**この記事のポイント**

1. 片麻痺の人は**健側から浴槽に入り**、出るときは**前かがみ**で立つ（または縁やバスボードにいったん座ってから）。
2. 清拭は**末梢から中枢へ**、水分は**その都度**拭く。背部を拭くときは**健側を下**に。
3. 洗髪は「**すすぐ前に泡をタオルで拭き取る**」（3回出題）。

> この記事の言葉：**健側**＝麻痺のない側、**患側**＝麻痺のある側。**末梢**＝手足の先、**中枢**＝心臓に近いほう。**側臥位**＝横向きに寝た姿勢。

## ① 浴室での介助

### 片麻痺の人の浴槽の出入り

| 場面 | ○ | × |
|---|---|---|
| 浴槽に入る | **健側の足から**（健側で湯温を確かめられる） | 麻痺側から入る |
| 湯につかる | 手すりや浴槽の縁につかまり、ゆっくり | — |
| 浴槽の中 | **足で浴槽の壁を押して**姿勢を安定させる | 後ろに寄りかかって足を伸ばす（体が浮いて沈む） |
| 浴槽から出る | **前かがみ**になって立つ（または浴槽の縁やバスボードにいったん座る） | 真上に立ち上がる（重心が前に移らず立てない・ふらつく） |
| 介護者の位置 | 麻痺側について支える | — |

## ② 部分浴（手浴・足浴）

| ポイント | ○ | × |
|---|---|---|
| 湯温 | 手浴・足浴は**ぬるめ（37〜39℃）** | 熱い湯 |
| 効果 | 手浴は温めて指を動かすことで**拘縮予防**、足浴は**安眠**につながる | 足浴で目が覚める |
| 支え方 | 洗う側の**足関節・手関節を支えて**洗う | — |

## ③ 清拭・洗髪・陰部洗浄

### 全身清拭

清拭（せいしき）は、入浴できない人の体をタオルで拭いて清潔にすることです。**血行をよくする**ほか、全身の皮膚を**観察する機会**にもなります。

| ポイント | 正解 |
|---|---|
| 湯の温度 | 洗面器には熱めの湯（**50〜55℃程度**）を準備。絞ったタオルが肌に当たるころには40℃前後になる（40℃の湯で準備は×：すぐ冷める） |
| 室温 | 窓を閉め、室温は**24℃前後**に暖かく |
| 拭く順番 | **顔から**始め、上肢→胸・腹部→背部・腰部→下肢→陰部 |
| 拭く方向 | 四肢は**末梢から中枢**へ |
| 目 | **目頭から目尻**へ（1回ごとにタオルの面を変える） |
| 顔 | 額→頬→あごへ<strong>「3」の字</strong>を書くように |
| 腹部 | 腸の走行に沿って**時計回り**（「の」の字） |
| 背部 | **健側を下**にした側臥位で拭く（患側を下にすると圧迫・痛み） |
| 水分 | 拭いたら**その都度、乾いたタオルで**拭き取る（残ると気化熱で冷える） |

### ベッド上の洗髪（ケリーパッド）

1. 洗う前に**ブラッシング**しておく。体全体をベッドの端に寄せることはしない（転落の危険）
2. 膝は軽く**曲げて**クッションで支え、楽な姿勢に（伸ばしたままは×）
3. 湯は少しずつかけ、**指の腹**で**生え際から頭頂部へ**洗う（爪を立てない）
4. **すすぐ前に、タオルで泡を拭き取る**（すすぎの湯が少なくて済む。第25回・第31回・第35回）
5. ドライヤーは**頭皮から離して**（20cm程度）使い、同じ所に当て続けない
- 洗髪中に気分が悪いと言われたら**中止して医療職に連絡**
- 湯を使えないときは**ドライシャンプー**（水を使わない）、皮脂やふけが多い人には**オイルシャンプー**

### 陰部洗浄

- 両下肢は**バスタオルで包む**（保温とプライバシー、第38回）
- 湯は**ぬるま湯**（**38〜39℃程度**）。滅菌手袋は不要（使い捨て手袋）
- 上半身をベッドの端へ寄せる必要はない（転落の危険）
- 女性は**前から後ろへ**（尿路感染予防）。殿部は内側から外側へ。終わったら**乾いたタオルで押さえ拭き**（蒸しタオルは×）

| 特殊浴槽で首までつかる・固定ベルトを腕の上から | 肩まで・5分程度。ベルトは腕の上から締めない |
| 清拭の湯を40℃で準備 | すぐ冷めて寒くなる |
| 水分を最後にまとめて拭く | 気化熱で体が冷える |
| 洗髪で爪を立てる | 頭皮を傷つける |
