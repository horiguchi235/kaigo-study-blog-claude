**結論を3行で**

1. 利用者が**不安や迷いを打ち明けた**ら、正解は「**まず思いを聴く**」「**理由を確かめる**」。提案・説得・励ましは後回し。
2. 様子が変わった人・落ち込んでいる人には、**昔の仕事・趣味・役割**を生かす支援が正解。
3. 「安全のため」「家族が言っているから」と**本人の意思より優先する選択肢は×**。

## ① 型1：不安や迷いには、まず思いを聴く・理由を確かめる【介護の基本／人間の尊厳と自立】

**見分け方**：事例の最後が「〜と話した」「〜と打ち明けた」「〜と相談した」で終わり、「**最初の**対応」「応答」を聞かれたらこの型です。

| 回 | 本人の言葉・状況 | 正解 |
|---|---|---|
| 第30回 | 「この家で死にたいと思っていたけど、いつまで二人で暮らせるか…」 | 「**何か心配なことがおありなんですね**」 |
| 第31回 | 骨折後、一人暮らしを続けることが不安と告げた | 「**また転ぶかもしれないと思っているのですか**」 |
| 第36回 | 「自宅で暮らし続けたいけど、心配なの…」 | **生活に対する思いを聞く** |
| 第34回 | 「性同一性障害でも施設に受け入れてもらえるでしょうか」 | 「**施設での生活で心配なことは何ですか**」 |
| 第35回 | 認知症で「サービスを変更したい」「夫とは話したくない」 | **変更したい理由を本人に確認**（夫の同席・決断を急がせるは×） |
| 第24回 | 自助具をすすめたが、どうしても家族の介助を受けたい | **なぜ家族の介助を望むのか理由を聞く** |
| 第37回 | 片麻痺の人が実習生に「腕が痛いので車いすを押して」と頼む | 「**依頼する理由を、まず考えてみることが大切です**」 |
| 第32回 | 延命治療の計画書を作ったが、自宅で静かに過ごしたい気持ちに迷い | 「**意思確認のための話合いは、何度でもできますよ**」 |
| 第38回 | ALSの夫。妻は「人工呼吸器をつけてほしい」と夫に言えない | 「**お互いの気持ちを話し合う時間をつくりませんか**」 |

**よく出る不正解**：施設入所・同居・入院を**すぐ提案**する／「大丈夫ですよ」と根拠なく安心させる／家族や医師に**決めてもらう**／「〜しないで」と一方的に指示する

> 意思は変わってもよいものです。人生の最終段階の医療・ケアについて、本人・家族・支援者がくり返し話し合うことを**アドバンス・ケア・プランニング（ACP、人生会議）**といいます。

<details>
<summary>✏️ 解いてみよう（第37回）</summary>

家族から「できることは自分でさせてほしい」と言われている片麻痺の女性。最近、実習生に「今日は腕が痛いので、食堂まで車いすを押してください」と頼むようになった。悩んだ実習生への実習指導者の最初の助言として、最も適切なものはどれ？

1. 「腕は痛くないので、気にしないでください」
2. 「どのようなときも、本人に行ってもらうことが必要です」
3. 「家族から自分で行うように言われています」
4. 「自立につながらないので、押さないでください」
5. 「依頼する理由を、まず考えてみることが大切です」

<details class="answer">
<summary>正解を見る</summary>

**正解：5**　頼むのには理由があるはずです（本当に痛い、実習生と話したい、不安がある…）。理由を確かめずに断るのも、言われるままに押すのも、最初の対応ではありません。
</details>
</details>

## ② 型2：生活歴・役割・楽しみを生かす【介護の基本／生活支援技術】

**見分け方**：事例に**昔の仕事や趣味**が書かれていて、今は元気がない・落ち着かない・帰りたがる、という流れならこの型です。

| 回 | 生活歴・状況 | 正解 |
|---|---|---|
| 第31回 | 茶道の師範。寝ていることが多く、表情が乏しい | **お茶のたて方を話題にする** |
| 第32回 | 毎朝コーヒーを豆から入れていたが、失敗が増えて自信をなくす | 夫が「**そばにいて一緒にコーヒーを入れる**」 |
| 第32回 | 美容院・俳句教室が楽しみだった | **おしゃれをして俳句クラブに参加**を勧める（ノーマライゼーション） |
| 第37回 | 夕方「ご飯の支度をしないと」と帰りたがる | **職員と一緒に夕食の準備**をしてもらう |
| 第35回 | 夕方「家に帰らないといけない」と訴える | 「**家のことが気になるんですね**」と気持ちを受け止める |
| 第30回 | 「仕事があるから夜に一人で入浴したい」と日中の入浴を拒否 | **働いていた頃の話を詳しく聴く** |
| 第38回 | 元地域の医師。最期まで自宅で暮らしたい | 「**近所の方の力も借りて、この地域で暮らせるように**考えましょう」 |
| 第35回 | 「台所を借りて自分でおやつを作りたい」 | おやつ作りをきっかけに**施設生活に楽しみ**がもてるように |

**レクリエーション**
- 買物や調理など**生活に根ざした活動**も取り入れる（第36回）
- 過去の趣味を取り入れる。地域のボランティアも歓迎。全員参加を強制しない
- **アイスブレーキング**：参加者の**緊張をほぐす**（第37回）

**よく出る不正解**：「ここが家ですよ」「仕事はないですよ」と**事実で否定**する／鍵をかける・薬で落ち着かせる／転倒予防で車いす・居室中心にする／職員がメニューや役割を決める

<details>
<summary>✏️ 解いてみよう（第37回・事例）</summary>

血管性認知症で軽い左片麻痺のある75歳の女性。ユニット型の施設に入所後、夕方になると「ご飯の支度をしないといけないから帰ります」と言い、興奮して歩き回る。対応として最も適切なものはどれ？

1. 居室に鍵をかけて、自室で過ごしてもらう
2. 介護福祉職と一緒に、夕食の準備をしてもらう
3. 杖を預かり、低めの丸椅子に座ってもらう
4. 介護福祉職の判断で、向精神薬を服用してもらう
5. ここが自宅であることを理解してもらう

<details class="answer">
<summary>正解を見る</summary>

**正解：2**　「ご飯の支度」は、本人が長年担ってきた大切な役割です。その役割を施設の中で果たせるようにすると、落ち着きを取り戻しやすくなります。1・3は身体拘束にあたるおそれもあります。
</details>
</details>

## ひっかけパターン集（自己決定の事例で「ほぼ×」）

| 選択肢の表現 | なぜ× |
|---|---|
| すぐに施設・同居・入院を勧める | 思いを聴く前に結論を出している |
| 「大丈夫」「心配いらない」と励ます | 不安を受け止めていない |
| 家族・医師・職員に決めてもらう | 決めるのは本人 |
| 「ここが家ですよ」と事実で正す | 気持ちを否定している |
| 安全のために活動を制限する | 自立・尊厳を奪う。身体拘束のおそれ |
