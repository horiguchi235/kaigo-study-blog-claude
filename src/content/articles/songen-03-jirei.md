**この記事のポイント**

1. 利用者が**不安や迷いを打ち明けた**ら、正解は「**まず思いを聴く**」「**理由を確かめる**」。提案・説得・励ましは後回し。
2. 様子が変わった人・落ち込んでいる人には、**昔の仕事・趣味・役割**を生かす支援が正解。
3. 「安全のため」「家族が言っているから」と**本人の意思より優先する選択肢は×**。危険は、本人の選択を尊重したうえで**減らす工夫**をする。

> **解き方の手順**：事例の最後の一文を見る → 型1〜型3のどれかを判定する → ひっかけパターン集の×を消す。病名（ALS・血管性認知症など）がわからなくても、この手順で解けます。

## ① 型1：不安や迷いには、まず思いを聴く・理由を確かめる

**見分け方**：事例の最後が「〜と話した」「〜と打ち明けた」「〜と相談した」で終わり、「**最初の**対応」「応答」を聞かれたらこの型です。

| 回 | 本人の言葉・状況 | 正解 |
|---|---|---|
| 第38回 | ALS（全身の筋力が落ちていく病気）の夫。妻は「人工呼吸器をつけてほしい」と夫に言えない | 「**お互いの気持ちを話し合う時間をつくりませんか**」 |
| 第37回 | 片麻痺の人が実習生に「腕が痛いので車いすを押して」と頼む | 「**依頼する理由を、まず考えてみることが大切です**」 |
| 第36回 | 「自宅で暮らし続けたいけど、心配なの…」 | **生活に対する思いを聞く** |
| 第35回 | 認知症で「サービスを変更したい」「夫とは話したくない」 | **変更したい理由を本人に確認**（夫の同席・決断を急がせるは×） |
| 第34回 | 「性同一性障害でも施設に受け入れてもらえるでしょうか」（現在、WHOの分類では「性別不合」と呼ぶ） | 「**施設での生活で心配なことは何ですか**」 |
| 第32回 | 延命治療の計画書を作ったが、自宅で静かに過ごしたい気持ちに迷い | 「**意思確認のための話合いは、何度でもできますよ**」 |
| 第31回 | 骨折後、一人暮らしを続けることが不安と告げた | 「**また転ぶかもしれないと思っているのですか**」 |
| 第30回 | 「この家で死にたいと思っていたけど、いつまで二人で暮らせるか…」 | 「**何か心配なことがおありなんですね**」 |
| 第24回 | 自助具をすすめたが、どうしても家族の介助を受けたい | **なぜ家族の介助を望むのか理由を聞く** |

**よく出る不正解**：施設入所・同居・入院を**すぐ提案**する／「大丈夫ですよ」と根拠なく安心させる／家族や医師に**決めてもらう**／「〜しないで」と一方的に指示する

> 意思は変わってもよいものです。人生の最終段階の医療・ケアについて、本人・家族・支援者がくり返し話し合うことを<strong>アドバンス・ケア・プランニング（ACP、人生会議）</strong>といいます。施設入所時などに書く「延命治療に関する意思確認書」も、**一度書いたあとで変更できます**。

### 意思決定支援とは

判断能力が低下した人も含め、**本人が自分で決められるように支える**ことです。厚生労働省のガイドライン（障害福祉サービス 2017年、認知症の人 2018年）では、次の3段階で考えます。

| 段階 | 支援の中身 |
|---|---|
| **意思形成**支援 | 本人が決めるのに必要な情報を、わかる形で伝える |
| **意思表明**支援 | 本人が思いを言葉にできるよう、聴く・待つ（家族の前では言いにくいことにも配慮） |
| **意思実現**支援 | 本人が決めたことを、チームや社会資源を使って実現する |

型1の「まず聴く・理由を確かめる」は、意思表明支援にあたります。

## ② 型2：生活歴・役割・楽しみを生かす

**見分け方**：事例に**昔の仕事や趣味**が書かれていて、今は元気がない・落ち着かない・帰りたがる、という流れならこの型です。帰宅願望のように本人の言葉で終わる事例は、**型1（まず気持ちを受け止める）と型2（生活歴をくみ取る）の両方**で考えます。

| 回 | 生活歴・状況 | 正解 |
|---|---|---|
| 第38回 | 元地域の医師。最期まで自宅で暮らしたい | 「**近所の方の力も借りて、この地域で暮らせるように**考えましょう」 |
| 第37回 | 料理好き。夕方「ご飯の支度をしないと」と帰りたがる | **職員と一緒に夕食の準備**をしてもらう |
| 第35回 | 家を守ってきた人が、夕方「家に帰らないといけない」と訴える | 「**家のことが気になるんですね**」と気持ちを受け止める（型1と型2の両方） |
| 第35回 | 「台所を借りて自分でおやつを作りたい」 | おやつ作りをきっかけに**施設生活に楽しみ**がもてるように |
| 第32回 | 毎朝コーヒーを豆から入れていたが、失敗が増えて自信をなくす | 夫が「**そばにいて一緒にコーヒーを入れる**」 |
| 第32回 | 美容院・俳句教室が楽しみだった | **おしゃれをして俳句クラブに参加**を勧める（ノーマライゼーション） |
| 第31回 | 茶道の師範。寝ていることが多く、表情が乏しい | **お茶のたて方を話題にする** |
| 第30回 | 「仕事があるから夜に一人で入浴したい」と日中の入浴を拒否 | **働いていた頃の話を詳しく聴く** |

**レクリエーション**（生活支援技術）：事例ではなく知識問題で出ますが、「本人の趣味・希望・生活を生かす」という考え方は型2と同じです。
- 買物や調理など**生活に根ざした活動**も取り入れる
- 過去の趣味を取り入れる。地域のボランティアも歓迎。全員参加を強制しない
- **アイスブレーキング**：参加者の**緊張をほぐす**

**よく出る不正解**：「ここが家ですよ」「仕事はないですよ」と**事実で否定**する／鍵をかける・薬で落ち着かせる／転倒予防で車いす・居室中心にする／職員がメニューや役割を決める

## ③ 型3：リスクがあっても本人の選択を尊重し、危険を減らす

**見分け方**：転倒・徘徊・病気の悪化など「危ない」状況が書かれ、本人のしたいことと安全がぶつかる事例です。正解は「やめさせる」ではなく、**本人の希望をかなえながら危険を減らす工夫**です。

| ○ 正解の方向 | × よく出る不正解 |
|---|---|
| 一緒に行う・見守る・環境を整える（手すり・動線など） | 転ばないよう車いすや居室で過ごしてもらう |
| 落ち着かない理由を探り、役割や楽しみで安心してもらう | 鍵をかける・杖を預かる・薬で落ち着かせる（身体拘束・虐待につながる） |
| 本人と話し合い、リスクも説明したうえで本人が選ぶ | 家族や職員が「安全のため」と決める |

身体拘束の考え方は [虐待防止と身体拘束](../kenriyougo-02-gyakutai/) で扱います。
