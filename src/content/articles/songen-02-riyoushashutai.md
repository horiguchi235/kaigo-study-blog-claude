**この記事のポイント**

1. 生活の主人公は**利用者**。生活時間・生活習慣・生活歴は**その人独自のもの**で、施設や介護者の都合に合わせない。
2. 迷ったら「**今までどおり**」を選ぶ。畳に布団、夜の入浴、好みの切り方――本人の暮らし方を続けられる選択肢が正解。
3. 見守り的援助＝介護者が**代わりにやる**のではなく、**声をかけて一緒に行う**こと。

---

## ① 生活支援の基本視点【介護の基本／生活支援技術】

| ○ 正解になる視点 | × よく出る不正解 |
|---|---|
| **利用者の意思**を尊重する | 介護者の意向を優先する |
| **生活モデル**・ICFの視点 | 医学モデル・ICIDHの視点 |
| **生活歴**を理解して支援する | 知識より経験を重視する |
| **生活時間はその人独自** | 生活は食事・排泄・睡眠の3つだけ |
| **信頼関係**に基づいて支援する | 支援者の価値観・規則を優先する |
| 利用者の**全体像**をとらえる | できないことを代わりに行うことに重点 |
| **個別ケア** | 集団ケアを優先する |

**よく出る一言**：「1人で生活行為ができることを目的にする」「すべて自分一人でできるようにする」は×です。目的は**その人らしい生活**であって、何でも一人でできることではありません。

## ② 個別性・生活習慣を尊重する【介護の基本】

### 「今までどおり」が正解になる例

| 回 | 場面 | 正解 |
|---|---|---|
| 第32回 | 一人暮らしの認知症の女性 | 本人の意向を確認し、**今までどおり畳で布団**を使う |
| 第33回 | 自宅で夜に入浴していた人 | **夕食後に入浴**してもらう |
| 第34回 | 衣服を選ぶのが難しい人 | **自分で選べるような声かけ**をする（全介助・代わりに選ぶは×） |
| 第35回 | 煮物の調理 | 利用者に**好みの切り方を確認**する |
| 第37回 | 母語が日本語でない人 | 自分で食事ができるよう**自助具の使用状況を確認**（日本語を強制・日本式の布団・余暇を職員が決めるは×） |
| 第25回 | 片麻痺の人の入所当日の食事 | **食べやすい方法を確認**する（決めた席・エプロン・刻み食・全介助は×） |

### 個別性のとらえ方

- 生活習慣は、その人が**生活してきた環境から**理解する
- 年齢から**生きてきた時代**を考えて体験談を聞く。性別・家族構成・所得・障害特性で決めつけない
- その人らしい生活のために最優先で把握する情報は、**これまでの生活環境と生活習慣**
- **エコマップ**：利用者や家族を**取り巻くさまざまな人・機関との関係**を図にしたもの

### プライバシー・羞恥心

- **羞恥心に配慮**した介護を行う
- 愛称で呼ばない。多床室ではカーテンを閉める。入室時は**ノックと声かけ**

施設利用者の多様な生活に配慮した対応として、最も適切なものはどれ？

1. 夜型の生活習慣がある人に、施設の就寝時刻に合わせてもらった
2. 毎日化粧をしていた人に、シーツが汚れるので化粧をやめてもらった
3. 本に囲まれて暮らしてきた人に、散乱している本を捨ててもらった
4. 自宅で畳に布団を敷いて寝ていた人に、ベッドで寝てもらった
5. 自宅で夜間に入浴していた人に、夕食後に入浴してもらった

**正解：5**　1〜4はすべて、施設の都合に本人を合わせています。5だけが、本人の習慣を施設の中で続けられるよう工夫しています。

## ③ 入所・転居のときの配慮【生活支援技術】

環境が大きく変わるときは、**なじみのもの・なじみの人**が心の支えになります。

- 施設入所の負担を減らす → **早くなじみの職員ができる**ようにする。家族の訪問を控える・新しい家具・施設の時間に合わせるは×
- 息子夫婦の家へ引っ越す認知症の人の部屋 → **思い出の小物や写真を飾る**
- 入居して戸惑っている人 → **入居前の生活の様子を聞く**。日課を伝える・役割を職員が決めるは×

## ④ 見守り的援助と生活援助【生活支援技術／介護の基本】

**見守り的援助**＝利用者の自立と重度化防止のために、**一緒に行う・声をかける・そばで確認する**支援です。

| ○ 見守り的援助 | × 単なる代行 |
|---|---|
| ごみの分別が**できるように声をかける** | その場で介護者がごみを分別する |
| 服薬時に**飲むよう促し、そばで確認**する | 冷蔵庫を介護者が整理・期限切れを捨てる |
| — | テレビを見ている横で介護者が洗濯物をたたむ |

**買物代行のルール**：リストどおりに買う（安くても多く買わない）、おつり・レシートは**一緒に確認**、冷蔵庫の中を**勝手に捨てない**、本人が調理するなら**調理しにくい食材がないか確認**する。

<details>
<summary>✏️ 解いてみよう（第33回）</summary>

自立生活支援・重度化防止のための見守り的援助として、最も適切なものはどれ？

1. ごみの分別がわからない利用者なので、その場でごみを分別した
2. 冷蔵庫の中が片づいていないので、整理整頓した
3. トイレ誘導した利用者の尿パッドを、無言で取り替えた
4. 服薬時に、薬を飲むように促して、そばで確認した
5. 利用者がテレビを見ているそばで、洗濯物をたたんだ

<details class="answer">
<summary>正解を見る</summary>

**正解：4**　見守り的援助は「本人が行うのを、そばで支える」ことです。1・2・5は介護者が代わりにやっているだけ、3は声かけもなく本人の参加がありません。
</details>
</details>
