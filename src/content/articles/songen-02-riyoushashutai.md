**この記事のポイント**

1. 生活の主人公は**利用者**。生活時間・生活習慣・生活歴は**その人独自のもの**で、施設や介護者の都合に合わせない。
2. 迷ったら、**本人の意向を確かめたうえで**「**今までどおり**」を選ぶ。畳に布団、夜の入浴、好みの切り方――本人の暮らし方を続けられる選択肢が正解（本人が変えたいと望むなら、それに沿う）。
3. 見守り的援助＝介護者が**代わりにやる**のではなく、**声をかけて一緒に行う**こと。

## ① 生活支援の基本視点

| ○ 正解になる視点 | × よく出る不正解 |
|---|---|
| **利用者の意思**を尊重し、十分に情報を伝えて本人が選ぶ | 介護者の意向を優先する／チームで決めたプログラムを押しつける |
| **生活モデル**（暮らし全体をみる）・ICFの視点 | 医学モデル（できない所を治す）・ICIDH（ICFの前の国際障害分類）の視点 |
| 専門的な**知識**に基づき、**生活歴**も理解して支援する | 知識より経験を重視する |
| 生活は余暇や人とのつながりも含み、**生活時間はその人独自** | 生活は食事・排泄・睡眠の3つだけ |
| **利用者の価値観**を尊重し、信頼関係を築く | 支援者の価値観・規則を優先する |
| 利用者の**全体像**をとらえ、持てる力を生かす | できないことを代わりに行うことに重点 |
| 一人ひとりに合わせた**個別ケア** | 集団ケアを優先する |

**よく出る一言**：「1人で生活行為ができることを目的にする」「すべて自分一人でできるようにする」「いつもそばに付き添い、何でも積極的にやるよう促す」は×です。目的は**その人らしい生活**であって、何でも一人でできることではありません。本人の**できる力と必要な支援を組み合わせ**、ペースを尊重します。

ICF・生活モデルの考え方は [ICF（国際生活機能分類）の見分け方](../icf-01-icf/) で詳しく扱います。

## ② 個別性・生活習慣を尊重する

### 「今までどおり」が正解になる例

| 回 | 場面 | 正解 |
|---|---|---|
| 第37回 | 母語が日本語でない人 | 自分で食事ができるよう**自助具の使用状況を確認**（日本語を強制・日本式の布団・余暇を職員が決めるは×） |
| 第35回 | 煮物の調理 | 利用者に**好みの切り方を確認**する |
| 第34回 | 衣服を選ぶのが難しい人 | **自分で選べるような声かけ**をする（全介助・代わりに選ぶは×） |
| 第33回 | 自宅で夜に入浴していた人 | **夕食後に入浴**してもらう |
| 第32回 | 一人暮らしの認知症の女性 | **本人の意向を確認し**、今までどおり畳で布団を使う |
| 第25回 | 片麻痺の人の入所当日の食事 | **食べやすい方法を確認**する（決めた席・エプロン・刻み食・全介助は×） |

### 個別性のとらえ方

- 生活習慣は、その人が**生活してきた環境から**理解する
- 年齢から**生きてきた時代**を考えて体験談を聞く。性別・家族構成・所得・障害特性で決めつけない
- その人らしい生活のために最優先で把握する情報は、**これまでの生活環境と生活習慣**
- 「その人らしさ」をつくるもの＝価値観・生活習慣・これまでの体験・地域性・時代背景。同じ病気・同じ要介護度でも支援は人によって変わる
- 生活歴や人間関係をつかむ図：**エコマップ**＝利用者や家族を**取り巻くさまざまな人・機関との関係**を線でつないだ図。**ジェノグラム**（家族図）＝家族の構成（3世代ほど）を記号で表した図。入れ替えに注意

### プライバシー・羞恥心

- **羞恥心に配慮**した介護を行う
- 愛称で呼ばない。多床室ではカーテンを閉める。入室時は**ノックと声かけ**

## ③ 入所・転居のときの配慮

環境が大きく変わるときは、**なじみのもの・なじみの人**が心の支えになります。

- 施設入所の負担を減らす → **早くなじみの職員ができる**ようにする。家族の訪問を控える・新しい家具・施設の時間に合わせるは×
- 息子夫婦の家へ引っ越す認知症の人の部屋 → **思い出の小物や写真を飾る**
- 入居して戸惑っている人 → **入居前の生活の様子を聞く**。日課を伝える・役割を職員が決めるは×

## ④ 見守り的援助と生活援助

訪問介護のサービスは、次の3つに分けて考えます。

| 区分 | 中身 | 例 |
|---|---|---|
| **身体介護** | 体に直接ふれる介護＋**本人と一緒に行う家事（見守り的援助）** | 入浴・排泄・食事の介助、一緒にごみを分別する |
| **生活援助** | 本人に代わって行う家事 | 掃除・洗濯・調理・買物の代行 |
| 対象外 | 本人の日常生活の援助にあたらないもの | **家族の分の洗濯・調理**、大掃除、窓ふき、庭の手入れ、ペットの世話、服の作り直し |

**見守り的援助**＝利用者の自立と重度化防止のために、**一緒に行う・声をかける・そばで確認する**支援で、**身体介護**に区分されます。服薬時に飲むよう促し、そばで確認するのも見守り的援助です。

| ○ 見守り的援助 | × 単なる代行（生活援助） |
|---|---|
| ごみの分別が**できるように声をかける** | その場で介護者がごみを分別する |
| 冷蔵庫の中を**本人と一緒に**整理する | 冷蔵庫を介護者が整理・期限切れを捨てる |
| 洗濯物を**一緒に干す・たたむ** | テレビを見ている横で介護者が洗濯物を干す |

**家事の支援**：片麻痺でも「家事は無理だから介護者がやる」は×。**片手で使える自助具や手順の工夫**でできることを生かします。家事のアセスメントでは心身機能・生活歴・希望・環境・家族の分担を把握し、清潔さより本人の生活習慣や価値観を尊重します。

**買物代行のルール**：リストどおりに買う（安くても多く買わない）、おつり・レシートは**一緒に確認**、冷蔵庫の中を**勝手に捨てない**、本人が調理するなら**調理しにくい食材がないか確認**する。

## ⑤ 利用者主体を支える制度

- **措置から契約へ**：以前は行政がサービスの内容や行き先を決める「措置」制度だった。2000年の介護保険の開始と社会福祉法への改正で、**利用者がサービスを選んで事業者と契約する**しくみになった。
- 選ぶための情報：事業者は**介護サービス情報の公表制度**で事業所の情報を公表する義務がある。
- **インフォームド・コンセント**＝十分な説明を受け、理解したうえで本人が同意・選択すること。説明するだけ、同意書をとるだけでは不十分。

制度のくわしい内容は [介護保険のサービスの種類と事業所](../kaigohoken-02-service/) で扱います。
