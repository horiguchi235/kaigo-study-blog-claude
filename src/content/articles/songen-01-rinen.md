## ① 福祉の理念と人物【人間の尊厳と自立／障害の理解】

### 人物とキーワード

| 人物 | キーワード |
|---|---|
| **バンク-ミケルセン**（デンマーク） | ノーマライゼーションの父（1959年法） |
| **ニィリエ**（スウェーデン） | ノーマライゼーションの**8つの原理** |
| **ヴォルフェンスベルガー**（アメリカ） | **ソーシャルロール・バロリゼーション**（価値ある社会的役割の獲得） |
| **エド・ロバーツ** | **自立生活運動**（アメリカ・1960年代後半） |
| **糸賀一雄** | 「**この子らを世の光に**」・**発達保障** |
| **フランクル** | 『夜と霧』・**態度価値**（命が制限された状況でどんな態度をとるか） |
| **メイヤロフ** | 『**ケアの本質**』（ケアとは相手の成長・自己実現をたすけること） |
| **リッチモンド** | 『ソーシャル・ケース・ワークとは何か』（ケースワークの母） |
| **キットウッド** | パーソン・センタード・ケア（認知症ケア） |

> **入れ替えのひっかけ**が定番です（第38回）。「ケースワークの7原則」はリッチモンドではなく**バイステック**、「エーデル改革」は人物の提唱ではなく**スウェーデンの高齢者ケア改革**です。

### 理念の違い

| 理念 | ひとことで | 正解になる例 |
|---|---|---|
| **ノーマライゼーション** | 障害があっても**普通の生活環境**に近づける | 施設から**地域生活への移行**、バリアフリー新法、障害者基本計画の理念 |
| **ソーシャルインクルージョン** | すべての人を**社会の一員として包み込み**、共に支え合う | 「障害のある人もない人も**包摂**する社会」 |
| **自立生活運動（IL運動）** | 障害者自身の**選択による自己決定**の尊重 | 介助を受けながらでも地域で自立して暮らす |

**よく出る不正解**：大規模入所施設の整備（ノーマライゼーションと逆）／障害の完治を目指す／機能回復＝自立／「統合」（インクルージョンは「包摂」）

## ② 自立・自立支援・自己決定・QOL【人間の尊厳と自立／介護の基本】

### 「自立」の意味

| 種類 | 正しい説明 |
|---|---|
| **精神的自立** | 生活の目標をもち、**自らが主体となって**物事を進めること（第36回） |
| 身体的自立 | 自分の身体を使って日常生活を送ること |
| 社会的自立 | 社会の中で役割をもち、参加すること |
| 経済的自立 | 自分の収入や資産で生活を営むこと |

- 自立支援＝**自己選択・自己決定を支援する**こと（第29回）
- 介護を**受けていても**、**社会参加**できるように支援すること（第30回）
- 「他者の支援を受けずに生活できる状態」「ADLの回復」「機能回復訓練中心」は×

### 用語

| 用語 | 意味 |
|---|---|
| **アドボカシー** | 利用者の意思を**代弁**する（権利擁護） |
| **エンパワメント** | 本人の力を引き出す。エンパワメントアプローチで**自己決定能力が高まる**（第28回） |
| **ユニバーサルデザイン** | **どこでも、だれでも、自由に、使いやすく**。7原則の1つに「**安全**で使いやすい」 |
| ストレングス | 本人の強み |
| パターナリズム | 本人のためと言って、本人に代わって決めること（父権主義） |

### QOL（生活の質）を高める

- 身体面だけでなく、**心理的・社会的な面**も含めて支援する（第27回）
- 利用者の**ニーズや生活環境を総合的に**みて方針を決める（第29回）
- 福祉用具の活用は**利用者と相談しながら**進める（第35回）
- 「ADLの向上が必須」「全員に同じ基準」は×

<details>
<summary>✏️ 解いてみよう（第30回）</summary>

自立に向けた支援として、最も適切なものはどれ？

1. 機能回復訓練を中心に介護計画を作成すること
2. 他者の支援を受けずに自らの力で生活できる状態にすること
3. 本人の意思よりも、介護者からみた自立を優先すること
4. 介護を受けていても社会参加できるように支援すること
5. 自分で着衣し終わるまで、何時間でも介護者が見守ること

<details class="answer">
<summary>正解を見る</summary>

**正解：4**　自立は「一人で全部できること」ではありません。支援を使いながら、自分で決めて社会とつながることが自立です。
</details>
</details>
