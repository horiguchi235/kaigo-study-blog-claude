**この記事のポイント**

1. コミュニケーションは**双方向**。一方的に話す・黙って聞くだけ、のどちらも×。
2. 初対面では**自分から自己紹介**し、**相手の感情に関心をもつ**。距離を急に縮める（愛称・密着・ボディタッチ中心）のは×。
3. 「大丈夫」と言いながら不安そうな表情 ＝ **言語と非言語が矛盾**している。本当の気持ちは非言語に**出やすい**（決めつけず、本人に確かめる）。

## ① 関係づくり（ラポール形成）の基本

**ラポール**＝利用者と援助者のあいだの**信頼関係**。安心して話せる関係があってはじめて、本音や希望を聞くことができます。

| ○ 正解 | × よく出る不正解 |
|---|---|
| **双方向**のやり取り（あいづちで相手の発話を引き出す） | 一方的に話す／聞き手に徹するだけ |
| 初対面では**自分から自己紹介**する | 自発的な関わりを控える／詳しすぎる自己紹介 |
| 利用者の**感情に関心**をもつ | 家族環境を詳しく聞く／「なぜ」をくり返す |
| 表情や行動を**観察**し、さりげない会話から | 肩に手を回すなど**身体接触を中心**にする |
| 利用者の**生活史を尊重**する | 介護福祉職の主観を基準にする |
| 利用者の**主観的な訴えに耳を傾ける** | 自分の意見と違っても賛同する／感情的に反応する |
| 言葉だけでなく**表情やしぐさ**にも注意 | 理解できない話には沈黙する |
| **自分自身の感情の動き**も意識する | 介護福祉職の価値判断に従ってもらう |
| 言葉が出にくいときは**待つ** | 次々に話しかける |

**×の理由**
- 家族環境を詳しく聞く・「なぜ」をくり返す → 初対面で踏み込みすぎ、問い詰められている感じを与える
- 身体接触を中心にする → 触れられるのを不快に感じる人もいる。**接触は安心にも不快にもなる**ので、むやみに触れない（言葉が届きにくい重度の認知症の人に、安心を伝える手段として触れるのは別 → [認知症・うつ・精神障害・知的障害の人とのコミュニケーション](../shougaicomm-03-ninchi/)）
- 理解できない話には沈黙する → 反応がないと相手は不安になる。わからないときは**確かめる**

> <strong>沈黙は○？×？</strong>　相手が考えている・言葉を探しているときの沈黙は、<strong>大切な時間として待つ（○）</strong>。わからないまま黙って反応しない、うなずきもせず聞いているだけ（**聞き手に徹するだけ**）は、双方向にならないので×。傾聴（[傾聴・共感・受容と質問の技法](../communication-02-keichou/)）も、あいづちや表情で「聴いています」を伝えながら聴くことです。

> 「〇〇ちゃん」と愛称で呼ぶ、孫のような口調で話す、友人のような口調、は親しみではなく**尊厳を傷つける**対応として必ず×です。

- **共体験**＝同じものを見る・一緒に出かけるなど、体験を共有すること。その後の会話のきっかけになり、関係づくりに役立ちます。

## ② 座り方・距離・聞く姿勢

### 座り方

<photo name="communication-01__ichi" caption="テーブルの角をはさんで<strong>直角（90度）</strong>に座ると、視線が自然にそれて緊張しにくい。">

| 座り方 | 特徴 |
|---|---|
| **直角法**（90度） | 視線をそらしやすく、**緊張しにくい**。関係づくりに向く |
| 対面法（正面） | 視線が合いすぎて緊張しやすい → **机に花瓶など視線を向けられる物を置く**とよい |

### 距離と目線

<fig name="kyori">

- **対人距離**（ホールの分類）：密接距離＝約45cmまで、個人距離＝約45〜120cm、社会距離＝約120〜360cm、公衆距離＝それ以上。相談は**個人距離**が目安
- **パーソナルスペース**（他人に入られると不快に感じる身のまわりの空間）は、相手との**親密度**・文化・その人の状態によって**変わる**（一定ではない、第24回）

<photo name="communication-01__mesen" caption="車いすの人と話すときは、**腰を落として目の高さを合わせる**。見下ろすと威圧感を与えます。">

- 相手と**視線を合わせられる位置**で話す。相手が座っていれば**自分も座る**
- 初対面から**密着した距離**は×。近づけば近づくほど話しやすくなるわけではない
- 静かで、表情が見える明るい場所で話す（にぎやかな場所・薄暗い場所は×）

### 聞く姿勢

- **上半身を少し相手のほうへ傾けて**聞く
- 腕組み・足組み・正面に立って話し続ける・目を見つめ続けるは×
- 緊張感が伝わるような背筋の伸ばし方も×（リラックスした姿勢で）
- **聞き上手**の基本＝話の腰を折らない・表情豊かに・ほどよいあいづち。相手のペースに合わせる

## ③ 言語・準言語・非言語メッセージ

| 種類 | 中身 | 例 |
|---|---|---|
| **言語** | 言葉の内容 | 「お風呂は午後3時からです」 |
| **準言語** | 声の**大きさ・速さ・高さ・抑揚・間** | **大きな声でゆっくり**伝える |
| **非言語** | 表情・視線・身振り・姿勢・距離・接触 | 部屋の**ドアを指差す**、**目元の笑顔と大きなうなずき** |

> <strong>準言語は非言語？</strong>　準言語は言葉の「中身」ではなく「話し方」なので、広い意味では非言語の一部と説明されることもあります。ただし試験では**言語・準言語・非言語を分けて**問います。選択肢に並んだら、**非言語＝表情・視線・身振り・指さし・うなずき・姿勢・距離・接触**、**準言語＝声の大きさ・速さ・高さ・抑揚**、**言語＝話し言葉と文字**、と仕分けます。

**よく出るパターン**
- 「大丈夫」と**不安そうな表情**で答えた → **言語メッセージと矛盾する内容を非言語で伝えている**
- マスクで口元が見えないとき → **目元**を意識した笑顔と**大きなうなずき**
- 「ゆっくり話す」「大きな声」は**準言語**、「紙に書く」は**言語**（文字）。非言語と区別する
- 「大きな声」が正解になるのは、聞き取りにくそうなとき。ただし**老人性難聴**（高い音から聞こえにくくなる）の人には、大声で声が高くなるとかえって聞き取りにくいので、**低めの声でゆっくり・はっきり**（→ [視覚障害・聴覚障害・盲ろうの人とのコミュニケーション](../shougaicomm-02-kankaku/)）

## ひっかけパターン集（関係づくりで「ほぼ×」）

| 選択肢の表現 | なぜ× |
|---|---|
| 愛称・孫のような口調・友人口調 | 尊厳を傷つける |
| 初対面から密着・手を握り続ける | 相手の距離感を無視している |
| 聞き手に徹する／黙って聴くだけ | 双方向にならない |
| 立ったまま話す・腕を組む | 威圧感を与える |
| パーソナルスペースは一定 | 親密度で変わる |
| 「紙に書く」は非言語 | 文字は**言語**。非言語は表情・身振り・指さしなど |
