試験の日は、知識より先に「段取り」でつまずくことがあります。当日の流れを先に知っておくと、落ち着いて問題に向き合えます。

**結論を3行で**

1. 午前は**Aパート（60問・105分）**、午後は**B・Cパート（65問・115分）**。どちらも**1問あたり約1分45秒**です。
2. 持ち物の基本は**受験票・HBの鉛筆かシャープペンシル・消しゴム・腕時計**。**ボールペンと耳栓は使えません**。スマートフォンは電源を切ってかばんへ。
3. 入室できるのは**午前8時30分〜9時20分**、**午後12時45分〜13時10分**だけ。会場には**早く着いても入れず、待つ場所もありません**。

---

## ① 当日の時間割（第39回・2027年1月31日）

| 時間 | 午前（Aパート） | 午後（B・Cパート） |
|---|---|---|
| 入室できる時間 | 8:30〜9:20 | 12:45〜13:10 |
| 注意事項の説明 | 9:25〜 | 13:15〜 |
| 試験時間 | **10:00〜11:45（105分）** | **13:40〜15:35（115分）** |
| 問題数 | 60問 | 65問（Bパート45問・Cパート20問） |

- パート合格の結果、午後の**Bパートだけ・Cパートだけ**を受ける人もいます。入室できる時間は午後の受験者と同じです。
- **受験票は2026年12月11日（金）に発送**される予定です。届いたら、試験会場（試験室の場所）、上履きが要るかどうか、受験資格の欄を確認しましょう。
- 会場には**公共交通機関**で行きます（車での送り迎え・駐車はできません）。**下見もできません**。地図アプリで、駅からの道と時間を前もって確かめておきます。

## ② 持ち物チェックリスト

| 区分 | もの | ひとこと |
|---|---|---|
| **必ず持っていく** | **受験票** | 机の通路側に、番号が見えるように置く |
| 必ず持っていく（会場による） | 上履き（スリッパ可）と靴袋 | 受験票に書いてある会場だけ |
| 使える | **HBの鉛筆・シャープペンシル**、プラスチック消しゴム、手で回す鉛筆削り | 鉛筆は数本。芯が折れたときの予備も |
| 使える | **腕時計**（アラームは止める） | 会場に時計がないこともある。時間配分に必須 |
| 使える | ひざ掛けなどの防寒具 | 1月の試験。会場が寒いことがある |
| 自分で用意 | 昼食・飲み物 | ごみは家に持ち帰る（会場のごみ箱は使えない） |
| **使えない** | **ボールペン** | マークシートが読み取れないことがある |
| **使えない** | **耳栓** | 監督員の指示が聞こえないため |
| 使えない | 置き時計、通信や辞書の機能がある時計（スマートウォッチなど） | 身につけていると不正行為になることがある |
| 使えない | 電動・大型の鉛筆削り、カッターなどの刃物 | |

**スマートフォンなどの通信機器**は、電源を切ってかばんの中へ。試験の前に監督員の指示でいったん机の上に出し、電源が切れていることを確かめてからしまいます。**自分の機種の電源の切り方を、前の日までに確認**しておきましょう。試験中に身につけたり使ったりすると、不正行為として試験が無効になることがあります。

## ③ 時間配分と解く順番

| | 問題数 | 時間 | 1問あたり |
|---|---|---|---|
| 午前（Aパート） | 60問 | 105分 | 約1分45秒 |
| 午後（B・Cパート） | 65問 | 115分 | 約1分46秒 |

時間は足りるように見えますが、**事例問題（長い文章を読む問題）が全体の約3分の1**あります（読みもの①）。とくに午後の**Cパート（介護過程・総合問題）は全部が事例**で、1問を読むのに時間がかかります。

**おすすめの進め方**

1. **最初の1周は、迷ったら印をつけて先へ進む**。1問に3分以上かけない。
2. 短い知識問題（制度・からだのしくみなど）で時間の「貯金」をつくる。
3. 残り時間で、印をつけた問題に戻る。
4. **最後の5分はマークの確認**だけにする（番号のずれ、塗り残し）。

> 午後は、Bパートの知識問題を先に解いてからCパートの事例に進むか、頭が疲れる前にCパートから解くか、**過去問演習の「本番形式」で一度ずつ試して**、自分に合う順番を決めておくと安心です。

**マークシートの注意**

- 問題番号と解答欄の番号がずれていないか、**10問ごとに確かめる**と、ずれても被害が小さくすみます。
- 消すときは、プラスチック消しゴムで**跡が残らないように**きれいに消します。
- 試験が終わったら、すぐに筆記用具を机に置きます（持ったままだと不正行為になることがあります）。解答用紙は持ち出せません。

## ④ 受験上の配慮（申込みのときに申請）

| 対象 | 受けられる配慮 |
|---|---|
| **外国籍の人**（日本に帰化した人を含む） | 申請すると、**すべての漢字にふりがなが付いた問題用紙**になり、**試験時間が1.5倍**になる。通常の問題用紙は配られない。初めて申請するときは在留カードの写しなど、国籍がわかる書類が必要 |
| **EPA介護福祉士候補者** | 申請しなくても、ふりがな付きの問題用紙と試験時間の延長がある |
| **障害などのある人** | 障害の種類と程度に応じて、点字・拡大文字の問題、チェック式の解答用紙、試験時間の延長（弱視などは1.3倍、点字などは1.5倍）など。医師の「診断・意見書（指定の様式）」などが必要 |

- 配慮は**受験の申込みのとき（第39回は2026年7月22日〜9月2日）に申請**するものです。次の試験を受ける人は、申込みの時期に忘れずに。
- 申込みのあとに病気やけが、妊娠などで配慮が必要になったときは、社会福祉振興・試験センター（03-3486-7521、平日9時30分〜17時）に相談します。
- 外国籍の人は、ふりがな付きの問題で本番と同じ体験ができるよう、このサイトの言語の切り替えで「**ふりがな付き**」を選んで記事を読んでおくと慣れやすくなります。

## ⑤ 試験が終わってから

| 日にち | できごと |
|---|---|
| 試験の当日〜翌日 | 資格学校などが「解答速報」を出す。自己採点ができる（正式な正答は合格発表の日に厚生労働省が公表） |
| **2027年3月23日（火）午後** | **合格発表**。試験センターのホームページに合格者の受験番号が載る |
| 2027年3月26日（金） | 結果の通知が発送される |
| 2027年4月9日（金）まで | 受験資格が「見込」の人は、必要な書類を提出（出さないと試験が無効になる） |

合格したら、**登録の手続きをして初めて「介護福祉士」と名乗れます**（読みもの④）。総得点で不合格でも、**基準を満たしたパートは次の2回の試験で免除**されます（読みもの②・⑤）。
