**この記事のポイント**

1. 介護を受けたい場所は「**自宅**」が最多。高齢者の家庭内事故は「**居室**」が最多。介護が必要になった原因の1位は**認知症**（2022年）。
2. **フォーマル＝制度に基づく支援**（地域包括支援センター・民生委員など）、**インフォーマル＝家族・近所・ボランティア**。
3. 民生委員は**児童委員を兼ね**、**住民の立場で相談・援助**。ヤングケアラーには**学校やケアマネと一緒に**、**同じ体験の人と出会える場**を。

## ① 介護の現状・高齢者の意識調査

| 調査・テーマ | 押さえる結果 |
|---|---|
| 介護が必要になった主な原因 | 要介護者・要支援者の全体で**認知症**（16.6%）→ **脳血管疾患**（16.1%）→ **骨折・転倒**（13.9%）の順（2022年 国民生活基礎調査。介護の項目は3年ごとの大規模調査の年だけ調べるので、これが最新）。2013年調査までは脳血管疾患が最多 |
| 要介護度と介護時間 | 要介護度が**高いほど**同居の介護者の介護時間が長い（2022年 国民生活基礎調査） |
| 介護を受けたい場所 | 「**自宅**で介護してほしい」が最多（内閣府の高齢者の意識調査） |
| 世話の費用 | 「**年金等の収入でまかなえる**と思う」が最多（内閣府の高齢者の意識調査） |
| 地域活動に参加しない理由 | 「**健康・体力に自信がない**」が最多（内閣府の高齢者の意識調査） |
| 地域のグループ活動 | 参加している活動は**健康・スポーツ**→趣味→地域行事の順に多い。参加したいと思う人は、実際に参加している人より多い（内閣府の高齢者の意識調査） |
| 生活への思い | 多くの人が**生きがい**を感じ、生活に満足している一方、将来に不安を感じる人も多い。地域で不便なことは**日常の買い物**と**通院** |
| 学び | 一生学び続けることを**生涯学習**、社会人が学び直すことを**リカレント教育**という |
| 家庭内事故の場所 | **居室**が最多。次いで階段・台所 |
| 在宅の身体障害者 | **65歳以上が7割超**（2016年 生活のしづらさなどに関する調査） |
| 障害者数 | **精神（約603万人）＞身体（約423万人）＞知的（約127万人）**（2025年版 障害者白書。身体・知的は2022年調査、精神は2023年 患者調査） |

障害者の統計の補足：

- 合わせて約1,150万人で、**人口の約9％**
- 施設に入所している割合が最も高いのは**知的障害者**（約1割）
- 65歳以上の割合が最も高いのは**身体障害者**
- 身体障害者手帳では**肢体不自由**が最も多く、次いで**内部障害**、聴覚・平衡機能障害、視覚障害
- 精神疾患の患者は、入院では**統合失調症**、外来では**気分障害**（うつ病など）が最も多い
- 精神障害者の多くは手帳を持っていない（「8割が手帳を持っている」は×）

### 介護の政策の考え方

- 「**2015年の高齢者介護**」（2003年 厚生労働省の研究会の報告書）：**高齢者の尊厳を支えるケア**を掲げ、のちの地域包括ケアや認知症ケアの土台になった。認知症ケアの基本は**本人の生活の仕方や潜在する力を大切にする**
- 「今後の社会福祉のあり方について」（1989年 意見具申）：**市町村の役割重視**や在宅福祉の充実など、介護保険につながる考え方

## ② 社会資源・民生委員・年金・ヤングケアラー

### フォーマルとインフォーマル

| フォーマル（制度に基づく） | インフォーマル |
|---|---|
| **地域包括支援センター**、介護保険サービス、行政、**民生委員** | 家族、友人・知人、近所の住民、ボランティア、学生サークル |

| 特徴 | フォーマル | インフォーマル |
|---|---|---|
| 専門性 | 高い | 低い |
| 安定性 | 契約に基づき**確実に**提供される | 不安定になることがある |
| 柔軟さ | 決まりの範囲で提供 | 一人ひとりに**柔軟に**対応できる |

ケアプランでは、フォーマルとインフォーマルを**組み合わせ**ます。

> 民生委員は無報酬ですが、**民生委員法に基づき厚生労働大臣が委嘱する**ので、制度に基づくフォーマルな社会資源に入ります。

### 民生委員

| ○ | × |
|---|---|
| **児童委員を兼ねる** | 児童委員の兼務は禁止 |
| **厚生労働大臣が委嘱**、任期**3年**、無報酬 | 都道府県知事が任命／任期10年 |
| **社会奉仕の精神**で住民の立場に立って**相談・援助**し、社会福祉の増進に努める | 担当する要介護者の数・毎月訪問が決まっている |

### そのほか

- 地域包括支援センターは**ボランティアや民生委員などと連携**する。介護福祉士の配置義務はない
- **セルフヘルプグループ**（自助グループ）の目的＝**同じ悩みを持つ人どうしで課題を共有**
- **障害基礎年金**：等級は**1級と2級**。**18歳未満の子がいれば加算**。20歳前の障害は所得制限あり。老齢厚生年金と一定の組み合わせで併給できる

### 家族介護の困りごとを表す言葉

| 用語 | 意味 |
|---|---|
| **ヤングケアラー** | 家族の介護や家事などの世話を**日常的に（過度に）担っている子ども・若者**。2024年6月施行の改正子ども・若者育成支援推進法で、国・自治体が支援に努める対象として**法律に明記** |
| **ダブルケア** | **育児と介護を同時に**担うこと |
| **老老介護** | 介護する人もされる人も**65歳以上** |
| 認認介護 | 認知症の人が認知症の家族を介護すること |
| 8050問題 | 80代の親が、ひきこもりなどの50代の子の生活を支えている状態 |
| **介護の社会化** | 家族機能の低下で、家族が担っていた介護を社会で支えること |

## ③ 暮らしとお金・介護者の実態

### 高齢者の暮らしとお金（2024年 国民生活基礎調査。所得は2023年の1年間）

| ○ | × |
|---|---|
| 高齢者世帯の平均所得は**約315万円**で、全世帯平均（536万円）の**約6割** | 全世帯平均より多い |
| 高齢者世帯の所得の**約6割（63.5%）が公的年金・恩給** | 稼働所得が最多 |
| 年金を受けている高齢者世帯の**4割超**は、所得が**年金だけ** | — |
| 高齢者世帯の<strong>半数以上（55.8%）</strong>が生活が「苦しい」と感じている | ほとんどが「ゆとりがある」 |
| 生活が「苦しい」と感じる割合は、高齢者世帯と全世帯で**大きな差はない** | 高齢者世帯の方がずっと多い |

ワーク・ライフ・バランスと働き方は [高齢者の年齢の決まり・人口・世帯と家族](../jinkou-01-setai/) の「② 人口・少子高齢化・地域社会」で扱います。

### 介護する人（2022年 国民生活基礎調査）

介護の数字は3年ごとの大規模調査の年だけ調べます。2024年は簡易調査で介護の項目がないため、2022年が最新です。

| ○ | × |
|---|---|
| 主な介護者は**同居の家族が約半数**（45.9%）。続柄は**配偶者→子→子の配偶者** | 事業者が最多 |
| 同居の主な介護者の**約7割が女性**（68.9%） | 男性が多い |
| 要介護者と同居の介護者が**ともに65歳以上が約6割**（63.5%）＝**老老介護**。ともに75歳以上も3割超 | 老老介護は少数 |
| 要介護3以上では、同居の介護者が「**ほとんど終日**」介護している割合が最も多い（要介護5では6割超） | — |

同居の主な介護者の多くが悩みやストレスを抱えています。本人だけでなく**介護者を支える**ことも大切です。
