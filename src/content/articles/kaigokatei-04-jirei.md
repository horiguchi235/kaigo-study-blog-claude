**この記事のポイント**

1. 事例の中の「**本人の発言（かぎかっこ）**」と「**生活歴（昔の仕事・役割）**」が、ほぼ必ず正解のヒント。
2. 様子が**急に変わった**ら、まず**その理由・背景を確かめる**のが正解。
3. 正解は「**本人の思いを生かす**」選択肢。機能訓練だけ・行動の制限・介護者の都合は×。

> 介護過程の過去問119問のうち、事例問題は約4割です。知識より「読み方」で点が取れる分野なので、型を覚えると得点が安定します。

---

## ① 型1：行動や言葉の意味を解釈する

**問われ方**：「〜した行動の解釈として最も適切なもの」「理解するために必要な情報は」

**解き方**
1. 本文の**本人の発言**を探す → その言葉の意味を考える
2. 行動が変わる**直前に何があったか**を探す（失敗・指摘・環境の変化）
3. **生活歴**とつなげる

| 回 | 事例の要旨 | 正解 |
|---|---|---|
| 第36回 | 元大正琴の先生。クラブの後「あの子たちが待っているの」と言って部屋に戻らない | **「あの子たちが待っているの」という発言**を解釈する |
| 第32回 | 元体育教師・野球部の監督。高校野球の試合を見たあと、体操の指導を断った | **高校野球のことが気になっている** |
| 第37回 | 調理中に包丁を置いて横になった。「悔しい。もう一度ひとりで作れるようになりたい」 | 調理がうまくできないことへの**苛立ち** |
| 第35回 | 買い物の帰りに急に立ち止まり「ここはどこなの」 | 自分のいる場所がわからない**不安** |
| 第30回 | 廊下を歩き回り、声をかけると「私には行くところがある」と怒鳴る | **その言葉を解釈する**（「短気な性格」と決めつけるのは×） |

**よく出る不正解**：介護福祉職の気持ち・声かけのタイミング／「性格のせい」「面倒くさがっている」と決めつける／体調不良と決めつける

## ② 型2：優先する生活課題・ニーズ・情報を選ぶ

**問われ方**：「最も優先すべき生活課題は」「収集する情報として最も優先度が高いものは」「ニーズとして適切なものは」

**解き方**
- **命・安全にかかわること**が最優先（誤嚥、転倒など）
- 次に、**本人が望む生活**を妨げていること
- 情報は「**目標に直接関係するもの**」を選ぶ

| 回 | 事例の要旨 | 正解 |
|---|---|---|
| 第33回 | パーキンソン病。昼食時によくむせる。ショートステイを利用 | **食事を安全に摂取できること** |
| 第27回 | 階段で転倒歴。友人のけがもあり「転びそうで怖い」と外出が減った | **転倒の不安があること** |
| 第29回 | 仲の良い友人が別の階へ移った。寂しそうに探し歩く。友人も会いたがっている | **友人との交友関係を保てること** |
| 第29回 | 「迷惑がかかるのでおむつのままでいい」と訓練を拒否 | ニーズは**トイレで排泄ができること**（遠慮の言葉の奥にある本当の望み） |
| 第30回 | 尿失禁の改善が目標。歩行は自立、トイレに間に合わない | 情報は**トイレに行く時間帯** |
| 第24回 | 「便秘を解消する」が目標 | 優先度が**低い**情報は**体温の変化** |

**よく出る不正解**：家族の介護負担・家族の意見を中心にする／お金や制度の話を先にする／目標と関係の薄い情報（体温・人数・時間）

## ③ 型3：目標に合った支援内容・支援の見直し

**問われ方**：「支援内容として最も適切なもの」「見直した支援の方向性は」「長期目標の方向性は」

**解き方**
- **生活歴・昔の役割**を生かす（いちばん多いパターン）
- 目標が「〜したい」なら、それを**少しずつ実現する**具体的な支援
- 本人ができることは**本人がする**ように支える（代わりにやる・全介助は×）

| 回 | 生活歴・状況 | 正解 |
|---|---|---|
| 第31回 | 元造園業。骨折で入所し「歩けるようになるはずはない」と落ち込む | 長期目標は**造園業に再び携わること** |
| 第36回 | 元大正琴の先生 | **大正琴を教える役割をもつ** |
| 第32回 | 元体育教師。体操の順番を指摘されて意欲を失った | **体操を指導する自信を回復すること** |
| 第25回 | 「できるだけ歩いて生活したい」、短期目標「転倒しない」 | **職員と施設内を散歩する**（車いす・居室で過ごすのは×） |
| 第37回 | 「もう一度ひとりで調理したい」 | **調理に関する福祉用具の活用**（調理の代行・配食は×） |
| 第36回 | 片麻痺で作業の手順が分からず「こんなの、できない」 | **完成までの手順をわかりやすく示す** |
| 第37回 | 知的障害。目標「下着を汚さずに排泄する」 | **定期的に手順を一緒に確認する**（おむつ・全介助は×） |

**よく出る不正解**：車いす・居室で過ごすなど**活動を減らす**／**代わりにやる**・全介助／薬で鎮静／介護者が常に横で指示する／反省させる

## ひっかけパターン集（事例問題で「ほぼ×」）

| 選択肢の表現 | なぜ× |
|---|---|
| 介護福祉職の気持ち・都合を基にする | 主体は利用者 |
| 「性格」「面倒だから」と決めつける | 根拠のない解釈。言葉と背景から考える |
| 車いす・居室で過ごす・活動を控える | 安全のために生活を狭めている |
| 代わりにやる・全介助・おむつ | 自立支援に反する |
| 薬で鎮静する・理解させる | 本人の思いを無視している |
| 家族の意向・施設入所を前提にする | 本人の望みを確かめていない |
