**この記事のポイント**

1. **設問を先に読んで型を決め**、本文の「**本人の発言（かぎかっこ）**」「**生活歴（昔の仕事・役割）**」「**変化のきっかけ**」に印をつける。ほぼ必ず正解のヒントになる。
2. 様子が**急に変わった**ら、まず**その理由・背景を確かめる**のが正解。1問目で見つけた背景が、2問目（支援）の根拠になる。
3. 正解は「**本人の思いを生かす**」選択肢。消去チェックリスト（主語・根拠・代わりにやる・役割の範囲・家族や職員の都合）で×を消す。

> 介護過程の過去問119問のうち、この記事の事例問題は42問（約3分の1）です。近年の試験では、介護過程8問のうち4問が「1つの事例に2問×2事例」の形です。知識より「読み方」で点が取れる分野なので、手順を身につけると得点が安定します。

## ① 事例の読み方の手順

### 手順

1. **設問（最後の一文）を先に読む** → 下の表で型1〜3のどれかを決める
2. **本文に印をつける**（5か所）
   - 年齢・疾患・障害（できること・できないこと）
   - **生活歴・役割**（昔の仕事、得意なこと、家での役割）
   - **かぎかっこの発言**（とくに気持ちを表す言葉）
   - **変化のきっかけ**（行動が変わる直前の出来事：失敗・指摘・環境の変化）
   - **今の目標**（「〜したい」という本人の希望、短期目標）
3. **選択肢を消去チェックリストで消す**
4. 残った選択肢が、2で印をつけた**本文のどこに根拠があるか**を確かめて選ぶ

### 設問の言葉で型を見分ける

| 設問の言葉 | 型 |
|---|---|
| 「行動の解釈として」「〜を理解するために必要な情報は」 | 型1：行動や言葉の意味を解釈する |
| 「優先すべき生活課題は」「ニーズは」「収集する情報で優先度が高いのは」 | 型2：優先する課題・ニーズ・情報を選ぶ |
| 「支援内容として」「見直した支援の方向性は」「目標は」 | 型3：目標に合った支援を選ぶ |

### 消去チェックリスト

| チェック | ×になる選択肢の例 |
|---|---|
| 主語は利用者か | 介護福祉職の気持ち・声かけのタイミング |
| 本文に根拠があるか | 「性格のせい」「面倒くさがっている」「体調不良」と決めつける |
| 代わりにやっていないか | 調理の代行、全介助、おむつにする |
| 介護福祉職の役割の範囲か | 薬で落ち着かせる、医学的な判断をする |
| 家族や職員の都合が主になっていないか | 家族の希望だから、施設の都合で、説得してもらう |
| 生活を狭めていないか | 車いす・居室で過ごす、活動を休ませる |

### 「安全」と「生活歴・役割」はどちらを優先する？

- **危険が本文に書かれているとき**（よくむせる、転倒をくり返す など）→ 安全が最優先（第33回：むせる人 → 食事を安全に摂取できること）。
- **危険が書かれていないとき** → 安全を理由に活動を減らす選択肢は×（第25回：「できるだけ歩いて生活したい」人 → 職員と施設内を散歩する。車いすで過ごすのは×）。
- 危険があっても、「やめさせる」ではなく「**安全にできる方法**」を選ぶのが基本です。

## ② 例題：1つの事例を通して解く

この例題は、このブログで作ったオリジナルの事例です（過去問ではありません）。本番と同じく、1つの事例に2問です。

**事例**　Cさん（82歳、女性）は、夫と60年間和菓子店を営み、毎朝あんこを炊いてきた。脳梗塞の後遺症で左片麻痺があり、在宅復帰を目指して介護老人保健施設に入所している。杖を使えば見守りで歩け、立っている姿勢も安定している。月1回のおやつ作りの会では、はじめは率先して手伝っていた。先月、鍋に手を伸ばしたときに職員から「危ないので座っていてください」と言われた。それ以来、会に参加しなくなり、「ここでは何もさせてもらえない。昔は毎日あんこを炊いていたのに」と話している。

3. 得意なことを生かす役割を失ったと感じている

**正解：3**

- 生活歴・役割：「和菓子店を60年」「毎朝あんこを炊いてきた」
- 変化のきっかけ：職員の「危ないので座っていてください」
- 発言：「ここでは何もさせてもらえない」「昔は毎日あんこを炊いていたのに」

**消去**
- 1・4・5：本文に根拠がない（決めつけ）
- 2：疲れやすさは書かれていない。立位は安定している
- 3：きっかけ（座っていてと言われた）と発言（何もさせてもらえない）と生活歴（あんこ）がすべてつながる

2. 安全のため、会には車いすに座ったまま見学で参加してもらう

- 2：危険は本文に書かれていない（立位は安定）。安全を理由に活動を減らしている

## ③ 型1：行動や言葉の意味を解釈する

**問われ方**：「〜した行動の解釈として最も適切なもの」「理解するために必要な情報は」

**解き方**
1. 本文の**本人の発言**を探す → その言葉の意味を考える
2. 行動が変わる**直前に何があったか**を探す（失敗・指摘・環境の変化）
3. **生活歴**とつなげる

| 回 | 事例の要旨 | 正解 |
|---|---|---|
| 第36回 | 元大正琴の先生。クラブの後「あの子たちが待っているの」と言って部屋に戻らない | **「あの子たちが待っているの」という発言**を解釈する |
| 第32回 | 元体育教師・野球部の監督。高校野球の試合を見たあと、体操の指導を断った | **高校野球のことが気になっている** |
| 第37回 | 調理中に包丁を置いて横になった。「悔しい。もう一度ひとりで作れるようになりたい」 | 調理がうまくできないことへの**いら立ち** |
| 第35回 | 買い物の帰りに急に立ち止まり「ここはどこなの」 | 自分のいる場所がわからない**不安** |
| 第30回 | 廊下を歩き回り、声をかけると「私には行くところがある」と怒鳴る | **その言葉を解釈する**（「短気な性格」と決めつけるのは×） |
| 第38回 | 部屋が散らかり、友人に笑われて日中活動を休むようになった | **自信をなくした理由**を知る |

**よく出る不正解**：介護福祉職の気持ち・声かけのタイミング／「性格のせい」「面倒くさがっている」と決めつける／体調不良と決めつける（バイタルに変化がないと書かれていることが多い）

## ④ 型2：優先する生活課題・ニーズ・情報を選ぶ

**問われ方**：「最も優先すべき生活課題は」「収集する情報として最も優先度が高いものは」「ニーズとして適切なものは」

**解き方**
- **命・安全にかかわること**が本文に書かれていれば最優先（誤嚥、転倒など）
- 次に、**本人が望む生活**を妨げていること（生命の安全→生活の安定→人生の豊かさ の順。[生活課題・目標・介護計画の立て方](../kaigokatei-02-keikaku/)）
- 要望（口にした言葉）の奥にある**ニーズ**を考える
- 情報は「**目標に直接関係するもの**」を選ぶ

| 回 | 事例の要旨 | 正解 |
|---|---|---|
| 第33回 | パーキンソン病。昼食時によくむせる。ショートステイを利用 | **食事を安全に摂取できること** |
| 第27回 | 階段で転倒歴。友人のけがもあり「転びそうで怖い」と外出が減った | **転倒の不安があること** |
| 第29回 | 仲の良い友人が別の階へ移った。寂しそうに探し歩く。友人も会いたがっている | **友人との交友関係を保てること** |
| 第29回 | 「迷惑がかかるのでおむつのままでいい」と訓練を拒否 | ニーズは**トイレで排泄ができること**（遠慮の言葉の奥にある本当の望み） |
| 第30回 | 尿失禁の改善が目標。歩行は自立、トイレに間に合わない | 情報は**トイレに行く時間帯** |
| 第24回 | 「便秘を解消する」が目標 | 優先度が**低い**情報は**体温の変化**（便秘に直接関係するのは水分量・食事・排便のリズム） |

**よく出る不正解**：家族の介護負担・家族の意見を中心にする／お金や制度の話を先にする／目標と関係の薄い情報（体温・人数・時間）

## ⑤ 型3：目標に合った支援内容・支援の見直し

**問われ方**：「支援内容として最も適切なもの」「見直した支援の方向性は」「長期目標の方向性は」

**解き方**
- **生活歴・昔の役割**を生かす（いちばん多いパターン）
- 目標が「〜したい」なら、それを**少しずつ実現する**具体的な支援
- 本人ができることは**本人がする**ように支える（代わりにやる・全介助は×）
- 手順がわからない人・認知症の人には、**目で見える手がかり**を使う（手順を紙に示す、写真やイラストを使った一日のスケジュール表をつくり、そのつど一緒に確認する）。伝えるときは短く具体的に、一度に1つ

| 回 | 生活歴・状況 | 正解 |
|---|---|---|
| 第31回 | 元造園業。骨折で入所し「歩けるようになるはずはない」と落ち込む | 長期目標は**造園業に再び携わること** |
| 第36回 | 元大正琴の先生 | **大正琴を教える役割をもつ** |
| 第32回 | 元体育教師。体操の順番を指摘されて意欲を失った | **体操を指導する自信を回復すること** |
| 第25回 | 「できるだけ歩いて生活したい」、短期目標「転倒しない」 | **職員と施設内を散歩する**（車いす・居室で過ごすのは×） |
| 第37回 | 「もう一度ひとりで調理したい」 | **調理に関する福祉用具の活用**（調理の代行・配食は×） |
| 第36回 | 片麻痺で作業の手順が分からず「こんなの、できない」 | **完成までの手順をわかりやすく示す** |
| 第37回 | 知的障害。目標「下着を汚さずに排泄する」 | **定期的に手順を一緒に確認する**（おむつ・全介助は×） |
| 第38回 | 部屋が散らかり自信をなくした。「前はきれいにできていた」 | **自分の部屋を整理整頓する** |

### 「自信を取り戻す」は○？×？

- 第32回（元体育教師）：「体操を**指導する**自信を回復すること」が○。失ったのは**指導する自信**（順番を指摘されて意欲を失った）。
- 第36回（元大正琴の先生）：「演奏できる自信を取り戻す」は×。Aさんは楽しそうに**演奏できている**ので、失ったものではない。失ったのは**教える役割**なので「教える役割をもつ」が○。

→ 「自信」という言葉で選ばず、**本人が何を失ったのか**を本文で確かめます。

**よく出る不正解**：車いす・居室で過ごすなど**活動を減らす**／**代わりにやる**・全介助／薬で鎮静／介護者が常に横で指示する／反省させる

## ⑥ 過去問を事例セットで解く

本番と同じく、1つの事例につき2問を続けて解きます。1問目（解釈・情報）で見つけた背景が、2問目（支援）の根拠になっていることを確かめてください。

**障害福祉の事例に出る言葉**：就労継続支援B型（B型事業所）＝雇用契約を結ばずに、自分のペースで作業をする場所／生活介護＝日中に介護や創作活動などを受ける場所／生活支援員＝事業所で日常生活の支援をする職員／サービス管理責任者＝事業所の個別支援計画をつくる人／相談支援専門員＝全体の計画（サービス等利用計画）をつくる人。

## ひっかけパターン集（事例問題で「ほぼ×」）

| 選択肢の表現 | なぜ× |
|---|---|
| 介護福祉職の気持ち・都合を基にする | 主体は利用者 |
| 「性格」「面倒だから」と決めつける | 根拠のない解釈。言葉と背景から考える |
| 車いす・居室で過ごす・活動を控える | 危険が書かれていないのに、安全のために生活を狭めている |
| 代わりにやる・全介助・おむつ | 自立支援に反する |
| 薬で鎮静する・理解させる | 本人の思いを無視している。介護福祉職の役割を超える |
| 家族の意向・施設入所を前提にする | 本人の望みを確かめていない |
| 「自信を取り戻す」なら何でも○ | 本人が何を失ったのかを本文で確かめる |
| 目標と関係の薄い情報（体温など）を優先する | 目標に直接関係する情報を選ぶ |
