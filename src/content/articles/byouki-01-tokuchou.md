**この記事のポイント**

1. 高齢者の病気は「**いくつも持つ・症状がはっきりしない・慢性・個人差が大きい・薬が効きすぎる**」。
2. 服薬介助で介護福祉職がしてはいけないのは「**他人の薬・まとめ飲み・カプセルを開ける・自己判断で量や処分を決める**」。
3. 坐薬は**とがった方から**、**口で息をして力を抜いてもらい**、入れたら**出てこないか確認**。

## ① 高齢者の病気の特徴

| ○ 高齢者の病気の特徴 | × よく出る誤り |
|---|---|
| **複数の病気を持ちやすい** | 複数疾患の合併は少ない |
| 症状が**典型的でない**（はっきりしない） | 症状が定型的 |
| **慢性**の病気が多い（完治しにくい） | 完治可能な急性疾患が多い |
| **個人差**が大きい、**潜在的な臓器障害**が多い | — |
| **薬の副作用・効果が強く出やすい** | 薬の種類は若年者より少ない |
| **環境**の影響を受けやすい、**うつ症状**を伴うことも | 環境因子の影響を受けにくい |
| **QOL（生活の質）への影響が大きい** | 生活への影響は小さい |
| 痛みに**鈍く**なる | 痛みに敏感になる |
| **予備力が低く**、**合併症**を起こして悪化しやすい | 急に悪くなることは少ない |
| **寝たきり（長期臥床）**でも**脱水**は起こる（ほかに褥瘡・筋力低下・関節拘縮・感染） | 寝ていれば脱水は起こらない |

**老年症候群**：加齢に伴って現れ、介護が必要になるきっかけになる症状のまとまり（転倒・骨折、失禁、低栄養、認知機能低下、せん妄、褥瘡など）。試験では「老年症候群に直接関わる病気＝**骨粗鬆症**」（転倒→骨折→寝たきりにつながる）が正解として出ました。

症状がはっきりしないので、**いつもと違う**ことに気づき、医療職に伝えるのが介護福祉職の役割です。

## ② 服薬・坐薬・留置カテーテル

### 高齢者の薬の効き方

| 体の変化 | 結果 |
|---|---|
| **肝臓**の代謝が遅くなる | 薬が分解されにくい |
| **腎臓**からの排泄が減る | 薬が体に残りやすい |
| 体の水分が減り、脂肪の割合が増える | 脂溶性（油に溶けやすい）の薬がたまりやすい |
| **薬の種類が多い** | **薬どうしの相互作用**（いっしょに飲むと効き方が変わる）が起こりやすい |

→ **効きすぎる・副作用が出やすい**。消化管からの吸収は大きくは変わりません。

- **抗精神病薬**（統合失調症などの薬）は、副作用で**体重が増えやすい**（肥満・代謝の異常）
- うつ病は一日の中で気分が変わる（**日内変動**、朝に悪い）ことがある。服薬は医師・薬剤師と連携する

### 介護福祉職ができる薬の介助の範囲

厚生労働省の通知（2005年）で「原則として医行為ではない」とされ、介護福祉職ができるのは、次の**3つの条件**がそろったときの薬の使用の介助です。

1. 本人の**容態が安定**している
2. 医師・看護職員による**連続的な容態の観察が必要ない**（副作用の危険や量の調整のため）
3. 薬の使い方そのものに**専門的な配慮が必要ない**

対象：**一包化**（飲む時刻ごとに1回分ずつ1袋にまとめること。医師・薬剤師が行う）された**内服薬**（舌下錠も）、**皮膚への軟膏**（褥瘡の処置は除く）、**湿布**、**点眼**、**肛門からの坐薬**、鼻への薬の噴霧。

### 服薬介助

| ○ | × |
|---|---|
| **副作用の知識**をもって介助し、様子を医療職に伝える | 服薬時間を食後に統一する |
| 薬は**本人に処方されたもの**だけ | 他の利用者の睡眠薬を勧める |
| 飲み忘れたら**医師・看護師・薬剤師に相談** | 飲み忘れたら次に**2回分** |
| カプセル・錠剤は**そのままの形**で飲む（飲みにくいときは医療職に相談） | **カプセルを開けて**中身を飲ませる |
| 湿布は**貼る場所を少しずつずらす**。皮膚が赤くなったら医療職へ | 皮膚が赤くなっても**同じ所に湿布** |
| 点眼は**容器の先がまつ毛に触れない**ように | 容器の先を目につけてさす |
| 残った薬・量・一包化は**医師・薬剤師が判断** | 残った薬を**自己判断で処分**／介護福祉士が**一包化**／その日の体調で**用量を決める** |

### 坐薬

| ○ | × |
|---|---|
| **側臥位**（横向き）で膝を軽く曲げる | 仰臥位（あおむけ）で膝を伸ばす |
| **口で息をして**おなかの力を抜いてもらう | 腹式呼吸・おなかに力を入れる |
| **とがった方から**入れる | とがっていない方から |
| 入れた後、**出てこないか確認** | — |
| 下剤以外の坐薬は**先に排泄を済ませて**から | 腟から入れる坐薬（介護福祉職は扱えない） |
| **冷所**で保管 | 暖かい場所で保管 |
| 手袋を外してから衣服を整える | 衣服を整えてから手袋を外す |

### 膀胱留置カテーテル

尿道から膀胱まで管を入れたままにして、尿を蓄尿袋（バッグ）にためる方法です。

| ○ | × |
|---|---|
| カテーテルが**折れたりねじれたりしていないか**確認。尿漏れは医療職に報告 | 尿漏れがあったらカテーテルを抜く |
| 蓄尿袋は**膀胱より低い位置**に、**床にはつけない** | 腰より高い・膀胱と同じ高さ |
| 管と袋の**接続は外さない**（閉鎖式を保つ） | 介護職が接続を外して尿を捨てる |
| 男性は**陰茎を上向き**にして**腹部に固定**（尿道の圧迫を防ぐ） | 陰茎を下向きにして太ももに固定 |
| **水分は控えない**（尿路感染予防）、**陰部洗浄はできるだけ毎日** | 水分を控える |
| 蓄尿袋は**カバーをかける**（尊厳） | カバーを外したまま |
| 膀胱洗浄は**医療職**の判断で行う | 介護職の判断で膀胱洗浄 |
| 抜いてしまいそうでも、**介護職の判断でミトンはつけない**（身体拘束） | 抜かないようにミトンをつける |

> 在宅で療養する人の主治医の役割を担う**在宅療養支援診療所**は、**24時間往診できる体制**が必要です。

## ③ 高齢者に多いその他の病気（がん・甲状腺・痛風など）

| 病気 | 押さえるポイント |
|---|---|
| **がん**（悪性新生物） | 死亡数が多い部位は、**男性＝肺がん**、**女性＝大腸がん**。肺がんは症状が出にくい、胃がんは**ピロリ菌**、肝がんは肝炎→肝硬変→肝がんの流れ、膵臓がんは早期発見が難しい |
| **痛風** | プリン体（レバー・干物など）のとりすぎで**尿酸**がたまり、**足の親指の付け根**が激しく痛む |
| **脂質異常症** | 自覚症状がほとんどなく、**動脈硬化**を進める |
| 甲状腺の病気 | → [心臓・糖尿病・肺炎・脱水](../byouki-02-shinzou/) |

### 死因と介護が必要になった原因

| 統計 | 順位 |
|---|---|
| **死因**（2023年 人口動態統計） | ①**悪性新生物（がん）** ②**心疾患** ③老衰 ④脳血管疾患 ⑤肺炎 |
| **要介護者**が介護を必要とした原因（2022年 国民生活基礎調査） | ①**認知症** ②**脳血管疾患（脳卒中）** ③骨折・転倒 |
| **要支援者**が介護を必要とした原因（同） | ①**関節疾患** ②高齢による衰弱 ③骨折・転倒 |

> 古い過去問は当時の調査の順位で作られています（例：以前は要介護の原因1位が脳血管疾患）。

## ひっかけパターン集（服薬で「ほぼ×」）

| 選択肢の表現 | なぜ× |
|---|---|
| 飲み忘れたので次に2回分 | 過量になる。医療職に確認 |
| カプセルを開けて飲ませる | 効き方が変わる |
| 介護福祉士が一包化・用量を決める | 医師・薬剤師の仕事 |
| 坐薬はとがっていない方から | とがった方から |
| 蓄尿袋を膀胱より高く | 尿が逆流して感染の原因 |
| 介護福祉職は軟膏で褥瘡を処置できる | 褥瘡の処置は医療職。介護職の軟膏は褥瘡以外 |
| 留置カテーテルの人は水分を控える | 尿路感染を防ぐため水分をとる |
