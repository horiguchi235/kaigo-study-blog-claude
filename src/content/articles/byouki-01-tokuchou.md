**この記事のポイント**

1. 高齢者の病気は「**いくつも持つ・症状がはっきりしない・慢性・個人差が大きい・薬が効きすぎる**」。
2. 服薬介助で介護福祉職がしてはいけないのは「**他人の薬・まとめ飲み・カプセルを開ける・自己判断で量や処分を決める**」。
3. 坐薬は**とがった方から**、**口で息をして力を抜いてもらい**、入れたら**出てこないか確認**。

---

## ① 高齢者の病気の特徴【発達と老化の理解】

| ○ 高齢者の病気の特徴 | × よく出る誤り |
|---|---|
| **複数の病気を持ちやすい** | 複数疾患の合併は少ない |
| 症状が**典型的でない**（はっきりしない） | 症状が定型的 |
| **慢性**の病気が多い（完治しにくい） | 完治可能な急性疾患が多い |
| **個人差**が大きい、**潜在的な臓器障害**が多い | — |
| **薬の副作用・効果が強く出やすい** | 薬の種類は若年者より少ない |
| **環境**の影響を受けやすい、**うつ症状**を伴うことも | 環境因子の影響を受けにくい |
| **QOL（生活の質）への影響が大きい** | — |
| 痛みに**鈍く**なる | 痛みに敏感になる |

**老年症候群**：加齢に伴って現れ、介護が必要になるきっかけになる症状のまとまり（転倒・骨折、失禁、低栄養、認知機能低下、せん妄、褥瘡など）。病気として直接関わるのは**骨粗鬆症**。

## ② 服薬・坐薬・留置カテーテル【発達と老化の理解／介護の基本／生活支援技術】

### 高齢者の薬の効き方

| 体の変化 | 結果 |
|---|---|
| **肝臓**の代謝が遅くなる | 薬が分解されにくい |
| **腎臓**からの排泄が減る | 薬が体に残りやすい |
| 体の水分が減り、脂肪の割合が増える | 脂溶性の薬がたまりやすい |
| **薬の種類が多い** | **薬どうしの相互作用**が起こりやすい |

→ **効きすぎる・副作用が出やすい**。消化管からの吸収は大きくは変わりません。

### 服薬介助

| ○ | × |
|---|---|
| **副作用の知識**をもって介助 | 服薬時間を食後に統一する |
| 点眼は**容器の先がまつ毛に触れない**ように | 他の利用者の睡眠薬を勧める |
| 飲めない・残ったときは**医師・看護師・薬剤師に相談** | 飲み忘れたら次に**2回分** |
| — | **カプセルを開けて**中身を飲ませる |
| — | 皮膚が赤くなっても**同じ所に湿布** |
| — | 残った薬を**自己判断で処分**／介護福祉士が**一包化**／その日の体調で**用量を決める** |

### 坐薬

| ○ | × |
|---|---|
| **側臥位**で膝を軽く曲げる | 仰臥位で膝を伸ばす |
| **口で息をして**おなかの力を抜いてもらう | 腹式呼吸・おなかに力を入れる |
| **とがった方から**入れる | とがっていない方から |
| 入れた後、**出てこないか確認** | — |
| 下剤以外の坐薬は**先に排泄を済ませて**から | 腟から入れる坐薬（介護福祉職は扱えない） |
| **冷所**で保管 | 暖かい場所で保管 |
| 手袋を外してから衣服を整える | 衣服を整えてから手袋を外す |

### 膀胱留置カテーテル

| ○ | × |
|---|---|
| カテーテルが**折れたりねじれたりしていないか**確認 | 尿漏れがあったらカテーテルを抜く |
| 蓄尿袋は**膀胱より低い位置**に | 腰より高い・膀胱と同じ高さ |
| 男性は**陰茎を上向き**にして**腹部に固定**（尿道の圧迫を防ぐ） | — |
| **水分は控えない**（尿路感染予防） | 水分を控える |
| 蓄尿袋は**カバーをかける**（尊厳） | カバーを外したまま |
| 抜いてしまいそうでも、**介護職の判断でミトンはつけない**（身体拘束） | — |

> 在宅療養支援診療所は**24時間往診できる体制**が必要。

介護福祉職が行える坐薬を用いた介護として、最も適切なものはどれ？

1. 腟から挿入する坐薬を扱える
2. 坐薬は、暖かい場所で保管する
3. 坐薬は、とがっていない方から挿入する

**正解：5**　介護福祉職が扱えるのは肛門からの坐薬です。暖かい所では溶けるので冷所保管、とがった方から入れ、口で息をして力を抜いてもらいます。

## ひっかけパターン集（服薬で「ほぼ×」）

| 選択肢の表現 | なぜ× |
|---|---|
| 飲み忘れたので次に2回分 | 過量になる。医療職に確認 |
| カプセルを開けて飲ませる | 効き方が変わる |
| 介護福祉士が一包化・用量を決める | 医師・薬剤師の仕事 |
| 坐薬はとがっていない方から | とがった方から |
| 蓄尿袋を膀胱より高く | 尿が逆流して感染の原因 |
| 留置カテーテルの人は水分を控える | 尿路感染を防ぐため水分をとる |
