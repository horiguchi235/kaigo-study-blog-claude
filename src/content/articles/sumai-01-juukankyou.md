**この記事のポイント**

1. 介護保険の住宅改修は「**手すり・段差解消・床材・扉・洋式便器**」（＋それに伴う工事）の5つ。**機器の設置や増築は対象外**。
2. 扉は「**トイレは外開き**、**浴室は引き戸**、取っ手は**棒型・レバー型**」。
3. 疾患別：**リウマチ＝握らない平手すり**、**パーキンソン病＝床に歩幅の目印**、**全盲＝音声ガイド付き調理器**。

## ① 住宅改修と扉・浴室・床

### 介護保険の住宅改修（上限20万円）

<photo name="sumai-01__jutaku-kaishu" caption="住宅改修の例：廊下の**手すり**、敷居をなくした**段差解消**、**滑りにくい床**、**引き戸**への取り替え、**洋式便器**とL字手すり。">

| ○ 対象 | × 対象外 |
|---|---|
| **手すりの取付け**、**そのための壁の下地補強** | 取り外しできる手すり（→福祉用具） |
| **段差の解消** | 階段昇降機・段差解消機の設置（→福祉用具や対象外） |
| **床材の変更**（**畳 → フローリング**など） | 浴室のすのこ（→福祉用具の購入） |
| **引き戸などへの扉の取替え** | トイレの増設・浴室暖房機 |
| **和式便器 → 洋式便器** | 火災警報器・緊急通報装置・電磁調理器 |

### 扉・浴室・階段

| ○ | × |
|---|---|
| トイレの開き戸は**外開き**（中で倒れても開けられる） | 内開き |
| 浴室の入口は**引き戸** | 段差10cm |
| 引き戸の取っ手は**棒型** | 丸いノブ（握ってひねる動作が必要） |
| 浴槽の縁の高さは床から**40cm程度**（またぎやすい） | 50cm・20cm |
| 廊下の手すりは床から**75〜80cm** | 120cm |
| 自走用車いすの廊下幅は**85cm以上**が目安 | 60cm |
| 階段の手すりは**下りるときの利き手側**（片側の場合） | 上るときの利き手側 |
| 階段の段鼻は**反対色**で目立たせる | 同系色 |

**ユニバーサルデザインの7原則**：誰にでも公平に使える、柔軟に使える、使い方が簡単、必要な情報がすぐわかる、ミスしても危険が少ない、少ない力で使える、**誰にでも使える大きさと広さ**。「高齢者が優先」「訓練が必要」「伝達手段は1つ」は×。

## ② 室内環境・転倒予防・防災

| テーマ | ○ 正解 | × よく出る不正解 |
|---|---|---|
| 感覚の低下 | **嗅覚**の低下（ガス漏れに気づかない）→ **電磁調理器** | 照明を暗く／防犯ベルの音量を下げる／真夏に冷房を控える |
| 熱中症 | **屋内でも起こる** | — |

| 寝室の位置 | **トイレの近く** | 玄関と別の階／照明の真下にベッド |
| 換気 | **対角線上の窓**を開けて**風の通り道**をつくる | 湿度を高く保つ／硬い床材 |
| 施設の居室 | **使い慣れた家具**を置く。ユニットの「プライベート空間」＝**居室** | ドアを開けたまま／職員の感覚で室温調整 |
| グループホーム | カーテンは**防炎物品**、住宅地の中に、個室 | 住宅地から離す／多床室／統一した家具 |

| 地震対策 | 非常持ち出し品を**リュックサック**にまとめる | 家具にキャスター／書棚の上に重い物／避難経路は1方向 |

## ④ 福祉用具の制度・室内環境・ユニバーサルデザイン

- **介護保険の住宅改修の対象**：①**手すりの取り付け** ②**段差の解消** ③滑り防止・移動しやすい**床材への変更** ④**引き戸などへの扉の取り替え** ⑤**洋式便器などへの取り替え** ⑥これらに付帯して必要な工事。上限は**20万円**（自己負担1〜3割）で、**事前に市町村へ申請**（理由書が必要）。
- **ベッドの高さ**は、座ったとき足の裏が床につく**40〜45cm**程度。
- 高齢者の部屋は**適度に明るい照明**に。浴室の床は**滑りにくい材質**、扉は**引き戸**など救助しやすいものを。
- 認知症の人が**影を怖がる**ときは、部屋を明るくし<strong>影ができにくい照明（無影灯など）</strong>を使う。
- **介護保険の福祉用具**：**貸与13種目**（車いす・特殊寝台・床ずれ防止用具・体位変換器・手すり・スロープ・歩行器・歩行補助つえ・認知症老人徘徊感知機器・移動用リフトなど）、**購入6種目**（腰掛便座・入浴補助用具・簡易浴槽・**移動用リフトのつり具**・自動排泄処理装置の交換部品・**排泄予測支援機器**）。肌にふれる排泄・入浴用品は貸与ではなく購入。2024年から**固定式スロープ・歩行器・単点杖・多点杖は貸与か購入を選べる**。
- 室内環境のめやす：室温は**24℃±2℃**（季節で調整）、湿度**40〜60％**、外気との差は**5〜7℃以内**、換気は**2か所以上の窓**を開ける。**シックハウス症候群**＝建材の化学物質で頭痛など。
- **階段**：手すりは**下りるときの利き手側**（両側が理想）、高さ75〜80cm、蹴上げは低め・踏み面は広め、足元灯と**三路スイッチ**（上下どちらでも点灯）。
- 浴槽の縁の高さは洗い場から**約40cm**（膝くらい）。**トイレの戸は引き戸か外開き**（中で倒れても開けられる）、鍵は外から開けられるもの。
- **ユニバーサルデザインの7原則**：公平性・柔軟性・**単純で直感的**・わかりやすい情報・安全性・体への負担が少ない・使いやすい広さ。ドアノブより**レバーハンドル**。
