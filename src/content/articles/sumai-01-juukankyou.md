**結論を3行で**

1. 介護保険の住宅改修は「**手すり・段差解消・床材・扉・洋式便器**」（＋それに伴う工事）の5つ。**機器の設置や増築は対象外**。
2. 扉は「**トイレは外開き**、**浴室は引き戸**、取っ手は**棒型・レバー型**」。
3. 疾患別：**リウマチ＝握らない平手すり**、**パーキンソン病＝床に歩幅の目印**、**全盲＝音声ガイド付き調理器**。

## ① 住宅改修と扉・浴室・床【生活支援技術】

### 介護保険の住宅改修（上限20万円）

| ○ 対象（第25・27回） | × 対象外 |
|---|---|
| **手すりの取付け**、**そのための壁の下地補強** | 取り外しできる手すり（→福祉用具） |
| **段差の解消** | 階段昇降機・段差解消機の設置（→福祉用具や対象外） |
| **床材の変更**（**畳 → フローリング**など）（第36回） | 浴室のすのこ（→福祉用具の購入） |
| **引き戸などへの扉の取替え** | トイレの増設・浴室暖房機 |
| **和式便器 → 洋式便器** | 火災警報器・緊急通報装置・電磁調理器 |

### 扉・浴室・階段

| ○ | × |
|---|---|
| トイレの開き戸は**外開き**（中で倒れても開けられる）（第24回） | 内開き |
| 浴室の入口は**引き戸**（第28回） | 段差10cm |
| 引き戸の取っ手は**棒型**（第33回） | 丸いノブ（握ってひねる動作が必要） |
| 浴槽の縁の高さは床から**40cm程度**（またぎやすい） | 50cm・20cm |
| 廊下の手すりは床から**75〜80cm** | 120cm |
| 自走用車いすの廊下幅は**85cm以上**が目安 | 60cm |
| 階段の手すりは**下りるときの利き手側**（片側の場合） | 上るときの利き手側 |
| 階段の段鼻は**反対色**で目立たせる | 同系色 |

**ユニバーサルデザインの7原則**：誰にでも公平に使える、柔軟に使える、使い方が簡単、必要な情報がすぐわかる、ミスしても危険が少ない、少ない力で使える、**誰にでも使える大きさと広さ**（第32回）。「高齢者が優先」「訓練が必要」「伝達手段は1つ」は×。

## ② 室内環境・転倒予防・防災【生活支援技術】

| テーマ | ○ 正解 | × よく出る不正解 |
|---|---|---|
| 感覚の低下 | **嗅覚**の低下（ガス漏れに気づかない）→ **電磁調理器**（第24回） | 照明を暗く／防犯ベルの音量を下げる／真夏に冷房を控える |
| 熱中症 | **屋内でも起こる**（第26回） | — |
| **ヒートショック** | 急な温度差で血圧が大きく変動。**トイレ・脱衣室を暖める**（**小型のパネルヒーター**）（第33回） | 熱湯でのやけど／居室の温度を下げる／湯温60℃ |
| 転倒予防 | マットは**滑り止め付き**（第29回）、足元灯は光源が直接見えないように | コードを動線に這わせる／スリッパ／移動を減らす |
| 寝室の位置 | **トイレの近く**（第34回） | 玄関と別の階／照明の真下にベッド |
| 換気 | **対角線上の窓**を開けて**風の通り道**をつくる（第29・38回） | 湿度を高く保つ／硬い床材 |
| 施設の居室 | **使い慣れた家具**を置く（第30回）。ユニットの「プライベート空間」＝**居室**（第30回） | ドアを開けたまま／職員の感覚で室温調整 |
| グループホーム | カーテンは**防炎物品**（第25回）、住宅地の中に、個室 | 住宅地から離す／多床室／統一した家具 |
| 事故防止 | **在宅酸素療法中の人のそばで喫煙しない**（火気厳禁）（第37回） | 認知症の人にガスコンロ |
| 地震対策 | 非常持ち出し品を**リュックサック**にまとめる（第32回） | 家具にキャスター／書棚の上に重い物／避難経路は1方向 |

> 住環境と健康：**シックハウス症候群**は建材の化学物質による体調不良（生活不活発病ではない）。ダニの死がいやカビは**アレルギー**の原因になります。

古い住宅で暮らす高齢者のヒートショックを防ぐための環境整備として、最も適切なものはどれ？

1. 居室の室温を低くする
2. 脱衣室の照明を明るくする
3. トイレに床置き式の小型のパネルヒーターを置く
4. 入浴直前に浴槽の湯温を60℃にし、蒸気を立てる
5. 24時間換気システムを導入する

<details class="answer">
<summary>正解を見る</summary>

**正解：3**　ヒートショックは暖かい部屋から寒いトイレ・脱衣室・浴室へ移ったときの急な温度差で起こります。寒い場所を暖めて温度差を小さくします。

## ③ 疾患別の住まいと福祉用具・マーク【生活支援技術／介護の基本】

### 疾患・障害に合わせた工夫

| 状態 | ○ 正解 |
|---|---|
| **関節リウマチ** | **握らずに使える平手すり**（第36回）。いすは**高め**、ベッド、**引き戸**、居室は1階 |
| **パーキンソン病** | 廊下の床に**歩幅に合わせた目印**（第38回）。スロープ・重ねたカーペットは×（すくみ足・つまずき） |
| **全盲** | **音声ガイド付き電磁調理器**（第35回） |
| 胸髄損傷で車いす（浴槽に入る） | **移乗台**（バスボード）（第34回） |
| 一人暮らしでごみ出し・食事の準備が難しくなった要介護1の人の住み替え | **ケアハウス**（軽費老人ホーム）（第24回） |

### 福祉用具を安全に使う

- 車いすを**たたむ前にブレーキ**をかける（第35回）
- 移動用リフトで吊り上げるときは**体から手を離さない**。入浴用介助ベルトは真上に持ち上げない
- 複数の福祉用具は**状況に合わせて組み合わせ**、**使い始めた後もモニタリング**する（第36回）。福祉用具があっても住宅改修を検討してよい。選択は**福祉用具専門相談員**などと

### マーク・介護ロボット

| マーク・用語 | 意味 |
|---|---|
| **JISマーク** | 国に登録された**第三者認証機関**が品質を保証（第28回） |
| **聴覚障害者標識**（蝶のマーク） | 聴覚障害のある運転者 → **手話や筆談**で話しかける（第35回） |
| **オストメイトマーク** | **オストメイト**（人工肛門・人工膀胱の人）用の設備があるトイレ（第31回） |
| **介護ロボット** | 利用者の**自立支援・生活の質の向上**が期待される（第38回）。人員配置基準の撤廃・巡回不要・関わりを減らす、は× |
