**この記事のポイント**

1. 介護保険の住宅改修は「**手すり・段差解消・床材・扉・洋式便器**」（＋それに伴う工事）の5つ。**機器の設置や増築は対象外**。
2. 扉は「**トイレは外開き**、**浴室は引き戸**、取っ手は**棒型・レバー型**」。
3. 疾患別：**リウマチ＝握らない平手すり**、**パーキンソン病＝床に歩幅の目印**、**全盲＝音声ガイド付き調理器**。

## ① 住宅改修と扉・浴室・床

### 介護保険の住宅改修（上限20万円）

<photo name="sumai-01__jutaku-kaishu" caption="住宅改修の例：廊下の**手すり**、敷居をなくした**段差解消**、**滑りにくい床**、**引き戸**への取り替え、**洋式便器**とL字手すり。">

| ○ 対象 | × 対象外 |
|---|---|
| **手すりの取付け**、**そのための壁の下地補強** | 取り外しできる手すり（→福祉用具） |
| **段差の解消**（敷居を低くする・スロープを設置する工事など） | 階段昇降機・段差解消機などの**機器の設置**（工事のいらない段差解消機は福祉用具貸与の移動用リフトに入る） |
| **床材の変更**（**畳 → フローリング**など） | 浴室のすのこ（→福祉用具の購入） |
| **引き戸などへの扉の取替え** | トイレの増設・浴室暖房機 |
| **和式便器 → 洋式便器** | 火災警報器・緊急通報装置・電磁調理器 |

- 上記5つと、それに**付帯して必要な工事**が対象。上限は**20万円**（自己負担1〜3割）で、**工事の前に市町村へ申請**する（ケアマネジャーなどの理由書が必要）
- 20万円は原則1人1回分。**転居した**とき、**要介護状態区分が3段階以上上がった**ときは、もう一度利用できる

### 扉・浴室・階段

| ○ | × |
|---|---|
| トイレの戸は**引き戸か外開き**（中で倒れても開けられる）、鍵は外から開けられるもの | 内開き（倒れた人に戸が当たって開かない） |
| 浴室の入口は**引き戸** | 開き戸 |
| 浴室の入口の段差は**なくす** | 段差10cm |
| 取っ手は**棒型・レバーハンドル** | 丸いノブ（握ってひねる動作が必要） |
| 浴室の床は**滑りにくい**材質 | — |
| 階段の手すりは**下りるときの利き手側**（片側の場合。両側が理想） | 上るときの利き手側 |
| 階段の段鼻（段の先端）は**反対色**で目立たせる | 同系色 |
| 階段は蹴上げ（1段の高さ）を**低め**、踏み面（足をのせる面）を**広め**に。足元灯と**三路スイッチ**（上下どちらでも点灯） | — |

### 住まいの数値早見表

| 場所 | 目安 |
|---|---|
| 廊下・階段の手すりの高さ | 床から**75〜80cm** |
| 浴槽の縁の高さ | 洗い場の床から**40cm程度**（膝くらい。またぎやすい） |
| 自走用車いすの廊下幅 | **85cm以上** |
| ベッドの高さ | 座ったとき足の裏が床につく**40〜45cm**程度 |

### ユニバーサルデザインの7原則

| 原則 | 身近な例 |
|---|---|
| 誰にでも**公平**に使える | 自動ドア |
| 使い方を選べる（**柔軟性**） | 左右どちらの手でも使えるはさみ |
| 使い方が**簡単で直感的** | 押すだけのボタン |
| 必要な**情報がすぐわかる** | 音と光で知らせる表示 |
| **ミスしても危険が少ない** | 空だきを防ぐ機能 |
| **少ない力**で使える | **レバーハンドル** |
| 誰にでも使える**大きさと広さ** | 広いトイレ |

「高齢者が優先」「訓練が必要」「伝達手段は1つ」は×です。
