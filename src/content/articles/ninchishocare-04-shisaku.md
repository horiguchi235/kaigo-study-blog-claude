**この記事のポイント**

1. 2024年1月に**認知症基本法**が施行され、同年12月に国の**認知症施策推進基本計画**が決まった。目的は認知症の人が希望をもって暮らせる**共生社会**。
2. 過去問によく出る**認知症施策推進大綱（2019年）**は「**共生**」と「**予防**」が**車の両輪**、柱は**5つ**。予防は「ならない」ではなく「**遅らせる・進行を緩やかにする**」。
3. 認知症サポーターは**正しく理解して見守る応援者**（ステップアップ講座→**チームオレンジ**）。認知症初期集中支援チームには**医師が入り**、**チーム員会議**で支援方針を決める。

## ① 認知症基本法と認知症施策推進基本計画

正式名は「共生社会の実現を推進するための認知症基本法」。**2023年6月に成立**し、**2024年1月1日に施行**されました。今の認知症施策の土台になる法律です。

| 項目 | 中身 |
|---|---|
| 目的 | 認知症の人が**尊厳を保持**しつつ**希望をもって暮らせる**よう、**共生社会**の実現を推進する |
| 基本理念 | 認知症の人が**自らの意思**で日常生活・社会生活を営めること、**意見を表明し社会に参画**する機会の確保、本人の意向を尊重した切れ目のない保健医療・福祉サービス、**家族等への支援**など（7つ） |
| 国民の責務 | 認知症への正しい知識と理解を深め、共生社会の実現に寄与するよう**努める** |
| 認知症の日・月間 | **9月21日**が「認知症の日」、**9月**が「認知症月間」 |
| 計画 | 国は**認知症施策推進基本計画**をつくる（**義務**）。都道府県・市町村の認知症施策推進計画は**努力義務**。どちらも認知症の人や家族の意見を聴く |
| 推進体制 | 内閣に**認知症施策推進本部**（本部長＝内閣総理大臣） |
| 基本的施策 | 国民の理解の増進／生活の**バリアフリー化**／社会参加の機会の確保（若年性認知症の人の就労支援など）／**意思決定の支援**と権利利益の保護／保健医療・福祉サービスの体制整備／相談体制の整備／研究等の推進／予防（早期発見・早期診断・早期対応） |

**認知症施策推進基本計画**（**2024年12月**閣議決定、2029年度までのおおむね5年間）

- 「**新しい認知症観**」＝認知症になったら何もできなくなるのではなく、**できること・やりたいことがあり**、住み慣れた地域で仲間とつながりながら**希望をもって自分らしく暮らし続けられる**という考え方
- 施策は、**認知症の人本人の声を聴き、本人が参画して**つくり、評価する

## ② 認知症の人を支える取り組み

### 認知症サポーター

| ○ | × |
|---|---|
| 正しい知識と理解をもち、**認知症の人と家族を見守り、支援する**応援者。**誰でもなれる** | 認知症ケア専門の介護福祉職 |
| **ステップアップ講座**を受けた人は**チームオレンジ**（サポーターがチームで本人・家族を支えるしくみ）への参加が期待される | 講座を受ければ介護の仕事ができる |

## ③ 統計と運転免許

| 項目 | 押さえる数字・事実 |
|---|---|
| 認知症高齢者数 | **2024年公表の推計：2025年 約472万人、2040年 約584万人**（高齢者の約15％）。軽度認知障害（MCI）は2025年 約564万人。旧推計は**2012年 462万人 → 2025年 約700万人**で、過去問はこの数字 |
| 原因疾患の割合 | **アルツハイマー型が約7割**、血管性が約2割（2013年 調査） |
| 認知症高齢者の日常生活自立度Ⅱ以上（見守りなどが必要な人）がいる場所 | **居宅**がいちばん多い |
| 介護が必要になった主な原因（2022年 国民生活基礎調査） | 要介護者では**認知症が1位**、次いで脳血管疾患・骨折転倒 |
| アルツハイマー型の有病率 | **男性より女性が高い** |
| リスク | 年齢が**高い**ほど上がる。**生活習慣病と関連**し、**運動は予防に有効** |

### 高齢者の運転免許

| ○ | × |
|---|---|
| **75歳以上**は免許更新時に**認知機能検査** | 80歳から運転技能検査が義務（一定の違反歴がある75歳以上が対象） |
