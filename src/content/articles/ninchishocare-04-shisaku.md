**この記事のポイント**

1. 認知症施策推進大綱（2019年）は「**共生**」と「**予防**」が**車の両輪**。予防は「ならない」ではなく「**遅らせる・進行を緩やかにする**」。
2. 認知症サポーターは**正しく理解して見守る応援者**。ステップアップ講座を受けると**チームオレンジ**で活動。
3. 認知症初期集中支援チームには**医師が入り**、**チーム員会議**で支援方針を決める。

## ① 認知症施策

### 認知症サポーター

| ○ | × |
|---|---|
| 正しい知識と理解をもち、**認知症の人と家族を見守り、支援する** | 認知症ケア専門の介護福祉職 |
| **ステップアップ講座**を受けた人は**チームオレンジ**への参加が期待される | 10万人・100万人を目標に養成 |
| 講座は**自治体や企業・団体**が実施（講師はキャラバン・メイト） | 国が実施主体／認知症介護実践者等養成事業の一環 |

### 認知症施策推進大綱（2019年）

- 基本の考え方：**「共生」と「予防」を車の両輪**
- 「予防」＝**認知症になるのを遅らせる・なっても進行を緩やかにする**（「ならない」ではない）
- **5つの柱**
  1. **普及啓発・本人発信支援**
  2. 予防
  3. 医療・ケア・介護サービス・介護者への支援
  4. 認知症バリアフリーの推進・若年性認知症の人への支援・社会参加支援
  5. 研究開発・産業促進・国際展開
- 「本人発信支援」は**本人が自ら発信する**ことの支援（家族が代弁する、は×）

### そのほかの取り組み

| 取り組み | ○ 正しい説明 | × |
|---|---|---|
| **認知症初期集中支援チーム** | **医師を含む**医療・介護の専門職。家庭を**訪問**してアセスメントし、**チーム員会議で支援方針を決める**。**家族も支援対象**。期間はおおむね**6か月** | 入院・入所すべきという考え／診断済みの人は対象外／支援期間2〜3年／金銭管理・ケアプラン作成・契約を行う |
| **本人ミーティング** | **当事者どうしが語り合い、社会に発信**する | — |
| **認知症ケアパス** | 状態に応じた**適切なサービス提供の流れ**をまとめたもの。**市町村**が作成 | 都道府県ごと／地域密着型サービス／レスパイトケア |
| 認知症カフェ | 本人・家族・住民・専門職が集う場 | 介護指導者を養成する |
| 若年性認知症支援コーディネーター | 若年性認知症の人の相談・支援の調整 | 診断を行う |
| 介護保険の対象 | **40歳以上**（第2号被保険者は認知症などの特定疾病） | 39歳で利用できる |

## ② 統計と運転免許

| 項目 | 押さえる数字・事実 |
|---|---|
| 認知症高齢者数 | 旧推計：**2012年 462万人 → 2025年 約700万人**（過去問はこの数字）。**2024年公表の新推計：2025年 約472万人、2040年 約584万人**（軽度認知障害は2025年 約564万人） |
| 自立度Ⅱ以上の人がいる場所 | **居宅**がいちばん多い |
| 介護が必要になった主な原因（2016年） | **認知症が上位**（脳血管疾患・高齢による衰弱・骨折転倒と並ぶ） |
| アルツハイマー型の有病率 | **男性より女性が高い** |
| リスク | 年齢が**高い**ほど上がる。**生活習慣病と関連**し、**運動は予防に有効** |

### 高齢者の運転免許

| ○ | × |
|---|---|
| **75歳以上**は免許更新時に**認知機能検査** | 80歳から運転技能検査が義務（一定の違反歴がある75歳以上が対象） |
| 認知症と診断されると**免許の取消し**などの対象 | MCIで取消し／サポートカー限定免許なら運転可 |
| 運転経歴証明書は**自主返納**した人に交付 | 取消し後に交付 |

## ③ 認知症施策の年表と支援の担い手

- 認知症施策の年表：1987年 初の認知症グループホーム／**2004年「痴呆」→「認知症」へ名称変更**／2006年 地域密着型サービス／2012年 オレンジプラン／2015年 **新オレンジプラン**／2018年 意思決定支援ガイドライン／**2019年 認知症施策推進大綱（共生と予防）**／**2023年 認知症基本法**（2024年1月施行）。
- **認知症初期集中支援チーム**＝医師（専門医）と医療・介護の専門職が、**初期の段階で家庭を訪問**し、集中的に支えて医療・介護サービスにつなぐ。
- **認知症疾患医療センター**＝鑑別診断・専門医療相談（全国に約500か所）。**認知症サポーター**は1,500万人を超え、サポーターなどが支援チームをつくる「**チームオレンジ**」も進んでいる。
- **認知症ケアパス**＝状態に応じてどんなサービスを受けられるかの流れを示したもの（市町村が作成）。
