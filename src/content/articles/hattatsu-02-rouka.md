**この記事のポイント**

1. 生理的老化は**誰にでも起こる・遺伝的にプログラムされた・元に戻らない**変化。階段で息切れ＝**予備力の低下**。
2. 老化で「**下がる**」もの＝免疫・骨密度・尿の濃縮力・嚥下・メラトニン。「**増える**」もの＝不整脈・収縮期血圧。
3. 感覚は**高音から聞こえにくい・明るさが多く必要・暗さに慣れにくい・味が薄く感じる**。**手続き記憶・意味記憶は保たれる**。

## ① 老化の考え方・老化の学説【発達と老化の理解】

| ○ | × |
|---|---|
| **老性自覚**（自分が老いたと感じる）の時期には**個人差**がある | 疾病は老性自覚に影響しない／精神機能は一貫して低下 |
| **生理的老化**＝誰にでも起こり、**遺伝的にプログラム**された不可逆的な変化 | 環境で起こる・個人差がない・回復する（それは病的老化の説明に近い） |
| 階段を上ると息切れ＝**予備力の低下** | 防衛力・回復力・適応力の低下 |

### 老化の学説

| 学説 | 中身 |
|---|---|
| **プログラム説** | **細胞分裂の回数はあらかじめ決まっている** |
| フリーラジカル説 | **活性酸素**が細胞を傷つける |
| エラー破局説 | DNA・たんぱく質合成の**誤りが蓄積** |
| 消耗説 | 使ううちにすり減る |
| 老化の免疫説 | 免疫機能の低下 |

## ② 老化によるからだの変化【発達と老化の理解】

| 器官 | ○ 老化の変化 | × |
|---|---|---|
| 免疫 | **免疫機能が低下** | — |
| 皮膚 | 乾燥・弾力低下 | 皮脂が増える |
| 運動器 | **骨密度の低下**、筋力低下、関節の可動域が狭まる | 骨密度は変わらない |
| 循環器 | **不整脈が増える**、動脈硬化、**収縮期血圧が上がる** | 心拍出量が増える |
| 血液・呼吸 | **貧血になりやすい**、肺活量・肺の弾力が低下、残気量は増加 | — |
| 腎・泌尿器 | **尿の濃縮力が低下**（夜間頻尿）、薬が体に残りやすい。前立腺肥大は男性 | 膀胱容量が増える |
| 嚥下 | **喉頭の挙上が不十分**、咳反射が弱い、唾液が減る | 舌骨の位置が上がる |
| 睡眠 | **メラトニンが減る**、眠りが浅い、中途覚醒・**早朝覚醒**、寝つくまでの時間が長い | ノンレム睡眠の深い眠りが増える |

## ③ 感覚・認知機能の変化【発達と老化の理解】

### 感覚

| 感覚 | ○ 老化の変化 | × |
|---|---|---|
| 視覚 | 近くが見えにくい（**老眼**）、**物の識別に必要な照度が高くなる**、**暗順応に時間がかかる**、視野が狭くなる、青と黒・黄と白の区別がつきにくい | 周辺視野が広くなる |
| 聴覚 | **感音性難聴**。**高音域から**聞こえにくい、**似た音の聞き分け**が難しい（「いちじ」と「しちじ」）、**大声でかえって響いて聞こえにくい（補充現象）** | 低音から聞こえにくい |
| 味覚 | **感受性が低下**し、**濃い味を好む**。塩味の感受性も低下 | 甘味だけ敏感になる |
| 嗅覚・触覚 | 鈍くなる | 振動・においに敏感になる |

### 認知・記憶

| 保たれやすい ○ | 低下しやすい |
|---|---|
| **手続き記憶**（自転車の乗り方など体で覚えたこと） | **エピソード記憶**（出来事の記憶） |
| **意味記憶**（言葉の意味・知識） | **作業記憶（ワーキングメモリ）** |
| **結晶性知能**（経験・知識に基づく判断） | **流動性知能**（新しい場面に素早く対応） |
| — | **選択的注意**（多くの情報から必要なものを選ぶ）・**展望的記憶** |

> 結晶性知能は高齢になっても**維持・上昇**しうる。流動性知能は**30〜40代をピーク**に低下します。

1. 大きな声で話しかけられると、かえって聞こえにくいことがある
2. 会話しながらの運転のほうが安全になる
3. 白と黄色より白と赤の区別がつきにくくなる
