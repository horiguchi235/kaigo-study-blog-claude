**この記事のポイント**

1. 生理的老化は**誰にでも起こる・遺伝的にプログラムされた・元に戻らない**変化。階段で息切れ＝**予備力の低下**。
2. 老化で「**下がる**」もの＝免疫・骨密度・尿の濃縮力・嚥下・メラトニン。「**増える**」もの＝不整脈・収縮期血圧。
3. 感覚は**高音から聞こえにくい・明るさが多く必要・暗さに慣れにくい・味が薄く感じる**。**手続き記憶・意味記憶は保たれる**。

## ① 老化の考え方・老化の学説

| ○ | × |
|---|---|
| **老性自覚**（自分が老いたと感じる）の時期には**個人差**がある | 老性自覚の時期は誰でも同じ |
| 病気（疾病）も老性自覚のきっかけになる | 疾病は老性自覚に影響しない |
| 精神機能は、低下するものと保たれるもの・伸びるものがある | 精神機能は一貫して低下 |

### 生理的老化と病的老化

| | **生理的老化** | 病的老化 |
|---|---|---|
| 起こる人 | **誰にでも**起こる（普遍性） | 病気や環境の影響で**一部の人**に起こる |
| 原因 | 体の内側（**遺伝的にプログラム**された変化） | 病気・生活習慣・環境など |
| 例 | 白髪・老眼・聴力の低下 | 骨粗鬆症・動脈硬化が進んで病気になる |
| 戻るか | 元に戻らない（不可逆） | 治療や生活の見直しで進みを抑えられることがある |

**ストレーラーの老化の4原則**（生理的老化の基準）

| 原則 | 意味 |
|---|---|
| 普遍性 | **誰にでも**起こる |
| 内在性 | 外からの原因ではなく、<strong>体の内側（遺伝的なプログラム）</strong>から起こる |
| 進行性 | 少しずつ進み、**元に戻らない** |
| 有害性 | 体の機能を低下させ、**生きるうえで不利**にはたらく |

- 「内在性」は「固有性」と書かれることもあります。人名も「シュトレーラー」と書かれることがあります
- **加齢**は生まれてから死ぬまでのすべての変化、**老化**はそのうち成熟したあとに心身のはたらきが下がっていく変化です
- 一部の人だけに起こる病気は「普遍性」に当てはまらないので、生理的老化ではありません

### 恒常性（ホメオスタシス）を保つ4つの力

| 力 | 意味 | 老化による変化 |
|---|---|---|
| **予備力** | ふだんは使っていない**余力** | 減る → 階段を上ると**すぐ息切れ** |
| 防衛力 | 病原体や危険から身を守る力（免疫など） | 弱まる → 感染しやすい |
| 適応力 | 暑さ寒さなど環境の変化に合わせる力 | 弱まる → 熱中症・低体温になりやすい |
| 回復力 | 病気やけがから元に戻る力 | 弱まる → 治るのに時間がかかる |

### 老化の学説

| 学説 | 中身 |
|---|---|
| **プログラム説** | **細胞分裂の回数はあらかじめ決まっている** |
| フリーラジカル説 | **活性酸素**が細胞を傷つける |
| エラー破局説 | DNA・たんぱく質合成の**誤りが蓄積** |
| 消耗説 | 使ううちにすり減る |
| 老化の免疫説 | 免疫機能の低下 |

## ② 老化によるからだの変化

| 器官 | ○ 老化の変化 | × |
|---|---|---|
| 免疫 | **免疫機能が低下** | 免疫機能が高まる |
| 皮膚 | 乾燥・弾力低下 | 皮脂が増える |
| 運動器 | **骨密度の低下**、筋力低下、関節の可動域が狭まる。筋肉量は中年期から少しずつ減り、**上肢より下肢**ではっきり減る | 骨密度は変わらない／高齢になると筋肉は増やせない |
| 循環器 | **不整脈が増える**、動脈硬化（末梢の血管抵抗が増え血流が悪くなる）、**収縮期血圧が上がる** | 心拍出量が増える／動脈が軟らかくなる／心臓が小さくなる（実際は左心室の壁が厚くなる）／安静時の脈拍数が増える（あまり変わらない。運動したときの最大の心拍数は下がる） |
| 見た目・神経 | 身長が縮む（椎間板が薄くなる・円背）、体重が減る、白髪・しわ・しみ。**平衡感覚**が衰え反応も遅くなり、**転びやすくなる** | — |
| 血液・呼吸 | **貧血になりやすい**、肺活量・肺の弾力が低下、残気量は増加 | 残気量が減る |
| 腎・泌尿器 | **尿の濃縮力が低下**（尿量が増えやすく夜間頻尿に）、薬が体に残りやすい。前立腺肥大は男性 | 膀胱容量が増える |
| 体温・反応 | 筋肉量・基礎代謝が落ちて**熱をつくりにくい**、暑さ寒さを感じにくい、**反応時間が長くなる** | 体温調節がうまくなる |
| 嚥下 | **喉頭の挙上が不十分**、咳反射が弱い、唾液が減る | 舌骨の位置が上がる |
| 睡眠 | **メラトニンが減る**、眠りが浅い、中途覚醒・**早朝覚醒**、寝つくまでの時間が長い | ノンレム睡眠の深い眠りが増える |

- 筋肉は、高齢になってからでも**筋力トレーニング**と**たんぱく質をとること**で、保つ・増やすことができます。加齢で筋肉量と筋力が落ちることを**サルコペニア**といいます
- **フレイル**：心身の活力が落ち、健康と要介護の間にある状態。適切に関われば健康な状態に戻れます。例：膝の痛みで散歩をやめ、食事量が減ってやせ、一日中座っている → フレイルが心配（判定のサインなどは → [リハビリテーションと廃用症候群・フレイル](../icf-02-rehabili/)）
- 用語：**残気量**＝息を吐き切っても肺に残る空気の量。**喉頭挙上**＝飲み込むときに「のどぼとけ」が上がる動き（足りないと気管のふたが閉じきらず、誤嚥しやすい）。**収縮期血圧**＝心臓が縮んで血液を送り出すときの血圧（上の血圧）

## ③ 感覚・認知機能の変化

### 感覚

<fig name="me">

<fig name="mimi">

- **眼のしくみ**：光は**角膜 → 瞳孔 → 水晶体 → 硝子体 → 網膜**と進む。**白内障＝水晶体が濁る**、**緑内障＝視神経が傷み視野が欠ける**、**加齢黄斑変性＝網膜の中心（黄斑）が傷み、真ん中がゆがむ・見えにくい**。
- **耳のしくみ**：音は**耳介 → 外耳道 → 鼓膜 → 耳小骨（中耳）→ 蝸牛（内耳）→ 脳**と伝わる。**伝音性難聴＝外耳・中耳**の障害（補聴器が効きやすい）、**感音性難聴＝内耳より奥**の障害で、老人性難聴はこちら。**三半規管・前庭**は体のバランス（平衡）を担う。

| 感覚 | ○ 老化の変化 | × |
|---|---|---|
| 視覚 | 近くが見えにくい（**老眼**）、**物の識別に必要な照度が高くなる**、**暗順応に時間がかかる**、視野が狭くなる。水晶体が黄色くにごるため、**青と黒・黄と白**の区別がつきにくい。赤系より**青系（青・紺・紫）**が見分けにくい | 周辺視野が広くなる／赤系の方が見分けにくい |
| 聴覚 | **感音性難聴**（耳の奥の蝸牛などの衰え）。**高音域から**聞こえにくい、**似た音の聞き分け**が難しい（「いちじ」と「しちじ」）。**補充現象**＝小さい音は聞こえにくいのに、大きい音は急に響いて割れる → 大声より**低めの声でゆっくり** | 低音から聞こえにくい |
| 味覚 | **感受性が低下**し、**濃い味を好む**。塩味の感受性も低下 | 甘味だけ敏感になる |
| 嗅覚・触覚 | 鈍くなる | 振動・においに敏感になる |

老人性難聴のサイン：後ろから声をかけても振り向かない、会話のつじつまが合わない、周りがうるさいと聞き取れない。

**明順応**は、暗い所から明るい所に出て、まぶしさに慣れること。**暗順応**は、明るい所から暗い所に入って、暗さに慣れること。どちらも加齢で遅くなりますが、もともと時間がかかるのは**暗順応**で、高齢者では特に目立ちます。

### 認知・記憶

- 記憶は「**感覚記憶**（目や耳に入った情報が一瞬だけ残る）→ **短期記憶** → **長期記憶**」の順に送られます
- 試験では「感覚記憶は低下しやすい」が×とされました（第29回）。目や耳が衰えて見えにくい・聞こえにくいことと、感覚記憶そのものの衰えは、分けて考えます

| 保たれやすい ○ | 低下しやすい |
|---|---|
| **手続き記憶**（自転車の乗り方など体で覚えたこと） | **エピソード記憶**（体験した出来事の記憶） |
| **意味記憶**（言葉の意味・知識・家族の名前などの事実） | **作業記憶（ワーキングメモリ）**＝情報を一時的に覚えながら同時に処理する力 |
| **結晶性知能**（経験・知識に基づく判断） | **流動性知能**（新しい場面に素早く対応） |
| **遠隔記憶**（昔のこと） | **近時記憶**（数分〜数日前のこと） |
| **短期記憶**（数十秒覚えておける量）は比較的保たれる | — |
| — | **選択的注意**（多くの情報から必要なものを選ぶ）・**展望的記憶**（「3時に薬を飲む」など、これからの予定を覚えておくこと） |

> 流動性知能は**20〜30歳代ごろをピーク**に、加齢とともに低下しやすい（動作性知能と対応づけて説明されることが多い）。結晶性知能は学校教育や社会経験の影響を受けて**60歳代ごろまで伸び**、その後もゆるやかにしか下がりません（言語性知能と対応づけて説明されることが多い）。「短期記憶（数十秒）」と「近時記憶（数分〜数日前）」は時間の長さがちがいます。また、短期記憶の**量**は保たれやすく、落ちやすいのは**覚えながら処理する作業記憶**です。試験では「ふだんかけない電話番号が覚えられない」を短期記憶の低下として正解にし（第26回）、「数字の逆唱は加齢の影響を受けない」は×でした（第32回）。記憶の分類は → [マズローの欲求・適応機制・記憶のしくみ](../kokoro-01-yokkyuu/)
