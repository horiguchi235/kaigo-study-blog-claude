## ③ 世帯・家族の機能・民法の親族

### 2つの「高齢者の世帯」

| 統計の言葉 | 中身 |
|---|---|
| **65歳以上の者のいる世帯** | 65歳以上の人が**1人でもいる**世帯（若い家族と同居していてもよい） |
| **高齢者世帯** | 65歳以上の人**だけ**、またはそれに18歳未満の未婚の子が加わった世帯 |

### 世帯（国民生活基礎調査）

| ○ | × |
|---|---|
| **核家族＝夫婦のみ・夫婦と未婚の子・ひとり親と未婚の子** | 三世代世帯も核家族 |
| 核家族の中で「**ひとり親と未婚の子**」が増加 | — |
| 世帯構造で最も多いのは**単独世帯**（34.6%）。平均世帯人員は**2.20人**（2024年） | 平均3人超 |
| 65歳以上の**単独世帯は女性が多い**（約6割が女性、2024年） | 男性が多い |
| 65歳以上の者のいる世帯で最も多いのは**単独世帯**（32.7%）。**夫婦のみ世帯**（31.8%）がほぼ並ぶ（2024年。2022年までは夫婦のみが最多） | 親と未婚の子のみの世帯 |
| 同居の主な介護者と要介護者が**ともに65歳以上が約6割**（63.5%、2022年）＝老老介護 | 約2割 |
| 高齢者世帯は全世帯の**約3割**（31.4%、2024年） | 5割以上 |
| 50歳時の未婚割合は**男性の方が高い** | 女性の方が高い |

### 家族と世帯

- **世帯**＝**住まいと家計をともにする**単位。単身赴任や進学で離れて暮らす人は「家族」だが「**同じ世帯**」ではない
- 家族の分類：**核家族**、**拡大家族**（直系家族・複合家族）。**定位家族**＝自分が生まれ育った家族／**生殖家族**＝自分が結婚してつくる家族

### 家族の機能

| 機能 | 中身 |
|---|---|
| 生命維持機能 | 食欲・性欲・安全の充足 |
| 生活維持機能 | 衣食住の生活水準を保つ |
| パーソナリティの形成機能 | 子どもの社会化 |
| パーソナリティの安定化機能 | くつろぎ・やすらぎ |
| **ケア機能** | **介護が必要な家族を支える** |

→ 家族機能の低下で、家族が担っていた介護を**社会で代わりに担う必要**が生じた（**介護の社会化**）。

### 民法の親族

- 親族＝**6親等内の血族、配偶者、3親等内の姻族**（姻族＝配偶者の血族と、血族の配偶者）
- **親等の数え方**：本人から見て、親・子が**1親等**、祖父母・孫・兄弟姉妹が**2親等**、おじ・おば・おい・めいが**3親等**、いとこが**4親等**。配偶者には親等がない
- **直系血族と同居の親族は互いに扶け合わなければならない**
- 扶養義務：直系血族と兄弟姉妹（いとこは×）。**3親等内の親族**は家庭裁判所が特別に扶養義務を負わせることがある
- 養子は**縁組の日から**養親の血族と親族関係になる
- **姻族関係は離婚で終わる**（死別のときは、残った配偶者の意思で終わらせられる）
