**この記事のポイント**

1. 年齢は「**65歳＝高齢者・介護保険第1号・虐待防止法**」「**40歳＝介護保険第2号**」「**75歳＝後期高齢者・免許更新の認知機能検査**」。
2. 日本の総人口は**2011年から減少**、**生産年齢人口も減少**。高齢化率は**21%超＝超高齢社会**（いまは約3割）。
3. 世帯は**2人世帯が最多**、**65歳以上の単独世帯は女性が多い**、同居の介護は**65歳以上どうしが約6割（老老介護）**。

## ① 高齢者の年齢の決まり・寿命【発達と老化の理解】

| 法律・用語 | 年齢 |
|---|---|
| 介護保険 第1号被保険者 | **65歳以上** |
| 介護保険 第2号被保険者 | **40〜64歳**（医療保険加入者） |
| 高齢者虐待防止法の高齢者 | **65歳以上** |
| 老人福祉法 | 原則**65歳以上**（60歳・70歳・55歳は×） |
| 前期高齢者 | **65〜74歳** |
| **後期高齢者**（後期高齢者医療制度） | **75歳以上** |
| 道路交通法 | **75歳以上**は免許更新時に**認知機能検査**。高齢運転者標識は**70歳以上**の努力義務 |
| 高年齢者雇用安定法 | 65歳までの雇用確保が義務、70歳までは努力義務 |
| 老齢年金 | 原則**65歳**から |
| 高齢化率の区分 | **7%＝高齢化社会、14%＝高齢社会、21%＝超高齢社会**（日本は1970・1994・2007年） |

> 35歳の人は老人福祉施設に入れない、50歳・70歳は第1号・第2号が逆、60歳は前期高齢者ではない。

## ③ 世帯・家族の機能・民法の親族【社会の理解／介護の基本】

### 世帯（国民生活基礎調査）

| ○ | × |
|---|---|
| **核家族＝夫婦のみ・夫婦と未婚の子・ひとり親と未婚の子** | — |
| 核家族の中で「**ひとり親と未婚の子**」が増加 | — |
| 世帯数で最も多いのは**2人世帯**。平均世帯人員は**約2.2人** | 3人超 |
| 65歳以上の**単独世帯は女性が多い** | 男性が多い |
| 65歳以上の者のいる世帯で最も多いのは**夫婦のみ世帯** | 親と未婚の子のみの世帯・単独世帯 |
| 同居の主な介護者と要介護者が**ともに65歳以上が約6割**（老老介護） | — |
| 高齢者世帯は全世帯の**約3割** | 5割以上 |
| 50歳時の未婚割合は**男性の方が高い** | 女性の方が高い |

### 家族の機能

| 機能 | 中身 |
|---|---|
| 生命維持機能 | 食欲・性欲・安全の充足 |
| 生活維持機能 | 衣食住の生活水準を保つ |
| パーソナリティの形成機能 | 子どもの社会化 |
| パーソナリティの安定化機能 | くつろぎ・やすらぎ |
| **ケア機能** | **介護が必要な家族を支える** |

→ 家族機能の低下で、家族が担っていた介護を**社会で代わりに担う必要**が生じた（**介護の社会化**）。

### 民法の親族

- 親族＝**6親等内の血族、配偶者、3親等内の姻族**
- **直系血族と同居の親族は互いに扶け合わなければならない**
- 扶養義務：直系血族と兄弟姉妹（いとこは×）。養子と養親は**親族関係が生じる**

## ＋α もう一歩：実務者研修レベルで覚えたいこと

過去問にはまだ出ていないけれど、実務者研修の確認テストでよく問われる、関連して覚えておきたい知識です。

- **家族の分類**：規模で＝大家族・小家族／構成で＝**核家族**（夫婦のみ・夫婦と子・ひとり親と子）・直系家族など。**定位家族**＝自分が生まれ育った家族／**生殖家族**＝自分が結婚してつくる家族。
- **民法の親族**＝6親等内の血族・配偶者・3親等内の姻族。**姻族関係は離婚で終わる**（死別のときは残った配偶者の意思で終わらせられる）。養子は**縁組の日から**養親の血族と親族関係になる。
- **地域社会**：**限界集落**＝65歳以上が**半数以上**で、共同生活の維持が難しい集落。村落的な生活＝住民の助け合い中心／都市的な生活＝専門機関への依存が強い。本家・分家のつながり＝**同族**、近所の横のつながり＝**組**。
- **高齢者の暮らしとお金**：高齢者世帯の所得は**公的年金が最も多い**。2018年調査では高齢者世帯の半数以上が「生活が苦しい」（大変苦しい22.0％＋やや苦しい33.1％）。**日本年金機構**は2010年発足。**シルバー人材センター**＝臨時的・短期的・軽易な仕事を紹介。**高年齢者雇用安定法**＝65歳までの雇用確保が義務、70歳までは努力義務。
