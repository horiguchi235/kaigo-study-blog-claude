**この記事のポイント**

1. 記録は**その日のうちに**、**客観的事実と主観的情報を区別**し、**ほかから得た情報は情報源も**書く。
2. 主観的情報＝**本人の発言や訴え**、客観的情報＝**観察・測定した事実**。「〜そうだった」「〜と思う」「〜はずだ」は職員の**推測**なので、事実と分けて書く。
3. **利用者（本人）は記録の開示（閲覧）を請求できる**。事例検討会では**氏名・住所を匿名化**。ヒヤリ・ハット報告書は**事故の予防**のために共有する。

## ① 介護記録の書き方

| ○ | × |
|---|---|
| 介護を実施した**その日のうちに**記録 | 数日後に書く |
| 記録は職場で書き、**職場の外に持ち出さない** | 自宅に持ち帰って書く |
| 訂正は**二重線を引いて訂正印**、元の文字が読めるように | 修正液・塗りつぶし |
| **客観的事実と主観的情報を区別**して書く | 区別しない |
| **ほかから得た情報は情報源も**書く（「長女より」など） | 誰から聞いたかを書かない |
| 事実を中心に書き、推測は推測とわかるように書く | 利用者の気持ちだけを推測して書く／介護職の意見を中心に書く |
| 利用者の言葉は「 」で**そのまま**、**時刻**も書く | 言葉を職員の言い方に要約する |
| **利用者本人は記録の開示を請求できる**（家族は本人の同意や代理人の場合） | 利用者は記録を見られない |
| 調査・研究や教育にも**活用できる**（匿名化など配慮して） | 研究目的の利用は避ける |
| 記録の様式は**事業所ごと**（法律で統一されていない） | 介護保険法で統一 |
| 食事チェック表・排泄チェック表も**記録に含まれる** | チェック表は記録ではない |

- **記録の目的**：ケアの質の向上、職員どうしの情報共有、**リスクマネジメント**（事故のときの証拠）、職員の教育、調査・研究など。
- **保存期間**：国の運営基準では、サービスの完結の日から**2年**（事故の記録・身体拘束の記録も含む）。条例で**5年**としている自治体も多い。

### 主観的情報・客観的情報・職員の推測

記録・介護過程・報告の問題では、次の3つを分けて考えます。

| 種類 | 中身 | 例 |
|---|---|---|
| **主観的情報** | 利用者**本人の発言や訴え**（本人が感じていること） | 「おなかが痛い」「家に帰ります」 |
| **客観的情報** | 職員が**観察・測定した事実** | パンを残した、体温37.8℃ |
| 職員の推測・解釈 | 事実から職員が考えたこと。記録では**事実と分けて**書く | 不安そうだった、帰宅願望がある |

本人の発言は「 」でそのまま書きます。発言の中身は本人の**主観的情報**ですが、「16時頃に〜と発言した」という出来事は、職員が聞いた**事実**として記録できます。記録の問題で×になるのは、職員の**推測・解釈**を事実のように書くことです（選択肢では「主観的に書く」と表現されることもあります）。

### 客観的事実はどれ？（文末で見分ける）

| 文末・書き方 | 分類 |
|---|---|
| 〜した／〜を残した／〜と発言した | 事実 |
| 体温・回数・量などの数値 | 事実 |
| 〜はずだ／〜と思う／〜そうだった／〜したそうだった | 職員の推測 |
| 〜が悪化し／〜が心配になって／〜願望があった | 職員の解釈 |

| ○ 客観的事実 | × 職員の推測・解釈 |
|---|---|
| 朝食のパンを残した | 楽しかったはずだ／不安だったと思う／退屈そうにしていた／何か言いたそうだった |
| **16時頃、「仕事は終わりました。家に帰ります」という発言があった** | 自宅が心配になって〜／認知症が悪化し〜／帰宅願望があったが問題はなかった |

### 記録の文体

| 文体 | 特徴 |
|---|---|
| **叙述体** | **起こったことをそのまま時間の順に**書く（解釈を入れない） |
| **要約体** | 要点を整理・要約して書く（項目別に整理） |
| **説明体** | 事実に**介護職の解釈・考察**を加えて書く |

### SOAPの記入例

SOAPは、情報を4つの欄に分けて書く記録の型です。

| 欄 | 中身 | 記入例 |
|---|---|---|
| S（主観的情報） | 本人の言葉 | 「おなかが張って苦しい」 |
| O（客観的情報） | 見た・測った事実 | 腹部が張っている。排便が3日ない。水分は1日800mL |
| A（アセスメント） | S・Oからの判断 | 水分不足による便秘の可能性 |
| P（計画） | これからの対応 | 水分を増やす。看護師に報告する |

## ② 情報管理とヒヤリ・ハット報告書

### ICT・個人情報

ICT（パソコンやタブレットなどの情報機器）で記録すると便利な反面、システム障害で記録が消える・情報が漏れる・ウイルスに感染する、といったリスクがあります。

| ○ | × |
|---|---|
| **ウイルス対策ソフトを使っても情報が漏れることはある** | 対策ソフトを入れれば漏れない |
| USBメモリは**紛失・盗難の危険が高い** | 危険性が低い |
| バックアップは**定期的に** | 気づいたときに |
| パスワードは推測されにくいものにし、**定期的に変更**、貼り出さない | 変更しない／使わない |
| データの修正は**記録者本人** | 誰でも修正できる |
| 閲覧できる人を限定する | 誰でも見られるようにする |
| 事例検討会では**利用者の氏名・住所を匿名化**、家族情報も匿名化 | 家族情報はそのまま |
| 音声・映像は**同意を得て**使う | 同意なしで使える |
| 記録類は使い終わったら片付ける | 記録類を机に広げておく |
| 外部に送るときは匿名化する | 匿名化せずに電子メールで送る |

### ヒヤリ・ハット報告書と事故報告書

**ヒヤリ・ハット**＝事故には至らなかったが、ヒヤリとした・ハッとした出来事のこと。

| | ヒヤリ・ハット報告書 | 事故報告書 |
|---|---|---|
| 対象 | 事故に至らなかった出来事 | 実際に起きた事故 |
| 目的 | 職員で共有し、**事故を予防**する | 状況を報告し、**原因を究明して再発を防ぐ** |
| 書き方 | 口頭で報告した内容も**書面に残す** | 日時・場所・経過・状態・対応を**客観的に**書く |
| 共通 | 報告者の責任追及が目的ではない。個人だけでなく手順・環境・組織の要因も考える | ← 同じ |

| ○ | × |
|---|---|
| ヒヤリ・ハット報告書を共有する目的は**事故の予防** | 情報公開・苦情対応のために共有する |
| ヒヤリ・ハットは**事故報告書とは分けて**記載 | 介護事故の状況をヒヤリ・ハット報告書に書く（それは事故報告書） |
| 口頭で報告した内容も**書面に残す** | 口頭なら記載不要 |
| 職員で**共有**して再発防止 | 報告者の責任追及／管理者以外は見られない |

小さなヒヤリ・ハットも報告するのは、**ハインリッヒの法則**（1件の重大事故の背後に29件の軽い事故、300件のヒヤリ・ハットがある＝**1：29：300**）があるからです。詳しくは[リスクマネジメント・事故対応・防災](../anzen-01-risk/)で扱います。
