**この記事のポイント**

1. 記録は**その日のうちに**、**客観的事実と主観的情報を区別**し、**ほかから得た情報は情報源も**書く。
2. 「〜そうだった」「〜と思う」「〜はずだ」は**主観**。「**パンを残した**」「**16時頃『家に帰ります』と発言**」が**客観的事実**。
3. **利用者・家族は記録の閲覧を請求できる**。事例検討会では**氏名・住所を匿名化**。ヒヤリ・ハットは**事故予防**のために共有。

## ① 介護記録の書き方

| ○ | × |
|---|---|
| 介護を実施した**その日のうちに**記録 | 数日後に書く／自宅に持ち帰って書く |
| 訂正は**二重線を引いて訂正印**、元の文字が読めるように | 修正液・塗りつぶし |
| **客観的事実と主観的情報を区別**して書く | 区別しない |
| **ほかから得た情報は情報源も**書く | 利用者の気持ちだけを推測して書く |
| 利用者の言葉は「 」で**そのまま**、**時刻**も書く | 介護職の意見を中心に |
| **利用者・家族は記録の閲覧を請求できる** | 閲覧できない |
| 調査・研究や教育にも**活用できる**（匿名化など配慮して） | 研究目的の利用は避ける |
| 記録の様式は**事業所ごと**（法律で統一されていない） | 介護保険法で統一 |
| 食事チェック表・排泄チェック表も**記録に含まれる** | チェック表は記録ではない |

### 客観的事実はどれ？

| ○ 客観的事実 | × 主観・解釈 |
|---|---|
| 朝食のパンを残した | 楽しかったはずだ／不安だったと思う／退屈そうにしていた／何か言いたそうだった |
| **16時頃、「仕事は終わりました。家に帰ります」という発言があった** | 自宅が心配になって〜／認知症が悪化し〜／帰宅願望があったが問題はなかった |

### 記録の文体

| 文体 | 特徴 |
|---|---|
| **叙述体** | **起こったことをそのまま時間の順に**書く（解釈を入れない） |
| 要約体 | 要点を**整理・要約**して書く（項目別に整理） |
| 説明体 | 事実に**介護職の解釈・考察**を加えて書く |

> SOAP（S＝主観的情報、O＝客観的情報、A＝アセスメント、P＝計画）もセットで押さえましょう。

## ② 情報管理とヒヤリ・ハット報告書

### ICT・個人情報

| ○ | × |
|---|---|
| **ウイルス対策ソフトを使っても情報が漏れることはある** | — |
| USBメモリは**紛失・盗難の危険が高い** | 危険性が低い |
| バックアップは**定期的に** | 気づいたときに |
| パスワードは**定期的に変更** | 変更しない／使わない |
| データの修正は**記録者本人** | 誰でも修正できる |
| 事例検討会では**利用者の氏名・住所を匿名化**、家族情報も匿名化 | 家族情報はそのまま |
| 音声・映像は**同意を得て**使う | 同意なしで使える |
| — | 匿名化せずメールで送る／記録類を机に広げておく |

### ヒヤリ・ハット報告書

| ○ | × |
|---|---|
| 共有の目的は**事故の予防** | 事故の分析・情報公開・苦情対応・管理者への報告 |
| **事故報告書とは分けて**記載 | 介護事故の状況を報告する（それは事故報告書） |
| 口頭で報告した内容も**書面に残す** | 口頭なら記載不要 |
| 職員で**共有**して再発防止 | 報告者の責任追及／管理者以外は見られない |

## ③ 記録の目的・ICTのリスク・ハインリッヒの法則

- **事故報告書の目的**＝**原因を究明し、再発を防ぐ**こと（責任追及ではない）。日時・場所・経過・状態・対応を**客観的に**書き、個人だけでなく手順・環境・組織の要因も分析する。
- 記録は**職場の外に持ち出さない**（自宅に持ち帰って書くのは×）。閲覧の権限・保管方法を守る。
- **記録の目的**：生活の質の向上・情報共有・**リスクマネジメント**（事故時の証拠）・職員の教育（スーパービジョン）・研究など。**介護記録は利用者・家族が閲覧できる**。
- 保存期間は国の基準で**2年**（事故の記録・身体拘束の記録も）。
- **ICTで記録するときのリスク**：システム障害で記録が消える・情報漏えい・ウイルス。対策＝**バックアップ**、パスワードは推測されにくく**定期的に変更し貼り出さない**、閲覧者を限定、USBメモリの紛失に注意、**記録を電子メールで送らない**。
- **ハインリッヒの法則**＝1件の重大事故の背後に29件の軽い事故、300件のヒヤリハット（**1：29：300**）。だから小さなヒヤリハットも報告する。
