## ① 発達理論【発達と老化の理解】

### エリクソンの発達段階（第28・29回）

| 段階（目安の年齢） | 発達課題 ○ | 失敗すると |
|---|---|---|
| 乳児期（0〜1歳） | **基本的信頼** | 不信 |
| 幼児前期（1〜3歳） | **自律性**（自分をコントロール） | 恥・疑惑 |
| 幼児後期（3〜6歳） | **自発性（主体性）** | 罪悪感 |
| 学童期（6〜12歳） | **勤勉性** | 劣等感 |
| 青年期（12〜20歳） | **同一性（アイデンティティ）** | 同一性の拡散 |
| 成人前期（20〜30歳） | **親密性** | 孤立 |
| 成人期（30〜60歳） | **生殖性（世代性）** | 停滞 |
| 老年期 | **統合** | 絶望 |

> 「1歳までに行動のコントロール」「12〜20歳で勤勉性」「30〜60歳で信頼感」はすべて段階がずれた×。

### ピアジェの認知発達（第27回）

| 段階 | 年齢 | 特徴 |
|---|---|---|
| 感覚運動期 | 0〜2歳 | 見る・触るで世界を知る。**対象の永続性** |
| **前操作期** | 2〜7歳 | **見立て遊び（積み木を飛行機に）**、自己中心性、見た目にとらわれ**保存ができない** |
| 具体的操作期 | 7〜11歳 | 具体物なら論理的に考えられる。**保存の概念**の獲得 |
| 形式的操作期 | 11歳〜 | 抽象的・仮説的に考えられる |

### ハヴィガースト・コールバーグ・スキャモン

| 理論 | 押さえる正解 |
|---|---|
| ハヴィガーストの**児童期** | **読み・書き・計算の基礎的技能**を発達させる（第25回） |
| ハヴィガーストの**中年期** | **市民的・社会的責任**を果たす（第38回）。配偶者の死への適応は老年期 |
| コールバーグの道徳性 | 最も高い段階＝**人間の権利や平等などの普遍的な倫理**に従う（第35回）。罰の回避・損得・多数意見・権威への服従は低い段階 |
| スキャモンの発育曲線 | **神経系**は乳幼児期に急速に発達、**生殖器系**は**12歳ごろから急速**に発達（第36回）。リンパ系は思春期に成人の約2倍 |

## ② 乳幼児の発達・愛着・社会的参照【発達と老化の理解】

| 時期 | 標準的な発達 |
|---|---|
| 生後3か月 | 体重が出生時の**約2倍**（第35回）。首がすわる |
| 生後6か月ごろ | 喃語、寝返り |
| 8か月ごろ | **人見知り** |
| 9か月〜1歳 | **指さし**、つかまり立ち |
| 1歳ごろ | 体重**約3倍**、**初語**、ひとり歩き |
| 1歳半ごろ | **語彙が急に増える（語彙爆発）** |
| 2歳ごろ | **二語文**（第34回） |

### 愛着と社会的参照

| 用語 | 試験の正解 |
|---|---|
| **社会的参照** | 見知らぬ人や状況で、**養育者の表情を見て**行動を決める（父の友人を見て父の顔を見る・視覚的断崖で母の表情を確かめる）（第32・35回） |
| ストレンジ・シチュエーション法の**安定型** | 養育者がいないと**不安**になり、**再会すると安心して再び遊ぶ**（第34回） |
| 回避型 | 分離しても泣かず、再会しても避ける |
| アンビバレント型 | 再会しても怒って抵抗し、なかなか落ち着かない |

エリクソンの発達段階説について、最も適切なものはどれ？

1. 誕生〜1歳ごろは、自分の行動をコントロールする力を身につける

4. 20〜30歳ごろは、自分らしさを身につける
5. 30〜60歳ごろは、社会や他者への信頼感をもつ

**正解：2**　1は幼児前期（自律性）、3は学童期、4は青年期（同一性）、5の信頼は乳児期の課題です。

## ③ 発達障害のある子ども【発達と老化の理解】

| 障害 | 特徴・対応 ○ |
|---|---|
| **学習障害（LD）** | 知的な遅れはないが、**読み書きなど特定の学習が困難**（字の左右が反転する・書き写しが苦手）（第33回） |
| **自閉症スペクトラム障害（ASD）** | 対人関係の難しさ、**同じ行動の繰り返し・こだわり**（第38回） |
| ASDの子への予定変更 | **前日に、理由とともに具体的に**伝える（台風で砂場が使えない など）（第36回） |
| ADHD | 不注意・多動・衝動性 |

> 「急な変更をその場で伝える」「こだわりをやめさせる」は×。見通しを持てるようにするのが基本です。

コールバーグの道徳性判断で、最も高い発達段階を示すものはどれ？

1. 権威に服従する
2. 罰を避ける
3. 多数意見を重視して判断する
4. 損得で判断する
5. 人間の権利や平等などの倫理に従って判断する

<details class="answer">
<summary>正解を見る</summary>

**正解：5**　罰の回避・損得は前慣習的水準、多数意見や権威への服従は慣習的水準、普遍的な倫理原則が最も高い脱慣習的水準です。
