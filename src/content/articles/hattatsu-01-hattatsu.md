## ① 発達理論

### エリクソンの発達段階

| 段階（目安の年齢） | 発達課題 ○ | 失敗すると |
|---|---|---|
| 乳児期（0〜1歳） | **基本的信頼** | 不信 |
| 幼児前期（1〜3歳） | **自律性**（自分をコントロール） | 恥・疑惑 |
| 幼児後期（3〜6歳） | **自発性（主体性）** | 罪悪感 |
| 学童期（6〜12歳） | **勤勉性** | 劣等感 |
| 青年期（12〜20歳） | **同一性（アイデンティティ）** | 同一性の拡散 |
| 成人前期（20〜30歳） | **親密性** | 孤立 |
| 成人期（30〜60歳） | **生殖性（世代性）**＝次の世代を育て支えること（子育て・後輩の指導） | 停滞 |
| 老年期 | **自我の統合**（自分の人生を受け入れる） | 絶望 |

> 「1歳までに行動のコントロール」「12〜20歳で勤勉性」「30〜60歳で信頼感」はすべて段階がずれた×。

### ピアジェの認知発達

| 段階 | 年齢 | 特徴 |
|---|---|---|
| 感覚運動期 | 0〜2歳 | 見る・触るで世界を知る。**対象の永続性**（布で隠したおもちゃも、見えないだけでそこにあるとわかる）を身につける |
| **前操作期** | 2〜7歳 | **見立て遊び（積み木を飛行機に）**。**自己中心性**（自分の見え方からしか考えられない）。見た目にとらわれ**保存ができない** |
| 具体的操作期 | 7〜11歳 | 具体物なら論理的に考えられる。**保存の概念**（細長いコップに水を移しても量は同じとわかる）の獲得 |
| 形式的操作期 | 11歳〜 | 抽象的・仮説的に考えられる |

### ハヴィガースト・コールバーグ・スキャモン・フロイト

| 理論 | 押さえる正解 |
|---|---|
| ハヴィガーストの**児童期** | **読み・書き・計算の基礎的技能**を発達させる |
| ハヴィガーストの**中年期** | **市民的・社会的責任**を果たす。配偶者の死への適応は老年期 |
| コールバーグの道徳性 | 最も高い段階＝**人間の権利や平等などの普遍的な倫理**に従う。罰の回避・損得・多数意見・権威への服従は低い段階 |
| スキャモンの発育曲線 | 4つの型。**神経型**（脳など）は乳幼児期に急速に発達、**生殖型**は**12歳ごろから急速**に発達、**リンパ型**は思春期に成人の約2倍、**一般型**（身長・体重・筋骨格・循環器など）は乳幼児期と思春期の2回大きく伸びる |
| フロイトの心理性的発達 | **口唇期→肛門期→男根期→潜在期→性器期**の5段階 |

### 発達の要因（遺伝か環境か）

| 学説 | 中身 |
|---|---|
| 成熟優位説（ゲゼル） | **遺伝**（成熟）が中心 |
| 学習説（ワトソン） | **環境**（学習）が中心 |
| 輻輳説（シュテルン） | 遺伝と環境の**足し算** |
| 相互作用説 | 遺伝と環境が**影響し合う**（今の主流） |
| 環境閾値説（ジェンセン） | 特性ごとに、環境の影響が現れる「しきい値」がちがう（相互作用説の1つ） |

## ② 乳幼児の発達・愛着・社会的参照

| 時期 | 標準的な発達 |
|---|---|
| 生後3か月 | 体重が出生時の**約2倍**。首がすわる |
| 生後6か月ごろ | 喃語（「バブバブ」など意味のない声）、寝返り |
| 8か月ごろ | **人見知り**、ハイハイ（8〜9か月ごろ） |
| 9か月〜1歳 | **指さし**、つかまり立ち |
| 1歳ごろ | 体重**約3倍**（身長は約1.5倍）、**初語**（一語文）、ひとり歩き |
| 1歳半ごろ | **語彙が急に増える（語彙爆発）** |
| 2歳ごろ | **二語文**（「ママ、きた」） |
| 2〜3歳ごろ | **第一反抗期**（イヤイヤ期）。第二反抗期は思春期 |

- **原始反射**＝生まれつき備わり、成長とともに消えていく反射（大きな音などで両手を広げて抱きつくような動きをする**モロー反射**、口に触れたものに吸いつく吸啜反射など）

### 愛着と社会的参照

| 用語 | 試験の正解 |
|---|---|
| **社会的参照** | 見知らぬ人や状況で、**養育者の表情を見て**行動を決める（父の友人を見て父の顔を見る・視覚的断崖で母の表情を確かめる） |
| ストレンジ・シチュエーション法の**安定型** | 養育者がいないと**不安**になり、**再会すると安心して再び遊ぶ** |
| 回避型 | 分離しても泣かず、再会しても避ける |
| アンビバレント型 | 再会しても怒って抵抗し、なかなか落ち着かない |

## ③ 発達障害のある子ども

| 障害 | 特徴・対応 ○ |
|---|---|
| **学習障害（LD）**（今の診断名は限局性学習症） | 知的な遅れはないが、**読む・書く・計算など特定の学習が困難**（字の左右が反転する・書き写しが苦手。読みの困難＝ディスレクシア）。非言語性LDは図形・空間の理解や動作でつまずきやすい |
| <strong>自閉スペクトラム症（ASD）</strong>（旧：自閉症スペクトラム障害・広汎性発達障害） | 対人関係・コミュニケーションの難しさ、**同じ行動の繰り返し・こだわり** |
| ASDの子への予定変更 | **前日に、理由とともに具体的に**伝える（台風で砂場が使えない など） |
| ADHD（注意欠如・多動症） | 不注意・多動・衝動性 |

> 「急な変更をその場で伝える」「こだわりをやめさせる」は×。見通しを持てるようにするのが基本です。過去問では「自閉症スペクトラム障害」「広汎性発達障害」の名前でも出ます。
