**この記事のポイント**

1. 車いすで「**下る**」ときは**後ろ向き**（段差も急な坂も）。段差を上がるときは**前輪を上げる**。
2. 視覚障害者の誘導は「**肘の少し上を握ってもらい、半歩前を歩く**」。狭い道は**介護者が前**、階段は**手前で止まって声かけ**。
3. パーキンソン病は**小刻み歩行・すくみ足** → **一度足を引いてから**歩き出す。

## ① 車いすの介助【生活支援技術】

<photo name="idou-03__kurumaisu" caption="標準型の車いす。大きな後輪の外側の輪＝**ハンドリム**（自分でこぐ）、後ろ下に突き出た棒＝**ティッピングレバー**（段差で前輪を上げるとき踏む）、足をのせる板＝**フットサポート**、ひじ置き＝**アームサポート**、後輪の横のレバー＝**ブレーキ**。">

| 場面 | ○ 正解 | × よく出る不正解 |
|---|---|---|
| 出発前 | 足が**フットサポートにのっているか確認** | — |
| 段差を上がる | ティッピングレバーを踏んで**前輪を上げ**、段にのせてから後輪を押し上げる | キャスターを斜めに向ける |
| **段差を下りる** | **後ろ向きで後輪から** | 前輪から下りる |
| 急な上り坂 | 押し戻されないよう、**ゆっくり**しっかり押す | すばやく進む |
| **急な下り坂** | **後ろ向き**で進む | 前向きで進む |
| 砂利道 | **前輪を上げて**進む | 後輪を持ち上げる |
| **踏切** | **前輪を上げ、駆動輪でレールを越える** | 駆動輪を上げる |
| エレベーター | **正面からまっすぐ**入る | — |
| 速さ | 歩くより**ゆっくり** | 歩行速度より速く |

### 外出・散歩

- 施設から車いすで外出するときに最優先：**外出先の経路情報を集める**（段差・トイレ・エレベーター）
- 散歩中は**顔色や表情を確認**する。行き先は本人と決め、靴も用意する

### 脊髄損傷のレベルと車いす

**第6胸髄（Th6）損傷**：上肢は使えるが体幹の支えが弱い → **腰部までのバックサポート**の車いすで自分でこげる。ヘッドサポートやハンドリムのない車いすは、もっと高い位置（頸髄）の損傷向けです。

## ② 視覚障害者の歩行誘導【生活支援技術】

<photo name="idou-03__hakujo-tenji" caption="黄色い点字ブロック。細長い線の**線状ブロック＝進む方向**、丸い点の**点状ブロック＝止まる・注意する位置**。白杖には視覚障害があることを**周囲に知らせる**役目もあります。">

| 場面 | ○ 正解 | × よく出る不正解 |
|---|---|---|
| 基本の姿勢 | 介護者の**肘の少し上**を握ってもらい、**半歩前**を歩く | 利用者の手首を握る／後ろから背中を支える／白杖に触れる |
| **狭い通路** | **介護者が前**、利用者は後ろに一列（握った腕を背中側へ） | 後ろから誘導する |
| **階段** | **階段の手前でいったん止まり**、上りか下りかを伝える | 手首を握って誘導 |
| バス・電車 | **介護者が先に**乗る | — |
| タクシー | **利用者が先に**乗る | 支援者が先に乗る |
| エスカレーター | 介護者が**先に**降りる。可能なら**エレベーター**を使う | 介護者が後から降りる／エスカレーターを勧める |
| 駅のホームで待つ | 点字ブロックより**内側（線路から離れた安全な場所）** | 点字ブロックの上で待つ |
| 一時離れる | **柱や壁に触れられる位置**まで誘導する | その場に立たせて離れる |
| トイレ | **トイレ内の情報**（便器・紙・水洗の位置）を伝える | — |
| 雨の日 | 周囲の音が聞こえるよう、フードは避ける | フードつきレインコート |

<details>
<summary>✏️ 解いてみよう（第38回）</summary>

視覚障害者の歩行誘導として、最も適切なものはどれ？

1. 利用者の半歩後ろで背中を支えながら歩く
2. 白杖に触れながら歩く
3. 狭い通路では、利用者の後ろを歩く
4. 階段では、階段の前で声をかけて止まる
5. 利用者が握っている腕を振って歩く

<details class="answer">
<summary>正解を見る</summary>

**正解：4**　段差の手前で止まり、上りか下りかを伝えてから進みます。介護者はいつも半歩前、狭い通路でも前です。白杖は利用者の目の代わりなので触れません。

## ③ 疾患別の歩行と転倒予防の環境【こころとからだのしくみ／生活支援技術】

| 病気 | 歩き方 | 介助・環境 |
|---|---|---|
| **パーキンソン病** | **小刻み歩行**・**すくみ足**・突進 | **一度足を引いてから**歩き出す。曲がり角は勢いをつけず大きく回る |
| **脊髄小脳変性症** | **失調性歩行**（ふらふら・酔ったよう） | **よく通る場所に手すり**。弾力の強い床・キャスター付きいす・頭上の収納は× |
| 脊柱管狭窄症 | **間欠性跛行**（歩くと痛み、休むと回復） | — |
| 変形性膝関節症 | 膝の痛みでかばって歩く | — |

### 手すり・階段

- 片麻痺の人が洋式便器から立つ縦手すり：便器の先端から**20〜30cm前方**、**健側の壁**
- 高齢者の階段：**手すりを設置**。一段を低く、足をのせる板は奥行きを広く、**全体を明るく**する。毛の長いじゅうたんは×
