**この記事のポイント**

1. 車いすで「**下る**」ときは**後ろ向き**（段差も急な坂も）。段差を上がるときは**前輪を上げる**。
2. 視覚障害者の誘導は「**肘の少し上を握ってもらい、半歩前を歩く**」。狭い道は**介護者が前**、階段は**手前で止まって声かけ**。
3. パーキンソン病は**小刻み歩行・すくみ足** → **一度足を引いてから**歩き出す。

## ① 車いすの介助

<photo name="idou-03__kurumaisu" caption="標準型の車いす。大きな後輪の外側の輪＝**ハンドリム**（自分でこぐ）、後ろ下に突き出た棒＝**ティッピングレバー**（段差で前輪＝**キャスター**を上げるとき踏む）、背もたれ＝**バックサポート**、足をのせる板＝**フットサポート**、ひじ置き＝**アームサポート**、後輪の横のレバー＝**ブレーキ**。">

車いすの各部の名前：大きな後輪の外側の輪＝**ハンドリム**（自分でこぐ）、後ろ下に突き出た棒＝**ティッピングレバー**（段差で前輪＝**キャスター**を上げるときに踏む）、背もたれ＝**バックサポート**、足をのせる板＝**フットサポート**、ひじ置き＝**アームサポート**、後輪の横のレバー＝**ブレーキ**。すねを支える部分＝レッグサポート、グリップの近くのブレーキ＝介助用ブレーキです。

出発前に**タイヤの空気・ブレーキ**を点検し、足が**フットサポートにのっているか確認**します。バックサポートまで深く座れているかも確かめます。動かす前には**必ず声をかけます**。

#### 段差・坂道

| 場面 | ○ 正解 | × よく出る不正解 |
|---|---|---|
| 段差を上がる | ティッピングレバーを踏んで**前輪（キャスター）を上げ**て進み、**後輪（駆動輪）が段に当たってから**前輪をそっと下ろし、後輪を押し上げる | キャスターを斜めに向ける／後輪が段に当たる前に前輪を下ろす |
| **段差を下りる** | **後ろ向きで後輪から**（前向きだと利用者が前に投げ出される） | 前輪から下りる |
| 急な上り坂 | 押し戻されないよう、足を開いて**ゆっくり**しっかり押す | すばやく進む |
| **急な下り坂** | **後ろ向き**で、グリップを握ってゆっくり進む | 前向きで進む |

#### 踏切・砂利道・エレベーター

| 場面 | ○ 正解 | × よく出る不正解 |
|---|---|---|
| 砂利道 | **前輪を上げて**進む（小さな前輪は石にとられやすい） | 後輪を持ち上げる |
| **踏切** | **前輪を上げ、駆動輪（後輪）でレールを越える**（前輪が溝にはまらないように） | 駆動輪を上げる |
| エレベーター | **正面からまっすぐ**入る（溝に前輪がはまらないように）。中で向きを変えられないときは、正面から入って後ろ向きで出る。昇降中はブレーキをかける | — |
| 速さ | 歩くより**ゆっくり**。急な方向転換はしない | 歩行速度より速く |

### 車いすの種類と座り方の調整

| 種類 | 特徴・向いている人 |
|---|---|
| 自走用（普通型） | 大きな後輪のハンドリムを自分でこぐ |
| 介助用 | 後輪が小さく、ハンドリムがない。介護者が押す |
| 電動 | 腕の力が弱く、自分でこぐのが難しい人 |
| **リクライニング式** | 背もたれを後ろに倒せる |
| **ティルト式** | 背もたれと座面の角度を保ったまま、**いす全体を後ろに傾ける**。体幹を支えられない人、不随意運動や筋肉の緊張が強い人（アテトーゼ型脳性麻痺など）の**姿勢を保つ・休む**のに向く。両方の機能をもつ**リクライニング・ティルト式**もある |

- **進行性の病気**（筋ジストロフィーなど）の人：残っている筋力を使いながら、行動範囲を保てる手段を選びます。歩くことにこだわると行動範囲が狭くなり、早すぎる電動化は筋力を使う機会を減らします。今は自分でこぐ車いすを使い、次の手段へいつ切り替えるかを医師やリハビリ職と確認しておきます
- **片麻痺の人が麻痺側へ傾く**とき：まず深く座り直してもらい、**麻痺側の腕とアームサポートの間にクッション**を入れて腕の重さを支えます（腕の重みで肩が下がり、体が傾くのを防ぐ）

### 外出・散歩

- 施設から車いすで外出するときに最優先：**外出先の経路情報を集める**（段差・トイレ・エレベーター）
- 散歩中は**顔色や表情を確認**する。行き先は本人と決め、靴も用意する

### 片麻痺の人の車いす自走

**健側の手でハンドリムを回し、健側の足で床をけって**方向を調整します。足が床に届くよう、座面の低い車いすを選びます。

### 脊髄損傷のレベルと車いす

脊髄は背骨の中を通る神経の束で、首＝**頸髄**（C）、胸＝**胸髄**（Th）、腰＝**腰髄**（L）と分かれます。**損傷の位置が高いほど、動かせない範囲が広く**なります。

| 損傷の高さ | 残る主な機能 | 車いすの例 |
|---|---|---|
| 頸髄（首） | 腕や手も動かしにくい。高い位置では呼吸にも影響 | ヘッドサポート付きのリクライニング型、電動車いす |
| 胸髄（胸） | 腕は使える。高い位置ほど体幹（腹や背中）の支えが弱い | 自分でこげる標準型 |
| 腰髄（腰） | 腕と体幹は使える。脚の一部が動くこともある | 自分でこげる。装具や杖で歩ける人もいる |

**第6胸髄（Th6）損傷**：腕は使えるが、腹筋・背筋の一部が働かず体幹が不安定 → **腰部までのバックサポート**の車いすで自分でこげる（背もたれが高すぎると腕をこぐ動きのじゃまになる）。ヘッドサポートやハンドリムのない車いすは、もっと高い位置（頸髄）の損傷向けです。

**胸髄損傷の人の生活**：腕と手は使えるので、スプーンを手に固定する自助具やボタンエイドはふつう必要なく、リクライニング式の車いすもいりません（これらは頸髄損傷向け）。自分でお尻を浮かせて圧を逃がす（**プッシュアップ**）こともできます。一方で、排尿・排便の感覚や調整に障害が残るため、**外出前に多機能トイレの場所を確認しておく**ことが大切な準備です。また、不全麻痺の訓練で片足に体重をかけられるようになったばかりの段階では、**その足の膝折れ**に注意して見守ります。

## ② 視覚障害者の歩行誘導

<photo name="idou-03__hakujo-tenji" caption="黄色い点字ブロック。細長い線の**線状ブロック＝進む方向**、丸い点の**点状ブロック＝止まる・注意する位置**。白杖には視覚障害があることを**周囲に知らせる**役目もあります。">

**点字ブロック**は黄色いブロックで、細長い線の**線状ブロック＝進む方向**、丸い点の**点状ブロック＝止まる・注意する位置**を示します。**白杖**には、道を確かめるだけでなく、視覚障害があることを**周囲に知らせる**役目もあります。

| 場面 | ○ 正解 | × よく出る不正解 |
|---|---|---|
| 基本の姿勢 | 介護者の**肘の少し上**を握ってもらい、**半歩前**を歩く | 利用者の手首を握る／後ろから背中を支える／白杖に触れる |
| **狭い通路** | **介護者が前**、利用者は後ろに一列（握った腕を背中側へ） | 後ろから誘導する |
| **階段** | **階段の手前でいったん止まり**、上りか下りかを伝える | 手首を握って誘導 |
| バス・電車 | **介護者が先に**乗り、**先に**降りる（段差や足場を先に確かめる）。電車では介護者が片足を車内に入れてから誘導し、ホームとのすき間に注意 | — |
| タクシー | **利用者が先に**乗る（奥へ詰めてもらう） | 支援者が先に乗る |
| エスカレーター | 幅に余裕があれば**並んで同時に**乗り降りする。幅が狭いときは介護者が**先に**降りる。可能なら**エレベーター**を使う | 介護者が後から降りる／エスカレーターを勧める |
| 駅のホームで待つ | 点字ブロックより**内側（線路から離れた安全な場所）** | 点字ブロックの上で待つ |
| 一時離れる | **柱や壁に触れられる位置**まで誘導する | その場に立たせて離れる |
| トイレ | **トイレ内の情報**（便器・紙・水洗の位置）を伝える | — |
| 雨の日 | 周囲の音が聞こえるよう、フードは避ける | フードつきレインコート |

「どちらが先？」を乗り物ごとにまとめると次のとおりです。

| 乗り物 | 乗るとき | 降りるとき |
|---|---|---|
| バス・電車 | 介護者が先 | 介護者が先 |
| タクシー（自動車） | **利用者が先** | 介護者が先 |
| エスカレーター | 並んで同時（狭ければ介護者が先） | 並んで同時（狭ければ介護者が先） |

## ③ 疾患別の歩行と転倒予防の環境

### なぜ転ぶのか

| 原因 | 例 |
|---|---|
| からだ | 筋力・バランス・すばやさの低下、白内障などの視力低下、認知症、関節の病気 |
| 環境 | 段差・床の障害物 |
| 薬 | 睡眠薬など |

- **円背**の人は重心が前に移り、膝を曲げて歩くので、つま先が上がらずつまずきやすくなります
- **片麻痺**の人は、麻痺側の足を外へ回すように振り出して歩きます
- 視野が狭いと段差に気づきにくく、加齢による難聴（高い音から聞こえにくくなる）では車や自転車の音に気づきにくくなります
- 夜間頻尿で、目が覚めきらないまま歩くと転びやすくなります。心臓や肺の病気では少し動いただけで疲れます
- 移動する意欲が下がる背景には、認知症、脳卒中などの障害、環境の変化、身近な人の死などがあります

| 病気 | 歩き方 | 介助・環境 |
|---|---|---|
| **パーキンソン病** | **小刻み歩行**・**すくみ足**・突進 | **一度足を引いてから**歩き出す。床にテープで線を引いてまたいでもらう、「いち、に」と号令をかけるなど、目印やリズムで足が出やすくなる。曲がり角は勢いをつけず大きく回る |
| **脊髄小脳変性症** | **失調性歩行**（バランスがとれず、ふらふらと酔ったような歩き方） | **よく通る場所に手すり**。弾力の強い床（足元が沈んでよけいにふらつく）・キャスター付きいす（動いてしまう）・頭上の収納（見上げてふらつく）は× |
| 腰部脊柱管狭窄症 | **間欠性跛行**（歩くと脚が痛み・しびれ、休むと回復） | **前かがみで楽になる**ので、シルバーカーを押す・途中で休憩をはさむ |
| 変形性膝関節症 | 膝の痛みでかばって歩く | 膝に負担をかけない（正座を避けていすの生活に、体重管理）。杖は痛む膝と反対の手に持つ |

- 間欠性跛行の原因には、神経が圧迫される腰部脊柱管狭窄症（前かがみで楽になる）と、脚の血管が狭くなる閉塞性動脈硬化症（姿勢に関係なく休むと楽になる）があります

### 手すり・階段

- 片麻痺の人が洋式便器から立つ縦手すり：便器の先端から**20〜30cm前方**、**健側の壁**
- 高齢者の階段：**手すりを設置**（両側が望ましい。片側だけなら**下りるときの利き手側**）。一段を低く、足をのせる板は奥行きを広く、**全体を明るく**する。毛の長いじゅうたんは×
