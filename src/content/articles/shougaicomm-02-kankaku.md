**この記事のポイント**

1. **中途失聴者＝筆談**（手話は習得が難しい）。筆談は**キーワード**で短く。
2. 老人性難聴は**高音域から**。**正面で向き合い、口元を見てもらい**、大声は逆効果。箱型補聴器のイヤホンは**比較的聞こえる側の耳**に。
3. 視覚障害者には**聴覚・触覚・嗅覚**を活用し、**見えている情報を整理して言葉で**。会話の相手は**名前を呼んで**示す。盲ろう者には**触手話**。

## ① 聴覚障害の人とのコミュニケーション

### 手段の選び方

聞こえの障害は、いつ・どの程度聞こえなくなったかで、使いやすい手段が違います。

- **ろう者**：生まれつき、または言葉を覚える前に聞こえなくなった人。**手話**が第一言語のことが多い
- **中途失聴者**：言葉を覚えたあとに聞こえなくなった人。話すことはできるが、手話を習得していないことが多い → **筆談・要約筆記**（話の内容を要約して文字で伝える）
- **難聴者**：聞こえにくいが、ある程度は聞こえる人 → 補聴器・話し方の工夫

| 対象 | ○ 手段 |
|---|---|
| **高齢になってからの中途失聴者** | **筆談**（手話・指文字は習得が難しい） |
| 補聴器を使ったことのない難聴の人で、話すことは得意 | **本人は話し、職員は筆談と発語を併用** |
| 筆談のコツ | **キーワードを活用**、短く簡潔に（長文・漢字だけ・細かく丁寧に書くのは×） |

そのほかの手段：手話・**指文字**（五十音を指の形で表す。固有名詞に）・**読話**（口の動きを読む）・**空書**（空中に文字を書く）・音声認識アプリ。

### 老人性難聴

| ○ | × |
|---|---|
| **高音域から**聞こえにくくなる（感音性） | 低音域から |
| 話し手の**口元に注目**してもらう | — |
| **正面で向き合って**話しかける | 耳元で大声／高い声で話す |
| 低めの声で、**ゆっくり・はっきり** | 体に触れてから話す（驚かせることも） |
| 補聴器は**静かな場所**で効果的 | 騒がしい場所でも同じように聞こえる |

- **難聴の種類**：**伝音性難聴**（外耳・中耳の障害）は音を大きくすれば聞こえやすく、**補聴器が効きやすい**。**感音性難聴**（内耳より奥の障害）は**音を大きくしても聞き分けにくい**。老人性難聴は主に感音性です。
- <strong>なぜ大声は×？</strong>　大声を出すと声が高く、音も割れやすくなり、高い音から聞こえにくい老人性難聴の人にはかえって聞き取りにくくなります。だから「**低めの声でゆっくり・はっきり**」。コミュニケーション①の「大きな声でゆっくり（準言語）」は、聞き取りにくそうな人一般への話し方として出た問題です。

### 補聴器

<photo name="shougaicomm-02__hochouki" caption="補聴器。左から**耳かけ型**、**耳あな型**、**箱型**（ポケット型）。箱型はイヤホンを**よく聞こえる側の耳**につけ、本体のマイクに向かって話します。">

**箱型補聴器のイヤホン**は**比較的聞こえる側の耳**に装着し、マイク（本体）に向かって話す。耳かけ型・耳あな型は、両耳につける人もいます（第35回のCさんは両耳）。

## ② 視覚障害・盲ろうの人とのコミュニケーション

| ○ | × |
|---|---|
| **聴覚・触覚・嗅覚を活用**する | — |
| 視覚情報は**整理して口頭で伝える** | 「あれ」「そこ」など指示語 |
| 声をかけるときは**名前を名乗ってから** | 黙って体に触れる |
| 方向は「**右へ**」など具体的に、物の位置は時計の文字盤にたとえる（**クロックポジション**：「3時の方向にお茶」） | 「こちらに」と言う |
| **白杖には、視覚障害があることを周囲に知らせる役目もある** | — |

- 外出の支援には、障害福祉サービスの**同行援護**（**ガイドヘルパー**が外出に同行し、移動の援護や代読・代筆をする）が使えます。
- <strong>ロービジョン（弱視）</strong>＝見えにくいが、視覚情報がまったくないわけではない状態。補助具：拡大鏡・**拡大読書器**・弱視眼鏡・スマートフォンの音声読み上げ。照明や文字の大きさを本人の見え方に合わせる。

### 場面で覚える

| 場面 | ○ 正解 |
|---|---|
| 暗い廊下で声をかけたら「びっくりした。見えにくくて…」 | 「**驚かせてしまいましたね。一緒に歩きましょうか**」（受容） |
| 糖尿病性網膜症で右目失明、左目かすかに見える | **視覚情報を整理して口頭で** |
| **中途失明**の人が、同じテーブルの人どうしの会話を自分への話しかけと思って答え、下を向いてしまった | 同じテーブルの人に「**相手の名前を呼んでから話しかけて**」と頼む（見えないと、誰に話しているかがわからない） |
| **先天性の全盲**で入居したばかりの人が「場所を覚えられない。ここでやっていけるか」 | **トイレや食堂を一緒に歩いて確かめる** |

### 視覚障害の病気

| 病気 | 初期症状など |
|---|---|
| **網膜色素変性症** | **夜盲**（暗いところで見えにくい）→ 視野が狭くなる |
| 緑内障 | 視野が欠ける・狭くなる |
| 糖尿病性網膜症 | 網膜の出血、中途失明の原因に |
| **白内障** | 水晶体がにごり、かすんで見える。**強い日差しのなかでまぶしく**見えにくい（光が散乱する） |
| 加齢黄斑変性 | 視野の**中心**が見えにくい・ゆがんで見える |

### 盲ろう

**盲ろう**＝視覚と聴覚の両方に障害がある状態。もともと**聴覚障害で手話を使っていた人**が緑内障で明暗がわかる程度の視力に → **触手話**（相手の手話に触れて読み取る）。ほかに**指点字**（両手の人さし指・中指・薬指の6本を点字の6つの点に見立て、相手の指を軽くたたく）・**手書き文字**（手のひらに文字を書く）。どの手段を使うかは、障害を受けた順番やそれまで使っていた言語で決まります。
