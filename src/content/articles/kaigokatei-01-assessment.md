**この記事のポイント**

1. 介護過程の目的は「**利用者の望む生活の実現**」。正解の言い回しは毎年少しずつ変わるが、中身は同じ。主語が利用者の選択肢を選ぶ。
2. アセスメントのゴールは「**生活課題を明らかにする**」こと。情報は**多角的に、他職種からも**集め、「**生命の安全・生活の安定・人生の豊かさ**」の3つの視点で解釈する。
3. 主観的情報＝**本人の発言や訴え**、客観的情報＝**観察・測定した事実**。介護福祉職の推測や解釈はどちらにも混ぜず、分けて書く。

## ① 介護過程の目的

介護過程は「アセスメント → 計画 → 実施 → 評価」をくり返す、**根拠のある個別ケア**のための考え方です。中心にあるのは、いつも「利用者の望む生活」です。

```
アセスメント（情報収集 → 解釈・関連づけ → 生活課題の明確化）
      ↓
介護計画の立案（目標 → 支援内容）　… 介護過程②
      ↓
実施　… 介護過程③
      ↓
評価　… 介護過程③ →（必要なら再アセスメントへ戻り、くり返す）
```

「目的として最も適切なもの」は**11問**出ています。正解は、どれも同じことを言い換えたものです。

| ○ 正解になる言葉 | × 不正解になる言葉 |
|---|---|
| 利用者の望む、よりよい生活の実現 | 介護福祉職が望む生活／**家族が望む**生活 |
| 自立支援・自己実現 | 業務効率の優先 |
| 生活の質（QOL）の向上 | 画一的な介護 |
| 根拠のある個別ケア | 経験則・直感に基づく介護 |
| 利用者主体のケア | ケアプランを作成する（介護支援専門員の仕事） |
| 利用者の自立を支える | 他職種との連携の促進／医師と連携する（連携は手段で、目的ではない） |

**よく出る一言**：主語が「**利用者**」になっている選択肢を選びます。「介護福祉職の」「家族の」「業務の」が主語なら、ほぼ×です。チームでの連携は、介護過程を行うことで**できるようになること（手段・結果）**で、目的として問われたら×になります。

## ② アセスメントと情報収集の原則

アセスメントとは、**情報を集め、解釈し、関連づけて、生活課題を明らかにする**ことです。

| ○ 正しい情報収集 | × よく出る不正解 |
|---|---|
| **多角的・継続的**に集める | 1つの場面・1つの情報だけで判断する |
| **五感**を使って観察する | 先入観をもって見る |
| **他職種の情報**も活用する | 他職種の記録は使わない |
| 「**できること**」「**やりたいこと**」も集める | 困っていることだけを集める |
| 本人の**生活への思い**を大切にする | 家族の要望を中心に聴く |
| 会話は**そのまま**記録する | 会話は解釈して記録する |
| **介護福祉の知識**を使って解釈する | 介護福祉職の主観で解釈する |
| 初回面談では**目的を意識して**聴く | 用意した質問を次々にする／最初に経済状況を聞く |

### 直接的情報と間接的情報

| 種類 | 中身 | 例 |
|---|---|---|
| **直接的情報** | 介護福祉職が**本人から直接**得た情報 | 本人との会話、観察した様子 |
| **間接的情報** | **家族・他職種・記録**などを通して得た情報 | 家族の話、看護記録、ケアプラン |

他職種の記録は「間接的情報」です（第34回で「直接的な情報として扱う」が×）。

### 情報を解釈するときの3つの視点

集めた情報は、次の3つの視点で解釈・関連づけます。生活課題の**優先順位**（介護過程②）や、事例問題の型2（介護過程④）でも同じ考え方を使います。

| 視点 | 見るところ |
|---|---|
| **生命の安全** | 健康が悪化しそう・命や安全が脅かされそうな点 |
| **生活の安定** | 自立できていない・これまでの生活を続けられていない点 |
| **人生の豊かさ** | その人らしく、楽しみや役割をもって暮らせていない点 |

### 例：情報から生活課題まで

| 段階 | 例（80歳の女性） |
|---|---|
| 情報 | 「また畑に出たい」と話す（本人の言葉）。膝の痛みで歩く距離が短くなった。最近は居室で過ごす時間が増えた |
| 解釈 | 歩く機会が減ると筋力が落ち、さらに歩けなくなるおそれがある（生活の安定）。畑仕事はこの人の楽しみ（人生の豊かさ） |
| 関連づけ | 膝の痛み → 歩かない → 筋力低下 → 畑に出られない、がつながっている |
| 生活課題 | 痛みに配慮しながら歩く力を保ち、畑に出る楽しみを続けられること |

### ICFで情報を整理する

アセスメントでは、情報を<strong>ICF（国際生活機能分類）</strong>の枠組みで整理する問題も出ます。

| 構成要素 | 事例での例 |
|---|---|
| 心身機能・身体構造 | 片麻痺、人工肛門、物忘れ |
| 活動 | 日常の動作。**できる活動（能力）**＝訓練などの場面でできること（例：車いすから便座へ移乗できる）と、**している活動（実行状況）**＝ふだんの生活で実際にしていること、を分けてとらえる |
| 参加 | 趣味の会、仕事、地域の役割 |
| 環境因子 | **家族の状況**（例：娘の仕事が忙しくなった）、住まい、福祉用具 |
| 個人因子 | 年齢、性別、生活歴、性格 |

ICFそのものの詳しい説明は[ICF（国際生活機能分類）の見分け方](../icf-01-icf/)でまとめます。

### 状態をみる指標（寝たきり度）

事例文には「障害高齢者の日常生活自立度（寝たきり度）A」のように、状態を表す指標が出てきます。アセスメントで、移動や外出の自立度をつかむ目安になります。

<fig name="jiritsudo">

寝たきり度は、軽い順に次の4ランクです。

- **J（生活自立）**：障害はあるが、ほぼ自立。ひとりで外出できる
- **A（準寝たきり）**：家の中はおおむね自立。介助なしには外出しない
- **B（寝たきり）**：家の中でも介助が必要。日中もベッド上が中心だが、座位は保てる
- **C（寝たきり）**：1日中ベッドの上。排泄・食事・着替えに介助が必要

認知症の人には「認知症高齢者の日常生活自立度」（Ⅰ〜Ⅳ・M）を使います。認知症の評価スケールは[若年性認知症・評価スケール・薬・予防](../ninchisho-03-hyoka/)で扱います。

## ③ 主観的情報・客観的情報と記録

| 種類 | 中身 | 例 |
|---|---|---|
| **主観的情報** | 利用者**本人の発言や訴え**（本人が感じていること） | 「何となく気持ちが悪い」と言った |
| **客観的情報** | 介護福祉職が**観察・測定した事実**（検査の結果も） | タンスに食べこぼしのついた上着が入っていた／体温37.5℃ |
| 介護福祉職の**解釈・推測** | 事実から考えたこと | 「帰宅願望から参加を拒否した」 |

> 主観的情報＝**利用者本人の発言や訴え**（本人が感じていること）、客観的情報＝**観察・測定した事実**。職員の推測・解釈はどちらでもなく、記録では事実と分けて書きます。選択肢で「主観的に記録した」と言うときは、**職員の推測が混ざっている**ことを指すので注意。考え方は[介護記録の書き方と情報管理](../kiroku-01-kiroku/)と同じです。

**よく出る一言**
- 本人の主観的情報を得る方法 → **本人の考えを聞く**（表情から推測するのは×、第27回）
- 「〜ではないか」「〜だからだと思う」「汚い」「生活しづらそう」は**解釈**。客観的情報ではない
- 第33回では、「帰宅願望から、レクリエーションの参加を拒否した」が「**主観的に**記録したもの」の正解でした。介護福祉職の推測（帰宅願望）が混ざっているからです。「帰宅願望」は職員がつけた言葉で、本人には家に帰りたい理由があることが多いので、本人の言葉と様子をそのまま書きます

### 記録のルール

- 事実を**ありのまま**、**その日のうちに**記録する（鉛筆で書く・数日後にまとめて書くのは×）
- 介護福祉職が**判断した内容も記録**する（ただし事実とは分けて書く）
- 計画どおりに実施した日も記録する
- 利用者の気持ちを**憶測**で書かない

### SOAP方式

| 記号 | 意味 |
|---|---|
| **S** | 主観的情報（本人の言葉） |
| **O** | 客観的情報（観察・測定） |
| **A** | アセスメント（判断・分析） |
| **P** | **今後の計画** |

4つの欄の記入例は[介護記録の書き方と情報管理](../kiroku-01-kiroku/)にあります。

## ひっかけパターン集（介護過程の基本で「ほぼ×」）

| 選択肢の表現 | なぜ× |
|---|---|
| 家族の望む生活／介護福祉職の望む生活 | 主体は利用者 |
| 業務効率・画一的・経験則 | 個別ケア・根拠のある介護に反する |
| 目的は他職種との連携 | 連携は手段。目的は利用者の望む生活・自立支援 |
| 1つの情報・1つの場面で判断する | 多角的・継続的に集める |
| 他職種の情報は使わない | チームで情報を集めて活用する |
| 他職種の記録は直接的情報 | 本人以外から得たものは間接的情報 |
| 本人の言葉を介護福祉職が解釈して記録する | 発言はそのまま記録する |
| 本人の思いは表情から推測する | 本人に考えを聞く |
