**この記事のポイント**

1. 介護過程の目的は「**利用者の望む生活の実現**」。正解の言い回しは毎年少しずつ変わるが、中身は同じ。
2. アセスメントのゴールは「**生活課題を明らかにする**」こと。情報は**多角的に、他職種からも**集める。
3. 主観的情報＝**本人が言ったこと**、客観的情報＝**見た・測った事実**。介護福祉職の推測や解釈はどちらにも混ぜない。

---

## ① 介護過程の目的

介護過程は「アセスメント → 計画 → 実施 → 評価」をくり返す、**根拠のある個別ケア**のための考え方です。

```
アセスメント（情報収集 → 解釈・関連づけ → 生活課題の明確化）
      ↓
介護計画の立案（目標 → 支援内容）
      ↓
実施
      ↓
評価 →（必要なら再アセスメントへ戻る）
```

「目的として最も適切なもの」は**11問**出ています。正解は、どれも同じことを言い換えたものです。

| ○ 正解になる言葉 | × 不正解になる言葉 |
|---|---|
| 利用者の望む、よりよい生活の実現 | 介護福祉職が望む生活／**家族が望む**生活 |
| 自立支援・自己実現 | 業務効率の優先 |
| 生活の質（QOL）の向上 | 画一的な介護 |
| 根拠のある個別ケア | 経験則・直感に基づく介護 |
| チームアプローチができる | ケアプランを作成する（介護支援専門員の仕事） |

**よく出る一言**：主語が「**利用者**」になっている選択肢を選びます。「介護福祉職の」「家族の」「業務の」が主語なら、ほぼ×です。

## ② アセスメントと情報収集の原則

アセスメントとは、**情報を集め、解釈し、関連づけて、生活課題を明らかにする**ことです。

| ○ 正しい情報収集 | × よく出る不正解 |
|---|---|
| **多角的・継続的**に集める | 1つの場面・1つの情報だけで判断する |
| **五感**を使って観察する | 先入観をもって見る |
| **他職種の情報**も活用する | 他職種の記録は使わない |
| 「**できること**」「**やりたいこと**」も集める | 困っていることだけを集める |
| 本人の**生活への思い**を大切にする | 家族の要望を中心に聴く |
| **介護福祉の知識**を使って解釈する | 介護福祉職の主観で解釈する |
| 初回面談では**目的を意識して**聴く | 用意した質問を次々にする／最初に経済状況を聞く |

### ICFで情報を整理する

アセスメントでは、情報を<strong>ICF（国際生活機能分類）</strong>の枠組みで整理する問題も出ます。

| 構成要素 | 事例での例 |
|---|---|
| 心身機能・身体構造 | 片麻痺、人工肛門、物忘れ |
| 活動 | 「**能力**」＝できる活動（例：車いすから便座へ移乗できる） |
| 参加 | 趣味の会、仕事、地域の役割 |
| 環境因子 | **家族の状況**（例：娘の仕事が忙しくなった）、住まい、福祉用具 |
| 個人因子 | 年齢、性別、生活歴、性格 |

> ICFそのものの詳しい説明は「ICF・リハビリ」の記事でまとめます。

## ③ 主観的情報・客観的情報と記録

| 種類 | 中身 | 例 |
|---|---|---|
| **主観的情報** | 利用者本人が**言ったこと**・訴え | 「何となく気持ちが悪い」と言った |
| **客観的情報** | 介護福祉職が**見た・聞いた・測った事実** | タンスに食べこぼしのついた上着が入っていた／体温37.5℃ |
| 介護福祉職の**解釈・推測** | 事実から考えたこと | 「帰宅願望から参加を拒否した」 |

**よく出る一言**
- 本人の主観的情報を得る方法 → **本人の考えを聞く**（表情から推測するのは×、第27回）
- 「〜ではないか」「〜だからだと思う」「汚い」「生活しづらそう」は**解釈**。客観的情報ではない
- 第33回では、「帰宅願望から、レクリエーションの参加を拒否した」が「**主観的に**記録したもの」の正解でした。介護福祉職の推測（帰宅願望）が混ざっているからです

### 記録のルール

- 事実を**ありのまま**、**その日のうちに**記録する（鉛筆で書く・数日後にまとめて書くのは×）
- 介護福祉職が**判断した内容も記録**する（ただし事実とは分けて書く）
- 計画どおりに実施した日も記録する
- 利用者の気持ちを**憶測**で書かない

### SOAP方式

| 記号 | 意味 |
|---|---|
| **S** | 主観的情報（本人の言葉） |
| **O** | 客観的情報（観察・測定） |
| **A** | アセスメント（判断・分析） |
| **P** | **今後の計画** |

## ④ 介護過程の8つの視点と情報の見方

<fig name="jiritsudo">

- **介護過程の8つの視点**：ICFで利用者をとらえる／尊厳を守る／個別ケア／生活と人生の継続性／生きがいと役割／自立支援／多職種連携と情報共有／根拠に基づく実践と的確な記録。
- **集めた情報を確かめる5つの視点**：正確な事実か、必要な事実をすべてつかんだか、結論を出すのに十分か、**先入観や偏見なく**集めたか、言葉の意味を正しくつかんだか。
- 情報を**解釈・関連づけ・統合**するときの3つの視点：**生命の安全**（健康が悪化しそうな点）、**生活の安定**（自立・継続できていない点）、**人生の豊かさ**（その人らしく暮らせていない点）。
- 利用者の状態をみる指標：**障害高齢者の日常生活自立度（寝たきり度）**、**認知症高齢者の日常生活自立度**（Ⅰ・Ⅱa/b・Ⅲa/b・Ⅳ・M）、アルツハイマー型の**FAST**。
- 在宅での観察は**身体面・心理面（認識）・行動面**の3側面から。
