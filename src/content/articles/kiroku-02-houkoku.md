**この記事のポイント**

1. 報告は**結論が先、経過はあと**。**指示を受けた仕事は指示者へ**。事実は**具体的に**（「朝6時に少量の胃液を嘔吐」）。判断は事実と分けて「〜と思います」と添える。
2. 苦情は**すぐ口頭で概要→文書で報告**、「**まだ解決していない**」ことも伝える。
3. カンファレンスは**専門性を理解して参加**、意見が分かれても**議論して合意点**を。多数決・上の人に従う・医師に従うは×。

## ① 報告・申し送り・苦情

### 報告・連絡・相談（報連相）

| | 中身 |
|---|---|
| 報告 | 指示された仕事の結果や経過を、**指示した人に**伝える |
| 連絡 | 関係する人に事実や予定を知らせる |
| 相談 | 判断に迷うときに意見を求める。目的をはっきりさせ、資料と**自分なりの考え**を準備し、結果も報告する |

報告では、**いつ・どこで・誰が・何を・なぜ・どのように（5W1H）**を落とさないようにします。

### 報告のルール

| ○ | × |
|---|---|
| **結論を述べてから経過**を説明 | 詳しい状況から話す |
| **指示を受けた業務は指示者に報告** | 指示者以外にだけ伝える |
| 時間がかかるときは**途中で報告** | 完了後にまとめて |
| **事実を具体的に**、推測は推測として | 抽象的な言葉／推測を事実として |
| 事故・苦情・緊急のときは上司の都合を待たず**すぐ** | タイミングは上司に合わせる／軽微な事故は後日 |
| 記録したことも**口頭で報告** | 書けば口頭は不要 |

### 判断は言ってよい？　「事実→判断」の順で分ける

報告で×になるのは、**事実の代わりに判断だけを言う**ことです。見たまま・聞いたままの事実を先に伝え、自分の判断は「〜と思います」と**分けて添える**のは○です。

| 解釈・判断だけの言い方（×） | 見たままの言い方（○） |
|---|---|
| 「もの盗られ妄想があります」 | 「『財布を盗まれた』と言って、ベッドの周りを歩き回っていました」 |
| 「少しだけ吐きました。かわいそうでした」 | 「本日朝6時に、少量の胃液を嘔吐しました」 |
| 「認知機能が低下しました」 | 「今朝は、いつもできている歯みがきの手順がわからない様子でした」 |

> 報告の話し方の例：「Aさんが転倒しました（結論）。10時ごろ、トイレから戻る途中に廊下でしりもちをつきました（経過）。右の腰を痛がっていますが、出血はありません（状態）。念のため看護師に見てもらうのがよいと思います（自分の判断）。」

### 申し送り

| 場面 | ○ 正解 |
|---|---|
| 申し送りの目的 | **ケアの継続性を保つ** |
| 聞き手の留意点 | **不明な点を確認しながら聞く** |
| 伝え方 | 口頭だけでなく、**記録（文書）と組み合わせて**確実に伝える |

### 苦情の報告

| ○ | × |
|---|---|
| **すぐに口頭で概要を報告→文書を作成して報告** | 時間をかけて詳しく口頭で／翌日に報告／同僚に伝える |
| 「**苦情を受け、まだ解決していない**」ことを報告 | 自分で責任をもって処理してから報告する |
| 苦情の内容をそのまま伝える | 自分の方法は問題ないと主張する |
| 上司は「**一緒に考えましょう**」と支える | 「気にしなくていい」「自分で考えて」 |

## ② カンファレンス・事例検討・ブレインストーミング

### カンファレンスへの参加

カンファレンス（ケアカンファレンス）は、利用者の支援について関係者が集まって話し合う会議です。利用者本人・家族が参加することもあります。

| ○ | × |
|---|---|
| **各職種の専門性を理解**して参加 | 経験年数の長い人に従う／自分の思いにこだわる |
| 意見の不一致があっても**議論して合意点を見いだす** | 施設長・医師・多数意見に合わせる／多数決 |
| **利用者本人の参加を促し、意向をケア方針に反映** | 本人抜きで決める |
| 少数意見も大事にし、根拠をもって意見を言う | 対立を避けて他職種に反論しない／介護職への批判中心 |

上の表のほかに出る×（理由つき）は、ひっかけパターン集にまとめました。

### 用語は「使う」？「避ける」？

- **記録**：利用者・家族も読み、職種もさまざまなので、**誰でもわかる言葉**で書く（専門用語や略語は避ける）。
- **チーム内の話し合い**：専門用語を使うときは、**意味をチームでそろえて**使う（記録や言葉で確かめ合う）。

### 事例検討・チーム

- 事例検討の目的＝**チームで事例の課題を共有し、解決策を見いだす**
- リーダーは指示だけでなく、**メンバーの経験に応じて裁量を認める**。リーダーシップとフォロワーシップは[ケアマネジメント・多職種連携・人材育成](../team-01-renkei/)で扱います。
- カンファレンスは、先輩などから助言・指導を受ける**スーパービジョン**の機会にもなる。

### ブレインストーミングの4原則

ブレインストーミング＝アイデアを自由にたくさん出し合う会議の方法です。

| 原則 | 中身 |
|---|---|
| 批判禁止 | 他人の意見をその場で判断・批判しない |
| 自由奔放 | **奇抜な意見も歓迎** |
| **質より量** | 数多くの意見を出す |
| 結合・便乗 | **他人の意見を参考にして発展させる** |

## ひっかけパターン集（報告・会議で「ほぼ×」）

| 選択肢の表現 | なぜ× |
|---|---|
| 経過を詳しく話してから結論 | 結論が先 |
| 報告は上司の都合に合わせる | 事故・苦情・緊急なら、すぐ |
| 「もの盗られ妄想があります」と報告 | 解釈だけ。見たままの言動を伝える |
| 介護職の判断は報告に含めない | 事実と分ければ、判断も添えてよい |
| 苦情は自分で解決してから報告 | すぐ報告・未解決も伝える |
| 意見が分かれたら多数決・医師に従う | 議論して合意点を見いだす |
| 分からないことは会議のあとで調べる | その場で確認し、共通理解をつくる |
| 全員参加なら議事録は不要 | 決まったことを残し、欠席者・途中退席者とも共有するために作る |
| 議題は支援内容の確認だけに限る | 学び合い（スーパービジョン）の機会にしてもよい |
| 資料は当日配る／勤務時間外に開く | 資料は事前に配り、勤務時間内に開く |
| ヘルパーは自分の感想を発言する | 支援の状況を報告し、意見を求める |
| ブレストで奇抜な意見を除く | 歓迎する |
