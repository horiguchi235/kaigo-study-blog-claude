**この記事のポイント**

1. 報告は**結論が先、経過はあと**。**指示を受けた仕事は指示者へ**。事実は**具体的に**（「朝6時に少量の胃液を嘔吐」）。
2. 苦情は**すぐ口頭で概要→文書で報告**、「**まだ解決していない**」ことも伝える。
3. カンファレンスは**専門性を理解して参加**、意見が分かれても**議論して合意点**を。多数決・上の人に従う・医師に従うは×。

## ① 報告・申し送り・苦情【コミュニケーション技術】

### 報告のルール

| ○ | × |
|---|---|
| **結論を述べてから経過**を説明 | 詳しい状況から話す |
| **指示を受けた業務は指示者に報告** | — |
| 時間がかかるときは**途中で報告** | 完了後にまとめて |
| **事実を具体的に**、推測は推測として | 抽象的な言葉／推測を事実として |
| 緊急のときは上司の都合を待たず**すぐ** | タイミングは上司に合わせる／軽微な事故は後日 |
| 介護職としての**判断も添える**（事実と分けて） | 判断を除外 |
| 記録したことも**口頭で報告** | 書けば口頭は不要 |

### 申し送り・事実の伝え方

| 場面 | ○ 正解 |
|---|---|
| 嘔吐の申し送り | 「**本日朝6時に少量の胃液を嘔吐した**」（「少しだけ」「かわいそう」「薬が必要」は×） |
| もの盗られの訴えをカンファで報告 | 「**財布が盗まれたと言って、ベッドの周りをうろうろしていました**」（「もの盗られ妄想があります」「認知機能が低下」は解釈） |
| 申し送りの目的 | **ケアの継続性を保つ** |
| 聞き手の留意点 | **不明な点を確認しながら聞く** |

### 苦情の報告

| ○ | × |
|---|---|
| **すぐに口頭で概要を報告→文書を作成して報告** | 時間をかけて詳しく口頭で／翌日に報告／同僚に伝える |
| 「**苦情を受け、まだ解決していない**」ことを報告 | 自分で責任をもって処理する／自分の方法は問題ないと主張 |
| 上司は「**一緒に考えましょう**」と支える | 「気にしなくていい」「自分で考えて」 |

## ② カンファレンス・事例検討・ブレインストーミング【コミュニケーション技術】

### カンファレンスへの参加

| ○ | × |
|---|---|
| **各職種の専門性を理解**して参加 | 経験年数の長い人に従う／自分の思いにこだわる |
| 意見の不一致があっても**議論して合意点を見いだす** | 施設長・医師・多数意見に合わせる／分からないことは後で調べる |
| **利用者本人の参加を促し、意向をケア方針に反映** | 多数決／他職種に反論しない／介護職への批判中心 |
| ヘルパーは**支援状況を報告し、意見を求める** | 自分の感想を発言 |
| **議事録を作る**、途中退席者にも記録で共有 | 全員参加なら議事録不要 |
| カンファの場を**スーパービジョンの機会**にしてよい | 議題は支援内容の確認に限定 |
| 資料は**事前に配布**、**勤務時間内**に開催 | 事前配布しない／時間外に設定 |

### 事例検討・チーム

- 事例検討の目的＝**チームで事例の課題を共有し、解決策を見いだす**
- リーダーは指示だけでなく、**メンバーの経験に応じて裁量を認める**
- 専門用語の意味は**共通認識**を。記録や言葉で**確かめ合う**

### ブレインストーミングの4原則

| 原則 | 中身 |
|---|---|
| 批判禁止 | 他人の意見をその場で判断・批判しない |
| 自由奔放 | **奇抜な意見も歓迎** |
| **質より量** | **数多くの意見を出す** |
| 結合・便乗 | **他人の意見を参考にして発展させる** |
