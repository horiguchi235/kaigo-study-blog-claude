## この記事で対策できる科目

| 科目 | 過去15年の出題数 | この記事の章 |
|---|---|---|
| 介護過程 | 19問 | ①生活課題 ②目標設定 ③介護計画の立案 |

**結論を3行で**

1. 生活課題＝「**利用者が望む生活を実現するために解決すべきこと**」。複数あれば**優先順位**をつけ、最優先は**緊急性**（命・安全）。
2. 目標の主語は**利用者**。「〜できる」の形で、**具体的・実現可能**に。短期目標は長期目標につながる**段階**。
3. 介護計画は**具体的に**、**利用者・家族の意向を反映**し、**同意**を得て、**見直しの時期**も決める。

## ① 生活課題と優先順位【介護過程】

**生活課題の定義**（第24回・第34回・第37回）：利用者が**望む生活を実現するために解決すべきこと**。

- 「生活上の困難を起こしている**原因**」ではない（第24回のひっかけ）
- 「家族の望む生活」「効率的な支援」のための課題ではない
- 判断の基盤は**利用者のニーズ**（介護福祉職の主観は×）

| ○ | × |
|---|---|
| 複数あれば**優先順位をつける** | 1つに絞る／要望を1つに集約する |
| **潜在的な課題**も取り上げる | 表に出ている課題だけを扱う |
| 優先順位は**緊急性の高いもの**から | 要望の多い順／評価しやすい順／家族の負担が減る順 |

> 「生命の危機よりも利用者の意向を優先する」は×（第37回）。命と安全が最優先です。

## ② 目標設定（長期目標・短期目標）【介護過程】

| | 長期目標 | 短期目標 |
|---|---|---|
| 中身 | 最終的に実現したい**生活像** | 長期目標に向かう**段階的**な目標 |
| 関係 | — | **長期目標の達成につながる**ように設定（第34回） |
| 根拠 | アセスメントで明らかにした生活課題 | アセスメントに基づく**具体的な生活課題**から検討（第38回） |

**目標の書き方のルール**

- 主語は**利用者**（介護福祉職の行動目標にしない）
- 「**〜できる**」の形で書く → 第25回の正解は「夜間はポータブルトイレで排泄**できる**」
- **具体的**で、誰が読んでも同じ意味になる言葉（多様な解釈ができる言葉は×）
- **実現可能**な内容を、**段階的**に
- **利用者と話し合いながら**つくる（第29回）。家族が望む生活を長期目標にするのは×

**よく出る不正解**
- 「〜するように**理解させる**」「おむつで排泄**させない**」 → 介護者側の目線・使役
- 「ポータブルトイレを**置く**」「排泄の介護を**する**」 → 介護福祉職の行動

> 事例では、本人の望む暮らしが目標になります。第27回、もの盗られ妄想で長男の妻を責める認知症の女性への目標は「**Dさんと穏やかに過ごすことができる**」でした。「BPSDを改善する」「説明を受けて理解する」は利用者の望む生活ではありません。

## ③ 介護計画の立案【介護過程】

| ○ 正しい計画 | × よく出る不正解 |
|---|---|
| 生活課題を**解決する方法**を計画する | アセスメントせずに計画する |
| **具体的**に書く（いつ・どこで・誰が・何を・どのように） | 抽象的に書く／支援方法の記載を省略する |
| **利用者と家族の意向を反映**する | 介護福祉職の意向・望む利用者像を優先する |
| 利用者の**同意**を得る | — |
| **現実的で実践可能**な内容 | 実現不可能でも高い目標 |
| **今までの生活習慣**を考慮する | 生活習慣は考慮しない |
| **介護するときの注意点**も書く | 時間の設定を省略する |
| **見直しの時期**を決める | 計画は変更しない／見直し時期を決めない |
| 誰にでもわかる言葉で書く | 専門用語・「〜させる」の使役文 |

### ケアプランとの関係

- 介護支援専門員（ケアマネジャー）が作る**居宅サービス計画（ケアプラン）**が全体の方針
- 訪問介護などの各事業所は、**ケアプランの方針に沿って**、自分たちの**個別援助計画**（訪問介護計画など）を作る（第35回）
- ケアプランの目標が変わったら、個別援助計画も見直す

<details>
<summary>✏️ 解いてみよう（第35回）</summary>

居宅サービス計画と訪問介護計画の関係として、最も適切なものはどれ？

1. 訪問介護計画を根拠に、居宅サービス計画を作成する
2. 居宅サービス計画の目標が変わっても、訪問介護計画は見直さない
3. 居宅サービス計画と同じ内容を、訪問介護計画に転記する
4. 居宅サービス計画の方針に沿って、訪問介護計画を作成する
5. 訪問介護計画の終了後に、居宅サービス計画を作成する

<details class="answer">
<summary>正解を見る</summary>

**正解：4**　「全体の計画（ケアプラン）→ 各サービスの計画」という順番です。転記ではなく、方針に沿って具体化します。
</details>
</details>

## ひっかけパターン集（生活課題・目標・計画で「ほぼ×」）

| 選択肢の表現 | なぜ× |
|---|---|
| 生活課題は困難の「原因」のこと | 望む生活のために「解決すべきこと」 |
| 課題を1つに絞る | 複数あれば優先順位をつける |
| 目標の主語が介護福祉職／家族 | 主語は利用者 |
| 「〜させる」「理解させる」 | 利用者主体の表現にする |
| 計画は変更しない／見直し時期を決めない | 状況に応じて見直す。時期も決める |
| 専門用語で書く | 利用者・家族・チームが理解できる言葉で |
