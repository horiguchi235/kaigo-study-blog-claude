**この記事のポイント**

1. 生活課題＝「**利用者が望む生活を実現するために解決すべきこと**」。複数あれば**優先順位**をつけ、最優先は**命・安全**（生命の安全→生活の安定→人生の豊かさ）。ただし安全を理由に生活を狭めるのは×。
2. 目標の主語は**利用者**。「〜できる」の形で、**具体的・実現可能**に。短期目標は長期目標につながる**段階**。
3. 介護計画は**具体的に**、**利用者・家族の意向を反映**し、**同意**を得て、**見直しの時期**も決める。

## ① 生活課題と優先順位

**生活課題の定義**：利用者が**望む生活を実現するために解決すべきこと**。

- 「生活上の困難を起こしている**原因**」ではない（原因は課題の「要因」。下の図）
- 「家族の望む生活」「効率的な支援」のための課題ではない
- 判断の基盤は**利用者のニーズ**（介護福祉職の主観は×）

### 要望とニーズの違い

| 言葉 | 意味 | 例 |
|---|---|---|
| **要望（デマンド）** | 本人が口にした希望 | 「迷惑がかかるから、おむつのままでいい」 |
| **ニーズ** | 本人の思いや状態から、専門職が見立てた本当に必要なこと | トイレで排泄できること（遠慮の奥にある望み） |

要望をそのまま課題にするのではなく、その奥にあるニーズを考えます。この例は第29回の事例です（[介護過程の事例問題の解き方](../kaigokatei-04-jirei/)の型2）。

### 顕在的課題・潜在的課題・要因

<fig name="kadai">

- **顕在的課題**＝いま現れている課題（例：ひとりで外に出てしまう）
- **潜在的課題**＝今は表に出ていないが、放っておくと起こる課題（例：交通事故にあう危険）
- **要因**＝課題を起こしている背景・原因（例：血管性認知症）。生活課題そのものではないが、支援内容を考えるときに「取り除く・軽くする」対象になる

| ○ | × |
|---|---|
| 複数あれば**優先順位をつける** | 1つに絞る／要望を1つに集約する |
| **潜在的な課題**も取り上げる | 表に出ている課題だけを扱う |
| 優先順位は**緊急性の高いもの**（命・安全）から | 要望の多い順／評価しやすい順／家族の負担が減る順 |

### 優先順位の3つの視点

アセスメントの3つの視点（[介護過程の目的とアセスメント](../kaigokatei-01-assessment/)）を、そのまま優先順位に使います。

1. **生命の安全**：誤嚥・転倒・脱水など、命や健康にかかわること
2. **生活の安定**：食事・排泄・移動など、毎日の生活を続けること
3. **人生の豊かさ**：趣味・役割・人との交流など、その人らしさ

> 「生命の危機よりも利用者の意向を優先する」は×。命と安全が最優先です。ただし、危険が事例に書かれていないのに「安全のため」と活動を減らす（車いすで過ごす・外出を控える）のも×。安全を守りながら、望む生活を実現する方法を考えます。

## ② 目標設定（長期目標・短期目標）

| | 長期目標 | 短期目標 |
|---|---|---|
| 中身 | 最終的に実現したい**生活像** | 長期目標に向かう**段階的**な目標 |
| 期間の目安 | おおむね**6か月〜1年** | **数か月**（長期目標より短い） |
| 関係 | 生活全体の課題が解決した状態 | **長期目標の達成につながる**ように設定 |
| 根拠 | アセスメントで明らかにした生活課題 | アセスメントに基づく**具体的な生活課題**から検討 |

**目標の書き方のルール**

- 主語は**利用者**（介護福祉職の行動目標にしない）
- 「**〜できる**」の形で書く → 第25回の正解は「夜間はポータブルトイレで排泄**できる**」
- **具体的**で、誰が読んでも同じ意味になる言葉（多様な解釈ができる言葉は×）
- **観察や測定ができる**表現にし、**いつまでに**を明記する（例：「3か月後に、リビングまで歩行器で歩ける」）
- **実現可能**な内容を、**段階的**に
- **利用者と話し合いながら**つくる。家族が望む生活を長期目標にするのは×

### ×の目標を○に書き換える

| ×の目標 | なぜ× | ○に書き換えると |
|---|---|---|
| 排泄の介護をする | 介護福祉職の行動になっている | 日中はトイレで排泄できる |
| ポータブルトイレを置く | 介護福祉職の行動 | 夜間はポータブルトイレで排泄できる |
| 転倒の危険を理解させる | 使役（〜させる）で、介護者の目線 | 杖を使って、居室からトイレまで歩ける |
| 元気に過ごす | 何をもって達成かがわからない | 週2回、デイサービスの体操に参加できる |

> 事例では、本人の望む暮らしが目標になります。第27回、もの盗られ妄想で長男の妻（Dさん）を責める認知症の女性への目標は「**Dさんと穏やかに過ごすことができる**」でした。「BPSD（認知症の行動・心理症状。妄想や、歩き回る〈徘徊〉など）を改善する」「説明を受けて理解する」は利用者の望む生活ではありません。

## ③ 介護計画の立案

| ○ 正しい計画 | × よく出る不正解 |
|---|---|
| 生活課題を**解決する方法**を計画する | アセスメントせずに計画する |
| **具体的**に書く（いつ・どこで・誰が・何を・どのように） | 抽象的に書く／支援方法の記載を省略する |
| 時間も書く | 業務の都合に合わせるため時間を書かない |
| **利用者と家族の意向を反映**する | 介護福祉職の意向・望む利用者像を優先する |
| 利用者の**同意**を得る | 説明や同意を省く |
| **現実的で実践可能**な内容 | 実現不可能でも高い目標 |
| **今までの生活習慣**を考慮する | 生活習慣は考慮しない |
| **介護するときの注意点**も書く | 注意点は書かない |
| **見直しの時期**を決める | 計画は変更しない／見直し時期を決めない |
| 誰にでもわかる言葉で書く | 専門用語・「〜させる」の使役文 |

**支援内容の条件**：利用者の自己決定と個別のニーズを尊重している／**介護福祉職の業務の範囲内**である／課題の要因がわかるなら、それを取り除く・軽くする内容である／根拠（理論・研究・経験）がある／安全で効果的・効率的・経済的である。

### 介護計画の見本（架空の事例）

80歳の女性。膝の痛みで歩く距離が短くなり、居室で過ごす時間が増えた。「また畑に出たい」と話している（[介護過程の目的とアセスメント](../kaigokatei-01-assessment/)の例の続き）。

| 項目 | 記入例 |
|---|---|
| 生活課題 | 痛みに配慮しながら歩く力を保ち、畑に出る楽しみを続けられる |
| 長期目標（1年） | 家族と一緒に、自宅の畑で野菜の世話ができる |
| 短期目標（3か月） | 杖を使って、居室から食堂まで（約30m）休まずに歩ける |
| 支援内容 | 毎日、昼食の前に（いつ）、居室から食堂まで（どこで）、介護福祉職が見守りながら（誰が）、杖で歩いてもらう（何を・どのように） |
| 注意点 | 歩く前に膝の痛みを確認し、痛みが強い日は距離を短くする。看護職に痛みの様子を報告する |
| 評価日 | 3か月後（評価日は計画を立てるときに決める） |

### ケアプランとの関係

- 介護支援専門員（ケアマネジャー）が作る<strong>居宅サービス計画（ケアプラン）</strong>が全体の方針
- 訪問介護などの各事業所は、**ケアプランの方針に沿って**、自分たちの**個別援助計画**（訪問介護計画など）を作る
- ケアプランの目標が変わったら、個別援助計画も見直す

| 全体の計画（つくる人） | 事業所の計画（つくる人） |
|---|---|
| 居宅サービス計画（介護支援専門員） | 訪問介護計画など（サービス提供責任者など） |
| 施設サービス計画（施設の介護支援専門員） | 施設での介護計画（介護福祉職など） |
| サービス等利用計画（相談支援専門員） | 個別支援計画（サービス管理責任者） |

くわしくは[ケアプラン・サービス等利用計画・個別支援計画…計画とつくる人の違い](../hikaku-10-keikaku/)で比べています。

## ひっかけパターン集（生活課題・目標・計画で「ほぼ×」）

| 選択肢の表現 | なぜ× |
|---|---|
| 生活課題は困難の「原因」のこと | 原因は「要因」。生活課題は望む生活のために「解決すべきこと」 |
| 課題を1つに絞る／要望を1つにまとめる | 複数あれば優先順位をつける |
| 本人の要望をそのまま課題にする | 要望の奥にあるニーズを考える |
| 安全のため活動を控える目標にする | 危険が書かれていないなら、生活を狭めない |
| 目標の主語が介護福祉職／家族 | 主語は利用者 |
| 「〜させる」「理解させる」 | 利用者主体の表現にする |
| 長期目標は1か月程度 | 長期は6か月〜1年程度。数か月は短期目標 |
| 計画は変更しない／見直し時期を決めない | 状況に応じて見直す。時期も決める |
| 専門用語で書く | 利用者・家族・チームが理解できる言葉で |
