## この記事で対策できる科目

| 科目 | 過去15年の出題数 | この記事の章 |
|---|---|---|
| 認知症の理解 | 34問 | ①アルツハイマー型 ②レビー小体型 ③前頭側頭型・血管性・CJD ④治る認知症 |

**結論を3行で**

1. 疾患ごとの「顔」を1つずつ：**アルツハイマー＝もの盗られ妄想**、**レビー＝幻視とパーキンソン症状**、**前頭側頭＝人格変化・常同行動**、**血管性＝感情失禁・段階的悪化**、**CJD＝急速進行**。
2. 事例問題は「**頭を打って1〜3か月後**」＝**慢性硬膜下血腫**、「**歩行障害・尿失禁・物忘れ**」＝**正常圧水頭症**。どちらも**治療で改善**する。
3. 原因で多い順は**アルツハイマー型 → 血管性**（第33回）。

## 早見表

| 疾患 | 性別・進行 | 特徴的な症状 |
|---|---|---|
| **アルツハイマー型** | **女性**に多い／**ゆるやか**に進行 | 初期から**近時記憶障害**、**もの盗られ妄想**、取り繕い |
| **レビー小体型** | 男性にやや多い | **具体的な幻視**、**パーキンソン症状**（小刻み歩行・転倒）、**認知機能の変動**、レム睡眠行動障害、**起立性低血圧** |
| **前頭側頭型** | 比較的若い | **人格変化**、**脱抑制**（万引きなど）、**常同行動**、甘い物へのこだわり。記憶は比較的保たれる |
| **血管性** | **男性**に多い／**階段状**に悪化 | **まだら認知症**、**感情失禁**、**抑うつ**、麻痺、初期に**めまい** |
| **クロイツフェルト・ヤコブ病** | — | **プリオン病**、**急速に進行**し**1年以内の死亡**も多い、ミオクローヌス（不随意運動） |

疾患とBPSDの組合せ：**血管性 ― 抑うつ**が正解（第31回）。幻視はレビー、人格変化は前頭側頭、もの盗られ妄想はアルツハイマーです。

## ① アルツハイマー型認知症【認知症の理解】

| ○ | × |
|---|---|
| **女性**に多い（第25回） | 麻痺がある・階段状に悪化・多発性脳梗塞（血管性の特徴） |
| 初期から**記憶障害**（**近時記憶・エピソード記憶**）（第30・37・38回） | 古い記憶から障害される／若い頃のことを忘れる |
| 初期に**もの盗られ妄想**（第24回）。**不安**から生じる（第35回） | 説明すれば誤りに気づく・現実にいない人が犯人・幻視が原因 |
| 軽度で**炊事の自立が困難**（IADLの低下）（第29回） | 小刻み歩行・嚥下障害・尿失禁（いずれも後期） |
| 見当識障害は**初期〜中期**から | 中期以降／ADL障害は重度期以降 |
| アミロイドβの沈着は**発症の何年も前**から始まる | 沈着するとすぐ発症 |

> FAST（アルツハイマー型の重症度）：料理・家計・買い物が難しいのは**軽度**、季節や場面に合った**服を選べず介助が必要**になると**中等度**（第28回は中等度）。

## ② レビー小体型認知症【認知症の理解】

| ○ よく出る症状 | × 出ない・誤り |
|---|---|
| **鮮明で具体的な幻視**（「窓のそばに知らない人が立っている」）（第25・30回） | 幻視はあいまい |
| **パーキンソン症状**：**最初の一歩が出にくく小刻み**に歩く、**動作が遅く転倒しやすい**（第26・36回） | 運動機能障害は見られない |
| 認知機能・症状の**日内変動** | **初期からの人格変化**（第24回で×） |
| **自律神経症状**＝**起立性低血圧**（第38回） | 幻聴・意味性失語・食欲増加 |
| **レム睡眠行動障害**（夢を見て大声・手足を動かす） | ノンレム睡眠 |
| **誤嚥性肺炎**の合併が多い（第33回） | 脳梗塞が原因・初発が記憶障害 |
| 幻視は**部屋を明るくすると消える**ことがある（第34回） | 抗精神病薬が多く使われる（薬に過敏で副作用が出やすい） |

**幻視への対応**：ふりかけを「アリがたかっている」と言う → **普通のご飯に取り替えて**勧める（第27回）。「アリはいません」と否定するのは×。

<details>
<summary>✏️ 解いてみよう（第36回）</summary>

レビー小体型認知症にみられる歩行障害として、最も適切なものはどれ？

1. しばらく歩くと足が痛くなり、休みながら歩く
2. 最初の一歩が踏み出しにくく、小刻みに歩く
3. 動きがぎこちなく、酔っぱらったように歩く
4. 下肢が伸び、つま先を引きずるように歩く
5. 歩くたびに骨盤が傾き、腰を左右に振って歩く

<details class="answer">
<summary>正解を見る</summary>

**正解：2**　パーキンソン症状の歩き方です。1は間欠性跛行（脊柱管狭窄症など）、3は失調性歩行、4は痙性歩行（脳卒中の片麻痺など）、5は筋疾患などでみられる歩き方です。
</details>
</details>

## ③ 前頭側頭型・血管性・クロイツフェルト・ヤコブ病【認知症の理解】

### 前頭側頭型認知症

- **社会のルールや常識がわからなくなる**（第27回）、**常同行動**（同じ時間に同じ行動）（第30回）
- 対応：常同行動は止めるのではなく、**本人と周囲が納得できる生活習慣**にする（第32回）
- ×の選択肢：「物忘れの自覚」「幻視」「急速な進行」「エピソード記憶障害が初期から」

### 血管性認知症

- 脳梗塞・脳出血が原因。**男性**に多く、**階段状**に悪化
- **初期にめまい**を自覚することがある（第29回）
- 危険因子：**メタボリックシンドローム**・高血圧・糖尿病（第30回）
- ×：「女性に多い」「ゆっくり少しずつ進行」「人格変化が多い」「85歳以上に多い」

### クロイツフェルト・ヤコブ病

- **プリオン病**（第33回）。進行が速く、**1年以内の死亡例も多い**（第28回）
- ×：有病率1万人に1人（実際は**約100万人に1人**）、緩やかに進行、致死率は低い、不随意運動を伴わない

認知症の原因疾患と、特徴的なBPSDの組合せとして適切なものはどれ？

1. アルツハイマー型認知症 ― 幻視
2. 血管性認知症 ― 抑うつ

4. 前頭側頭型認知症 ― もの盗られ妄想
5. クロイツフェルト・ヤコブ病 ― 徘徊

**正解：2**　1・3・4は中身が入れ替わっています（幻視はレビー、人格変化は前頭側頭、もの盗られ妄想はアルツハイマー）。

## ④ 治療で改善が期待できる認知症【認知症の理解】

| | **慢性硬膜下血腫** | **正常圧水頭症** |
|---|---|---|
| きっかけ | **頭部の打撲**（転倒など）。**抗凝固薬**の使用もリスク（第35回） | はっきりしない |
| 発症 | 打撲から**1〜3か月後**に物忘れ・ふらつき・麻痺（第24回） | — |
| 症状 | 物忘れ・歩行障害・片麻痺 | **歩行障害・尿失禁・認知障害**の3つ（第28・32回） |
| 診断 | **頭部CT**（第33回） | 頭部CT・MRI |
| 治療 | **外科的手術**（血腫を取り除く）（第25・28回） | **シャント手術** |

> 「早期発見で改善が可能」（第27回）・「外科的手術で治療が可能」（第28回）と聞かれたら、この2つから選びます。

<details>
<summary>✏️ 解いてみよう（第28回・事例）</summary>

一人暮らしの80歳男性。2か月ほど前から物忘れとぼうっとする様子が見られ、歩行が不安定になり、最近は尿意を我慢できず失禁がある。最も可能性の高いものはどれ？

1. 軽度認知障害
2. アルツハイマー型認知症
3. 正常圧水頭症
4. 前頭側頭型認知症
5. 血管性認知症

<details class="answer">
<summary>正解を見る</summary>

**正解：3**　「物忘れ＋歩行障害＋尿失禁」がそろったら正常圧水頭症です。アルツハイマー型では歩行障害や失禁は後期に出ます。
</details>
</details>

## ひっかけパターン集（疾患で「ほぼ×」）

| 選択肢の表現 | なぜ× |
|---|---|
| アルツハイマー型は男性に多い／階段状に悪化 | 女性・ゆるやか。階段状は血管性 |
| アルツハイマー型で初期から失禁・歩行障害 | 後期の症状 |
| レビー小体型で初期から人格変化 | 人格変化は前頭側頭型 |
| レビー小体型の幻視はあいまい | 具体的・鮮明 |
| CJDはゆっくり進行・致死率が低い | 急速・予後不良 |
| 慢性硬膜下血腫は打撲の2〜3日後 | 1〜3か月後 |
