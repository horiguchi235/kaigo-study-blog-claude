**この記事のポイント**

1. 疾患ごとの「顔」を1つずつ：**アルツハイマー＝もの盗られ妄想**、**レビー＝幻視とパーキンソン症状**、**前頭側頭＝人格変化・常同行動**、**血管性＝感情失禁・段階的悪化**、**クロイツフェルト・ヤコブ病（CJD）＝急速進行**。
2. 事例問題は「**頭を打って1〜3か月後**」＝**慢性硬膜下血腫**、「**歩行障害・尿失禁・物忘れ**」＝**正常圧水頭症**。どちらも**治療で改善**する。
3. 原因で多い順は**アルツハイマー型 → 血管性**。

## 早見表

| 疾患 | 主に障害される脳の場所 | 性別・進行 | 特徴的な症状 |
|---|---|---|---|
| **アルツハイマー型** | **海馬**（側頭葉の内側）から全体へ萎縮 | **女性**に多い／**ゆるやか**に進行 | 初期から**近時記憶障害**、**もの盗られ妄想**、取り繕い |
| **レビー小体型** | 後頭葉（見る働き）など | 男性にやや多い | **具体的な幻視**、**パーキンソン症状**（小刻み歩行・転倒）、**認知機能の変動**、レム睡眠行動障害、**起立性低血圧** |
| **前頭側頭型**（ピック病など） | **前頭葉・側頭葉** | 比較的若い | **人格変化**、**脱抑制**（万引きなど）、**常同行動**、甘い物へのこだわり。記憶は比較的保たれる |
| **血管性** | 脳梗塞・脳出血が起きた場所 | **男性**に多い／**階段状**に悪化 | **まだら認知症**、**感情失禁**、**抑うつ**、麻痺、初期に**めまい** |
| <strong>クロイツフェルト・ヤコブ病（CJD）</strong> | 脳全体 | — | **プリオン病**（異常なたんぱく質プリオンが原因）、**急速に進行**し**1年以内の死亡**も多い、ミオクローヌス（手足がピクッと動く不随意運動） |

<photo name="ninchisho-02__shinkou-graph" caption="横軸は時間、縦軸は認知機能。青はアルツハイマー型（ゆるやか）、緑は血管性（階段状）、紫はレビー小体型（変動の波）、赤はクロイツフェルト・ヤコブ病（急速）">

過去問で「疾患とBPSDの正しい組合せ」が問われ、正解は**血管性 ― 抑うつ**でした。幻視はレビー、人格変化は前頭側頭、もの盗られ妄想はアルツハイマーです。

## ① アルツハイマー型認知症

| ○ | × |
|---|---|
| **女性**に多い | 麻痺がある・階段状に悪化・多発性脳梗塞（血管性の特徴） |
| 初期から**記憶障害**（**近時記憶・エピソード記憶**） | 古い記憶から障害される／若い頃のことを忘れる |
| 初期に**もの盗られ妄想**。**不安**から生じる | 説明すれば誤りに気づく・現実にいない人が犯人・幻視が原因 |
| 軽度で**炊事の自立が困難**（IADL＝買い物・調理・金銭管理など道具を使う生活動作の低下） | 小刻み歩行・嚥下障害・尿失禁（いずれも後期） |
| 見当識障害は**初期〜中期**から | 中期以降／ADL（食事・排泄など毎日の基本動作）障害は重度期以降 |
| アミロイドβ（脳にたまる異常なたんぱく質）の沈着は**発症の何年も前**から始まる | 沈着するとすぐ発症 |

> FAST（アルツハイマー型の進み具合を7段階で見る物差し）：料理・家計・買い物が難しいのは**FAST 4＝軽度**、季節や場面に合った**服を選べず介助が必要**になると**FAST 5＝中等度**。

## ② レビー小体型認知症

| ○ よく出る症状 | × 出ない・誤り |
|---|---|
| **鮮明で具体的な幻視**（「窓のそばに知らない人が立っている」） | 幻視はあいまい |
| **パーキンソン症状**：**最初の一歩が出にくく小刻み**に歩く、**動作が遅く転倒しやすい** | 運動機能障害は見られない |
| 認知機能・症状の**日内変動** | **初期からの人格変化** |
| **自律神経症状**＝**起立性低血圧** | 幻聴・意味性失語・食欲増加 |
| **レム睡眠行動障害**（夢を見ている浅い眠り＝レム睡眠のときに、大声を出したり手足を動かしたりする） | ノンレム睡眠 |
| **誤嚥性肺炎**の合併が多い | 脳梗塞が原因・初発が記憶障害 |
| 幻視は**部屋を明るくすると消える**ことがある | 抗精神病薬が多く使われる（薬に過敏で副作用が出やすい） |

**幻視への対応**：ふりかけを「アリがたかっている」と言う → **普通のご飯に取り替えて**勧める。「アリはいません」と否定するのは×。

## ③ 前頭側頭型・血管性・クロイツフェルト・ヤコブ病

### 前頭側頭型認知症

- **社会のルールや常識がわからなくなる**、**常同行動**（同じ時間に同じ行動）
- 対応：常同行動は止めるのではなく、**本人と周囲が納得できる生活習慣**にする
- ×の選択肢：「物忘れの自覚」「幻視」「急速な進行」「エピソード記憶障害が初期から」

### 血管性認知症

- 脳梗塞・脳出血が原因。**男性**に多く、**階段状**に悪化
- 記憶障害にムラがある（**まだら認知症**）、**感情失禁**、**病識がある**ことが多い
- **初期にめまい**を自覚することがある
- 危険因子：**メタボリックシンドローム**・高血圧・糖尿病などの生活習慣病
- ×：「女性に多い」「ゆっくり少しずつ進行」「人格変化が多い」「85歳以上に多い」

### クロイツフェルト・ヤコブ病

- **プリオン病**。進行が速く、**1年以内の死亡例も多い**
- ×：有病率1万人に1人（実際は**約100万人に1人**）、緩やかに進行、致死率は低い、不随意運動を伴わない

## ④ 治療で改善が期待できる認知症

| | **慢性硬膜下血腫** | **正常圧水頭症** |
|---|---|---|
| きっかけ | **頭部の打撲**（転倒など）。**抗凝固薬**の使用もリスク | はっきりしない |
| 発症 | 打撲から**1〜3か月後**に物忘れ・ふらつき・麻痺 | — |
| 症状 | 物忘れ・歩行障害・片麻痺 | **歩行障害・尿失禁・認知障害**の3つ |
| 診断 | **頭部CT** | 頭部CT・MRI |
| 治療 | **外科的手術**（血腫を取り除く） | **シャント手術**（たまった脳脊髄液を管でおなかなどに流す） |

> 「早期発見で改善が可能」・「外科的手術で治療が可能」と聞かれたら、この2つから選びます。

そのほか、治療で改善が期待できるもの：**甲状腺機能低下症**、**ビタミンB12不足**。アルコール多飲などによる**ビタミンB1不足**は**ウェルニッケ脳症**を起こし、記憶障害と**作話**（記憶の穴を作り話でうめる）が目立つ**コルサコフ症候群**に進むことがあります。
