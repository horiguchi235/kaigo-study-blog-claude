**この記事のポイント**

1. 疾患ごとの「顔」を1つずつ：**アルツハイマー＝もの盗られ妄想**、**レビー＝幻視とパーキンソン症状**、**前頭側頭＝人格変化・常同行動**、**血管性＝感情失禁・段階的悪化**、**クロイツフェルト・ヤコブ病（CJD）＝急速進行**。
2. 事例問題は「**頭を打って1〜3か月後**」＝**慢性硬膜下血腫**、「**歩行障害・尿失禁・物忘れ**」＝**正常圧水頭症**。どちらも**治療で改善**する。
3. 原因で多い順は**アルツハイマー型 → 血管性**。

---

## 原因疾患の割合と分類

- 割合（2013年の都市部の調査）：**アルツハイマー型 67.6％**、**血管性 19.5％**、**レビー小体型 4.3％**（パーキンソン病による認知症を含む）、混合型 3.3％、前頭側頭型 1.0％ など。上位3つを「**三大認知症**」と呼びます
- 原因による分け方：
  - 脳の神経細胞が変性して減るもの：アルツハイマー型・レビー小体型・前頭側頭型
  - 脳血管疾患：脳梗塞・脳出血
  - 外傷：慢性硬膜下血腫・頭部外傷の後遺症
  - 感染：クロイツフェルト・ヤコブ病・髄膜炎・梅毒・エイズ
  - 内分泌・代謝：甲状腺機能低下症・ビタミンB12不足
  - 中毒：アルコール
  - 腫瘍：脳腫瘍
  - その他：正常圧水頭症
- 治療で改善が期待できるのは、慢性硬膜下血腫・甲状腺機能低下症・正常圧水頭症の一部など（→ ④）

## 早見表

| 疾患 | 主に障害される脳の場所 | 性別・進行 | 特徴的な症状 |
|---|---|---|---|
| **アルツハイマー型** | **海馬**（側頭葉の内側）から全体へ萎縮 | **女性**に多い／**ゆるやか**に進行 | 初期から**近時記憶障害**、**もの盗られ妄想**、取り繕い |
| **レビー小体型** | 後頭葉（見る働き）など | 男性にやや多い | **具体的な幻視**、**パーキンソン症状**（小刻み歩行・転倒）、**認知機能の変動**、レム睡眠行動障害、**起立性低血圧** |
| **前頭側頭型**（ピック病など） | **前頭葉・側頭葉** | 比較的若い | **人格変化**、**脱抑制**（万引きなど）、**常同行動**、甘い物へのこだわり。記憶は比較的保たれる |
| **血管性** | 脳梗塞・脳出血が起きた場所 | **男性**に多い／**階段状**に悪化 | **まだら認知症**、**感情失禁**、**抑うつ**、麻痺、初期に**めまい** |
| <strong>クロイツフェルト・ヤコブ病（CJD）</strong> | 脳全体 | — | **プリオン病**（異常なたんぱく質プリオンが原因）、**急速に進行**し**1年以内の死亡**も多い、ミオクローヌス（手足がピクッと動く不随意運動） |

過去問で「疾患とBPSDの正しい組合せ」が問われ、正解は**血管性 ― 抑うつ**でした。幻視はレビー、人格変化は前頭側頭、もの盗られ妄想はアルツハイマーです。

## ① アルツハイマー型認知症

**脳の変化**：アミロイドβがたまってできる「**老人斑**」と、神経細胞の中にできる糸くずのような「**神経原線維変化**」が増え、神経細胞が減って脳が縮みます。記憶の中心の**海馬**から始まり、側頭葉・頭頂葉、やがて前頭葉へ広がります。体を動かすはたらきは**末期まで比較的保たれます**。

- **巣症状**＝脳の傷んだ場所のはたらきが失われて起こる症状（失語・失行・失認・失計算）。アルツハイマー型でも見られます
- **遂行機能障害**は、記憶障害とならんで**初期から**出ます（料理・家計が難しくなる理由）
- **取り繕い**＝できないことを隠すように、もっともらしい返事でその場を合わせること。アルツハイマー型でよく見られます

| ○ | × |
|---|---|
| **女性**に多い | 麻痺がある・階段状に悪化・多発性脳梗塞（血管性の特徴） |
| 初期から**記憶障害**（**近時記憶・エピソード記憶**） | 古い記憶から障害される／若い頃のことを忘れる |
| 初期に**もの盗られ妄想**。**不安**から生じる | 説明すれば誤りに気づく・現実にいない人が犯人・幻視が原因 |
| 軽度で**炊事の自立が困難**（IADL＝買い物・調理・金銭管理など道具を使う生活動作の低下） | 小刻み歩行・嚥下障害・尿失禁（いずれも後期） |
| 見当識障害は**初期〜中期**から | 中期以降／ADL（食事・排泄など毎日の基本動作）障害は重度期以降 |
| アミロイドβ（脳にたまる異常なたんぱく質）の沈着は**発症の何年も前**から始まる | 沈着するとすぐ発症 |

> FAST（アルツハイマー型の進み具合を7段階で見る物差し）：料理・家計・買い物が難しいのは**FAST 4＝軽度**、季節や場面に合った**服を選べず介助が必要**になると**FAST 5＝中等度**。

### 進行による変化

アルツハイマー型は、おおむね**8年**（3〜20年と幅がある）かけて進みます。

| 時期（FAST） | 本人の様子 |
|---|---|
| 1〜3 | 1＝正常、2＝年相応の物忘れ、3＝境界（仕事の複雑な作業でつまずく） |
| 軽度（FAST 4） | **近時記憶障害**・もの盗られ妄想・不安や抑うつ。料理・家計・買い物（IADL）が難しい |
| 中等度（FAST 5） | 見当識障害が進み、迷子・帰宅願望。服を選べない、入浴に説得が必要 |
| やや高度（FAST 6） | 着替え・入浴に介助が必要。トイレの水を流し忘れる、**尿失禁 → 便失禁** |
| 高度（FAST 7） | 話せる言葉が数語 → 1語。歩けない → 座っていられない → 笑えない。最後は寝たきり |

- BPSDは**中等度**で目立ちやすく、重度になると言葉と活動が減り、どの型でも**アパシー**（無関心）が前に出ます。そのため、妄想や探し歩きなどは、重度になると目立たなくなることが多いです
- 認知症高齢者の日常生活自立度の **Ⅳ**（頻繁に支障があり、常に介護が必要）は、この重度の時期にあたります（→ [若年性認知症・評価スケール・薬・予防](../ninchisho-03-hyoka/)）
- 亡くなる原因は、肺炎などの**感染症**や心不全が多いです

## ② レビー小体型認知症

- **レビー小体**＝神経細胞の中にできる、異常なたんぱく質（αシヌクレイン）のかたまりです
- 脳幹にたまると、**ドーパミン**をつくる神経細胞が減り、パーキンソン病と同じ手足のふるえ（振戦）・筋肉のこわばり・小刻み歩行・前かがみの姿勢が出ます。大脳にたまると、幻視や認知の変動が出ます
- 治療：認知機能には**ドネペジル**、パーキンソン症状には**レボドパ**などの抗パーキンソン病薬。**抗精神病薬にはとても敏感**で、少量でも動けなくなる・飲み込めなくなることがあります
- 立ちくらみ（起立性低血圧）による**失神**、便秘など自律神経の症状もあるので、**転倒**に注意します

| ○ よく出る症状 | × 出ない・誤り |
|---|---|
| **鮮明で具体的な幻視**（「窓のそばに知らない人が立っている」） | 幻視はあいまい |
| **パーキンソン症状**：**最初の一歩が出にくく小刻み**に歩く、**動作が遅く転倒しやすい** | 運動機能障害は見られない |
| 認知機能・症状の**日内変動** | **初期からの人格変化** |
| **自律神経症状**＝**起立性低血圧** | 幻聴・意味性失語・食欲増加 |
| **レム睡眠行動障害**（夢を見ている浅い眠り＝レム睡眠のときに、大声を出したり手足を動かしたりする） | ノンレム睡眠 |
| **誤嚥性肺炎**の合併が多い | 脳梗塞が原因・初発が記憶障害 |
| 幻視は**部屋を明るくすると消える**ことがある | 抗精神病薬が多く使われる（薬に過敏で副作用が出やすい） |

**幻視への対応**：ふりかけを「アリがたかっている」と言う → **普通のご飯に取り替えて**勧める。「アリはいません」と否定するのは×。

## ③ 前頭側頭型・血管性・クロイツフェルト・ヤコブ病

### 前頭側頭型認知症

- **社会のルールや常識がわからなくなる**、**常同行動**（同じ時間に同じ行動）
- **65歳未満の初老期**に発症することが多い。見当識や道順の記憶は保たれ、**迷子になりにくい**
- 決まった物ばかり食べる・甘い物を好むなど、食べ方が変わる
- **脱抑制**＝その場にふさわしくない行動を抑えられないこと（万引き・無断で物を取る）
- 側頭葉の萎縮が強いと、物の名前や言葉の意味がわからなくなる（**意味性失語**）。これは前頭側頭型の症状で、レビー小体型ではない
- 原因に効く薬はない。対応：常同行動は止めるのではなく、**本人と周囲が納得できる生活習慣**にする（生活のリズムに組み込む）
- ×の選択肢：「物忘れの自覚」「幻視」「急速な進行」「エピソード記憶障害が初期から」

### 血管性認知症

- 脳梗塞・脳出血が原因。**男性**に多く、**階段状**に悪化
- 記憶障害にムラがある（**まだら認知症**）、**感情失禁**、**病識がある**ことが多い
- **初期にめまい**を自覚することがある
- 危険因子：**メタボリックシンドローム**・高血圧・糖尿病などの生活習慣病
- ×：「女性に多い」「ゆっくり少しずつ進行」「人格変化が多い」「85歳以上に多い」
- 型：大きな脳梗塞・脳出血の発作の**直後から**起こる型と、小さな脳梗塞をくり返して**段階的に**進む型（多発性脳梗塞による認知症）がある。後者は本人も気づかないうちに進み、頭が重い・めまい・もの忘れから始まることが多い

**アルツハイマー型と血管性で、早見表にない違い**

| | アルツハイマー型 | 血管性 |
|---|---|---|
| 多い年齢 | 70歳以上 | 60〜70歳代 |
| 初期の自覚 | ほとんどない（病識がない） | 頭が重い・頭痛・めまい・もの忘れ（病識があり、抑うつになりやすい） |
| 神経症状 | 末期まで少ない | 片麻痺・言語障害などが初期から |
| 人格 | 比較的保たれ、進むと変化 | 比較的保たれる |
| 治療の中心 | 抗認知症薬・薬を使わないケア | 高血圧・糖尿病などの管理で**再発を防ぐ**（原因を治す薬はない） |

### クロイツフェルト・ヤコブ病

- **プリオン病**。進行が速く、**1年以内の死亡例も多い**
- 50〜60歳代に多く、症状が出てから半年〜1年ほどで寝たきり・死亡に至ることが多い。BSE（牛海綿状脳症）の牛から感染した例（変異型）もある。治療法はない
- ×：有病率1万人に1人（実際は**約100万人に1人**）、緩やかに進行、致死率は低い、不随意運動を伴わない

## ④ 治療で改善が期待できる認知症

| | **慢性硬膜下血腫** | **正常圧水頭症** |
|---|---|---|
| きっかけ | **頭部の打撲**（転倒など）。**抗凝固薬**の使用もリスク | はっきりしない |
| 発症 | 打撲から**1〜3か月後**に物忘れ・ふらつき・麻痺 | — |
| 症状 | 物忘れ・歩行障害・片麻痺 | **歩行障害・尿失禁・認知障害**の3つ |
| 診断 | **頭部CT** | 頭部CT・MRI |
| 治療 | **外科的手術**（血腫を取り除く） | **シャント手術**（たまった脳脊髄液を管でおなかなどに流す） |

> 「早期発見で改善が可能」・「外科的手術で治療が可能」と聞かれたら、この2つから選びます。

脳は外側から**硬膜・くも膜・軟膜**の3枚の膜に包まれています。慢性硬膜下血腫は、いちばん外の**硬膜の下**に少しずつ血がたまり、脳を押す病気です。

そのほか、治療で改善が期待できるもの：**甲状腺機能低下症**、**ビタミンB12不足**。アルコール多飲などによる**ビタミンB1不足**は**ウェルニッケ脳症**を起こし、記憶障害と**作話**（記憶の穴を作り話でうめる）が目立つ**コルサコフ症候群**に進むことがあります。

慢性硬膜下血腫（chronic subdural hematoma）に関する次の記述のうち、最も適切なものを1つ選びなさい。

1. 運動機能障害が起こることは非常に少ない。
2. 頭蓋骨骨折を伴い発症する。
3. 抗凝固薬の使用はリスクとなる。
4. 転倒の後、2～3日で発症することが多い。
5. 保存的治療が第一選択である。
