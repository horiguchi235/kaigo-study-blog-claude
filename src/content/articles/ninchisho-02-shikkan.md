**この記事のポイント**

1. 疾患ごとの「顔」を1つずつ：**アルツハイマー＝もの盗られ妄想**、**レビー＝幻視とパーキンソン症状**、**前頭側頭＝人格変化・常同行動**、**血管性＝感情失禁・段階的悪化**、**CJD＝急速進行**。
2. 事例問題は「**頭を打って1〜3か月後**」＝**慢性硬膜下血腫**、「**歩行障害・尿失禁・物忘れ**」＝**正常圧水頭症**。どちらも**治療で改善**する。
3. 原因で多い順は**アルツハイマー型 → 血管性**。

---

## 早見表

| 疾患 | 性別・進行 | 特徴的な症状 |
|---|---|---|
| **アルツハイマー型** | **女性**に多い／**ゆるやか**に進行 | 初期から**近時記憶障害**、**もの盗られ妄想**、取り繕い |
| **レビー小体型** | 男性にやや多い | **具体的な幻視**、**パーキンソン症状**（小刻み歩行・転倒）、**認知機能の変動**、レム睡眠行動障害、**起立性低血圧** |
| **前頭側頭型** | 比較的若い | **人格変化**、**脱抑制**（万引きなど）、**常同行動**、甘い物へのこだわり。記憶は比較的保たれる |
| **血管性** | **男性**に多い／**階段状**に悪化 | **まだら認知症**、**感情失禁**、**抑うつ**、麻痺、初期に**めまい** |
| **クロイツフェルト・ヤコブ病** | — | **プリオン病**、**急速に進行**し**1年以内の死亡**も多い、ミオクローヌス（不随意運動） |

疾患とBPSDの組合せ：**血管性 ― 抑うつ**が正解。幻視はレビー、人格変化は前頭側頭、もの盗られ妄想はアルツハイマーです。

## ① アルツハイマー型認知症【認知症の理解】

| ○ | × |
|---|---|
| **女性**に多い | 麻痺がある・階段状に悪化・多発性脳梗塞（血管性の特徴） |
| 初期から**記憶障害**（**近時記憶・エピソード記憶**） | 古い記憶から障害される／若い頃のことを忘れる |
| 初期に**もの盗られ妄想**。**不安**から生じる | 説明すれば誤りに気づく・現実にいない人が犯人・幻視が原因 |
| 軽度で**炊事の自立が困難**（IADLの低下） | 小刻み歩行・嚥下障害・尿失禁（いずれも後期） |
| 見当識障害は**初期〜中期**から | 中期以降／ADL障害は重度期以降 |
| アミロイドβの沈着は**発症の何年も前**から始まる | 沈着するとすぐ発症 |

> FAST（アルツハイマー型の重症度）：料理・家計・買い物が難しいのは**軽度**、季節や場面に合った**服を選べず介助が必要**になると**中等度**（中等度）。

## ② レビー小体型認知症【認知症の理解】

| ○ よく出る症状 | × 出ない・誤り |
|---|---|
| **鮮明で具体的な幻視**（「窓のそばに知らない人が立っている」） | 幻視はあいまい |
| **パーキンソン症状**：**最初の一歩が出にくく小刻み**に歩く、**動作が遅く転倒しやすい** | 運動機能障害は見られない |
| 認知機能・症状の**日内変動** | **初期からの人格変化** |
| **自律神経症状**＝**起立性低血圧** | 幻聴・意味性失語・食欲増加 |
| **レム睡眠行動障害**（夢を見て大声・手足を動かす） | ノンレム睡眠 |
| **誤嚥性肺炎**の合併が多い | 脳梗塞が原因・初発が記憶障害 |
| 幻視は**部屋を明るくすると消える**ことがある | 抗精神病薬が多く使われる（薬に過敏で副作用が出やすい） |

**幻視への対応**：ふりかけを「アリがたかっている」と言う → **普通のご飯に取り替えて**勧める。「アリはいません」と否定するのは×。

## ③ 前頭側頭型・血管性・クロイツフェルト・ヤコブ病【認知症の理解】

### 前頭側頭型認知症

- **社会のルールや常識がわからなくなる**、**常同行動**（同じ時間に同じ行動）
- 対応：常同行動は止めるのではなく、**本人と周囲が納得できる生活習慣**にする
- ×の選択肢：「物忘れの自覚」「幻視」「急速な進行」「エピソード記憶障害が初期から」

### 血管性認知症

- 脳梗塞・脳出血が原因。**男性**に多く、**階段状**に悪化
- **初期にめまい**を自覚することがある
- 危険因子：**メタボリックシンドローム**・高血圧・糖尿病
- ×：「女性に多い」「ゆっくり少しずつ進行」「人格変化が多い」「85歳以上に多い」

### クロイツフェルト・ヤコブ病

- **プリオン病**。進行が速く、**1年以内の死亡例も多い**
- ×：有病率1万人に1人（実際は**約100万人に1人**）、緩やかに進行、致死率は低い、不随意運動を伴わない

## ④ 治療で改善が期待できる認知症【認知症の理解】

| | **慢性硬膜下血腫** | **正常圧水頭症** |
|---|---|---|
| きっかけ | **頭部の打撲**（転倒など）。**抗凝固薬**の使用もリスク | はっきりしない |
| 発症 | 打撲から**1〜3か月後**に物忘れ・ふらつき・麻痺 | — |
| 症状 | 物忘れ・歩行障害・片麻痺 | **歩行障害・尿失禁・認知障害**の3つ |
| 診断 | **頭部CT** | 頭部CT・MRI |
| 治療 | **外科的手術**（血腫を取り除く） | **シャント手術** |

> 「早期発見で改善が可能」・「外科的手術で治療が可能」と聞かれたら、この2つから選びます。

## ＋α もう一歩：実務者研修レベルで覚えたいこと

過去問にはまだ出ていないけれど、実務者研修の確認テストでよく問われる、関連して覚えておきたい知識です。

- **4大認知症の整理**：アルツハイマー型＝**海馬（側頭葉）周辺から萎縮**、近時記憶障害、ゆっくり進行し、重度では意思疎通が難しくなり寝たきりにも（前頭葉が萎縮するのは前頭側頭型）／**血管性＝高血圧・糖尿病などの生活習慣病が危険因子**、段階的に悪化、まだら症状／前頭側頭型（**ピック病**）＝**人格の変化・行動の異常・言語障害**、初期は記憶や知的機能が保たれやすい／**レビー小体型＝男性に多い**、幻視・パーキンソン症状で**転倒しやすい**・自律神経症状。
- **コルサコフ症候群**＝ビタミンB1欠乏（アルコール多飲など）による記憶障害と**作話**。
- **脳血管障害**：脳梗塞＝血管が詰まる／脳出血＝脳の中で出血／**くも膜下出血**＝主に脳動脈瘤の破裂で**突然の激しい頭痛**。麻痺などの局所症状はまれで、**消化管出血を合併**することがある。
- **神経の難病**：多系統萎縮症（**シャイ・ドレーガー症候群**など）＝パーキンソン症状・小脳失調・**自律神経障害**／**クロイツフェルト・ヤコブ病**＝プリオン病で急速に進む認知症。
