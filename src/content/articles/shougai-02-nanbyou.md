**この記事のポイント**

1. ALSは**運動神経だけ**が壊れる。**感覚・視力聴力・眼球運動・排泄・知能は保たれる**。出るのは**筋力低下・構音障害・嚥下障害・呼吸障害**。
2. パーキンソン病は**振戦・筋固縮・無動・姿勢保持障害**。進むと**誤嚥**に注意。
3. 高次脳機能障害は「**注意＝2つ同時ができない**」「**遂行機能＝計画して実行できない**」「**社会的行動＝感情が爆発**」で見分ける。

## ① 難病

**難病**＝原因がわからず、治療法が確立しておらず、まれな病気で、長期の療養が必要なもの（難病法の定義）。このうち医療費助成の対象になるのが**指定難病**で、**348疾病**。障害者総合支援法の障害福祉サービスの対象になる難病等は**376疾病**です（2025年4月から。それ以前は341・369）。制度は → 障害者総合支援法〔T07〕

### ALS（筋萎縮性側索硬化症）

**運動神経**が少しずつ壊れ、全身の筋肉がやせて力が入らなくなる病気。進むと呼吸筋が弱り、人工呼吸器を使うかどうかの選択が必要になります。コミュニケーションは文字盤・視線入力・意思伝達装置など。

| ○ 出る症状 | × 出にくい症状（4大陰性徴候） |
|---|---|
| **四肢の運動障害** | **感覚障害**（痛みはわかる） |
| **構音障害**（話しにくい） | **眼球運動障害**（目の動きで意思を伝えられる） |
| **嚥下障害** | **膀胱直腸障害**（失禁・便秘は出にくい） |
| **呼吸障害** | **褥瘡**（できにくい） |

ほかに、**視力・聴力・知能**も保たれやすい機能です。

> 進行したALSの人の状態として正しいのは「**身体の痛みがわかる**」。誤嚥せずに食べる・明瞭に話す・自分で痰を出す・箸を使う、はできなくなっています。

### パーキンソン病

| 症状 | 中身 |
|---|---|
| **安静時振戦** | **じっとしているとき**の手のふるえ（動くとおさまる） |
| **筋固縮** | 筋肉のこわばり |
| **無動・寡動** | 動きが少なく遅い。**仮面様顔貌**、小声 |
| **姿勢保持障害** | 立位で重心が傾く、**歩行中に止まる・向きを変えるのが難しい**、前傾姿勢 |
| 歩き方 | **すくみ足**・小刻み歩行・突進 |
| そのほか | **仮面様顔貌**（表情が乏しく、まばたきが減る）、便秘・起立性低血圧などの**自律神経症状**、役割を失うことによる孤立感・**抑うつ** |

**ホーエン・ヤール重症度分類**

| ステージ | 状態 |
|---|---|
| Ⅰ | 体の片側だけの症状 |
| Ⅱ | 両側に症状。姿勢保持障害なし |
| **Ⅲ** | **姿勢保持障害**（前傾・方向転換が不安定）が出るが、**ADLは自立** |
| Ⅳ | 日常生活に一部介助が必要（立つ・歩くのがやっと） |
| Ⅴ | 車いす・寝たきりで全面介助 |

> 難病の医療費助成の対象になるのは、パーキンソン病では原則として**ホーエン・ヤールⅢ度以上**（かつ生活機能障害度2度以上）。だからⅢの「姿勢保持障害が出る」が試験の分かれ目になります。

- ステージⅢの生活の注意：**誤嚥に気をつける**。サンダルは×、安静は×（動くことが大切）、薬の飲み忘れで2回分飲むのは×、便秘になりやすいので食物繊維は**とる**
- 全介助で食事に時間がかかり**かすれ声** → **誤嚥**に注意

### そのほかの難病

| 病気 | 特徴 |
|---|---|
| **脊髄小脳変性症** | **運動失調**（物をつかもうとすると手がふるえる・ふらつき・**ろれつが回らない**） |
| 多系統萎縮症 | パーキンソン症状が目立つ型、小脳症状（運動失調）が目立つ型、自律神経症状（起立性低血圧など）が目立つ型（シャイ・ドレーガー症候群）がある |
| **筋ジストロフィー** | **筋線維そのもの**が壊れる。デュシェンヌ型は男児に多い |
| **クローン病** | 口から肛門までの消化管に炎症 → **栄養障害** |
| 潰瘍性大腸炎 | 大腸の炎症。下痢・粘血便 |
| ベーチェット病 | 口の中のアフタ（口内炎）をくり返す |
| SLE（全身性エリテマトーデス） | 若い女性に多い。顔の**蝶形紅斑**・関節炎・腎障害 |
| ハンチントン病 | 遺伝性。自分の意思と関係なく体が勝手に動く（舞踏運動） |

**ふるえの見分け方**：**じっとしているとふるえる＝パーキンソン病**（安静時振戦）／**動こうとするとふるえる＝小脳の病気**（企図振戦。脊髄小脳変性症など）。

**動きの障害の見分け方**（第35回で直接問われた）

| 用語 | 意味 |
|---|---|
| 運動麻痺 | 神経の障害で、**力が入らない・動かせない** |
| **運動失調** | 力はあるのに、**動きの調整ができない**（ふらつき・企図振戦・ろれつ） |
| 筋固縮 | 筋肉がこわばり、動かすと抵抗がある（パーキンソン病） |
| 筋萎縮 | 筋肉がやせる（ALS・筋ジストロフィー） |
| 関節拘縮 | 関節がかたまって動く範囲がせまくなる |

## ② 高次脳機能障害と失語症

**原因**：脳血管障害・**脳外傷**・**脳炎**・低酸素脳症など、**後から脳が傷ついたこと**。ダウン症・アルツハイマー型認知症・自閉症・統合失調症は×。

<fig name="nou">

| 症状 | 中身・例 |
|---|---|
| 記憶障害 | 物の置き場所や約束を忘れる、新しいことを覚えられない |
| **注意障害** | **同時に2つ以上のことに気配りできない**、集中が続かない |
| **遂行機能障害** | **計画を立てて実行できない**、**決まった方法にこだわり、状況に応じた判断ができない** |
| **社会的行動障害** | **ちょっとしたことで感情を爆発させる**、依存的、こだわり |
| 失行 | 道具の使い方がわからない（歯ブラシ） |
| **半側空間無視** | 脳の損傷と反対側に気づかない。**右脳の損傷で左側**を無視することが多い。**片側の食べ残し**。**本人は気づいていない**。視野が欠ける**半盲とは別**（顔を動かしても気づかない） |

- 支援：**誰が関わっても同じ方法**で（混乱を防ぐ）。説明は短く、**メモ**や手順表を使う。

**認知症とのちがい**：症状の名前（記憶・注意・遂行機能）は認知症の中核症状と似ていますが、高次脳機能障害は**脳のけが・病気のあとに起こり、基本的に進行しない**（リハビリで改善することもある）。認知症は**少しずつ進行する**のが特徴です。

### 失語症

- 脳の言語中枢の障害。**構音障害（口や舌のまひ）や聴覚障害は含まない**
- <strong>運動性失語（ブローカ失語）</strong>＝前頭葉のブローカ野の障害で、わかるけれど話せない。<strong>感覚性失語（ウェルニッケ失語）</strong>＝側頭葉のウェルニッケ野の障害で、話せるけれど理解が難しい（上の図）
- **あいさつなど決まった言葉**は保たれやすい。単語より**長い文章**の理解が難しい
- 話しかけるときは**はっきり、ゆっくり、短く**。関わり方は → [失語症・構音障害の人とのコミュニケーション](../shougaicomm-01-gengo/)

## ひっかけパターン集（難病・高次脳で「ほぼ×」）

| 選択肢の表現 | なぜ× |
|---|---|
| ALSで感覚障害・眼球運動障害・失禁・褥瘡 | 現れにくい（4大陰性徴候） |
| 脊髄小脳変性症の手のふるえ＝安静時振戦 | 動こうとするとふるえる（企図振戦）。安静時振戦はパーキンソン病 |

| 半側空間無視に本人は気づいている | 気づいていない |
