**この記事のポイント**

1. ALSは**運動神経だけ**が壊れる。**感覚・視力聴力・眼球運動・排泄・知能は保たれる**。出るのは**筋力低下・構音障害・嚥下障害・呼吸障害**。
2. パーキンソン病は**振戦・筋固縮・無動・姿勢保持障害**。進むと**誤嚥**に注意。
3. 高次脳機能障害は「**注意＝2つ同時ができない**」「**遂行機能＝計画して実行できない**」「**社会的行動＝感情が爆発**」で見分ける。

## ① 難病【障害の理解】

### ALS（筋萎縮性側索硬化症）

**運動神経**が少しずつ壊れ、全身の筋肉がやせて力が入らなくなる病気。

| ○ 出る症状 | × 出にくい症状（保たれる機能） |
|---|---|
| **四肢の運動障害** | **感覚障害**（痛みはわかる） |
| **構音障害**（話しにくい） | **視力・聴力** |
| **嚥下障害** | **眼球運動**（目の動きで意思を伝えられる） |
| **呼吸障害** | **膀胱直腸障害**（失禁・便秘は出にくい） |
| — | 知的障害 |

> 進行したALSの人の状態として正しいのは「**身体の痛みがわかる**」。誤嚥せずに食べる・明瞭に話す・自分で痰を出す・箸を使う、はできなくなっています。

### パーキンソン病

| 症状 | 中身 |
|---|---|
| **安静時振戦** | じっとしているときの手のふるえ |
| **筋固縮** | 筋肉のこわばり |
| **無動・寡動** | 動きが少なく遅い。**仮面様顔貌**、小声 |
| **姿勢保持障害** | 立位で重心が傾く、**歩行中に止まる・向きを変えるのが難しい**、前傾姿勢 |
| 歩き方 | **すくみ足**・小刻み歩行・突進 |

**ホーエン・ヤール重症度分類**

| ステージ | 状態 |
|---|---|
| Ⅰ | 体の片側だけの症状 |
| Ⅱ | 両側に症状。姿勢保持障害なし |
| **Ⅲ** | **姿勢保持障害**（前傾・方向転換が不安定）が出るが、**ADLは自立** |
| Ⅳ | 日常生活に一部介助が必要 |
| Ⅴ | 車いす・寝たきりで全面介助 |

- ステージⅢの生活の注意：**誤嚥に気をつける**。サンダルは×、安静は×（動くことが大切）、薬の飲み忘れで2回分飲むのは×、便秘になりやすいので食物繊維は**とる**
- 全介助で食事に時間がかかり**かすれ声** → **誤嚥**に注意

### そのほかの難病

| 病気 | 特徴 |
|---|---|
| **脊髄小脳変性症** | **運動失調**（手のふるえ・ふらつき・**ろれつが回らない**） |
| **筋ジストロフィー** | **筋線維そのもの**が壊れる。デュシェンヌ型は男児に多い |
| **クローン病** | 口から肛門までの消化管に炎症 → **栄養障害** |
| 潰瘍性大腸炎 | 大腸の炎症。下痢・血便 |

## ② 高次脳機能障害と失語症【障害の理解】

**原因**：脳血管障害・**脳外傷**・**脳炎**・低酸素脳症など、**後から脳が傷ついたこと**。ダウン症・アルツハイマー型認知症・自閉症・統合失調症は×。

| 症状 | 中身・例 |
|---|---|
| 記憶障害 | 物の置き場所や約束を忘れる、新しいことを覚えられない |
| **注意障害** | **同時に2つ以上のことに気配りできない**、集中が続かない |
| **遂行機能障害** | **計画を立てて実行できない**、**決まった方法にこだわり、状況に応じた判断ができない** |
| **社会的行動障害** | **ちょっとしたことで感情を爆発させる**、依存的、こだわり |
| 失行 | 道具の使い方がわからない（歯ブラシ） |
| **半側空間無視** | 脳の損傷と反対側（多くは**左側**）に気づかない。**片側の食べ残し**。**本人は気づいていない**。視野が欠ける**半盲とは別**（顔を動かしても気づかない） |

### 失語症

- 脳の言語中枢の障害。**構音障害（口や舌のまひ）や聴覚障害は含まない**
- **あいさつなど決まった言葉**は保たれやすい。単語より**長い文章**の理解が難しい
- 話しかけるときは**はっきり、ゆっくり、短く**

## ③ 高次脳機能障害・パーキンソン病・ALSなど

- **パーキンソン病の症状**：4大症状（安静時振戦・筋固縮・無動・姿勢保持障害）のほか、**仮面様顔貌（表情が乏しく、まばたきが減る）**、すくみ足・小刻み歩行、便秘・起立性低血圧などの自律神経症状。**役割を失うことによる孤立感・抑うつ**にも配慮。
- **多系統萎縮症**には、パーキンソン症状が目立つ**線条体黒質変性症**、小脳症状が目立つオリーブ橋小脳萎縮症、自律神経症状が目立つ**シャイ・ドレーガー症候群**がある。
- **ベーチェット病**＝口の中のアフタ（口内炎）が代表的な症状の難病。
- **高次脳機能障害**：記憶障害・**注意障害**（ぼんやり、2つのことを同時にできない）・**遂行機能障害**（段取りできない）・**社会的行動障害**（感情のコントロールが難しい）。**半側空間無視**は**右脳の損傷で左側**を無視することが多い。支援は**誰が関わっても同じ方法**で、説明は短くメモに。
- **パーキンソン病の重症度（ホーエン・ヤール）**：Ⅰ＝片側のふるえ、Ⅱ＝両側、Ⅲ＝**小刻み歩行・姿勢の不安定（介助なしで生活可）**、Ⅳ＝立つ・歩くのが難しい、Ⅴ＝車いす・寝たきり。
- **ALS**：運動神経だけが侵され、**感覚・知能・眼球運動・排泄は保たれやすい**。進むと呼吸筋の低下で人工呼吸器。コミュニケーションは文字盤・視線入力など。
- **SLE（全身性エリテマトーデス）**＝若い女性に多い、顔の**蝶形紅斑**・関節炎・腎障害。**潰瘍性大腸炎**＝粘血便・下痢。**ハンチントン病**＝遺伝性、勝手に体が動く（舞踏運動）。

## ひっかけパターン集（難病・高次脳で「ほぼ×」）

| 選択肢の表現 | なぜ× |
|---|---|
| ALSで感覚障害・眼球運動障害・失禁 | 保たれる |
| ALSは免疫疾患・振戦が主症状 | 運動神経の病気（振戦はパーキンソン病） |
| パーキンソン病は安静にして過ごす | 動いて機能を保つ |
| 筋ジストロフィーは運動神経の変性 | 筋線維そのものの変性 |
| 半側空間無視に本人は気づいている | 気づいていない |
| 構音障害は失語症に含まれる | 別のもの |
