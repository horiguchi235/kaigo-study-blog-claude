## この記事で対策できる科目

| 科目 | 過去15年の出題数 | この記事の章 |
|---|---|---|
| 障害の理解 | 23問 | ①難病 ②高次脳機能障害・失語症 |

**結論を3行で**

1. ALSは**運動神経だけ**が壊れる。**感覚・視力聴力・眼球運動・排泄・知能は保たれる**。出るのは**筋力低下・構音障害・嚥下障害・呼吸障害**。
2. パーキンソン病は**振戦・筋固縮・無動・姿勢保持障害**。進むと**誤嚥**に注意。
3. 高次脳機能障害は「**注意＝2つ同時ができない**」「**遂行機能＝計画して実行できない**」「**社会的行動＝感情が爆発**」で見分ける。

## ① 難病【障害の理解】

### ALS（筋萎縮性側索硬化症）

**運動神経**が少しずつ壊れ、全身の筋肉がやせて力が入らなくなる病気。

| ○ 出る症状 | × 出にくい症状（保たれる機能） |
|---|---|
| **四肢の運動障害** | **感覚障害**（痛みはわかる）（第34・36回） |
| **構音障害**（話しにくい） | **視力・聴力**（第32回） |
| **嚥下障害**（第28・38回） | **眼球運動**（目の動きで意思を伝えられる） |
| **呼吸障害**（第29回） | **膀胱直腸障害**（失禁・便秘は出にくい） |
| — | 知的障害 |

> 進行したALSの人の状態として正しいのは「**身体の痛みがわかる**」（第36回）。誤嚥せずに食べる・明瞭に話す・自分で痰を出す・箸を使う、はできなくなっています。

### パーキンソン病

| 症状 | 中身 |
|---|---|
| **安静時振戦** | じっとしているときの手のふるえ |
| **筋固縮** | 筋肉のこわばり |
| **無動・寡動** | 動きが少なく遅い。**仮面様顔貌**、小声 |
| **姿勢保持障害** | 立位で重心が傾く、**歩行中に止まる・向きを変えるのが難しい**（第34回）、前傾姿勢 |
| 歩き方 | **すくみ足**・小刻み歩行・突進（第28回） |

**ホーエン・ヤール重症度分類**

| ステージ | 状態 |
|---|---|
| Ⅰ | 体の片側だけの症状 |
| Ⅱ | 両側に症状。姿勢保持障害なし |
| **Ⅲ** | **姿勢保持障害**（前傾・方向転換が不安定）が出るが、**ADLは自立**（第32回） |
| Ⅳ | 日常生活に一部介助が必要 |
| Ⅴ | 車いす・寝たきりで全面介助 |

- ステージⅢの生活の注意：**誤嚥に気をつける**（第29回）。サンダルは×、安静は×（動くことが大切）、薬の飲み忘れで2回分飲むのは×、便秘になりやすいので食物繊維は**とる**
- 全介助で食事に時間がかかり**かすれ声** → **誤嚥**に注意（第37回）

### そのほかの難病

| 病気 | 特徴 |
|---|---|
| **脊髄小脳変性症** | **運動失調**（手のふるえ・ふらつき・**ろれつが回らない**）（第30・35回） |
| **筋ジストロフィー** | **筋線維そのもの**が壊れる（第33回）。デュシェンヌ型は男児に多い |
| **クローン病** | 口から肛門までの消化管に炎症 → **栄養障害**（第37回） |
| 潰瘍性大腸炎 | 大腸の炎症。下痢・血便 |

ALS（筋萎縮性側索硬化症）で出現しにくい症状として、適切なものはどれ？

1. 四肢の運動障害
2. 構音障害
3. 嚥下障害
4. 感覚障害
5. 呼吸障害

<details class="answer">
<summary>正解を見る</summary>

**正解：4**　ALSで壊れるのは運動神経だけなので、感覚は保たれます。口・のど・呼吸の筋肉も動かせなくなるため、2・3・5は出ます。

## ② 高次脳機能障害と失語症【障害の理解】

**原因**：脳血管障害・**脳外傷**・**脳炎**・低酸素脳症など、**後から脳が傷ついたこと**（第27回）。ダウン症・アルツハイマー型認知症・自閉症・統合失調症は×。

| 症状 | 中身・例 |
|---|---|
| 記憶障害 | 物の置き場所や約束を忘れる、新しいことを覚えられない |
| **注意障害** | **同時に2つ以上のことに気配りできない**（第28回）、集中が続かない |
| **遂行機能障害** | **計画を立てて実行できない**（第24・37回）、**決まった方法にこだわり、状況に応じた判断ができない**（第25回） |
| **社会的行動障害** | **ちょっとしたことで感情を爆発させる**（第30回）、依存的、こだわり |
| 失行 | 道具の使い方がわからない（歯ブラシ） |
| **半側空間無視** | 脳の損傷と反対側（多くは**左側**）に気づかない。**片側の食べ残し**（第34回）。**本人は気づいていない**。視野が欠ける**半盲とは別**（顔を動かしても気づかない） |

### 失語症（第24回）

- 脳の言語中枢の障害。**構音障害（口や舌のまひ）や聴覚障害は含まない**
- **あいさつなど決まった言葉**は保たれやすい。単語より**長い文章**の理解が難しい
- 話しかけるときは**はっきり、ゆっくり、短く**

<details>
<summary>✏️ 解いてみよう（第37回）</summary>

遂行機能障害の特徴として、最も適切なものはどれ？

1. ささいなことですぐに興奮して怒鳴る
2. 新しい知識を覚えることが難しい
3. ぼんやりして、周囲に注意を向け続けることが難しい
4. 行動を計画して実行することが難しい
5. 言葉の表出や理解が難しい

<details class="answer">
<summary>正解を見る</summary>

**正解：4**　1は社会的行動障害、2は記憶障害、3は注意障害、5は失語症です。
</details>
</details>

## ひっかけパターン集（難病・高次脳で「ほぼ×」）

| 選択肢の表現 | なぜ× |
|---|---|
| ALSで感覚障害・眼球運動障害・失禁 | 保たれる |
| ALSは免疫疾患・振戦が主症状 | 運動神経の病気（振戦はパーキンソン病） |
| パーキンソン病は安静にして過ごす | 動いて機能を保つ |
| 筋ジストロフィーは運動神経の変性 | 筋線維そのものの変性 |
| 半側空間無視に本人は気づいている | 気づいていない |
| 構音障害は失語症に含まれる | 別のもの |
