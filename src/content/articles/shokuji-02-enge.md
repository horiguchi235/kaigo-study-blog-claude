**この記事のポイント**

1. 5期は「**先行期（見て認識）→準備期（かむ）→口腔期（舌で送る）→咽頭期（ごくん）→食道期**」。目・認知症の問題は**先行期**。
2. 姿勢は「**足底を床、深く座って、顎を引く**」。テーブルは**肘がつく高さ**。
3. 介助は「**まず汁物で口を湿らす→ティースプーン1杯→口を閉じる→一口ごとに飲み込み確認**」。むせたら**咳を続けてもらう**。

## ① 摂食・嚥下の5期と誤嚥

| 期 | 何が起こる | 試験のキーワード |
|---|---|---|
| **先行期** | 食べ物を**目で見て認識**し、食べ方を判断 | **認知機能・視覚**の影響を受ける。**唾液分泌が増える** |
| 準備期 | **かんで**唾液と混ぜ、**食塊**をつくる | 食塊形成 |
| 口腔期 | **舌**で食塊を咽頭へ送る | 口唇ではなく舌 |
| **咽頭期** | **軟口蓋**が上がり鼻への道を閉じる → **喉頭蓋**が気管にふたをする → 食道へ | 嚥下反射。一瞬呼吸が止まる（嚥下性無呼吸） |
| 食道期 | **蠕動運動**で胃へ | **不随意**運動（自分の意思で動かせない） |

<fig name="enge">

- 誤嚥 ＝ 食べ物が**気管**に入ること
- 誤嚥を防ぐ部位 ＝ **喉頭蓋**。のどでは**気管が前（首の側）、食道が後ろ（背中側）**にあるので、飲み込む瞬間に喉頭蓋がふたをしないと、食べ物が気管に入ってしまう
- **眼鏡が壊れて**食事に時間がかかる、**献立を説明したら**食べ始めた認知症の人 → どちらも**先行期**
- 誤嚥のサイン：むせ・**ガラガラした湿った声**・口の中の食べ残し。高齢者は<strong>むせない誤嚥（不顕性誤嚥）</strong>も多く、寝ている間に唾液が気管に入ることもあります。発熱・痰が増える・なんとなく元気がない・食欲が落ちる、は**誤嚥性肺炎**のサインです

### 球麻痺と仮性球麻痺

「球」は脳の**延髄**のこと。延髄には飲み込みや発音をつかさどる中枢があります。

| 比べる点 | 球麻痺 | 仮性球麻痺 |
|---|---|---|
| 傷んだ場所 | **延髄そのもの** | 延髄より上（大脳の両側など）。延髄は無事 |
| 主な原因 | 延髄の脳梗塞、ALS（筋萎縮性側索硬化症）など | 脳血管障害のくり返し |
| 症状 | 飲み込み・発音の障害 | 同じく飲み込み・発音の障害 |

## ② 食事の姿勢と介助の基本

### 姿勢

| ○ | × |
|---|---|
| **足底を床**につける（車いすは**フットサポートから下ろす**。踏ん張れて飲み込みやすい） | かかとを浮かす |
| いすに**深く**座る | 浅く座る |
| **顎を引く**（やや前かがみ） | 顎を上げる・頭部を後屈・体幹を後ろに傾ける |
| テーブルは**肘がつき腕が自由に動く**高さ | テーブルと体の間を30cm離す |
| ずり落ち・首が後屈してむせる → **まず座位姿勢の調整** | 食事回数・量・食器を先に変える |
| 片麻痺で体が傾く → **クッションで姿勢保持** | 全介助にする・臥位で食べる |

- ベッド上で食べるときは、**背もたれを45〜60度**ほど起こし、顎を軽く引きます。嚥下障害が重い人は、医師や言語聴覚士の指示で30度ほどに起こし、首を前に曲げた姿勢をとることもあります
- 食堂は換気をし、**明るい照明**に（暗い照明は先行期で食べ物を認識しにくくなる）

### 介助の手順

1. 介護者は**座って**、利用者と**目線を合わせる**（立って介助は×）
2. 食事が楽しくなる**雰囲気**をつくる（会話を禁止・大音量のテレビは×）
3. 最初に**お茶や汁物で口を湿らせる**
4. 一口量は**ティースプーンに軽く1杯**。スプーンは**下から口元へ**運び、**舌の中央**に置く（奥に入れるは×）
5. 口に入れたら**口唇を閉じるよう声かけ**
6. **一口ごとに飲み込みを確認**（2〜3口ごとは×）
7. 話しかけるのは**口に入っていないとき**

### むせた・様子がおかしいとき

| 状態 | 見分け方 | ○ 対応 |
|---|---|---|
| **むせ** | 咳ができる・声が出る | **しっかり咳を続けてもらう**（お茶を飲ませる・上を向く・深呼吸は×） |
| **窒息** | 声も咳も出ない。のどを両手でつかむ（**チョークサイン**） | すぐに応援を呼び、**背部叩打法**や<strong>腹部突き上げ法（ハイムリック法）</strong>で取り除く |

- 箸が止まり、表情がこわばり呼吸が浅い → 医療職に報告しつつ**口腔の状況を観察**（窒息の確認）

## ③ 状態に応じた食事介助

<photo name="shokuji-02__jijogu-shokuji" caption="食事の自助具。**太柄スプーン**（握る力が弱い人）、**首の曲がるスプーン**、**ふちが立ち上がった皿**（すくいやすい）、**滑り止めマット**、**取っ手付きの吸い口コップ**。">

<photo name="shokuji-03__haizen" caption="右利きの人の基本の配膳。ご飯は左手前、汁物は右手前、主菜は右奥、副菜は左奥、箸は手前に箸先を左にして置く（時計に見立てるとご飯7時・汁物5時）。">

食事の**自助具**：**太柄スプーン**（握る力が弱い人）、**首の曲がるスプーン**（手首や腕が動きにくくても口に運びやすい）、**ふちが立ち上がった皿**（すくいやすい）、**滑り止めマット**（食器が動かない）、**取っ手付きの吸い口コップ**。

| 利用者の状態 | ○ 正解 | × よく出る不正解 |
|---|---|---|
| 嚥下機能の低下 | おやつは**プリン・ゼリー** | もなか・餅・カステラ・クッキー・だんご・ラスク・レモンジュース |
| 加齢で飲み込みにくい | **食前に嚥下体操**（首・肩・口・舌を動かす準備運動） | 食後に嚥下体操／細かく刻む（バラけてむせる）／リクライニングいす（体が後ろに倒れ顎が上がる） |
| 脳梗塞後の嚥下障害（在宅） | 肉・野菜・魚を**軟らかく調理** | 細かく刻む（バラけてむせやすい）／会話しながら |
| **右片麻痺** | **健側（左）から**口に入れ、**一口ごとに飲み込み確認** | 口の右側（麻痺側）に入れる／刻み食 |
| **視覚障害** | **クロックポジション**（食器の位置を時計の文字盤に見立てて「ご飯は7時、汁物は5時」と伝える）で説明 | — |
| **左半側空間無視**（脳の障害で左側の空間に注意が向かず、見落とす） | 食べる様子を観察して**食器の位置を変える** | 左側にトレーを置く |
| **パーキンソン病**（手の震え） | **片側の縁が高い皿** | 上半身を後ろに倒す |
| **前頭側頭型認知症**（行動の抑えがきかず、次々口に詰め込む） | 食器に**少量ずつ盛る** | 大きなスプーン・全部並べる |
| 構音障害（発音がうまくできない） | 食事中の会話は控えめに | 会話しながら食べるよう勧める |

- **アイスマッサージ**＝凍らせた綿棒などで、のどの奥を軽く刺激して飲み込む反射を起こしやすくする方法。**食前**に行います

### 食べやすい形・温度

| 誤嚥しやすい性質 | 例 |
|---|---|
| さらさら | 水・お茶・汁物 |
| ぱさぱさ | パン・カステラ・クッキー |
| くっつく | 餅・のり・もなか |
| ばらける | 刻み食・そぼろ・ナッツ |
| むせを誘う | 酸味の強いもの（レモンジュース・酢の物） |

- **誤嚥しにくい**＝ゼリー・プリン・ヨーグルト・**とろみのあるもの**・やわらかいもの。刻むだけではまとまらないので、とろみ・ゼリーで**まとまりとなめらかさ**を調整します
- 温度のめやす：**温かいものは60〜65℃、冷たいものは10〜15℃**。体温に近いと飲み込む反射が起きにくくなります

| 義歯の調整 | 歯科医師 |
| **食べ残しが目立つ** → 献立・調理 | **管理栄養士** |
