**結論を3行で**

1. 5期は「**先行期（見て認識）→準備期（かむ）→口腔期（舌で送る）→咽頭期（ごくん）→食道期**」。目・認知症の問題は**先行期**。
2. 姿勢は「**足底を床、深く座って、顎を引く**」。テーブルは**肘がつく高さ**。
3. 介助は「**まず汁物で口を湿らす→ティースプーン1杯→口を閉じる→一口ごとに飲み込み確認**」。むせたら**咳を続けてもらう**。

## ① 摂食・嚥下の5期と誤嚥【こころとからだのしくみ】

| 期 | 何が起こる | 試験のキーワード |
|---|---|---|
| **先行期** | 食べ物を**目で見て認識**し、食べ方を判断 | **認知機能・視覚**の影響を受ける。**唾液分泌が増える** |
| 準備期 | **かんで**唾液と混ぜ、**食塊**をつくる | 食塊形成 |
| 口腔期 | **舌**で食塊を咽頭へ送る | 口唇ではなく舌 |
| **咽頭期** | **軟口蓋**が上がり鼻への道を閉じる → **喉頭蓋**が気管にふたをする → 食道へ | 嚥下反射。一瞬呼吸が止まる（嚥下性無呼吸） |
| 食道期 | **蠕動運動**で胃へ | **不随意**運動（自分の意思で動かせない） |

<fig name="enge">

- 誤嚥 ＝ 食べ物が**気管**に入ること（第36回）
- 誤嚥を防ぐ部位 ＝ **喉頭蓋**（第27回）
- **眼鏡が壊れて**食事に時間がかかる（第33回）、**献立を説明したら**食べ始めた認知症の人（第38回） → どちらも**先行期**

軟口蓋が上がって鼻腔と咽頭が閉じ、次に喉頭が上がって喉頭蓋が閉じ、食塊が食道に運ばれる時期はどれ？

1. 先行期
2. 準備期
3. 口腔期
4. 咽頭期
5. 食道期

<details class="answer">
<summary>正解を見る</summary>

**正解：4**　鼻と気管の両方にふたをして、食べ物を食道だけに送るのが咽頭期です。ここがうまくいかないと誤嚥が起こります。

## ② 食事の姿勢と介助の基本【生活支援技術】

### 姿勢

| ○ | × |
|---|---|
| **足底を床**につける（車いすは**フットサポートから下ろす**）（第35・38回） | かかとを浮かす |
| いすに**深く**座る | 浅く座る |
| **顎を引く**（やや前かがみ） | 顎を上げる・頭部を後屈・体幹を後ろに傾ける |
| テーブルは**肘がつき腕が自由に動く**高さ（第32回） | テーブルと体の間を30cm離す |
| ずり落ち・首が後屈してむせる → **まず座位姿勢の調整**（第35回） | 食事回数・量・食器を先に変える |
| 片麻痺で体が傾く → **クッションで姿勢保持**（第25回） | 全介助にする・臥位で食べる |

### 介助の手順

1. 介護者は**座って**、利用者と**目線を合わせる**（立って介助は×）
2. 食事が楽しくなる**雰囲気**をつくる（会話を禁止・大音量のテレビは×）
3. 最初に**お茶や汁物で口を湿らせる**（第26回）
4. 一口量は**ティースプーンに軽く1杯**（第38回）。スプーンは**舌の中央**に置く（奥に入れるは×）
5. 口に入れたら**口唇を閉じるよう声かけ**（第24回）
6. **一口ごとに飲み込みを確認**（2〜3口ごとは×）
7. 話しかけるのは**口に入っていないとき**

### むせた・様子がおかしいとき

- むせ込んだ → **しっかり咳を続けてもらう**（第35回）。お茶を飲ませる・上を向く・深呼吸は×
- 箸が止まり、表情がこわばり呼吸が浅い → 医療職に報告しつつ**口腔の状況を観察**（窒息の確認）（第38回）

<details>
<summary>✏️ 解いてみよう（第35回）</summary>

利用者が食事中にむせ込んだときの介護として、最も適切なものはどれ？

1. 上を向いてもらう
2. お茶を飲んでもらう
3. 深呼吸をしてもらう
4. 口の中のものを飲み込んでもらう
5. しっかりと咳を続けてもらう

<details class="answer">
<summary>正解を見る</summary>

**正解：5**　むせ（咳）は気管に入りかけたものを出そうとする防御反応です。止めずに出し切ってもらいます。1〜4はどれも気管に入り込む危険を高めます。
</details>
</details>

## ③ 状態に応じた食事介助【生活支援技術】

| 利用者の状態 | ○ 正解 | × よく出る不正解 |
|---|---|---|
| 嚥下機能の低下 | おやつは**プリン・ゼリー**（第28・30・36回） | もなか・餅・カステラ・クッキー・だんご・ラスク・レモンジュース |
| 加齢で飲み込みにくい | **食前に嚥下体操**（第33回） | 食後に嚥下体操／細かく刻む／リクライニングいす |
| 脳梗塞後の嚥下障害（在宅） | 肉・野菜・魚を**軟らかく調理**（第34回） | 細かく刻む（バラけてむせやすい）／会話しながら |
| **右片麻痺** | **一口ごとに飲み込み確認**（第31回） | 口の右側（麻痺側）に入れる／刻み食 |
| **視覚障害** | **クロックポジション**で説明（第27回） | — |
| **左半側空間無視** | 食べる様子を観察して**食器の位置を変える**（第32回） | 左側にトレーを置く |
| **パーキンソン病**（手の震え） | **片側の縁が高い皿**（第37回） | 上半身を後ろに倒す |
| **前頭側頭型認知症**（次々口に詰め込む） | 食器に**少量ずつ盛る**（第37回） | 大きなスプーン・全部並べる |
| 構音障害 | 食事中の会話は控えめに | 会話しながら食べるよう勧める |

| 箸・スプーンの動作 | 作業療法士 |
| 嚥下訓練 | 言語聴覚士 |
| 義歯の調整 | 歯科医師 |
| **食べ残しが目立つ** → 献立・調理 | **管理栄養士**（第34・36回） |

左半側空間無視のある利用者の食事介護として、最も適切なものはどれ？

1. 利用者の左側にトレーを置く
2. トレーの右側に印をつける
3. クロックポジションに従って配膳する
4. 食べる様子を観察して、適宜食器の位置を変える
5. 利用者の右側にあるテレビをつけておく

**正解：4**　左側にある料理に気づかず残してしまうので、様子を見て食器を右側（見える側）へ動かします。3は視覚障害の人への方法です。
