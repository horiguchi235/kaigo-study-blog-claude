**結論を3行で**

1. 上田敏の障害受容は「**ショック → 否認 → 混乱 → 解決への努力 → 受容**」。怒り・自責は**混乱期**、**価値観の転換**は**受容期**。
2. **ストレングス＝本人の強さを生かす**、**エンパワメント＝本人が自分の力に気づき課題に向かう**。
3. 本人への関わりは「**できることに目を向ける**」「**本人が決めて実行する**」。叱る・強く指示する・代わりに決める・できることまで手伝うは×。

## ① 障害受容の過程【障害の理解】

### 上田敏の5段階

| 段階 | 様子 | 試験に出た例 |
|---|---|---|
| ① **ショック期** | 受傷直後。**現実を実感できない**。意外に平静なことも（第29・31回） | — |
| ② 否認期 | 障害を**認めない**、「元に戻る」と信じる | 「自分には障害はない」 |
| ③ **混乱期** | 否認できなくなり、**怒り・恨み・抑うつ・自責** | 失明は避けられないと言われ、**周囲に怒りをぶつけ、壁に頭を打ちつける**（第32回） |
| ④ 解決への努力期 | **できることに目を向け**、前向きに努力する | — |
| ⑤ **受容期** | **障害に対する価値観が転換**し、積極的な生活態度に。新しい役割を見つける（第35回） | **できることに目を向けて行動する**（第36回） |

### 適応機制（障害の理解で出る形）

| 機制 | 意味 |
|---|---|
| **抑圧** | 認めたくない欲求や不安を**意識の下に押しとどめる**（第25回） |
| **昇華** | すぐに実現できない欲求を**価値ある行為に置き換える**（第27回） |
| **退行** | **発達の未熟な段階に後戻り**して自分を守る（第30回） |
| 合理化 | 都合のよい理由で自分を正当化 |
| 同一化 | 名声や権威に自分を近づける |
| 逃避 | つらい現実から逃げる |

<details>
<summary>✏️ 解いてみよう（第32回・事例）</summary>

糖尿病性網膜症で眼底出血をくり返していた56歳の男性。医師から失明は避けられないと説明された後、周囲に怒りをぶつけたり、壁に頭を打ちつけたりするようになった。障害受容の状況として最も適切なものはどれ？

1. ショックではあるが、不安はそれほど強くない
2. 自分には障害はないと否認する
3. 前向きに自己努力を図ろうとする
4. 否認ができずに混乱する
5. 新しい価値観や役割を見いだす

<details class="answer">
<summary>正解を見る</summary>

**正解：4**　事実を否定しきれなくなり、怒りや自傷として気持ちがあふれ出ている「混乱期」です。1はショック期、2は否認期、3は解決への努力期、5は受容期です。
</details>
</details>

## ② 本人への関わり・状態別の留意点【障害の理解】

### 支援の考え方

| 用語 | 意味 | × と混同しやすいもの |
|---|---|---|
| **ストレングス** | 本人の**特性や強さ**を見つけて**生かす**支援（第35回） | ノーマライゼーション（障害のない人と同じ生活条件） |
| **エンパワメント** | 本人が**自らの能力や長所に気づき**、課題に対応する（第37回） | 専門職主導で受け身に支援 |
| **自立生活運動（IL運動）** | 1960年代アメリカ。**自分で意思決定して生活する**ことが自立（第35回） | リハビリテーション（全人間的復権）／アドボカシー（権利の代弁） |

### 場面別の関わり

| 場面 | ○ 正解 | × |
|---|---|---|
| 頸髄損傷で四肢麻痺、リハビリをやめ周囲にあたる（混乱期）（第34回） | **できることに目を向けられるよう**支援 | 歩けるよう訓練を続けさせる／近寄らない／厳しく注意／できることも手伝う |
| 脳梗塞で左片麻痺、病室に閉じこもる（第31回） | **心理カウンセリング** | 利き手の交換・階段訓練・義足 |
| うつ病で「母親失格」と自分を責める（第25回） | 「**子どもの世話ができないのは、つらいですね**」 | 励ます・旅行を勧める・家事を頑張らせる |
| 統合失調症で就労を考え始めた（第35回） | **本人が物事を決め、実行できる**ように関わる | あいまいな説明・代理で手続き・強く指示 |
| 高次脳機能障害ですぐ怒り出す（社会的行動障害）（第38回） | 感情が落ち着くよう**場面や話題を変える** | 同じ質問に一度だけ答える・その都度強く注意・できないことを指摘 |

### 病気・状態ごとの生活の注意

| 状態 | ○ 正解 |
|---|---|
| **ALS**、体を起こすと血圧が下がり息苦しい、「何もしたくない」（第26回） | **安楽な体位**を工夫する（治療・呼吸器を勧めるのは医療職） |
| **COPD**（第26回） | 着替えで**腕を高く上げない**、ぬるめの湯、洋式トイレ、**高カロリー**の食事、息を止めない |
| **上肢リンパ浮腫**（第27回） | **体重の増加を防ぐ**。庭仕事は手袋、患側で血圧を測らない、サウナ・きつい肌着は× |
| **糖尿病性網膜症**で視覚障害、末梢神経障害あり（第36回） | **足先の傷や壊疽**に注意（感覚が鈍く見えないので気づかない） |
