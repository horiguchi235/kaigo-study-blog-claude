**この記事のポイント**

1. ノーマライゼーションは**デンマークの1959年法**から。日本では**1981年の国際障害者年**を機に広まった。
2. ICFは「**できること＝活動**、**社会での役割＝参加**」。福祉用具を使って料理ができる＝**活動**。
3. **身体障害者＝手帳を持つ18歳以上**。**知的障害者は知的障害者福祉法に定義がない**。

## ① 理念・ICF・リハビリテーション【障害の理解】

### ノーマライゼーションと日本の流れ

| ○ | × |
|---|---|
| **デンマーク**の「1959年法」で初めて法律に（バンク-ミケルセン） | スウェーデン・アメリカ・イギリス |
| **国際障害者年（1981年）**を機に、日本に**ノーマライゼーションの理念が浸透** | 弱者として保護する見方が広まった／身体障害者福祉法の制定 |
| 障害者基本計画（2002年）の理念：**リハビリテーション**と**ノーマライゼーション** | インクルージョン・バリアフリー |

### ICF（国際生活機能分類）

| 例 | 分類 |
|---|---|
| 右片麻痺があるが**福祉用具を使って食事を作れる** | **活動** |
| 義足で歩ける | 活動 |
| 尿失禁が心配でゲートボール大会に**出ない** | **参加制約** |
| 調理や掃除ができない | **活動制限** |
| 盲導犬を理由に結婚式への出席を断られる | **参加制約**（環境因子の影響） |

### リハビリテーションの分野

| 分野 | 例 |
|---|---|
| **医学的** | 機能訓練、**利き手の交換** |
| 職業的 | 職業訓練・就労支援 |
| 教育的 | 特別支援教育 |
| 社会的 | 社会生活力を高める支援 |

## ② 障害の法的定義・手帳・関連制度【障害の理解／社会の理解】

### 法的定義

| ○ | × |
|---|---|
| 身体障害者福祉法の身体障害者＝**身体障害者手帳の交付を受けた18歳以上** | — |
| **知的障害者福祉法には知的障害者の定義がない** | 知的障害者福祉法に定義されている |
| 精神保健福祉法の精神障害者には**知的障害者も含まれる** | 含まれていない |
| 障害者基本法で**発達障害は精神障害に含まれる** | 含まれていない |
| 障害児は**児童福祉法**で定義 | 障害者基本法で定義 |

### 身体障害の種類

視覚障害・聴覚または平衡機能障害・音声言語そしゃく機能障害・肢体不自由・**内部障害**（心臓・腎臓・**呼吸器**・膀胱直腸・小腸・HIV免疫・肝臓）。

> 嚥下障害は「聴覚」ではなく音声言語そしゃく機能、構音障害は「肢体不自由」ではなく音声言語機能、半側空間無視は視覚障害ではなく高次脳機能障害です。

### 聴覚障害

| ○ | × |
|---|---|
| **要約筆記**で意思疎通を補う | 手話は意思の伝達に役立たない |
| 手帳の対象は**両耳70dB以上** | 40dBで交付 |
| フラッシュベル＝音を**光で知らせる** | 音を増幅する |
| 「ろう」＝**重度**の聴覚障害 | 軽度を「ろう」という |

### そのほか

- 身体障害者手帳所持者の情報入手手段は**テレビ**が最多（2016年調査）
- **精神保健福祉法の入院形態**

| 入院形態 | 中身 |
|---|---|
| 任意入院 | **本人の同意**による |
| 措置入院 | 自傷他害のおそれ。**精神保健指定医2名**の診察で**都道府県知事**が決定 |
| **緊急措置入院** | 急いでいて措置入院の手続きがとれないとき。指定医1名・**72時間以内** |
| 医療保護入院 | 本人の同意がなく、**家族等の同意**による |
| 応急入院 | 家族等の同意も得られないとき。**72時間以内** |

- 法定後見の成年後見人等を選ぶのは**家庭裁判所**

ICFで次の状態を定義した場合、正しいものはどれ？

1. 片足を切断しても義足で歩けるのは「参加」である
2. 右片麻痺があるが福祉用具を使って食事を作れるのは「活動」である
3. 尿失禁が心配でゲートボール大会への出場を控えるのは「活動制限」である
4. 調理や掃除などの生活行為ができなくなるのは「参加制約」である
5. 盲導犬の利用者が結婚式への出席を断られるのは「活動制限」である

<details class="answer">
<summary>正解を見る</summary>

**正解：2**　一つひとつの生活行為ができる・できないは「活動（活動制限）」、社会の場面に加われる・加われないは「参加（参加制約）」です。1は活動、3と5は参加制約、4は活動制限です。
