**この記事のポイント**

1. ノーマライゼーションは**デンマークの1959年法**から。日本では**1981年の国際障害者年**を機に広まった。
2. ICFは「**できること＝活動**、**社会での役割＝参加**」。福祉用具を使って料理ができる＝**活動**。
3. **身体障害者＝手帳を持つ18歳以上**。**知的障害者は知的障害者福祉法に定義がない**。

## ① 理念・ICF・リハビリテーション

### ノーマライゼーションと日本の流れ

| ○ | × |
|---|---|
| **デンマーク**の「1959年法」で初めて法律に（バンク-ミケルセン） | スウェーデン・アメリカ・イギリス |
| <strong>国際障害者年（1981年）</strong>を機に、日本に**ノーマライゼーションの理念が浸透** | 弱者として保護する見方が広まった／身体障害者福祉法の制定 |
| 障害者基本計画（2002年）の理念：**リハビリテーション**と**ノーマライゼーション** | インクルージョン・バリアフリー |

- **障害者差別解消法**：2024年4月から、**民間の事業者にも合理的配慮の提供が義務**になった（それまでは努力義務。行政機関は以前から義務）

## ② 障害の法的定義・手帳・関連制度

### 法的定義

| ○ | × |
|---|---|
| 身体障害者福祉法の身体障害者＝**身体障害者手帳の交付を受けた18歳以上** | 手帳がなくても身体障害者 |
| **知的障害者福祉法には知的障害者の定義がない** | 知的障害者福祉法に定義されている |
| 精神保健福祉法の精神障害者には**知的障害者も含まれる** | 含まれていない |
| 障害者基本法で**発達障害は精神障害に含まれる** | 含まれていない |
| 障害児は**児童福祉法**で定義 | 障害者基本法で定義 |

### 身体障害の種類

視覚障害・聴覚または平衡機能障害・音声言語そしゃく機能障害・肢体不自由・**内部障害**（心臓・腎臓・**呼吸器**・膀胱直腸・小腸・HIV免疫・肝臓）。

> 嚥下障害は「聴覚」ではなく音声言語そしゃく機能、構音障害は「肢体不自由」ではなく音声言語機能、半側空間無視は視覚障害ではなく高次脳機能障害です。

### 障害者手帳の3種類

| | 身体障害者手帳 | 療育手帳 | 精神障害者保健福祉手帳 |
|---|---|---|---|
| 根拠 | **身体障害者福祉法** | 法律ではなく**国の通知**（自治体の制度） | **精神保健福祉法** |
| 等級 | **1〜6級**（7級だけでは交付されない。7級の障害が2つ以上なら6級扱い） | 自治体ごと（A・Bなど） | **1〜3級** |
| 更新 | 原則なし | 再判定あり | **2年ごと** |
| 判定 | 指定医の診断書で都道府県知事などが交付（**肝臓機能障害**も対象。15歳未満は保護者が申請） | **児童相談所**（18歳未満）・**知的障害者更生相談所**（18歳以上） | 精神保健福祉センター。**知的障害だけの人は対象外** |

### 聴覚障害

| ○ | × |
|---|---|
| **要約筆記**で意思疎通を補う | 手話は意思の伝達に役立たない |
| 手帳の対象は**両耳70dB以上** | 40dBで交付 |
| フラッシュベル＝音を**光で知らせる** | 音を増幅する |
| 「ろう」＝**重度**の聴覚障害 | 軽度を「ろう」という |

- 身体障害者手帳を持つ人が情報を得る手段は**テレビ**が最多（2016年 生活のしづらさなどに関する調査）

### 精神保健福祉法の入院形態

| 入院形態 | 中身 |
|---|---|
| 任意入院 | **本人の同意**による（原則） |
| 措置入院 | 自傷他害のおそれ。**精神保健指定医2名以上**の診察が一致し、**都道府県知事**が決定（本人・家族の同意は不要） |
| **緊急措置入院** | 急いでいて措置入院の手続きがとれないとき。指定医1名・**72時間以内** |
| 医療保護入院 | 本人の同意がなく、指定医1名の診察＋**家族等の同意**による。家族等がいない・同意も反対も示さないときは**市町村長の同意**（2024年4月から）。入院期間は入院から6か月までは3か月以内、その後は6か月以内と定め、**更新**するしくみ（2024年4月から） |
| 応急入院 | 急いでいて家族等の同意が得られないとき。指定医1名・**72時間以内** |

### そのほかの論点

- 法定後見の成年後見人等を選ぶのは**家庭裁判所**（申立ては本人・4親等内の親族・市町村長など）
- ADHD（注意欠如・多動症）の子への助言：**集中できる環境をつくる**。一度に多くの指示・比喩・強い視覚刺激は×

## ③ 障害福祉制度の歴史と障害者数

| 年 | できごと |
|---|---|
| 1949年 | 身体障害者福祉法（障害の法律で最も早い） |
| 1981年 | 国際障害者年（完全参加と平等） |
| 2003年 | **支援費制度**（措置→契約） |
| 2005年成立・2006年施行 | **障害者自立支援法**（3障害を一元化。当初は**応益負担**、2010年改正で**応能負担**へ） |
| 2012年成立・2013年施行 | **障害者総合支援法**（難病を追加。2014年に障害程度区分→**障害支援区分**） |
| 2016年 | 障害者差別解消法の施行（2024年4月から事業者の合理的配慮も義務） |

- 障害者数のめやす：**精神（約603万人）＞身体（約423万人）＞知的（約127万人）**（2025年版 障害者白書。身体・知的は2022年調査、精神は2023年 患者調査）
