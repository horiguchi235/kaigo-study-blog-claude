勉強を始める前に、試験そのもののしくみを知っておくと、計画が立てやすくなります。

**結論を3行で**

1. 第39回の筆記試験は<strong>2027年1月31日（日）</strong>。<strong>125問（125点満点）</strong>で、合格点は「**60％程度**を基準に難しさで補正」。第38回は**64点**でした。
2. 第38回から**パート合格**が始まりました。<strong>A（60問）・B（45問）・C（20問）</strong>のうち、基準を満たしたパートは**翌年・翌々年の2回**免除。
3. 合格率は**70〜80％台**。第38回は<strong>70.1％</strong>とやや下がりました。

---

## ① 第39回試験の基本

| 項目 | 内容 |
|---|---|
| 筆記試験日 | <strong>2027年1月31日（日）</strong> |
| 受験申込 | 2026年7月22日〜9月2日（インターネットで申込み。例年夏〜初秋） |
| 受験手数料 | 20,510円 |
| 合格発表 | 2027年3月23日（火） |
| 問題数 | **125問**（1問1点・五肢択一が基本） |
| 試験時間 | 午前：**Aパート** 10:00〜11:45（105分）／午後：**Bパート・Cパート** 13:40〜15:35（115分） |
| 合格基準 | 総得点の**60％程度**を基準に、問題の難しさで補正した点数以上。さらに**11の科目群すべてで得点**があること |

> 「全科目群で得点」がポイント。総得点が合格点を超えていても、1つの科目群が**0点だと不合格**です。苦手科目を0点にしないことが大切です（医療的ケアは5問しかありません）。

<strong>受験資格（主なルート）</strong>

| ルート | 条件 |
|---|---|
| 養成施設ルート | 介護福祉士養成施設（2年以上・1年以上の課程など）を卒業 |
| 実務経験ルート | 介護等の業務に**3年以上**従事し、**実務者研修**を修了 |
| 福祉系高校ルート | 福祉系高校で必要な科目を履修して卒業（特例高校は卒業後に9か月以上の実務経験も必要） |
| EPA（経済連携協定）ルート | EPA介護福祉士候補者として3年以上介護等の業務に従事 |

働きながら受ける人の多くは**実務経験ルート**です。実務経験3年だけでは受験できず、**実務者研修の修了が必要**です（見込みで申し込む場合は2027年3月31日までに満たす）。

## ② パート合格（第38回から）

筆記試験が3つのパートに分かれ、総得点で不合格でも、**基準を満たしたパートは次の試験から免除**されます。

<photo name="yomimono-02__part-goukaku" caption="パート合格のしくみ（第39回で受験した例）。第39回でAパートだけ合格すると、第40回・第41回はAが免除になり、第42回は再びAも受験する。">

| パート | 科目（問題数） | 科目群 | 合計 |
|---|---|---|---|
| **A** | 人間の尊厳と自立（2）、介護の基本（10）、社会の理解（12）、人間関係とコミュニケーション（4）、コミュニケーション技術（6）、生活支援技術（26） | 4群：①人間の尊厳と自立＋介護の基本 ②人間関係とコミュニケーション＋コミュニケーション技術 ③社会の理解 ④生活支援技術 | **60問** |
| **B** | こころとからだのしくみ（12）、発達と老化の理解（8）、認知症の理解（10）、障害の理解（10）、医療的ケア（5） | 5群（1科目＝1群） | **45問** |
| **C** | 介護過程（8）、総合問題（12） | 2群（1科目＝1群） | **20問** |

13科目のうち、「人間の尊厳と自立」と「介護の基本」、「人間関係とコミュニケーション」と「コミュニケーション技術」がそれぞれ1つにまとまって、**11の科目群**になります。

**パート合格の条件**

1. 全パートを受けた人は、まず**総得点で合否**を判定。総得点で不合格だったときだけ、パートごとに判定します
2. そのパートの**合格基準点以上**を取り、かつ**そのパートの科目群すべてで得点**があること
3. パートの合格基準点は、全体の合格点を、全パートを受けた人の各パートの平均点の比率で分けて決めます。そのため **A 32.23点・B 20.43点・C 11.33点**（第38回）のように小数になります
4. 合格したパートは**翌年と翌々年の試験**で免除。再受験のときは「全パートを受ける」か「不合格のパートだけ受ける」かを**申込みのときに選びます**（あとから変えられません）

**例**：第39回でAパートだけ合格 → 第40回・第41回はAパートが免除になり、BとCだけ受けることができます。

- 第38回のパート別の合格者は、Aパート3,935人・Bパート1,509人・Cパート6,181人でした（重複あり）
- 働きながら受験する人は、「今年はAとCを確実に」のように**分けて合格を目指す**作戦もとれます

## ③ 合格点と合格率の推移

| 回（実施年） | 合格点（125点満点） | 合格率 |
|---|---|---|
| 第30回（2018年） | 77点 | 70.8％ |
| 第31回（2019年） | 72点 | 73.7％ |
| 第32回（2020年） | 77点 | 69.9％ |
| 第33回（2021年） | 75点 | 71.0％ |
| 第34回（2022年） | 78点 | 72.3％ |
| 第35回（2023年） | 75点 | 84.3％ |
| 第36回（2024年） | 67点 | 82.8％ |
| 第37回（2025年） | 70点 | 78.3％ |
| 第38回（2026年） | **64点** | <strong>70.1％</strong> |

- 合格点は「60％（75点）」で固定ではなく、**問題が難しい年は下がり、やさしい年は上がります**。第38回の64点は正答率で約51％でした。目標は**75点（6割）以上**を安定して取れることにしておくと安心です
- 第38回は受験者78,469人、合格者54,987人でした

**受験者数の大きな変化（第29回）**

| 回（実施年） | 受験者数 | 合格率 |
|---|---|---|
| 第26回（2014年） | 154,390人 | 64.6％ |
| 第28回（2016年） | 152,573人 | 57.9％ |
| **第29回（2017年）** | **76,323人** | **72.1％** |

第29回から、実務経験ルートで受ける人に**実務者研修の修了が必要**になり、受験者は約半分に減りました。そのかわり合格率は60％前後から**70％台**に上がりました。今の受験者は、ほとんどが実務者研修や養成施設で学んだ人です。「合格率が高いからやさしい」のではなく、**準備してきた人どうしの試験**と考えておきましょう。

- 第1回（1989年）の合格率は23.2％。これまでの累計では、約303万人が受験し、約178万人が合格しています（第38回まで）
- 10人中7〜8人が合格する試験です。ただし、**事例問題が増えて**問題文が長くなっており（読みもの①参照）、**時間内に読み切る練習**も必要になっています

## ④ ちょっとした雑学

- **介護福祉士は「名称独占」の資格**。資格がなくても介護の仕事はできますが、「介護福祉士」と名乗れるのは登録した人だけ。法律は1987年にできました（介護福祉士の法律・倫理①）
- **問題は全部5択**。15年分1,838問すべてが5択で、正解の番号は1〜5番でほぼ均等でした
- <strong>いちばん問題数が多い科目は生活支援技術（26問）</strong>。Aパートの4割以上を占めます
- <strong>「認知症」という言葉は約6問に1問</strong>に登場。どの科目にも関わる最重要キーワードです
- **第24回だけ「適切でないもの」を選ぶ問題が21問**ありました。今は「最も適切なもの」を選ぶ問題が中心です
