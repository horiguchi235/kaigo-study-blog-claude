勉強を始める前に、試験そのもののしくみを知っておくと、計画が立てやすくなります。

**結論を3行で**

1. 試験は**1月下旬**、筆記**125問（125点満点）**。合格点は「**60％程度**を基準に難しさで補正」。第38回は**64点**でした。
2. 第38回から**パート合格**が始まりました。<strong>A（60問）・B（45問）・C（20問）</strong>のうち、基準を満たしたパートは**翌年・翌々年の2回**免除。
3. 合格率は**70〜80％台**。第38回は<strong>70.1％</strong>とやや下がりました。

---

## ① 試験の基本（第38回の例）

| 項目 | 内容 |
|---|---|
| 試験日 | 2026年1月25日（日）※例年1月下旬 |
| 合格発表 | 2026年3月16日（月） |
| 問題数 | **125問**（1問1点・すべて5択） |
| 合格基準 | 総得点の**60％程度**を基準に、問題の難しさで補正した点数以上。さらに**11の科目群すべてで得点**があること |
| 第38回の合格点 | **64点**（正答率で約51％） |
| 受験者・合格者 | 受験者 78,469人、合格者 54,987人 |
| 合格率 | **70.1％** |

> 「全科目群で得点」がポイント。苦手科目を**0点にしない**ことが大切です（医療的ケアは5問しかありません）。

---

## ② パート合格（第38回から）

筆記試験が3つのパートに分かれ、総得点で不合格でも、**基準を満たしたパートは次の試験から免除**されます。

| パート | 科目（問題数） | 合計 |
|---|---|---|
| **A** | 人間の尊厳と自立（2）、人間関係とコミュニケーション（4）、社会の理解（12）、介護の基本（10）、コミュニケーション技術（6）、生活支援技術（26） | **60問** |
| **B** | こころとからだのしくみ（12）、発達と老化の理解（8）、認知症の理解（10）、障害の理解（10）、医療的ケア（5） | **45問** |
| **C** | 介護過程（8）、総合問題（12） | **20問** |

- 合格したパートは、**翌年と翌々年の試験**で受験が免除されます
- 第38回のパートごとの基準点は、**A 32.23点・B 20.43点・C 11.33点**でした
- 働きながら受験する人は、「今年はAとCを確実に」のように**分けて合格を目指す**作戦もとれます

## ③ 合格率の推移

| 回（実施年） | 合格率 |
|---|---|
| 第34回（2022年） | 72.3％ |
| 第35回（2023年） | 84.3％ |
| 第36回（2024年） | 82.8％ |
| 第37回（2025年） | 78.3％ |
| 第38回（2026年） | **70.1％** |

10人中7〜8人が合格する試験です。ただし、**事例問題が増えて**問題文が長くなっており（読みもの①参照）、**時間内に読み切る練習**も必要になっています。

## ④ ちょっとした雑学

- **介護福祉士は「名称独占」の資格**。資格がなくても介護の仕事はできますが、「介護福祉士」と名乗れるのは登録した人だけ。法律は1987年にできました（介護福祉士の法律・倫理①）
- **問題は全部5択**。15年分1,838問すべてが5択で、正解の番号は1〜5番でほぼ均等でした
- **いちばん問題数が多い科目は生活支援技術（26問）**。Aパートの4割以上を占めます
- **「認知症」という言葉は約6問に1問**に登場。どの科目にも関わる最重要キーワードです
- **第24回だけ「適切でないもの」を選ぶ問題が21問**ありました。今は「最も適切なもの」を選ぶ問題が中心です
