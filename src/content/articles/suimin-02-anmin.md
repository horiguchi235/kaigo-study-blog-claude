**この記事のポイント**

1. 安眠の3点セットは「**朝に日光、日中に適度な運動、入浴は寝る1〜2時間前（足浴も◎）**」。
2. 「**夜食・寝酒・カフェイン・長い昼寝・寝だめ・夕食直後に寝る**」は×。
3. 眠れない人には、まず**これまでの睡眠の様子を聞く**。睡眠薬を勧める・無理に寝かせるは×。

## ① 安眠を促す生活習慣

整理のしかた：**光は朝**（体内時計を合わせる）、**運動は日中〜夕方**（適度な疲れ）、**温めるのは寝る1〜2時間前**（体温が下がるころに眠くなる）。

| ○ | × |
|---|---|
| **起床後にカーテンを開けて日光**を浴びる | — |
| 日中に**適度な疲労が得られる運動** | 汗をかく運動・強度の高い運動を寝る前や日中に多く |
| 関節リウマチで昼夜逆転 → **午後に温水プール**で運動（朝は関節がこわばるため） | 早朝の散歩・朝食を抜く |
| 就寝前に**軽いストレッチ** | — |
| 入浴は**就寝の1〜2時間前**、**ぬるめ**の湯 | 就寝直前・熱めの湯 |
| **足浴**で温めてから寝る | — |
| 寝室の照明は**暖色系**で暗めに | 昼光色の蛍光灯（明るい光で目が覚める） |
| 布団に入ったら**ゆっくり深い呼吸** | 短く浅い呼吸（緊張が高まる） |
| 自分なりの<strong>入眠儀式（習慣）</strong>を大切に。寝る前の**イブニングケア**（洗面・歯みがき・足浴など、眠る前の身支度）で眠りの準備 | 入眠への習慣を控える |
| 昼寝は**短く**（**30分以内**・**15時まで**） | 1時間以上の昼寝 |
| 眠くなってから床につく | 眠くなくても早く床につく・決まった時刻に目を閉じる |

**よく出る×**：**夕食直後に寝る・夜食・緑茶・コーヒー・寝酒・寝だめ**（カフェイン・アルコールは眠りを浅くする）。

### 夜勤のある職員の睡眠

夜勤明けの帰宅時は**サングラスで日光を避ける**（体内時計が朝だと思わないように）。夜勤前の仮眠は**とってよい**、寝る前のスマホ・寝だめ・食事時間をばらばらにするのは×。

## ② 睡眠環境・寝具・ベッドメイキング

### 寝室の環境

| ○ | × |
|---|---|
| **換気**して臭気がこもらないように | 締め切ったまま |
| ドアは閉め、**職員同士の会話や足音が響かないように** | 観察のためドアを開けておく |
| **寝室（眠るとき）**は室温**夏25℃前後・冬15〜20℃**、湿度**50〜60％**（**居室（日中を過ごす部屋）**の目安は室温**24℃前後**・湿度**40〜60％**） | 湿度20％以下・1年中15℃ |
| 寝床内（布団の中）は**32〜34℃**程度 | 寝床内20℃ |
| 冷暖房の風が**体に直接当たらない** | 直接当てる |
| 夜間は**足元灯**（杖歩行の人にも） | 部屋全体が見えるほど明るく |
| 湯たんぽは**皮膚に直接触れない**（低温やけど） | 電気毛布をつけっぱなし |
| 寝衣は**ゆったり**した物 | 体に密着した物 |

### 寝具

<photo name="suimin-02__mattress" caption="**体圧分散マットレス**：凹凸で体重を分散させ、褥瘡を予防する。やわらかすぎると寝返りがしにくくなる点に注意。">

| ○ | × |
|---|---|
| マットレスは**適度な硬さ**（腰が沈まない）、寝返りできる広さ | 柔らかく沈む物（寝返りしにくい） |
| 枕は**頸部が前に曲がらない**高さ（首の角度が約15度上がるくらい） | 顎が首につくほど高い |
| 寝具は**吸湿性・保温性**のバランス | 保温性だけで選ぶ（汗で蒸れる） |
| **パーキンソン病**の人はベッドに**手すり** | 介護者に合わせた高さ・沈むマット |
| ベッドまわりの床は平らに | 床にクッションマット（すり足でつまずく） |

**畳に布団の利点**：**転落の心配がない**。湿気がこもりやすく、立ち上がりにくく、介護の負担は大きくなります。

## ③ 状態別の安眠支援・夜間の対応

| 場面 | ○ 正解 | × |
|---|---|---|
| 夜間の**巡回** | **異変の有無を確認** | 顔に懐中電灯・足音で知らせる・普通の声で話す |
| 認知機能の低下した人が**深夜に歩き回る** | **いったん座ってもらい話を聞く** | 部屋に戻るよう促す・睡眠薬・一人で歩かせる |
| ショートステイで「夜眠れない」 | **自宅での睡眠の状況を詳しく尋ねる** | 施設の消灯時間を伝える・睡眠薬を提案 |
| 認知症で不眠、昼間眠い | **午前中に太陽の光**を浴びる | 1時間以上の昼寝・夕食後すぐ寝る |
| 認知症で夜に活動的になる | 日中の活動と光でリズムを整え、**寝間着に着替える**など「夜だ」とわかる環境に。昼夜逆転には**午後〜夕方の散歩**やレクリエーション | 夜も昼と同じ服で過ごす |
| **心不全**で横になると息苦しい | **セミファーラー位**（ベッドの上半身を15〜30度ほど上げた姿勢）で寝る（セミファーラー位＝15〜30度、ファーラー位（半座位）＝45度前後。息苦しさが強いほど上半身を高くする） | 肩まで入浴・寝る前の食事・以前の散歩を再開 |
| いびきが**途切れる**、日中だるい | **睡眠中の呼吸状態**を観察 | 枕・マットレスの硬さ |
| **消化管ストーマ** | 寝る前に**パウチ（ストーマにつけて便をためる袋）の便を捨てる** | 装具を毎晩交換・おむつで強く巻く・観察を控える |
| **睡眠薬**を飲んでいる人 | 日中の**ふらつきは医師に伝える**。飲んだら**すぐ床に就く** | アルコールと一緒・1時間起きている・追加で飲む・服薬時間を変える |

### 「眠れない」と言われたら

1. まず**つらさを受け止める**（共感する）
2. **これまでの睡眠の様子**（自宅での習慣・寝る時刻）と原因（痛み・かゆみ・頻尿・不安など）を聞く
3. 足浴、**カフェインのない温かい飲み物**、清潔で乾いた寝具、室温・湿度など**環境を整える**
4. 続くとき・体の症状があるときは**医療職へ**（睡眠薬を勧めるのは介護職の判断ではない）

夜間のおむつ交換は[ポータブルトイレ・おむつ交換・住宅改修](../haisetsu-03-kaijo/)、寝たままの寝衣の交換は[更衣の介助と衣服・靴の選び方](../nyuyoku-04-koui/)へ。
