**結論を3行で**

1. 安眠の3点セットは「**朝に日光、日中に適度な運動、入浴は寝る1〜2時間前（足浴も◎）**」。
2. 「**夜食・寝酒・カフェイン・長い昼寝・寝だめ・夕食直後に寝る**」は×。
3. 眠れない人には、まず**これまでの睡眠の様子を聞く**。睡眠薬を勧める・無理に寝かせるは×。

<details>
<summary>✏️ 解いてみよう（第38回）</summary>

良質な睡眠のための環境づくりとして、最も適切なものはどれ？

1. 日中は、強度の高い運動を多く取り入れる
2. 夜食は、就寝直前にとる
3. 入浴は、就寝の1〜2時間前に行う
4. 眠気がなくても、決まった時間に目を閉じる
5. 寝ている間も、照明は明るくしておく

<details class="answer">
<summary>正解を見る</summary>

**正解：3**　入浴で上がった体温が1〜2時間かけて下がるときに眠気が来ます。運動は「適度」に、眠くなってから床に就きます。
</details>
</details>

## ② 睡眠環境・寝具・ベッドメイキング【生活支援技術】

### 寝室の環境

| ○ | × |
|---|---|
| **換気**して臭気がこもらないように（第35回） | ドアを開けておく |
| **職員同士の会話が響かないように**（第32回） | — |
| 湿度は**50〜60％**、室温は夏25℃前後・冬15〜20℃ | 湿度20％以下・1年中15℃ |
| 冷暖房の風が**体に直接当たらない** | 直接当てる |
| 夜間は**足元灯**（杖歩行の人にも）（第31回） | 部屋全体が見えるほど明るく |
| 湯たんぽは**皮膚に直接触れない**（低温やけど）（第33回） | 電気毛布をつけっぱなし |
| 寝衣は**ゆったり**した物 | 体に密着した物 |

### 寝具

| ○ | × |
|---|---|
| マットレスは**適度な硬さ**（腰が沈まない） | 柔らかく沈む物 |
| 枕は**頸部が前に曲がらない**高さ | 顎が首につくほど高い |
| 寝具は**吸湿性・保温性**のバランス | 保湿性を最優先 |
| **パーキンソン病**の人はベッドに**手すり**（第30回） | 介護者に合わせた高さ・沈むマット・床にクッションマット |

**畳に布団の利点**：**転落の心配がない**（第33回）。湿気がこもりやすく、立ち上がりにくく、介護の負担は大きくなります。

### ベッドメイキング（第34・37回）

| ○ | × |
|---|---|
| シーツの角は**対角線の方向に伸ばして**しわを作らない | — |
| シーツの**中心線をマットレスの中央**に合わせる | マットレスの端に合わせる |
| マットレスの下に入れるときは**手のひらを下**に | — |
| 外すときは**汚れた面を内側**に丸める | 汚れた面を外側に |
| **窓を開けて**換気、キャスターは**ストッパーをかける** | 窓を閉める・ストッパーを外す |
| 作業は**膝を曲げて**（ボディメカニクス） | 膝を伸ばしたまま |
| 枕カバーの折り込みは**下（入口が見えない向き）** | 折り込み側を上に |
| 動かした物は**元の位置**に戻す | 使いやすいように位置を変える |

## ③ 状態別の安眠支援・夜間の対応【生活支援技術】

| 場面 | ○ 正解 | × |
|---|---|---|
| 夜間の**巡回** | **異変の有無を確認**（第25回） | 顔に懐中電灯・足音で知らせる・普通の声で話す |
| 認知機能の低下した人が**深夜に歩き回る** | **いったん座ってもらい話を聞く**（第26回） | 部屋に戻るよう促す・睡眠薬・一人で歩かせる |
| ショートステイで「夜眠れない」 | **自宅での睡眠の状況を詳しく尋ねる**（第33回） | 施設の消灯時間を伝える・睡眠薬を提案 |
| 認知症で不眠、昼間眠い | **午前中に太陽の光**を浴びる（第37回） | 1時間以上の昼寝・夕食後すぐ寝る |
| **心不全**で横になると息苦しい | **セミファーラー位**で寝る（第30回） | 肩まで入浴・寝る前の食事・以前の散歩を再開 |
| いびきが**途切れる**、日中だるい | **睡眠中の呼吸状態**を観察（第36回） | 枕・マットレスの硬さ |
| **消化管ストーマ** | 寝る前に**パウチの便を捨てる**（第36回） | 装具を毎晩交換・おむつで強く巻く・観察を控える |
| **睡眠薬**を飲んでいる人 | 日中の**ふらつきは医師に伝える**（第32回）。飲んだら**すぐ床に就く** | アルコールと一緒・1時間起きている・追加で飲む・服薬時間を変える |

### 夜間のケアの基本

- おむつは**腹部とおむつの間に指2本**の余裕（第25回）。紙おむつのテープは**斜め上向き**に留める
- 臥床したままの**和式寝衣**の交換：新しい寝衣の**背縫いを脊柱に合わせる**（第31回）。袖は**肩→肘→手**の順に抜き、**右前身頃が下、左前身頃が上**（右前）。腰紐は**横で結ぶ**（背中で結ぶと褥瘡の原因）

<details>
<summary>✏️ 解いてみよう（第36回・事例）</summary>

介護老人保健施設に入所して1か月の79歳の男性。睡眠中に大きないびきをかき、いびきが途切れることもある。夜間に目を覚ましていたり、起床時にだるそうにしていたりする。収集すべき情報として最も優先度が高いものはどれ？

1. 枕の高さ
2. マットレスの硬さ
3. 掛け布団の重さ
4. 睡眠中の足の動き
5. 睡眠中の呼吸状態

<details class="answer">
<summary>正解を見る</summary>

**正解：5**　「いびきが途切れる」は呼吸が止まっているサインで、睡眠時無呼吸症候群が疑われます。命に関わることもあるため、呼吸の観察を最優先します。
</details>
</details>
