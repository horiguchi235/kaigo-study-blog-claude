**この記事のポイント**

1. 安眠の3点セットは「**朝に日光、日中に適度な運動、入浴は寝る1〜2時間前（足浴も◎）**」。
2. 「**夜食・寝酒・カフェイン・長い昼寝・寝だめ・夕食直後に寝る**」は×。
3. 眠れない人には、まず**これまでの睡眠の様子を聞く**。睡眠薬を勧める・無理に寝かせるは×。

## ① 安眠を促す生活習慣【生活支援技術】

| ○ | × |
|---|---|
| **起床後にカーテンを開けて日光**を浴びる | — |

## ② 睡眠環境・寝具・ベッドメイキング【生活支援技術】

### 寝室の環境

| ○ | × |
|---|---|
| **換気**して臭気がこもらないように | ドアを開けておく |
| **職員同士の会話が響かないように** | — |
| 湿度は**50〜60％**、室温は夏25℃前後・冬15〜20℃ | 湿度20％以下・1年中15℃ |
| 冷暖房の風が**体に直接当たらない** | 直接当てる |
| 夜間は**足元灯**（杖歩行の人にも） | 部屋全体が見えるほど明るく |
| 湯たんぽは**皮膚に直接触れない**（低温やけど） | 電気毛布をつけっぱなし |
| 寝衣は**ゆったり**した物 | 体に密着した物 |

### 寝具

| ○ | × |
|---|---|

| **パーキンソン病**の人はベッドに**手すり** | 介護者に合わせた高さ・沈むマット・床にクッションマット |

**畳に布団の利点**：**転落の心配がない**。湿気がこもりやすく、立ち上がりにくく、介護の負担は大きくなります。

### ベッドメイキング

| ○ | × |
|---|---|
| シーツの角は**対角線の方向に伸ばして**しわを作らない | — |
| シーツの**中心線をマットレスの中央**に合わせる | マットレスの端に合わせる |
| マットレスの下に入れるときは**手のひらを下**に | — |
| 外すときは**汚れた面を内側**に丸める | 汚れた面を外側に |
| **窓を開けて**換気、キャスターは**ストッパーをかける** | 窓を閉める・ストッパーを外す |
| 作業は**膝を曲げて**（ボディメカニクス） | 膝を伸ばしたまま |
| 枕カバーの折り込みは**下（入口が見えない向き）** | 折り込み側を上に |
| 動かした物は**元の位置**に戻す | 使いやすいように位置を変える |

## ③ 状態別の安眠支援・夜間の対応【生活支援技術】

| 場面 | ○ 正解 | × |
|---|---|---|
| 夜間の**巡回** | **異変の有無を確認** | 顔に懐中電灯・足音で知らせる・普通の声で話す |
| 認知機能の低下した人が**深夜に歩き回る** | **いったん座ってもらい話を聞く** | 部屋に戻るよう促す・睡眠薬・一人で歩かせる |
| ショートステイで「夜眠れない」 | **自宅での睡眠の状況を詳しく尋ねる** | 施設の消灯時間を伝える・睡眠薬を提案 |
| 認知症で不眠、昼間眠い | **午前中に太陽の光**を浴びる | 1時間以上の昼寝・夕食後すぐ寝る |
| **心不全**で横になると息苦しい | **セミファーラー位**で寝る | 肩まで入浴・寝る前の食事・以前の散歩を再開 |
| いびきが**途切れる**、日中だるい | **睡眠中の呼吸状態**を観察 | 枕・マットレスの硬さ |
| **消化管ストーマ** | 寝る前に**パウチの便を捨てる** | 装具を毎晩交換・おむつで強く巻く・観察を控える |
| **睡眠薬**を飲んでいる人 | 日中の**ふらつきは医師に伝える**。飲んだら**すぐ床に就く** | アルコールと一緒・1時間起きている・追加で飲む・服薬時間を変える |

### 夜間のケアの基本

- おむつは**腹部とおむつの間に指2本**の余裕。紙おむつのテープは**斜め上向き**に留める
- 臥床したままの**和式寝衣**の交換：新しい寝衣の**背縫いを脊柱に合わせる**。袖は**肩→肘→手**の順に抜き、**右前身頃が下、左前身頃が上**（右前）。腰紐は**横で結ぶ**（背中で結ぶと褥瘡の原因）

## ＋α もう一歩：実務者研修レベルで覚えたいこと

過去問にはまだ出ていないけれど、実務者研修の確認テストでよく問われる、関連して覚えておきたい知識です。

- **昼寝は午後の早い時間に30分未満**が目安（30〜45分以上の長い昼寝は夜の眠りを妨げる）。
- 夜になると活動的になる認知症の人には、日中の活動と光で生活リズムを整え、**寝間着に着替える**など「夜だ」とわかる睡眠環境づくりを。
