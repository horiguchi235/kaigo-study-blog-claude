**この記事のポイント**

1. 共感の正解は「**〜なのですね**」と**相手の気持ちを言葉にして返す**形。励まし・同情・解決策の提案は×。
2. 開かれた質問＝**考えや背景を引き出す**、閉じられた質問（閉じた質問）＝**はい／いいえや一語で答えられる**。
3. 技法名の問題は「**要約＝まとめて返す**」「**直面化＝矛盾に向き合えるよう投げかける**」「**感情の反射＝口にした気持ちを返す**」をセットで。

## ① 傾聴・共感・受容

| 用語 | 正しい意味 | よく出る誤り |
|---|---|---|
| **傾聴** | 相手の言葉を**妨げずに、じっくり聴く**。言葉の奥の**感情を推察**する | 解決策を提案しながら聴く／客観的事実の把握が目的／沈黙させない |
| **共感** | 相手の**立場に立って感情を理解**し、それを**言葉で伝える** | 自分の感情と区別せず同調する／同情する |
| **受容** | 相手の**価値観を尊重**し、気持ちや背景をありのまま受け止める | 言い分に同調する／問題行動もそのまま認める（容認する） |

> 受容は「行動を認めること」ではありません。たとえば暴言そのものはよしとしないまま、「そう言いたくなるほどつらかった」という**気持ちや背景**を受け止めるのが受容です。

### 共感の応答（いちばん出る形）

共感は**態度**（相手の立場で気持ちを理解し、伝える）。それを言葉にする具体的な技法が、③の**感情の反射**や**感情の明確化**です。だから「つらい気持ちなのですね」は、共感の応答でもあり、技法名でいえば感情の反射でもあります。

| 回 | 相手の言葉 | ○ 正解 |
|---|---|---|
| 第31回 | 「リハビリを頑張っているけど、なかなかうまくいかない。自宅に戻れるのか…」 | 「**リハビリがうまくいかなくて不安なのですね**」 |
| 第34回 | 認知症の母の介護で心身共に疲れている家族 | 「**お母さんのために頑張ってきたんですね**」 |
| 第25回 | 「同じ話を毎日聞いて疲れる。つらいです」 | 「**つらい気持ちなのですね**」（感情の反射） |
| 第34回 | 全盲の人「私はここでやっていけるでしょうか」 | **立場に立って感情を推し測り、言葉で伝える** |

**×になる応答のパターン**
- 励まし：「不安に負けてはいけません」「元気を出して頑張って」
- 根拠のない保証：「きっと戻れますよ」「心配いりません」
- 同情：「かわいそうです」
- 一般化：「皆さん疲れていますよ」
- 自分の話：「私も疲れているので、よくわかります」
- すぐに解決策：「施設入所を検討しては」

## ② バイステックの7原則

アメリカの社会福祉学者**バイステック**がまとめた、**ケースワーク（個別の相談援助）で援助関係をつくるための7つの原則**です。主語が**利用者**か**援助者**かに注意します。

| 原則 | 意味（主語） |
|---|---|
| 個別化 | 援助者が、一人ひとりを**個人として**とらえる |
| **意図的な感情表出** | **利用者が**感情を自由に表現できるようにする（「自分の気持ちを我慢しなくてもいいですよ」） |
| **統制された情緒的関与** | **援助者が**自分の感情を自覚・コントロールして関わる |
| 受容 | 援助者が、利用者をありのまま受け止める |
| **非審判的態度** | 援助者の**価値観で善悪を判断しない** |
| 自己決定 | **利用者が**自分で決めることを尊重する |
| 秘密保持 | 援助者が、知り得た情報を守る |

> 第27回のひっかけ：「意図的な感情表出＝**介護福祉職の**感情表出」「統制された情緒的関与＝**利用者の**感情をコントロール」はどちらも×。主語を入れ替えています。

## ③ 質問と応答の技法

| 技法 | 意味・使う場面 |
|---|---|
| **開かれた質問** | 自由に答えられる質問（「どのように」「何が」）。**漠然とした考えを明確にする**、**背景にある理由を知る** |
| **閉じられた質問**（閉じた質問） | <strong>「はい」「いいえ」</strong>や一語で答えられる質問。例：「**この本は好きですか**」。**事実や意思の確認**、話すのが難しい人（**運動性失語**・疲れているとき）に向く |
| 繰り返し | 相手の言葉を**そのまま**返す |
| 言い換え | 相手の話の内容を**自分の言葉**で返す |
| **要約** | 話の内容を**総合的にまとめて返し**、気持ちを整理する |
| 焦点化 | 話の中の大事な点に**しぼって**返し、そこを深める |
| **感情の反射** | 相手が**口にした気持ち**を言葉で返す（「つらい気持ちなのですね」） |
| 感情の明確化 | 相手が**まだ言葉にできていない気持ち**をくみ取って言葉にする |
| **直面化** | 相手が自分の**感情と行動の矛盾**に**向き合えるよう投げかける**（信頼関係ができていないと傷つける） |
| **自己開示** | 支援に役立つ範囲で自分のことを話す。目的は**信頼関係の形成** |
| **アサーティブ** | 相手の思いを**尊重しながら**、自分の意見を**率直に**伝える。ほかの2タイプ＝**非主張的**（我慢して言わない）・**攻撃的**（相手を押さえつける） |

**同じ発言への返し方のちがい**（相手：「家に帰りたいけど、娘に迷惑をかけるし…」）

| 技法 | 応答の例 |
|---|---|
| 繰り返し | 「家に帰りたいけど…」 |
| 言い換え | 「自宅に戻りたい気持ちがあるのですね」 |
| 感情の反射 | 「娘さんに迷惑をかけるのが心配なのですね」 |
| 感情の明確化 | 「本当は帰りたいのに、遠慮して言い出せずにいるのですね」 |
| 焦点化 | 「娘さんへの遠慮のことを、もう少し聞かせてください」 |

### ジョハリの窓と自己開示

**ジョハリの窓**は、自分のことを「自分が知っているか」「他人が知っているか」で4つに分けて、自分を知る・知ってもらう関係を考える枠組みです。

| | 自分が知っている | 自分が知らない |
|---|---|---|
| **他人が知っている** | 開放の窓 | 盲点の窓 |
| **他人が知らない** | 秘密の窓 | 未知の窓 |

自己開示をすると「**開放の窓**」が**広がる**（狭くする、は×）。

## ④ 応答の注意点と、避けたい質問

- 話の**内容だけでなく、相手が「いま」感じている気持ち**を大切にする。感情を受け止めてもらえないと、本人は「こんな気持ちになってはいけない」と思ってしまうことがある。
- 感情は**言葉・表情・しぐさ・声**に表れるが、同じ表情でも意味は1つとは限らない。推測で決めつけず**本人に確かめる**。
- 技法は1つに決めず、**状況に応じて使い分ける**。聴きながら**自分の心の動き（感情・価値観）にも気づいておく**（自己覚知 → [家族とのコミュニケーションと自己覚知](../communication-03-kazoku/)）。
- 利用者が自分で話を広げられるよう、意識して**開かれた質問**を使う。**閉じられた質問**ばかりだと、相手の世界を狭めてしまう。
- 質問は**一度に1つ**。答えを急かしたり誘導したりしない。
- 避けたい質問：**重複する質問**（2つのことを同時に聞く）、「なぜ？」「どうして？」の多用（問い詰められている・責められている気持ちになる）、**評価的な質問**（「みんな参加してますよ」など価値判断を含む）。

## ひっかけパターン集（技法で「ほぼ×」）

| 選択肢の表現 | なぜ× |
|---|---|
| 励ます・頑張ってと言う | 気持ちを受け止めていない |
| 同情する・同調する | 共感は感情を区別したうえで理解すること |
| 傾聴しながら解決策を提案する | まず最後まで聴く |
| 閉じられた質問で背景を探る | 背景は開かれた質問で |
| 自己開示で開放の窓を狭くする | 広がる |
| 受容＝問題行動も認める | 受け止めるのは気持ちや背景。行動の容認ではない |
| 意図的な感情表出＝援助者の感情表出 | 感情を表出するのは**利用者** |
