**結論を3行で**

1. 共感の正解は「**〜なのですね**」と**相手の気持ちを言葉にして返す**形。励まし・同情・解決策の提案は×。

## ① 傾聴・共感・受容【コミュニケーション技術】

| 用語 | 正しい意味 | よく出る誤り |
|---|---|---|
| **傾聴** | 相手の言葉を**妨げずに、じっくり聴く**。言葉の奥の**感情を推察**する | 解決策を提案しながら聴く／客観的事実の把握が目的／沈黙させない |
| **共感** | 相手の**立場に立って感情を理解**し、それを**言葉で伝える** | 自分の感情と区別せず同調する／同情する |
| **受容** | 相手の**価値観を尊重**し、ありのまま受け止める | 言い分に同調する／問題行動を否定する |

### 共感の応答（いちばん出る形）

| 回 | 相手の言葉 | ○ 正解 |
|---|---|---|
| 第31回 | 「リハビリを頑張っているけど、なかなかうまくいかない。自宅に戻れるのか…」 | 「**リハビリがうまくいかなくて不安なのですね**」 |
| 第34回 | 認知症の母の介護で心身共に疲れている家族 | 「**お母さんのために頑張ってきたんですね**」 |
| 第25回 | 「同じ話を毎日聞いて疲れる。つらいです」 | 「**つらい気持ちなのですね**」（感情の反射） |
| 第34回 | 全盲の人「私はここでやっていけるでしょうか」 | **立場に立って感情を推し測り、言葉で伝える** |

**×になる応答のパターン**
- 励まし：「不安に負けてはいけません」「元気を出して頑張って」
- 根拠のない保証：「きっと戻れますよ」「心配いりません」
- 同情：「かわいそうです」
- 一般化：「皆さん疲れていますよ」
- 自分の話：「私も疲れているので、よくわかります」
- すぐに解決策：「施設入所を検討しては」

<details>
<summary>✏️ 解いてみよう（第31回）</summary>

脳梗塞で左片麻痺がある男性が「リハビリを頑張っているけれど、なかなかうまくいかない。このままで自宅に戻れるようになるのか…」と暗い表情で話した。共感的な応答として最も適切なものはどれ？

1. 「不安な気持ちに負けてはいけません」
2. 「きっと自宅に戻れますよ」
3. 「不安に思う必要はありません」
4. 「不安に思っているあなたがかわいそうです」
5. 「リハビリがうまくいかなくて不安なのですね」

<details class="answer">
<summary>正解を見る</summary>

**正解：5**　相手の「状況」と「気持ち」をそのまま言葉にして返しています。1は励まし、2は根拠のない保証、3は気持ちの否定、4は同情です。
</details>
</details>

## ② バイステックの7原則【人間関係とコミュニケーション／コミュニケーション技術】

| 原則 | 意味 |
|---|---|
| 個別化 | 一人ひとりを**個人として**とらえる |
| **意図的な感情表出** | 利用者が**感情を自由に表現できる**ようにする（第30回：「自分の気持ちを我慢しなくてもいいですよ」） |
| 統制された情緒的関与 | 援助者が**自分の感情を自覚・コントロール**して関わる |
| 受容 | ありのままを受け止める |
| **非審判的態度** | 援助者の**価値観で善悪を判断しない**（第27回） |
| 自己決定 | 利用者が自分で決めることを尊重する |
| 秘密保持 | 知り得た情報を守る |

> 第27回のひっかけ：「意図的な感情表出＝**介護福祉職の**感情表出」「統制された情緒的関与＝**利用者の**感情をコントロール」はどちらも×。主語を入れ替えています。

## ③ 質問と応答の技法【コミュニケーション技術／人間関係とコミュニケーション】

| 技法 | 意味・使う場面 |
|---|---|
| **開かれた質問** | 自由に答えられる質問（「どのように」「何が」）。**漠然とした考えを明確にする**（第30回）、**背景にある理由を知る**（第33回） |
| **閉じられた質問** | **「はい」「いいえ」**や一語で答えられる質問。例：「**この本は好きですか**」（第35回） |
| 繰り返し | 相手の言葉をそのまま返す |
| 言い換え | 相手の話を自分の言葉で返す |
| **要約** | 話の内容を**総合的にまとめて返し**、気持ちを整理する（第37回・第38回） |
| **感情の反射** | 相手の**気持ちをそのまま返す**（「つらい気持ちなのですね」） |
| **直面化** | 利用者の**感情と行動の矛盾点を指摘**する（第32回） |
| **自己開示** | 自分のことを話す。目的は**信頼関係の形成**（第34回・第38回） |
| **アサーティブ** | 相手の思いを**尊重しながら**、自分の意見を**率直に**伝える（第34回） |

> 「なぜ」「どうして」で始まる質問は、問い詰められているように感じさせることがあります（第24回）。

### ジョハリの窓と自己開示

| | 自分が知っている | 自分が知らない |
|---|---|---|
| **他人が知っている** | 開放の窓 | 盲点の窓 |
| **他人が知らない** | 秘密の窓 | 未知の窓 |

自己開示をすると「**開放の窓**」が**広がる**（狭くする、は×）。

<details>
<summary>✏️ 解いてみよう（第38回・事例）</summary>

認知症のある女性が「小さい頃は毎年お祭りが楽しみでね」「最近ひざが痛いような気がしてね」「今から何をしようかしらね」と次々に話している。介護福祉職は混乱しないように「子どもの頃の思い出や体調のことをお話しくださっているのですね」と返した。この技術はどれ？

1. 要約
2. 承認
3. 賞賛
4. 共感
5. 同意

<details class="answer">
<summary>正解を見る</summary>

**正解：1**　いくつもの話題を「思い出と体調のこと」とまとめて返しています。気持ちを返すのが共感、内容をまとめて返すのが要約です。
</details>
</details>

## ひっかけパターン集（技法で「ほぼ×」）

| 選択肢の表現 | なぜ× |
|---|---|
| 励ます・頑張ってと言う | 気持ちを受け止めていない |
| 同情する・同調する | 共感は感情を区別したうえで理解すること |
| 傾聴しながら解決策を提案する | まず最後まで聴く |
| 閉じられた質問で背景を探る | 背景は開かれた質問で |
| 自己開示で開放の窓を狭くする | 広がる |
