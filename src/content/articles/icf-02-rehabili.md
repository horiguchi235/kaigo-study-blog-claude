**この記事のポイント**

1. リハビリテーションの理念は「**全人間的復権**」。語源は「**再び適したものにする**」で、**名誉の回復**の意味もある。
2. 介護でのリハビリは**生活の視点を重視**。高齢者の訓練は**1回の量を少なく、複数回に分けて**。
3. 廃用症候群＝**筋萎縮・関節拘縮・褥瘡・深部静脈血栓症・うつ状態**。予防の基本は**離床**。1週間寝たきりで筋力は**約15%低下**。

## ① リハビリテーションの理念と領域【介護の基本／障害の理解】

| ○ | × |
|---|---|
| 理念は**全人間的復権** | 機能回復訓練・就労移行支援 |
| 語源は「**再び適したものにする**」、**名誉の回復**の意味もある | ニィリエが定義 |
| **生きる意欲の回復**も含む。身体・精神だけでなく**社会的・職業的**な回復も | 介護保険施設では主に教育的リハ |
| 介護実践では**生活の視点を重視** | 自助努力に任せる／リハ室で集中的に／疾病治療が目標 |
| **職業的リハビリテーション**は領域の1つ | 最終目的は全員のADL自立 |
| 発症直後から開始、施設に限らない、**レクリエーションと組み合わせる**、福祉用具も使う | 障害が固定してから開始／レクと対極 |
| 自立生活運動とも関係が深い | 医療の領域に限定 |

### 4つの領域

| 領域 | 中身 |
|---|---|
| 医学的リハ | 機能回復訓練（急性期・回復期・生活期） |
| 教育的リハ | 障害のある子どもの教育（特別支援教育など） |
| 職業的リハ | 職業訓練・就労支援 |
| 社会的リハ | 社会生活力を高める（地域生活・社会参加） |

> 機能回復訓練は**医学的**リハビリテーション。「社会的リハ」は×。

## ② リハビリ専門職と高齢者の訓練【障害の理解／介護の基本】

| 職種 | ○ 業務 | × |
|---|---|---|
| **言語聴覚士（ST）** | **嚥下訓練**、言語訓練、**失語症の評価** | 心理的な面接 |
| **作業療法士（OT）** | **ADL訓練**、手芸・工作など作業を通じた訓練 | — |
| **理学療法士（PT）** | 立つ・歩くなど**基本動作の訓練**、物理療法 | 短下肢装具の製作 |
| **義肢装具士** | 義肢・装具の**製作・適合** | 義肢の処方（医師）・立位訓練 |
| 視能訓練士 | 視機能の検査・訓練 | 高次脳機能障害の評価 |

### 高齢者のリハビリ

| ○ | × |
|---|---|
| 機能訓練は**1回の量を少なくして複数回に分ける** | — |
| 関節リウマチは**朝のこわばり**があるので**朝は避ける** | 朝に行うと効果的 |
| 関節障害のある人は**関節に負担をかけない**筋力訓練（等尺性運動など） | 関節を積極的に動かす |
| パーキンソン病は**体幹をひねる運動も取り入れる** | 体幹をひねることは避ける |
| 基本動作の訓練は**運動療法** | 物理療法（温熱・電気など） |

## ③ 廃用症候群・フレイル・転倒・ADL【こころとからだのしくみ／発達と老化の理解／生活支援技術】

### 廃用症候群（生活不活発病）

| 起こるもの ○ | 起こらない × |
|---|---|
| **筋萎縮・筋力低下**、**関節拘縮**、骨萎縮（骨粗鬆症） | 筋肥大 |
| **褥瘡**、**深部静脈血栓症**、起立性低血圧、心肺機能の低下 | 高血圧・頻脈 |
| **うつ状態**、意欲低下、認知機能低下 | 躁病・関節炎・下痢 |
| 便秘、食欲低下 | — |

| ○ 病態と対策 | × |
|---|---|
| **深部静脈血栓症 − 離床** | 筋萎縮−日光浴、関節拘縮−運動制限、褥瘡−安静、せん妄−入院 |
| **1週間の安静臥床で筋力は約15%低下** | 1%・5%・50% |

### 予防の事例

| 場面 | ○ 正解 |
|---|---|
| 腰椎圧迫骨折から退院し、日中いつも横になっている80歳 | **日中の休養は座位でとる** |
| 日中もベッド上で過ごす要介護度の高い人 | **個別レクリエーションを取り入れる**（安静・全介助・一人の環境は×） |

### フレイル・転倒

| 用語 | 意味 |
|---|---|
| **フレイル** | **健康と要介護の中間**の状態（虚弱） |
| サルコペニア | 加齢による**筋肉量・筋力の低下** |
| ロコモティブシンドローム | **運動器の障害**で移動機能が低下 |
| ホメオスタシス | 体の内部環境を一定に保つしくみ |

- 転倒は**服用する薬剤と関連がある**（睡眠薬・降圧薬など）。**一度転ぶと再転倒の危険が高まる**。屋内では**居室**が多い。骨折は**大腿骨頸部**など

### ADLとIADL

| ADL（日常生活動作） | IADL（手段的日常生活動作） |
|---|---|
| **入浴**・食事・排泄・更衣・洗面・移乗・整容 | **洗濯**・買物・料理・掃除・乗り物の利用・金銭管理・服薬管理・電話 |
