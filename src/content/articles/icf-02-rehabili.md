**この記事のポイント**

1. リハビリテーションの理念は「**全人間的復権**」。語源は「**再び適したものにする**」で、**名誉の回復**の意味もある。
2. 介護でのリハビリは**生活の視点を重視**。高齢者の訓練は**1回の量を少なく、複数回に分けて**。
3. 廃用症候群＝**筋萎縮・関節拘縮・褥瘡・深部静脈血栓症・うつ状態**。予防の基本は**離床**。1週間寝たきりで筋力は**約15%低下**。

---

## ① リハビリテーションの理念と領域

### 4つの領域

| 領域 | 中身 |
|---|---|
| 医学的リハ | 機能回復訓練・二次障害の予防（急性期・回復期・生活期） |
| 教育的リハ | 障害のある子どもの教育（特別支援教育など） |
| 職業的リハ | 職業訓練・就労支援（ハローワーク・障害者職業センターなど） |
| 社会的リハ | 社会生活力を高める（地域生活・社会参加） |

> 機能回復訓練は**医学的**リハビリテーション。「社会的リハ」は×。

### 理念

| ○ | × |
|---|---|
| 理念は**全人間的復権** | 理念は機能回復訓練・就労移行支援（どちらも手段の1つにすぎない） |
| 語源は「**再び適したものにする**」、**名誉の回復**の意味もある | ニィリエが定義（ニィリエはノーマライゼーションの原理を整理した人で、リハビリの定義とは無関係） |
| **生きる意欲の回復**も含む。身体・精神だけでなく**社会的・職業的**な回復も | 介護保険施設では主に教育的リハ（教育的リハは子どもの教育が中心） |
| 介護実践では**生活の視点を重視** | 自助努力に任せる／リハ室で集中的に／疾病治療が目標（生活の場で、生活の視点で行う） |
| **職業的リハビリテーション**は領域の1つ | 最終目的は全員のADL（日常生活動作）自立（目的は全人間的復権。ADL自立だけではない） |
| 発症直後から開始、施設に限らない、**レクリエーションと組み合わせる**、福祉用具も使う | 障害が固定してから開始／レクと対極 |
| 自立生活運動とも関係が深い | 医療の領域に限定（教育・職業・社会の領域もある） |

### 高齢者のリハビリ

| ○ | × |
|---|---|
| 機能訓練は**1回の量を少なくして複数回に分ける** | — |
| 関節リウマチは**朝のこわばり**があるので**朝は避ける** | 朝に行うと効果的 |
| 関節障害のある人は**関節に負担をかけない**筋力訓練（**等尺性運動**＝関節を動かさずに筋肉に力を入れる運動。壁を押すなど） | 関節を積極的に動かす |
| パーキンソン病は**体幹をひねる運動も取り入れる** | 体幹をひねることは避ける |
| 基本動作の訓練は**運動療法**（体を動かす訓練） | 物理療法（温熱・電気などで痛みをやわらげる治療） |

## ③ 廃用症候群・フレイル・転倒・ADL

### 廃用症候群（生活不活発病）

動かない状態が続くことで起こる心身の機能低下。長く寝ていると**最初に現れやすいのは筋力の低下**です。

| 区分 | 起こるもの ○ |
|---|---|
| 局所性 | **筋萎縮・筋力低下**、**関節拘縮**（関節が固まって動きにくくなる）、骨萎縮（骨がもろくなる＝骨粗鬆症）、**褥瘡**（床ずれ）、**深部静脈血栓症**（脚の奥の静脈に血のかたまりができる） |
| 全身性 | **起立性低血圧**（起き上がると血圧が下がり、ふらつく）、**心肺機能の低下**（少し動いただけで脈が速くなる・息が切れる）、便秘、食欲低下、誤嚥性肺炎 |
| 精神・神経 | **うつ状態**、意欲低下、認知機能低下 |

- 起こらない（×）：**高血圧**・**筋肥大**・躁病・関節炎・下痢
- 予防の基本は**離床**（座る・立つ時間を増やす）。褥瘡の予防は、栄養管理、**定期的な体位変換**（2時間ごとが目安。体圧分散寝具なら間隔を調整）、除圧、皮膚の清潔と乾燥
- 似た言葉：**過用症候群**＝訓練のやりすぎで筋肉や関節を痛める／**誤用症候群**＝誤った方法や介助で痛める（廃用は「使わない」ことが原因）

病態と対策の正しい組み合わせを選ぶ問題では、次のように問われます。

| ○ | × |
|---|---|
| **深部静脈血栓症 − 離床** | 筋萎縮−日光浴、関節拘縮−運動制限、褥瘡−安静、せん妄−入院（どれも動かないことを勧めていて逆効果。日光浴は骨の対策） |
| **1週間の安静臥床で筋力は約15%低下** | 1%・5%・50% |

### 予防の事例

| 場面 | ○ 正解 |
|---|---|
| 腰椎圧迫骨折から退院し、日中いつも横になっている80歳 | **日中の休養は座位でとる** |
| 日中もベッド上で過ごす要介護度の高い人 | **個別レクリエーションを取り入れる**（安静・全介助・一人の環境は×） |

### フレイル・転倒

| 用語 | 意味 |
|---|---|
| **フレイル** | **健康と要介護の中間**の状態（虚弱）。栄養・運動・社会参加で**元に戻れる（可逆性）** |
| サルコペニア | 加齢による**筋肉量・筋力の低下** |
| ロコモティブシンドローム | **運動器の障害**で移動機能が低下 |
| ホメオスタシス | 体の内部環境を一定に保つしくみ |

- フレイルには**身体的・心理的（精神的）・社会的**の3つの側面があります。判定の5項目は、体重減少・筋力（握力）の低下・疲れやすさ・歩く速さの低下・身体活動の低下で、3つ以上あてはまるとフレイル、1〜2つはプレフレイル（フレイルの手前）とされます
- 転倒は**服用する薬剤と関連がある**（睡眠薬・降圧薬など）。**一度転ぶと再転倒の危険が高まる**。屋内では**居室**が多い。骨折は**大腿骨頸部**など

### ADLとIADL・寝たきり度

| ADL（日常生活動作） | IADL（手段的日常生活動作） |
|---|---|
| **入浴**・食事・排泄・更衣・整容（洗面など）・移動（移乗を含む） | **洗濯**・買物・料理・掃除・乗り物の利用・金銭管理・服薬管理・電話 |

- 訓練の場で**できるADL**と、ふだんの生活で**しているADL**を区別し、「している」を「できる」に近づけます

障害高齢者の日常生活自立度（寝たきり度）は次の4ランクです。

| ランク | 状態 |
|---|---|
| **J** | ほぼ自立し、一人で外出できる |
| **A** | 家の中はおおむね自立、外出には介助が必要 |
| **B** | 家の中でも介助が必要。日中もベッド中心だが**座位はとれる** |
| **C** | 一日中ベッドで過ごし、食事・排泄・着替えに介助が必要 |
