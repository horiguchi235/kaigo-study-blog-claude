**この記事のポイント**

1. **中核症状**＝脳の障害で**誰にでも起こる**（記憶・見当識・判断・失語・失行・失認・遂行機能）。**BPSD**＝環境やケアで**起こる人と起こらない人がいる**（徘徊・昼夜逆転・妄想・興奮）。
2. 「〜が**できない**」は中核症状、「〜**してしまう**・**眠れない**」はBPSD、と読むと選択肢を見分けやすい（目安。例外もある）。
3. せん妄＝**急に起こり、意識が濁り、1日の中で変動し、夜に多い**。原因（**薬・発熱・脱水**）を探すのが大事。

## ① 中核症状

| 症状 | 意味 | 試験に出た具体例 |
|---|---|---|
| **記憶障害** | 新しいことを覚えられない。初期は**近時記憶・エピソード記憶** | 10分前の挨拶を覚えていない。食べたことを忘れてご飯をほしがる |
| **見当識障害** | 時間 → 場所 → 人の順にわからなくなる | 「**今いるところはどこですか**」と確認する。目の前の夫を夫とわからず「夫が帰ってくるのでお帰りください」と言う（人の見当識障害） |
| **失語** | 話す・聞いて理解する・読み書きなど、**言葉の働き**が損なわれる | 物の名前が出てこない |
| **失行** | 体は動くのに、**目的に沿った動作ができない**。着衣失行（服の着方がわからない）・構成失行（図形が写せない）・観念失行（道具の使い方がわからない） | **洋服をうまく着られない**、包丁の使い方がわからない |
| **失認** | 目や耳は正常なのに、**何かを認識できない**。相貌失認・視空間失認など | **相貌失認＝目の前の家族がわからない**、皿の模様をおかずと間違える、鏡に映った自分がわからない |
| **視空間認知障害** | 物の位置・距離・形をとらえられない | 椅子にうまく座れない、図形を写せない |
| 半側空間無視 | 片側（多くは左側）にあるものに気づかない。脳卒中の後遺症で多い | 配膳された食事の**左側を残す** |
| **遂行（実行）機能障害** | **計画を立てて段取りをする**ことができない | **調理の手順を順序立てて行えない** |
| **注意障害** | 注意を保てない・切り替えられない | **物音が聞こえると食事を中断したまま**になる |
| 判断力の低下 | 状況に合った判断ができない | 中核症状の代表 |
| 病識の低下 | 自分が病気だという自覚が乏しい | 「どこも悪くない」と受診を嫌がる |

- 長年の裁縫が短時間でできた → 体で覚えた**手続き記憶**は残りやすい
- 試験では、「認知症の症状として**通常見られない**もの」＝**運動失調**（手足の動きがうまく協調しない）が正解として出た。運動失調は認知機能の障害（中核症状）ではない。レビー小体型のパーキンソン症状や血管性の麻痺は、原因疾患による**神経症状**として別に考える

### 加齢による物忘れとの違い

| 加齢の物忘れ | 認知症の物忘れ |
|---|---|
| 体験の**一部**を忘れる（夕食の献立） | 体験**全体**を忘れる（夕食を食べたこと） |
| 忘れた**自覚がある** | **自覚がない** |
| 進行しない・生活に支障なし | 進行する・生活に支障がある |

## ② BPSD（行動・心理症状）と妄想の種類

BPSDは、中核症状に**体調・環境・関わり方**が重なって起こる症状で、原因を整えると**軽くなる**ことがあります。

| ○ BPSDの例 | × BPSDではない（中核症状） |
|---|---|
| **徘徊**・出口を探して歩き回る | 親しい人がわからない |
| **昼夜逆転**・**十分に眠れない** | 言葉を口に出せない／トイレの水を流せない |
| 興奮・暴言・妄想・幻覚・抑うつ・不安 | 計算ができない／計画を立てられない |
| **異食**（食べ物でないものを口に入れる） | 食べたことを忘れる（記憶障害） |
| **夕暮れ症候群**（夕方になると落ち着かず「家に帰る」と言う） | 日付がわからない（見当識障害） |

> 「できない＝中核症状／してしまう＝BPSD」は目安です。迷ったら「<strong>脳の障害そのものか（中核症状）</strong>、<strong>体調・環境・関わりで起こるか（BPSD）</strong>」で判断します。たとえば「食べたことを忘れてご飯をほしがる」は記憶障害（中核症状）です。

**よく出るポイント**
- **興奮はケアの方法によって起こる**ことがある。徘徊は誰にでも起こるわけではない
- もの盗られ妄想は**記憶障害と関係**がある（しまい忘れ → 盗まれた）
- **感情失禁**＝感情を抑えられず、ささいなことで泣いたり笑ったりする。理由もなく急に泣き出し、すぐ笑顔に戻る
- **アパシー**（意欲低下）＝**感情の起伏がみられない・無関心**。「将来に希望がない」「自分を責める」はうつの症状
- 自分の考えや要求を言葉で伝えられないことがあるので、**顔色や表情もよく観察**する

### 妄想の種類

| 名前 | 中身 |
|---|---|
| もの盗られ妄想 | 自分でしまい忘れた物を「誰かに盗まれた」 |
| **嫉妬妄想** | 夫が外出すると「外で女性に会っている」と興奮する |
| **カプグラ症候群** | 家族など身近な人が**よく似た偽物と入れ替わっている** |
| 幻の同居人 | 家の中に知らない人が住んでいると思う |
| **心気妄想** | 病気がないのに**自分は病気だ**と思い込む |

## ③ せん妄

| | **せん妄** | 認知症 |
|---|---|---|
| 発症 | **急に**（数時間〜数日） | ゆるやかに |
| 意識 | **軽い意識障害がある**（ぼんやりする。昏睡のような重い意識障害ではない） | 意識ははっきり |
| 変動 | **日内変動が大きい**、**夜間に多い** | 変動は少ない |
| 幻覚 | **伴うことが多い** | — |
| 注意 | 注意が保てない | — |
| 原因 | **薬剤（睡眠薬など）・発熱・脱水・感染・脳血管障害・体調変化**・環境の変化 | 脳の病気 |
| 経過 | 原因を取り除けば**改善する** | 進行する |

- せん妄中のことは**覚えていない**ことが多い
- 対応のポイントは「**関与する因子を特定する**」＝原因を取り除けば改善する。変化は医療職に報告し、**チームで原因を考える**
- 認知症と間違えやすい病気には**うつ病**（仮性認知症）もある → [若年性認知症・評価スケール・薬・予防](../ninchisho-03-hyoka/)

| 選択肢の表現 | なぜ× |
|---|---|
| 徘徊は認知症なら誰にでも起こる | BPSDは環境・ケア次第 |
