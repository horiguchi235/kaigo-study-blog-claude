「どこに住むのが適切か」を選ぶ事例問題では、<strong>目的（生活の場？リハビリ？医療？）</strong>と<strong>入り方（契約？措置？）</strong>がカギです。

**この記事のポイント**

1. 介護保険施設は **特養（生活の場）・老健（在宅復帰）・介護医療院（医療と生活）** の3つ。
2. 特養の新規入所は**原則要介護3以上**。要支援の人は介護保険施設に入れない。
3. **養護老人ホーム**は経済的・環境的な理由で**市町村の措置**により入所（要介護の条件なし）。
4. **サービス付き高齢者向け住宅**は高齢者住まい法の**賃貸住宅**。義務は**安否確認と生活相談**だけ。
5. **有料老人ホーム**は老人福祉法。介護付（特定施設）・住宅型・健康型がある。

---

## ① 介護保険施設3つ

| | 介護老人福祉施設（特養） | 介護老人保健施設（老健） | 介護医療院 |
|---|---|---|---|
| 根拠法 | 老人福祉法＋介護保険法 | **介護保険法** | **介護保険法**（2018年〜） |
| 目的 | **生活の場**（終の住み家） | リハビリをして**在宅復帰** | **長期療養が必要な人の医療と生活** |
| 対象 | **原則要介護3以上**（特例で1・2も） | 要介護1以上 | 要介護1以上 |
| 医師 | 健康管理に必要な数（非常勤可） | **常勤の医師** | 常勤の医師（Ⅰ型は手厚い） |
| ポイント | 待機者が多い | 入所期間は原則3か月ごとに見直し | 介護療養型医療施設（2024年3月廃止）の移行先 |

## ② そのほかの住まい・施設

| | 根拠法 | 対象・入り方 | 特徴 |
|---|---|---|---|
| **養護老人ホーム** | 老人福祉法 | 65歳以上で**環境上・経済的な理由**で家での生活が難しい人。**市町村の措置** | 要介護でなくてもよい。介護が必要なら外部サービス |
| **軽費老人ホーム**（ケアハウス） | 老人福祉法・社会福祉法 | 60歳以上で、家庭環境・住宅事情などで自宅での生活が難しい人。**契約** | **低額**な料金。A型（食事つき）・B型（自炊）・ケアハウス・**都市型（定員20人以下）** |
| **有料老人ホーム** | **老人福祉法** | **契約** | 介護・食事・家事・健康管理の**1つ以上**を提供。**介護付**（特定施設入居者生活介護）・住宅型・健康型 |
| **サービス付き高齢者向け住宅** | **高齢者住まい法** | 60歳以上など。**賃貸借契約** | バリアフリー、**安否確認（状況把握）と生活相談が必須**。介護は外部サービス |
| **認知症対応型共同生活介護**（グループホーム） | 介護保険法（地域密着型） | **要支援2以上の認知症の人**、原則その市町村の住民 | **5〜9人のユニット**で家庭的に共同生活 |
| **小規模多機能型居宅介護** | 介護保険法（地域密着型） | 登録制（定員29人以下） | 「通い」中心に「訪問」「泊まり」を組み合わせる（住まいではない） |

## ③ 事例で選ぶ

1. 要介護4、家族の介護が難しく、ずっと暮らせる場所がほしい → **特養**
2. 入院していたが、リハビリをして**家に帰りたい** → **老健**
3. 医療的な管理（たんの吸引など）が長く必要、生活の場もほしい → **介護医療院**
4. 自立して自炊もしたいが、バリアフリーで見守りがほしい → **サービス付き高齢者向け住宅**
5. 低所得で身寄りがなく、家での生活が難しい（要介護ではない） → **養護老人ホーム**（措置）
6. 認知症があり、少人数で家庭的に暮らしたい → **グループホーム**

## ひっかけパターン集

| 選択肢の表現 | なぜ× |
|---|---|
| 要支援1の人が特養に入所できる | 介護保険施設は**要介護者**のみ |
| 養護老人ホームは本人との契約で入所 | **市町村の措置** |
| サ高住は食事と介護の提供が義務 | 必須は**安否確認と生活相談** |
| 有料老人ホームは介護保険法に基づく | **老人福祉法** |
| 老健の目的は終身の生活の場 | **在宅復帰**。生活の場は特養 |
| グループホームは要支援1から使える | **要支援2から** |
