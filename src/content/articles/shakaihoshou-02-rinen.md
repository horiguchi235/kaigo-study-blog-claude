**この記事のポイント**

1. **ナショナルミニマム＝国が保障する最低限度の生活**（憲法25条の生存権）、**ソーシャルインクルージョン＝誰も排除せず社会の一員として包み込む**。
2. **地域共生社会＝住民みんなが支え合い、自分らしく活躍できる地域**（「我が事・丸ごと」）。分野を問わず丸ごと受け止める**重層的支援体制整備事業**で進める。
3. 歴史は「**福祉三法（戦後）→ 福祉六法（1960年代）→ 皆保険・皆年金（1961年）→ 社会福祉基礎構造改革（2000年、措置から契約へ）**」。

## ① 福祉の理念・地域共生社会

| 用語 | 意味 |
|---|---|
| **ナショナルミニマム** | **国家が国民に保障する最低限度の生活水準**。イギリスの**ウェッブ夫妻**が唱え、**ベヴァリッジ報告**で社会保障の目標になった |
| **生存権** | **憲法25条**「健康で文化的な最低限度の生活を営む権利」 |
| **ノーマライゼーション** | **障害があっても地域社会の一員として生活できるよう条件を整える** |
| **ソーシャルインクルージョン** | **誰も排除せず社会の一員として包み込む**。社会的な孤立や排除の問題に取り組み、つながりを再構築する |
| バリアフリー | 生活の妨げとなる障壁を**あとから**取り除く |
| ユニバーサルデザイン | **はじめから**誰もが使いやすいように設計する |
| ジェンダー | 社会的・文化的につくられた性差 |
| 居場所 | 自分が安心して身を置ける場所 |

### 地域共生社会

- **すべての住民が支え合い、自分らしく活躍できる地域コミュニティ**
- 人と人、人と社会がつながり、**生きがいや役割**をもって助け合う**包摂的な**社会。「支え手」「受け手」に分かれない
- 「ニッポン一億総活躍プラン」（2016年）：**「我が事・丸ごと」の地域づくり**
- **重層的支援体制整備事業**（2020年の社会福祉法改正で創設、2021年4月施行）：市町村が、介護・障害・子ども・生活困窮などの**分野を問わず**、制度のはざまの課題も**丸ごと**受け止める相談支援・参加支援・地域づくりを一体で行う
- ×：高齢者分野**だけ**の相談強化・公的サービス**だけ**に重点・専門職**だけ**が担う（育児と介護が重なる**ダブルケア**のような複合的な課題こそ、分野を超えて受け止める対象）

## ② 社会福祉の歴史・法・計画

### 措置から契約へ

| | 措置 | 契約 |
|---|---|---|
| 誰が決めるか | **行政**がサービスの内容や行き先を決める | **利用者**が選び、事業者と契約する |
| 利用者の立場 | 行政の決定を受ける | サービスを選ぶ主体 |
| 例 | 養護老人ホームへの入所（現在も措置） | 介護保険（2000年）、障害福祉の支援費制度（2003年） |

**今も残る「措置」**：介護保険が始まって多くのサービスは契約になりましたが、**老人福祉法**の措置は今も残っています。

- **養護老人ホーム**：環境や経済的な理由で家での生活が難しい65歳以上の人を、市町村が措置で入所させる（要介護の条件はない）
- **やむを得ない事由による措置**：虐待や認知症などで本人が契約できない、家族が利用を拒む、といったときに、**市町村**が自分の判断で特別養護老人ホームへの入所やショートステイなどにつなぐ

老人福祉法（1963年）は特養・養護・軽費老人ホームをつくった法律です。名前の似た**老人保健法**（1982年。老人医療費の一部負担。2008年に高齢者医療確保法へ）とは別の法律です。

### 年表

| 年代 | できごと |
|---|---|
| 1874年 | **恤救規則**（明治政府の救貧制度。家族や近所の助け合いが前提） |
| 1922年成立（1927年施行） | 健康保険法（日本初の社会保険の法律） |
| 1929年成立（1932年施行） | **救護法**（国の救護義務を定めた） |
| 1938年 | **国民健康保険法**（農業をする人などにも医療保険） |
| 1941年 | 労働者年金保険法（**1944年に厚生年金保険法**に名前を変更） |
| 1946年 | 日本国憲法（25条2項で「**社会福祉**」の語が初めて法律用語に） |
| 1940年代後半 | **福祉三法**：児童福祉法（1947年）・身体障害者福祉法（1949年）・生活保護法（1950年） |
| 1947年 | **労働者災害補償保険法**・**失業保険法**（1974年に**雇用保険法**へ） |
| 1950年 | 社会保障制度審議会の勧告 |
| 1956年 | 長野県で**家庭養護婦派遣事業**（ホームヘルプの始まり） |
| **1958年** | 国民健康保険法の改正 → **1961年 国民皆保険・皆年金** |
| 1959年 | **国民年金法**（1961年から皆年金） |
| **1960年代** | 精神薄弱者（知的障害者）福祉法（1960年）・**老人福祉法**（1963年。特養・養護・軽費老人ホームを制度化）・母子福祉法（1964年、現・母子及び父子並びに寡婦福祉法）→ **福祉六法** |
| 1971年 | **児童手当法** |
| 1973年 | **福祉元年**（老人医療費の無料化。**高額療養費**も始まった） |
| 1981年 | **国際障害者年** → ノーマライゼーションが広まる |
| 1982年成立（1983年施行） | 老人保健法（老人医療費の一部負担が復活） |
| 1985年成立（1986年施行） | 基礎年金制度の創設 |
| 1987年 | 社会福祉士及び介護福祉士法（介護福祉士の資格ができた） |
| 1989年 | **ゴールドプラン**（高齢者保健福祉推進十か年戦略）：在宅・施設サービスの整備目標 |
| 1997年成立（**2000年施行**） | **介護保険法** |
| **2000年** | **社会福祉基礎構造改革**：社会福祉事業法が**社会福祉法**に。**措置から利用契約へ**、**地域福祉の推進**、**地域福祉権利擁護事業**（現・日常生活自立支援事業）・苦情解決のしくみ |
| 2003年 | **支援費制度**（障害福祉が契約に） |
| 2005年成立（2006年施行） | 障害者自立支援法。2006年は高齢者虐待防止法の施行も |
| 2008年 | 後期高齢者医療制度 |
| 2011年 | 障害者権利条約の批准に向けて障害者基本法を改正（**社会的障壁の除去**） |
| 2017年改正（2018年施行） | 介護保険と障害福祉の**共生型サービス**。社会福祉法の改正で、市町村は分野を超えた**包括的な支援体制**づくりに努めることに |
| **2020年改正**（2021年施行） | 地域共生社会の実現のための社会福祉法等の改正：**重層的支援体制整備事業**の創設、**医療・介護のデータ基盤の整備の推進**など |

> 社会保障の考え方はイギリスで育ちました。ウェッブ夫妻の**ナショナルミニマム**、1942年の**ベヴァリッジ報告**（「ゆりかごから墓場まで」の社会保障の設計図）が代表です。

> 身体障害者福祉法（1949年）が知的障害（1960年）・精神障害より先にできました。障害者の福祉制度が契約になったのは2003年の支援費制度で、高齢者（2000年の介護保険）より**後**です。介護保険法は福祉六法に入りません。

### 社会福祉法

- 生活保護法・児童福祉法・老人福祉法・障害者総合支援法など、社会福祉の各分野に**共通する基本のこと**（社会福祉事業の範囲、社会福祉法人、福祉事務所、社会福祉協議会、苦情解決など）を決めた法律。個別の法律の「**土台**」
- 社会福祉事業法（1951年）を2000年に改正・改称。**3条＝福祉サービスの基本理念（個人の尊厳）**、**4条＝地域福祉の推進**
- 福祉サービス提供体制の確保を**国と地方公共団体の責務**に
- サービス提供者は社会福祉法人に限らない、集団主義・家族責任・専門職への罰則は規定していない

### 福祉の計画

| 計画 | ポイント |
|---|---|
| **介護保険事業計画** | 市町村。**3年1期**。**第1号被保険者の保険料の設定**や地域支援事業の量の見込みに関わる |
| 介護保険事業支援計画 | 都道府県。3年1期。人材確保なども含む |
| 老人福祉計画 | 市町村・都道府県に**策定義務**（施設の有無に関係なく） |
| **障害福祉計画**（障害者総合支援法） | **厚生労働大臣が基本指針**を定め、都道府県・市町村は**策定義務**。障害福祉サービスの**量の見込み**と確保の方法を定める実施計画。**3年1期**で、障害児福祉計画と一体的に |
| **障害者計画**（障害者基本法） | 障害者施策**全体の基本計画**。国は**障害者基本計画**（今は第5次、2023〜2027年度）、都道府県・市町村も策定義務 |
| 地域福祉計画 | **市町村**が策定（社協ではない）。策定は**努力義務**（老人福祉計画・障害福祉計画は義務） |

障害者計画＝「**理念の計画**」、障害福祉計画＝「**サービス量の計画**」と覚えます。

## ③ 福祉の法律の目的と憲法の人権

### 各法律の目的・理念

| 法律 | 目的・理念 |
|---|---|
| 介護保険法 | **尊厳の保持**・**能力に応じた自立**した日常生活 |
| 生活保護法 | **最低限度の生活の保障**と**自立の助長** |
| 障害者基本法 | **個人の尊厳**・**共生社会**の実現 |
| 児童福祉法 | 児童の健やかな育成 |
| 老人福祉法 | 高齢者を敬愛し、生きがいをもてる生活を保障 |

> 「健康で文化的な最低限度の生活」は憲法25条と生活保護法の言葉です（障害者基本法・介護保険法の目的ではない）。

### 憲法の人権

| 人権 | 中身 |
|---|---|
| **平等権** | 法の下の平等（**14条**） |
| **自由権** | 国家から干渉されない権利。人権の歴史では**先に確立** |
| **社会権** | **生存権（25条）** など。自由権より**あとから**発展した（同時期ではない） |
| 人権を守るための権利 | **参政権・請願権・裁判を受ける権利** |
