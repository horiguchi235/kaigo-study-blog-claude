**この記事のポイント**

1. **ナショナルミニマム＝国が保障する最低限度の生活**（憲法25条の生存権）、**ソーシャルインクルージョン＝孤立・排除をなくしつながりを取り戻す**。
2. **地域共生社会＝住民みんなが支え合い、自分らしく活躍できる地域**（「我が事・丸ごと」）。
3. 歴史は「**福祉三法（戦後）→ 福祉六法（1960年代）→ 皆保険・皆年金（1961年）→ 社会福祉基礎構造改革（2000年、措置から契約へ）**」。

## ① 福祉の理念・地域共生社会【社会の理解】

| 用語 | 意味 |
|---|---|
| **ナショナルミニマム** | **国家が国民に保障する最低限度の生活水準**。イギリスのベヴァリッジ報告など |
| **生存権** | **憲法25条**「健康で文化的な最低限度の生活を営む権利」 |
| **ノーマライゼーション** | **障害があっても地域社会の一員として生活できるよう条件を整える** |
| **ソーシャルインクルージョン** | **社会的な孤立や排除**の問題に取り組み、**つながりを再構築**する |
| バリアフリー | 生活の妨げとなる障壁を取り除く |
| ユニバーサルデザイン | 誰もが使いやすいデザイン |
| ジェンダー | 社会的・文化的につくられた性差 |

### 地域共生社会

- **すべての住民が支え合い、自分らしく活躍できる地域コミュニティ**
- 人と人、人と社会がつながり、**生きがいや役割**をもって助け合う**包摂的な**社会
- 「ニッポン一億総活躍プラン」（2016年）：**「我が事・丸ごと」の地域づくり**
- ×：ダブルケアへの対応・高齢者分野だけの相談強化・公的サービス重点・専門職主体

## ② 社会福祉の歴史・法・計画【社会の理解】

### 年表

| 年代 | できごと |
|---|---|
| 1946年 | 日本国憲法（25条に「**社会福祉**」の語） |
| 1940年代後半〜 | **福祉三法**：生活保護法・児童福祉法・身体障害者福祉法 |
| 1950年 | 社会保障制度審議会の勧告 |
| **1958年** | 国民健康保険法の改正 → **1961年 国民皆保険・皆年金** |
| **1960年代** | 精神薄弱者（知的障害者）福祉法・**老人福祉法**（1963年）・母子福祉法 → **福祉六法** |
| 1981年 | **国際障害者年** → ノーマライゼーションが広まる |
| 1985年 | 基礎年金制度の創設（1986年施行） |
| **2000年** | **社会福祉基礎構造改革**：社会福祉事業法が**社会福祉法**に。**措置から利用契約へ**、**地域福祉の推進**、**地域福祉権利擁護事業**（現・日常生活自立支援事業）の創設 |
| 2006年 | 高齢者虐待防止法の施行、障害者自立支援法の施行 |
| 2011年 | 障害者権利条約の批准に向けて障害者基本法を改正（**社会的障壁の除去**） |
| **2020年** | 地域共生社会の実現のための社会福祉法等の改正：**医療・介護のデータ基盤の整備の推進**など |

> 身体障害者福祉法（1949年）が知的障害（1960年）・精神障害より先にできました。障害者の福祉制度が契約になったのは2003年の支援費制度で、高齢者（2000年の介護保険）より**後**です。

### 社会福祉法

- **地域福祉の推進**を規定
- 福祉サービス提供体制の確保を**国と地方公共団体の責務**に
- サービス提供者は社会福祉法人に限らない、集団主義・家族責任・専門職への罰則は規定していない

### 福祉の計画

| 計画 | ポイント |
|---|---|
| **介護保険事業計画** | 市町村。**第1号被保険者の保険料の設定**に関わる |
| 老人福祉計画 | 市町村・都道府県に策定義務（施設の有無に関係なく） |
| **障害福祉計画** | **厚生労働大臣が基本指針**を定め、都道府県・市町村は**策定義務**。サービス量の見込みを定める。障害児福祉計画と一体的に |
| 地域福祉計画 | **市町村**が策定（社協ではない） |
