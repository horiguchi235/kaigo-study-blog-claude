介護福祉士試験には「自立」がつく言葉がたくさん出てきます。**どの法律の言葉か**を最初に押さえると混乱しません。

**この記事のポイント**

1. **障害者総合支援法**：自立支援給付（総称）・**自立支援医療**・**自立訓練**・**自立生活援助**。
2. **生活困窮者自立支援法**：**自立相談支援事業**（必須事業）。
3. **社会福祉法**（社協）：**日常生活自立支援事業**（判断能力が不十分な人のお金の管理など）。
4. **生活保護法**：**就労自立給付金**。
5. 評価の物差し：**障害高齢者の日常生活自立度**（J・A・B・C）と**認知症高齢者の日常生活自立度**（Ⅰ〜Ⅳ・M）。

## ① 一覧表

### よく出る5つ＋就労自立給付金

| 名前 | 根拠法 | 中身 | 窓口・担い手 |
|---|---|---|---|
| **自立支援医療** | 障害者総合支援法 | 医療費の自己負担を軽くする（原則1割）。**更生医療**（18歳以上の身体障害）・**育成医療**（18歳未満）・**精神通院医療** | 市町村（精神通院は都道府県） |
| **自立訓練** | 障害者総合支援法（訓練等給付） | 機能訓練（身体のリハビリ、原則1年6か月）・生活訓練（家事など生活の訓練、原則2年） | 事業所 |
| **自立生活援助** | 障害者総合支援法（訓練等給付） | 一人暮らしを始めた人を**定期訪問・随時相談**で支える（2018年〜） | 事業所 |
| **自立相談支援事業** | **生活困窮者自立支援法** | 生活に困っている人の相談を受け、支援プランをつくる（**必須事業**） | 自治体（社協・NPOに委託可） |
| **日常生活自立支援事業** | **社会福祉法** | 判断能力が不十分な人の**福祉サービス利用援助・日常的な金銭管理・書類預かり** | 都道府県・指定都市社協（窓口は**市町村社協**） |
| **就労自立給付金** | **生活保護法** | 就職などで保護をやめる世帯に一括支給 | 福祉事務所 |

**自立支援給付**は、障害者総合支援法で一人ひとりに支給されるサービスの**総称**です（介護給付・訓練等給付・自立支援医療・補装具・相談支援など）。障害福祉サービスは「自立支援給付」と、市町村が行う「地域生活支援事業」の2本立てになっています（全体像は障害福祉制度①・比較①）。

## ③ 見分けるコツ

- 「**医療**」が入っていたら → 医療費の軽減（**自立支援医療**）
- 「**訓練**」が入っていたら → 期間限定で力をつける（**自立訓練**）
- 「**生活援助**」なら → 一人暮らしの見回り（**自立生活援助**）
- 「**相談支援事業**」なら → 生活困窮者（**自立相談支援事業**）
- 「日常生活**自立支援事業**」まで続いたら → 社協のお金の管理（**日常生活自立支援事業**）

頭に「日常生活」がつく言葉はほかにもあるので、**最後まで読んで**見分けます。

| 言葉 | 制度 | 中身 |
|---|---|---|
| **日常生活自立支援事業** | 社会福祉法（社協） | 判断能力が不十分な人のお金の管理・福祉サービスの利用援助 |
| **日常生活用具**給付等事業 | 障害者総合支援法（市町村の地域生活支援事業） | 特殊寝台・入浴補助用具・ストーマ用装具などの給付・貸与 |
| 介護予防・**日常生活支援総合事業** | 介護保険法（市町村の地域支援事業） | 要支援の人などへの訪問型・通所型サービスや介護予防（「総合事業」） |
| 障害高齢者・認知症高齢者の**日常生活自立度** | 国の判定基準 | 体の動き・認知症による支障の程度を表すランク（上の②） |

## ひっかけパターン集

| 選択肢の表現 | なぜ× |
|---|---|
| 日常生活自立支援事業は障害者総合支援法の事業 | **社会福祉法**（社協が実施） |
| 自立相談支援事業は生活保護法の事業 | **生活困窮者自立支援法** |
| 育成医療は18歳以上の身体障害者が対象 | 18歳以上は**更生医療**、18歳未満が育成医療 |
| 自立訓練は期間の定めがない | 機能訓練・生活訓練とも**期間の目安あり** |
| 日常生活用具の給付は社会福祉協議会の日常生活自立支援事業で行う | 日常生活用具は障害者総合支援法の**地域生活支援事業**（市町村） |
