どちらも「生活に困っている人」を支える制度ですが、**生活保護に至る前に支えるのが生活困窮者自立支援制度**、**最低限度の生活を保障するのが生活保護**です。

**この記事のポイント**

1. **生活困窮者自立支援制度＝第2のセーフティネット**（生活保護の手前）。**生活保護＝最後のセーフティネット**。
2. 生活困窮者自立支援法の**必須事業は「自立相談支援事業」と「住居確保給付金」**。
3. 生活保護は**8つの扶助**、医療扶助・介護扶助は**現物給付**。
4. 生活保護は**資産・能力・ほかの制度を活用してもなお足りない**ときに受けられる（補足性の原理）。
5. お金の出方は3通り：**住居確保給付金・生活保護＝返さない（給付）**、**生活福祉資金＝返す（貸付）**。

---

## ① 3段のセーフティネット

| | 何で支える？ | 例 |
|---|---|---|
| 第1のセーフティネット | **社会保険・労働保険** | 年金・医療保険・雇用保険・労災 |
| 第2のセーフティネット | **生活困窮者自立支援制度**・求職者支援制度 | 相談・家賃の給付・就労準備 |
| 最後（第3）のセーフティネット | **生活保護** | 最低生活費に足りない分を支給 |

- **求職者支援制度**：雇用保険を受けられない人（受給が終わった人・加入していなかった人など）が、無料の職業訓練を受け、条件を満たせば訓練中の生活費の給付金も受けられるしくみ（窓口はハローワーク）。

## ② 2つの制度を比べる

| | 生活困窮者自立支援制度 | 生活保護制度 |
|---|---|---|
| 根拠法 | **生活困窮者自立支援法**（2015年施行） | **生活保護法**（1950年）…<strong>憲法25条（生存権）</strong>を具体化 |
| 対象 | 経済的に困窮し、**最低限度の生活を維持できなくなるおそれ**のある人 | 最低生活費に収入が足りない人（要保護者） |
| 実施 | 福祉事務所を設置する自治体（**社協・NPOなどに委託できる**） | **福祉事務所** |
| 主な内容 | 相談・計画づくり（自立相談支援）、家賃の給付、就労準備、家計改善、子どもの学習支援 | **8つの扶助**：生活・教育・住宅・医療・介護・出産・生業・葬祭 |
| お金 | **住居確保給付金**（家賃相当額、原則3か月・最長9か月） | 扶助として支給。生活扶助などは金銭、**医療扶助・介護扶助は現物給付**（サービスそのものを受ける） |
| 資産の活用 | 住居確保給付金などには収入・資産の要件あり | **資産・能力・他の制度の活用が前提**（補足性） |
| 費用 | 必須事業は**国3/4**（そのほかの事業は国の補助） | **国3/4**・自治体1/4 |
| 就労の支援 | 就労準備支援事業・認定就労訓練（中間的就労） | 被保護者就労支援事業・**就労自立給付金**（保護をやめるとき一括支給） |

- **介護扶助**：生活保護を受けている要介護・要支援の人の介護サービスの費用。65歳以上は介護保険の自己負担分を、介護保険に入っていない40〜64歳の人は費用の全額を介護扶助でまかないます。

## ③ 生活困窮者自立支援法の事業

| 種類 | 事業 |
|---|---|
| **必須事業** | **自立相談支援事業**（相談を受け、支援プランをつくる）／**住居確保給付金**（離職などで家を失うおそれのある人に家賃相当額） |
| **努力義務** | **就労準備支援事業**（すぐ働けない人の生活習慣づくりなど）／**家計改善支援事業**（家計の立て直し）／**居住支援事業**（住まいのない人への一時的な宿泊・食事の提供と、その後の見守り。2025年4月に「一時生活支援事業」から名前が変わった） |
| 任意事業 | **子どもの学習・生活支援事業** |

**2025年4月施行の改正のポイント**

- 住居確保給付金の対象に、収入が大きく減り、**家計を立て直すために家賃の安い住まいへ移る必要がある人**も加わった
- 就労準備支援・家計改善支援などを、**生活保護を受けている人**も使えるようになった（生活保護の側でも同じような事業を行う）
- 家計改善支援事業への国の補助が手厚くなった（1/2 → 2/3）

## ④ お金を出す制度の違い

| 制度 | 実施 | 出し方 | 返す？ |
|---|---|---|---|
| **住居確保給付金** | 自治体（生活困窮者自立支援法） | 家賃相当額を**給付**（大家さんへ直接払う） | 返さない |
| **生活福祉資金貸付制度** | **都道府県社会福祉協議会**（窓口は市町村社協） | 低所得・高齢者・障害者の世帯に**貸付**（低利または無利子） | **返す** |
| **生活保護** | 福祉事務所 | 最低生活費に足りない分を**扶助** | 返さない（原則） |

---

## ⑤ 生活保護の原理・原則（復習）

- **4つの原理**：**国家責任**／**無差別平等**／**最低生活の保障**／**補足性**（資産・能力などを活用しても足りない分を補う）
- **4つの原則**：**申請保護**（原則本人・扶養義務者・同居の親族が申請）／基準及び程度／必要即応／**世帯単位**

## ひっかけパターン集

| 選択肢の表現 | なぜ× |
|---|---|
| 生活困窮者自立支援制度は最後のセーフティネット | **第2**。最後は生活保護 |
| 子どもの学習支援は必須事業 | **任意事業**。必須は自立相談支援と住居確保給付金 |
| 生活困窮者自立支援法では就労自立給付金が出る | 就労自立給付金は**生活保護** |
| 生活保護は個人単位で行う | 原則**世帯単位** |
| 医療扶助は現金で支給される | 医療・介護扶助は**現物給付** |
| 自立相談支援事業は社会福祉法人に委託できない | **委託できる** |
| 生活福祉資金は返さなくてよい | **貸付**なので返す。返さなくてよいのは住居確保給付金 |
