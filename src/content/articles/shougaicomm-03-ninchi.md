**この記事のポイント**

1. 認知症の人には**否定・訂正・説得をしない**。本人の**世界に合わせ**、**気持ちに沿って**応じる（「おなかがすきましたか」）。
2. 抑うつの人は**励まさない**。「死にたい」には「**とてもつらいのですね**」、**見守っていることを伝える**。
3. 妄想は**肯定も否定もせず聞く**。知的障害の人には**落ち着ける場所で、一緒に考える**。

## ① 認知症の人とのコミュニケーション【コミュニケーション技術】

### 基本

**情報は簡潔に**、一度に1つずつ。目線を合わせ、ゆっくり。

### 場面で覚える

| 場面 | ○ 正解 | × |
|---|---|---|
| 朝食を済ませたのにまた朝食の準備 | 「**おなかがすきましたか**」 | 「さっき食べたでしょう」 |
| 面会に来た夫が誰かわからず不安そう | 「**ご主人ですよ。来てもらってよかったですね**」 | 誰だかわかりますか？と試す |
| 「亡くなった人が立っている」（幻視） | **受容する** | 否定する・見に行かせる |
| 同じ話を繰り返す | **話の内容に沿った会話** | 話題を変える・前にも聞いたと伝える |
| 男性職員を亡き夫と思い「お父さん聞いて」と不安そう | **話に耳を傾ける** | 夫ではないと訂正 |
| 自分の料理と知らず「これは誰のもの？」 | 「**一緒に作って食べましょう**」 | — |
| 小さくたたんだティッシュを「お金はこれしかありません」と渡す | **飲食店での会計の場面だと受け止めて対応** | ティッシュの使い方を教える |
| 「家に帰ります」と衣類を出している | まず**挨拶しながら表情や行動を観察** | — |
| 「場所が覚えられない。ここでやっていけるか」 | **トイレや食堂を一緒に歩いて確認** | 大丈夫ですよと励ますだけ |
| 発語が減り視線が合わない | **表情やしぐさを確かめながら感情の理解に努める** | — |
| 進行して問いかけにも応えたり応えなかったり | **ボディタッチを増やす** | 沈黙・開かれた質問・コミュニケーションノート |
| 話がそれて「何の話だったかな」 | 「**何かお願いがあるのではありませんか**」と本題に戻す | 脱線した話を広げる |

<details>
<summary>✏️ 解いてみよう（第37回）</summary>

アルツハイマー型認知症が進行しているAさん。昼食の配膳をすると「お金はこれしかありません。足りますか」と小さくたたんだティッシュペーパーを渡してきた。対応として最も適切なものはどれ？

1. ティッシュは口の周りを拭くものだと伝える
2. ティッシュが足りないサインと受け止める
3. 飲食店での会計の場面だと認識して対応する
4. 食事に集中するよう促す
5. 小遣いの増額を家族に相談する

<details class="answer">
<summary>正解を見る</summary>

**正解：3**　Aさんにとっては「お店で食事の代金を払う」場面です。本人の世界に合わせて受け止めると安心して食事ができます。

## ② 抑うつ・精神障害・知的障害・終末期【コミュニケーション技術】

### 抑うつ状態

| ○ | × |
|---|---|
| 初めて関わるきっかけは「**今日は少し暖かくなりましたね**」など負担のない話題 | 悩みをいきなり聞く |
| **見守っていることを伝える** | 励ます・気分転換に連れ出す |
| 「もう死んでしまいたい」→「**とてもつらいのですね**」 | 「元気を出して」「落ちこんだらだめ」「どうして寝てばかり」 |
| 意欲が低下した人には**意欲低下の背景を考える**ことを最優先 | — |

### 精神障害

| 場面 | ○ 正解 |
|---|---|
| 統合失調症の人が妄想を話す | **理解できなくても、否定も肯定もせずに関わる** |
| 「頭の中に機械が埋め込まれ監視されている」と興奮 | **肯定も否定もせずに聞く** |
| 双極性障害で考えがつながりなく浮かび多弁（躁状態） | 「**いつもより気分が高ぶっていますよ**」と状態を伝える |

### 知的障害

| 場面 | ○ 正解 |
|---|---|
| 自閉症のある20歳が人を叩き、家族にも叱られた後、個室で | 「**ここで話をしましょう**」（まず落ち着ける場で） |
| 一人暮らしを始めた人が説明書を見てもゴミを分別できない | 「**ゴミ捨ては難しいですよね。できることをいっしょに考えましょう**」 |

### 終末期

衰弱した97歳が「お迎えはまだかしらね」と穏やかに → **手を握り、ゆっくりさする**（言ってはいけない・早く寝て・素通りは×）。

<details>
<summary>✏️ 解いてみよう（第36回）</summary>

抑うつ状態で寝ていることが多く、「もう死んでしまいたい」とつぶやくFさん。介護福祉職の言葉かけとして、最も適切なものはどれ？

1. 「落ちこんだらだめですよ」
2. 「とてもつらいのですね」
3. 「どうしてそんなに寝てばかりいるのですか」
4. 「食堂へおしゃべりに行きましょう」
5. 「元気を出して、頑張ってください」

<details class="answer">
<summary>正解を見る</summary>

**正解：2**　まず気持ちを受け止めて共感します。励ましや否定は「わかってもらえない」と感じさせ、さらに追い詰めることがあります。
</details>
</details>
