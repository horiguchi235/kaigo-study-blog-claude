**この記事のポイント**

1. 口腔内・鼻腔内の吸引は**咽頭の手前まで**（口腔内は**口蓋垂に当たらない手前まで**、鼻腔内は**医師・看護職から指示された長さまで**）、気管カニューレ内部は**カニューレの先端を越えない**。姿勢は**上半身を10〜30度**起こす。
2. 取り切れなくても**時間を延ばす・圧を上げる・太くする・とどめる**は×。**呼吸が落ち着いてから**もう一度。
3. 気管カニューレ内部は**無菌的**に（**滅菌精製水**）。終わったら**人工呼吸器の作動**と**SpO2**を確認。

---

> **注意**　喀痰吸引・経管栄養は、所定の研修を修了し、医師の指示のもとで行う行為です。この記事の手順は試験の基本としてまとめたもので、実際は研修と勤務先の手順に従ってください。

## ① 吸引できる範囲と、2種類の吸引の違い

**この表を覚えれば、吸引の問題の半分は解けます。**

| | 口腔内・鼻腔内 | **気管カニューレ内部** |
|---|---|---|
| 深さ | **咽頭の手前まで**。口腔内は**口蓋垂（のどちんこ）に当たらない手前まで**、鼻腔内は**医師・看護職から指示された長さまで** | **カニューレの先端を越えない** |
| 清潔の程度 | 清潔 | **無菌的**（滅菌したチューブを使い、チューブに触れる部分を汚さない） |
| 洗浄水 | 水道水でよい | **滅菌精製水** |
| 1回の時間の目安 | **10〜15秒以内**（指示どおり） | **10秒以内**（指示どおり。口腔内より長くしない） |
| 吸引圧 | 医師の指示どおり | 医師の指示どおり（研修テキストの例では20kPa以下）。口腔内より高くしない |
| チューブの太さ | 指示どおり | カニューレ内径の**2分の1以下** |
| チューブ | 口腔・鼻腔用 | カニューレ用（口腔・鼻腔用と**区別**する） |

**言葉の意味**
- **陰圧**＝吸い込む力が出ている状態。吸引器が陰圧になれば、痰を吸い出せる。
- **気管切開**＝首の前に穴をあけて気管に通じる道をつくること。その穴に入れる管が**気管カニューレ**。
- **臥位（がい）**＝寝た姿勢。仰臥位＝あおむけ、腹臥位＝うつぶせ。
- **COPD**＝慢性閉塞性肺疾患。たばこなどで肺が傷み、息が吐きにくく痰がたまりやすい病気。

**位置関係**：顔を横から見ると、鼻腔・口腔の奥に**咽頭**（のど）があり、その下で空気の通り道の**喉頭・気管**（前）と、食べ物の通り道の**食道**（後ろ）に分かれます。介護福祉士が吸引できるのは**咽頭の手前まで**。鼻腔の吸引では、チューブを鼻の穴から上向きではなく、**顔に対して水平に、まっすぐ奥へ**進めます。

## ② 口腔内・鼻腔内の吸引

### 姿勢

- 姿勢は**上半身を10〜30度挙上**（少し起こした姿勢）。
- 頭を低くする・平らなあおむけ（仰臥位）・うつぶせ（腹臥位）・座らせるは×。

### いつ吸引するか・吸引の前に見ること

- 吸引は時間を決めて行うものではなく、**痰がたまって本人が苦しいとき・必要なとき**に行います。「1時間おきに」「就寝後は控える」は×。**食後や就寝中でも必要なら行います**（試験では「食後の吸引は避ける」は×）。
- ただし食べた直後は、チューブの刺激で吐きやすいので、姿勢と吐き気に注意します。
- 吸引が必要になりやすい状態：痰が増えている・咳の力が弱い・痰がかたい。
- 吸引の前に、**口の中の状態と入れ歯（義歯）**を確かめます（ぐらついた義歯は、口を開けたときに落ち込むおそれ）。口から吸引したから鼻は不要、とは限りません。

### 手順の流れ

<photo name="iryoucare-02__kyuuin" caption="吸引器と物品。**吸引びん**の量、**圧**（指示どおりか）、**カテーテル**・清浄綿・手袋を準備します。">

1. 医師の**指示書を確認**し、利用者に**説明して同意**を得る（毎回）
2. 実施者が**手洗い・手指消毒**、使い捨て手袋をつける
3. カーテンなどで**プライバシー**に配慮し、**姿勢**を整える
4. 物品（吸引器・**吸引びん**の量・**カテーテル**・清浄綿〈消毒液をしみこませた使い捨ての綿〉・手袋など）を確認し、吸引器のスイッチを入れて**陰圧になる**こと、**圧が指示どおり**かを確かめる
5. **圧をかけずに**チューブを入れる（鼻腔は粘膜が薄く出血しやすいので、とくにゆっくり）
6. 圧をかけ、**チューブを回しながら**、決められた時間内で吸う
7. 終わったら**チューブの外側を清浄綿で拭き、洗浄水を吸って**内側を洗う
8. 利用者の顔色・呼吸・痰の量や色を**観察**し、**報告・記録**する

| ○ | × |
|---|---|
| **吸引のたびに**利用者に**説明**して同意を得る | 説明は初回だけ |
| 医師の指示書は**毎回**確認 | 初回に一度だけ確認 |
| 吸引器が**陰圧になる**ことを確認 | 確認せずに始める |
| 吸引びんは清潔なものを用意する | 吸引びんは滅菌品を用意する |
| チューブの太さは**指示どおり** | チューブは痰の量で選ぶ |
| **プライバシー**に配慮（カーテン） | 同室者から見える状態 |
| 実施者が**手洗い・手指消毒** | 利用者に手指消毒してもらう |
| **圧をかけずに**チューブを入れる | 圧をかけたまま挿入 |
| 口腔内は**チューブを回転させながら**吸う | 口蓋垂まで入れる（口蓋垂に当たらない手前まで） |
| 吸引圧・時間は**指示どおり** | 介護福祉士が体調で圧を決める |
| 終わったら**チューブの外側を拭き、洗浄水を吸う** | 洗浄水→拭く、の順 |

### 困ったとき

| 場面 | ○ 正解 |
|---|---|
| 1回で取り切れない | **呼吸が落ち着いたことを確認**してから再度。時間延長・圧を上げる・太いチューブ・とどめるは× |
| 鼻腔内吸引で**血液が少量混じった** | **鼻腔と口腔の中を観察**して看護職へ報告。再吸引・消毒・とどめるは× |
| 入浴 | **入浴の前後**に吸引（湯気で痰がゆるむ） |
| 吸引器が吸わない | 電源 → 吸引びんのふたの密閉 → びんの中身（いっぱいなら捨てる）→ チューブの接続 → 圧、の順に確認 |
| 吸引中に吐いた | **すぐ中止**し、顔を横に向けて看護職へ |
| 出血が多い | 中止して顔を横に向け、看護職へ（決められた圧だったかも確認） |
| チューブをかむ・口を開けない | ゆっくり抜いて全身を観察し、報告 |
| 痰の色がいつもと違う | 体温を測って報告 |

### 痰を出しやすくする生活支援

- **室内の空気を清浄に**、**加湿**（湿度50〜60％）、**水分をとる**
- **体位ドレナージ**：痰がたまっている側を**上**にする（右肺にたまる → **左側を下**に）
- 適度に体を動かす・体位変換する

## ③ 気管カニューレ内部の吸引と人工呼吸器

### 気管カニューレの構造

- 気管切開した穴から**気管**に入れる管（咽頭ではない）。**定期的に交換**が必要（医療職）
- **カフ**は**下端**についた風船で、**空気**を入れてふくらませる（すき間から分泌物が気管に流れ込むのを防ぐ）
- **サイドチューブ**から、**カフの上にたまった分泌物を吸引**できる
- **パイロットバルーン**＝カフのふくらみ具合を外から確かめる小さな風船

### 吸引のときの注意

- カニューレの先端を越えて入れると、気管の壁を傷つけるほか、**迷走神経**（心臓の動きをゆっくりにする神経）が刺激されて、**心拍が遅くなる・血圧が下がる**危険がある。
- カニューレを抜いて吸引する・20〜30秒吸引する・気管分岐部まで入れる、は×。
- 吸引中は空気も吸い出すので、指示より長くなったら<strong>動脈血酸素飽和度（SpO2）</strong>・顔色・呼吸を確認する。

### 人工呼吸器

- 気管切開して使う**侵襲的**（体に管を入れる）なものと、鼻や口のマスクで使う**非侵襲的**なものがある。
- 吸引のときは**コネクターを外し、終わったら確実につなぎ**、**人工呼吸器の作動状況を確認**する。
- 停電時の電源を確保しておく。アラームが鳴りやまないときは、すぐ医療職へ。
- **マスク型（非侵襲的）**の人に口腔・鼻腔の吸引をするときは、取り決めに沿ってマスクを外し、外している時間が長くならないよう**手早く**行い、終わったらマスクが確実についているかを確認する。吐くと息の通り道がふさがるので、顔を横に向けた姿勢にしておく。
- 気管カニューレの人は、人工呼吸器から空気が入ったのを確かめてからコネクターを外し、回路の中の**水滴がカニューレに入らない**ようにする。

## ④ 吸引前後の観察と、物品の管理

### すぐ連絡？　観察して報告？

| 様子 | 対応 |
|---|---|
| 顔色が悪い・唇や爪が紫色（チアノーゼ） | **すぐ医療職に連絡** |
| 呼吸が苦しそう、吸引しても苦しさが続く | **すぐ医療職に連絡** |
| 意識の変化 | **すぐ医療職に連絡** |
| SpO2が、その人のいつもの値（基準は95〜100％）や指示された値に**戻らない** | **すぐ医療職に連絡**（大きく下がるまで待たない） |
| 人工呼吸器のアラームが鳴りやまない | **すぐ医療職に連絡** |
| 呼吸が止まった・吐いた物がのどにつまった | **すぐ医療職に連絡** |
| 気管カニューレが抜けている | **すぐ医療職に連絡** |
| 人工呼吸器の動きに合わせて胸がふくらまない・停電で人工呼吸器が止まった | **すぐ医療職に連絡** |
| 鮮やかな赤い痰（出血） | **すぐ医療職に連絡** |
| 黄色・緑色の痰 | 感染の疑い。観察して報告・記録 |
| うっすら赤い痰 | 口・鼻・のどの小さな傷の疑い。観察して報告・記録 |
| さらさらで量が多い痰 | 急な気道の炎症の疑い。観察して報告・記録 |
| 粘りが強い痰 | **水分不足**の疑い。水分・加湿を見直し、報告・記録 |

呼吸音が「ヒューヒュー」「ゼーゼー」（**喘鳴**）、「ゴロゴロ」なら、痰や分泌物がたまっているサインです。

### 物品の管理

| ○ | × |
|---|---|
| 吸引びんの中身は**70〜80％になる前**に捨てる | あふれる直前まで使う |
| 洗浄水・消毒液は**少なくとも24時間ごと**に交換（施設では8時間ごとも）。継ぎ足さず、容器ごと取り換える | 72時間で交換／継ぎ足して使う |
| チューブの洗浄は**水**（気管カニューレは滅菌精製水） | アルコールで洗浄 |
| 物品は清潔な場所に置く | 床やベッドに直接置く |
| **清浄綿は1回ごとに捨てる** | 使い回す |

- 吸引チューブの保管は、**浸漬法**（しんしほう：消毒液につけておく）か、**乾燥法**（乾かして保管する）。気管カニューレ内部の吸引チューブは、感染予防のため**1回ごとの使い捨て**がすすめられている。
- 停電に備えて、手動式・足踏み式の吸引器を予備にすることもある。

### 本人・家族の気持ちへの対応

- 吸引は、本人や家族にとって**苦痛や不安が大きい**ものです。気持ちを否定せずに受け止め、療養生活の不安や希望を具体的に聞きます。
- 強く嫌がるときは、医師・看護職と一緒に説明し、複数でかかわって、本人の気持ちを医療職と共有します。
- 説明する内容：なぜ必要か・目的と方法・起こりうる危険・ほかの方法があるか・しなかった場合どうなるか。

### 子どもの吸引・家族

- 子どもは吸引の必要性を理解できず、**怖がって抵抗することが多い**。年齢に応じて事前に説明し（**プレパレーション**）、泣いていたら落ち着くまで待つ。
- **吸引圧は大人より低く**、時間も短く。チューブの長さなどは個別の指示に従う。
- 在宅では、**家族**もあらかじめ吸引の操作の練習を受けておくとよい。

| 選択肢の表現 | なぜ× |
