## ① 口腔内・鼻腔内の吸引【医療的ケア】

### 範囲と姿勢

- 介護福祉士が吸引できるのは**咽頭の手前まで**。口蓋垂（のどちんこ）より奥は×
- 姿勢は**上半身を10〜30度挙上**。頭を低くする・腹臥位・座らせるは×

### 準備と手順

<photo name="iryoucare-02__kyuuin" caption="吸引器と物品。**吸引びん**の量、**圧**（指示どおりか）、**カテーテル**・清浄綿・手袋を準備します。">

| ○ | × |
|---|---|
| **吸引のたびに**利用者に**説明**して同意を得る | 説明は初回だけ |
| 医師の指示書は**毎回**確認 | 初回に一度だけ確認 |
| 吸引器が**陰圧になる**ことを確認 | 吸引びんは滅菌品／チューブは痰の量で選ぶ |
| **プライバシー**に配慮（カーテン） | 同室者から見える状態 |
| 実施者が**手洗い・手指消毒** | 利用者に手指消毒してもらう |
| 口腔内は**チューブを回転させながら**吸う | 圧をかけたまま挿入／口蓋垂まで入れる |
| 吸引圧・時間は**指示どおり**（1回10〜15秒以内） | 介護福祉士が体調で圧を決める |
| 終わったら**チューブの外側を拭き、洗浄水を吸う** | 洗浄水→拭く、の順 |

### 困ったとき

| 場面 | ○ 正解 |
|---|---|
| 1回で取り切れない | **呼吸が落ち着いたことを確認**してから再度。時間延長・圧を上げる・太いチューブ・とどめるは× |
| 鼻腔内吸引で**血液が少量混じった** | **鼻腔と口腔の中を観察**して看護職へ報告。再吸引・消毒・とどめるは× |
| 入浴 | **入浴の前後**に吸引（湯気で痰がゆるむ） |

### 痰を出しやすくする生活支援

- **室内の空気を清浄に**、**加湿**（湿度50〜60％）、**水分をとる**
- **体位ドレナージ**：痰がたまっている側を**上**にする（右肺にたまる → **左側を下**に）
- 適度に体を動かす・体位変換する

喀痰吸引を指示どおり行ったが、1回で痰が取り切れなかった。再度吸引するときの対応として最も適切なものはどれ？

1. 呼吸が落ち着いたことを確認する
2. 吸引時間を延長する
3. 吸引圧を高くする
4. 太い吸引チューブに変更する
5. 痰がたまっていそうな部位にしばらくチューブをとどめる

<details class="answer">
<summary>正解を見る</summary>

**正解：1**　吸引中は空気も吸い取るので、低酸素になります。呼吸が落ち着くのを待ってから行い、2〜5のように指示を変えたり粘膜を傷つけたりすることはしません。
</details>

## ② 気管カニューレ内部の吸引・人工呼吸器・物品の管理【医療的ケア】

### 気管カニューレの構造

- 気管切開した穴から**気管**に入れる管（咽頭ではない）。**定期的に交換**が必要（医療職）
- **カフ**は**下端**についた風船で、**空気**を入れてふくらませる（すき間からの垂れ込みを防ぐ）
- **サイドチューブ**から、**カフの上にたまった分泌物を吸引**できる

### 口腔内との違い

| | 口腔内・鼻腔内 | **気管カニューレ内部** |
|---|---|---|
| 清潔の程度 | 清潔 | **無菌的**（滅菌手袋・滅菌チューブ） |
| 洗浄水 | 水道水でよい | **滅菌精製水** |
| 深さ | 咽頭の手前まで | **カニューレの先端を越えない** |
| 姿勢 | 上半身10〜30度 | 頸部を前に曲げない |
| 時間・圧 | 指示どおり | 指示どおり（口腔内より長く・高くはしない） |
| チューブの太さ | — | カニューレ内径の**2分の1以下** |

### 人工呼吸器・吸引後の観察

- 吸引のときは**コネクターを外し、終わったら確実につなぎ**、**人工呼吸器の作動状況を確認**
- 指示より吸引が長くなった → **動脈血酸素飽和度（SpO2）**を確認
- カニューレを抜いて吸引・20〜30秒の吸引・気管分岐部まで、は×

### 物品の管理

| ○ | × |
|---|---|
| 吸引びんの中身は**70〜80％になる前**に捨てる | — |
| 洗浄水・消毒液は**少なくとも24時間ごと**に交換（施設では8時間ごとも） | 72時間で交換 |
| 浸漬法（消毒液につける）のほうが乾燥法より**確実に早く**消毒できる | 乾燥法のほうが早く死滅 |
| チューブの洗浄は**水**（気管カニューレは滅菌精製水） | アルコールで洗浄 |

<summary>✏️ 解いてみよう（第33回）</summary>

介護福祉職が行う口腔内と気管カニューレ内部の吸引について、最も適切なものはどれ？

1. 気管カニューレ内部では、カニューレ内径の3分の2程度の太さのチューブを使う
2. 気管カニューレ内部では、滅菌された洗浄水を使う
3. 気管カニューレ内部では、頸部を前屈した姿勢で行う
4. 吸引時間は、口腔内より気管カニューレ内部のほうを長くする
5. 吸引圧は、口腔内より気管カニューレ内部のほうを高くする

<details class="answer">
<summary>正解を見る</summary>

**正解：2**　気管の中はもともと無菌なので、細菌を持ち込まないよう滅菌したものを使います。太すぎるチューブ・長い時間・高い圧はどれも低酸素や粘膜の傷の原因になります。
</details>
</details>
