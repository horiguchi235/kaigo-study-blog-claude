**この記事のポイント**

1. 変形性膝関節症は**女性に多く、O脚**。助言は「**減量・杖・温める**」（正座・階段運動・冷やすは×）。
2. **前立腺肥大症は初期に頻尿**、飲酒や風邪薬で**尿が出なくなる**。女性は**腹圧性尿失禁**が多い。
3. 褥瘡は**仙骨部**が最多。**乾燥によるかゆみ**（老人性皮膚掻痒症）は電気毛布や入浴で悪化。

## ① 骨・関節【発達と老化の理解】

| 病気 | ○ | × |
|---|---|---|
| **変形性膝関節症** | **女性に多い**、**O脚（内反）**に変形。**減量**・**杖**・**温める** | X脚／冷やす／正座／階段の昇り降り運動／歩行を控える |
| **腰部脊柱管狭窄症** | **下肢のしびれ**、**間欠性跛行**（歩くと痛み、休むと回復） | — |
| 骨粗鬆症 | **女性**（閉経後）に多い | 男性に多い |
| 関節リウマチ | **自己免疫**の病気 | 軟骨の老化 |
| **サルコペニア** | 加齢による**筋肉量・筋力の低下** | 骨量の低下 |

<details>
<summary>✏️ 解いてみよう（第31回・事例）</summary>

68歳の女性。階段の昇り降りで両膝の痛みが強くなり、変形性膝関節症と診断された。身長153cm、体重75kg。日常生活の留意点として最も適切なものはどれ？

1. 歩行を控える
2. 正座で座る
3. 膝を冷やす
4. 体重を減らす
5. 杖は使わない

<details class="answer">
<summary>正解を見る</summary>

**正解：4**　BMIは約32で肥満です。膝への負担を減らすには減量が第一。歩行は適度に続け、正座は避け、膝は温め、杖を使います。
</details>
</details>

## ② パーキンソン病【発達と老化の理解】

| ○ | × |
|---|---|
| **振戦** | 筋弛緩・多動・下痢・高血圧 |
| **無表情**（仮面様顔貌） | 後屈した姿勢・大股歩行 |
| **突進現象**、前傾姿勢、小刻み歩行 | 40歳代発症が最多（実際は50〜60歳代） |
| 中脳の**ドパミン不足**（神経の病気） | 筋肉の異常が原因 |
| 認知症を**合併することがある** | 合併はまれ／5年以内の死亡が多い |

> 4大症状（振戦・筋固縮・無動・姿勢保持障害）とホーエン・ヤール分類は → 障害の特性②「難病と高次脳機能障害」

## ③ 排尿・排便の病気【発達と老化の理解】

### 尿失禁

| 種類 | 特徴 |
|---|---|
| **腹圧性** | 咳・くしゃみ・重い物を持ったとき。**女性に多い** |
| **切迫性** | **トイレまで我慢できない** |
| 溢流性 | 尿が出にくく、あふれて漏れる（前立腺肥大症など） |
| 機能性 | 排尿機能は正常だが、**認知症や運動障害**でトイレに間に合わない |

### 前立腺肥大症

- **初期は頻尿**（特に夜間）。進むと尿が出にくくなる（**尿閉**）。無尿・透析にはならない
- **飲酒・風邪薬**（抗コリン作用）で**尿が出なくなる**ことがある → **下半身を冷やさない**、長く座らない、排尿を我慢しない
- 男性は尿路の**通過障害**が多い。前立腺がんは**増えている**

### 便秘

| ○ | × |
|---|---|
| **腹筋の筋力低下**は原因になる | 1日1回出なければ便秘 |
| **大腸がん**は**器質性便秘**の原因 | 病気・薬剤が原因になることはまれ |
| 高齢者は**弛緩性便秘**が多い | 弛緩性はまれ |
| けいれん性便秘は**ウサギの糞のような硬い便** | 大きく柔らかい便 |
| 直腸性便秘は、便が直腸に来ても**便意が起こらない** | 便が直腸に送られてこない |
| 食事・運動・水分の見直しが先 | 下剤を優先 |

## ④ 皮膚の病気【発達と老化の理解】

| 病気 | ポイント |
|---|---|
| **褥瘡** | 最も多いのは**仙骨部**。原因は**圧迫による血流の悪化**、**低栄養**・湿潤も。**体位変換・おむつ交換をこまめに** |
| **老人性皮膚掻痒症** | **皮膚の乾燥**でかゆい。**電気毛布**・熱い湯・入浴後の乾燥で悪化 |
| かゆみを伴う病気 | **糖尿病・慢性腎不全・肝疾患・胆道疾患**。**心疾患はかゆみを伴わない** |

> 褥瘡のケアは → 入浴・清潔③「皮膚のしくみと皮膚トラブル」

## ⑤ こころの病気・肝臓・栄養【発達と老化の理解】

| テーマ | ○ |
|---|---|
| **老年期うつ病** | **身体症状（だるい・痛い）の訴えが多く**、**抑うつ気分は若い人より軽い**ことが多い。自殺を図ると**亡くなる率が高い** |
| 高齢者のせん妄 | **夜間**に起こりやすい |
| **神経性無食欲症** | **活動性が高まる**、太ることへの恐怖、低体重の深刻さを認めない、思春期の**女性**に多い |
| **C型肝炎** | 慢性化し、**肝硬変・肝がん**へ進むことが多い。B型も慢性化あり。A型は食べ物から |
| 栄養状態を保つ | **歯科健康診査**を受ける。多剤併用・外出を控える・孤食・たんぱく質制限は× |

## ひっかけパターン集（骨・排泄・皮膚で「ほぼ×」）

| 選択肢の表現 | なぜ× |
|---|---|
| 変形性膝関節症で膝を冷やす・正座 | 温める・正座は避ける |
| 変形性膝関節症はX脚 | O脚 |
| サルコペニア＝骨量の低下 | 筋肉量の低下 |
| パーキンソン病は筋肉の病気 | 脳（ドパミン）の病気 |
| 前立腺肥大症で無尿・透析 | 尿閉はあるが透析にはならない |
| 心疾患はかゆみを伴う | 伴わない |
