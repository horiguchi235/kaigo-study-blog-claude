**この記事のポイント**

1. 変形性膝関節症は**女性に多く、O脚**。助言は「**減量・杖・温める**」（正座・階段運動・冷やすは×）。
2. **前立腺肥大症は初期に頻尿**、飲酒や風邪薬で**尿が出なくなる**。女性は**腹圧性尿失禁**が多い。
3. 褥瘡は**仙骨部**が最多。**乾燥によるかゆみ**（老人性皮膚掻痒症）は電気毛布や入浴で悪化。

## ① 骨・関節

| 病気 | ○ | × |
|---|---|---|
| **変形性膝関節症** | 関節の軟骨がすり減る。**女性・肥満**に多い、<strong>O脚（内反）</strong>に変形。**減量**・**杖**・**温める**・**洋式トイレ**、痛みに配慮した太ももの**筋力づくり**（水中運動は浮力で膝の負担が少ない） | X脚／冷やす／正座／階段の昇り降り運動／歩行を控える |
| **腰部脊柱管狭窄症** | **下肢のしびれ**、**間欠性跛行**（歩くと足がしびれ・痛み、休むと回復）。**前かがみで楽**になる | — |
| 骨粗鬆症 | **女性**（閉経後、女性ホルモンのエストロゲンが減る）に多い。骨折しやすいのは**大腿骨頸部・脊椎（圧迫骨折）・手首（橈骨遠位端）・肩（上腕骨近位部）**。予防は**カルシウム・ビタミンD・日光浴・適度な運動** | 男性に多い |
| 関節リウマチ | **自己免疫**の病気。手指などの関節が**左右対称**に腫れて痛み、**朝のこわばり**が特徴。女性に多い | 軟骨の老化 |
| 後縦靱帯骨化症 | 首の靱帯が骨のようにかたくなり脊髄を圧迫、手足のしびれ・細かい動作の障害。介護保険の**特定疾病**（40〜64歳でも介護保険を使える16の病気）の1つ | — |
| **サルコペニア** | 加齢による**筋肉量・筋力の低下** | 骨量の低下 |

## ② パーキンソン病

| ○ | × |
|---|---|
| **振戦** | 筋弛緩・多動・下痢・高血圧 |
| **無表情**（仮面様顔貌） | 後屈した姿勢・大股歩行 |
| **突進現象**、前傾姿勢、小刻み歩行 | 40歳代発症が最多（実際は50〜60歳代） |
| 中脳の**ドパミン不足**（神経の病気） | 筋肉の異常が原因 |
| 認知症を**合併することがある** | 合併はまれ／5年以内の死亡が多い |

> 4大症状は、**振戦**（じっとしているときの手のふるえ）・**筋固縮**（筋肉がこわばる）・**無動**（動きが少なく遅い）・**姿勢保持障害**（転びやすい）。重症度のホーエン・ヤール分類と生活の支援は → [難病と高次脳機能障害](../shougai-02-nanbyou/)

## ③ 排尿・排便の病気

### 尿失禁

| 種類 | 特徴 | 主な対応 |
|---|---|---|
| **腹圧性** | 咳・くしゃみ・重い物を持ったとき。**女性に多い** | **骨盤底筋訓練** |
| **切迫性** | 急に強い尿意が起こり、**トイレまで我慢できない** | 早めのトイレ誘導、トイレに近い部屋 |
| 溢流性 | 尿が出にくく、膀胱にたまった尿があふれて漏れる（前立腺肥大症など） | 医療職に相談（導尿など） |
| 機能性 | 排尿機能は正常だが、**認知症や運動障害**でトイレに間に合わない | トイレの場所の目印、脱ぎやすい服、排尿パターンに合わせた誘導 |

### 前立腺肥大症

- **初期は頻尿**（特に夜間）。進むと尿が出にくくなる（**尿閉**）。無尿・透析にはならない
- **飲酒・風邪薬**（抗コリン作用＝膀胱の筋肉の働きを弱める作用）で**尿が出なくなる**ことがある → **下半身を冷やさない**、長く座らない、排尿を我慢しない
- 男性は尿路の**通過障害**が多い。前立腺がんは**増えている**

### 便秘

| 種類 | 意味 |
|---|---|
| 弛緩性便秘 | 腸の動きが**弱い**。高齢者に多い |
| けいれん性便秘 | 腸が**緊張しすぎて**便がうまく進まない。ストレスなど |
| 直腸性便秘 | 便が直腸まで来ているのに**便意が起こらない**（便意をがまんする習慣など） |
| 器質性便秘 | 大腸がんなど、**腸の病気や形の異常**で便が通りにくい |

| ○ | × |
|---|---|
| **腹筋の筋力低下**は原因になる | 腹筋の力は関係ない |
| 排便の回数には個人差がある | 1日1回出なければ便秘 |
| **大腸がん**は**器質性便秘**の原因。病気・薬剤も原因になる | 病気・薬剤が原因になることはまれ |
| 高齢者は**弛緩性便秘**が多い | 弛緩性はまれ |
| けいれん性便秘は**ウサギの糞のような硬い便** | 大きく柔らかい便 |
| 直腸性便秘は、便が直腸に来ても**便意が起こらない** | 便が直腸に送られてこない |
| 食事・運動・水分の見直しが先 | 下剤を優先 |

## ④ 皮膚の病気

| 病気 | ポイント |
|---|---|
| **褥瘡** | 最も多いのは**仙骨部**。原因は**圧迫による血流の悪化**、**低栄養**・湿潤も。**体位変換・おむつ交換をこまめに** |
| **老人性皮膚掻痒症** | **皮膚の乾燥**でかゆい。**電気毛布**・熱い湯・入浴後の乾燥で悪化 |
| かゆみを伴う病気 | **糖尿病・慢性腎不全・肝疾患・胆道疾患**。**心疾患はかゆみを伴わない** |
| 疥癬 | ヒゼンダニによる強いかゆみ。感染力の強い**角化型疥癬**（ノルウェー疥癬）は**個室**で対応。ダニは熱に弱い（50℃・10分で死ぬ） |
| 帯状疱疹 | 子どものころの**水ぼうそうのウイルス**が再び活動し、**体の片側に帯状の水疱と痛み** |
| カンジダ症 | かびの一種。おむつの中など**蒸れやすい場所**に起こる |

> 褥瘡のケアは → 入浴・清潔③「皮膚のしくみと皮膚トラブル」

## ⑤ こころの病気・消化器・栄養

| テーマ | ○ |
|---|---|
| **老年期うつ病** | **身体症状（だるい・痛い）の訴えが多く**、**抑うつ気分は若い人より軽い**ことが多い。自殺を図ると**亡くなる率が高い**（くわしくは → [高齢期の心理・知能・喪失と悲嘆](../kokoro-02-koureiki/)） |
| 高齢者のせん妄 | **夜間**に起こりやすい（→ [認知症の中核症状・BPSD・せん妄](../ninchisho-01-shoujou/)） |
| **神経性無食欲症**（思春期の病気だが過去問で出た） | **活動性が高まる**、太ることへの恐怖、低体重の深刻さを認めない、思春期の**女性**に多い |
| **肝炎** | **A型・E型**＝主に**口から**（経口感染）。**B型・C型**＝主に**血液を介して**感染。**C型は慢性化しやすく**、**肝硬変・肝がん**へ進むことが多い。B型も慢性化することがある |
| 胃潰瘍 | 高齢者は**みぞおちの痛みが出にくい**。**黒いタール便**（胃からの出血）に注意 |
| 逆流性食道炎 | 胸やけ。食後すぐ横にならない |
| 腸閉塞 | 腹痛・嘔吐・お腹の張り |
| 栄養状態を保つ | **歯科健康診査**を受ける。多剤併用・外出を控える・孤食・たんぱく質制限は× |

## ひっかけパターン集（骨・排泄・皮膚で「ほぼ×」）

| 選択肢の表現 | なぜ× |
|---|---|
| 変形性膝関節症で膝を冷やす・正座 | 温める・正座は避ける |
| 変形性膝関節症はX脚 | O脚 |
| サルコペニア＝骨量の低下 | 筋肉量の低下 |
| パーキンソン病は筋肉の病気 | 脳（ドパミン）の病気 |
| 前立腺肥大症で無尿・透析 | 尿閉はあるが透析にはならない |
| 心疾患はかゆみを伴う | 伴わない |
| 腹圧性尿失禁は男性に多い | 女性に多い（骨盤底筋が弱まる） |
