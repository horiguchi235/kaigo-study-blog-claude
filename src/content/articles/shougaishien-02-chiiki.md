**この記事のポイント**

1. **レスパイトケア＝介護する家族の休息**。利用中も**本人が自分らしく**過ごせることが大切。
2. 障害福祉サービスの計画は**相談支援専門員**が作る**サービス等利用計画**（介護保険のケアプランとの混同に注意）。
3. 施設や病院から地域へ戻るときは**地域移行支援**、地域に足りない資源は<strong>（自立支援）協議会</strong>で**開発**する。

## ① 家族支援とレスパイトケア

### レスパイトケア

| ○ | × |
|---|---|
| **介護を担う家族に休息**を提供する | 利用者の安静・介護職の休息・経済的負担の軽減 |
| 家族が休んでいる間も、**障害者が自分らしく過ごせる**ように | 家族は自宅で休まなければならない／旅行は認められない／宿泊に限る |
| 痰の吸引で家族が眠れない → **レスパイトケアの利用** | 仕事を辞める・吸引の講習・流動食にする |

- 障害福祉で使えるレスパイト：<strong>短期入所（ショートステイ）</strong>、市町村の地域生活支援事業の**日中一時支援**など。制度のサービスだけでなく、**家族会・相談・地域の活動**など制度外の支えも組み合わせる。

### 家族への関わり

家族も、障害を受け入れていく**当事者**です。家族それぞれの生活と、家族全体の両方を見ます。

| 場面 | ○ 正解 |
|---|---|
| 脳性麻痺の息子を介護する母親が腰痛 | **母親の介護方法を尊重**しながら、**腰の負担が軽い方法を提案** |
| 統合失調症の息子に「なぜ働けない」と言う父親 | **家族心理教育プログラム**（病気の知識や対応のしかたを家族が学ぶ）への参加を勧める |
| 発達障害の子の子育てに自信をなくす母親 | 同じ立場の**ペアレント・メンター**（発達障害の子を育てた経験のある親の相談役）を紹介 |
| 夫が脳梗塞で障害が残り、将来が不安な妻 | **不安に寄り添い、今の課題を一緒に整理**する |
| 家族の介護力のアセスメント | **家族の一人ひとりと家族全体**の生活を見る |

## ② 地域生活支援・相談支援・多職種連携

### 相談支援のしくみ（まず全体像）

障害福祉サービスの相談は、大きく2種類です。

| 種類 | 中身 | 担う事業所 |
|---|---|---|
| **計画相談支援** | **サービス等利用計画**をつくる（サービス利用支援）・定期的に見直す（継続サービス利用支援＝モニタリング） | **特定相談支援事業所**（基本相談＋計画相談） |
| **地域相談支援** | **地域移行支援**（施設・**精神科病院**などから地域へ移る準備）・**地域定着支援**（地域で暮らし始めた人の緊急時の対応） | **一般相談支援事業所**（基本相談＋地域相談） |

地域の相談支援の中核になるのが**基幹相談支援センター**です。

### 誰が何をするか

**相談支援専門員**の仕事は、**サービス等利用計画**をつくることと、**サービス担当者会議**を開くこと。障害支援区分の判定（市町村）、個別支援計画（各事業所のサービス管理責任者）、訓練、移動介護は×です。介護保険のケアプランとの関係は → [計画とつくる人の違い](../hikaku-10-keikaku/)

| 人・機関 | 役割 |
|---|---|
| **相談支援専門員** | サービス等利用計画・サービス担当者会議 |
| サービス管理責任者 | 事業所の個別支援計画 |
| 介護支援専門員 | 介護保険のケアプラン（障害福祉サービスの計画は作らない） |
| **市町村** | 障害支援区分の決定、**地域生活支援事業** |
| 基幹相談支援センター | 地域の相談支援の中核 |
| **保健師** | **子育て相談**など |
| **作業療法士** | スプーンが握れない人の**自助具**を作る |

### （自立支援）協議会

障害者総合支援法での名前は「**協議会**」ですが、自治体では「自立支援協議会」と呼ぶことが多いため、かっこ付きで書かれます。

- 地域の関係者が集まり、**個別の事例から地域の課題**を共有する
- 市内にサービス事業所がない → **地域の社会資源の開発**
