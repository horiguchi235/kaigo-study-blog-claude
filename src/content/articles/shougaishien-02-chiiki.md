**この記事のポイント**

1. **レスパイトケア＝介護する家族の休息**。利用中も**本人が自分らしく**過ごせることが大切。
2. 障害福祉サービスの計画は**相談支援専門員**が作る**サービス等利用計画**（介護保険のケアプランとの混同に注意）。
3. 施設や病院から地域へ戻るときは**地域移行支援**、地域に足りない資源は<strong>（自立支援）協議会</strong>で**開発**する。

---

## ① 家族支援とレスパイトケア

### レスパイトケア

| ○ | × |
|---|---|
| **介護を担う家族に休息**を提供する | 利用者の安静・介護職の休息・経済的負担の軽減 |
| 家族が休んでいる間も、**障害者が自分らしく過ごせる**ように | 家族は自宅で休まなければならない／旅行は認められない／宿泊に限る |
| 痰の吸引で家族が眠れない → **レスパイトケアの利用** | 仕事を辞める・吸引の講習・流動食にする |

### 家族への関わり

| 場面 | ○ 正解 |
|---|---|
| 脳性麻痺の息子を介護する母親が腰痛 | **母親の介護方法を尊重**しながら、**腰の負担が軽い方法を提案** |
| 統合失調症の息子に「なぜ働けない」と言う父親 | **家族心理教育プログラム**への参加を勧める |
| 発達障害の子の子育てに自信をなくす母親 | 同じ立場の**ペアレント・メンター**を紹介 |
| 夫が脳梗塞で障害が残り、将来が不安な妻 | **不安に寄り添い、今の課題を一緒に整理**する |
| 家族の介護力のアセスメント | **家族の一人ひとりと家族全体**の生活を見る |

## ② 地域生活支援・相談支援・多職種連携

### 相談支援専門員

- **サービス等利用計画**を作る
- **サービス担当者会議**を開く
- ×：障害支援区分の判定（市町村）、個別支援計画（各サービス事業所のサービス管理責任者）、訓練、移動介護

### 誰が何をするか

| 人・機関 | 役割 |
|---|---|
| **相談支援専門員** | サービス等利用計画・サービス担当者会議 |
| サービス管理責任者 | 個別支援計画 |
| 介護支援専門員 | 介護保険のケアプラン（障害福祉サービスの計画は作らない） |
| **市町村** | 障害支援区分の決定、**地域生活支援事業** |
| 基幹相談支援センター | 地域の相談支援の中核 |
| **保健師** | **子育て相談**など |
| **作業療法士** | スプーンが握れない人の**自助具**を作る |

### 地域生活への移行

| 場面 | ○ 正解 |
|---|---|
| 入所施設から出て暮らしたい知的障害者 | **指定一般相談支援事業者**（地域移行支援）の利用 |
| 同 | **地域自立支援協議会**に個別支援計画の検討を依頼 |
| 統合失調症で長期入院、退院して一人暮らししたいが住居探しが不安 | **地域移行支援** |
| 重度知的障害の人の地域移行先 | **共同生活援助（グループホーム）** |
| 本人はグループホーム希望、母親は施設継続を希望 | **グループホームの生活について本人と話し合う** |

**地域移行支援と地域定着支援**：地域移行支援＝入所・入院中の人の**住居探しや体験**など、地域定着支援＝地域で暮らし始めた人の**緊急時の相談**など。自立生活援助＝一人暮らしの人への**定期訪問**。

### （自立支援）協議会

- 地域の関係者が集まり、**個別の事例から地域の課題**を共有する
- 市内にサービス事業所がない → **地域の社会資源の開発**

### そのほかのサービス・機関

| 場面 | ○ |
|---|---|
| 重度知的障害の人の**通院の付き添い** | **行動援護**。同行援護は**視覚障害** |
| 療育手帳をもつ一人暮らしの人の**金銭管理**（生活支援員と銀行へ） | **日常生活自立支援事業** |
| ADHDが疑われる24歳の息子のことで母親が相談 | **発達障害者支援センター** |
| 制度化された社会資源 | **民生委員**の相談・援助。家族会・近所の声かけ・家族の介護・コンビニの見守りはインフォーマル |
| **エコマップ** | 本人と**社会資源との相関関係**を図にしたもの。家族関係はジェノグラム |

## ③ 相談支援の担い手と家族支援

- **相談支援の分類**：**計画相談支援**＝サービス利用支援（計画の作成）・継続サービス利用支援（モニタリング）／**地域相談支援**＝**地域移行支援**（施設・**精神科病院**などから地域へ）・**地域定着支援**（一人暮らしの人の緊急時の対応）。**特定相談支援事業所**＝基本相談＋計画相談、**一般相談支援事業所**＝基本相談＋地域相談。
- **レスパイトケア**は介護保険のサービス（通所・ショートステイ・小規模多機能）だけでなく、**家族会・相談・地域の活動**など保険外のものも活用する。
- **相談支援専門員**＝サービス等利用計画をつくる。**サービス管理責任者**＝事業所の個別支援計画をつくる。地域の相談の中核は**基幹相談支援センター**。
- **協議会**（障害者総合支援法）＝地域の関係機関が集まり、地域の課題を話し合う場。
- 家族支援：家族も障害を受け入れていく当事者。**家族心理教育**・**ペアレント・メンター**（同じ経験をもつ親の相談役）・**レスパイトケア**。家族それぞれの生活と家族全体の両方を見る。
