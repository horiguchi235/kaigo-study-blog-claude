「ヘルパーさん」「ショートステイ」「グループホーム」…。介護保険にも障害福祉にも、よく似た名前のサービスがあります。**どの法律の、誰のためのサービスか**を軸に整理すると一気にわかりやすくなります。

**この記事のポイント**

1. 介護保険＝**介護保険法**（保険料＋税）、障害福祉＝**障害者総合支援法**（税）。
2. 認定は <strong>要介護認定（要支援1・2／要介護1〜5）</strong> と <strong>障害支援区分（区分1〜6）</strong>。
3. 計画を作るのは <strong>介護支援専門員（ケアマネ）</strong> と **相談支援専門員**。
4. 自己負担は介護保険＝<strong>1〜3割（定率）</strong>、障害福祉＝<strong>所得に応じた負担上限（応能負担）</strong>。
5. 65歳になると、同じようなサービスは**介護保険が優先**。障害福祉にしかないサービスは続けて使える。

## ① 制度のちがいを一覧で

| | 介護保険 | 障害福祉サービス |
|---|---|---|
| 根拠法 | **介護保険法**（2000年〜） | **障害者総合支援法**（2013年〜、前身は障害者自立支援法） |
| しくみ | **社会保険**（保険料50％＋公費50％） | <strong>税（公費）</strong>（国1/2・都道府県1/4・市町村1/4） |
| 対象 | 65歳以上（第1号）／40〜64歳の医療保険に加入している人（第2号。**特定疾病**（16種類）が原因で要介護・要支援になったときに使える） | 身体・知的・精神（発達障害を含む）障害・難病の**18歳以上**の人（65歳以上も含む）。18歳未満の障害児も居宅介護・短期入所などは総合支援法、通所・入所は**児童福祉法** |
| 窓口・保険者 | 市町村 | 市町村 |
| 給付の種類 | **介護給付**（要介護1〜5）・**予防給付**（要支援1・2） | **自立支援給付**（この中に**介護給付**・**訓練等給付**・自立支援医療・補装具・相談支援など）と**地域生活支援事業** |
| 市町村が地域の実情で行う部分 | 地域密着型サービス（原則その市町村の住民だけ）・地域支援事業 | **地域生活支援事業**（移動支援・日常生活用具など） |
| 認定 | **要介護認定**（要支援1・2、要介護1〜5）…**介護認定審査会** | **障害支援区分**（区分1〜6）…**市町村審査会** |
| 利用できる量 | 要介護度ごとの**区分支給限度基準額**（1か月に使える上限額） | 市町村が**支給決定**（量を決める） |
| 全体の計画 | ケアプラン（居宅サービス計画）…**介護支援専門員** | サービス等利用計画…**相談支援専門員** |
| 事業所の計画 | 訪問介護計画など…**サービス提供責任者** | 個別支援計画…**サービス管理責任者** |
| 自己負担 | **1〜3割**（定率）＋高額介護サービス費 | **応能負担**（所得に応じた月の上限。生活保護・住民税非課税は**0円**） |
| 認定・決定への不服 | 都道府県の**介護保険審査会**に審査請求 | **都道府県知事**に審査請求（都道府県は**障害者介護給付費等不服審査会**を置くことができる＝任意設置） |
| サービスの苦情 | 事業所 → 市町村・**国民健康保険団体連合会**（国保連） | 事業所 → 市町村、**運営適正化委員会**（都道府県社協） |

> 「介護給付」は**両方の制度にある名前**です。介護保険では「要介護の人への給付（要支援は予防給付）」、障害福祉では「自立支援給付の中の、介護を受けるサービスのグループ（居宅介護・生活介護など）」を指します。

不服申立て・苦情の流れは比較⑨、計画とつくる人は比較⑩でくわしく比べています。

## ② 似ているサービスの対応表

| 介護保険 | 障害福祉サービス | 違い・ポイント |
|---|---|---|
| 訪問介護 | **居宅介護** | どちらも自宅での身体介護・家事援助 |
| （なし） | **重度訪問介護** | 重度の人の**長時間の見守りを含む総合支援**。障害福祉だけ |
| 通所介護（デイサービス） | **生活介護** | 生活介護は日中の介護＋**創作・生産活動** |
| 短期入所生活介護 | 短期入所 | どちらも「ショートステイ」 |
| 介護老人福祉施設（特養） | **施設入所支援**＋生活介護 | 障害福祉は**夜（施設入所支援）と昼（生活介護）を分けて**支給 |
| 認知症対応型共同生活介護 | **共同生活援助**（グループホーム） | 名前は同じ「グループホーム」でも法律が違う |
| 福祉用具貸与・購入 | **補装具**・日常生活用具 | 補装具＝体の機能を補う（車いす・義肢・補聴器） |
| 居宅介護支援（ケアマネ） | **計画相談支援**（相談支援専門員） | ケアプラン ↔ サービス等利用計画 |
| 訪問介護の通院等乗降介助・通院介助 | 居宅介護の**通院等介助**・通院等乗降介助 | 通院の介助は、どちらも「ヘルパーの訪問サービス」の一部 |
| （趣味・余暇の外出は原則対象外） | **同行援護**・**行動援護**・移動支援 | 余暇や社会参加の外出は障害福祉の方が細かく分かれる（比較⑥） |

## ③ 65歳になったらどうなる？

1. **優先の原則**：障害福祉サービスを使っていた人も、65歳になって（40〜64歳で特定疾病なら40歳から）**介護保険に同じようなサービスがあれば、介護保険が優先**されます。
2. **障害福祉にしかないサービスは続く**：**同行援護・行動援護・重度訪問介護（介護保険で足りない分）・就労系サービス・自立訓練**などは、65歳以降も障害福祉で使えます。
3. <strong>共生型サービス（2018年〜）</strong>：ホームヘルプ・デイサービス・ショートステイなどで、**1つの事業所が介護保険と障害福祉の両方の指定**を受けられるしくみ。65歳になっても**なじみの事業所を使い続けられる**ようにするためです。
4. **負担の軽減**：65歳になったことで介護保険の自己負担が新たに生じた人のために、介護保険の自己負担を<strong>償還（払い戻し）</strong>する制度があります（**新高額障害福祉サービス等給付費**、2018年〜）。主な条件は、65歳になる前の**5年間**、居宅介護・重度訪問介護・生活介護・短期入所を続けて利用していた／本人と配偶者が**住民税非課税または生活保護**／65歳前の障害支援区分が**2以上**、など。まずは「こういう制度がある」と押さえれば十分です。

## ひっかけパターン集

| 選択肢の表現 | なぜ× |
|---|---|
| 障害福祉サービスは保険料でまかなう | <strong>税（公費）</strong>。保険料があるのは介護保険 |
| 障害支援区分は区分1〜5 | **区分1〜6** |
| サービス等利用計画はサービス管理責任者がつくる | **相談支援専門員**（サ管は個別支援計画） |
| 65歳になると障害福祉サービスは一切使えない | 介護保険にないサービスは**使える** |
| 障害福祉の自己負担は一律1割 | **所得に応じた上限**（応能負担）。0円の人も多い |
| 障害者のグループホームは介護保険のサービス | **共同生活援助＝障害者総合支援法** |
| 障害支援区分の決定に不服があれば介護保険審査会に審査請求する | 障害福祉は**都道府県知事**に審査請求。介護保険審査会は介護保険の処分を扱う |
