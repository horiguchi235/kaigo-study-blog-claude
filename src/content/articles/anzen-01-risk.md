**この記事のポイント**

1. 事故予防の基本は**ヒヤリ・ハットの収集・分析**と**組織での体制づくり**（安全対策担当者・委員会・研修）。事故が起きたら**速やかに家族へ連絡し、市町村にも報告**。
2. 転倒した人には、医療職が来るまで**そばで状況と体の様子を把握**。自己判断で湿布・飲水・様子見はしない。
3. 防災は**計画を職員で共有**、**BCP（業務継続計画）策定は義務**。警戒レベル3なら**垂直避難**（上の階がある場合）。避難所では**体を動かして血栓予防**。

## ① リスクマネジメント

### ヒヤリ・ハットとハインリッヒの法則

- **ヒヤリ・ハット**（インシデント）＝事故にはならなかったが、ヒヤリとした・ハッとした出来事
- **アクシデント**＝実際に起きた事故

**ハインリッヒの法則**：**1件の重大事故**の背後に **29件の軽微な事故**、**300件のヒヤリ・ハット**がある（1：29：300）。

→ ヒヤリ・ハットを**集めて分析する**ことが事故防止につながる。報告した人を責めず、**組織全体で改善**する。

### リスクマネジメントの3段階

1. 事故を**予防する**
2. 起きたときに**被害を広げない**（初動）
3. **原因を分析して再発を防ぐ**（報告・記録・見直し）

どれか1つだけで十分、ということはありません。細心の準備をしても、慣れても、事故は**起こりうる**という前提で考えます。

### よく出る○×

| ○ | × |
|---|---|
| **事故が起きる前から**体制を整える | 事故が起きてから検討する |
| 生活を制限せず、その人らしい生活の中で安全を考える | 安全のため、外出・飲酒喫煙・お祭り参加を制限する |
| 職員に**安全の研修を定期的に**行う | 施設管理者の安全を第一に考える |
| **安全対策担当者**を置き、**事故防止の委員会を定期開催**（施設長・医師・看護職・介護職・ケアマネなど多職種） | 事故防止は個々の職員に任せる |
| 苦情は**組織で受け止め**、上司に報告して対応する | 家族からの苦情は、介護福祉職がその場で解決する |
| 私物を壊したら、**上司に報告**して組織で対応する | 介護福祉職の判断で弁償する |
| 事故が起きたら**速やかに家族に連絡**し、**市町村にも報告**する | 家族への連絡は落ち着いてから |
| 事故の記録には、対応した職員名も含めて**事実を残す** | 職員名を記録に残さない |
| 小さな事故・インシデントも**組織で報告・共有**（書面で） | 個人で対応／口頭のみ |
| 事故報告書は職員で共有し再発防止に生かす | 管理者以外は閲覧できない |

- **安全対策担当者**の配置は、2021年度の介護報酬改定で介護保険施設に求められるようになりました。
- 事故の記録の保存期間は、国の運営基準で**2年**（条例で5年とする自治体も多い）。
- 安全のためでも、**身体拘束や「活動を一律に禁止する」ことに頼らない**（[虐待防止と身体拘束](../kenriyougo-02-gyakutai/)）。
- 施設で多い事故は「**転倒・転落**」、次いで「**誤嚥・誤飲**」。家庭内の不慮の事故で亡くなる高齢者は**浴槽内での溺死**が多い。

## ② 事故発生時の対応・場面ごとの危険回避

**初動の順番**：安全の確保 → 状態の確認 → 医療職へ連絡。**体調がいつもと違う**（顔色・反応など）と気づいたら、自分で判断せず**すぐ医療職に連絡**します。

| 場面 | ○ 正解 | × |
|---|---|---|
| 転倒して腹部と足を強く打った | 医療職が来るまで**そばで転倒の状況や身体状況を把握** | 湿布を貼る・水を飲ませる・仰向けにする・「大丈夫」で様子見 |
| 転倒したが、けががなさそう | **しばらく観察**する（痛み・意識・あとから出る症状） | 本人が「大丈夫」と言うので記録しない |
| 食事介助中に姿勢が傾いてきた | **姿勢を直す** | そのまま介助を続ける |
| 車いすで前かがみになってスプーンを拾おうとする | すぐ近づいて**代わりに拾う・支える** | 目で確認するだけ |
| 下肢筋力が落ちた人が靴下で歩いている | 滑りにくい**靴**を履いてもらう | スリッパ |
| フットサポートを下げたまま立とうとする | **フットサポートを上げる** | またいでもらう |
| ふらつきながら廊下を歩く人 | 声をかけ付き添う | 黙って通り過ぎる |
| 薬を渡すとき | 医師から処方された薬を、**本人確認と薬袋の名前・飲む時間（食前・食後・食間）を毎回確かめて**渡す | 食事を食べなかったときの服薬を自己判断する（医師・看護職に確認） |

### けがの手当て（外傷・骨折・熱傷）

| けが | ○ 手当て | × |
|---|---|---|
| 出血 | **清潔なガーゼで直接押さえる（直接圧迫止血）**、**ゴム手袋**で感染予防 | ティッシュで押さえる（繊維が残る） |
| 鼻血 | **前かがみ**で小鼻をつまむ | 上を向く |
| 骨折が疑われる | 動かさずに**副子**（添え木）で固定し、腫れていれば冷やして**患部を心臓より高く** | 動かして痛みを確かめる |
| 熱傷（やけど） | すぐに**流水で冷やす**。服の上からかかった熱湯は**服を脱がさずその上から冷やす**。**水疱（水ぶくれ）は破らない** | 水疱をつぶす／服を無理に脱がせる |

- 高齢者は典型的な症状がなくても骨折していることがある。
- **低温やけど**：湯たんぽ・カイロ・電気あんかなど、熱すぎない温度でも長く当たると、深いやけどになる。感覚が鈍い高齢者は気づきにくい。

### 車いすの安全

| ○ | × |
|---|---|
| **急な下り坂は後ろ向き**で降りる | 前向きで降りる |
| 点検は**定期的に** | 気づいたときだけ |
| 空気圧は適正に（低いとブレーキが利きにくい） | 空気圧を下げる |
| 1台ずつ、両手で押す | 2台同時に押す／ドアを片手で押さえながら押す |

### パーキンソン病の人

**歩き始めはリズムをとれるよう声をかける**（「いち、に」）。常に車いす＋ベルト固定（身体拘束になる）、お茶をなみなみ注ぐ（手のふるえでこぼれる）、入浴中に浴室を離れる（転倒・溺水の危険）は×。

> 2010年の内閣府調査では、自宅での転倒場所は「**庭**」が最多でした。最近の調査では居室・居間が多い結果もあるので、問題文の調査に注意。

## ③ 災害・防災・避難所

### 施設の防災

| ○ | × |
|---|---|
| **非常災害対策計画**の内容を**職員間で十分に共有** | 計画は管理者だけが知っていればよい |
| **業務継続計画（BCP）の策定が義務**（2024年4月から全事業所。研修・訓練も） | BCPは任意 |
| 消火・避難訓練は**年2回以上**（夜間想定も） | 年1回／夜間は避ける |
| 地域の**ハザードマップ**で危険を確認しておく | — |

- **BCP（業務継続計画）**＝災害や感染症のときもサービスを続けるための計画。
- **DWAT（災害派遣福祉チーム）**＝災害時に避難所などへ派遣される福祉専門職のチーム。介護福祉士に参加の**義務はない**。防災士の資格も義務ではない。
- 水・食料の**備蓄量は法律で決まっていない**（目安は3日分程度）。「1日分の備蓄が義務」は×。

### 要配慮者と避難行動要支援者

| 言葉 | 意味 |
|---|---|
| 要配慮者 | 災害時に特に配慮が必要な人（高齢者・障害者・乳幼児など） |
| 避難行動要支援者 | 要配慮者のうち、自力で避難するのが難しく支援が必要な人 |

- **避難行動要支援者名簿**の作成は**市町村の義務**。
- 一人ひとりの**個別避難計画**の作成は**市町村の努力義務**（2021年の災害対策基本法改正）。施設長の義務ではない。

### 警戒レベルと垂直避難

| レベル | 避難情報 | とる行動 |
|---|---|---|
| 1・2 | 気象庁の注意情報 | 避難の方法・場所を確認する |
| **3** | **高齢者等避難** | **高齢者・障害者など避難に時間がかかる人は避難を始める** |
| 4 | 避難指示 | 危険な場所から全員避難 |
| 5 | 緊急安全確保 | すでに災害が起きている・迫っている。命を守る行動 |

- **垂直避難**＝建物の上の階へ移ること。浸水の想定より**上の階がある建物**で、外へ移動するほうが危ないときに選ぶ。
- 図記号：人の足元に円＝**避難場所**（一時的に身を守る場所）。**避難所**（しばらく生活する場所）とは別。

### 避難所での支援

| ○ | × |
|---|---|
| **深部静脈血栓症（エコノミークラス症候群）予防に運動**を勧める | 日中も横になる／水分を控える |
| 情報提供に**音声やピクトグラム**も使う | 掲示の文字だけで伝える |
| 室内は**土足を避け**、清潔を保つ | 二次避難に備えて土足で過ごす |
| 食事は持病や飲み込みに合わせる | 平等のため全員同じ食事 |
| トイレは使いやすい**洋式**を用意する | 感染予防のため和式 |
| 「個」への配慮（杖の人は杖のまま） | 全体の調和を優先／全員車いす |

### 福祉避難所・労災保険

| ○ | × |
|---|---|
| 福祉避難所は**在宅の要配慮者**向け。**介護老人福祉施設の入所者は原則対象外** | 施設の入所者が優先 |
| 福祉避難所の根拠は**災害対策基本法** | 介護保険法に基づく |
| 医療的ケアが必要な人も**対象になる** | 医療的ケアが必要な人は対象外 |
| 労災保険は**パート・アルバイトも対象** | 自営業者が当然に対象 |
| 保険料は**事業主が全額負担** | 労使折半 |
| **通勤中の事故**・**業務による精神障害**も対象 | 通勤災害は対象外 |

## ひっかけパターン集（安全管理で「ほぼ×」）

| 選択肢の表現 | なぜ× |
|---|---|
| 事故が起きてから体制を考える | 事前に整える |
| 小さな事故は個人で対応 | 組織で報告・共有 |
| 事故記録に職員名を残さない | 事実として記録に残す |
| 安全のため外出・行事参加を控える | 生活を制限しない |
| 転倒後「大丈夫」と言うので様子見 | 状況と体を観察し医療職へ |
| 下り坂を前向きで | 後ろ向き（前向きだと前に転落しやすい） |
| 水疱をつぶして手当てする | 感染の原因になる。破らずに医療職へ |
| 避難所で水分を控える | 脱水・血栓の原因 |
| BCPの策定は任意 | 2024年4月から全事業所で義務 |
| 個別避難計画は施設長が作る義務 | 市町村の努力義務 |
| 福祉避難所は介護保険法に基づく | 災害対策基本法に基づく |
| 労災保険料は労使折半 | 事業主の全額負担 |
| 通勤中の事故は労災の対象外 | 通勤災害も対象 |
