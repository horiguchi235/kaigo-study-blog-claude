**この記事のポイント**

1. 事故予防の基本は**ヒヤリ・ハットの収集・分析**と**組織での体制づくり**（委員会・研修）。事故が起きたら**速やかに家族へ連絡**。
2. 転倒した人には、医療職が来るまで**そばで状況と体の様子を把握**。自己判断で湿布・飲水・様子見はしない。
3. 防災は**計画を職員で共有**、**BCP策定は義務**。警戒レベル3なら**垂直避難**。避難所では**体を動かして血栓予防**。

## ① リスクマネジメント【介護の基本】

### ハインリッヒの法則

**1件の重大事故**の背後に **29件の軽微な事故**、**300件のヒヤリ・ハット**がある（1：29：300）。

→ ヒヤリ・ハットを**集めて分析する**ことが事故防止につながる。

### よく出る○×

| ○ | × |
|---|---|
| **事故が起きる前から**体制を整える | 事故が起きてから検討 |
| 生活を制限されるストレスも事故の原因になる | 社会的活動・飲酒喫煙・お祭り参加を制限 |
| 職員に**安全の研修を定期的に** | 施設管理者の安全が第一／画一的なサービス |
| **安全対策担当者**を置き、**事故防止の委員会を定期開催** | 苦情はその場で職員が解決／私物破損は自己判断で弁償 |
| 事故が起きたら**速やかに家族に連絡** | 損害賠償は市町村／職員名を記録に残さない |
| 小さな事故・インシデントも**組織で報告・共有**（書面で） | 個人で対応／口頭のみ／報告後は代表者に一任 |
| 事故報告書は職員で共有し再発防止に生かす | 管理者以外閲覧不可 |

> 細心の準備をしても、慣れても、事故は**起こりうる**という前提で考えます。

## ② 事故発生時の対応・場面ごとの危険回避【介護の基本】

| 場面 | ○ 正解 | × |
|---|---|---|
| 転倒して腹部と足を強く打った | 医療職が来るまで**そばで転倒の状況や身体状況を把握** | 湿布を貼る・水を飲ませる・仰向けにする・「大丈夫」で様子見 |
| 食事介助中に姿勢が傾いてきた | **姿勢を直す** | — |
| 車いすで前かがみになってスプーンを拾おうとする | すぐ近づいて**代わりに拾う・支える** | 目で確認するだけ |
| 下肢筋力が落ちた人が靴下で歩いている | 滑りにくい**靴**を履いてもらう | スリッパ |
| フットサポートを下げたまま立とうとする | **フットサポートを上げる** | またいでもらう |
| ふらつきながら廊下を歩く人 | 声をかけ付き添う | 黙って通り過ぎる |

### 車いすの安全

| ○ | × |
|---|---|
| **急な下り坂は後ろ向き**で降りる | 前向きで降りる |
| 点検は**定期的に** | 気づいたときだけ |
| 空気圧は適正に（低いとブレーキが利きにくい） | 空気圧を下げる |
| — | 2台同時に押す／ドアを片手で押さえながら押す |

### パーキンソン病の人

**歩き始めはリズムをとれるよう声をかける**（「いち、に」）。常に車いす＋ベルト固定、お茶をなみなみ注ぐ、入浴中に浴室を離れるは×。

> 2010年の内閣府調査では、自宅での転倒場所は「**庭**」が最多でした。最近の調査では居室・居間が多い結果もあるので、問題文の調査に注意。

## ③ 災害・防災・避難所【介護の基本／社会の理解】

### 施設の防災

| ○ | × |
|---|---|
| **非常災害対策計画**の内容を**職員間で十分に共有** | — |
| **業務継続計画（BCP）の策定が義務**（2024年度から全事業所） | 防災士の資格・DWATでの活動が義務 |
| 消火・避難訓練は**年2回以上**（夜間想定も） | 年1回／夜間は避ける |
| 避難行動要支援者名簿・個別避難計画は**市町村**が作る | 施設長に義務 |

### 警戒レベルと図記号

| 項目 | ○ 正解 |
|---|---|
| 洪水で**警戒レベル3（高齢者等避難）**、3階建ての施設 | **垂直避難**（上の階へ）を誘導 |
| 人の足元に円の図記号 | **避難場所**（一時的に身を守る場所）。避難所（生活する場所）とは別 |

### 避難所での支援

| ○ | × |
|---|---|
| **深部静脈血栓症（エコノミークラス症候群）予防に運動**を勧める | 日中も横になる／水分を控える |
| 情報提供に**音声やピクトグラム**も使う | 土足で過ごす／全員同じ食事／和式トイレ |
| 「個」への配慮（杖の人は杖のまま） | 全体の調和を優先／全員車いす |

### 福祉避難所・労災保険

| ○ | × |
|---|---|
| 福祉避難所は**在宅の要配慮者**向け。**介護老人福祉施設の入所者は原則対象外** | 介護保険法に基づく／医療的ケアが必要な人は対象外 |
| 労災保険は**パート・アルバイトも対象** | 自営業者が当然に対象 |
| 保険料は**事業主が全額負担**。**通勤中の事故**・**業務による精神障害**も対象 | 労使折半／通勤災害は対象外 |
