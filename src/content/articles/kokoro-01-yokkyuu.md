**この記事のポイント**

1. マズローは下から「**生理的 → 安全 → 所属・愛情 → 承認 → 自己実現**」。**自己実現だけが成長欲求**、ほかの4つは欠乏欲求。
2. 適応機制は事例で出る：**子どもに返る＝退行**、**もっともらしい言い訳＝合理化**、**別の得意分野で埋め合わせ＝補償**。
3. 加齢で衰えやすいのは**エピソード記憶**と**短期記憶**、保たれやすいのは**手続き記憶**と**意味記憶**。

## ① マズローの欲求階層説【こころとからだのしくみ／発達と老化の理解】

| 段階（下から） | 中身 | 試験に出た例 |
|---|---|---|
| ① **生理的欲求** | 食べる・眠る。**ホメオスタシス**（体の状態を一定に保つ働き）で制御 | 「おなかがすいたので食事をしたい」 |
| ② **安全欲求** | 身の安全、生命を脅かされない | — |
| ③ **所属・愛情欲求** | **好意のある人との良好な関係**、仲間がほしい | 「深く話せる**同年代の同僚**がほしい」、「心を打ち明けられる親友がほしい」 |
| ④ **承認欲求** | 他者から**認められたい**・賞賛 | 骨折後、車いす生活で**役割を失い元気がない**（関係は良好） |
| ⑤ **自己実現欲求** | 自分らしく成長したい（**最上層**） | 「**平和な社会をつくりたい**」 |

- ①〜④は**欠乏欲求**（満たされないと不満）、⑤は**成長欲求**
- 5段階（4段階は×）。最下層は**生理的欲求**

## ② 適応機制（防衛機制）【こころとからだのしくみ／発達と老化の理解】

| 機制 | 意味 | 試験に出た例 |
|---|---|---|
| **退行** | **子どものように振る舞う**・依存的になる | 周囲の関心が新しい入所者に移り、**伝い歩きをやめ失禁**するように／「危ないから座っていて」と言われ続け、**着替えも手伝ってと依存** |
| **合理化** | **もっともらしい理由**をつけて自分を正当化 | 「他人には自分の気持ちがわかるはずがない、**どうせ代わっても同じ**」 |
| **補償** | 劣っている面を**別の面の優越感**で埋め合わせる | 身体機能の低下の代わりに**認知的な活動で優越感** |
| 投影 | 自分の受け入れがたい感情を**相手のもの**と思う | 自分が嫌いなのに「相手が自分を嫌っている」 |
| 抑圧 | つらい気持ちを**無意識に押し込める** | — |
| 逃避 | つらい場面を**避けてひきこもる** | — |
| 昇華 | 欲求を**社会的に価値のある活動**に向ける | — |
| 反動形成 | 本心と**反対の態度**をとる | 嫌いな人に過剰に優しく |
| 同一化 | 尊敬する人の**まね**をする | — |

**学習性無力感**：入所時は「買物に行きたい」などと要望していたが、かなえられない経験が重なり、「どこにも行きたくない」と**無気力**になった状態。

## ③ ストレス反応・PTSD・こころの状態【こころとからだのしくみ】

| 状態 | 特徴 |
|---|---|
| **PTSD**（心的外傷後ストレス障害） | 災害などの体験が**繰り返し思い起こされる**（フラッシュバック）、**入眠障害・イライラ・夜中に突然目が覚める**（土砂崩れの後）。**1か月以上**続く |
| **抑うつ状態** | 夫の死・骨折・入所が重なり、「**死にたい**」ともらす |
| **夕暮れ症候群** | 認知症の人が**夕方から夜にかけて**落ち着かず怒りっぽくなる |
| **情動** | **短い時間の大きな感情**の動き（怒り・喜び） |
| 気分 | 弱いが**長く続く**感情 |

> 3歳の子の言葉の発達の遅れを心配する母親への助言 → **児童発達支援センター**に相談。

## ④ 記憶と学習【こころとからだのしくみ／発達と老化の理解】

- 記憶の3過程：**記銘（覚える）→ 保持（覚えておく）→ 想起（思い出す）**
- 記憶をつかさどる脳の部位：**海馬**

| 記憶 | 中身 | 加齢の影響 |
|---|---|---|
| **短期記憶** | **数十秒**だけ覚えておく。**容量が小さい**（7±2個） | 低下。**ふだんかけない電話番号を覚えられない** |
| **エピソード記憶** | **自分に起きた出来事**の記憶 | **加齢の影響を強く受ける** |
| **意味記憶** | **言葉の意味・知識** | 影響を受けにくい |
| **手続き記憶** | **体で覚えた技能**（自転車・裁縫） | **長く保たれる** |

- 高齢者は**複数のことを同時に行う能力**（注意の分配）が低下する
- 若い頃の記憶は**10〜30歳代**の出来事をよく覚えている（レミニセンス・バンプ）
- 「パブロフの犬」は**古典的条件づけ**（道具的条件づけは×）

## ＋α もう一歩：実務者研修レベルで覚えたいこと

過去問にはまだ出ていないけれど、実務者研修の確認テストでよく問われる、関連して覚えておきたい知識です。

- **欲求の分類**：生理的欲求のうち、**個体保存の欲求**＝呼吸・食事・水分・睡眠・排泄など／**種族保存の欲求＝性の欲求**。**ホメオスタシス（恒常性）**＝体の内部の状態を一定に保つしくみ。**達成動機**＝目標をやり遂げたいという欲求。
- マズローの5段階＝生理的→安全→所属・愛情→承認→自己実現（「未来的思考欲求」などはない）。
- **感情の種類**：情動（情緒）＝急に起こる強い感情／**気分**＝弱く長く続く感情で、行動のきっかけにもなる／**情操**＝美しさや道徳など価値に結びついた感情。
- **防衛機制の追加**：**代償（補償）**＝苦手な面を別の得意な面で補う（**昇華とは別**）／昇華＝欲求を社会的に認められる活動に向ける／同一化＝あこがれの人の特徴を取り込む。
- **学習理論**：**パブロフ**＝古典的条件づけ（犬とベル）／**スキナー**＝オペラント条件づけ（行動とその結果）／**ケーラー**＝洞察学習（ひらめき）／**バンデューラ**＝**観察学習（モデリング）**…大人が人形をたたくのを見た子どもがまねる実験。
- 記憶：**朝食に何を食べたか＝エピソード記憶**（意味記憶ではない）。
- **住まいの役割**：休息など生理的役割／安全の役割／**家族との関係を通して安心や精神的満足を得る**心理的役割／地域との交流などの社会的役割。
