**この記事のポイント**

1. マズローは下から「**生理的 → 安全 → 所属・愛情 → 承認 → 自己実現**」。**自己実現だけが成長欲求**、ほかの4つは欠乏欲求。
2. 適応機制は事例で出る：**子どもに返る＝退行**、**もっともらしい言い訳＝合理化**、**別の得意分野で埋め合わせ＝補償**。
3. 加齢で衰えやすいのは**エピソード記憶**と<strong>作業記憶（覚えながら処理する力）</strong>、保たれやすいのは**手続き記憶**と**意味記憶**。<strong>短期記憶</strong>（数十秒覚えておける量）は加齢の影響を比較的受けにくい。

## ① マズローの欲求階層説

| 段階（下から） | 中身 | 試験に出た例 |
|---|---|---|
| ① **生理的欲求** | 食べる・眠る。**ホメオスタシス**（体の状態を一定に保つ働き）で制御 | 「おなかがすいたので食事をしたい」 |
| ② **安全欲求** | 身の安全、生命を脅かされない | — |
| ③ **所属・愛情欲求** | **好意のある人との良好な関係**、仲間がほしい | 「深く話せる**同年代の同僚**がほしい」、「心を打ち明けられる親友がほしい」 |
| ④ **承認欲求** | 他者から**認められたい**・賞賛 | 骨折後、車いす生活で**役割を失い元気がない**（関係は良好） |
| ⑤ **自己実現欲求** | 自分らしく成長したい（**最上層**） | 「**平和な社会をつくりたい**」 |

- ①〜④は**欠乏欲求**（足りないと満たそうとする欲求）、⑤だけが**成長欲求**（さらに伸びたいという欲求）
- 5段階（4段階は×。「未来的思考欲求」などの段階はない）。最下層は**生理的欲求**、下の欲求がある程度満たされると上の欲求が出てくる

### 欲求のそのほかの分け方

| 用語 | 意味 |
|---|---|
| 個体保存の欲求 | 自分が生きるための欲求（呼吸・食事・水分・睡眠・排泄など） |
| 種族保存の欲求 | 子孫を残すための欲求（性の欲求） |
| ホメオスタシス（恒常性） | 体温・血圧・体液などを一定に保つ働き。司令塔は**視床下部**（自律神経・内分泌・免疫で調整） |
| 達成動機 | 目標をやり遂げたいという欲求 |
| 内発的動機づけ | **興味・好奇心・楽しさ**から行う |
| 外発的動機づけ | **ほうび・罰・指示・評価**のために行う（親に言われてしかたなく掃除する） |

## ② 適応機制（防衛機制）

適応機制は、不安や欲求不満から自分の心を守るために、**無意識に**とる心の動きです。

| 機制 | 意味 | 例（★は試験に出た例） |
|---|---|---|
| **退行** | **子どものように振る舞う**・依存的になる | ★周囲の関心が新しい入所者に移り、**伝い歩きをやめ失禁**するように／★「危ないから座っていて」と言われ続け、**着替えも手伝ってと依存** |
| **合理化** | **もっともらしい理由**をつけて自分を正当化 | ★「他人には自分の気持ちがわかるはずがない、**どうせ代わっても同じ**」 |
| **補償** | 劣っている面を**別の得意な面**で埋め合わせる | ★身体機能の低下の代わりに**認知的な活動で優越感**（足が弱ったので囲碁で一番を目指す） |
| 代償 | 手に入らないものの代わりに、**似た別のもので満足**する | 子どもがいないので、ペットをわが子のようにかわいがる |
| 昇華 | 満たされない欲求を**社会的に価値のある活動**に向ける（代償の一種。補償とは別） | 失恋のつらさを歌づくりに向ける |
| 投影 | 自分の受け入れがたい感情を**相手のもの**と思う | 自分が嫌いなのに「相手が自分を嫌っている」 |
| 抑圧 | つらい気持ちや記憶を**無意識に押し込める** | つらい事故のことを思い出せない |
| 逃避 | つらい場面を**避けてひきこもる**・別のことに逃げる | リハビリの時間になると眠くなる |
| 反動形成 | 本心と**反対の態度**をとる | 嫌いな人に過剰に優しくする |
| 同一化（同一視） | 尊敬する人や権威のある人に**自分を重ね**、その特徴を取り込む | あこがれの先輩と同じ言い方・服装をする |
| 攻撃 | 欲求不満の原因や周りの人・物に**怒りをぶつける** | 思いどおりにならず職員にどなる |

**学習性無力感**：入所時は「買物に行きたい」などと要望していたが、かなえられない経験が重なり、「どこにも行きたくない」と**無気力**になった状態。

## ③ ストレス反応・PTSD・こころの状態

| 状態 | 特徴 |
|---|---|
| **PTSD**（心的外傷後ストレス障害） | 災害などの体験が**繰り返し思い起こされる**（フラッシュバック）、**入眠障害・イライラ・夜中に突然目が覚める**（土砂崩れの後）。**1か月以上**続く |
| **抑うつ状態** | 夫の死・骨折・入所が重なり、「**死にたい**」ともらす |

### 感情の種類

| 感情 | 特徴 |
|---|---|
| **情動**（情緒） | **短い時間に急に起こる大きな感情**の動き（怒り・喜び・驚き・恐怖） |
| **気分** | 弱いが**長く続く**感情。対象がはっきりせず、行動のきっかけにもなる |
| 情操 | 美しさ・正しさ・道徳など、**価値に結びついた**感情 |

## ④ 記憶と学習

- 記憶の3過程：**記銘（覚える）→ 保持（覚えておく）→ 想起（思い出す）**
- 記憶をつかさどる脳の部位：**海馬**

### 記憶の分類

- 覚えている時間で分けると：感覚記憶（一瞬）→ **短期記憶**（数十秒）→ **長期記憶**（長く残る）
- 長期記憶は、言葉で説明できる**陳述記憶**（**エピソード記憶**・**意味記憶**）と、言葉にしにくい**非陳述記憶**（**手続き記憶**・プライミング）に分かれる
- **エピソード記憶は長期記憶**（短期記憶ではない）。ただし加齢の影響は**強く受ける**
- 「短期記憶（数十秒、量）」と「作業記憶（覚えながら処理する）」は別のもの。落ちやすいのは**作業記憶**のほう
- 「**近時記憶**」は数分〜数日前のことの記憶で、医療・認知症の場面で使う分け方（短期記憶より長い時間）

| 記憶 | 中身 | 加齢の影響 |
|---|---|---|
| **短期記憶** | **数十秒**だけ覚えておく。**容量が小さい**（7±2個） | 覚えておける量は、加齢の影響を**比較的受けにくい** |
| **作業記憶**（ワーキングメモリ） | 短期記憶を使い、**覚えながら同時に処理**する（暗算・会話しながらの作業） | **低下しやすい**。聞いた電話番号を覚えながら、別のことをするのが苦手になる |
| **エピソード記憶** | **自分に起きた出来事**の記憶（朝食に何を食べたか） | **加齢の影響を強く受ける** |
| **意味記憶** | **言葉の意味・知識** | 影響を受けにくい |
| **手続き記憶** | **体で覚えた技能**（自転車・裁縫） | **長く保たれる** |
| プライミング | 前に見聞きしたものの影響で、思い出しやすくなる | 保たれやすい |

- 高齢者は**複数のことを同時に行う能力**（注意の分配）が低下する
- 若い頃の記憶は**10〜30歳代**の出来事をよく覚えている（レミニセンス・バンプ）

### 学習理論

| 人 | 理論 | 中身 |
|---|---|---|
| **パブロフ** | **古典的条件づけ** | ベルの音とえさを組み合わせると、ベルだけで犬がよだれを出す（道具的条件づけは×） |
| スキナー | オペラント（道具的）条件づけ | 行動の後にほうび・罰があると、その行動が増える・減る |
| ケーラー | 洞察学習 | 試行錯誤ではなく「ひらめき」で解決する |
| **バンデューラ** | **観察学習（モデリング）** | 大人が人形をたたくのを見た子どもがまねる |
