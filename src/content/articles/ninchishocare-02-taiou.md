**この記事のポイント**

1. 事例問題の正解は「**否定しない・気持ちを受け止める・一緒に行動する**」。説得・訂正・制止・病気の説明は×。
2. 繰り返す行動には「**なぜそうするのか（理由・目的）を観察して考える**」。
3. 急な変化（ふらつき・むせ・物忘れの悪化）は「**薬・体調・受診**」を疑う。

## ① 場面別の対応【認知症の理解】

| 場面 | ○ 正解 | × よく出る不正解 |
|---|---|---|
| 「泥棒に通帳を盗まれた」 | **一緒に探すことを提案**する | 保管場所を忘れたのでしょう／認知症が進んだと伝える／話題を変える |
| 夫が「泥棒が入った、警察に」と言われ困っている | 「**一緒に探してみては**」と助言 | 薬で抑える／施設入所／認知症だと説明する |
| 大切な人形がなくなったと大声 | 「**心配ですね、一緒に探しませんか**」 | 「私を疑っているんですか」「見えないんですか」 |
| 死別した妻の父親と間違えられる夫 | つらさを聴き、**誤認を否定せず、いつもどおり**に接するよう勧める | 諦めるよう伝える／受診を勧める |
| 夜中に荷物を持ち「出口はどこか」 | 「**どちらに行きたいのですか**」と声をかけて**並んで歩く** | 「家族が迎えに来ます」とうそ／荷物を持って腕を取る |
| 入所3日目「家に帰ります」と大声 | まず**本人が訴えている内容**を優先して検討 | ほかの利用者が落ち着かないこと／薬が効かないこと |
| 外へ出て帰れなくなることを繰り返す | **日常の様子を観察**し、**出ていく理由や目的**を検討 | 制止する／「通行止め」の札／「ここが家です」と繰り返す |
| 息子の居場所を心配 | 「**会社で働いていますから、安心してください**」 | 「座っていてください」「おむつの中にしても」「皆さん同じです」 |
| 今どこにいるかわからない | **そのたびに場所を伝える** | ヒントだけ伝えて考えさせる／着衣失行で毎回代わりに着せる |
| 両手に便がついている | 「**手を洗いましょう**」 | 「臭い」「汚い」「ここはトイレではありません」 |
| パソコンの操作に迷いイライラ | **使い方を手助け**する | パソコンを処分／施設入所を相談 |

### 体調・医療とのつながり

| 場面 | ○ 正解 |
|---|---|
| 意欲低下のあと、怒りっぽく直前のことを忘れる | 「**かかりつけ医に診てもらいましょう**」（認知症と決めつけない） |
| 服薬中の人が急にむせる・ふらつく（麻痺なし） | 「**処方薬が変更されていませんか**」 |
| グループホームの人が骨折で入院 | **看護師に日常生活の状況を伝える** |
| 看取り期・反応が少ない | **苦痛があるかないか状態を観察**する |

介護老人保健施設に入所した認知症高齢者が、夜中に荷物を持って部屋から出てきて「出口はどこか」と聞いてきた。介護福祉職の対応として最も適切なものはどれ？

1. 「今日はここにお泊りになることになっています」と伝える
2. 「もうすぐご家族が迎えに来るので、お部屋で待っていましょう」と誘う
3. 「トイレですよね」と手を取って案内する
4. 「どちらに行きたいのですか」と声をかけて並んで歩く
5. 「部屋に戻って寝ましょう」と荷物を持って腕を取る

<details class="answer">
<summary>正解を見る</summary>

**正解：4**　まず本人の思い（どこへ、なぜ）を聞き、気持ちに寄り添って一緒に歩きます。1・5は本人の思いを無視、2はうそ、3は決めつけです。
</details>

## ② 認知症の人に配慮した環境【認知症の理解】

| ○ | × |
|---|---|
| 部屋やトイレに**表示や目印** | 表示を**壁と同系色**にする |
| 廊下の**手すりに色をつけて目立たせる** | 細かい模様の壁紙で統一 |
| **使い慣れた道具**・**なじみの家具や私物**を見える所に | 新しい便利な道具に変える／家具の配置を毎月変える／私物は見えない所へ |
| **いつも安心感**をもってもらえるように接する | 毎日新しい体験／日中は1人で過ごす |
| 落ち着ける明るさ・音量 | 光の刺激を強く・BGMを大きく |
| **家事などに参加する機会**をつくり**役割**を見つける | 常に見守る／夫の位牌を息子に預ける |
| 食事は**雰囲気**も大切に | 栄養摂取を雰囲気より優先 |

## ひっかけパターン集（対応で「ほぼ×」）

| 選択肢の表現 | なぜ× |
|---|---|
| 「忘れたのでしょう」「病気のせいです」と説明 | 本人の不安を強める |
| 出ていこうとするのを制止する・札を貼る | 理由を探るのが先 |
| 「家族が迎えに来ます」とその場しのぎ | うそは信頼を失う |
| 「汚い」「臭い」と言う | 自尊心を傷つける |
| 興奮には薬で対応・施設入所を勧める | まず関わり方を見直す |
| 環境をこまめに新しくする | なじみが安心につながる |
