**この記事のポイント**

1. 事例問題の正解は「**否定しない・気持ちを受け止める・一緒に行動する**」。説得・訂正・制止・病気の説明は×。
2. 繰り返す行動には「**なぜそうするのか（理由・目的）を観察して考える**」。次にすることは**具体的に**伝える。
3. 急な変化（ふらつき・むせ・物忘れの悪化）は「**薬・体調・受診**」を疑う。

---

## ① 場面別の対応

正解に共通する型は「**① 気持ちを受け止める → ② 行動の理由を探る → ③ 次にすることを具体的に伝える・一緒にする**」です。知らない場面でも、この順で選択肢を見ます。

### 否定せず、気持ちを受け止めて一緒に行動する

| 場面 | ○ 正解 | × よく出る不正解 |
|---|---|---|
| 「泥棒に通帳を盗まれた」 | **一緒に探すことを提案**する | 保管場所を忘れたのでしょう／認知症が進んだと伝える／話題を変える |
| 認知症の妻から「泥棒が入った、警察に連絡して」と言われ、夫が困っている | 「**一緒に探してみては**」と助言 | 薬で抑える／施設入所／認知症だと説明する |
| 大切な人形がなくなったと大声 | 「**心配ですね、一緒に探しませんか**」 | 「私を疑っているんですか」「見えないんですか」 |
| 認知症の妻から、亡くなった妻の父親と間違えられ、つらいと話す夫 | つらさを聴き、**誤認を否定せず、いつもどおり**に接するよう勧める | 諦めるよう伝える／受診を勧める |
| パソコンの操作に迷いイライラ | **使い方を手助け**する | パソコンを処分／施設入所を相談 |

### 行動の理由・目的を探る

| 場面 | ○ 正解 | × よく出る不正解 |
|---|---|---|
| 夜中に荷物を持ち「出口はどこか」 | 「**どちらに行きたいのですか**」と声をかけて**並んで歩く** | 「家族が迎えに来ます」とうそ／荷物を持って腕を取る |
| 入所3日目「家に帰ります」と大声 | まず**本人が訴えている内容**を優先して検討 | ほかの利用者が落ち着かないこと／薬が効かないこと |
| 外へ出て帰れなくなることを繰り返す | **日常の様子を観察**し、**出ていく理由や目的**を検討 | 制止する／「通行止め」の札／「ここが家です」と繰り返す |

### 安心できる事実と、次にすることを具体的に伝える

| 場面 | ○ 正解 | × よく出る不正解 |
|---|---|---|
| 息子の居場所を心配 | 「**会社で働いていますから、安心してください**」 | 「座っていてください」「おむつの中にしても」「皆さん同じです」 |
| 今どこにいるかわからない | **そのたびに場所を伝える** | ヒントだけ伝えて考えさせる |
| 服の着方がわからない（着衣失行） | 着る順に服を並べ、**一つずつ声をかける**（できるところは本人に） | 毎回代わりに着せる |
| 両手に便がついている（便を触ってしまう行動。いわゆる弄便） | 「**手を洗いましょう**」 | 「臭い」「汚い」「ここはトイレではありません」 |

> 「息子さんは会社で働いています」は、本人の不安に応える**事実**を伝えるので○。「家族が迎えに来ます」は、守れない約束（うそ）でその場をしのぐので×。**事実で安心してもらう**のはよく、**うその約束**はいけない、が判断の軸です。

### 体調・医療とのつながり

| 場面 | ○ 正解 |
|---|---|
| 意欲低下のあと、怒りっぽく直前のことを忘れる | 「**かかりつけ医に診てもらいましょう**」（認知症と決めつけない） |
| 服薬中の人が急にむせる・ふらつく（麻痺なし） | 「**処方薬が変更されていませんか**」 |
| グループホームの人が骨折で入院 | **看護師に日常生活の状況を伝える** |
| 看取り期・反応が少ない | **苦痛があるかないか状態を観察**する |

Aさん（84歳、女性、要介護3）は、アルツハイマー型認知症（dementia of the Alzheimerʼs type）で、介護老人福祉施設に入所している。赤ちゃんの人形を持っていて、「はなちゃん」と呼んで話しかけている。

昼食のため、介護福祉職が居室を訪問すると、Aさんは不安そうな顔で、「はなちゃんがいなくなった。どこへ連れて行ったの？返して」と大声を出した。人形はAさんのロッカーの上に置かれていた。

Aさんに対する介護福祉職の最初の声かけとして、最も適切なものを1つ選びなさい。

1. 「私を疑っているんですか」
2. 「置いた場所を忘れたんですか」
3. 「心配ですね、一緒に探しませんか」
4. 「ご飯を食べてから探してはどうですか」
5. 「ロッカーの上にあるのが見えないんですか」

## ② 認知症の人に配慮した環境

| ○ | × |
|---|---|
| 部屋やトイレに**表示や目印** | 表示を**壁と同系色**にする |
| 廊下の**手すりに色をつけて目立たせる** | 細かい模様の壁紙で統一 |
| **使い慣れた道具**・**なじみの家具や私物**を見える所に。施設に入るときは使い慣れた家具を持ち込み、**リロケーションダメージ**（環境が急に変わることによる混乱）を和らげる | 新しい便利な道具に変える／家具の配置を毎月変える／私物は見えない所へ |
| **いつも安心感**をもってもらえるように接する | 毎日新しい体験／日中は1人で過ごす |
| 落ち着ける明るさ・音量 | 光の刺激を強く・BGMを大きく |
| **家事などに参加する機会**をつくり**役割**を見つける | 何もさせずに常に見守る |
| 夫の位牌など**本人の大切な物は本人のそばに** | 夫の位牌を息子に預ける（大切な物を本人から離す） |
| 食事は**雰囲気**も大切に | 栄養摂取を雰囲気より優先 |

## ③ 行動の背景を探る・見当識の手がかり

- **入浴を拒む**ときは、怖さ・遠慮・体調・持ち物の心配など**理由を確かめ**、「心配事があったんですね。どうしたら安心して入れるか一緒に考えましょう」と**本人と一緒に方法を考える**。説得・命令・根拠のない「大丈夫」は避ける。
- 「徘徊」「帰宅願望」は試験や現場で使われる言葉ですが、歩き回る・家に帰りたいと訴える・物を集めるなどの行動には、本人なりの目的や理由があることが多い（不安・役割を果たしたい・トイレを探している など）。**ひもときシート**などで背景を整理する。
- 夕方に落ち着かなくなる**夕暮れ症候群**には、無理に止めず**一緒に歩く・お茶に誘う**など気持ちに寄り添う（症状の説明は → [認知症の中核症状・BPSD・せん妄](../ninchisho-01-shoujou/)）。
- 家族と同居を始めるなど**環境が変わるとき**は、なじみの物を置き、生活習慣を続けられるようにする。照明は**光源が直接目に入らない間接照明**などがよい。
- **見当識**は「**時間→場所→人**」の順に失われやすい。カレンダー・時計・名札で手がかりを増やす。

| 選択肢の表現 | なぜ× |

| 環境をこまめに新しくする | なじみが安心につながる |
