**この記事のポイント**

1. 知的障害は<strong>発達期（おおむね18歳まで）</strong>に現れる。**てんかんの合併が多い**。伝えるときは**身振りや絵**も使う。
2. 自閉スペクトラム症は**社会性・対人関係の障害**と**こだわり**。伝え方は「**具体的に・短く・肯定形で・予定変更は前もって絵やメモで**」。
3. 統合失調症の特徴は**妄想・幻覚**（陽性症状）。うつ病の人には**受容的に**接し、励まさない。

## ① 知的障害・ダウン症候群

| ○ | × |
|---|---|
| **知的機能の障害**と**日常生活の支障**で特徴づけられる | 一度正常に発達した知能が低下したもの（＝認知症） |
| **発達期**に現れる（おおむね18歳まで） | 10歳まで・成人期に出現 |
| **てんかんの合併率が高い** | 女性に多い・重度が大半・遺伝性が大半 |
| 原因がわからないことも多い | 原因は明らか |
| 一般就労している人も多い | 一般就労は不可能 |
| 療育手帳は**児童相談所・知的障害者更生相談所**が判定 | 障害支援区分で等級を決める |

- 程度のめやす：厚生労働省の知的障害児（者）基礎調査では、IQ（知能指数）を**おおむね51〜70／36〜50／21〜35／20以下**の4段階に分け、**日常生活能力**と合わせて軽度〜最重度を判定します（IQの境界値は、ICD-10の「軽度＝50〜69」など出典によって少し違います）。
- **強度行動障害**＝自傷・他害などが高い頻度で起こり、特別な支援が必要な状態（診断名ではない）。
- **原因**：原因がはっきりしている**病理型**（染色体異常、妊娠中の感染症やアルコール、出産時の障害、乳幼児期の高熱など）と、原因がはっきりしない**生理型**があり、**生理型のほうが多い**。だから「原因は明らか」は×。
- **重症心身障害**＝**重度の知的障害**と**重度の肢体不自由**が重なった状態（内部障害との重複ではない）。

### 支援の方法

- 伝えるときは**言葉だけでなく身振りや絵**も使う。作業は**1工程ずつ区切ってゆっくり**、写真・実物・見本で
- **本人を交えて**決める。子ども扱いしない
- 失敗も経験のうち。先回りしすぎない。マナー違反は**その場で**伝える

### ライフステージに応じた支援

試験で問われたのは**壮年期**（第26回）。ほかの時期は流れをつかむための整理です。

| 時期 | 支援 |
|---|---|
| 乳幼児期 | 家族の障害受容を支える |
| 学齢期 | 身体と心の成長のアンバランスへの配慮 |
| 成人期 | 就労・自立した生活 |
| **壮年期**（試験に出た） | **親と死別した後の生活への適応**（親亡き後） |
| 老年期 | 65歳になると、同じ内容のサービスは原則として**介護保険が優先**。なじみの事業所を使い続けられるよう**共生型サービス**もある |

### ダウン症候群

- 原因：**染色体異常**（21番染色体が1本多く3本ある＝**21トリソミー**）
- 合併しやすいもの：**難聴**、**先天性心疾患**、筋緊張の**低下**、早い老化。首の骨の不安定さにも注意

## ② 発達障害

| 障害 | 特徴 |
|---|---|
| **自閉スペクトラム症（ASD）** | **社会性の障害・対人関係の障害**、**コミュニケーションの障害**、**こだわりが強い**、**変化への不安が強い**。音や光などの**感覚過敏**も |
| **学習障害（LD）** | 知的な遅れはないが、**読む・書く・計算する**などの習得が難しい |
| **ADHD**（注意欠如・多動症） | 不注意・多動（じっとしていられない）・衝動性 |

**呼び名の対応**（選択肢には新旧どちらも出ます）

| 新しい呼び名（DSM-5など） | 古い呼び名・別名 |
|---|---|
| 自閉スペクトラム症（ASD） | 自閉症・アスペルガー症候群・広汎性発達障害・自閉症スペクトラム障害 |
| 限局性学習症（SLD） | 学習障害（LD） |
| 注意欠如・多動症（ADHD） | 注意欠陥多動性障害 |

**アスペルガー症候群**（古い呼び名）＝今の自閉スペクトラム症のうち、**知的な遅れや言葉の遅れが目立たない**タイプ。言葉は話せるのに、相手の反応に関係なく**自分の興味のことばかり話す**、冗談や遠回しな言い方がわからない、悪気なく失礼なことを言ってしまう、などで困りやすくなります。

| 選択肢の特徴 | 当てはまるもの |
|---|---|
| 言葉の遅れがある | 知的障害を伴う自閉症（アスペルガー症候群ではない） |
| 計算だけが極端に苦手 | 学習障害 |
| 動き回る・忘れ物が多い | ADHD |

- 発達障害は、2010年の障害者自立支援法（今の障害者総合支援法）の改正で、**精神障害に含まれる**ことが法律に書かれました（手帳は精神障害者保健福祉手帳。知的障害を伴えば療育手帳も）。**トゥレット症候群**（声や体の動きをくり返すチック）や**吃音**も発達障害に含まれます。いくつかの発達障害が重なって現れることもあります。
- 原因は**脳の機能の障害**。**親の育て方・愛情不足・本人の努力不足ではない**
- ASDの人は「その場の雰囲気や相手の意図を読み取る」「協調作業」が**苦手**。幻覚・妄想・構音障害は特徴ではない
- 支援の基本：情報は**一度に1つ**、**予定の変更は前もって**、言葉だけでなく**絵や写真で具体的に**、感覚過敏ならつらい刺激を避ける。相談先は**発達障害者支援センター**

### ASDの人への伝え方

| ○ | × |
|---|---|
| 「**Eちゃんは、これから遊園地に行きます**」（具体的・短く） | 「もっとたくさん」（あいまい）／「いい子にしていたら」（条件）／「手を洗って、ご飯を食べて…」（一度に多く）／「終わらないと連れて行きません」（否定形） |
| **予定の変更**は**メモや絵で予告** | 強く制止する・一度に多くの情報・パニックの原因を克服する訓練 |

### 就労支援

発達障害の人が**一般就労**に向けて使う → **職場適応援助者（ジョブコーチ）**（職場に出向いて、本人と職場の両方に働きかける）。

| 就労系のサービス | 中身 |
|---|---|
| 就労移行支援 | 一般就労をめざして、訓練や職場探しをする（期限あり） |
| 就労継続支援A型 | **雇用契約を結んで**働く |
| 就労継続支援B型 | **雇用契約を結ばない**福祉的就労 |
| 就労定着支援 | **就職した後**、働き続けられるよう支える |

行動援護・同行援護は外出の支援で、就労の支援ではありません（→ [同行援護・行動援護・移動支援・重度訪問介護の違い](../hikaku-06-idoushien/)）。

## ③ 精神障害

### 統合失調症

精神障害は、原因の考え方で3つに分けられます。

| 分類 | 原因 | 例 |
|---|---|---|
| 外因性 | 脳や体の病気・けが・薬物など、**外から確かめられる原因** | 脳腫瘍・認知症・アルコール依存症 |
| **内因性** | はっきりしないが、体質など**内側の要因**が考えられる | **統合失調症**・双極性障害・うつ病 |
| 心因性 | ストレスなど**心の要因** | パニック障害などの神経症 |

- 統合失調症は**内因性**。青年期〜成人期に発症しやすい
- 特徴的な症状は**妄想**

| 陽性症状（本来ないものが出る） | 陰性症状（本来あるものが減る） |
|---|---|
| **幻覚**（幻聴が多い）・**妄想**・誰かに操られている感覚・話のまとまりがない | **感情の動きが乏しくなる**（感情の平板化）、意欲の低下、引きこもり |

- 幻聴・妄想の訴えは**否定も肯定もせず**、不安に寄り添って聴く（内容に同調はしない）
- **回復期**：**病の体験と現実との葛藤**があることを理解して支援する。新しいことを次々に・発症前の生活にすぐ戻す・薬を自己判断で減らす、は×
- 水を飲みすぎる**水中毒**に注意

### うつ病

| ○ | × |
|---|---|
| 訴えに**受容的に**接する | 励ます・にぎやかな場所に誘う |
| ゆっくり、**休養**を大切に | 次から次へと話しかける |
| **自殺念慮**を打ち明けられたら**真剣に受け止め**、専門職につなぐ。**回復しかけた時期も自殺に注意** | 無関心でいる |

- 高齢者のうつ病（老年期うつ病）は、気分の落ち込みより**体の不調の訴え**やもの忘れが目立つことがある → [高齢期の心理・知能・喪失と悲嘆](../kokoro-02-koureiki/)

### そのほかの精神障害

| 病気 | 特徴 |
|---|---|
| 双極性障害 | 気分が高ぶる**躁状態**と**うつ状態**をくり返す |
| アルコール依存症 | 急にやめると手のふるえや幻覚（**離脱症状**・**振戦せん妄**：手のふるえ・意識がぼんやり・虫が見えるなどの幻視・眠れない）。長く続くと**コルサコフ症候群**（新しいことを覚えられない・日時や場所がわからない・**作話**＝事実でない話をつくる） |

**まぎらわしい言葉の見分け**

| 言葉 | 意味 |
|---|---|
| せん妄 | 体の病気や薬などで**急に**起こる**意識の混乱**（一時的） |
| 妄想 | 意識ははっきりしているのに、**事実でないことを強く信じ込む**（統合失調症の中心症状） |
| 幻覚 | **ないものが見える・聞こえる** |

### 治療と介護の原則

- 治療は、**薬物療法**（中心）・**精神療法**（カウンセリングなど話を聴いて苦痛を和らげる）・**生活療法**（作業療法・レクリエーション療法など、生活の中で練習する）を組み合わせます。
- 介護の原則：ありのままを受け止めて共感する／被害的な訴えも頭から否定せずに聴く／動きが少ない人には歯みがき・洗顔など日常の行動を促す／薬を飲めているか確かめ、**飲みたがらないときは介護職が説得せず医師・看護師につなぐ**。
- 精神科に入院している人で最も多い病気は**統合失調症**です。
