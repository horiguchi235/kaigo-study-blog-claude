**この記事のポイント**

1. 知的障害は**発達期（おおむね18歳まで）**に現れる。**てんかんの合併が多い**。伝えるときは**身振りや絵**も使う。
2. 自閉スペクトラム症は**社会性・対人関係の障害**と**こだわり**。伝え方は「**具体的に・短く・肯定形で・予定変更は前もって絵やメモで**」。
3. 統合失調症の特徴は**妄想・幻覚**（陽性症状）。うつ病の人には**受容的に**接し、励まさない。

## ① 知的障害・ダウン症候群【障害の理解】

| ○ | × |
|---|---|
| **知的機能の障害**と**日常生活の支障**で特徴づけられる | 一度正常に発達した知能が低下したもの（＝認知症） |
| **発達期**に現れる（おおむね18歳まで） | 10歳まで・成人期に出現 |
| **てんかんの合併率が高い** | 女性に多い・重度が大半・遺伝性が大半 |
| 原因がわからないことも多い | 原因は明らか |
| 一般就労している人も多い | 一般就労は不可能 |
| 療育手帳は**児童相談所・知的障害者更生相談所**が判定 | 障害支援区分で等級を決める |

### 支援の方法

- 伝えるときは**言葉だけでなく身振りや絵**も使う
- **本人を交えて**決める。子ども扱いしない
- 失敗も経験のうち。先回りしすぎない。マナー違反は**その場で**伝える

### ライフステージに応じた支援

| 時期 | 支援 |
|---|---|
| 乳幼児期 | **家族の障害受容**を支える |
| 学齢期 | 身体と心の成長のアンバランスへの配慮 |
| 成人期 | 就労・自立した生活 |
| **壮年期** | **親と死別した後の生活への適応**（親亡き後） |
| 老年期 | 介護保険サービスへの移行 |

### ダウン症候群

- 原因：**染色体異常**（21番が3本）
- 合併しやすいもの：**難聴**、心疾患、筋緊張の**低下**、早い老化

## ② 発達障害【障害の理解】

| 障害 | 特徴 |
|---|---|
| **自閉スペクトラム症（ASD）**（旧：自閉症・広汎性発達障害） | **社会性の障害・対人関係の障害**、**コミュニケーションの障害**、**こだわりが強い**、**変化への不安が強い** |
| **学習障害（LD）** | 知的な遅れはないが、**読む・書く・計算する**などの習得が難しい |
| **ADHD**（注意欠如・多動症） | 不注意・多動（じっとしていられない）・衝動性 |

- 原因は**脳の機能の障害**。**親の育て方・愛情不足・本人の努力不足ではない**
- ASDの人は「その場の雰囲気や相手の意図を読み取る」「協調作業」が**苦手**。幻覚・妄想・構音障害は特徴ではない

### ASDの人への伝え方

| ○ | × |
|---|---|
| 「**Eちゃんは、これから遊園地に行きます**」（具体的・短く） | 「もっとたくさん」（あいまい）／「いい子にしていたら」（条件）／「手を洗って、ご飯を食べて…」（一度に多く）／「終わらないと連れて行きません」（否定形） |
| **予定の変更**は**メモや絵で予告** | 強く制止する・一度に多くの情報・パニックの原因を克服する訓練 |

### 就労支援

発達障害の人が**一般就労**に向けて使う → **職場適応援助者（ジョブコーチ）**。行動援護・同行援護は外出の支援、就労継続支援B型は雇用契約を結ばない福祉的就労、就労定着支援は**就職した後**の支援です。

## ③ 精神障害【障害の理解】

### 統合失調症

- **内因性**精神障害。脳腫瘍・認知症は外因性、パニック障害は心因性
- 特徴的な症状は**妄想**

| 陽性症状（本来ないものが出る） | 陰性症状（本来あるものが減る） |
|---|---|
| **幻覚**（幻聴が多い）・**妄想**・誰かに操られている感覚・話のまとまりがない | **感情の動きが乏しくなる**、意欲の低下、引きこもり |

- **回復期**：**病の体験と現実との葛藤**があることを理解して支援する。新しいことを次々に・発症前の生活にすぐ戻す・薬を自己判断で減らす、は×

### うつ病

| ○ | × |
|---|---|
| 訴えに**受容的に**接する | 励ます・にぎやかな場所に誘う |
| ゆっくり、**休養**を大切に | 次から次へと話しかける |
| **自殺念慮**を打ち明けられたら**真剣に受け止め**、専門職につなぐ | 無関心でいる |

## ④ 知的障害の程度・発達障害と精神障害への支援

- **ダウン症候群**＝主に**21番染色体が3本**ある染色体異常。筋緊張の低下・発達の遅れ、**先天性心疾患**を合併しやすい（首の骨の不安定さにも注意）。
- 知的障害のある人に作業を伝えるときは、**1工程ずつ区切ってゆっくり**、写真・実物・見本を使う。
- **統合失調症**：陽性症状＝幻覚・妄想／**陰性症状＝感情の鈍麻・意欲の低下・常同的な思考**。青年期〜成人期に発症しやすい。**幻聴や幻視の訴えは否定せず、受容的な態度で不安に寄り添う**（内容に同調はしない）。服薬は自己判断で増減しない。
- **老年期のうつ病**：体の不調や物忘れが目立つことがある。**喪失体験や家庭内の人間関係の葛藤**も原因になる。安易に励まさず、受診・相談につなぐ。**回復しかけた時期も自殺に注意**。
- 知的障害の程度（IQのめやす）：軽度＝69〜50、中度＝49〜35、重度＝34〜20、最重度＝20未満。発達期（おおむね18歳まで）に現れる。
- **ダウン症候群**＝21番染色体が1本多い（**21トリソミー**）。知的障害に加え、先天性心疾患・難聴を伴いやすい。
- **発達障害**の支援：情報は一度に1つ、**予定の変更は前もって伝える**、言葉だけでなく**絵や写真で具体的に**、感覚過敏ならつらい刺激を避ける。相談先は**発達障害者支援センター**。
- **強度行動障害**＝自傷・他害などが高い頻度で起こる状態（診断名ではない）。
- **統合失調症**：陽性症状（幻覚・妄想）と陰性症状（意欲がない・感情の平板化）。妄想は**否定も肯定もせず**話を聴く。水を飲みすぎる**水中毒**に注意。
- **アルコール依存症**：急にやめると手のふるえや幻覚（**離脱症状・振戦せん妄**）。

| 選択肢の表現 | なぜ× |
|---|---|
| 知的障害は成人期に出現・原因は明らか | 発達期、原因不明も多い |
| 発達障害は親の育て方が原因 | 脳の機能の障害 |
| ASDの人は相手の意図を読むのが得意 | 苦手 |
| ASDの人に「いい子にしたら」と条件付きで | 具体的・肯定的に |

| うつ病の人を励ます | 受容的に接する |
