**この記事のポイント**

1. **地域密着型サービス**は**市町村が指定**し、原則**その市町村の住民**だけが使える。施設サービスは**都道府県**が指定。
2. 「**通い・訪問・泊まり**」＝小規模多機能、「**＋看護**」＝看護小規模多機能、「**24時間・随時訪問**」＝定期巡回。
3. **ケアプラン（居宅サービス計画）＝ケアマネジャー**、**訪問介護計画＝サービス提供責任者**。

## ① サービスの種類【介護の基本／社会の理解】

| 区分 | 指定する所 | 主なサービス |
|---|---|---|
| **居宅サービス** | 都道府県 | 訪問介護・訪問入浴・訪問看護・通所介護・通所リハ・短期入所・福祉用具貸与・特定施設入居者生活介護 など |
| **地域密着型サービス** | **市町村** | **認知症対応型通所介護**・**認知症対応型共同生活介護（グループホーム）**・**小規模多機能型居宅介護**・**看護小規模多機能型居宅介護**・**定期巡回・随時対応型訪問介護看護**・**夜間対応型訪問介護**・地域密着型通所介護・地域密着型特養（定員**29人以下**） |
| **施設サービス** | **都道府県** | 介護老人福祉施設（特養）・介護老人保健施設（老健）・介護医療院 |

### 地域密着型サービスのポイント

| サービス | ○ | × |
|---|---|---|
| **小規模多機能型居宅介護** | **通い**を中心に**訪問・泊まり**を組み合わせる。**運営推進会議**を設ける。地域密着型 | 2012年開始（2006年）／長期の宿泊が目的／管理者は医師 |
| **看護小規模多機能型居宅介護** | **看護と介護を一体的に**提供。旧「複合型サービス」 | 居宅サービス／長期宿泊／都道府県域 |
| **定期巡回・随時対応型訪問介護看護** | **日中・夜間を通じて**、定期訪問と**随時訪問**。要介護者が対象 | 要支援者も使える／緊急時対応なし／都道府県が指定 |
| **認知症対応型通所介護** | 利用者は**原則その市町村の住民** | 65歳以上に限る／家族の送迎が原則 |

### 介護予防・日常生活支援総合事業（総合事業）

- 市町村の**地域支援事業**の一つ。**第一号訪問事業（訪問型サービス）**・<strong>第一号通所事業（通所型サービス）</strong>など
- 「日中話し相手がいなくて寂しい」要支援1の一人暮らし → **通所型サービス**
- 要支援者が自宅で安全に移動したい → **介護予防住宅改修**。夜間対応型訪問介護・小規模多機能（カラオケ目的）は×

### 訪問介護でできること・できないこと

| ○ できる | × できない |
|---|---|
| **生活等に関する相談・助言** | 理美容・通帳と印鑑の預かり・訪問日以外の安否確認 |
| 掃除の習慣がある人と**一緒に**寝室を掃除（自立支援） | **庭の草むしり・植木の水やり**・**ペットの世話**・外食への同行・クレジットカードでの買物代行 |
| 通院介助（**身体介護**） | — |

## ② 介護保険施設・ユニットケア・グループホーム【介護の基本】

| 施設 | 特徴 |
|---|---|
| **介護老人福祉施設（特養）** | **要介護認定**が必要（第2号被保険者も同じ）。新規入所は**原則要介護3以上**。根拠は老人福祉法・介護保険法。1963年の**老人福祉法**で創設（常時介護が必要な**65歳以上**） |
| 介護老人保健施設（老健） | **在宅復帰**をめざすリハビリ中心 |
| **介護医療院** | 長期療養と生活の場。**都道府県知事が許可**。**レクリエーション行事**にも努める |
| 軽費老人ホーム | 低額で入居。**都市型は定員20人以下** |

### ユニットケア

| ○ | × |
|---|---|
| 1ユニット**おおむね10人以下** | 20名程度／4人部屋 |
| ユニットの担当職員を**一定期間固定**（なじみの関係） | — |
| 共同生活室で**入所者同士の関係**を築く | 居室で食事／交流はユニット内に限定 |
| **家族や友人が気軽に宿泊**できる配慮 | 施設が決めた時間内に食べ終える／施設内で生活を完結 |

- **なじみのある人や店との関係を継続**する。同じ日課・過去の状態の把握を優先・車いす移動を勧める、は×

## ④ 事業所の指定と費用を軽くする制度

**介護保険サービスの全体像**（過去問に出ていないものも含めて一覧にしておきます）

| 区分 | 指定する人 | 主なサービス |
|---|---|---|
| 居宅サービス | 都道府県 | 訪問介護・訪問入浴介護・訪問看護・訪問リハビリテーション・**居宅療養管理指導**／通所介護・通所リハビリテーション／短期入所生活介護・短期入所療養介護／**特定施設入居者生活介護**／福祉用具貸与・特定福祉用具販売 |
| 地域密着型サービス | **市町村** | **定期巡回・随時対応型訪問介護看護**・夜間対応型訪問介護・地域密着型通所介護・**認知症対応型通所介護**・**小規模多機能型居宅介護**・**看護小規模多機能型居宅介護**・**認知症対応型共同生活介護（グループホーム）**・地域密着型特定施設入居者生活介護・地域密着型介護老人福祉施設入所者生活介護 |
| 施設サービス | 都道府県 | **介護老人福祉施設（特養）**・**介護老人保健施設（老健）**・**介護医療院** |
| ケアマネジメント | **市町村** | **居宅介護支援**（ケアプラン作成、**利用者負担なし**）・介護予防支援 |
| その他 | 市町村 | 住宅改修（20万円まで）・**地域支援事業**（総合事業など） |

- **要支援1・2**の人は**施設サービスは使えない**。訪問介護・通所介護は**総合事業**（市町村）で、それ以外の多くは「介護予防〇〇」として使う。**定期巡回・夜間対応型・看護小規模多機能・地域密着型の特定施設や特養**は要支援では使えない（小規模多機能と認知症対応型通所介護には介護予防版があり、グループホームは**要支援2から**）。
- **みなし指定**：病院・診療所や**保険薬局**は、医療保険の指定を受けていれば**居宅療養管理指導**・訪問看護などの指定を受けたとみなされる。
- **複合型サービス**（2012年創設）＝小規模多機能＋訪問看護 → 2015年に**看護小規模多機能型居宅介護**へ名称変更。
- **小規模多機能**：「通い」を中心に「訪問」「泊まり」を組み合わせ、**登録した人の在宅生活を支える**。**グループホーム**：5〜9人のユニットで家庭的に暮らす。教育ではなく、本人の**多様な活動**を大切にする。**認知症対応型通所介護**には、グループホームの共用スペースなどを使う**共用型**もある。
- **通所介護計画**などの個別計画は、ケアマネの**居宅サービス計画（ケアプラン）に沿って**つくる。
- **都市型軽費老人ホーム**＝都市部向けの小規模な軽費老人ホーム（**定員20人以下**）。
- **老健**は在宅復帰を目指す施設なので、医師・看護師・リハビリ職など**医療職との連携**が欠かせない。
- **指定・監督する人**：居宅サービス・施設サービス＝**都道府県知事**（指定都市・中核市は市長）。**居宅介護支援・地域密着型・介護予防支援**＝**市町村長**。指定は**6年ごとに更新**。老健と介護医療院は「指定」ではなく「**開設許可**」。
- **特定施設**＝有料老人ホーム・軽費老人ホーム（ケアハウス）・養護老人ホーム。定員**30人以上**は特定施設、**29人以下**は地域密着型。
- 費用の軽減：**高額介護サービス費**（月の自己負担に上限）・**高額医療・高額介護合算療養費**・**特定入所者介護サービス費**（低所得者の施設の食費・居住費、預貯金が一定以上なら対象外）。
- **居宅介護支援**（ケアプラン作成）は**利用者負担なし**（10割給付）。
- 地域密着型サービスでは、事業所が地域に開かれるよう**運営推進会議**（利用者・家族・市町村職員・地域住民の代表など）を開く。定期巡回・随時対応型は「**介護・医療連携推進会議**」。
