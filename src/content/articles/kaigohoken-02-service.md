## ① サービスの種類

| 区分 | 指定する所 | 主なサービス |
|---|---|---|
| **居宅サービス** | 都道府県 | 訪問介護・訪問入浴介護・訪問看護・訪問リハビリテーション・**居宅療養管理指導**／通所介護・通所リハビリテーション／短期入所生活介護・短期入所療養介護／**特定施設入居者生活介護**／福祉用具貸与・特定福祉用具販売 |
| **地域密着型サービス** | **市町村** | **定期巡回・随時対応型訪問介護看護**・**夜間対応型訪問介護**・地域密着型通所介護・**認知症対応型通所介護**・**小規模多機能型居宅介護**・**看護小規模多機能型居宅介護**・**認知症対応型共同生活介護（グループホーム）**・地域密着型特定施設入居者生活介護・地域密着型介護老人福祉施設（地域密着型特養、定員**29人以下**） |
| **施設サービス** | **都道府県** | 介護老人福祉施設（特養）・介護老人保健施設（老健）・介護医療院 |
| ケアマネジメント | **市町村** | **居宅介護支援**（ケアプラン作成。**利用者負担なし**）・介護予防支援 |
| その他 | 市町村 | 住宅改修（20万円まで）・**地域支援事業**（総合事業など） |

- **指定・監督する人**：居宅サービス・施設サービス＝**都道府県知事**（指定都市・中核市は市長）。**居宅介護支援・地域密着型・介護予防支援**＝**市町村長**。指定は**6年ごとに更新**。老健と介護医療院は「指定」ではなく「**開設許可**」
- **みなし指定**：病院・診療所や**保険薬局**は、医療保険の指定を受けていれば**居宅療養管理指導**・訪問看護などの指定を受けたとみなされる
- **特定施設**＝有料老人ホーム・軽費老人ホーム（ケアハウス）・養護老人ホーム・サービス付き高齢者向け住宅（有料老人ホームにあたるもの）。入居者を要介護者などに限る**介護専用型で定員29人以下**が地域密着型（地域密着型特定施設入居者生活介護）、**それ以外**は居宅サービスの特定施設入居者生活介護

### 居宅サービスは何をしてくれる？

名前だけでは中身がわかりにくいので、「訪問・通い・泊まり・用具」に分けて見ておきましょう。

| 分類 | サービス | 何をしてくれる？ |
|---|---|---|
| 訪問 | **訪問入浴介護** | 浴槽を積んだ車で家に来て、入浴を介助する |
| 訪問 | 訪問看護・訪問リハビリテーション | **主治医が必要と認めた人**の家に、看護師や理学療法士・作業療法士・言語聴覚士が行く |
| 訪問 | **居宅療養管理指導** | 通院が難しい人の家に、医師・歯科医師・薬剤師・管理栄養士・歯科衛生士などが行き、療養の管理と指導をする |
| 通い | **通所介護（デイサービス）** | 日帰りで、**入浴**・食事・排泄の介護や機能訓練をする。家族の介護の負担を軽くする目的もある |
| 通い | 通所リハビリテーション（デイケア） | 老健・病院・診療所などで、医師の管理のもとリハビリをする |
| 通い | 地域密着型通所介護 | 定員**18人以下**の小さなデイサービス（市町村が指定） |
| 通い | 療養通所介護 | 難病や末期がんなど、医療が必要な重い人のためのデイサービス |
| 泊まり | **短期入所生活介護**（ショートステイ） | 特養などに短い期間泊まり、日常の介護を受ける |
| 泊まり | **短期入所療養介護** | 老健・介護医療院などに泊まり、**看護や医学的な管理**も受ける |
| 用具 | 福祉用具貸与／特定福祉用具販売 | 貸与＝**借りる**。肌にふれて貸し借りに向かない入浴・排泄の用具（簡易浴槽・腰掛便座など）は**買う**。一部の用具は貸与か購入かを選べる（くわしくは[住環境・住宅改修・福祉用具](../sumai-01-juukankyou/)） |

- 泊まりのサービスは、家族の旅行・冠婚葬祭・休息（**レスパイト**）のときにも使います
- 福祉用具の購入費は**年10万円まで**、住宅改修費は**原則20万円まで**。どちらも原則**償還払い**（いったん全額払い、あとで保険の分が戻る）
- **夜間対応型訪問介護**は、夜間に定期巡回と、通報による随時訪問をするサービス。日中も含めて**24時間**、介護と看護を行うのが**定期巡回・随時対応型訪問介護看護**です（1つの事業所で行う一体型と、訪問看護事業所と組む連携型がある）

### 要支援の人が使えるサービス

| サービス | 要支援1・2の人は？ |
|---|---|
| 訪問介護・通所介護 | 市町村の**総合事業**（訪問型・通所型サービス）で使う |
| 訪問看護・通所リハ・短期入所・福祉用具貸与・**住宅改修**など | 「介護予防〇〇」として**予防給付**で使える |
| 小規模多機能型居宅介護・認知症対応型通所介護 | 介護予防版があり**使える** |
| グループホーム（認知症対応型共同生活介護） | **要支援2から**使える（要支援1は×） |
| 定期巡回・**夜間対応型訪問介護**・看護小規模多機能 | **使えない**（要介護者のみ） |
| 施設サービス・地域密着型特養・地域密着型特定施設 | **使えない** |

### 地域密着型サービスのポイント

| サービス | ○ | × |
|---|---|---|
| **小規模多機能型居宅介護** | **通い**を中心に**訪問・泊まり**を組み合わせ、**登録した人**の在宅生活を支える。2006年に創設 | 2012年に始まった（正しくは2006年）／長期の宿泊が目的／管理者は医師でなければならない |
| **看護小規模多機能型居宅介護** | **看護と介護を一体的に**提供。2012年創設の「複合型サービス」が2015年に改称 | 居宅サービス／長期宿泊／都道府県域 |
| **定期巡回・随時対応型訪問介護看護** | **日中・夜間を通じて**、定期訪問と**随時訪問**。要介護者が対象 | 要支援者も使える／緊急時対応なし／都道府県が指定 |
| **認知症対応型通所介護** | 利用者は**原則その市町村の住民**。グループホームの共用スペースなどを使う**共用型**もある | 65歳以上に限る／家族の送迎が原則 |

- 地域密着型サービスでは、事業所が地域に開かれるよう**運営推進会議**（利用者・家族・市町村職員・地域住民の代表など）を開く。定期巡回・随時対応型は「**介護・医療連携推進会議**」。**夜間対応型訪問介護**だけは、この会議を置く決まりがありません

### 介護予防・日常生活支援総合事業（総合事業）

- 市町村の**地域支援事業**の一つ。**第一号訪問事業（訪問型サービス）**・<strong>第一号通所事業（通所型サービス）</strong>など
- 「日中話し相手がいなくて寂しい」要支援1の一人暮らし → **通所型サービス**（総合事業）
- 要支援者が自宅で安全に移動したい → **介護予防住宅改修**（これは総合事業ではなく**予防給付**）。夜間対応型訪問介護（要介護のみ）・小規模多機能（カラオケ目的）は×

### 訪問介護の「身体介護」と「生活援助」

| 区分 | 中身・例 |
|---|---|
| **身体介護** | 利用者の体に直接触れる介助（入浴・排泄・食事など）、**通院の付き添い**、利用者と**一緒に**家事をする**自立生活支援のための見守り的援助** |
| **生活援助** | 一人暮らしなどで本人が家事をできないときに、本人の代わりに行う**掃除・洗濯・調理・買い物**、**薬の受け取り**（処方された薬を薬局でもらってくる） |
| 生活等に関する相談・助言 | 訪問介護として行える |

### 訪問介護の対象外になるもの

| 対象外の例 | 理由 |
|---|---|
| **庭の草むしり・植木の水やり**・**ペットの世話** | 本人の日常生活に直接必要ではない |
| 家族の部屋の掃除・家族の食事づくり | 利用者本人への援助ではない |
| 外食への同行・趣味の外出 | 日常生活に必要な外出（通院など）ではない |
| 理美容・通帳と印鑑の預かり・クレジットカードでの買物代行 | 専門職の仕事や、金銭トラブルにつながる管理は訪問介護の範囲外 |
| 訪問日以外の安否確認 | サービスは計画で決めた訪問時に行う |
| 利用者が**いないとき**の家事（洗濯物の取り込みなど） | 利用者本人への援助として行うもの |
| **大掃除**・窓ふき・家具の移動・**壁紙の張替え** | ふだんの家事をこえている |
| 来客の接待（お茶出しなど） | 利用者本人の生活に直接必要ではない |

### 事業所に決められていること

- 正当な理由がないのに、サービスの提供を**断ってはいけない**（提供拒否の禁止）
- **通所介護計画**・訪問介護計画などの個別計画をつくることは義務。利用者に説明して**同意**を得る
- 火事や地震などに備えた**非常災害対策**（計画づくりと、定期的な避難訓練）も義務
- 通所介護は、ほかのサービスと組み合わせて使うことを条件にしていない

### 費用を軽くする制度

| 制度 | 中身 |
|---|---|
| **高額介護サービス費** | 1か月の自己負担に上限を設け、超えた分を払い戻す |
| 高額医療・高額介護合算療養費 | 医療と介護の自己負担を1年分合わせて上限を超えた分を払い戻す |
| **特定入所者介護サービス費** | 低所得の人の施設の**食費・居住費**を軽くする（預貯金が一定以上なら対象外） |

- 特定入所者介護サービス費は、試験では「**補足給付**」とも呼ばれます。対象は住民税非課税の世帯や生活保護の人で、預貯金が一定額をこえると対象外です（2015年から）
- **要介護度で変わる**のは、サービスの費用（介護報酬）です。グループホームや施設の介護費は、要介護度ごとに1日の額が決まっています。**保険料**（所得の段階で決まる）・**負担割合**（所得で決まる）・**食費・居住費**（施設との契約）は、要介護度では変わりません

## ② 介護保険施設・ユニットケア・グループホーム

| 施設 | 特徴 |
|---|---|
| **介護老人福祉施設（特養）** | **要介護認定**が必要（第2号被保険者も同じ）。新規入所は**原則要介護3以上**（要介護1・2でも、認知症などでやむを得ない事情があれば**特例入所**できる）。根拠は老人福祉法・介護保険法。1963年の**老人福祉法**で創設 |
| 介護老人保健施設（老健） | **在宅復帰**をめざすリハビリ中心。医師・看護師・リハビリ職など**医療職との連携**が欠かせない |
| **介護医療院** | 長期療養と生活の場。**都道府県知事が許可**。**レクリエーション行事**にも努める |
| 軽費老人ホーム | 低額で入居。**都市型は定員20人以下** |

### ユニットケア

| ○ | × |
|---|---|
| 1ユニットは原則**おおむね10人以下**（15人を超えない） | 20名程度／4人部屋 |
| ユニットの担当職員を**一定期間固定**（なじみの関係） | 日ごとに職員を入れ替える |
| 共同生活室で**入所者同士の関係**を築く | 居室で食事／交流はユニット内に限定 |
| **家族や友人が気軽に宿泊**できる配慮 | 施設が決めた時間内に食べ終える／施設内で生活を完結 |

ユニットケアは、一緒に暮らす人のまとまり（**生活単位**）と、職員がケアを受け持つまとまり（**介護単位**）を同じにするやり方です。

- よい点：個室でプライバシーが守られる、少人数で**なじみの関係**ができる、家族が訪ねやすい
- 課題：個室のぶん**居住費の負担**が大きい。少ない職員で働くので、職員どうしで情報を共有する場を意識してつくる。ほかのユニットとの交流も大切

### グループホーム・施設での関わり

- グループホーム＝**認知症**の人が**5〜9人のユニット**で家庭的に暮らす。教育ではなく、本人の**多様な活動**を大切にする
- **なじみのある人や店との関係を継続**する。同じ日課・過去の状態の把握を優先・車いす移動を勧める、は×
- 入所後すぐ「退所したい」と訴える → **思いを受け止め、発言の背景を確認**

## ③ 介護保険の専門職

| 職種 | 役割 |
|---|---|
| **介護支援専門員（ケアマネジャー）** | <strong>居宅サービス計画（ケアプラン）</strong>を作成、サービス担当者会議を開く。**特養に配置義務**。介護支援専門員証の**有効期間は5年**（更新には研修が必要） |
| **サービス提供責任者** | **訪問介護計画書**を作成 |
| 主任介護支援専門員 | **地域包括支援センター**に配置義務 |
| グループホームの**計画作成担当者**（ケアマネジャーなど） | 入居時に**認知症対応型共同生活介護計画**を作成。本人への説明と同意は省略しない |

- **通所介護計画**・訪問介護計画などの個別計画は、ケアマネの**居宅サービス計画（ケアプラン）に沿って**つくる
- ケアマネになるには：介護福祉士などの資格をもち、**実務5年以上かつ900日以上** → 都道府県の**実務研修受講試験**に合格 → 実務研修 → **都道府県知事の登録** → 介護支援専門員証の交付。主任ケアマネは、ケアマネとして5年以上の経験などのうえで主任研修を受ける
- 2005年改正で、ケアマネの**5年ごとの更新制**・更新研修・**主任ケアマネ**が始まった
- ケアマネや訪問介護員の**守秘義務**は、社会福祉法ではなく、介護保険法や運営の基準で決められている
- ケアマネの5年ごとの更新制は、2026年6月に成立した改正法（**社会福祉法等の一部を改正する法律**）で**廃止が決まった**（施行は公布から1年6か月以内）。第39回の時点では現行の「有効期間5年」で覚える
