**結論を3行で**

1. 喀痰吸引等は**社会福祉士及び介護福祉士法**（2011年改正）で、**医行為のまま**、**医師の指示書**の下で行う。**実地研修**の修了が必要。
2. 介護福祉士が行うのは**栄養剤の注入**や**咽頭の手前までの吸引**。量・速度・種類を**決める**のは医師。
3. SpO2の基準は**95〜100％**。胸骨圧迫は「**呼吸がなければすぐ、胸の真ん中、約5cm、1分間に100〜120回**」。

## ① 喀痰吸引等の制度【医療的ケア】

| ○ | × |
|---|---|
| 根拠法は**社会福祉士及び介護福祉士法**（第29回） | 医師法・介護保険法・社会福祉法 |
| 喀痰吸引・経管栄養は**医行為のまま**、条件付きで実施できる | 医行為から除外された |
| **実地研修**を修了する必要がある（第32回） | 病院で実施できる／基本研修の講師になれる／インスリン注射もできる |
| 指示書は**医師**が作成（第30回）。有効期間は**6か月以内** | 看護師・ケアマネジャーが作成／3年 |
| 経管栄養の**注入量を指示**するのは**医師**（第33回） | 看護師・ケアマネジャー・事業所の管理者 |
| 事業所は登録時に**医療関係者との連携体制を確保**（第36回） | 登録研修機関になる／ケアマネの指示を受ける |

## ② 呼吸のしくみ・バイタルサイン・救急蘇生【医療的ケア】

### 呼吸のしくみ

| ○ | × |
|---|---|
| **気管は空気の通り道**（第36回） | 喉頭は食べ物の通り道／咽頭が左右に分かれる／鼻腔が3つの葉に分かれる（肺の説明） |
| **ガス交換**は**肺胞の空気と血液の間**で行う（第34回） | 換気＝二酸化炭素を取り込む |
| 呼吸運動は主に**横隔膜と肋間筋** | 大胸筋 |
| 1回に吸える量（肺活量）は年齢とともに**減る** | 増加する |
| **ALS**では呼吸筋が弱り**換気**が低下 | ガス交換が低下 |
| 気管の**せん毛運動**で痰を**口腔の方へ運ぶ**（第33回） | 粘りが強い・乾燥しているほど動きがよい |
| 痰は**咳や咳払い**で出す（第37回）。咳中枢は**延髄** | 呼吸器の中は乾燥／分泌物は咽頭で吸収 |

### 呼吸の観察（第35回）

**正常**：胸やお腹が**一定のリズム**で膨らんだり縮んだりする。成人は**1分間に12〜20回**。

**異常**：ゴロゴロ音（痰）、爪や唇が**紫色**（チアノーゼ）、1分間に40回、**下顎を上下させる呼吸**（下顎呼吸＝死が近いサイン）。

### パルスオキシメータ（第30回）

- **動脈血の酸素飽和度（SpO2）**と脈拍がわかる（呼吸数・体温は測れない）
- 健康な人の基準値は**95〜100％**
- **手足が冷たく血流が悪い**と正確に測れない。マニキュアも影響

### バイタルサイン測定の注意（第38回）

| ○ | × |
|---|---|
| **非接触型体温計**は**環境温度**に注意 | — |
| 脈拍は**人差し指・中指・薬指**で橈骨動脈に触れる | 親指で触れる（自分の脈と混ざる） |
| 呼吸は**意識させずに**測る | ゆっくり息をするよう伝える |
| マンシェットは**指が1〜2本入る**程度に巻く | すき間なく巻く |
| 意識は**呼びかけ**から確認 | まず体を揺さぶる |

### 胸骨圧迫（成人）（第37回）

- **呼吸がない（普段どおりでない）なら、すぐに**始める
- 位置：**胸の真ん中（胸骨の下半分）**
- **両手を重ね、手のひらの付け根**で押す（指先は×）
- 深さ**約5cm**（6cmを超えない）、**1分間に100〜120回**

パルスオキシメータでの測定に関する記述として、適切なものはどれ？

1. 呼吸回数を測定できる
2. 体温を測定できる
3. 静脈血の酸素飽和度を反映している

## ③ 消化器のしくみと症状【医療的ケア】

| ○ | × |
|---|---|
| 胃は**噴門**（入口）から始まり**幽門**（出口）で終わる | 幽門から始まる |
| 左上の**胃底部**に食べ物を一時的にためる（第38回） | 左下の縁は小弯（実際は**大弯**） |
| 胃に続くのは**十二指腸** | 空腸／胃に3つの狭窄部（食道の説明） |
| **腹部膨満感**＝お腹が張る感覚（第37回） | — |
| しゃっくり＝**横隔膜**のけいれん | 胸膜の刺激 |
| 胸やけ＝胃酸の逆流による焼けるような感じ | 食道の熱傷 |
| げっぷ＝**胃**にたまった空気が出る | 咽頭の空気 |
| **嘔気**＝吐き気、**嘔吐**＝実際に吐く | 嘔気＝吐き出すこと |
