**この記事のポイント**

1. 喀痰吸引等は**社会福祉士及び介護福祉士法**（2011年改正）で、**医行為のまま**、**医師の指示書**の下で行う。介護福祉士は**実地研修**を修了し、**登録**した事業所で行う。
2. 介護福祉士が行うのは、**咽頭の手前までの口腔・鼻腔の吸引**、**気管カニューレ内部の吸引**、**栄養剤の注入**など5つの行為。量・速度・種類を**決める**のは医師。
3. SpO2の基準は**95〜100％**。胸骨圧迫は「**呼吸がなければすぐ、胸の真ん中、約5cm、1分間に100〜120回**」。

## ① 喀痰吸引等の制度

**医行為**＝医師や看護師など医療職でなければ行ってはいけない行為。喀痰吸引と経管栄養は本来これに当たりますが、法律の条件（研修・登録・医師の指示）を満たせば、介護福祉士なども行えます。医行為で**なくなった**わけではないので、範囲を自己判断で広げてはいけません。

### 実施できる行為（5つ）と範囲

| 行為 | 範囲 |
|---|---|
| 口腔内の喀痰吸引 | **咽頭の手前まで** |
| 鼻腔内の喀痰吸引 | **咽頭の手前まで** |
| **気管カニューレ内部**の喀痰吸引 | **カニューレの内部まで**（先端を越えない） |
| <strong>胃ろう・腸ろう</strong>による経管栄養 | 胃ろう・腸ろうの状態の確認は看護職 |
| **経鼻**経管栄養 | チューブが胃に入っているかの確認は看護職 |

浣腸（滋養浣腸）などは、この5つに含まれません。

### 介護福祉士と、それ以外の介護職員

| | 介護福祉士 | 介護福祉士以外の介護職員 |
|---|---|---|
| 研修 | 養成課程などで基本研修 → **実地研修**を修了 | 登録研修機関で基本研修・実地研修を修了 |
| 資格の手続き | 介護福祉士の**登録証**に、実施できる行為を書き加える（登録） | 都道府県知事から<strong>認定証</strong>を受ける（**認定特定行為業務従事者**） |
| 区分 | なし | **第1号**＝不特定多数の人に5つ全部、**第2号**＝不特定多数の人に一部、**第3号**＝<strong>特定の人（重度障害児者など）</strong>にその人に必要な行為 |

- 働く**事業所**も、都道府県に**登録**が必要（**登録喀痰吸引等事業者**）。登録の条件は**医療関係者との連携体制の確保**など。
- **登録研修機関**＝研修を行う機関のこと。事業所の登録とは別物。
- **病院・診療所**は、看護職がいるのでこのしくみの対象外（介護職員が病院で吸引する、は×）。

### 指示から報告までの流れ

**医師の指示書**（有効期間**6か月以内**）→ **喀痰吸引等計画書**（事業所が作成）→ 実施 → **実施状況報告書**（事業所が医師に提出）

### よく出る○×

| ○ | × |
|---|---|
| 根拠法は**社会福祉士及び介護福祉士法** | 医師法・介護保険法・社会福祉法 |
| 喀痰吸引・経管栄養は**医行為のまま**、条件付きで実施できる | 医行為から除外された |
| 介護福祉士は**実地研修**を修了する必要がある | 実地研修なしで行える |
| 実施できるのは**登録した事業所**（病院・診療所は対象外） | 介護職員が病院で実施できる |
| 実施できるのは**5つの行為**だけ | インスリン注射もできる／基本研修の講師になれる |
| 指示書は**医師**が作成。有効期間は**6か月以内** | 看護師・ケアマネジャーが作成／3年 |
| 経管栄養の**注入量を指示**するのは**医師** | 看護師・ケアマネジャー・事業所の管理者 |
| 事業所は登録時に**医療関係者との連携体制を確保** | 登録研修機関になる／ケアマネの指示を受ける |

### 介護福祉士ができること・できないこと（経管栄養）

| ○ できる | × できない（医療職） |
|---|---|
| **栄養剤の注入** | 栄養剤の**種類の変更** |
| 注入中の観察 | **注入速度の決定** |
| 指示どおりの量・速さで注入する | 経鼻チューブを**胃に入れる**、胃ろうカテーテルの**交換** |

### ヒヤリ・ハットの報告

実害がなくてもヒヤリ・ハット報告書を書きます。医療では影響の大きさで分類し、**レベル0〜3a**（3a＝簡単な処置ですんだ）が**インシデント（ヒヤリ・ハット）**、**3b以上**（3b＝濃厚な処置や治療が必要になった）が**アクシデント**です。

## ② 呼吸のしくみ・バイタルサイン・救急蘇生

### 呼吸のしくみ

空気の通り道：鼻腔・口腔 → **咽頭**（のど。食べ物と空気の共通の通り道）→ **喉頭**（声帯がある。空気だけが通る）→ **気管** → 気管支 → 肺（**胸腔**の中）。

| ○ | × |
|---|---|
| **気管は空気の通り道** | 喉頭は食べ物の通り道 |
| 左右に分かれるのは**気管**（気管支へ） | 咽頭が左右に分かれる |
| 肺は**右3葉（上葉・中葉・下葉）・左2葉** | 鼻腔が上葉・中葉・下葉に分かれる |
| **ガス交換**は**肺胞の空気と血液の間**で行う | 換気＝二酸化炭素を取り込む |
| **換気**＝空気を肺に出し入れすること | 換気＝血液との酸素の交換 |
| 呼吸運動は主に**横隔膜と肋間筋** | 大胸筋 |
| **肺活量**（思いきり吸ってから吐き出せる量）は年齢とともに**減る** | 増加する |
| **ALS**では呼吸筋が弱り**換気**が低下 | ガス交換が低下 |
| 気管の<strong>線毛（せんもう）運動</strong>で痰を**口腔の方へ運ぶ** | 粘りが強い・乾燥しているほど動きがよい |
| 気道の中は粘液で**湿っている** | 呼吸器の中は乾燥している |
| 痰は**咳や咳払い**で出す。咳中枢は**延髄** | 分泌物は咽頭で吸収される／咳中枢は下垂体 |

- 気管の表面にあるのは**線毛**（細かい毛）。**絨毛**は小腸の内側のひだのことで、別物です（選択肢の「絨毛」はひっかけ）。
- **右の気管支は左より太く短く、垂直に近い**ので、誤嚥した物は右の肺に入りやすい。
- 呼吸中枢は**延髄**にあり自動で調節されるが、**意識的に止めたり深くしたりもできる**。
- **痰がたまると**：気道がふさがる・酸素が足りなくなる・息苦しさが**強くなる**・感染しやすい・眠れない。

### 呼吸の観察

**正常**：胸やお腹が**一定のリズム**で膨らんだり縮んだりする。成人は**1分間に12〜20回**。

**異常**：ゴロゴロ音（痰）、爪や唇が**紫色**（チアノーゼ）、1分間に40回、**下顎を上下させる呼吸**（下顎呼吸＝死が近いサイン）。

### パルスオキシメータ

- <strong>動脈血の酸素飽和度（SpO2）</strong>と脈拍がわかる（呼吸数・体温は測れない）
- 健康な人の基準値は**95〜100％**
- **手足が冷たく血流が悪い**と正確に測れない。マニキュアも影響

### バイタルサイン

**バイタルサイン**＝体温・脈拍・呼吸・血圧（意識を含めることもある）。成人の目安は、脈拍**60〜100回/分**、呼吸**12〜20回/分**、高血圧は**140/90mmHg以上**。

| ○ | × |
|---|---|
| **非接触型体温計**は**環境温度**（外気温・風）に注意 | 周りの温度の影響は受けない |
| わきの下の体温は、汗を拭き、体温計の先を**わきの中央のくぼみに下から斜め上へ**当てて測る。片麻痺の人は**健側**で | 汗を拭かずに測る／麻痺側で測る |
| 食事・運動・入浴の**直後は避けて**測る | 入浴直後に測る |
| 脈拍は**人差し指・中指・薬指**で橈骨動脈に触れる | 親指で触れる（自分の脈と混ざる） |
| 呼吸は**意識させずに**測る | ゆっくり息をするよう伝える |
| マンシェットは**指が1〜2本入る**程度に巻く | すき間なく巻く |
| 意識は**呼びかけ**から確認 | まず体を揺さぶる |

- 体温は1日のうちで**朝が低く、夕方（午後）が高め**（日内変動）。測る場所では**直腸＞耳＞口＞わきの下**の順に高い。
- 悪寒戦慄（ふるえるような寒気）があれば、感染を疑い保温し、医療職に報告する。

### 一次救命処置（成人）

1. **周りの安全**を確認する（安全でなければ近づかない）
2. 肩をたたき、**呼びかけて反応**を確認する
3. 反応がなければ、大声で人を呼び、**119番とAED**を頼む
4. **呼吸**を見る（10秒以内）。普段どおりの呼吸がない・わからない、しゃくりあげるような**死戦期呼吸**も「呼吸なし」
5. ただちに**胸骨圧迫**。人工呼吸ができれば**30：2**（圧迫30回・人工呼吸2回）
6. AEDが届いたら電源を入れ、音声に従う。救急隊に引き継ぐまで続ける

呼吸があれば、**回復体位**（横向きにし、上側の膝を曲げる）で様子を見ます。

**胸骨圧迫のしかた**
- **呼吸がない（普段どおりでない）なら、すぐに**始める
- 位置：**胸の真ん中（胸骨の下半分）**
- **両手を重ね、手のひらの付け根**で押す（指先は×）
- 深さ**約5cm**（6cmを超えない）、**1分間に100〜120回**

**関連して押さえること**
- **救命の連鎖**＝心停止の予防→早い通報→一次救命処置→二次救命処置（医療機関での処置）。救急車を呼ぶか迷ったら<strong>#7119（救急安心センター）</strong>。
- **カーラーの救命曲線**：死亡率50％の目安は**心停止3分・呼吸停止10分・大量出血30分**。早い対応が命を救う。
- **AEDの点検**：**毎日**インジケーターを確認。電極パッドとバッテリーの**使用期限**も確認・交換。

**正解：2**　入口が**噴門**、出口が**幽門**。上にあるのに「底」という**胃底部**に注意。左下の大きなカーブは**大弯**、胃の次は**十二指腸**、3つの狭窄部は**食道**です。
</details>

消化器症状の説明として、正しいものはどれ？

## ひっかけパターン集（制度・基礎で「ほぼ×」）

| 選択肢の表現 | なぜ× |
|---|---|
| 喀痰吸引は医行為から外された | 医行為のまま条件付きで実施 |

| 介護職員が病院で吸引を行える | 病院・診療所はこのしくみの対象外 |
| 指示書はケアマネ・看護師が作る | 医師 |
| 介護福祉士が注入速度・量を決める | 医師の指示どおりに |
| 浣腸も介護福祉士ができる医療的ケア | 5つの行為に含まれない |
| SpO2は静脈血の値 | 動脈血 |
| 胸骨圧迫は指先で・10cm・60回 | 手のひらの付け根・5cm・100〜120回 |
| どんな状況でも、すぐに処置を始める | まず周りの安全を確認 |
| 痰の粘りが強いほど線毛がよく動く | 粘りが強い・乾燥では動きにくい |
| 気管の表面には絨毛がある | 気管は線毛。絨毛は小腸 |
