**この記事のポイント**

1. 喀痰吸引等は**社会福祉士及び介護福祉士法**（2011年改正）で、**医行為のまま**、**医師の指示書**の下で行う。**実地研修**の修了が必要。
2. 介護福祉士が行うのは**栄養剤の注入**や**咽頭の手前までの吸引**。量・速度・種類を**決める**のは医師。
3. SpO2の基準は**95〜100％**。胸骨圧迫は「**呼吸がなければすぐ、胸の真ん中、約5cm、1分間に100〜120回**」。

## ① 喀痰吸引等の制度【医療的ケア】

| ○ | × |
|---|---|
| 根拠法は**社会福祉士及び介護福祉士法** | 医師法・介護保険法・社会福祉法 |
| 喀痰吸引・経管栄養は**医行為のまま**、条件付きで実施できる | 医行為から除外された |
| **実地研修**を修了する必要がある | 病院で実施できる／基本研修の講師になれる／インスリン注射もできる |
| 指示書は**医師**が作成。有効期間は**6か月以内** | 看護師・ケアマネジャーが作成／3年 |
| 経管栄養の**注入量を指示**するのは**医師** | 看護師・ケアマネジャー・事業所の管理者 |
| 事業所は登録時に**医療関係者との連携体制を確保** | 登録研修機関になる／ケアマネの指示を受ける |

| ○ できる | × できない（医療職） |

| **栄養剤の注入** | 栄養剤の**種類の変更** |

| — | 経鼻チューブを**胃に入れる**、胃ろうカテーテルの**交換** |

口腔内の喀痰吸引・鼻腔内の喀痰吸引・**気管カニューレ内部**の喀痰吸引・**胃ろう（腸ろう）**による経管栄養・**経鼻**経管栄養

## ② 呼吸のしくみ・バイタルサイン・救急蘇生【医療的ケア】

### 呼吸のしくみ

| ○ | × |
|---|---|
| **気管は空気の通り道** | 喉頭は食べ物の通り道／咽頭が左右に分かれる／鼻腔が3つの葉に分かれる（肺の説明） |
| **ガス交換**は**肺胞の空気と血液の間**で行う | 換気＝二酸化炭素を取り込む |
| 呼吸運動は主に**横隔膜と肋間筋** | 大胸筋 |
| 1回に吸える量（肺活量）は年齢とともに**減る** | 増加する |
| **ALS**では呼吸筋が弱り**換気**が低下 | ガス交換が低下 |
| 気管の**せん毛運動**で痰を**口腔の方へ運ぶ** | 粘りが強い・乾燥しているほど動きがよい |
| 痰は**咳や咳払い**で出す。咳中枢は**延髄** | 呼吸器の中は乾燥／分泌物は咽頭で吸収 |

### 呼吸の観察

**正常**：胸やお腹が**一定のリズム**で膨らんだり縮んだりする。成人は**1分間に12〜20回**。

**異常**：ゴロゴロ音（痰）、爪や唇が**紫色**（チアノーゼ）、1分間に40回、**下顎を上下させる呼吸**（下顎呼吸＝死が近いサイン）。

### パルスオキシメータ

- **動脈血の酸素飽和度（SpO2）**と脈拍がわかる（呼吸数・体温は測れない）
- 健康な人の基準値は**95〜100％**
- **手足が冷たく血流が悪い**と正確に測れない。マニキュアも影響

### バイタルサイン測定の注意

| ○ | × |
|---|---|
| **非接触型体温計**は**環境温度**に注意 | — |
| 脈拍は**人差し指・中指・薬指**で橈骨動脈に触れる | 親指で触れる（自分の脈と混ざる） |
| 呼吸は**意識させずに**測る | ゆっくり息をするよう伝える |
| マンシェットは**指が1〜2本入る**程度に巻く | すき間なく巻く |
| 意識は**呼びかけ**から確認 | まず体を揺さぶる |

### 胸骨圧迫（成人）

- **呼吸がない（普段どおりでない）なら、すぐに**始める
- 位置：**胸の真ん中（胸骨の下半分）**
- **両手を重ね、手のひらの付け根**で押す（指先は×）
- 深さ**約5cm**（6cmを超えない）、**1分間に100〜120回**

## ③ 消化器のしくみと症状【医療的ケア】

| ○ | × |
|---|---|
| 胃は**噴門**（入口）から始まり**幽門**（出口）で終わる | 幽門から始まる |
| 左上の**胃底部**に食べ物を一時的にためる | 左下の縁は小弯（実際は**大弯**） |
| 胃に続くのは**十二指腸** | 空腸／胃に3つの狭窄部（食道の説明） |
| **腹部膨満感**＝お腹が張る感覚 | — |

| げっぷ＝**胃**にたまった空気が出る | 咽頭の空気 |
| **嘔気**＝吐き気、**嘔吐**＝実際に吐く | 嘔気＝吐き出すこと |

## ＋α もう一歩：実務者研修レベルで覚えたいこと

過去問にはまだ出ていないけれど、実務者研修の確認テストでよく問われる、関連して覚えておきたい知識です。

- **医行為**は医師などが行う行為だが、喀痰吸引・経管栄養は**法律で定められた研修を修了し、登録した事業所**で、**医師の指示のもと**なら介護福祉士等も行える。範囲を自己判断で広げない。
- 介護福祉士等ができる医療的ケアは**5つ**：口腔内・鼻腔内・気管カニューレ内部の**喀痰吸引**、**胃ろう・腸ろう・経鼻経管栄養**。**浣腸（滋養浣腸）は含まれない**。
- 範囲の決まり：口腔・鼻腔の吸引は**咽頭の手前まで**／気管カニューレは**カニューレ内部まで**／胃ろう・腸ろうの状態、経鼻チューブが胃に入っているかの確認は**医師・看護職**が行う。
- **バイタルサイン**＝体温・脈拍・呼吸・血圧。体温には**日内変動**（朝低く夕方高い）がある。成人の脈拍は**60〜100回/分**。高血圧の目安は**140/90mmHg以上**。
- **わきの下の体温測定**：汗を拭き、体温計の先を**わきの中央のくぼみに下から斜め上へ**当てて腕を閉じる。片麻痺の人は**健側**で。食事・運動・入浴の直後は避ける。
- **呼吸**：呼吸中枢は延髄にあり自動で調節されるが、**意識的に止めたり深くしたりもできる**。肺は**右3葉・左2葉**。**右の気管支は左より太く短く、垂直に近い**ので、誤嚥した物は右に入りやすい。
- **痰がたまると**：気道がふさがる・酸素が足りなくなる・息苦しい・感染・眠れない。息切れは**強く**なる。
- **救急蘇生**：まず**周りの安全**を確認（どんな状況でもすぐ処置、ではない）→反応を確認→119番とAED→普段どおりの呼吸がなければ胸骨圧迫（**100〜120回/分**、深さ約5cm）。人工呼吸ができれば**30：2**。
- **カーラーの救命曲線**（フランスの医師カーラー）：死亡率50％の目安は**心停止3分・呼吸停止10分・大量出血30分**。早い対応が命を救う。
- **AEDの点検**：**毎日**インジケーターを確認。電極パッドとバッテリーの**使用期限**も確認・交換。
