**この記事のポイント**

1. 介護福祉士は「**心身の状況に応じた介護**」と「**介護者への介護の指導**」を行う**名称独占**の資格。更新制はない。
2. 義務は「**誠実義務・信用失墜行為の禁止・秘密保持義務・連携・資質向上の責務**」の5つ（＋名称の使用制限）。
3. **秘密保持は辞めた後も続く**。罰則があるのは秘密保持義務違反（**1年以下の懲役または30万円以下の罰金**）。

## ① 介護福祉士の定義と資格【介護の基本】

### 定義（法第2条）

介護福祉士とは、登録を受け、介護福祉士の名称を用いて、専門的知識・技術をもって、**身体上又は精神上の障害**があることにより日常生活を営むのに支障がある者に、**心身の状況に応じた介護**（喀痰吸引等を含む）を行い、**その者及びその介護者に対して介護に関する指導**を行うことを業とする者。

| ○ | × |
|---|---|
| 対象は**身体上又は精神上の障害**で日常生活に支障がある人 | 環境上の理由で支障がある人 |
| 2007年改正で「入浴、排せつ、食事その他の介護」→「**心身の状況に応じた介護**」へ | 逆向きの改正 |
| **介護者への介護の指導**も業務 | 指導は行わない |
| 療養上の世話・診療の補助は**看護師**の業務 | 介護福祉士の業務 |

### 資格のしくみ

| ○ | × |
|---|---|
| **名称独占**（資格がないと名乗れない） | 業務独占 |
| 試験合格後、**厚生労働大臣の登録**を受けて初めて名乗れる | 都道府県知事に申請／合格した日から名乗れる |
| **更新制はない** | 5年ごとの更新研修 |
| 社会福祉士の業務を介護福祉士が行っても**違法ではない** | 禁止されている |
| 刑罰を受けても**一定期間が過ぎれば**登録できる | どんな場合もなれない |
| 喀痰吸引等は**登録喀痰吸引等事業者（都道府県知事に登録）**で行う | 市町村の窓口に申請 |

### 制度ができた背景

1987年制定。**日本学術会議が介護職員の専門性と資格制度について意見**を出したことなどが背景（介護保険法・ゴールドプランより前）。

## ② 介護福祉士の義務と罰則【介護の基本／人間の尊厳と自立】

| 義務 | 中身 | 罰則 |
|---|---|---|
| **誠実義務** | **常に担当する利用者の立場に立って**、誠実に業務を行う。2007年改正で追加 | なし |
| **信用失墜行為の禁止** | 介護福祉士の**信用を傷つける行為をしてはならない** | なし（登録取消しはありうる） |
| **秘密保持義務** | 業務で知った秘密を漏らさない。**介護福祉士でなくなった後も同じ** | **1年以下の懲役または30万円以下の罰金** |
| **連携** | **福祉サービス関係者等**（医療関係者を含む）**と連携** | なし |
| **資質向上の責務** | **知識・技能の向上に努める**。研修受講は義務として定められていない | なし |
| 名称の使用制限 | 資格のない人・使用停止中の人は名乗れない | 30万円以下の罰金 |

> 誠実義務を定めた法律は「**社会福祉士及び介護福祉士法**」。介護保険法は「**国民の共同連帯の理念**」で介護保険制度を設けている。

<summary>✏️ 過去問を解いてみよう（第37回・介護の基本）</summary>

介護福祉に関わる法律について、適切なものはどれ？

1. 高齢者虐待防止法は福祉六法の1つである
2. 障害者総合支援法は障害者基本計画の策定を義務づけている
3. 社会福祉法に社会福祉士の定義がある
4. 介護保険法は国民の共同連帯の理念に基づいている
5. 医師法で介護福祉の業務として医行為が認められている

<details class="answer">
<summary>正解を見る</summary>

**正解：4**　介護保険法1条に**国民の共同連帯の理念**。障害者基本計画は**障害者基本法**、資格の定義は**社会福祉士及び介護福祉士法**です。
</details>
</details>

<summary>✏️ 過去問を解いてみよう（第37回・介護の基本）</summary>

社会福祉士及び介護福祉士法について、適切なものはどれ？

1. 5年に1回、更新研修を受けなければならない
2. 社会福祉士の業務を介護福祉士が行うことは禁止されている
3. 介護福祉士の信用を傷つける行為をしてはならない
4. 仕事を辞めたあとは秘密保持義務がなくなる

<summary>✏️ 過去問を解いてみよう（第35回・介護の基本）</summary>

社会福祉士及び介護福祉士法に定められた介護福祉士の責務として、最も適切なものはどれ？

1. 地域生活支援事業などを総合的に行う
2. 介護等の知識と技能の向上に努める
3. 肢体不自由の人に必要な訓練を行う
