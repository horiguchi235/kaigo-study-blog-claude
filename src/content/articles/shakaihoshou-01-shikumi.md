## この記事で対策できる科目

| 社会の理解 | 22問 | ①社会保障の体系・財源 ②医療保険・年金 ③保健医療 |

**結論を3行で**

1. 社会保険は**医療・年金・雇用・労災・介護の5つ**。**強制加入**で、**保険料＋公費**で運営。
2. 社会保障給付費で一番大きいのは**年金（約4割超）**。財源で一番大きいのは**社会保険料**。
3. 「どの保険？」は**年齢と原因**で決まる：**75歳以上＝後期高齢者医療**、**仕事中のけが＝労災**、**それ以外＝医療保険**。

## ① 社会保障の体系・財源・給付費【社会の理解】

### 社会保障の4本柱（1950年 社会保障制度審議会の勧告）（第35回）

**社会保険・国家扶助（公的扶助）・公衆衛生及び医療・社会福祉**

### 社会保険

| ○ | × |
|---|---|
| **医療・年金・雇用・労災・介護の5つ**（第29回） | — |
| **労働保険＝雇用保険＋労災保険**（第24回） | — |
| **強制加入** | 個人が選択できる・任意 |
| **保険料を払った人に受給権**を保障（第26回） | — |
| 保険料＋**公費**で運営 | 公費負担はない |
| 現金給付と**現物給付**（医療など） | 現金給付に限る |
| 保険料は**所得**に応じる | 個人のリスクに見合った額 |

### 社会保障の役割

- **所得の再分配**、**生活の安定**、**介護や子育てなど家庭機能の支援**（第25回）
- 生活保護制度・福祉サービスも**社会保障に含まれる**
- 社会手当は**現金**給付、生活保護は**現物給付（医療扶助・介護扶助）もある**

### 給付費と財源

| ○ | × |
|---|---|
| 部門別で最大は**年金**（全体の**4割超**）（第33回） | 医療が最大 |
| 2000年度以降、**介護対策の割合は増加**（第29回） | 介護が全体の30%超 |
| 財源で最大は**社会保険料** | 税が最大 |
| 国の一般会計の**3割超**が社会保障関係費（第32回） | — |
| 社会保障給付費は国の一般会計予算より**大きい** | 一般会計が上回る |

## ② 医療保険と年金【社会の理解】

### どの制度を使う？

| 事例 | ○ 使う制度 |
|---|---|
| 64歳・定年退職して無職、庭でけが（第30回） | **国民健康保険** |
| 77歳・元公務員、ゴルフでけが（第36回） | **後期高齢者医療制度**（75歳以上） |
| 60歳・休日に家庭菜園中に脳出血（第37回） | **医療保険制度**（仕事中ではないので労災ではない） |
| 介護施設の常勤職員が産休中の所得の補填（第29回） | **出産手当金**（医療保険）。出産育児一時金は出産費用 |

### 国民健康保険（第28回）

- 住所のある人が加入（日本国籍でも住所がなければ×）
- **生活保護の受給者は対象外**（医療は医療扶助）
- 会社の健康保険をやめた人も加入する

### 国民年金（第25回）

| ○ | × |
|---|---|
| **20歳以上60歳未満** | 65歳未満 |
| **国籍を問わない** | — |
| **学生も被保険者**（納付猶予の特例あり） | 学生は被保険者になれない |
| 厚生年金の加入者も**国民年金の第2号被保険者** | 厚生年金加入者はなれない |
| 会社員に扶養されている配偶者は**第3号被保険者** | 被保険者になれない |

## ③ 保健所・保健センター・医療法・健康施策【社会の理解】

### 医療法の医療提供施設（第24・28回）

| 施設 | ポイント |
|---|---|
| **病院** | **20床以上** |
| 診療所 | **19床以下**（無床もある） |
| 薬局 | 調剤を行う薬局も**医療提供施設** |
| 療養病床 | 長期療養のための病床（年齢制限はない） |
| 特定機能病院 | 高度な医療を提供する病院 |

### 保健所と市町村保健センター

| | **保健所** | **市町村保健センター** |
|---|---|---|
| 根拠法 | **地域保健法** | 地域保健法 |
| 設置 | 都道府県・政令市・中核市・特別区など（全市町村ではない） | 市町村（**任意**） |
| 業務 | **感染症の予防**（**結核の医療費公費負担の申請**・家庭訪問指導）（第34・36回）、**精神保健**（第37回）、食品衛生 | 住民への**健康相談・保健指導・健康診査**（第27回） |
| 所長 | 原則医師 | — |

> 児童の一時保護・判定は**児童相談所**、知的障害者の判定は**知的障害者更生相談所**です。

### 健康施策

- **特定健康診査**：**40〜74歳**、**生活習慣病（メタボ）**の検査、腹囲測定。結果に応じて特定保健指導（第30回）
- 健康寿命を延ばすために**ロコモティブシンドローム（運動器症候群）**の対策が重要（第29回）
- WHOの健康の定義：身体的・精神的・**社会的**に良好な状態（病気がないだけではない）

<details>
<summary>✏️ 解いてみよう（第37回・事例）</summary>

60歳の男性が、休日に自宅で家庭菜園の作業中に脳出血を起こして救急搬送された。現在は高次脳機能障害の治療とリハビリに専念している。医療費を支払うときに利用する制度として、最も適切なものはどれ？

1. 介護保険制度
2. 労働者災害補償保険制度
3. 雇用保険制度
4. 医療保険制度
5. 年金制度

<details class="answer">
<summary>正解を見る</summary>

**正解：4**　仕事とは関係のない病気なので労災ではなく、医療費は医療保険で支払います。介護保険は介護サービスの費用に使う制度です。
</details>
</details>
