**この記事のポイント**

1. 社会保険は**医療・年金・雇用・労災・介護の5つ**。**強制加入**で、**保険料＋公費**で運営。
2. 社会保障給付費で一番大きいのは**年金（約4割超）**。財源で一番大きいのは**社会保険料**。
3. 「どの保険？」は**年齢と原因**で決まる：**75歳以上＝後期高齢者医療**、**仕事中のけが＝労災**、**それ以外＝医療保険**。

## ① 社会保障の体系・財源・給付費【社会の理解】

### 社会保障の4本柱（1950年 社会保障制度審議会の勧告）

**社会保険・国家扶助（公的扶助）・公衆衛生及び医療・社会福祉**

### 社会保険

| ○ | × |
|---|---|
| **医療・年金・雇用・労災・介護の5つ** | — |
| **労働保険＝雇用保険＋労災保険** | — |
| **強制加入** | 個人が選択できる・任意 |
| **保険料を払った人に受給権**を保障 | — |
| 保険料＋**公費**で運営 | 公費負担はない |
| 現金給付と**現物給付**（医療など） | 現金給付に限る |
| 保険料は**所得**に応じる | 個人のリスクに見合った額 |

### 社会保障の役割

- **所得の再分配**、**生活の安定**、**介護や子育てなど家庭機能の支援**
- 生活保護制度・福祉サービスも**社会保障に含まれる**
- 社会手当は**現金**給付、生活保護は**現物給付（医療扶助・介護扶助）もある**

### 給付費と財源

| ○ | × |
|---|---|
| 部門別で最大は**年金**（全体の**4割超**） | 医療が最大 |
| 2000年度以降、**介護対策の割合は増加** | 介護が全体の30%超 |
| 財源で最大は**社会保険料** | 税が最大 |
| 国の一般会計の**3割超**が社会保障関係費 | — |
| 社会保障給付費は国の一般会計予算より**大きい** | 一般会計が上回る |

## ② 医療保険と年金【社会の理解】

### どの制度を使う？

| 事例 | ○ 使う制度 |
|---|---|
| 64歳・定年退職して無職、庭でけが | **国民健康保険** |
| 77歳・元公務員、ゴルフでけが | **後期高齢者医療制度**（75歳以上） |
| 60歳・休日に家庭菜園中に脳出血 | **医療保険制度**（仕事中ではないので労災ではない） |
| 介護施設の常勤職員が産休中の所得の補填 | **出産手当金**（医療保険）。出産育児一時金は出産費用 |

### 国民健康保険

- 住所のある人が加入（日本国籍でも住所がなければ×）
- **生活保護の受給者は対象外**（医療は医療扶助）
- 会社の健康保険をやめた人も加入する

### 国民年金

| ○ | × |
|---|---|
| **20歳以上60歳未満** | 65歳未満 |
| **国籍を問わない** | — |
| **学生も被保険者**（納付猶予の特例あり） | 学生は被保険者になれない |
| 厚生年金の加入者も**国民年金の第2号被保険者** | 厚生年金加入者はなれない |
| 会社員に扶養されている配偶者は**第3号被保険者** | 被保険者になれない |

## ③ 保健所・保健センター・医療法・健康施策【社会の理解】

### 医療法の医療提供施設

| 施設 | ポイント |
|---|---|
| **病院** | **20床以上** |
| 診療所 | **19床以下**（無床もある） |
| 薬局 | 調剤を行う薬局も**医療提供施設** |
| 療養病床 | 長期療養のための病床（年齢制限はない） |
| 特定機能病院 | 高度な医療を提供する病院 |

### 保健所と市町村保健センター

| | **保健所** | **市町村保健センター** |
|---|---|---|
| 根拠法 | **地域保健法** | 地域保健法 |
| 設置 | 都道府県・政令市・中核市・特別区など（全市町村ではない） | 市町村（**任意**） |
| 業務 | **感染症の予防**（**結核の医療費公費負担の申請**・家庭訪問指導）、**精神保健**、食品衛生 | 住民への**健康相談・保健指導・健康診査** |
| 所長 | 原則医師 | — |

> 児童の一時保護・判定は**児童相談所**、知的障害者の判定は**知的障害者更生相談所**です。

### 健康施策

- **特定健康診査**：**40〜74歳**、**生活習慣病（メタボ）**の検査、腹囲測定。結果に応じて特定保健指導
- 健康寿命を延ばすために**ロコモティブシンドローム（運動器症候群）**の対策が重要
- WHOの健康の定義：身体的・精神的・**社会的**に良好な状態（病気がないだけではない）

## ＋α もう一歩：実務者研修レベルで覚えたいこと

過去問にはまだ出ていないけれど、実務者研修の確認テストでよく問われる、関連して覚えておきたい知識です。

- **社会保険の分類**：**地域保険**＝住所が基準（**国民健康保険・介護保険**）／**職域保険**＝勤め先が基準（**健康保険・厚生年金**）。**医療保険は業務外の病気・けが**、仕事中・通勤中は**労災保険**（労災も社会保障の一つ）。被用者の医療保険の保険者＝協会けんぽ・健康保険組合・**共済組合**。
- **医療法の施設**：**病院＝20床以上**／**診療所＝19床以下（無床も）**／助産所＝入所9人まで。**特定機能病院**＝高度医療を行い**厚生労働大臣が承認**（開設者は業務報告書を大臣に提出）、**地域医療支援病院**＝都道府県知事が承認。
- **生活保護と介護**：65歳以上の生活保護受給者も**介護保険の第1号被保険者**（利用者負担分は介護扶助）。40〜64歳で医療保険に入っていない人は介護保険の対象外で、**介護扶助**で介護サービスを受ける。生活保護受給者も**特養に入所できる**（施設での生活費は生活扶助）。

<fig name="nenkin">

- **国民年金の被保険者**：第1号＝20〜59歳の自営業・学生など、第2号＝会社員・公務員（厚生年金加入者）、第3号＝第2号に扶養される20〜59歳の配偶者。日本に住む**外国人も対象**。
- **老齢基礎年金**＝受給資格期間**10年以上**、原則**65歳**から。60〜64歳に**繰上げ**（減額）、66〜**75歳**に**繰下げ**（増額）できる。
- **医療保険の自己負担**：小学校入学前2割／小学生〜69歳3割／70〜74歳2割（現役並み所得3割）／75歳以上1割（一定以上所得2割・現役並み3割）。
- **後期高齢者医療制度**＝75歳以上（65〜74歳で一定の障害がある人も）。運営は**後期高齢者医療広域連合**。財源はおおむね**公費5割・現役世代の支援金4割・高齢者の保険料1割**。
- **労災保険**の保険料は**事業主だけ**が負担。**雇用保険**は事業主と労働者で負担し、**介護休業給付**（休業前賃金の67％）もここから出る。
- **社会保障給付費**は「年金＞医療＞福祉その他」の順。財源は**保険料が約6割、公費が約4割**。
- 社会保障の歴史の年号：1961年 国民皆保険・皆年金／1973年 老人医療費無料化（福祉元年）／1982年 老人保健法で有料化／1985年 基礎年金導入／2008年 後期高齢者医療制度。
