**この記事のポイント**

1. 社会保険は**医療・年金・雇用・労災・介護の5つ**。**強制加入**で、**保険料＋公費**で運営。
2. 社会保障給付費で一番大きいのは**年金（4割強）**。財源で一番大きいのは**社会保険料**、次が**公費**。
3. 「どの保険？」は2段階で考える：**仕事中・通勤中のけが＝労災保険**／それ以外＝**医療保険**（**75歳以上＝後期高齢者医療**、75歳未満＝国民健康保険か職場の健康保険）。

**社会保障とは**：病気・けが・老い・障害・失業・出産・死亡など、**だれにでも起こる生活の困りごと**に、国や自治体が**保険や税**で備えるしくみです。

| 用語 | 意味 |
|---|---|
| 保険者 | 保険を**運営する側**（市町村・健康保険組合など） |
| 被保険者 | 保険に**入っている人** |
| 被扶養者 | 自分では保険料を払わず、**家族の保険に入れてもらう人** |
| 一般会計 | 国の基本の予算（税などで動く国の財布） |

## ① 社会保障の体系・財源・給付費

### 社会保障の4本柱（1950年 社会保障制度審議会の勧告）

**社会保険・国家扶助（公的扶助）・公衆衛生及び医療・社会福祉**

- 国家扶助（公的扶助）＝税で最低限度の生活を保障するしくみ。代表が**生活保護**
- 社会手当＝保険料を払っていなくても、条件に当てはまれば税からお金が出る（児童手当など）

**言葉の地図**：社会保障は、保険料が財源の「**社会保険**」と、税が財源の「**社会扶助**」に大きく分かれます。

| 大きな分け方 | 中身 | 例 |
|---|---|---|
| **社会保険**（保険料・強制加入） | 医療・年金・雇用・労災・介護 | 健康保険・国民年金・介護保険 |
| 社会扶助：**公的扶助** | 生活に困った人・所得の低い人への支援 | 生活保護、生活福祉資金の貸付、公営住宅 |
| 社会扶助：**社会手当** | 条件を満たせば現金が出る | 児童手当・児童扶養手当 |
| 社会扶助：**社会サービス** | 福祉のサービス | 保育所・障害者施設・老人福祉施設 |

民間の保険は任意で入るもので、社会保障には入りません。

### 社会保険

| ○ | × |
|---|---|
| **医療・年金・雇用・労災・介護の5つ** | — |
| **労働保険＝雇用保険＋労災保険** | — |
| **強制加入** | 個人が選択できる・任意 |
| **保険料を払った人に受給権**を保障 | — |
| 保険料＋**公費**で運営 | 公費負担はない |
| 現金給付と**現物給付**（お金ではなく医療やサービスそのものを受け取る） | 現金給付に限る |
| 保険料は多くが**所得**に応じる（国民年金の第1号は定額） | 個人のリスクに見合った額 |

### 社会保障の役割

- **所得の再分配**、**生活の安定**、**介護や子育てなど家庭機能の支援**

| 社会保障の5つの機能 | 中身 |
|---|---|
| **セーフティネット** | 生活の安全網。最後のよりどころは生活保護 |
| **所得の再分配** | 所得の多い人から少ない人へお金を回し、差を小さくする |
| **リスクの分散** | みんなで保険料を出し合い、病気・失業などが起きた人に給付する |
| **家族機能の支援** | 育児・介護・扶養を支える |
| **社会と経済の安定・成長への貢献** | 社会保障は経済を損なうのではなく、**支える**（「経済の成長をさまたげる」は×） |

給付の中身では、**所得保障**（年金・雇用保険・生活保護）・**医療保障**（医療保険など）・**社会福祉**（保育所・障害者福祉・高齢者福祉）の3つに分けることもあります。

- 生活保護制度・福祉サービスも**社会保障に含まれる**
- 社会手当は**現金**給付、生活保護は**現物給付（医療扶助・介護扶助）もある**

### 給付費と財源

| ○ | × |
|---|---|
| 部門別で最大は**年金**で、**4割強（全体の40％を超える）**。「年金（約42％）＞医療（約32％）＞福祉その他（約26％）」の順（2024年度 社会保障費用統計） | 医療が最大 |
| 給付費は長い目で見ると**増える傾向**（2022・2023年度はコロナ対策の費用が減って一時的に減少。部門ごとの増減は年度で違う） | — |
| 2000年度以降、**介護対策の割合は増加** | 介護が全体の30%超 |
| 年金・高齢者医療・老人福祉サービスなど**高齢者関係の給付費は全体の約6割** | — |
| 財源で最大は**社会保険料**、次が**公費（税）**（厚生労働省の予算ベースの資料では、保険料が約6割・公費が約4割） | 税が最大 |
| 国の一般会計の**3割超**が社会保障関係費 | — |
| 社会保障給付費は国の一般会計予算より**大きい** | 一般会計が上回る |

## ② 医療保険と年金・労働保険

### どの制度を使う？

| 事例 | ○ 使う制度 |
|---|---|
| 64歳・定年退職して無職、庭でけが | **国民健康保険** |
| 77歳・元公務員、ゴルフでけが | **後期高齢者医療制度**（75歳以上） |
| 60歳・休日に家庭菜園中に脳出血 | **医療保険制度**（仕事中ではないので労災ではない） |
| 介護施設の常勤職員が産休中の所得の補填 | **出産手当金**（医療保険）。出産育児一時金は出産費用 |

### 医療保険の種類

| 種類 | 対象・ポイント |
|---|---|
| **国民健康保険**（地域保険＝住所が基準） | 住所のある人が加入（日本国籍でも住所がなければ×）。会社の健康保険をやめた人も加入。**生活保護の受給者は対象外**（医療は医療扶助） |
| **健康保険・共済組合**（職域保険＝勤め先が基準） | 会社員は協会けんぽ・健康保険組合、公務員は**共済組合** |
| **後期高齢者医療制度** | **75歳以上**（65〜74歳で一定の障害がある人も）。運営は**後期高齢者医療広域連合**（都道府県ごとにすべての市町村が入る運営団体）。財源はおおむね**公費5割・現役世代の支援金4割・高齢者の保険料1割** |

- **保険者**：国民健康保険は**都道府県と市町村**（ほかに業種ごとの国保組合）、協会けんぽは**全国健康保険協会**、健康保険組合は大きな会社ごと、公務員は**共済組合**、船員は船員保険
- 会社を退職して、家族の被扶養者にもならない75歳未満の人は**国民健康保険**に入る
- 2024年12月から、今までの健康保険証の新しい発行が止まり、**マイナンバーカードの保険証利用（マイナ保険証）**が基本になった（カードがない人には資格確認書）
- 2026年4月から、少子化対策の財源として**子ども・子育て支援金**が医療保険料と一緒に集められている

### 医療保険の自己負担

| 年齢 | 自己負担 |
|---|---|
| 小学校入学前 | 2割 |
| 小学生〜69歳 | **3割** |
| 70〜74歳 | 2割（現役並み所得は3割） |
| **75歳以上** | **1割**（一定以上所得は2割、現役並み所得は3割） |

### 国民年金

<fig name="nenkin">

公的年金は**2階建て**です。**1階＝国民年金（基礎年金）**は20〜59歳の全員が入り、**2階＝厚生年金**には会社員・公務員（第2号）が入ります。自営業など（第1号）には2階の厚生年金がなく、代わりに**国民年金基金**などがあります。その上に、任意の3階部分（企業年金・iDeCoなど）があります。

| ○ | × |
|---|---|
| **20歳以上60歳未満** | 65歳未満 |
| **国籍を問わない**（日本に住む外国人も対象） | — |
| **学生も被保険者**（在学中は保険料を後払いにできる**学生納付特例**） | 学生は被保険者になれない |
| 第1号＝自営業・学生など。保険料は**定額** | — |
| 厚生年金の加入者（会社員・公務員）も**国民年金の第2号被保険者** | 厚生年金加入者はなれない |
| 第2号に扶養されている20〜59歳の配偶者は**第3号被保険者** | 被保険者になれない |
| 老齢基礎年金は受給資格期間**10年以上**、原則**65歳**から（60〜64歳に繰上げ＝減額、66〜75歳に繰下げ＝増額） | 受給資格期間25年 |

### 年金の種類

年金は**老齢・障害・遺族**の3種類です。国民年金からは**老齢基礎年金・障害基礎年金・遺族基礎年金**、厚生年金からはその上乗せ（老齢厚生年金など）が出ます。

- **20歳前**（保険料を払う前）の病気やけがで障害が残った人も、**20歳になったら障害基礎年金を受け取れる**（等級や所得制限は [障害者の実態](../jinkou-02-jittai/) で扱います）
- 会社で働いたことがない人には、障害厚生年金は出ない
- 仕事中・通勤中のけがで障害が残ったときは、**労災保険の傷病（補償）年金**などが別に出る（通学中は労災ではない）
- 昔、国民年金に任意加入だった時期に入っていなかったため障害基礎年金を受けられない人（当時の学生など）には、**特別障害給付金**という別のしくみがある

### 労働保険

- **労災保険**：仕事中・通勤中のけがや病気。保険料は**事業主だけ**が負担。1973年から**通勤中のけが**も対象。公務員は別の制度
- **雇用保険**：保険料は事業主と労働者で負担。失業給付のほか、**介護休業給付**（休業前賃金の67％）もここから出る

### どの保険から何が出る？

| 保険 | 給付 | どんなとき |
|---|---|---|
| 医療保険 | **出産育児一時金** | 出産の費用 |
| 医療保険 | **出産手当金** | 産休中の給料の代わり（会社員など） |
| 医療保険 | **傷病手当金** | **仕事以外**の病気・けがで休んだときの給料の代わり |
| 医療保険 | **高額療養費** | 1か月の自己負担が上限を超えた分が戻る |
| 労災保険 | **休業補償給付**・傷病補償年金など | **仕事中・通勤中**のけがで休んだとき |
| 雇用保険 | 失業したときの給付・**育児休業給付**・**介護休業給付** | 失業・育児休業・介護休業 |
| 雇用保険 | **高年齢雇用継続給付** | 60〜64歳で、賃金が60歳のときの75％未満に下がったとき |

## ③ 保健所・保健センター・医療法・健康施策

### 医療法の医療提供施設

| 施設 | ポイント |
|---|---|
| **病院** | **20床以上** |
| 診療所 | **19床以下**（無床もある） |
| 助産所 | 入所は9人まで |
| 薬局 | 調剤を行う薬局も**医療提供施設** |
| 療養病床 | 長期療養のための病床（年齢制限はない） |
| 特定機能病院 | 高度な医療と研修を行う病院（大学病院など）。**400床以上**。**厚生労働大臣**が承認 |
| 地域医療支援病院 | かかりつけ医を支援し、救急医療も行う病院。原則**200床以上**。**都道府県知事**が承認 |

### 保健所と市町村保健センター

| | **保健所** | **市町村保健センター** |
|---|---|---|
| 根拠法 | **地域保健法** | 地域保健法 |
| 設置 | 都道府県・政令市・中核市・特別区など（全市町村ではない） | 市町村（**任意**） |
| 業務 | **感染症の予防**（**結核の医療費公費負担の申請**・家庭訪問指導）、**精神保健**、食品衛生 | 住民への**健康相談・保健指導・健康診査** |
| 所長 | 原則医師 | — |

> 児童の一時保護・判定は**児童相談所**、知的障害者の判定は**知的障害者更生相談所**です。

### 健康施策

- **特定健康診査**：**40〜74歳**、<strong>生活習慣病（メタボ）</strong>の検査、腹囲測定。結果に応じて特定保健指導
- 健康寿命を延ばすために<strong>ロコモティブシンドローム（運動器症候群）</strong>の対策が重要
- WHOの健康の定義：身体的・精神的・**社会的**に良好な状態（病気がないだけではない）
- **健康日本21（第三次）**：2024年度から12年間の国民の健康づくり運動（根拠は**健康増進法**）。大きな目標は**健康寿命の延伸**と**健康格差の縮小**。健康寿命＝健康上の問題で日常生活が制限されずに暮らせる期間
