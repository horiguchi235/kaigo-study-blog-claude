**この記事のポイント**

1. 片麻痺の介助は「**健側を使ってもらい、介護者は患側に立って守る**」。車いすは**健側**に置く。
2. 杖は**健側**に持つ。平地は「**杖 → 患側 → 健側**」、階段は「**上りは健側から、下りは患側から**」。
3. 杖の握りの高さは**大転子**。握力が弱い人は**ロフストランドクラッチ**、手首が痛い人は**プラットホームクラッチ**。

## ① 起き上がり・立ち上がり・移乗【生活支援技術】

**まず最初に**：移乗の**目的を説明して同意を得る**。方法の説明や車いすの準備はその後。

### 起き上がり（側臥位 → 端座位）

- **健側を下**にした側臥位から、**健側の肘を支点**に上体を起こしてもらう
- 患側を下にして起き上がる・介護者が頸部を支えて起こす、は×

### 立ち上がり

| ○ | × |
|---|---|
| ベッドに**浅く**座り直す | 深く腰掛ける |
| 足を引き、**前かがみ（前傾）**になってから立つ | 背すじを伸ばして真上に立つ／真上に持ち上げる |
| 介護者は**患側**に立つ | 健側に立つ |
| **患側の膝**に手を当てて**膝折れを防ぐ** | 健側の膝を支える／患側に荷重がかかるように支える |
| 立ったら**膝の裏が伸びている**（しっかり立てている）か確認 | — |

### 車いすへの移乗

- 車いすは**健側**に、ベッドに対して斜め（20〜30度）に置く
- **フットサポートは上げて**おく、ブレーキをかける
- 移るときは**前傾姿勢**をとってもらい、健側の足を軸に回る

### スライディングボード

<photo name="idou-02__sliding-board" caption="スライディングボード：ベッドと車いすの座面に板を渡し、座ったまま滑って移る。ベッドを車いすより**少し高く**し、車いすの**アームサポートを外して**使います。">

| ○ | × |
|---|---|
| 立位はとれないが**座位が保て、上肢が使える**人 | — |
| ベッドを車いすの座面より**少し高く**する（高い方から低い方へ滑る） | ベッドと車いすの間を大きくあける |
| **アームサポートが外せる**車いすを使う | アームサポートが固定された車いす |
| **ゆっくり**移動する。抜くときは**体を少し傾けて**抜く | 臀部を素早く移動／傾けずに抜く |

### そのほかの場面

| 場面 | ○ 正解 |
|---|---|
| 夜間のポータブルトイレ（右片麻痺・膝関節症） | ベッドに**スイングアーム介助バー**を設置。トイレは**健側**に、**ベッドと同じ高さ** |
| 左片麻痺の人が浴槽から立つ | **右手（健側）で手すり**をつかみ、**前傾**して臀部を浮かす |
| 臥床で前開きの上着を交換（左片麻痺） | 脱ぐ前に**患側（左）の肩口を広げて**おく。**脱健着患** |
| 端座位でズボンをはく（左片麻痺） | **患側の足を健側の大腿にのせて**ズボンを通す |

## ② 杖歩行・階段昇降【生活支援技術】

| 場面 | 順番・位置 |
|---|---|
| 杖を持つ手 | **健側** |
| **3動作歩行** | **杖 → 患側 → 健側**（右片麻痺なら「杖、右足、左足」） |
| 2動作歩行 | **杖と患側を同時** → 健側 |
| **階段を上る** | **杖 → 健側 → 患側**。介護者は**患側の後方** |
| **階段を下りる** | **杖 → 患側 → 健側**。介護者は**患側の前方** |
| 手すりで階段 | 手すりは**健側**でつかむ |
| 溝をまたぐ | 杖は溝の**向こう側**に突く。またいだら**両足をそろえて**から次へ |

<fig name="step-tsue">

<fig name="kaidan">

> 覚え方：「**上りは良い足（健側）から天国へ、下りは悪い足（患側）から地獄へ**」。

### 歩行の助言・意欲

- 安定した歩行：**後ろ足のつま先で地面を蹴って**踏み出す。歩幅は広く、腕を振り、前を見て、**かかとから**着地
- 歩行が不安定で意欲が落ちた人：**達成できる目標距離**を設定し、成功体験を積む。福祉用具を避ける・移動範囲を狭める・本人の希望なしに毎日歩かせる、は×

## ③ 杖・歩行器の種類と選び方【生活支援技術】

<photo name="idou-02__hokouki" caption="左から**固定型歩行器**（持ち上げて前に出す）、**前輪付き歩行器**、**シルバーカー**（自分で歩ける人の買物などに。体重をあずける道具ではない）。">

<photo name="idou-02__tsue" caption="左から**T字杖**、**多点杖**（脚が4本で安定。歩行が不安定な人に）、**ロフストランドクラッチ**（前腕を支えるカフ付き。握力が弱い人に）、**松葉杖**。">

| 用具 | 合う人・使い方 |
|---|---|
| 杖の高さ | 握りを**大転子**の高さに。肘が少し曲がる（約30度） |
| T字杖 | 歩行が比較的安定している人 |
| **多点杖** | T字杖より**安定**。片麻痺の人 |
| **ロフストランドクラッチ**（前腕固定型） | **握力が弱い**人 |
| **プラットホームクラッチ**（前腕支持型） | **手首に負担をかけられない**人＝**関節リウマチ** |
| 歩行器 | 杖より**安定性が高い** |
| **固定式歩行器** | 両手で**持ち上げて**前に置いて進む。**握力があり、数秒立っていられる**人 |
| 交互型歩行器 | 左右のフレームを交互に出す |
| 歩行器型杖（ウォーカーケイン） | 片麻痺で杖歩行が**不安定**な人 |
| シルバーカー | **自立歩行できる**人の買い物・休憩用 |

## ＋α もう一歩：実務者研修レベルで覚えたいこと

過去問にはまだ出ていないけれど、実務者研修の確認テストでよく問われる、関連して覚えておきたい知識です。

- **T字杖の長さ**は、立った姿勢で**床から大転子（太もものつけ根の骨の出っぱり）まで**が目安（肘が軽く曲がる高さ）。
- **2動作歩行**＝**杖と麻痺側の足を同時に**出す→健側の足／**3動作歩行**＝杖→麻痺側→健側。
- **階段**：**上りは健側から**、**下りは杖→麻痺側から**（「のぼりは良い足から、くだりは悪い足から」）。
- **病気と福祉用具の組み合わせ**：関節リウマチ＝**補高便座**（立ち座りの負担を軽く）／難聴＝光や振動で知らせる機器／片麻痺の移乗＝スライディングボード。パーキンソン病は手の震えがあるので筆談器は合わない。用具は**病名ではなく実際の機能と希望**で選ぶ。
