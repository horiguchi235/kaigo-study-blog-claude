**結論を3行で**

1. 片麻痺の介助は「**健側を使ってもらい、介護者は患側に立って守る**」。車いすは**健側**に置く。
2. 杖は**健側**に持つ。平地は「**杖 → 患側 → 健側**」、階段は「**上りは健側から、下りは患側から**」。
3. 杖の握りの高さは**大転子**。握力が弱い人は**ロフストランドクラッチ**、手首が痛い人は**プラットホームクラッチ**。

## ① 起き上がり・立ち上がり・移乗【生活支援技術】

**まず最初に**：移乗の**目的を説明して同意を得る**（第32回）。方法の説明や車いすの準備はその後。

### 起き上がり（側臥位 → 端座位）

- **健側を下**にした側臥位から、**健側の肘を支点**に上体を起こしてもらう（第37回）
- 患側を下にして起き上がる・介護者が頸部を支えて起こす、は×

### 立ち上がり

| ○ | × |
|---|---|
| ベッドに**浅く**座り直す | 深く腰掛ける（第27・30・36回で×） |
| 足を引き、**前かがみ（前傾）**になってから立つ | 背すじを伸ばして真上に立つ／真上に持ち上げる |
| 介護者は**患側**に立つ | 健側に立つ |
| **患側の膝**に手を当てて**膝折れを防ぐ**（第27・36回） | 健側の膝を支える／患側に荷重がかかるように支える |
| 立ったら**膝の裏が伸びている**（しっかり立てている）か確認（第30回） | — |

### 車いすへの移乗（第38回）

- 車いすは**健側**に、ベッドに対して斜め（20〜30度）に置く
- **フットサポートは上げて**おく、ブレーキをかける
- 移るときは**前傾姿勢**をとってもらい、健側の足を軸に回る

### スライディングボード（第29・34回）

| ○ | × |
|---|---|
| 立位はとれないが**座位が保て、上肢が使える**人 | — |
| ベッドを車いすの座面より**少し高く**する（高い方から低い方へ滑る） | ベッドと車いすの間を大きくあける |
| **アームサポートが外せる**車いすを使う | アームサポートが固定された車いす |
| **ゆっくり**移動する。抜くときは**体を少し傾けて**抜く | 臀部を素早く移動／傾けずに抜く |

### そのほかの場面

| 場面 | ○ 正解 |
|---|---|
| 夜間のポータブルトイレ（右片麻痺・膝関節症）（第26回） | ベッドに**スイングアーム介助バー**を設置。トイレは**健側**に、**ベッドと同じ高さ** |
| 左片麻痺の人が浴槽から立つ（第34回） | **右手（健側）で手すり**をつかみ、**前傾**して臀部を浮かす |
| 臥床で前開きの上着を交換（左片麻痺）（第35回） | 脱ぐ前に**患側（左）の肩口を広げて**おく。**脱健着患** |
| 端座位でズボンをはく（左片麻痺）（第36回） | **患側の足を健側の大腿にのせて**ズボンを通す |

<summary>✏️ 解いてみよう（第36回）</summary>

回復期にある左片麻痺の利用者が、ベッドで端座位から立位になるときの基本的な介護として、最も適切なものはどれ？

1. 利用者の右側に立つ
2. ベッドに深く座るように促す
3. 背すじを伸ばして真上に立ち上がるように促す
4. 利用者の左側に荷重がかかるように支える
5. 利用者の左の膝頭に手を当てて保持し、膝折れを防ぐ

<details class="answer">
<summary>正解を見る</summary>

**正解：5**　介護者は患側（左）に立ち、力の入りにくい患側の膝が折れないよう支えます。浅く座って前かがみになるのが立ち上がりの基本です。
</details>

## ② 杖歩行・階段昇降【生活支援技術】

| 場面 | 順番・位置 |
|---|---|
| 杖を持つ手 | **健側** |
| **3動作歩行** | **杖 → 患側 → 健側**（第37回：右片麻痺なら「杖、右足、左足」） |
| 2動作歩行 | **杖と患側を同時** → 健側 |
| **階段を上る** | **杖 → 健側 → 患側**（第24回）。介護者は**患側の後方**（第29回） |
| **階段を下りる** | **杖 → 患側 → 健側**。介護者は**患側の前方**（第32回） |
| 手すりで階段 | 手すりは**健側**でつかむ |
| 溝をまたぐ（第35回） | 杖は溝の**向こう側**に突く。またいだら**両足をそろえて**から次へ |

<fig name="step-tsue">

<fig name="kaidan">

> 覚え方：「**上りは良い足（健側）から天国へ、下りは悪い足（患側）から地獄へ**」。

### 歩行の助言・意欲

- 安定した歩行：**後ろ足のつま先で地面を蹴って**踏み出す（第35回）。歩幅は広く、腕を振り、前を見て、**かかとから**着地
- 歩行が不安定で意欲が落ちた人：**達成できる目標距離**を設定し、成功体験を積む（第38回）。福祉用具を避ける・移動範囲を狭める・本人の希望なしに毎日歩かせる、は×

<details>
<summary>✏️ 解いてみよう（第37回）</summary>

右片麻痺の利用者が多点杖を使って3動作歩行を始めるときの説明として、適切なものはどれ？

1. 「杖、右足、左足の順で歩きましょう」
2. 「杖、左足、右足の順で歩きましょう」
3. 「右足、左足、杖の順で歩きましょう」
4. 「左足、杖、右足の順で歩きましょう」
5. 「左足、右足、杖の順で歩きましょう」

<details class="answer">
<summary>正解を見る</summary>

**正解：1**　3動作は「杖 → 患側 → 健側」。右片麻痺なので患側は右足です。杖は健側の左手で持ちます。

## ③ 杖・歩行器の種類と選び方【生活支援技術】

| 用具 | 合う人・使い方 |
|---|---|
| 杖の高さ | 握りを**大転子**の高さに（第29回）。肘が少し曲がる（約30度） |
| T字杖 | 歩行が比較的安定している人 |
| **多点杖** | T字杖より**安定**。片麻痺の人 |
| **ロフストランドクラッチ**（前腕固定型） | **握力が弱い**人（第25・36回） |
| **プラットホームクラッチ**（前腕支持型） | **手首に負担をかけられない**人＝**関節リウマチ**（第31回） |
| 歩行器 | 杖より**安定性が高い**（第26回） |
| **固定式歩行器** | 両手で**持ち上げて**前に置いて進む。**握力があり、数秒立っていられる**人（第38回） |
| 交互型歩行器 | 左右のフレームを交互に出す |
| 歩行器型杖（ウォーカーケイン） | 片麻痺で杖歩行が**不安定**な人 |
| シルバーカー | **自立歩行できる**人の買い物・休憩用 |

<details>
<summary>✏️ 解いてみよう（第31回）</summary>

手首に変形や痛みがある関節リウマチの利用者が、歩行時に使う杖として最も適切なものはどれ？

1. 前腕固定型杖（ロフストランドクラッチ）
2. 前腕支持型杖（プラットホームクラッチ）
3. 松葉杖
4. 多点杖
5. 歩行器型杖

<details class="answer">
<summary>正解を見る</summary>

**正解：2**　前腕全体を台にのせて体重を支えるので、手首や手指に負担がかかりません。1・3・4・5はいずれもグリップを握って手首で支えます。
</details>
</details>
