**この記事のポイント**

1. ICFは「**健康状態**」「**心身機能・身体構造／活動／参加**」「**環境因子／個人因子**」が**相互に影響し合う**モデル。
2. **トイレに行けない＝活動制限**、**社会の場に出る・役割を果たす＝参加**、**人・物・段差・制度＝環境因子**、**経歴・趣味・性格＝個人因子**。
3. 社会モデル＝**障害は環境との相互作用で生じる**。「個人の問題」「治療で解決」は医学モデル。

## ① ICFの構成要素と見分け方【介護の基本／障害の理解】

### ICFの全体像

<fig name="icf">

- **生活機能は、健康状態と背景因子との相互作用**
- **背景因子＝環境因子＋個人因子**
- 3つのレベル：心身機能（生物）・活動（個人・生活）・**参加（社会・人生）**
- マイナス面だけでなく**プラス面（できること）にも着目**

### 見分け方の早見表

| 構成要素 | 中身 | 過去問の例 |
|---|---|---|
| 健康状態 | 病気・けが・妊娠・加齢 | **アルツハイマー型認知症・パーキンソン病・糖尿病**（これは心身機能ではない） |
| 心身機能・身体構造 | 体や心の働き・体の部分 | 手足が動かない（機能障害）、**上肢が自由に動く**、排尿コントロールが困難、トイレの場所がわからない |
| **活動** | **生活の行為**をやり遂げる | **毎日の日課をやり遂げる**、**車いすで移動できる**、**トイレに行けない（活動制限）** |
| **参加** | 社会や家庭での**役割・関わり** | **レクで歌の伴奏をする**、**認知症カフェに通う**、復職できない・旅行に行けない（参加制約） |
| **環境因子** | 人・物・建物・制度・態度 | **仲の良い友人**、**娘が毎日訪問**、**自宅周辺の坂道や段差**、**床面が柔らかい**、車いす、近所の人・民生委員 |
| 個人因子 | 年齢・性別・経歴・性格・趣味 | **元教員**、医者嫌い、町内会長をしていた、映画鑑賞が趣味 |

### 「関係」を問う問題

| 問われ方 | ○ 正解 |
|---|---|
| 心身機能と活動の関係 | **上肢が自由に動く → 車いすで移動できる** |
| 環境因子と心身機能の関係 | **床が柔らかい → バランスを崩す** |
| 参加と活動の両方 | **認知症カフェに通い（参加）、体操をしている（活動）** |
| 参加制約の原因の環境因子 | **自宅周辺の坂道や段差** |

## ② ICIDHからICFへ・医学モデルと社会モデル【障害の理解】

### ICIDH（国際障害分類、1980年）

**機能・形態障害 → 能力障害 → 社会的不利** の一方向

| ICIDH | 例 | ICFでは |
|---|---|---|
| 機能・形態障害 | 運動麻痺・失語 | 機能障害 |
| **能力障害** | **ADLの障害** | 活動制限 |
| 社会的不利 | 職場復帰困難・経済的不利益 | 参加制約 |

- ICF（2001年）は**環境および環境と個人の相互作用を重視**したモデル。マイナス面中心から**中立的な用語**へ

### 医学モデルと社会モデル

| 医学モデル | 社会モデル ○ |
|---|---|
| 障害は**個人の問題** | 障害は**環境によって作り出される**／**環境との相互作用で生じる** |
| 病気・外傷から直接生じる | 社会の側のバリアを取り除く |
| 専門職の治療で解決・回復させる | 環境の改善・社会の変化で解決 |

> ICFは医学モデルと社会モデルを**統合**した「生物・心理・社会モデル」です。「医学モデルから社会モデルへの転換」は×。

## ③ ICIDHとICFのちがい

- **ICIDH（国際障害分類、1980年）**：病気→**機能・形態障害→能力障害→社会的不利**の一方向。目的には**障害への理解と啓発**も含まれていた。
- **ICF（2001年）**の例で整理：**健康状態**＝脳梗塞／**心身機能・身体構造（機能障害）**＝手足が動かない／**活動（制限）**＝移乗・調理ができない／**参加（制約）**＝**復職できない**・地域の集まりに出られない／**環境因子**＝**住まい**・福祉用具・家族・制度／**個人因子**＝年齢・性格・生活歴。
- ICFの前身は1980年の**ICIDH（国際障害分類）**。ICIDHは「機能障害→能力障害→社会的不利」と**マイナス面だけ**を一方向でとらえたが、ICF（2001年）は「心身機能・身体構造／活動／参加」と**背景因子（環境因子・個人因子）**が**相互に影響し合う**ととらえる。
- ICIDHとICFの対応：機能障害→**心身機能・身体構造**、能力障害→**活動**、社会的不利→**参加**。
- 介護過程ではICFの視点で、できないことだけでなく**できること・環境を変えれば広がること**を探す。

## ひっかけパターン集（ICFで「ほぼ×」）

| 選択肢の表現 | なぜ× |
|---|---|
| 認知症・パーキンソン病は心身機能 | 健康状態 |
| 元教員・趣味は環境因子 | 個人因子 |
| 近所の人・民生委員は個人因子 | 環境因子 |
| 背景因子に環境因子は含まれない | 環境因子＋個人因子 |
| ICFはマイナス部分へのアプローチ | プラス面にも着目 |
| 社会モデル＝障害は個人の問題 | 環境との相互作用 |
