**この記事のポイント**

1. 家族は**一緒に利用者を支えるパートナー**。まず**これまでの頑張りをねぎらい、体験を共感的に聴く**。
2. 利用者と家族の意向が違うときは、**それぞれの意見を聞き**、家族とは**別に話す機会**も設ける。どちらかを説得するのは×。
3. 自己覚知＝**自分の感情の動きとその背景に気づく**こと。

---

## ① 家族との関係づくり

| ○ 正解 | × よく出る不正解 |
|---|---|
| **協働するパートナー**として接する | 介護は全面的に任せてもらう |
| 介護の体験を**共感的に聴く** | 介護技術を教える／（関係づくりの最初の段階で）当事者の会・家族会を勧める |
| 夫の**頑張りを認めながら**、状況を聴く | おむつ交換の方法を指導する／限界を自覚させる |
| 話し合いの機会を**丁寧にもつ** | 家族の希望を優先する／一度できた関係は続くと考える |
| **相手のペースに合わせ、表情を確認**しながら話す | 友人口調・密着・スキンシップ・途切れないよう話し続ける |
| 家族の**これまでの対応や思いを聴く**（家族なりの介護の工夫は否定・訂正せず、まず尊重してねぎらう） | 叱った家族を支持する／否定する／黙認する |
| 家族のようすだけで家族を理解したと思わない | 家族と利用者の希望は同じと考える |

### 家族の言葉への応答

| 回 | 家族の言葉 | ○ 正解 |
|---|---|---|
| 第33回 | 入所の日、娘が「これから離れて暮らすんですね」 | 「**お母さんと離れて暮らすと寂しくなりますね**」 |
| 第31回 | 「母が『学校で教えている』と言ったとき、どうしたら」 | 「**お母さんの教員としての誇りを大切にしてあげてください**」 |
| 第26回 | 「皆さんも私の大変さをわかってくれない」 | **介護の大変さからくる感情に共感し、それを伝える** |
| 第34回 | 疲れているが「母を自宅で看取りたい」と強く希望する長男 | **これまでの介護をねぎらい、希望する理由を尋ねる** |

> 家族会・当事者の会は、家族支援として役に立つ場です。×になるのは「信頼関係をつくる最初の対応」として問われたとき。まず家族の体験を聴き、関係ができてから紹介します。
>
> 第31回の正解は、共感の言葉というより、**認知症の母の言動の意味を家族に伝える**応答です。「学校で教えている」は、教員だった母が誇りをもっていた時代の言葉。否定せず、その誇りを大切にする関わり方を家族と共有します。

## ② 利用者と家族の意向を調整する

| ○ | × |
|---|---|
| 利用者と家族の**それぞれの意見を聞く** | 利用者に従うよう家族を説得する |
| 両者が**それぞれの思いを語り合う場**をつくる | どちらが正しいか専門職として判断を伝える |
| 家族と**話す機会を別に設ける** | 家族を通して利用者の意向を聴く／家族に方針を決めてもらう |
| 「ご本人が何に関心があるのか、**気持ちを聞いてみませんか**」 | 「ご家族の価値観で判断してはいけません」 |
| 本人が自分の気持ちを家族に話せるよう**場面を設定**する。必要なら**代弁**する | どちらか一方の意見に合わせる |
| 必要に応じて**他職種と相談**する | 一人で解決する |

## ③ 自己覚知と対人関係の心理

「自己〇〇」は名前が似ているので、セットで区別します（第37回はこの区別を問う問題）。

| 用語 | 意味 |
|---|---|
| **自己覚知** | 自分の**感情の動きとその背景を洞察**する。自分の価値観や癖を知り、利用者への影響をコントロールする |
| **自己開示** | 自分のことを相手に**話す**。目的は**よい関係づくり**。量・深さ・タイミング・相手・状況を考えて行う（自分をよく見せるためではない） |
| **自己同一性**（アイデンティティ） | **自分とは何か**という認識をもつこと |
| 自己決定 | 利用者が自分のことを**自分で決める**こと（バイステックの7原則の1つ） |
| 転移 | **利用者が**、過去の重要な人に向けた感情を援助者に向ける。例：亡き父に向けていた甘えや反発を、担当職員に向ける |
| **逆転移** | **援助者が**、利用者に無意識の感情を向ける。例：亡くなった祖母に似た利用者に、無意識に頻繁に関わる |
| **役割葛藤** | 複数の役割の期待にはさまれて悩む。例：**仕事と介護の両立**に悩む家族介護者 |
| **問題焦点型コーピング** | ストレスの**原因に働きかけて解決**しようとする。気分転換・音楽・考え方を変えるのは情動焦点型 |

**自己覚知の方法**：自分の記録や関わりのふり返り、**スーパービジョン**（上司・先輩からの助言）、同僚からのフィードバック。逆転移のような無意識の感情に気づくためにも、自己覚知が必要です。

**職員自身のストレス**：新人職員が利用者の言葉に傷つき眠れなくなった → まず**上司や同僚に悩みを話して助言を受ける**。

PDCAサイクル（組織の業務改善）は → [ケアマネジメント・多職種連携・人材育成](../team-01-renkei/) の③で扱います。

## ひっかけパターン集（家族・自己覚知で「ほぼ×」）

| 選択肢の表現 | なぜ× |
|---|---|
| 家族に介護方法を指導する（最初の対応で） | まず労い、聴く |
| どちらかの味方をして説得する | それぞれの思いを聞いて調整する |
| 家族を通して利用者の意向を聞く | 本人の意向は本人から |
