**結論を3行で**

1. 家族は**一緒に利用者を支えるパートナー**。まず**これまでの頑張りをねぎらい、体験を共感的に聴く**。
2. 利用者と家族の意向が違うときは、**それぞれの意見を聞き**、家族とは**別に話す機会**も設ける。どちらかを説得するのは×。
3. 自己覚知＝**自分の感情の動きとその背景に気づく**こと。

## ① 家族との関係づくり【コミュニケーション技術】

| ○ 正解 | × よく出る不正解 |
|---|---|
| **協働するパートナー**として接する（第38回） | 介護は全面的に任せてもらう |
| 介護の体験を**共感的に聴く**（第36回） | 介護技術を教える・当事者の会を勧める |
| 夫の**頑張りを認めながら**、状況を聴く（第25回） | おむつ交換の方法を指導する／限界を自覚させる |
| 話し合いの機会を**丁寧にもつ**（第35回） | 家族の希望を優先する／一度できた関係は続くと考える |
| **相手のペースに合わせ、表情を確認**しながら話す（第33回） | 友人口調・密着・スキンシップ・途切れないよう話し続ける |
| 家族の**これまでの対応や思いを聴く**（第32回） | 叱った家族を支持する／否定する／黙認する |
| 家族のようすだけで家族を理解したと思わない（第25回） | 家族と利用者の希望は同じと考える |

利用者の家族との信頼関係の構築を目的としたコミュニケーションとして、最も適切なものはどれ？

1. 家族に介護技術を教える

## ② 利用者と家族の意向を調整する【コミュニケーション技術】

| ○ | × |
|---|---|

| 両者が**それぞれの思いを語り合う場**をつくる（第27回） | どちらが正しいか専門職として判断を伝える |

| 必要に応じて**他職種と相談**する | 一人で解決する |

## ③ 自己覚知と対人関係の心理【人間関係とコミュニケーション】

| 用語 | 意味 |
|---|---|
| **自己覚知** | 自分の**感情の動きとその背景を洞察**する（第26回・第32回）。自分の価値観や癖を知り、利用者への影響をコントロールする |
| **自己同一性**（アイデンティティ） | **自分とは何か**という認識をもつこと（第37回） |
| 転移 | 利用者が、過去の重要な人に向けた感情を援助者に向ける |
| **逆転移** | **援助者が**、利用者に無意識の感情を向ける。例：亡くなった祖母に似た利用者に、無意識に頻繁に関わる（第31回） |
| **役割葛藤** | 複数の役割の期待にはさまれて悩む。例：**仕事と介護の両立**に悩む家族介護者（第33回） |
| **問題焦点型コーピング** | ストレスの**原因に働きかけて解決**しようとする（第35回）。気分転換・音楽・考え方を変えるのは情動焦点型 |

**職員自身のストレス**：新人職員が利用者の言葉に傷つき眠れなくなった → まず**上司や同僚に悩みを話して助言を受ける**（第38回）。

**PDCAサイクル**：Plan（計画）→ Do（実行）→ Check（評価）→ **Act（改善）**。第35回では「来客者用の駐車スペースを確保する」が Act でした。

<details>
<summary>✏️ 解いてみよう（第31回）</summary>

利用者とのコミュニケーションで「逆転移」が起きている例として、最も適切なものはどれ？

1. 自分が利用者を嫌いなのに、利用者が自分を嫌っていると思い込む
2. 亡くなった祖母と似ている利用者に、無意識に頻繁に関わる
3. 利用者への不満をぶつけずに、机を強くたたいて発散する
4. 敬意を抱いている利用者の口癖を、自分もまねる
5. 嫌悪の感情を抑え、過剰に優しく接する

<details class="answer">
<summary>正解を見る</summary>

**正解：2**　援助者が、過去の大切な人への感情を利用者に向けています。1は投影、3は置き換え、4は同一視、5は反動形成という防衛機制です。
</details>
</details>
