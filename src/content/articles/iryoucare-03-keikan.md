**この記事のポイント**

1. 注入は**上半身を30〜45度**起こし、液面は**胃から約50cm上**。**速い・冷たい → 下痢**、**速い・姿勢が低い → 嘔吐**。
2. チューブが抜けていた、嘔吐した → **注入しない（止める）で看護職へ**。嘔吐したら**顔を横に向けて誤嚥を防ぐ**。
3. 口から食べなくても**口腔ケアは必要**。胃ろうでも**入浴・歩行**はできる。

## ① 経管栄養の手順とトラブル【医療的ケア】

### 手順のポイント

<photo name="iryoucare-03__keikan" caption="経管栄養の物品。栄養剤の容器（イルリガートル）、**点滴筒**（滴下を見る）、**クレンメ**（滴下の速さを調節）。容器は**胃より50cm程度高い位置**につるします。">

| 場面 | ○ 正解 | × |
|---|---|---|
| 準備 | **石けんと流水で手洗い** | 消費期限の新しい物から使う（古い物から） |
| 利用者の所へ運んだら最初に | **本人確認** | 体位・物品・指示内容の確認（その後） |
| 姿勢 | **上半身を30〜45度**起こす（**10度では低すぎて嘔吐**） | 仰臥位 |
| 高さ | 栄養剤の液面は**胃から50cm程度上** | — |
| 温度 | **常温〜人肌程度** | 冷蔵庫から出してそのまま（**下痢**の原因） |
| 注入後 | **白湯**を流して**チューブ内の栄養剤を洗い流す** | 消毒・水分補給・胃を温めるため |
| 注入後の姿勢 | しばらく**上半身を起こしたまま**（逆流予防） | すぐに横にする |

### トラブルと原因

| トラブル | 主な原因 |
|---|---|
| **下痢** | **注入速度が速い**、**栄養剤が冷たい**、濃度が濃い、不潔 |
| **嘔吐** | **注入速度が速い**、**姿勢が低い**、量が多い |
| 誤嚥性肺炎 | 逆流・嘔吐、口腔内の細菌（経管栄養でも誤嚥は**起こる**） |
| 呼吸困難 | チューブが**気管に誤って入っている** |

### こんなときどうする

| 場面 | ○ 正解 |
|---|---|
| 経鼻チューブが**10cm抜けていた** | **注入しないで看護職に報告**。元に戻す・抜く・気泡音で確認・そのまま注入は× |
| 注入中に**嘔吐**、苦しそう | 注入を中止して看護職を呼び、**誤嚥を防ぐため顔を横に向ける**（片付け・換気・酸素は後） |
| 「**お腹が張ってきた**」顔色・意識は変わらない | **腹部が圧迫されていないか確認**（衣服・姿勢）。様子を見る・仰臥位・速度を上げるは× |
| 嘔気があるとき | 注入を**止めて**看護職へ（速度を遅くして続けるは×） |

### 半固形栄養剤

- **胃ろう**向き（経鼻は細くて詰まる）
- 液状より**粘りがある** → **食道への逆流を減らす**、**短時間**で注入できる
- 上半身を起こして注入（仰臥位は×）

## ② 経管栄養をしている人の生活支援【医療的ケア】

| ○ | × |
|---|---|
| 口から食べなくても**口腔ケアは必要**。毎日行う | 数日に1回／不要 |
| **入浴できる**。胃ろう部は**湯につけてよい** | 清拭に変更／胃ろう部を湯につけない |
| 注入していないときは**歩行などの運動**を（便秘予防） | 日中もベッド上／排便はベッド上で |
| 便秘は**起こりうる** | 便秘の心配はなくなる |
| ボタン型胃ろうの周りは**石けんとぬるま湯で洗い清潔に** | 軟膏を塗る・消毒する（医療職の判断）／歩行を避ける |
| 「口から食べたい、チューブを抜いて」→ **医師や看護師に思いを伝える** | 手を固定する（身体拘束）／自分で経口摂取や胃ろうを提案 |

> 胃ろうチューブを回転させて癒着を防ぐのは**看護職**などの判断で行います。介護福祉士が自己判断で行うことではありません。

## ひっかけパターン集（経管栄養で「ほぼ×」）

| 選択肢の表現 | なぜ× |

| 注入中は仰臥位・10度 | 30〜45度起こす |
| 冷蔵庫の栄養剤をそのまま | 下痢の原因 |
| 抜けたチューブを押し戻す・気泡音で確認 | 医療職が確認する |
| 嘔気があるので速度を遅くして続ける | 止めて看護職へ |
| 注入後の白湯は消毒のため | チューブ内を洗い流すため |
| 経管栄養なので口腔ケア不要・入浴不可 | どちらも必要・可能 |
