**この記事のポイント**

1. 注入は**上半身を30〜45度**起こし、液面は**胃から約50cm上**。**速い・冷たい・濃い → 下痢**、**速い・姿勢が低い → 嘔吐**。注入後も**30分〜1時間**は上半身を起こしておく。
2. チューブが抜けていた、嘔吐した → **注入しない（止める）で看護職へ**。嘔吐したら**顔を横に向けて誤嚥を防ぐ**。チューブが胃に入っているかの確認は**看護職**。
3. 口から食べなくても**口腔ケアは必要**。胃ろうでも**入浴・歩行**はできる。

## ① 経管栄養の種類と栄養剤

経管栄養＝口から十分に食べられない人に、チューブで胃や腸へ栄養剤を入れる方法です。消化器のしくみ（胃の入口・出口など）は[医療的ケアの制度と呼吸・消化のしくみ](../iryoucare-01-seido/)で扱います。

| 種類 | どこから入れるか | 特徴・注意 |
|---|---|---|
| **経鼻経管栄養** | 鼻からチューブを入れ、胃へ | 入れ替えは簡単だが、違和感が強く**抜けやすい**。チューブが細い |
| **胃ろう** | お腹に開けた穴（ろう孔）から胃へ | **苦痛が比較的少なく**、抜けにくく管理しやすい。胃からの逆流は起こりうる |
| **腸ろう** | お腹に開けた穴から腸へ | 逆流しにくいが、チューブが細く**詰まりやすい**。速く入れると下痢や血糖の急上昇 |

- **ボタン型胃ろう**＝お腹の表面にボタン状の器具だけが出ていて、注入のときだけチューブをつなぐ形。目立たず、自分で抜いてしまうことが少ない。
- 胃ろうの器具の交換は**医師**が行う。目安は、胃の中の部分が風船の**バルーン型**で1〜2か月ごと、かたい**バンパー型**で4〜6か月ごと。
- **間欠的口腔食道経管栄養**（注入のときだけ口から食道へチューブを入れる方法）は、介護福祉士ができる5つの行為に**含まれない**。

### 栄養剤

- **医薬品タイプ**（医師の処方が必要・医療保険）と**食品タイプ**（処方不要・自費）がある。
- **半固形栄養剤**：液状より**粘りがある** → **食道への逆流を減らす**、**短時間**で注入できる。主に**胃ろう**で使う（経鼻はチューブが細くて詰まるので使わない）。注入は上半身を起こして（仰臥位は×）。

## ② 経管栄養の手順

<photo name="iryoucare-03__keikan" caption="経管栄養の物品。栄養剤の容器（イルリガートル）、**点滴筒**（滴下を見る）、**クレンメ**（滴下の速さを調節）。容器は**胃より50cm程度高い位置**につるします。">

イルリガートル＝栄養剤を入れてつるす容器。点滴筒（てんてきとう）＝しずくが落ちるのを見る部分。クレンメ＝チューブをはさんで、滴下の速さを調節する器具です。

### 誰が何を確認する？

| 確認すること | 担当 |
|---|---|
| 指示書の内容（栄養剤の種類・量・時間・速さ） | 介護福祉士 |
| 栄養剤の名前・量・温度・期限 | 介護福祉士 |
| 本人確認、体調（顔色・腹部の張り・吐き気） | 介護福祉士 |
| 経鼻チューブが**胃に入っているか** | **看護職** |
| 胃ろう・腸ろうの**状態**（周りの皮膚・チューブ） | **看護職** |
| 栄養剤の種類・量・速さを**決める・変える** | **医師** |

### 手順の流れ

1. **石けんと流水で手洗い**。栄養剤は**消費期限の古い物から**使う
2. 利用者の所へ運んだら、**最初に本人確認**。説明して同意を得る
3. 姿勢を**上半身30〜45度**に整える
4. 栄養剤の**温度（常温〜人肌）・量**、指示書を確かめる
5. **クレンメを閉めてから**栄養剤を容器に入れ、点滴筒を**3分の1〜2分の1**ほど満たし、チューブの先まで栄養剤を満たして**空気を抜く**
6. 容器を**胃から約50cm上**につるし、チューブをつないで**クレンメで滴下の速さを調整**する
7. 注入中は顔色・表情・腹部の張り・吐き気などを**観察**する
8. 終わったら**白湯**を流して**チューブ内の栄養剤を洗い流す**
9. **30分〜1時間ほど上半身を起こしたまま**にする（逆流予防）。注入直後の口腔ケアは避ける
10. 片付け、**報告・記録**

| 場面 | ○ 正解 | × |
|---|---|---|
| 準備 | **石けんと流水で手洗い**、消費期限の**古い物から**使う | 消費期限の新しい物から使う |
| 利用者の所へ運んだら最初に | **本人確認** | 体位・物品・指示内容の確認（その後） |
| 姿勢 | **上半身を30〜45度**起こす（**10度では低すぎて嘔吐**） | 仰臥位 |
| 高さ | 栄養剤の液面は**胃から50cm程度上** | 胃と同じ高さ |
| 温度 | **常温〜人肌程度** | 冷蔵庫から出してそのまま（**下痢**の原因） |
| 注入後 | **白湯**を流して**チューブ内の栄養剤を洗い流す** | 消毒・水分補給・胃を温めるため |
| 注入後の姿勢 | **30分〜1時間**、**上半身を起こしたまま**（逆流予防） | すぐに横にする |

## ③ トラブルと、こんなときどうする

### トラブルと原因

| トラブル | 主な原因 |
|---|---|
| **下痢** | **注入速度が速い**、**栄養剤が冷たい**、**濃度が濃い**（濃すぎる＝高浸透圧）、器具が不潔 |
| **嘔吐** | **注入速度が速い**、**姿勢が低い**、量が多い |
| 誤嚥性肺炎（胃の内容物や唾液が気管に入って起こる肺炎） | 逆流・嘔吐、口腔内の細菌（経管栄養でも誤嚥は**起こる**） |
| 呼吸困難 | チューブが**気管に誤って入っている** |

覚え方：**下痢は「速い・冷たい・濃い・不潔」、嘔吐は「速い・低い・多い」**。

### こんなときどうする

共通のパターンは「**注入を止める → 看護職へ → 誤嚥を防ぐ姿勢**」です。自己判断でチューブを動かしたり、入れ直したりはしません。

| 場面 | ○ 正解 |
|---|---|
| 経鼻チューブが**10cm抜けていた** | **注入しないで看護職に報告**。元に戻す・抜く・気泡音（空気を入れて胃の音を聞く方法）で確認・そのまま注入は× |
| 注入中に**嘔吐**、苦しそう | 注入を中止して看護職を呼び、**誤嚥を防ぐため顔を横に向ける**（片付け・換気・酸素は後） |
| 嘔気（吐き気）があるとき | 注入を**止めて**看護職へ（速度を遅くして続けるは×） |
| **しゃっくり**が始まった | 注入を止め、上半身を起こして看護職へ |
| 胃ろうの周りから**漏れている** | **まず注入を止めて**看護職へ |
| 滴下が止まった | チューブの折れ・詰まり・位置のずれを疑い、看護職へ（押し込む・入れ直すは×） |
| 呼吸が苦しい・発熱・顔色が悪い・血圧低下 | 注入を中止して医療職に連絡 |
| 「**お腹が張ってきた**」顔色・意識は変わらない | **腹部が圧迫されていないか確認**（衣服・姿勢）。様子を見る・仰臥位・速度を上げるは× |

介護職の都合で注入を中止するのは×です。

## ④ 経管栄養をしている人の生活支援

| ○ | × |
|---|---|
| 口から食べなくても**口腔ケアは必要**。毎日行う | 数日に1回／不要 |
| **入浴できる**。胃ろう部は**湯につけてよい** | 清拭に変更／胃ろう部を湯につけない |
| 胃ろうの周りに発赤があるときの入浴は**医療職に確認** | 発赤があれば一律に入浴禁止 |
| 注入していないときは**歩行などの運動**を（便秘予防） | 日中もベッド上／排便はベッド上で |
| 便秘は**起こりうる** | 便秘の心配はなくなる |
| ボタン型胃ろうの周りは**石けんとぬるま湯で洗い**、清潔・乾燥を保つ | 軟膏を塗る・消毒する（医療職の判断）／歩行を避ける |
| 「口から食べたい、チューブを抜いて」→ 気持ちを受け止め、**医師や看護師に思いを伝える** | 手を固定する・手袋で抑える（身体拘束）／自分で経口摂取や胃ろうを提案 |
| 子どもは抱っこでチューブが動くことがあるので、**固定を工夫してスキンシップは続ける** | 抱っこをやめる |

- 口から食べないと唾液が減って口の中の細菌が増え、**誤嚥性肺炎**の原因になる。
- 胃ろうチューブを回転させて**癒着**（皮膚とチューブがくっつくこと）を防ぐのは**看護職**などの判断で行います。介護福祉士が自己判断で行うことではありません。
