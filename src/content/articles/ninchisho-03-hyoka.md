**この記事のポイント**

1. 若年性認知症＝**65歳未満**で発症。**男性**に多く、**進行が速く**、**就労・経済の支援**が必要。
2. **長谷川式（HDS-R）は30点満点で20点以下**が認知症の疑い。ただし**スケールだけで診断はできない**。
3. 抗認知症薬は**進行を遅らせるが止められない**。副作用は**吐き気・下痢**。

## ① 若年性認知症とうつ病の仮性認知症

### 若年性認知症

| ○ | × |
|---|---|
| **65歳未満**で発症（18〜64歳で発症した認知症） | 40歳以下／75歳未満／前期高齢者 |
| **男性**に多い | 女性に多い |
| 原因は**アルツハイマー型**が最多（2020年 調査。血管性・前頭側頭型・アルコール性なども含む） | レビー小体型が最多 |
| 高齢者より**進行が速い** | 進行が緩やか |
| **不安・抑うつ**を伴いやすい。うつ病などと間違われ**発見が遅れがち** | 早期発見しやすい／健診で見つかることが多い |
| 本人も家族も負担が大きい（仕事を辞める・家計・子どもの進学） | 家族の心理的負担は少ない |
| **就労支援**・経済的支援が必要。**若年性認知症支援コーディネーター**・若年性認知症コールセンターが相談にのる | 特化した支援が充実している |
| 若年性アルツハイマー型は**神経症状**を伴うことが多い | — |

> 全国の若年性認知症の人は**約3.6万人**（2020年 調査）。古い調査（2009年）では**血管性が最多**だったので、それ以前の過去問は「血管性」が正解のことがあります。

- 2020年公表の調査では約3.57万人、18〜64歳の人口10万人あたり**50.9人**。**年齢が上がるほど多く**、60〜64歳がいちばん多い（「30歳代の方が50歳代より多い」は×）
- 原因は**アルツハイマー型（約5割）→ 血管性 → 前頭側頭型**の順
- 新オレンジプランで、若年性認知症支援ハンドブックの配布と、**若年性認知症支援コーディネーター**の配置が進められました

### うつ病による仮性認知症との違い

| | 仮性認知症（うつ） | 認知症 |
|---|---|---|
| 進行 | **急速** | ゆるやか |
| 自覚 | 物忘れを**自覚し、誇張して訴える** | 自覚に乏しい・取り繕う |
| 目立つ症状 | 不眠・食欲低下・**希死念慮** | **判断障害** |
| 薬 | **抗うつ薬が効く** | 効かない |

## ② 評価スケールと軽度認知障害（MCI）

評価スケールは、大きく2つに分かれます。

- **質問式**（本人に口頭で質問して答えてもらう）：HDS-R（9問）、MMSE（11問。図形の模写・文を書く問題がある）。**HDS-Rには図形の模写や書字がない**のが見分けどころ
- **観察式**（日常の様子を観察して重さを決める）：FAST、CDR、認知症高齢者の日常生活自立度
- MMSEの目安は「23点以下」ですが、「24点以下」とする資料もあります

| スケール | 中身 | よく出るポイント |
|---|---|---|
| **改訂長谷川式（HDS-R）** | **記憶・見当識・計算**などの質問（9問） | **30点満点・20点以下**で認知症の疑い。点が**低いほど**重い。これだけで**診断はできない** |
| **MMSE**（ミニメンタルステート検査） | 口頭の質問＋**図形の模写**・文を書く | 30点満点・**23点以下**で疑い。行動観察ではない。歌やダンスの項目はない |
| **FAST** | **アルツハイマー型**の進み具合を、**生活の様子（ADL）から7段階**で見る | 血管性用ではない |
| **CDR**（臨床認知症評価尺度） | 記憶・見当識・判断など**6項目を観察**して重症度を見る | **0.5＝MCI相当**、1＝軽度、2＝中等度、3＝重度 |
| 画像検査 | CT・MRI＝**脳の萎縮**や出血、**SPECT**＝**脳の血流** | 慢性硬膜下血腫を見分けるのは**頭部CT** |

HDS-R・MMSEは**スクリーニング**（認知症の疑いがある人をふるい分ける検査）で、点数だけでは診断しません。

### 認知症高齢者の日常生活自立度

| ランク | 状態 |
|---|---|
| Ⅰ | 何らかの認知症はあるが、日常生活は**ほぼ自立** |
| Ⅱa／Ⅱb | 生活に支障のある症状があるが、**誰かが注意していれば自立**（Ⅱa＝家庭の外で、Ⅱb＝家庭の中でも） |
| **Ⅲa／Ⅲb** | 支障のある症状が**ときどき見られ、介護が必要**（Ⅲa＝**日中**中心、Ⅲb＝**夜間**中心） |
| Ⅳ | 支障のある症状が**頻繁**に見られ、**常に介護が必要** |
| M | 著しい精神症状や問題行動（判定基準の用語。本人には理由があることが多い）、重い身体疾患があり、**専門医療が必要** |

> 体の動きで見る「障害高齢者の日常生活自立度（寝たきり度：J・A・B・C）」とは別のものです。

- **IADLのアセスメント**は**軽度**の認知症の把握に役立つ
- 生活のアセスメントで「**身体的要因**」に入るのは**IADL**。性格は心理的、居住環境・人的環境・社会とのつながりは環境・社会的要因

### 軽度認知障害（MCI）

| ○ | × |
|---|---|
| 本人や家族から**記憶低下の訴え**がある | 日常生活に支障がある |
| **日常生活は自立**している | 認知症の一種である |
| CDR **0.5** | CDR 2 |
| 一部が認知症へ移行する（<strong>年に5〜15%</strong>程度） | 約半数が1年で認知症になる |
| 運動・交流など**生活の見直し**で予防に取り組む。正常に戻る人もいる | 主に抗認知症薬で治療 |

## ③ 薬と予防

### 抗認知症薬

ドネペジル・ガランタミン・リバスチグミンは、記憶にかかわる物質**アセチルコリン**を分解する酵素のはたらきを抑えて、脳の中のアセチルコリンを増やす薬です。メマンチンは別のしくみで、神経細胞を過剰な刺激から守ります。

| 薬 | 対象 | 形・特徴 |
|---|---|---|
| ドネペジル | 軽度〜高度。**レビー小体型**にも使う | 飲み薬（貼り薬もある） |
| ガランタミン | 軽度〜中等度 | 飲み薬 |
| リバスチグミン | 軽度〜中等度 | **貼り薬**（貼付剤） |
| メマンチン | **中等度〜高度** | 飲み薬。副作用はめまい・便秘・眠気など |
| レカネマブ（2023年）・ドナネマブ（2024年） | **MCI〜軽度**のアルツハイマー型 | 点滴。原因物質**アミロイドβを取り除く**新しい薬。脳のむくみや小さな出血の副作用に注意 |

| ○ | × |
|---|---|
| **進行を遅らせる**が、**完全には止められない** | 進行を完全に止める |
| 主な副作用は**吐き気（悪心）・下痢**など消化器症状。手足のふるえ・こわばりなど**パーキンソン症状**（錐体外路症状）が出ることもある | 副作用はない |
| **貼り薬**（貼付剤）もある | 貼付剤はない |
| **非薬物療法と併用**する。種類によっては**併用**もある | 非薬物療法とは併用しない／複数の併用は不可 |
| 病期に応じて量を**段階的に増やす** | 段階的に減らす |
| 軽度〜高度、レビー小体型にも使われるものがある | 軽度・高度・若年性・レビーには効かない |

### BPSDに使う抗精神病薬の副作用

- **誤嚥のリスクが高くなる**（飲み込みが悪くなる）
- 歩幅が小さくなる・筋肉がこわばる（パーキンソン症状）、ふらつき・転倒

**薬どうしの関係**

| 薬 | はたらき | 気をつけること |
|---|---|---|
| 抗認知症薬 | 認知機能の低下をゆるやかにする | 吐き気・下痢、パーキンソン症状が出ることもある |
| 抗精神病薬 | 幻覚・妄想・興奮をしずめる。**ドーパミン**のはたらきを抑える | パーキンソン症状（小刻み歩行・こわばり）・飲み込みの悪化・眠気 |
| 抗パーキンソン病薬 | **ドーパミンを補う** | 逆に**幻覚**が出ることがある |
| 睡眠薬・抗不安薬 | 眠り・不安をやわらげる | **せん妄**や転倒の原因になる |

→ 「新しい薬が始まったあとの変化」は、医療職へ報告します。

### 予防とリスク要因

| リスクを下げる | リスクを上げる |
|---|---|
| **集団での交流活動** | **歯を失うことによる咀嚼機能の低下** |
| 運動・十分な睡眠 | 難聴（補聴器を使わない）・高血圧・糖尿病・喫煙・社会的孤立 |
| 不飽和脂肪酸（魚など）の摂取 | 飽和脂肪酸の多い食事 |
| 補聴器の使用・視力の矯正 | 視力低下の放置・LDLコレステロールが高い |

> ボランティア活動・身体活動・補聴器の使用は、リスクを**下げる**側です。最新の知見（2024年 ランセット委員会）では、難聴・高いLDLコレステロール・視力低下・高血圧・糖尿病・喫煙・運動不足・社会的孤立など**14の要因**を改善すると、認知症の<strong>約半分（45％）</strong>は予防・先送りできる可能性があるとされています。
