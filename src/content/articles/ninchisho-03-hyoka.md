**この記事のポイント**

1. 若年性認知症＝**65歳未満**で発症。**男性**に多く、**進行が速く**、**就労・経済の支援**が必要。
2. **長谷川式（HDS-R）は30点満点で20点以下**が認知症の疑い。ただし**スケールだけで診断はできない**。
3. 抗認知症薬は**進行を遅らせるが止められない**。副作用は**吐き気・下痢**。

## ① 若年性認知症とうつ病の仮性認知症【認知症の理解】

### 若年性認知症

| ○ | × |
|---|---|
| **65歳未満**で発症 | 40歳以下／75歳未満／前期高齢者 |
| **男性**に多い | 女性に多い |
| 原因は**アルツハイマー型**が最多（血管性・アルコール性も含む） | レビー小体型が最多 |
| 高齢者より**進行が速い** | 進行が緩やか |
| **不安・抑うつ**を伴いやすい | 家族の心理的負担は少ない |
| **就労支援**・経済的支援が必要 | 特化した支援が充実している／健診で見つかることが多い |
| 若年性アルツハイマー型は**神経症状**を伴うことが多い | — |

### うつ病による仮性認知症との違い

| | 仮性認知症（うつ） | 認知症 |
|---|---|---|
| 進行 | **急速** | ゆるやか |
| 自覚 | 物忘れを**自覚し、誇張して訴える** | 自覚に乏しい・取り繕う |
| 目立つ症状 | 不眠・食欲低下・**希死念慮** | **判断障害** |
| 薬 | **抗うつ薬が効く** | 効かない |

## ② 評価スケールと軽度認知障害（MCI）【認知症の理解】

| スケール | 中身 | よく出るポイント |
|---|---|---|
| **改訂長谷川式（HDS-R）** | **記憶・見当識・計算**などの質問 | **30点満点・20点以下**で認知症の疑い。点が**低いほど**重い。これだけで**診断はできない** |
| **MMSE** | 口頭の質問＋**図形の模写**・文を書く | 30点満点・23点以下で疑い。行動観察ではない |
| **FAST** | **アルツハイマー型**の重症度をADLで7段階 | 血管性用ではない |
| **CDR** | 記憶・判断など6項目で重症度 | **0.5＝MCI相当**、1＝軽度、2＝中等度 |
| 認知症高齢者の日常生活自立度 | Ⅰ〜Ⅳ・M | **ランクⅢ＝症状がときどき見られ、介護が必要**。Ⅱは「誰かが注意すれば自立」、Mは「専門医療が必要」 |

- **IADLのアセスメント**は**軽度**の認知症の把握に役立つ
- 生活のアセスメントで「**身体的要因**」に入るのは**IADL**。性格は心理的、居住環境・人的環境・社会とのつながりは環境・社会的要因
- 慢性硬膜下血腫を見分けるのは**頭部CT**

### 軽度認知障害（MCI）

| ○ | × |
|---|---|
| 本人や家族から**記憶低下の訴え**がある | 日常生活に支障がある |
| **日常生活は自立**している | 認知症の一種である |
| CDR **0.5** | CDR 2 |
| 一部が認知症へ移行する（年に<strong>5〜15%</strong>程度） | 約半数が1年で認知症になる／主に抗認知症薬で治療 |

## ③ 薬と予防【認知症の理解】

### 抗認知症薬（ドネペジルなど）

| ○ | × |
|---|---|
| **進行を遅らせる**が、**完全には止められない** | 進行を完全に止める |
| 副作用：**吐き気（悪心）・下痢**、**パーキンソン症状** | — |
| **貼り薬**（貼付剤）もある | 貼付剤はない |
| **非薬物療法と併用**する。種類によっては**併用**もある | 非薬物療法とは併用しない／複数の併用は不可 |
| 病期に応じて量を**段階的に増やす** | 段階的に減らす |
| 軽度〜高度、レビー小体型にも使われるものがある | 軽度・高度・若年性・レビーには効かない |

### BPSDに使う抗精神病薬の副作用

- **誤嚥のリスクが高くなる**（飲み込みが悪くなる）
- 歩幅が小さくなる・筋肉がこわばる（パーキンソン症状）、ふらつき・転倒

### 予防とリスク要因

| リスクを下げる | リスクを上げる |
|---|---|
| **集団での交流活動** | **歯を失うことによる咀嚼機能の低下** |
| 運動・十分な睡眠 | 難聴（補聴器を使わない）・高血圧・糖尿病・喫煙・社会的孤立 |
| 不飽和脂肪酸（魚など）の摂取 | 飽和脂肪酸の多い食事 |

> ボランティア活動・身体活動・補聴器の使用は、リスクを**下げる**側です。

## ④ 評価スケール・若年性認知症・非薬物療法

- **若年性認知症の原因疾患**：2009年公表の調査では**血管性認知症が最多**、次いでアルツハイマー型。**2020年の調査ではアルツハイマー型が最多**。出題された調査年で判断する。
- **認知症の検査**：**HDS-R（改訂長谷川式）**＝30点満点、20点以下で認知症の疑い／**MMSE**＝30点満点、見当識・記憶・計算・言語・図形の模写など（歌やダンスの項目はない）。どちらも**スクリーニング**で、点数だけで診断しない。画像検査（CT・MRIなど）で病型やほかの病気を確かめる。
- **認知症高齢者の日常生活自立度**：**Ⅰ**＝ほぼ自立／**Ⅱa**＝家庭の外で、**Ⅱb**＝家庭の中でも支障があるが見守りで自立／**Ⅲa**＝**日中**を中心に、**Ⅲb**＝**夜間**を中心に介護が必要／**Ⅳ**＝常に介護が必要／**M**＝著しい精神症状などで専門医療が必要。
- **評価スケール**：**HDS-R（長谷川式）**＝30点満点・**20点以下**で認知症の疑い、**MMSE**＝30点満点・**23点以下**で疑い（図形の模写あり）、**FAST**＝アルツハイマー型の進行を**生活の様子から7段階**で観察、**CDR**＝記憶・見当識など6項目を観察で評価。
- 画像検査：CT・MRI（脳の萎縮）、**SPECT**（脳の血流）。
- **若年性認知症**（65歳未満で発症）：約3.6万人、**アルツハイマー型が最多**、**男性に多い**。多くの人が仕事を辞めざるをえず、経済的な困難・子どもの進学などの問題が大きい。**若年性認知症支援コーディネーター**、**若年性認知症コールセンター**で支える。
- 非薬物療法：**回想法**（昔の写真や道具で思い出を語る。事実と違っても否定しない）、**リアリティ・オリエンテーション**（日付・場所などを繰り返し伝える）、音楽療法など。
