**この記事のポイント**

1. 終末期の介護は「**食べたい物を・楽な姿勢で・声をかけ続け・苦痛をやわらげる**」。高カロリー・同じ体位・反応がないので無言、は×。
2. 家族には「**付き添いやすい環境**」「**家族にできることを提案**」「**これから起こる変化を説明**」。面会を控えさせる・変化を伝えないは×。
3. 死後のケアは「**家族に一緒に行うか確認**し、**生前と同じように声をかけながら**」。**義歯は入れる、着物は左前、帯紐は縦結び**。

## ① 終末期の介護【生活支援技術／介護の基本】

| 場面 | ○ 正解 | × よく出る不正解 |
|---|---|---|
| 食事 | **嗜好を重視**、**食べたい物を確認して提供** | 回数・量を増やす／高カロリー／経管栄養を勧める／決まった時間に提供 |
| 在宅のがん末期で食欲がない | 「**好きなものを食べてもらいましょう**」 | 入院／麻薬は怖い／寝ているように |
| 体位 | **安楽な体位**、**体位変換**を続ける | 同一体位を保つ |
| 息苦しい | **半座位**にする | 顎を下げて頭部を前屈させた仰臥位 |
| 倦怠感が強い | 全身清拭から**部分清拭**に | 定期の入浴を続ける |
| 口腔 | **口腔ケアは続ける**（乾燥には保湿） | 口腔ケアを控える／アイスマッサージ |
| 声かけ | **手を握る**などスキンシップ、**反応がなくても話しかける** | 意識がなくなれば声かけを控える／無言で介護 |
| 苦痛・不安 | **マッサージや好きな音楽**で緩和。死への恐怖は否定しない | 苦痛緩和は医師に任せる |
| せん妄で話のつじつまが合わない | **否定せず受け止める** | — |
| 便秘予防 | **座位の機会**をつくる、大腸に沿った腹部マッサージ | 水分を減らす・冷やす・下剤で刺激 |
| 環境 | 家族と**ゆっくり過ごせる**居室、換気、仲の良い入所者の面会もよい | テレビをつけっぱなし／窓を閉め切る／夜間の巡回を控える |
| 観察 | **尿量を記録**、安心できるよう話しかける | — |

> 布団のダニの死骸やフンは**掃除機で吸い取る**。干す・たたくだけでは取れません。

## ② 家族支援・グリーフケア・死後のケア【生活支援技術】

### 看取りの時期の家族支援

| ○ | × |
|---|---|
| 家族が**付き添いやすい環境**を整える | 毎日面会に来るよう促す／パブリックスペース |
| 家族が**利用者のためにできること**を提案、**好きな物を持ってきてもらう** | 介護は職員が最後まで行い家族には控えてもらう |
| **死に至る過程の身体の変化**を前もって説明 | 体調の変化は伝えない／情報提供を控える |
| 死前喘鳴で「苦しそう」と心配する家族に「**自然な経過なので体位を工夫して一緒に見守りましょう**」 | 痰の吸引を準備／救急車／意識がないので心配ない |
| 家族の感情の表出を受け止める | 感情を出さないよう助言／苦痛を見せないよう面会を控える／家族から激励 |
| 緊急連絡先は**複数** | 1つにする |

### グリーフケア（悲嘆のケア）

| ○ | × |
|---|---|
| 家族の悲嘆へのケアは**終末期ケアとともに始める** | 亡くなってから・悲しみを表したときから始める |
| 「**悔いが残る**」と言う家族の**話を聴く** | 気分を切り替えるよう励ます／毎日電話する |
| 亡くなって1週間後に寂しさを語る夫に、**気遣いの言葉をかけて話を聴く** | 外食・趣味を勧める／元気を出すよう励ます |
| 悲嘆が**長引く**ときは**専門医などに相談**するよう助言 | 悲嘆は特異な反応／思い出に触れない |
| 故人の**思い出話**をしてよい | 思い出話は控える |

**悲嘆反応の例**：妻を亡くした夫が夜、妻のタンスの前に座ったり、妻の好きな食器を出したりする ＝ **探索行動**。

### 死後のケア（エンゼルケア）

| ○ | × |
|---|---|
| **家族に一緒に行うか確認**する。家族が希望すれば一緒に | 家族には見せない・職員だけで行う |
| **生前と同じように声をかけながら**行う | — |
| **死後硬直が始まる前**（できるだけ早く）に行う | 死後3時間たってから／硬直してから |
| **義歯は入れる**（顔の形が整う） | 義歯を外す |
| 着物は**左前**（ふだんと逆）、**帯紐は縦結び** | 右前 |
| 衣服は**本人や家族の希望**の物 | 施設が指定した物 |
| 清拭は**お湯**で、ひげ剃り後は**クリーム**を塗る | 水で清拭／手首を包帯でしばる／紐で顎を固定 |
| ペースメーカーの取り外しは**医師**の処置 | 介護職が取り除く |

### デスカンファレンス

**亡くなった利用者のケアを振り返り、悲しみを共有し、今後の介護に生かす**場。個人の責任追及・感情を抑える・死亡直後に行う・ボランティアの参加は×。

## ③ 4つの苦痛へのケア・エンゼルケア・グリーフケア

- 家族から「手伝いたい」と申し出があったら、**家族が無理なく参加できるケア**（体を拭く・口を湿らせる・手を握る・好きな音楽をかけるなど）を一緒に行う。坐薬の挿入など医療に関わることは、条件と医療職の判断を確認する。
- 施設になじめない人には、**趣味など本人の関心がある話題のきっかけ（映画のチラシなど）を用意し、本人のペースで反応を待つ**。集団活動を無理に勧めない。
- 夜間に歩き回る人には、まず**安心できる声かけ**をし、**日中の活動量**など生活リズムを見直す。
- **終末期の4つの苦痛**：**身体的**（痛み・息苦しさ）、**精神的**（不安・いらだち・孤独）、**社会的**（仕事・家庭・相続）、**スピリチュアル（霊的）**（死への恐れ・生きる意味・罪の意識）。
- **身体的苦痛を和らげるケア**：こまめな体位変換、呼吸が楽な姿勢、手足のマッサージ・保温、口や舌の乾燥には水を含ませたガーゼ。**聴覚は最期まで残る**ので声をかけ続ける。
- **死後のケア（エンゼルケア）**：家族が**十分にお別れをしてから**、希望があれば一緒に行う。**死亡診断のあと**、死後硬直が始まる前（**おおむね死後1〜2時間のうち**）に行う。着物は**左前**・帯は**縦結び**。
- **デスカンファレンス**＝亡くなった利用者のケアをふり返り、**今後のケアの質を高める**ための話し合い（家族の対応を批判する場ではない）。
- **グリーフケア**：遺族が悲しみを表現できるよう**よい聞き手**になる（助言者ではなく）。看取りについて遺族が**罪悪感をもたない**よう配慮する。
