**この記事のポイント**

1. 終末期の介護は「**食べたい物を・楽な姿勢で・声をかけ続け・苦痛をやわらげる**」。**聴覚は最後まで残る**ので、反応がなくても話しかける。高カロリー・同じ体位・無言の介護は×。
2. 家族には「**付き添いやすい環境**」「**家族にできることを提案**」「**これから起こる変化を説明**」。面会を控えさせる・変化を伝えないは×。
3. 死後のケアは「**家族に一緒に行うか確認**し、**生前と同じように声をかけながら**」。**義歯は入れる、着物は左前、帯紐は縦結び**。

## ① 終末期の介護

### 食事

| 場面 | ○ 正解 | × よく出る不正解 |
|---|---|---|
| 食事 | **嗜好を重視**、**食べたい物を確認して提供**。本人のペースで | 回数・量を増やす／高カロリー／経管栄養を勧める／決まった時間に提供 |
| 在宅のがん末期で食欲がない | 「**好きなものを食べてもらいましょう**」 | 入院／麻薬は怖い／寝ているように |

### 呼吸と体位

| 場面 | ○ 正解 | × よく出る不正解 |
|---|---|---|
| 体位 | **安楽な体位**、こまめな**体位変換**を続ける | 同一体位を保つ |
| 息苦しい | **半座位**（上半身を45度くらい起こした姿勢）にする。横隔膜が下がり呼吸が楽になる（セミファーラー位＝15〜30度、ファーラー位（半座位）＝45度前後。息苦しさが強いほど上半身を高くする） | あごを引いて頭部を前に曲げた仰臥位（気道が狭くなる） |

### 清潔・排泄

| 場面 | ○ 正解 | × よく出る不正解 |
|---|---|---|
| 倦怠感が強い | 全身清拭から**部分清拭**に | 定期の入浴を続ける |
| 口腔 | **口腔ケアは続ける**。口や舌の乾燥には水を含ませたガーゼや保湿剤 | 口腔ケアを控える／アイスマッサージ（凍らせた綿棒で飲み込みを促す訓練。終末期の目的に合わず負担になる） |
| 便秘予防 | **座位の機会**をつくる、大腸に沿った腹部マッサージ | 水分を減らす・冷やす・下剤で刺激 |
| 観察 | **尿量を記録**、安心できるよう話しかける | — |

### 声かけ・苦痛・環境

| 場面 | ○ 正解 | × よく出る不正解 |
|---|---|---|
| 声かけ | **手を握る**などスキンシップ、**反応がなくても話しかける**（**聴覚は最後まで残る**） | 意識がなくなれば声かけを控える／無言で介護 |
| 苦痛・不安 | **マッサージや好きな音楽**、手足の保温で緩和。死への恐怖は否定しない | 苦痛緩和は医師に任せる |
| せん妄で話のつじつまが合わない | **否定せず受け止める** | — |
| 環境 | 家族と**ゆっくり過ごせる**居室、換気、仲の良い入所者の面会もよい | テレビをつけっぱなし／窓を閉め切る／夜間の巡回を控える |

**終末期の4つの苦痛（全人的苦痛＝トータルペイン）**：**身体的**（痛み・息苦しさ）、**精神的**（不安・いらだち・孤独）、**社会的**（仕事・家庭・相続）、**スピリチュアル（霊的）**（死への恐れ・生きる意味・罪の意識）。本人・家族と多職種のチームで支えます。

## ② 家族支援・グリーフケア・死後のケア

### 看取りの時期の家族支援

| ○ | × |
|---|---|
| 家族が**付き添いやすい環境**を整える | 毎日面会に来るよう促す／パブリックスペース |
| 家族が**利用者のためにできること**を提案、**好きな物を持ってきてもらう**。手伝いたいと言われたら、体を拭く・口を湿らせる・手を握るなど**無理なくできるケア**を一緒に（坐薬など医療に関わることは医療職の判断を確認） | 介護は職員が最後まで行い家族には控えてもらう |
| **死に至る過程の身体の変化**を前もって説明 | 体調の変化は伝えない／情報提供を控える |
| 死前喘鳴で「苦しそう」と心配する家族に「**自然な経過なので体位を工夫して一緒に見守りましょう**」 | 痰の吸引を準備／救急車／意識がないので心配ない |
| 家族の感情の表出を受け止める | 感情を出さないよう助言／苦痛を見せないよう面会を控える／家族から激励 |
| 緊急連絡先は**複数** | 1つにする |

### グリーフケア（悲嘆のケア）

| ○ | × |
|---|---|
| 家族の悲嘆へのケアは**終末期ケアとともに始める**（亡くなる前から起こる悲しみ＝**予期悲嘆**） | 亡くなってから・悲しみを表したときから始める |
| 「**悔いが残る**」と言う家族の**話を聴く**（助言者ではなく**よい聞き手**に。罪悪感をもたないよう配慮） | 気分を切り替えるよう励ます／毎日電話する |
| 亡くなって1週間後に寂しさを語る夫に、**気遣いの言葉をかけて話を聴く** | 外食・趣味を勧める／元気を出すよう励ます |
| 悲嘆は**自然な反応**。ただし長引いて生活に支障が出る**複雑性悲嘆**のときは**専門医などに相談**するよう助言 | 悲嘆は特異な反応／思い出に触れない |
| 故人の**思い出話**をしてよい | 思い出話は控える |

**悲嘆反応の例**：妻を亡くした夫が夜、妻のタンスの前に座ったり、妻の好きな食器を出したりする ＝ **探索行動**。

### 死後のケア（エンゼルケア）

流れ：**医師の死亡診断** → **家族が十分にお別れ** → **死後硬直が始まる前**（死後硬直は2〜3時間ごろから始まるので、おおむね**死後1〜2時間のうち**）に死後のケア。

| ○ | × |
|---|---|
| **家族に一緒に行うか確認**する。家族が希望すれば一緒に | 家族には見せない・職員だけで行う |
| **生前と同じように声をかけながら**行う | — |
| 家族のお別れのあと、**死後硬直が始まる前**に行う | 死後3時間たってから／硬直してから |
| **義歯は入れる**（顔の形が整う） | 義歯を外す |
| 着物は**左前**（左の身頃を先に体に当てて下にし、右の身頃を上に重ねる。ふだんの右前と逆）、**帯紐は縦結び**（結び目が縦向きになる結び方） | 右前 |
| 衣服は**本人や家族の希望**の物 | 施設が指定した物 |
| 清拭は**お湯**で、ひげ剃り後は**クリーム**を塗る | 水で清拭／手首を包帯でしばる／紐で顎を固定 |
| ペースメーカーの取り外しは**医師**の処置 | 介護職が取り除く |

### デスカンファレンス

**亡くなった利用者のケアを振り返り、悲しみを共有し、今後の介護に生かす**場。職員の心のケアにもなる。個人の責任追及・家族の対応の批判・感情を抑える・死亡直後に行う・ボランティアの参加は×。
