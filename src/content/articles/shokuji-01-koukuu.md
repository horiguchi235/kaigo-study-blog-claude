**この記事のポイント**

1. 唾液には**消化酵素**と**抗菌作用**がある。唾液が減ると**飲み込みにくく、口臭**が出る。
2. 口腔ケアは**座位が基本**、座れなければ**セミファーラー位か側臥位で顔を横に**し、**顎を引く**。うがいは**ブラッシングの前**、歯ブラシは**小刻みに1〜2本ずつ**。
3. 総義歯は**下顎から外し、上顎から入れる**。**毎食後に流水で洗い、水につけて保管**（歯磨き粉・熱湯・乾燥は×）。

---

この記事の用語：**義歯**＝入れ歯。**総義歯**（総入れ歯）＝歯が1本もない人の全部の歯、**部分義歯**（部分床義歯・部分入れ歯）＝一部の歯を補うもの。

## ① 唾液と口の加齢変化

口には、食べる・話す・**呼吸する**・表情をつくる働きがあります。

### 唾液

| ○ 正しい | × よく出る誤り |
|---|---|
| 唾液には**消化酵素**が含まれる | 1日3L出る（実際は1〜1.5L）／分泌中枢は小脳（実際は延髄） |
| 唾液には**抗菌作用**がある。食べ物をまとめ、口の中を洗い流す（**自浄作用**） | 副交感神経は分泌を抑える（実際は**促進**）／食事のときだけ出る |
| 耳下腺・顎下腺・舌下腺は**大唾液腺** | 舌下腺は小唾液腺 |

### 口の加齢変化

| ○ 正しい | × よく出る誤り |
|---|---|
| 加齢で**舌の動きが低下**する | 唾液が増える／味蕾（舌にある味を感じる部分）は変わらない（実際は減る）／嚥下反射が亢進する（強まる。実際は**低下**する） |
| 義歯を使うと**言葉が明瞭**になる | 唾液が増える・舌の動きが悪くなる |

- 口の機能のささいな衰え（滑舌の低下、食べこぼし、わずかなむせ、かめない食品が増える）を**オーラルフレイル**といい、放っておくと低栄養やフレイルにつながります

### 口臭・口の汚れ

- 口臭の原因になりやすいのは**歯周病**と**舌苔**（舌につく細菌や古い細胞）、唾液の減少
- 口臭は**他者との交流を避ける原因**になる
- **口内炎**があると痛みで磨けず、清潔が保てない
- 「水分と一緒でないと飲み込みにくい」＋口臭 → **唾液分泌の低下**。**ドライマウス**（口の乾燥）は誤嚥性肺炎の原因にもなるので、唾液腺マッサージで唾液を促す

| 比べる点 | むし歯（う蝕） | 歯周病 |
|---|---|---|
| どこが傷む | 歯そのもの（エナメル質→象牙質→歯髄の順に溶ける） | 歯ぐきと歯を支える骨 |
| 特徴 | 痛みが出やすい | 痛みが少なく気づきにくい。**口臭の一番の原因**。進むと歯が抜ける |
| 全身との関係 | — | **糖尿病**・心疾患・脳血管疾患・誤嚥性肺炎と関係が深い |

## ② 口腔ケアの方法

口腔ケアには、歯みがきなどの清掃である**器質的口腔ケア**（介護職が主に担う）と、口の体操などで機能を保つ**機能的口腔ケア**があります。

<photo name="shokuji-01__koukuu-care" caption="口腔ケア用品。左から**やわらかい歯ブラシ**、**スポンジブラシ**（粘膜の汚れをとる。水はよく絞る）、**舌ブラシ**、**義歯用ブラシ**、**義歯ケース**。">

| ○ 正解 | × よく出る不正解 |
|---|---|
| **座位**が基本。座れない人は**セミファーラー位か側臥位で顔を横に**向け（片麻痺なら**健側を下**）、**顎を引く** | 仰臥位で行う／頭部を後屈・顎を上げる（誤嚥しやすい） |
| 片麻痺の人は**麻痺側に食べかすが残りやすい**ので、麻痺側をよく確認する | — |
| うがいができるなら**ブラッシング前にうがい** | うがいで歯垢を除去する（歯垢はブラッシングでしか取れない） |
| 歯ブラシは**やわらかめ**、**小刻み**に、**1〜2本ずつ**。歯と歯肉の境目こそ丁寧に | 硬い毛・強い力・大きく動かす／歯と歯肉の境目を避ける |
| 使った歯ブラシは**毛先を上**にして乾燥させる | 柄を上にしてコップに立てる |
| **舌の汚れ**も取る。舌は**奥から手前**へ | 舌苔は一度に残さず取る／手前から奥へ |
| スポンジブラシは**水をよく絞って**使う | したたるほど水を含ませる／乾いたまま使う |
| 上顎は**奥から手前**へ拭う | — |
| 経管栄養の人も**口腔ケアは必要**。**注入直後は避ける**（嘔吐・逆流の防止） | 口から食べていないので不要／注入後すぐ行う |
| 口の乾燥には**唾液腺マッサージ** | 水分を控える／苦味の強い食べ物 |
| 指先に力が入らない → **柄を太くした歯ブラシ** | 歯ブラシをやめて洗口液だけ |
| 歯みがきは**感染予防**（誤嚥性肺炎の予防）になる | 乾燥は口臭を予防する |
| <strong>歯がない人（無歯顎）</strong>も、歯ぐき・上あご・舌の汚れを清掃する | 歯がないので口腔ケアは不要 |

> 部分床義歯は**外してから**ケアをします（つけたまま行うは×）。

## ③ 義歯の取り扱い

<photo name="shokuji-01__gishi" caption="左が**総義歯**（上あご用）、右が金属のバネ（クラスプ）が付いた**部分義歯**。はずすときは**部分義歯はバネを持って**、総義歯は**下顎から**はずします。">

| 場面 | ○ 正解 | × よく出る誤り |
|---|---|---|
| 外す順 | **下顎から**外す | 上顎から外す |
| 上顎の総義歯の外し方 | **後方を下げて**外す | — |
| 入れる | **上顎から**。総義歯は大きいので、横向きにして**回転させながら**口に入れ、中で向きを戻す | 回転させずまっすぐ入れる |
| 部分義歯の着脱 | **クラスプ（金具）を指で持って**着脱する | かんで押し込む（バネが曲がり、歯ぐきを傷つける） |
| 洗う | **毎食後**、**流水**で**義歯用ブラシ** | 歯磨き粉を使う（すり減る）／熱湯（変形）／スポンジブラシ |
| 保管 | **水（または洗浄剤）に全部つけて**保管 | 乾燥させる／半分だけつける |
| つける時間 | 日中は**つけておく**。**就寝時は外して**歯ぐきを休ませ、水につけて保管 | 食事のときだけつける |

- 施設では取り違えや紛失を防ぐため、義歯に**名前を入れる**ことがあります

> 部分床義歯の<strong>クラスプ（金具）</strong>は汚れがたまりやすいので、**ブラシでしっかり**洗います（流水で軽く、は×）。

## ひっかけパターン集（口腔ケア・義歯で「ほぼ×」）

| 選択肢の表現 | なぜ× |
|---|---|
| 仰臥位で・顎を上げて行う | 誤嚥しやすい。顎を引く |
| 硬い歯ブラシで強く・大きく | 歯肉を傷つける。やわらかめで小刻みに |
| 経管栄養なので口腔ケア不要 | 口から食べなくても汚れ、肺炎の原因に |
| 義歯を歯磨き粉・熱湯で洗う | 研磨剤ですり減る・熱で変形する |
| 義歯を乾燥させて保管 | ひび割れ・変形する |
| 副交感神経が唾液を抑える | リラックス時（副交感）に唾液は増える |
| 部分義歯をかんで装着する | 指でクラスプを持って着脱する |
