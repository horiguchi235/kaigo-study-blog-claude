**結論を3行で**

1. 唾液には**消化酵素**と**抗菌作用**がある。唾液が減ると**飲み込みにくく、口臭**が出る。
2. 口腔ケアは**座位か側臥位で顎を引く**。うがいは**ブラッシングの前**、歯ブラシは**小刻みに1〜2本ずつ**。
3. 総義歯は**下顎から外し、上顎から入れる**。**毎食後に流水で洗い、水につけて保管**（歯磨き粉・熱湯・乾燥は×）。

## ① 唾液と口の加齢変化【こころとからだのしくみ】

| ○ 正しい | × よく出る誤り |
|---|---|
| 唾液には**消化酵素**が含まれる（第26回） | 1日3L出る（実際は1〜1.5L）／分泌中枢は小脳（実際は延髄） |
| 唾液には**抗菌作用**がある（第31回） | 副交感神経は分泌を抑える（実際は**促進**）／食事のときだけ出る |
| 耳下腺・顎下腺・舌下腺は**大唾液腺** | 舌下腺は小唾液腺 |
| 加齢で**舌の動きが低下**する（第24回） | 唾液が増える／味蕾は変わらない／嚥下反射が亢進する |
| 義歯を使うと**言葉が明瞭**になる（第33回） | 唾液が増える・舌の動きが悪くなる |

### 口臭・口の汚れ

- 口臭の原因になりやすいのは**歯周病**（第35回）
- 口臭は**他者との交流を避ける原因**になる（第32回）
- **口内炎**があると痛みで磨けず、清潔が保てない（第28回）
- 「水分と一緒でないと飲み込みにくい」＋口臭 → **唾液分泌の低下**（第37回）

<details>
<summary>✏️ 解いてみよう（第37回・事例）</summary>

78歳の女性が、友人に口臭を指摘されて悩んでいる。「水分と一緒に食べないと飲み込みにくい」とも話す。歯の欠損や麻痺はなく、ストレスの訴えもない。機能低下が考えられるものとして、最も適切なものはどれ？

1. 咀嚼
2. 蠕動運動
3. 嗅覚
4. 唾液分泌
5. 胃液分泌

<details class="answer">
<summary>正解を見る</summary>

**正解：4**　唾液には食べ物をまとめて飲み込みやすくする働きと、口の中を洗い流す（抗菌）働きがあります。減ると「飲み込みにくい」「口臭」の両方が起こります。
</details>
</details>

## ② 口腔ケアの方法【生活支援技術】

| ○ 正解 | × よく出る不正解 |
|---|---|
| **座位**、無理なら**側臥位**で**顎を引く** | 仰臥位で行う／頭部を後屈・顎を上げる |
| うがいができるなら**ブラッシング前にうがい**（第27・33・37回） | うがいで歯垢を除去する（歯垢はブラッシングでしか取れない） |
| 歯ブラシは**やわらかめ**、**小刻み**に、**1〜2本ずつ**（第34・38回） | 硬い毛・強い力・大きく動かす／歯と歯肉の境目を避ける |
| **舌の汚れ**も取る。舌は**奥から手前**へ（第24回） | 舌苔は一度に残さず取る／手前から奥へ |
| スポンジブラシは**水をよく絞って**使う | したたるほど水を含ませる／乾いたまま使う |
| 上顎は**奥から手前**へ拭う（第34回） | — |
| 経管栄養の人も**口腔ケアは必要**。**注入直後は避ける**（嘔吐・逆流の防止）（第26回） | 口から食べていないので不要／注入後すぐ行う |
| 口の乾燥には**唾液腺マッサージ**（第33回） | 水分を控える／苦味の強い食べ物 |
| 指先に力が入らない → **柄を太くした歯ブラシ**（第30回） | 歯ブラシをやめて洗口液だけ |
| 歯みがきは**感染予防**（誤嚥性肺炎の予防）になる（第37回） | 乾燥は口臭を予防する |

> 部分床義歯は**外してから**ケアをします（つけたまま行うは×）。

<details>
<summary>✏️ 解いてみよう（第38回）</summary>

介護が必要な利用者への口腔ケアとして、最も適切なものはどれ？

1. 仰臥位で行う
2. 歯垢を除去するためにうがいをしてもらう
3. 歯ブラシで歯を1、2本ずつ磨く
4. スポンジブラシは乾いた状態で使う
5. 部分床義歯はつけたまま行う

<details class="answer">
<summary>正解を見る</summary>

**正解：3**　1は誤嚥の危険、2の歯垢はうがいでは落ちません。4は粘膜を傷つけるので水で湿らせて絞ってから。5は義歯を外さないと金具の周りが磨けません。
</details>
</details>

## ③ 義歯の取り扱い【生活支援技術】

| 場面 | ○ 正解 | × よく出る誤り |
|---|---|---|
| 外す順 | **下顎から**外す | 上顎から外す（第25・35・37回で×） |
| 上顎の総義歯の外し方 | **後方を下げて**外す（第29回） | — |
| 入れる | 上顎から。**回転させながら**口に入れる | 回転させずまっすぐ入れる |
| 洗う | **毎食後**、**流水**で**義歯用ブラシ** | 歯磨き粉を使う（すり減る）／熱湯（変形）／スポンジブラシ |
| 保管 | **水（または洗浄剤）に全部つけて**保管 | 乾燥させる／半分だけつける |
| つける時間 | 日中は**つけておく** | 食事のときだけつける |

> 部分床義歯の**クラスプ（金具）**は汚れがたまりやすいので、**ブラシでしっかり**洗います（流水で軽く、は×）。

<details>
<summary>✏️ 解いてみよう（第35回）</summary>

総義歯の取扱いとして、最も適切なものはどれ？

1. 上顎から先に外す
2. 毎食後に洗う
3. スポンジブラシで洗う
4. 熱湯につけてから洗う
5. 乾燥させて保管する

<details class="answer">
<summary>正解を見る</summary>

**正解：2**　外すのは下顎から、洗うのは義歯用ブラシ、熱湯は変形のもと、保管は水の中です。
</details>
</details>
