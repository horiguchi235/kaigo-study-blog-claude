**この記事のポイント**

1. 標準予防策は「**汗以外の体液・排泄物・粘膜・傷のある皮膚**」を感染の危険ありとして扱う。
2. 手洗いは**1ケアごと・流水と液体石鹸**、手袋は**利用者ごとに交換**、タオル・コップは**共用しない**。
3. **ノロ＝冬・嘔吐物はマスクと手袋・次亜塩素酸**、**疥癬＝入浴は最後**、**MRSA＝接触感染予防策**、**結核＝胸部X線**、**レジオネラ＝循環式浴槽を塩素消毒**。

## ① 感染対策の基本【介護の基本／医療的ケア】

### スタンダードプリコーション（標準予防策）

| 感染の危険ありとして扱う ○ | 対象外 |
|---|---|
| 血液、**唾液**・痰などの分泌物、尿・便・嘔吐物、**粘膜**、**傷のある皮膚** | **汗**、傷のない皮膚、未使用の物品、経管栄養剤 |

### よく出る○×

| ○ | × |
|---|---|
| 手洗いは**介護行為ごと**に、**石鹸と流水**で | 消毒液に手を浸す |
| **液体石鹸**の方が望ましい | 固形石鹸を使う |
| おむつ交換は**使い捨て手袋**が基本、**利用者ごとに交換** | 手袋をしていれば手洗いは省略 |
| タオル・うがい用コップは**個人用** | 共用 |
| 発熱・下痢・嘔吐の職員は**業務を休む** | マスクをして業務 |
| 健康状態の異常は**すぐ看護職員などに報告** | 生活相談員に報告 |
| 感染対策委員会の開催は**義務** | 任意 |
| モップは**乾燥させて保管** | 湿らせておく |
| くしゃみは**ティッシュや袖で覆い、手を洗う** | 押さえた手でそのまま配膳 |

### 消毒と滅菌

| ○ | × |
|---|---|
| **滅菌**＝すべての微生物を死滅させる。**滅菌物には有効期限**がある | 消毒＝すべての微生物を死滅 |
| 消毒液は**混ぜない**（有毒ガスの危険） | 混ぜると効果的 |
| 手指消毒は**アルコール** | 次亜塩素酸ナトリウムで手指消毒 |
| 家庭では**煮沸**や熱水で**消毒** | 家庭で熱水滅菌 |

## ② 感染症別の対策【介護の基本】

| 感染症 | 押さえるポイント |
|---|---|
| **ノロウイルス** | **感染性胃腸炎**。**冬に多い**、**集団感染**しやすい。主に**経口感染**（嘔吐物の飛沫・乾燥した粉じんも）。嘔吐物・便の処理は**マスク・手袋・エプロン**、消毒は**次亜塩素酸ナトリウム**（アルコールは効きにくい） |
| **疥癬** | **ヒゼンダニ**が皮膚に寄生（マダニは×）。強いかゆみ・皮膚の変化。**入浴は最後**、衣類・寝具は**分けて洗う**。角化型（ノルウェー疥癬）は**個室** |
| **MRSA** | 保菌者がいても**接触感染予防策**（手洗い・手袋）。**レクへの参加制限・全員検査は不要**。入浴は**最後** |
| **結核** | **空気感染**（経皮感染は×）。予防は**年1回の胸部X線検査**、BCG。咳が続く人はマスク |
| **レジオネラ** | 水中で増える菌。**循環式浴槽は塩素系薬剤で消毒**、加湿器の水は**毎日入れ替えて**タンクを洗う |
| 日和見感染 | 抵抗力が落ちたときに弱い菌で発症（入院・入所で新たに発症するのは**院内感染**） |

## ＋α もう一歩：実務者研修レベルで覚えたいこと

過去問にはまだ出ていないけれど、実務者研修の確認テストでよく問われる、関連して覚えておきたい知識です。

- **標準予防策（スタンダード・プリコーション）**の対象＝**すべての人**の血液・体液・分泌物・**排泄物**・傷のある皮膚・粘膜（**汗は除く**）。
- 嘔吐物や排泄物に触れるときは**必ず手袋**。手洗いをすれば手袋はいらない、は×。使った**針はリキャップせず**専用容器へ。
- **口腔ケア**を充実させると、口の細菌が減り**感染症・誤嚥性肺炎の予防**になる。
- **点眼薬などは共有しない**。体調不良の職員は**早めに報告**する。
- **レジオネラ症**：汚染された水の細かい水滴（エアロゾル）を吸い込んで感染。**ワクチンはない**ので、浴槽・配管・**加湿器の清掃と水の管理**で防ぐ（家庭用加湿器は**毎日水を全部入れ替えてタンクを洗う**、継ぎ足しだけはNG）。
- **薬剤耐性菌**：抗菌薬が効きにくい菌。**MRSA**＝メチシリン耐性黄色ブドウ球菌、**MDRP**＝多剤耐性緑膿菌。菌がいても症状がない状態は**保菌**。対策は手指衛生と標準予防策、抗菌薬の適正使用。
- **洗浄・消毒・滅菌のちがい**：洗浄＝汚れを落とす／消毒＝病原体を減らす／**滅菌＝芽胞を含むすべての微生物をなくす**。滅菌物は**期限・包装の破れ・未開封**を確認し、開封したら無菌とはいえない。
- **消毒薬の種類**：アルコール系（エタノール＝手指・皮膚）、ヨウ素系（**ポビドンヨード＝皮膚・粘膜**。排泄物には使わない）、第四級アンモニウム塩（ベンザルコニウム塩化物など）、アルデヒド系（グルタラール＝器具）。濃度は**用途ごとに決められた濃度**で使う。
