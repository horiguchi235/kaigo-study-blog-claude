## この記事で対策できる科目

| 科目 | 過去15年の出題数 | この記事の章 |
|---|---|---|
| 介護の基本 | 10問 | ①感染対策の基本 ②感染症別の対策 |
| 医療的ケア | 2問 | ①標準予防策・消毒と滅菌 |

**結論を3行で**

1. 標準予防策は「**汗以外の体液・排泄物・粘膜・傷のある皮膚**」を感染の危険ありとして扱う。
2. 手洗いは**1ケアごと・流水と液体石鹸**、手袋は**利用者ごとに交換**、タオル・コップは**共用しない**。
3. **ノロ＝冬・嘔吐物はマスクと手袋・次亜塩素酸**、**疥癬＝入浴は最後**、**MRSA＝接触感染予防策**、**結核＝胸部X線**、**レジオネラ＝循環式浴槽を塩素消毒**。

## ① 感染対策の基本【介護の基本／医療的ケア】

### スタンダードプリコーション（標準予防策）（第31回）

| 感染の危険ありとして扱う ○ | 対象外 |
|---|---|
| 血液、**唾液**・痰などの分泌物、尿・便・嘔吐物、**粘膜**、**傷のある皮膚** | **汗**、傷のない皮膚、未使用の物品、経管栄養剤 |

### よく出る○×

| ○ | × |
|---|---|
| 手洗いは**介護行為ごと**に、**石鹸と流水**で | 消毒液に手を浸す |
| **液体石鹸**の方が望ましい（第28・36回） | 固形石鹸を使う |
| おむつ交換は**使い捨て手袋**が基本（第31回）、**利用者ごとに交換**（第36回） | 手袋をしていれば手洗いは省略 |
| タオル・うがい用コップは**個人用** | 共用 |
| 発熱・下痢・嘔吐の職員は**業務を休む**（第24・28回） | マスクをして業務 |
| 健康状態の異常は**すぐ看護職員などに報告** | 生活相談員に報告 |
| 感染対策委員会の開催は**義務** | 任意 |
| モップは**乾燥させて保管** | 湿らせておく |
| くしゃみは**ティッシュや袖で覆い、手を洗う** | 押さえた手でそのまま配膳 |

### 消毒と滅菌（第35回）

| ○ | × |
|---|---|
| **滅菌**＝すべての微生物を死滅させる。**滅菌物には有効期限**がある | 消毒＝すべての微生物を死滅 |
| 消毒液は**混ぜない**（有毒ガスの危険） | 混ぜると効果的 |
| 手指消毒は**アルコール** | 次亜塩素酸ナトリウムで手指消毒 |
| 家庭では**煮沸**や熱水で**消毒** | 家庭で熱水滅菌 |

## ② 感染症別の対策【介護の基本】

| 感染症 | 押さえるポイント |
|---|---|
| **ノロウイルス**（第25・26回） | **感染性胃腸炎**。**冬に多い**、**集団感染**しやすい。主に**経口感染**（嘔吐物の飛沫・乾燥した粉じんも）。嘔吐物・便の処理は**マスク・手袋・エプロン**、消毒は**次亜塩素酸ナトリウム**（アルコールは効きにくい） |
| **疥癬**（第27回） | **ヒゼンダニ**が皮膚に寄生（マダニは×）。強いかゆみ・皮膚の変化。**入浴は最後**、衣類・寝具は**分けて洗う**。角化型（ノルウェー疥癬）は**個室** |
| **MRSA**（第32回） | 保菌者がいても**接触感染予防策**（手洗い・手袋）。**レクへの参加制限・全員検査は不要**。入浴は**最後** |
| **結核**（第37回） | **空気感染**（経皮感染は×）。予防は**年1回の胸部X線検査**、BCG。咳が続く人はマスク |
| **レジオネラ**（第38回） | 水中で増える菌。**循環式浴槽は塩素系薬剤で消毒**、加湿器の水は**毎日入れ替えて**タンクを洗う |
| 日和見感染 | 抵抗力が落ちたときに弱い菌で発症（入院・入所で新たに発症するのは**院内感染**） |

<details>
<summary>✏️ 解いてみよう（第26回）</summary>

ノロウイルスによる感染症について、適切なものはどれ？

1. 冬より夏に多い
2. 集団感染になることは少ない
3. 感染経路は主に接触感染である
4. 消毒にはエタノール消毒液が有効である
5. 嘔吐物や便の処理にはマスクを着用する

<details class="answer">
<summary>正解を見る</summary>

**正解：5**　ノロウイルスは冬に多く、集団感染しやすい感染症です。主に口から入る経口感染で、消毒には次亜塩素酸ナトリウムを使います。
</details>
</details>

<details>
<summary>✏️ 解いてみよう（第32回）</summary>

施設でMRSAの保菌者が確認されたときの対応として、最も適切なものはどれ？

1. 入所者全員の保菌の有無を調べる
2. 接触感染予防策を実施する
3. 保菌者のレクリエーションへの参加を制限する
4. 保菌者は最初に入浴する
5. ふつうの消毒薬は効かない

<details class="answer">
<summary>正解を見る</summary>

**正解：2**　保菌しているだけなら発症していないので、手洗いなどの接触感染予防策で十分です。活動を制限するのは差別につながります。
</details>
</details>
