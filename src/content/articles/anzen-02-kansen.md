**この記事のポイント**

1. 標準予防策は「**汗以外の体液・排泄物・粘膜・傷のある皮膚**」を感染の危険ありとして扱う。
2. 手洗いは**1ケアごと・流水と液体石鹸**、手袋は**利用者ごとに交換**、タオル・コップは**共用しない**。消毒は「**アルコール＝手指**、**次亜塩素酸ナトリウム＝ノロ・環境**」の2本柱。
3. **ノロ＝冬・嘔吐物はマスクと手袋・次亜塩素酸**、**疥癬＝入浴は最後**、**MRSA＝接触感染予防策**、**結核＝空気感染・胸部X線で早期発見**、**レジオネラ＝循環式浴槽を塩素消毒**。

## ① 感染対策の基本

### 3原則と感染経路

**感染対策の3原則**：①感染源を取り除く、②感染経路を断つ、③抵抗力を高める。施設では「持ち込まない・持ち出さない・広げない」。

<fig name="kansen-keiro">

| 感染経路 | うつり方 | 主な例 |
|---|---|---|
| **空気感染** | 小さな粒（5μm未満）が空気中をただよい、吸い込む。ふつうのマスクでは防ぎきれないので**個室と換気**が基本 | **結核**・麻しん・水痘 |
| **飛沫感染** | せき・くしゃみの粒（5μm以上。1〜2mで落ちる） | **インフルエンザ**・新型コロナ・風しん |
| **接触感染** | 手や物を介してうつる | **MRSA**・**疥癬**・ノロウイルス |
| **経口感染** | 口から入る（食べ物・汚れた手） | **ノロウイルス**・**腸管出血性大腸菌（O157）** |
| 血液感染 | 血液・体液が傷口などから入る | B型肝炎・C型肝炎・HIV |

**ノロウイルスは「接触」と「経口」の両方**に出てきます。嘔吐物や便についたウイルスが手や物を介して（接触）、最後は口から入る（経口）からです。接触感染の例として挙げられることもありますが、試験で「主な感染経路」と聞かれたら**経口感染**です。

### スタンダードプリコーション（標準予防策）

**すべての人**の血液・体液を、感染のおそれがあるものとして扱う考え方です。

| 感染の危険ありとして扱う ○ | 対象外 |
|---|---|
| 血液、**唾液**・痰などの分泌物、尿・便・嘔吐物、**粘膜**、**傷のある皮膚** | **汗**、傷のない皮膚、未使用の物品、経管栄養剤 |

### よく出る○×

| ○ | × |
|---|---|
| 手洗いは**介護行為ごと**（1ケア1手洗い）に、**石鹸と流水**で15秒以上。親指・指先・指の間・手首まで | 消毒液に手を浸す |
| **液体石鹸**の方が望ましい | 固形石鹸を使う（共用で汚れやすい） |
| 嘔吐物・排泄物に触れるときは**必ず使い捨て手袋**、**利用者ごとに交換** | 手袋をしていれば手洗いは省略 |
| 防護具を外すときは、いちばん汚れている**手袋から**外し、外したら手を洗う | 手袋を最後に外す |
| 使った**針はリキャップせず**専用容器へ | キャップをはめ直してから捨てる |
| タオル・うがい用コップ・点眼薬は**個人用** | 共用 |
| 発熱・下痢・嘔吐の職員は**早めに報告し、業務を休む** | マスクをして業務 |
| 利用者の健康状態の異常は**すぐ看護職員などに報告** | 生活相談員に報告 |
| 感染対策委員会の開催は**義務** | 任意 |
| モップは**乾燥させて保管** | 湿らせておく |
| くしゃみは**ティッシュや袖で覆い、手を洗う** | 押さえた手でそのまま配膳 |
| **口腔ケア**で口の細菌を減らす（感染症・誤嚥性肺炎の予防） | — |

## ② 洗浄・消毒・滅菌

| 言葉 | 意味 |
|---|---|
| 洗浄 | 汚れを落とす（消毒・滅菌の前に必ず行う） |
| **消毒** | 害のある微生物を**減らす・弱める**（すべてではない） |
| **滅菌** | **芽胞**（熱や薬に強い、殻をかぶった状態の菌）を含む**すべての微生物をなくす** |

### 消毒薬は2本柱で覚える

| 消毒薬 | 使う所 | 注意 |
|---|---|---|
| **アルコール**（消毒用エタノール） | **手指**・皮膚 | **ノロウイルスには効きにくい**（ノロのときの手洗いは**流水と石鹸**）。粘膜や傷には使わない。引火に注意 |
| **次亜塩素酸ナトリウム** | **ノロ**の嘔吐物・便、ドアノブ・手すりなどの**環境** | 手指には使わない。**金属を腐食**させる。**酸性の洗剤と混ぜない**（有毒ガス） |

- 次亜塩素酸ナトリウムの濃度：**嘔吐物・便のついた所は0.1％**、ドアノブ・手すりなどは**0.02％**。
- 熱水消毒は**80℃で10分**（食器・リネンなどの一般的な目安。ノロウイルスで汚れたリネンは**85℃で1分以上**）。そのほかの消毒薬も、用途ごとに決められた濃度で使う。

| ○ | × |
|---|---|
| **滅菌**＝すべての微生物を死滅させる | 消毒＝すべての微生物を死滅させる |
| **滅菌物には有効期限**がある。期限・包装の破れ・未開封を確認し、開封したら無菌とはいえない | 一度開けた滅菌物も無菌のまま |
| 消毒液は**混ぜない**（有毒ガスの危険） | 混ぜると効果的 |
| 手指消毒は**アルコール** | 次亜塩素酸ナトリウムで手指消毒 |
| 家庭では**煮沸**や熱水で**消毒** | 家庭で熱水滅菌 |

## ③ 感染症別の対策

| 感染症 | 押さえるポイント |
|---|---|
| **ノロウイルス** | **感染性胃腸炎**。**冬に多い**、**集団感染**しやすい。主に**経口感染**（嘔吐物の飛沫・乾燥した粉じんも）。嘔吐物・便の処理は**マスク・手袋・エプロン**、消毒は**次亜塩素酸ナトリウム**（アルコールは効きにくい）。食品は中心部を**85〜90℃で90秒以上**加熱 |
| **疥癬** | **ヒゼンダニ**が皮膚に寄生（マダニは×）。強いかゆみ・皮膚の変化。**入浴は最後**、衣類・寝具は**分けて洗う** |
| **MRSA** | 抗菌薬が効きにくい**薬剤耐性菌**の1つ（メチシリン耐性黄色ブドウ球菌）。菌がいても症状のない**保菌者**には**接触感染予防策**（手洗い・手袋）。**レクへの参加制限・全員検査は不要**。入浴は**最後** |
| **結核** | **空気感染**（経皮感染は×）。高齢者は症状がはっきりしないことも多い。**年1回の胸部X線検査**は**早期発見**のため。咳が続く人はマスク |
| **レジオネラ** | 汚染された水の細かい水滴（エアロゾル）を吸い込んで感染。**ワクチンはない**。**循環式浴槽は塩素系薬剤で消毒**、家庭用加湿器は**毎日水を全部入れ替えてタンクを洗う**（継ぎ足しは×） |
| **腸管出血性大腸菌（O157）** | 食べ物から感染（経口）。**75℃で1分以上**の加熱で予防 |
| B型肝炎など | 血液・体液から感染。針刺しに注意（**リキャップしない**）。血液に触れるときは手袋 |

- **疥癬の2つの型**：ふつうの疥癬はダニの数が少なく、**個室にしなくてよい**。**角化型疥癬（ノルウェー疥癬）**はダニの数が非常に多く感染力が強いので、**個室**にし、衣類・寝具は**50℃以上で10分**程度の熱処理をする。
- **日和見感染**：抵抗力が落ちた人が、ふだんは害の少ない弱い菌で発症すること（入院・入所してから新たに発症するのは**院内感染**）。
- MRSAのほか、**MDRP**（多剤耐性緑膿菌）も薬剤耐性菌。対策は手指衛生と標準予防策、抗菌薬の適正使用。

### ノロウイルスの嘔吐物処理の手順

1. 周りの人を遠ざけ、窓を開けて**換気**する
2. **使い捨てのマスク・手袋・エプロン（ガウン）**をつける
3. 嘔吐物を**外側から内側へ**、静かに拭き取る（飛び散らせない）
4. 拭き取った所を**0.1％の次亜塩素酸ナトリウム**で消毒する
5. ごみはビニール袋に密閉する。防護具は手袋から外し、**流水と石鹸で手を洗う**

嘔吐物が乾くと、ウイルスが舞い上がって吸い込む危険があるので、**すぐに**処理します。くわしくは[洗濯・しみ抜き・掃除・ノロウイルス](../sumai-03-sentaku/)にもあります。

### 高齢者の予防接種

65歳以上の定期接種（B類）は、**インフルエンザ**・**新型コロナ**・**肺炎球菌**、**帯状疱疹**（2025年4月から）。新型コロナは2023年5月から5類感染症です。
