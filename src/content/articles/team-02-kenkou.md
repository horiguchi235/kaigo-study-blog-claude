## ① 腰痛予防・ストレス・バーンアウト・ハラスメント【介護の基本／人間関係とコミュニケーション】

### 腰痛予防（第26・29回）

| ○ | × |
|---|---|
| **静的ストレッチング**（ゆっくり伸ばして保つ） | — |
| ベッドの高さは**介護者の腰**くらいに | 腰より低くする |
| 体をひねらない、福祉用具を使う | 前傾中腰が基本／45度ひねる／抱え上げる |
| 健康診断は**配置前と6か月以内ごと**（腰痛健診） | 長時間の座位は負担がない／全員一律にコルセット |

### ストレスとメンタルヘルス

| 場面・用語 | ○ |
|---|---|
| ストレスマネジメント（第28回） | **自分に合った対処法**をもつ。人に相談する（仕事に没頭・一人で解決・目をそらすは×） |
| 初めての看取りで無力感、落ち込み（第27回） | **看取りのケアについてチームで話し合う**（デスカンファレンス） |
| **燃え尽き症候群（バーンアウト）**（第31回） | **無気力感・疲労感・無感動**。熱心な人ほどなりやすい |
| 感染症流行時に職員の精神的健康を守る組織的マネジメント（第36回） | **バーンアウトを防止**する |

### ストレスチェック制度（第30・38回）

| ○ | × |
|---|---|
| **心理的な負担の程度を把握**し、**メンタルヘルス不調を未然に防ぐ** | — |
| **常時50人以上**の事業場に義務 | 30人以上・100人の事業場は免除 |
| **年1回** | 2年・3年に1回 |
| 実施者は**医師・保健師など** | 上司が実施 |
| 結果は**本人に直接通知**（本人の同意なく事業者に渡さない） | 介護主任に提供される |
| 高ストレスなら**本人の申出で医師の面接指導** | 産業医による治療が必須 |

### ハラスメント（第34回）

利用者から暴力を受けた → 「**やめてください**」と伝え、**上司に相談**する。黙って耐える・笑顔で聞く・サービス外のことをやってしまう、は×。

## ② 労働の法律【介護の基本】

| 法律 | 中身 |
|---|---|
| **労働基準法** | 労働条件の**最低基準**、**法定労働時間**（1日8時間・週40時間）。**業務上のけがの療養費は使用者が負担**（第24回） |
| **労働安全衛生法** | **健康診断を年1回以上**（第37回）、**衛生委員会**（常時**50人以上**）、**ストレスチェック**、**労働者も労災防止に協力**（第28回） |
| 労働者災害補償保険法 | 業務上・通勤中の災害への保険給付（労働条件を定める法律ではない） |
| **育児・介護休業法** | 育児休業・介護休業・介護休暇など |
| 男女雇用機会均等法 | 妊娠・出産を理由とする不利益取扱いの禁止 |

### 介護休業と介護休暇（第25・30・37回）

| | **介護休業** | **介護休暇** |
|---|---|---|
| 期間 | 対象家族1人につき**通算93日**、**3回まで分割** | **年5日**（2人以上なら10日） |
| 使いみち | まとまった介護の体制づくり | **通院の付き添い**・ケアマネとの打ち合わせなど |
| 対象 | **2週間以上**常に介護が必要な家族（祖父母・兄弟姉妹・孫も、同居・扶養の要件なし） | 同左 |

### 育児休業

- 原則**子が1歳まで**（最長2歳）。**出生時育児休業（産後パパ育休）は出生後8週間以内に4週間まで**
- **3歳まで**短時間勤務、**子の看護休暇は小学校3年生修了まで年5日**（2人以上10日）

<details>
<summary>✏️ 解いてみよう（第38回）</summary>

介護福祉職が受けるストレスチェック制度に関する記述として、最も適切なものはどれ？

1. 3年に1回の実施が義務づけられている
2. 労働者が常時100名の事業場は受検が免除される
3. 結果は労務管理を行う介護主任に提供され、面接指導に活用する
4. 心理的な負担の程度を把握するためのものである
5. 高ストレスと判定された場合は、産業医による治療が必須である

<details class="answer">
<summary>正解を見る</summary>

**正解：4**　年1回、常時50人以上の事業場で実施します。結果は本人に通知され、本人の同意なしに職場に渡されることはありません。高ストレスの場合は本人の申出で医師の面接指導を受けます。
