1. 腰痛予防は**静的ストレッチング**。前かがみの中腰・ひねり・抱え上げは×。
2. ストレスチェックは**年1回**、**常時50人以上**の事業場に義務。目的は**メンタルヘルス不調の未然防止**、結果は**本人に通知**。

## ① 腰痛予防・ストレス・バーンアウト・ハラスメント【介護の基本／人間関係とコミュニケーション】

### 腰痛予防

| ○ | × |
|---|---|
| **静的ストレッチング**（ゆっくり伸ばして保つ） | — |
| ベッドの高さは**介護者の腰**くらいに | 腰より低くする |
| 体をひねらない、福祉用具を使う | 前傾中腰が基本／45度ひねる／抱え上げる |

### ストレスとメンタルヘルス

| 場面・用語 | ○ |
|---|---|
| ストレスマネジメント | **自分に合った対処法**をもつ。人に相談する（仕事に没頭・一人で解決・目をそらすは×） |
| 初めての看取りで無力感、落ち込み | **看取りのケアについてチームで話し合う**（デスカンファレンス） |
| **燃え尽き症候群（バーンアウト）** | **無気力感・疲労感・無感動**。熱心な人ほどなりやすい |
| 感染症流行時に職員の精神的健康を守る組織的マネジメント | **バーンアウトを防止**する |

### ストレスチェック制度

| ○ | × |
|---|---|
| **心理的な負担の程度を把握**し、**メンタルヘルス不調を未然に防ぐ** | — |
| **常時50人以上**の事業場に義務 | 30人以上・100人の事業場は免除 |
| **年1回** | 2年・3年に1回 |
| 実施者は**医師・保健師など** | 上司が実施 |
| 結果は**本人に直接通知**（本人の同意なく事業者に渡さない） | 介護主任に提供される |
| 高ストレスなら**本人の申出で医師の面接指導** | 産業医による治療が必須 |

## ② 労働の法律【介護の基本】

| 法律 | 中身 |
|---|---|
| **労働基準法** | 労働条件の**最低基準**、**法定労働時間**（1日8時間・週40時間）。**業務上のけがの療養費は使用者が負担** |
| **労働安全衛生法** | **健康診断を年1回以上**、**衛生委員会**（常時**50人以上**）、**ストレスチェック**、**労働者も労災防止に協力** |
| 労働者災害補償保険法 | 業務上・通勤中の災害への保険給付（労働条件を定める法律ではない） |
| **育児・介護休業法** | 育児休業・介護休業・介護休暇など |
| 男女雇用機会均等法 | 妊娠・出産を理由とする不利益取扱いの禁止 |

### 介護休業と介護休暇

| | **介護休業** | **介護休暇** |
|---|---|---|
| 期間 | 対象家族1人につき**通算93日**、**3回まで分割** | **年5日**（2人以上なら10日） |
| 使いみち | まとまった介護の体制づくり | **通院の付き添い**・ケアマネとの打ち合わせなど |
| 対象 | **2週間以上**常に介護が必要な家族（祖父母・兄弟姉妹・孫も、同居・扶養の要件なし） | 同左 |

### 育児休業

- 原則**子が1歳まで**（最長2歳）。**出生時育児休業（産後パパ育休）は出生後8週間以内に4週間まで**
- **3歳まで**短時間勤務、**子の看護休暇は小学校3年生修了まで年5日**（2人以上10日）

## ＋α もう一歩：実務者研修レベルで覚えたいこと

過去問にはまだ出ていないけれど、実務者研修の確認テストでよく問われる、関連して覚えておきたい知識です。

- **労働の法律**：**労働基準法＝労働条件の最低基準**（労働時間・休日・賃金・**産前産後休業**）／**労働安全衛生法**＝労働災害の防止・健康診断・快適な職場／**雇用保険法**＝失業時の給付・再就職支援／労働者派遣法。
- **産前産後休業**（労働基準法）：**産前6週間**（双子以上は14週間）は請求すれば休める／**産後8週間は原則働けない**（6週間を過ぎて本人が希望し医師が認めれば働ける）。**育児休業・介護休業は育児・介護休業法**で、産休とは別。
- **介護休業と介護休暇**：対象は**2週間以上常に介護が必要**な家族。**介護休業＝対象家族1人につき通算93日（3回まで分割）**／**介護休暇＝年5日（2人以上なら10日）、通院の付き添いや手続きにも使える**。
- **労災保険**：**パート・アルバイトも対象**。会社の用事での外出中の事故＝**業務災害**、通勤途中の事故＝**通勤災害**。保険料は**全額事業主負担**で、会社が保険料を滞納していても労働者は給付を受けられる。

## 📘 もう一歩先へ：過去問にはまだ出ていない重要ポイント

過去問ではまだ問われていないものの、テキストで重要語として扱われ、今後出題されてもおかしくない関連知識です。過去問の論点とセットで押さえておくと、初めて見る選択肢にも対応できます。

- **職場の腰痛予防対策指針**：抱え上げは**原則として人力で行わない**（福祉用具を使う）。人力で持ち上げる重さのめやすは**男性で体重の約40％以下**、女性はその**約60％**まで。
- **ストレスチェック**＝労働者**50人以上**の事業所は年1回の実施が義務。
- 安全衛生の体制（労働安全衛生法）：**50人以上で産業医・衛生管理者・衛生委員会**、10〜49人は**衛生推進者**。
- **感情労働**＝自分の感情をコントロールしながら相手に合わせる仕事。**バーンアウト（燃え尽き症候群）**の予防に、自己覚知と職場の支え合いが大切。
- **介護休業**＝対象家族1人につき通算**93日・3回まで分割**、休業中は雇用保険の介護休業給付（賃金の67％）。**介護休暇**＝年5日（2人以上は10日）、時間単位でも取れる。
- **2025年問題**＝団塊の世代が全員75歳以上に。人材確保のため**介護ロボット・ICT**の活用が進められている。
