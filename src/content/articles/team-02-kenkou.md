**この記事のポイント**

1. 腰痛予防は**静的ストレッチング**。前かがみの中腰・ひねり・抱え上げは×。
2. ストレスチェックは**年1回**、**常時50人以上**の事業場に義務（2028年4月からは50人未満の事業場にも義務）。目的は**メンタルヘルス不調の未然防止**、結果は**本人に通知**。
3. **介護休業＝通算93日（3回まで分割）**、**介護休暇＝年5日**で**通院の付き添いにも使える**。

## ① 腰痛予防・ストレス・バーンアウト・ハラスメント

### 腰痛予防

| ○ | × |
|---|---|
| **静的ストレッチング**（ゆっくり伸ばして保つ） | — |
| ベッドの高さは**介護者の腰**くらいに | 腰より低くする |
| 体をひねらない、福祉用具を使う | 前傾中腰が基本／45度ひねる／抱え上げる |
| 同じ姿勢を長く続けない（座りっぱなしも腰の負担） | 長時間の座位は負担がない |
| 腰痛ベルト（コルセット）は**一人ひとりに合わせて**使うか判断する | 全員一律にコルセット |
| 健康診断は**配置前と6か月以内ごと**（腰痛健診） | — |

- 国の「職場における腰痛予防対策指針」では、介護での抱え上げは**原則として人力で行わない**（リフトなどの福祉用具を使う）。やむを得ず人力で持ち上げる重さのめやすは、**男性は体重の約40％以下**、<strong>女性は男性の基準のさらに約60％</strong>まで。

### ストレスとメンタルヘルス

| 場面・用語 | ○ |
|---|---|
| ストレスマネジメント | **自分に合った対処法**をもつ。人に相談する（仕事に没頭・一人で解決・目をそらすは×） |
| 初めての看取りで無力感、落ち込み | **看取りのケアについてチームで話し合う**（**デスカンファレンス**＝看取りのあとに、行ったケアをふり返る会議） |
| **燃え尽き症候群（バーンアウト）** | **無気力感・疲労感・無感動**。熱心な人ほどなりやすい |
| 感情労働 | 自分の感情をコントロールしながら相手に合わせる仕事。バーンアウトの予防に、**自己覚知と職場の支え合い**が大切 |
| 感染症流行時に職員の精神的健康を守る組織的マネジメント | **バーンアウトを防止**する |

### ストレスチェック制度

| ○ | × |
|---|---|
| **心理的な負担の程度を把握**し、**メンタルヘルス不調を未然に防ぐ** | — |
| **常時50人以上**の事業場に義務（2025年5月公布の法改正で**2028年4月から50人未満の事業場にも義務**。施行日は2026年6月の政令で決定） | 30人以上・100人の事業場は免除 |
| **年1回** | 2年・3年に1回 |
| 実施者は**医師・保健師など** | 上司が実施 |
| 結果は**本人に直接通知**（本人の同意なく事業者に渡さない） | 介護主任に提供される |
| 高ストレスなら**本人の申出で医師の面接指導** | 産業医による治療が必須 |

### ハラスメント

利用者から暴力を受けた → 「**やめてください**」と伝え、**上司に相談**する。黙って耐える・笑顔で聞く・サービス外のことをやってしまう、は×。

ハラスメントは個人で我慢するものではなく、**組織で対応する**ものです。2021年度の介護報酬改定で、すべての介護サービス事業者に、職場のハラスメント対策（方針を決める・相談窓口をつくるなど）が義務づけられ、利用者や家族からのハラスメントへの対策も求められています。

## ② 労働の法律

| 法律 | 中身 |
|---|---|
| **労働基準法** | 労働条件（労働時間・休日・賃金）の**最低基準**、**法定労働時間**（法律で決められた上限：1日8時間・週40時間）。**産前産後休業**。**業務上のけがの療養費は使用者が負担** |
| **労働安全衛生法** | 労働災害の防止・快適な職場。**健康診断を年1回以上**、**ストレスチェック**、**労働者も労災防止に協力**。常時**50人以上**の事業場は**産業医・衛生管理者・衛生委員会**（職場の衛生について話し合う委員会）、10〜49人は衛生推進者 |
| 労働者災害補償保険法（労災保険） | 業務上・通勤中の災害への保険給付（労働条件を定める法律ではない）。**パート・アルバイトも対象**、保険料は**全額事業主負担** |
| **育児・介護休業法** | 育児休業・介護休業・介護休暇など |
| 雇用保険法 | 失業時の給付・再就職支援、**介護休業給付** |
| 男女雇用機会均等法 | 妊娠・出産を理由とする不利益取扱いの禁止 |

- 労災：会社の用事で外出中の事故＝**業務災害**、通勤途中の事故＝**通勤災害**。会社が保険料を滞納していても、労働者は給付を受けられる。
- **産前産後休業**（労働基準法）：**産前6週間**（双子以上は14週間）は請求すれば休める。**産後8週間は原則働けない**（6週間を過ぎ、本人が希望し医師が認めれば働ける）。育児休業・介護休業（育児・介護休業法）とは別のもの。

### 介護休業と介護休暇

| | **介護休業** | **介護休暇** |
|---|---|---|
| 期間 | 対象家族1人につき**通算93日**、**3回まで分割** | **年5日**（2人以上なら10日） |
| 使いみち | まとまった介護の体制づくり | **通院の付き添い**・ケアマネとの打ち合わせなど |
| 対象 | **2週間以上**常に介護が必要な家族（祖父母・兄弟姉妹・孫も、同居・扶養の要件なし） | 同左 |
| そのほか | 休業中は雇用保険の**介護休業給付**（賃金の67％） | **時間単位**でも取れる |

### 育児休業

- 原則**子が1歳まで**（最長2歳）。**出生時育児休業（産後パパ育休）は出生後8週間以内に4週間まで**
- **3歳まで**短時間勤務
- **子の看護等休暇**は**小学校3年生修了まで年5日**（2人以上10日）。2025年4月に「子の看護休暇」から名前が変わり、病気・けがの看護のほか、感染症による学級閉鎖や入園（入学）式・卒園式にも使えるようになった

## ③ 家族介護者と高齢者世帯の統計（国民生活基礎調査）

介護者の数値は2022年 国民生活基礎調査（3年ごとの大規模調査）によるものです。2024年は簡易調査で介護の項目がないため、2022年が最新です。世帯の傾向は2024年調査でも同じです（65歳以上の者のいる世帯は単独世帯と夫婦のみ世帯がほぼ並ぶ）。

| ○ | × |
|---|---|
| 65歳以上の者のいる世帯は**夫婦のみ世帯・単独世帯**が多い。**単独世帯は増えている** | 三世代世帯が半数超 |
| 同居の主な介護者は**60歳以上が男女とも半数以上**（老老介護） | 子の配偶者が最多 |
| 同居の主な介護者の**男性は約3割** | 1割程度 |
| 介護者の悩み・ストレスの原因は「**家族の病気や介護**」が最多 | — |

- **2025年問題**：団塊の世代が**2025年に全員75歳以上**になった。次の山は**2040年問題**（高齢者人口がピーク近くになる一方、支え手の現役世代が急に減る）。人材確保のため、**介護ロボット・ICT**の活用が進められている。
