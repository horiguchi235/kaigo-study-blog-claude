**結論を3行で**

1. **冷や汗を伴う激しい胸痛が30分以上**続く＝**心筋梗塞**。数分で治まるのは狭心症。高齢者は**痛みを訴えない**こともある。
2. 高齢者は**低血糖に気づきにくい**。「ふらふら・冷や汗」があれば**すぐ看護師・医師へ**。
3. 高齢者の肺炎は**高熱が出ないことも多い**。「元気がない・食欲がない・呼吸が速い」で疑う。

## ① 心臓・血圧【発達と老化の理解】

| 病気 | 試験に出る特徴 |
|---|---|
| **心筋梗塞** | **冷や汗を伴う激しい胸痛が30分以上**（第36回）、**ニトログリセリンが効かない**、安静でも治まらない。**高齢になるほど痛みを訴えない**人が増える（第24回） |
| 狭心症 | 階段などで胸が痛むが、**休むと数分で治まる**。ニトログリセリンが効く |
| **心房細動** | 脈が不規則で**頻脈**になりやすい（第26回）。心臓に血栓ができ**脳梗塞**の原因に。高齢になるほど多く、高血圧と関連 |
| **心不全** | 息切れ・**チアノーゼ**（第32回）・**下肢のむくみ**（全身にも）。**横になると苦しく、座ると楽**（起座呼吸） |
| **高血圧** | **140/90mmHg以上**（Ⅰ度）（第25回） |

<details>
<summary>✏️ 解いてみよう（第36回・事例）</summary>

高血圧と高コレステロール血症を指摘されていた80歳の男性。最近、階段で胸が痛んでも休むと治まっていた。今朝、朝食後から冷や汗を伴う激しい胸痛が30分しても治まらない。考えられる状況はどれ？

1. 喘息
2. 肺炎
3. 脳梗塞
4. 心筋梗塞
5. 逆流性食道炎

<details class="answer">
<summary>正解を見る</summary>

**正解：4**　「休むと治まる胸痛」は狭心症、それが「30分以上続く激しい痛み＋冷や汗」に変わったら心筋梗塞です。すぐに救急要請します。
</details>
</details>

## ② 糖尿病・低血糖・甲状腺・生活習慣病【発達と老化の理解／生活支援技術】

### 高齢者の糖尿病（第33回）

| ○ | × |
|---|---|
| **低血糖の自覚症状に乏しい** | アミラーゼの作用不足が原因（実際は**インスリン**） |
| HbA1cの目標は若年者より**高め**（低血糖を避ける） | 低めが推奨 |
| のどの渇き（口渇感）を**感じにくい** | 口渇感が強い |
| 運動療法は**有効** | 運動は避ける |

### 低血糖のサイン

**ふらふらする・冷や汗・空腹感・動悸・手のふるえ・意識がぼんやり**

| 場面 | ○ 正解 |
|---|---|
| インスリン治療中、受診が長引き昼食が遅れ「頭がふらふら」・冷や汗（第29回） | **すぐに看護師に血糖を測定してもらう** |
| 夕方ひどくおなかが空き「ふわふわ」、クッキーで良くなる（腎機能も低下）（第26回） | **早めに主治医に相談**（薬が効きすぎている可能性） |

> ×の選択肢：すぐにインスリンを打つ／内服薬を飲む／様子を見る／甘いものを禁止する。

### そのほか

- **甲状腺機能低下症**：**むくみ（浮腫）**・寒がり・無気力・便秘（第29回）。動悸・下痢・いらいら・手のふるえは**機能亢進症**
- **高コレステロール血症**の予防：**食物繊維**の多い食品（第29回）。高血圧の予防はカリウムを**多く**、骨粗鬆症はビタミンKを**多く**

## ③ 肺炎・誤嚥性肺炎【発達と老化の理解】

| ○ | × |
|---|---|
| **誤嚥性肺炎**を起こしやすい（第34回） | 意識障害になることはない |
| 予防には**口腔ケア**が有効（第27回） | 37.5℃未満なら肺炎ではない |
| 症状がはっきりしない（**微熱・元気がない・食欲低下**） | 初発症状は高熱 |
| **呼吸数が増える**（頻呼吸） | 呼吸数は減る・頻呼吸はまれ |
| インフルエンザに合併しやすい | 咳・痰はまれ |

**事例（第28回）**：脳梗塞の後遺症で食事中によくむせる人が、元気がなく食欲も半分、**呼吸数24回/分、37.4℃** → **誤嚥性肺炎**。

**嚥下障害**のサイン：**食事のときにむせる**（第30回）。

## ④ 脱水・下痢・めまい【発達と老化の理解／生活支援技術】

### 脱水

| ○ 脱水のときの状態 | × |
|---|---|
| **めまい**・ふらつき（第27回） | 徐脈・血圧の上昇 |
| **体重が減る**（第35回） | 体重の増加・皮膚の張りが増す |
| 頻脈・血圧の低下・口や皮膚の乾燥 | 起立時に血圧が上がる |
| 高齢者は**のどの渇きを感じにくく**、**体内の水分量が少ない** | 口渇感を感じやすい・水分量が多い |
| **下痢**も原因になる | 下痢が原因になることはまれ |

**下痢が続く在宅の高齢者**で最も緊急度が高い情報 → **意識の状態**（第31回）。

### めまい（第28・29回）

| 種類 | 特徴 |
|---|---|
| **良性発作性頭位めまい症** | 頭を動かすと**ぐるぐる回る**（回転性） |
| メニエール病 | 回転性めまい＋**耳鳴り・難聴** |
| 起立性低血圧 | **立ちくらみ** |
| 脳梗塞（小脳など） | めまいが**起こることがある** |

めまいや立ちくらみがある人への助言：**転んでもけがをしないよう部屋を片づける**。勢いよく立つ・首を振る体操・薬を勧めるのは×。
