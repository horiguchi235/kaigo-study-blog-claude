**この記事のポイント**

1. **冷や汗を伴う激しい胸痛が30分以上**続く＝**心筋梗塞**。数分で治まるのは狭心症。高齢者は**痛みを訴えない**こともある。
2. 高齢者は**低血糖に気づきにくい**。「ふらふら・冷や汗」があれば**すぐ看護師・医師へ**。
3. 高齢者の肺炎は**高熱が出ないことも多い**。「元気がない・食欲がない・呼吸が速い」で疑う。

## ① 心臓・血圧

| 病気 | 試験に出る特徴 |
|---|---|
| **心筋梗塞** | **冷や汗を伴う激しい胸痛が30分以上**、**ニトログリセリンが効かない**、安静でも治まらない。**高齢になるほど痛みを訴えない**人が増える |
| 狭心症 | 階段などで胸が痛むが、**休むと数分で治まる**。ニトログリセリンが効く |
| **心房細動** | 脈が不規則で**頻脈**になりやすい。心臓に血栓ができ**脳梗塞**の原因に。高齢になるほど多く、高血圧と関連 |
| **心不全** | 息切れ・**チアノーゼ**・**下肢のむくみ**（全身にも）。**横になると苦しく、座ると楽**（起座呼吸） |
| **高血圧** | **140/90mmHg以上**（Ⅰ度） |

## ② 糖尿病・低血糖・甲状腺・生活習慣病

### 高齢者の糖尿病

| ○ | × |
|---|---|
| **低血糖の自覚症状に乏しい** | アミラーゼの作用不足が原因（実際は**インスリン**） |
| HbA1cの目標は若年者より**高め**（低血糖を避ける） | 低めが推奨 |
| のどの渇き（口渇感）を**感じにくい** | 口渇感が強い |
| 運動療法は**有効** | 運動は避ける |

### 低血糖のサイン

**ふらふらする・冷や汗・空腹感・動悸・手のふるえ・意識がぼんやり**

| 場面 | ○ 正解 |
|---|---|
| インスリン治療中、受診が長引き昼食が遅れ「頭がふらふら」・冷や汗 | **すぐに看護師に血糖を測定してもらう** |
| 夕方ひどくおなかが空き「ふわふわ」、クッキーで良くなる（腎機能も低下） | **早めに主治医に相談**（薬が効きすぎている可能性） |

> ×の選択肢：すぐにインスリンを打つ／内服薬を飲む／様子を見る／甘いものを禁止する。

### そのほか

- **甲状腺機能低下症**：**むくみ（浮腫）**・寒がり・無気力・便秘。動悸・下痢・いらいら・手のふるえは**機能亢進症**
- **高コレステロール血症**の予防：**食物繊維**の多い食品。高血圧の予防はカリウムを**多く**、骨粗鬆症はビタミンKを**多く**

## ③ 肺炎・誤嚥性肺炎

| ○ | × |
|---|---|
| **誤嚥性肺炎**を起こしやすい | 意識障害になることはない |
| 予防には**口腔ケア**が有効 | 37.5℃未満なら肺炎ではない |
| 症状がはっきりしない（**微熱・元気がない・食欲低下**） | 初発症状は高熱 |
| **呼吸数が増える**（頻呼吸） | 呼吸数は減る・頻呼吸はまれ |
| インフルエンザに合併しやすい | 咳・痰はまれ |

**事例**：脳梗塞の後遺症で食事中によくむせる人が、元気がなく食欲も半分、**呼吸数24回/分、37.4℃** → **誤嚥性肺炎**。

**嚥下障害**のサイン：**食事のときにむせる**。

## ④ 脱水・下痢・めまい

### 脱水

| ○ 脱水のときの状態 | × |
|---|---|
| **めまい**・ふらつき | 徐脈・血圧の上昇 |
| **体重が減る** | 体重の増加・皮膚の張りが増す |
| 頻脈・血圧の低下・口や皮膚の乾燥 | 起立時に血圧が上がる |
| 高齢者は**のどの渇きを感じにくく**、**体内の水分量が少ない** | 口渇感を感じやすい・水分量が多い |
| **下痢**も原因になる | 下痢が原因になることはまれ |

**下痢が続く在宅の高齢者**で最も緊急度が高い情報 → **意識の状態**。

### めまい

| 種類 | 特徴 |
|---|---|
| **良性発作性頭位めまい症** | 頭を動かすと**ぐるぐる回る**（回転性） |
| メニエール病 | 回転性めまい＋**耳鳴り・難聴** |
| 起立性低血圧 | **立ちくらみ** |
| 脳梗塞（小脳など） | めまいが**起こることがある** |

めまいや立ちくらみがある人への助言：**転んでもけがをしないよう部屋を片づける**。勢いよく立つ・首を振る体操・薬を勧めるのは×。

## ⑤ 心臓・血管・呼吸器・腎臓の病気をもう少し詳しく

- **狭心症**＝**冠動脈が狭くなり**、心臓の筋肉が一時的に酸素不足になる病気。発作は**数分〜15分程度**で、安静や処方された<strong>ニトログリセリン（舌下）</strong>でおさまりやすい。
- **心筋梗塞**＝冠動脈が詰まって心筋が**壊死**する。**30分以上続く強い胸痛・冷や汗・呼吸困難**、ニトログリセリンが効かない → **すぐ救急車**。
- 高齢者や糖尿病の人は、心筋梗塞でも**強い胸痛がない**ことがある（息苦しさ・吐き気・だるさだけのことも）。
- **狭心症**＝冠動脈が一時的に狭くなる。発作は数分、**ニトログリセリン（舌下）で治まる**。**心筋梗塞**＝冠動脈が詰まり心筋が壊死。**30分以上続く激しい胸痛、ニトログリセリンが効かない**。高齢者は痛みを訴えないこともある。
- **心房細動**：心房が細かく不規則に動き、できた血栓が脳に飛ぶと**脳塞栓**。予防に血液を固まりにくくする薬（ワルファリンなど）→**出血しやすい**ので打撲に注意。
- **心不全**＝心臓のポンプ機能低下。息切れ・むくみ・**体重増加**・尿量減少。**夜間の急な呼吸困難**は起座位で楽になる。
- **高血圧**：高齢者は収縮期（上）の血圧が高いタイプが多く、原因不明の**本態性高血圧**がほとんど。治療は**減塩**・運動・減量と降圧薬。
- **糖尿病**：1型＝インスリンが出ない（若い人、生活習慣と無関係）、**2型**＝生活習慣が関係（日本の大多数）。**低血糖**＝冷や汗・ふるえ・ふらつき→糖分をとってもらい医療職に連絡。
- **COPD**＝主な原因は喫煙。**口すぼめ呼吸・腹式呼吸**、在宅酸素療法（**火気厳禁**、酸素量を自分で変えない）。
- 腎臓病：**慢性腎不全**の原因で多いのは**糖尿病性腎症**。食事は**たんぱく質・塩分・カリウム・水分を制限**しつつエネルギーは確保。**ネフローゼ症候群**＝大量のたんぱく尿でむくむ。
