**この記事のポイント**

1. **冷や汗を伴う激しい胸痛が30分以上**続く＝**心筋梗塞**。数分で治まるのは狭心症。高齢者は**痛みを訴えない**こともある。
2. 高齢者は**低血糖に気づきにくい**。「ふらふら・冷や汗」があれば**すぐ看護師・医師へ**。
3. 高齢者の肺炎は**高熱が出ないことも多い**。「元気がない・食欲がない・呼吸が速い」で疑う。

## ① 心臓・血圧

<fig name="shinzou">

心臓の筋肉に酸素を届ける血管を**冠動脈**といいます。冠動脈が**狭くなる**のが狭心症、**詰まって**心筋が死んでしまう（壊死）のが心筋梗塞です。

| 病気 | 試験に出る特徴 |
|---|---|
| **心筋梗塞** | 冠動脈が**詰まり**心筋が壊死。**冷や汗を伴う激しい胸痛が30分以上**、**ニトログリセリン**（舌の下で溶かす胸痛の薬）**が効かない**、安静でも治まらない → **すぐ救急車**。**高齢者や糖尿病の人は痛みを訴えない**ことがある（息苦しさ・吐き気・だるさだけのことも） |
| 狭心症 | 冠動脈が一時的に**狭くなる**。階段などで胸が痛むが、**休むと数分（長くても15分程度）で治まる**。ニトログリセリン（舌下）が効く |
| **心房細動** | 心房が細かく不規則に動き、脈が不規則で**頻脈**になりやすい。心臓にできた血栓が脳に飛ぶと**脳梗塞**（脳塞栓）。予防の薬（ワルファリンなど血液を固まりにくくする薬）を飲む人は**出血しやすい**ので打撲に注意。高齢になるほど多く、高血圧と関連 |
| **心不全** | 心臓のポンプの力が落ちる。息切れ・**チアノーゼ**（唇や指先が紫色になる）・**下肢のむくみ**（全身にも）・**体重増加**・尿量の減少。**横になると苦しく、座ると楽**（起座呼吸）。夜間の急な呼吸困難も |
| **高血圧** | 診察室で**140/90mmHg以上**（Ⅰ度）、家庭で測ると**135/85mmHg以上**。高齢者は収縮期（上）の血圧が高いタイプが多く、原因のはっきりしない**本態性高血圧**がほとんど。治療は**減塩**・運動・減量と降圧薬 |

## ② 糖尿病・低血糖・甲状腺・生活習慣病

### 高齢者の糖尿病

糖尿病は、血糖を下げるホルモン**インスリン**が足りない・効きにくいため、血糖値が高くなる病気です。**1型**＝インスリンがほとんど出ない（若い人に多く、生活習慣と無関係）、**2型**＝生活習慣が関係（日本の大多数）。

| ○ | × |
|---|---|
| 原因は**インスリン**の作用不足 | アミラーゼ（でんぷんを分解する消化酵素）の作用不足が原因 |
| **低血糖の自覚症状に乏しい** | 低血糖に気づきやすい |
| HbA1c（過去1〜2か月の血糖の平均を表す値）の目標は若年者より**高め**（低血糖を避ける） | 低めが推奨 |
| のどの渇き（口渇感）を**感じにくい** | 口渇感が強い |
| 運動療法は**有効** | 運動は避ける |

### 低血糖のサイン

**ふらふらする・冷や汗・空腹感・動悸・手のふるえ・意識がぼんやり**

介護福祉職がまずすることは、**すぐ看護師・医師に連絡**して血糖を確かめてもらい、**指示に従って糖分（ブドウ糖など）をとってもらう**ことです。意識がはっきりしないときは、口から無理に食べさせません。

| 場面 | ○ 正解 |
|---|---|
| インスリン治療中、受診が長引き昼食が遅れ「頭がふらふら」・冷や汗 | **すぐに看護師に血糖を測定してもらう** |
| 夕方ひどくおなかが空き「ふわふわ」、クッキーで良くなる（腎機能も低下） | **早めに主治医に相談**（薬が効きすぎている可能性） |

> ×の選択肢：すぐにインスリンを打つ（さらに血糖が下がる）／内服薬を飲む／様子を見る／甘いものを禁止する（低血糖のときは糖分が必要）。

### そのほか

- **甲状腺機能低下症**（橋本病など）：**むくみ（浮腫）**・寒がり・無気力・便秘。**甲状腺機能亢進症**（バセドウ病など）：動悸・発汗・下痢・いらいら・手のふるえ・やせる・眼球突出。どちらも女性に多い
- 糖尿病の合併症（神経障害・網膜症・腎症）のうち、**糖尿病性腎症**は慢性腎不全・人工透析の原因で最も多い
- **高コレステロール血症**の予防：**食物繊維**の多い食品。高血圧の予防はカリウムを**多く**、骨粗鬆症はビタミンKを**多く**

## ③ 肺炎・誤嚥性肺炎

| ○ | × |
|---|---|
| **誤嚥性肺炎**を起こしやすい。予防には**口腔ケア**が有効 | 誤嚥は肺炎の原因にならない |
| **意識障害**（ぼんやりする）が出ることもある | 意識障害になることはない |
| 症状がはっきりしない（**微熱・元気がない・食欲低下**） | 初発症状は高熱／37.5℃未満なら肺炎ではない |
| **呼吸数が増える**（頻呼吸） | 呼吸数は減る・頻呼吸はまれ |
| **咳・痰**を伴うことが多い。**インフルエンザ**のあとに細菌性肺炎を起こしやすい（予防接種が有効） | 咳・痰はまれ |

**事例**：脳梗塞の後遺症で食事中によくむせる人が、元気がなく食欲も半分、**呼吸数24回/分、37.4℃** → **誤嚥性肺炎**。

**嚥下障害**のサイン：**食事のときにむせる**。

## ④ 脱水・下痢・めまい

### 脱水

| ○ 脱水のときの状態 | × |
|---|---|
| **めまい**・ふらつき | 徐脈・血圧の上昇 |
| **体重が減る** | 体重の増加・皮膚の張りが増す |
| 頻脈・血圧の低下・口や皮膚の乾燥 | 起立時に血圧が上がる |
| 高齢者は**のどの渇きを感じにくく**、**体内の水分量が少ない** | 口渇感を感じやすい・水分量が多い |
| **下痢**も原因になる | 下痢が原因になることはまれ |

**下痢が続く在宅の高齢者**で最も緊急度が高い情報 → **意識の状態**。

### めまい

| 種類 | 特徴 |
|---|---|
| **良性発作性頭位めまい症** | 頭を動かすと**ぐるぐる回る**（回転性） |
| メニエール病 | 回転性めまい＋**耳鳴り・難聴** |
| 起立性低血圧 | **立ちくらみ** |
| 脳梗塞（小脳など） | めまいが**起こることがある** |

めまいや立ちくらみがある人への助言：**転んでもけがをしないよう部屋を片づける**。勢いよく立つ・首を振る体操・薬を勧めるのは×。

高齢者の脱水について、最も適切なものはどれ？

1. 若い人よりのどの渇きを感じやすい
2. 体内の水分量は若い人より多い
3. 立ち上がったときに血圧が上がりやすくなる

## ⑤ 脳血管疾患（脳卒中）

脳の血管が詰まる・破れる病気をまとめて脳血管疾患（脳卒中）といいます。要介護5の原因の第1位です（2022年 国民生活基礎調査）。

| 病気 | 中身 |
|---|---|
| **脳梗塞** | 脳の血管が**詰まる**。動脈硬化で細い血管が詰まるもの（ラクナ梗塞など）と、**心房細動**でできた血栓が飛んで詰まるもの（脳塞栓）がある |
| **脳出血** | 脳の中の血管が**破れて出血**。**高血圧**が最大の危険因子 |
| **くも膜下出血** | 主に**脳動脈瘤の破裂**。**突然の激しい頭痛**（「バットで殴られたよう」）、吐き気 |

- 後遺症として、**片麻痺・失語・構音障害・嚥下障害**、高次脳機能障害、血管性認知症が残ることがある
