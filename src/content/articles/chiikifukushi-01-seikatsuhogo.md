| 科目 | 過去15年の出題数 | この記事の章 |

**結論を3行で**

1. 生活保護は**憲法25条の生存権**。**補足性の原理＝資産・能力などを活用したうえで保護**。お金に困った人の相談先は**福祉事務所**。
2. 生活困窮者自立支援法は**生活保護の手前**の支援。必須事業は**自立相談支援**と**住居確保給付金**。
3. 介護休業の対象家族は**配偶者・父母・子・配偶者の父母**など。育児休業は**男性も取れる**。

## ① 生活保護制度【社会の理解】

### 4つの原理

| 原理 | 中身 |
|---|---|
| 国家責任の原理 | **国の責任**で保護（憲法25条の**生存権**）（第37回） |
| 無差別平等の原理 | すべての国民に**無差別平等** |
| 最低生活保障の原理 | **健康で文化的な**生活水準を維持できる保護（第28回） |
| **補足性の原理** | **資産・能力などを活用したうえで**保護。扶養や他の制度が優先（第32・38回） |

> 原則（申請保護・基準及び程度・必要即応・世帯単位）と原理を混同させる問題が定番。「申請に基づく」「世帯を単位」は原則で、補足性の原理ではありません。

### 扶助の種類と給付方法（第24・34回）

| 扶助 | 給付方法 |
|---|---|
| 生活・住宅・教育・**出産**・生業・葬祭扶助 | **金銭給付**が原則 |
| **医療扶助・介護扶助** | **現物給付**が原則 |

### よく出る○×

| ○ | × |
|---|---|
| 申請できるのは**本人・扶養義務者・同居の親族** | 事業所の担当者・民生委員が申請 |
| 世帯単位が原則だが**世帯分離**もできる | 世帯分離はできない |
| 家や車、年金・収入があっても**条件により対象になる** | 持ち家・年金があれば全て対象外 |
| 費用は**国が3/4**、自治体が1/4 | 国が全額 |
| 担当職員（現業員）に社会福祉士資格は必須ではない | 社会福祉士が必要 |

### 誰に相談する？

| 場面 | ○ 正解 |
|---|---|
| 年金暮らしで貯金が減り、家賃も払えず、デイサービスをやめたいという80歳（第32回） | **福祉事務所に相談**するよう助言 |
| 父親が亡くなり、家賃を滞納しているひきこもりの55歳の姉を心配する弟（第36回） | **福祉事務所** |

## ② 生活困窮者自立支援法【社会の理解】

| ○ | × |
|---|---|
| 対象は**最低限度の生活を維持できなくなるおそれのある人**（第35回） | 最終的なセーフティネット（それは生活保護） |
| 目的は**自立支援策を強化して自立を促す**（第29回） | — |
| **必須事業＝自立相談支援事業・住居確保給付金**（第38回） | 就労準備支援・学習支援が必須 |
| 社会福祉法人・NPO法人などへ**委託できる** | 委託できない |
| **障害者も対象**、都道府県の責務も規定 | 障害者は除外 |

> 生活保護＝**第3**のセーフティネット、生活困窮者自立支援＝**第2**のセーフティネット（生活保護に至る前）。

## ③ 育児・介護休業法・働き方・障害者雇用【社会の理解】

| ○ | × |
|---|---|
| 育児休業は**男性も取れる**（第25回） | 夫は取れない |
| 育児休業は原則**子が1歳になるまで**（延長あり）。**終了予定日を明らかにして申し出る**（第26回） | 1歳になる前の月まで |
| 小学校入学前の子の**看護休暇**がある | 休暇制度はない |
| 介護休業の対象家族＝**配偶者・父母・子・配偶者の父母**（祖父母・兄弟姉妹・孫も）（第31回） | — |
| 介護休業は1人につき**通算93日、3回まで分割**できる | 連続して取らなければならない |
| 契約社員も条件を満たせば取れる | 取れない |
| 休業中の給料の支払いは**義務ではない**（雇用保険から給付） | 給与支給が義務 |
| 育児休業の方が先に制度化（1991年）、介護休業は1995年 | 介護休業が先 |

### 雇用・働き方改革

- 非正規雇用は雇用者全体の**3分の1を上回る**（第30回）。パート・アルバイトが非正規の過半数
- **働き方改革**＝働く人のニーズに応じた**多様な働き方を選べる社会**。時間外労働の上限規制、同一労働同一賃金、中小企業も対象（第32回）
- **障害者雇用促進法**：民間企業の法定雇用率は**2024年度2.5%**（2026年7月から2.7%）。**精神障害者も対象**、週10〜20時間の短時間労働も一部算定（第37回）

「育児・介護休業法」について、適切なものはどれ？

1. 契約社員は育児休業を取れない
2. 介護休業は対象家族1人につき連続して取らなければならない
3. 介護休業は育児休業より先に制度化された
4. 雇用主は育児休業中の給与を支払わなければならない
5. 配偶者・父母・子・配偶者の父母は介護休業の対象家族である

**正解：5**　介護休業は3回まで分割でき、休業中の収入は雇用保険の介護休業給付で支えます。
