**この記事のポイント**

1. 生活保護は**憲法25条の生存権**。**補足性の原理＝資産・能力などを活用したうえで保護**。お金に困った人の相談先は**福祉事務所**。
2. 生活困窮者自立支援法は**生活保護の手前**の支援。必須事業は**自立相談支援**と**住居確保給付金**。
3. 介護休業の対象家族は**配偶者・父母・子・配偶者の父母**など。育児休業は**男性も取れる**。

## ① 生活保護制度

### 4つの原理と4つの原則

| 原理 | 中身 |
|---|---|
| 国家責任の原理 | **国の責任**で保護（憲法25条の**生存権**） |
| 無差別平等の原理 | すべての国民に**無差別平等** |
| 最低生活保障の原理 | **健康で文化的な**生活水準を維持できる保護 |
| **補足性の原理** | **資産・能力などを活用したうえで**保護。扶養や他の制度が優先 |

| 原則 | 中身 |
|---|---|
| **申請保護**の原則 | **申請に基づいて**始める（急迫した場合は申請がなくても保護できる） |
| 基準及び程度の原則 | 国の基準で測った需要をもとに、足りない分を補う |
| 必要即応の原則 | 年齢・健康状態など**個人や世帯の必要**に応じて行う |
| **世帯単位**の原則 | **世帯**を単位に要否と程度を決める（必要なら個人単位にする**世帯分離**もできる） |

> 原則と原理を混同させる問題が定番。「申請に基づく」「世帯を単位」は原則で、補足性の原理ではありません。

### 扶助の種類と給付方法

| 扶助 | 給付方法 |
|---|---|
| 生活・住宅・教育・**出産**・生業・葬祭扶助 | **金銭給付**が原則 |
| **医療扶助・介護扶助** | **現物給付**が原則 |

- 生活保護受給者は国民健康保険に入らない（医療は医療扶助）
- **母子加算**は一度廃止されたが**2009年12月に復活**し、現在もある
- **要保護者**＝保護が必要な人／**被保護者**＝いま保護を受けている人

### 窓口・手続き・費用

- **福祉事務所**＝生活保護などの窓口。都道府県と**市（特別区を含む）は設置義務**、町村は任意
- 手続き：福祉事務所で相談 → 申請 → 資産や扶養の調査、保護が必要かどうかの判定（**要否判定**）→ <strong>原則14日以内（最長30日）</strong>に決定
- 担当職員＝**現業員**（ケースワーカー）。家庭を訪問して相談・指導を行う

### よく出る○×

| ○ | × |
|---|---|
| 申請できるのは**本人・扶養義務者・同居の親族** | 事業所の担当者・民生委員が申請 |
| 世帯単位が原則だが**世帯分離**もできる | 世帯分離はできない |
| 家や車、年金・収入があっても**条件により対象になる** | 持ち家・年金があれば全て対象外 |
| 費用は**国が3/4**、自治体が1/4 | 国が全額 |
| 担当職員（現業員）に社会福祉士資格は必須ではない | 社会福祉士が必要 |

### 保護から抜け出す支援

- **就労自立給付金**：就職などで保護が要らなくなった世帯に、保護廃止時に**一括**支給（上限：単身10万円・複数世帯15万円）
- **生活保護受給者等就労自立促進事業**：**ハローワークと自治体が連携**し、福祉事務所などに**ハローワークの常設窓口**を置いて就職まで支援。児童扶養手当受給者や生活困窮者も対象

### 誰に相談する？

| 場面 | ○ 正解 |
|---|---|
| 年金暮らしで貯金が減り、家賃も払えず、デイサービスをやめたいという80歳 | **福祉事務所に相談**するよう助言 |
| 父親が亡くなり、家賃を滞納しているひきこもりの55歳の姉を心配する弟 | **福祉事務所** |

## ② 生活困窮者自立支援法・福祉ニーズ

| ○ | × |
|---|---|
| 対象は**最低限度の生活を維持できなくなるおそれのある人** | 最終的なセーフティネット（それは生活保護） |
| 目的は**自立支援策を強化して自立を促す**（2015年施行） | — |
| **必須事業＝自立相談支援事業・住居確保給付金** | 就労準備支援・学習支援が必須 |
| 社会福祉法人・NPO法人などへ**委託できる** | 委託できない |
| **障害者も対象**、都道府県の責務も規定 | 障害者は除外 |

<photo name="hikaku-02__safety-net" caption="3段のセーフティネット。上から第1＝社会保険・労働保険、第2＝生活困窮者自立支援制度・求職者支援、いちばん下の最後のネット＝生活保護。">

> セーフティネットの3段：**第1**＝社会保険・労働保険、**第2**＝生活困窮者自立支援（生活保護に至る前）、**第3**＝生活保護（最後のセーフティネット）。

### 福祉ニーズの分け方

| 分け方 | 中身 |
|---|---|
| **貨幣的ニーズ** | お金で満たす（生活費など） |
| **非貨幣的ニーズ** | サービスで満たす（介護・保育など） |
| **顕在的ニーズ** | 本人が自覚・表明している |
| **潜在的ニーズ** | 必要なのに本人が自覚・表明していない |

> ニーズは公的サービスだけで満たすものではありません。

## ③ 育児・介護休業法・働き方・障害者雇用

| ○ | × |
|---|---|
| 育児休業は**男性も取れる** | 夫は取れない |
| 育児休業は原則**子が1歳になるまで**（延長あり）。**終了予定日を明らかにして申し出る** | 1歳になる前の月まで |
| **子の看護等休暇**がある（2025年4月から**小学3年生修了まで**。学級閉鎖や入園・入学式も対象） | 休暇制度はない |
| 介護休業の対象家族＝**配偶者・父母・子・配偶者の父母**（祖父母・兄弟姉妹・孫も） | 配偶者の父母は対象外 |
| 介護休業は1人につき**通算93日、3回まで分割**できる | 連続して取らなければならない |
| **介護休暇**は対象家族1人につき**年5日**（2人以上なら年10日）。**時間単位**でも取れる | 介護休暇は毎年93日 |
| 契約社員も条件を満たせば取れる | 取れない |
| 休業中の給料の支払いは**義務ではない**（雇用保険から**介護休業給付**などが出る） | 給与支給が義務 |
| 育児休業の方が先に制度化（1991年）、介護休業は1995年 | 介護休業が先 |

### 雇用・働き方改革

- 非正規雇用は雇用者全体の**3分の1を上回る**。パート・アルバイトが非正規の過半数
- **働き方改革**＝働く人のニーズに応じた**多様な働き方を選べる社会**。時間外労働の上限規制、同一労働同一賃金、中小企業も対象

### 障害者雇用促進法

| ○ | × |
|---|---|
| 民間企業の法定雇用率は**2.5%**（2024年4月から）。国・地方公共団体は2.8%、教育委員会は2.7% | 2.0% |
| **精神障害者**は2006年から実雇用率に算定され、**2018年から雇用義務の対象** | 精神障害者は対象外 |
| 週10〜20時間の短時間労働も一部算定（2024年4月から） | 短時間労働は認められない |

- 法定雇用率の推移：2.0％（2013年）→2.2％（2018年）→2.3％（2021年）→**2.5％（2024年）**→2.7％（**2026年7月**から。対象は従業員37.5人以上の企業。試験の法令の基準日より後の改正）
- 職場定着には**ジョブコーチ（職場適応援助者）**、**障害者就業・生活支援センター**
