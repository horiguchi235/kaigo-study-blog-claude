## ① 消化管の順番【こころとからだのしくみ】

口 → 食道 → 胃 → **小腸** → **大腸** → 肛門

| 部位 | 順番 |
|---|---|
| 小腸 | 十二指腸 → **空腸** → 回腸 |
| 大腸 | 盲腸 → **上行結腸** → **横行結腸** → **下行結腸** → **S状結腸** → 直腸 |

**覚え方**：お腹の右下から始まって、時計回りに「の」の字を描きます。右下（盲腸）→ 右を上へ（上行）→ 上を横へ（横行）→ 左を下へ（下行）→ S字に曲がって（S状）→ 直腸。

この「の」の字は、②の**腹部マッサージの方向**とまったく同じです。セットで覚えましょう。

## ② 排便のしくみと、自然排便を促す介助【しくみ → 介助】

### しくみ【こころとからだのしくみ】

1. 食べ物が胃に入ると、大腸がぎゅっと動き出す（**胃・結腸反射**）。**朝食後に最も強く**起こる
2. 便が直腸に届くと、直腸の壁が伸びて「便意」が生まれる（**排便反射**）
3. お腹に力を入れ（**腹圧**）、**外肛門括約筋を自分の意思でゆるめて**排便する

> 腸の動きを活発にするのは**副交感神経**（リラックスしたとき）です。交感神経（緊張したとき）は腸の動きを抑えます。

### 介助【生活支援技術】

しくみがわかれば、介助の正解は自然に導けます。

| しくみ | 正解になる介助 |
|---|---|
| 胃・結腸反射は朝食後に強い | **朝食後にトイレへ誘導**する／**起床後に冷水を飲む**（胃への刺激） |
| 腹圧をかけると出やすい | **便座に座り、足の裏を床につけて前かがみ** |
| 腸は運動で動く | **散歩などの運動** |
| 大腸の走行は「の」の字 | 腹部マッサージは**上行 → 横行 → 下行**の順（時計回り） |

**よく出る不正解**：仰向け（寝た姿勢）で排便する／食後すぐに横になる／マッサージを「下行→横行→上行」（逆回り）で行う／お腹を冷やす／朝食を抜く／食事の量を減らす

> 「**朝食後にトイレ誘導**」は、胃・結腸反射（第35回）、直腸性便秘（第30回）、便失禁の改善（第35回）の**3問で正解**になっています。

胃・結腸反射を利用して自然な排便を促す支援として、最も適切なものはどれ？

1. 歩行を促す
2. 起床後に冷水を飲んでもらう
3. 腹部のマッサージをする
4. 便座に誘導する
5. 離床する時間を増やす

<details class="answer">
<summary>正解を見る</summary>

## ③ 便秘の種類と原因【こころとからだのしくみ】

| タイプ | ひとことで | 原因 | 対応 |
|---|---|---|---|
| **弛緩性** | 大腸の動きが弱い | 食物繊維・水分・運動の不足、**長期臥床**（**高齢者に多い**） | 食物繊維・水分・運動 |
| **直腸性** | 便意を感じにくい | **便意を我慢**する習慣 → 排便反射が鈍る | **朝食後のトイレ誘導**、我慢しない |
| **けいれん性** | 腸が緊張しすぎ | **ストレス**、過敏性腸症候群（コロコロ便） | ストレスを減らす |
| **器質性** | 腸そのものに病気 | **大腸がん**など（便が**細い**・**血**が混じる） | **受診**（介助で治すものではない） |

**薬による便秘**：**麻薬性鎮痛剤**（モルヒネなど）は、腸の動きを止めて便秘を起こします（第25回・第30回）。

<details>
<summary>✏️ 解いてみよう（第38回・事例）</summary>

80歳の男性。半年前から急に便秘になり、今は5日に1回程度しか出ない。お腹が張り、便は細く、血液が付くことがある。対応として最も適切なものはどれ？

1. 水分摂取を促す
2. 食物繊維の摂取を促す
3. 散歩などの運動を促す
4. 腹部のマッサージを行う
5. 医療機関の受診を促す

<details class="answer">
<summary>正解を見る</summary>

**正解：5**　「急に」「便が細い」「血が付く」は、器質性便秘（大腸がんなど）のサインです。1〜4は弛緩性便秘の対応なので、ここでは「まず受診」が優先です。
</details>
</details>

## ④ 下痢と排泄物の感染対策【生活支援技術】

- 下痢便は**感染源として扱う**（第26回）
- 汚れたおむつはビニール袋に入れ、**袋の口を固く縛る**（第29回・腸管出血性大腸菌）
- 手袋は**使い捨て**（くり返し使わない）。手洗いは**流水と石けん**で
- 下痢が続くと**脱水**になりやすい → **水分を控えるのは誤り**
- 肛門周りの皮膚は、強くこすらず**押さえるように拭く**

> ノロウイルスにはアルコールが効きにくく、**次亜塩素酸ナトリウム**で消毒します。詳しくは「感染対策」の記事でまとめます。

<details>
<summary>✏️ 解いてみよう（第29回）</summary>

1. 汚れたおむつをビニール袋に入れ、袋の口を固く縛る
2. 汚れたシーツにアルコールを噴霧する
3. 洗面器にためた水で手を洗う
4. お尻の汚れはトイレットペーパーで拭けばよい

<summary>正解を見る</summary>

**正解：1**　感染を広げないことが最優先です。手洗いは流水で、手袋は使い捨て、汚れはきちんと清拭します。

## ひっかけパターン集（便秘・排便で「ほぼ×」）

| 選択肢の表現 | なぜ× |
|---|---|
| 食物繊維・油を控える／朝食を抜く | 便のかさと刺激が減り、便秘が悪化する |
| 市販の下剤を毎日勧める | 習慣化して自然な排便力が落ちる。薬は医師の判断で |
| 食後すぐ横になる／仰向けで排便 | 腹圧がかからない |
| マッサージを下行→横行→上行の順で | 便の流れと逆 |
| 下痢のときは水分を控える | 脱水になる |
