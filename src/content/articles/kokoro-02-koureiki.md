**この記事のポイント**

1. **流動性知能（新しい問題を解く）は加齢で下がりやすく**、**結晶性知能（経験・知識）は保たれる**。
2. ライチャードの5類型は事例で出る：**満足＝円熟型**、**若さにこだわり世話を拒む＝装甲（自己防衛）型**。
3. キューブラー・ロスは「**否認 → 怒り → 取り引き → 抑うつ → 受容**」。「**なぜ私が**」＝怒り、「**我慢するので助けて**」＝取り引き。

## ① 知能と老年期の性格類型【発達と老化の理解】

### 知能

| | **流動性知能** | **結晶性知能** |
|---|---|---|
| 中身 | **新しい場面**に適応する**問題解決能力** | **過去に得た知識や経験を活用**して解決する能力 |
| 加齢 | **低下しやすい**（生理的な老化の影響） | **高齢でも維持**、伸びることも |
| 影響を受けるもの | 脳の働き | 教育・文化・経験 |

### ライチャードの老年期の性格（適応）5類型

| 類型 | 特徴 | 試験の事例 |
|---|---|---|
| **円熟型** | 自分の人生を受け入れ、**趣味や交流に積極的で満足** | 多くの趣味と友人、毎日を有意義に |
| **安楽いす（ロッキングチェアー）型** | **他人に依存**し、のんびり受け身 | — |
| **装甲（自己防衛）型** | 老いへの不安を**活動で打ち消す**。**若さにこだわり**、人の**世話になることを拒む** | 元営業部長、長男の同居の勧めを拒否／元役員、老人クラブ拒否・敬老の記念品に不快・毎日筋トレ・「若々しい」で喜ぶ |
| 憤慨（外罰）型 | 自分の失敗を**他人のせい**にして攻撃的 | — |
| 自責（内罰）型 | 自分の人生を**失敗と考え自分を責める** | — |

## ② エイジング理論・エイジズム・高齢期の適応【発達と老化の理解】

| 用語 | 意味 |
|---|---|
| **エイジズム** | **高齢を理由にした偏見や差別**。例：「年をとると**頑固になる**」 |
| **サクセスフル・エイジング** | 老いの変化に工夫して適応し、よく生きる。例：難聴があるので**補聴器をつけてパソコン教室**へ |
| **プロダクティブ・エイジング** | **バトラー**が提唱。高齢者も社会に貢献する存在。**セルフケア**も生産的な活動に含む |
| 活動理論 | 活動を続けるほど幸福 |
| 離脱理論 | 社会から少しずつ離れるのが自然 |
| **社会情動的選択理論** | 残りの時間を意識すると、**親しい人との関係を選んで大切に**する |

- 老性自覚：白髪などで「年をとった」と感じること
- 住み慣れた地域で満足して暮らす人が、息子に同居を迫られる → **住み慣れた環境や仲間を失うことへの不安**

### 意欲が低下した高齢者の動機づけ

| ○ 動機づけが強まる | × |
|---|---|
| **具体的に何をすればよいか**がわかる | 他人が高い目標を掲げる |
| **本人が興味のある**目標 | — |
| **小さな目標の達成を積み重ねる** | — |
| **自分にもできそう**と思える目標 | — |

### そのほか

- **高齢者のセクシュアリティ**：女性は高齢になると**性交痛**を感じやすい。性への関心はなくならない、男性の性ホルモンも減る
- 糖尿病の人が骨折後に自宅療養 → **ケアマネジャーが訪問リハビリの利用を提案**

## ③ 喪失体験・悲嘆・死の受容過程【発達と老化の理解／こころとからだのしくみ】

### 喪失と悲嘆

| ○ | × |
|---|---|
| 夫の死の後「眠れない」・横になってばかり → きっかけは**喪失体験** | せん妄・老性自覚 |
| **十分に悲しむ**ことが悲嘆を乗り越えるのに有効 | 悲嘆は心身に影響しない／誰でも同じように進む |
| 回復には**生活の立て直し**への対処も必要 | 悲嘆過程は病的なもの |
| 遺族への心理的ケアは**緩和ケアに含まれる** | — |

### ストローブとシュトの二重過程モデル

| 喪失志向 | 回復志向 |
|---|---|
| 亡くした人に向き合う。**悲しい気持ちを語る**、思い出す | 新しい生活に向き合う。旧友との交流・サークル・ボランティア・新しい役割 |

→ この2つを**行ったり来たり**しながら回復していく。

### キューブラー・ロスの死の受容過程

| 段階 | 例 |
|---|---|
| ① 否認 | 「自分が死ぬはずがない」 |
| ② **怒り** | 「**どうして私だけが**がんにならなければならないのか」 |
| ③ **取り引き** | 「**つらい治療を我慢するので助けてほしい**」 |
| ④ 抑うつ | 「もう助からない」と絶望する |
| ⑤ 受容 | 安らかに死を受け入れる |

## ＋α もう一歩：実務者研修レベルで覚えたいこと

過去問にはまだ出ていないけれど、実務者研修の確認テストでよく問われる、関連して覚えておきたい知識です。

- **パーソナリティのとらえ方**：**類型論**＝タイプに分ける（ユング・クレッチマー）／**特性論**＝いくつもの特性の程度で見る（キャッテル）。
- **人格検査の3種類**：**投影法**（あいまいな絵などへの反応：ロールシャッハ・バウムテスト）／**質問紙法**（YG性格検査）／**作業法**（内田クレペリン検査）。
- **動機づけ**：**内発的動機**＝興味・楽しさ・達成感から行う／**外発的動機**＝指示・ほうび・評価のために行う（親に言われてしかたなく掃除する）。
- 性格は生まれつきだけで決まらず、**環境や経験で変化する**。老化で**感覚は鈍くなる**傾向があり、それが心理にも影響する。
