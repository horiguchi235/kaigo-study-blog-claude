**この記事のポイント**

1. **流動性知能（新しい問題を解く）は加齢で下がりやすく**、**結晶性知能（経験・知識）は保たれる**。
2. ライチャードの5類型は事例で出る：**満足＝円熟型**、**若さにこだわり世話を拒む＝装甲（自己防衛）型**。
3. キューブラー・ロスは「**否認 → 怒り → 取り引き → 抑うつ → 受容**」。「**なぜ私が**」＝怒り、「**我慢するので助けて**」＝取り引き。

## ① 知能と老年期の性格類型

### 知能

| | **流動性知能** | **結晶性知能** |
|---|---|---|
| 中身 | **新しい場面**に適応する**問題解決能力** | **過去に得た知識や経験を活用**して解決する能力 |
| 加齢 | **低下しやすい**（**20〜30歳代ごろ**をピークに、その後は加齢とともに低下） | **60歳代ごろまで伸び**、70〜80歳代以降にゆるやかに下がる（高齢でも保たれやすい） |
| 影響を受けるもの | 脳の働き（生理的な老化） | 教育・文化・経験 |
| 近い考え方 | 動作性知能（暗記・計算・情報の処理）と対応づけて説明されることが多い | 言語性知能（一般知識・判断力・理解力）と対応づけて説明されることが多い |

### ライチャードの老年期の性格（適応）5類型

試験では別名で出ることも多いので、呼び名をまとめて覚えます。

| 類型 | 別名（試験に出た表記） | 特徴 | 試験の事例 |
|---|---|---|---|
| **円熟型** | 成熟型 | 自分の人生を受け入れ、**趣味や交流に積極的で満足** | 多くの趣味と友人、毎日を有意義に |
| **安楽いす型** | ロッキングチェアー型・依存型 | **他人に依存**し、責任から解放されたのんびりした暮らしを歓迎 | — |
| **装甲型** | 自己防衛型・防衛型 | 老いへの不安を**活動で打ち消す**。**若さにこだわり**、人の**世話になることを拒む** | 元営業部長、長男の同居の勧めを拒否／元役員、老人クラブ拒否・敬老の記念品に不快・毎日筋トレ・「若々しい」で喜ぶ |
| 憤慨型 | 外罰型 | 老いを受け入れられず、自分の失敗を**他人のせい**にして攻撃的 | — |
| 自責型 | 内罰型 | 自分の人生を**失敗と考え自分を責める** | — |

円熟型・安楽いす型・装甲型は「適応できている」タイプ、憤慨型・自責型は「適応できていない」タイプです。

### 性格のとらえ方と性格検査

- **類型論**＝人をいくつかのタイプに分ける（ユング・クレッチマー）／**特性論**＝いくつもの特性の強さで見る（キャッテル）
- 性格は生まれつきだけで決まらず、**環境や経験で変化する**

| 検査の種類 | 中身 | 代表例 |
|---|---|---|
| 投影法 | あいまいな刺激への反応から性格を見る | ロールシャッハ・テスト（インクのしみが何に見えるか）、バウムテスト（実のなる木の絵を描く） |
| 質問紙法 | 質問に「はい・いいえ」で答える | YG（矢田部ギルフォード）性格検査 |
| 作業検査法 | 単純な作業の進み方を見る | 内田クレペリン検査（1けたの足し算を続ける） |

## ② エイジング理論・エイジズム・高齢期の適応

| 用語 | 意味 |
|---|---|
| **エイジズム** | **高齢を理由にした偏見や差別**。例：「年をとると**頑固になる**」 |
| **サクセスフル・エイジング** | 老いの変化に工夫して適応し、よく生きる。例：難聴があるので**補聴器をつけてパソコン教室**へ。**長生き**・**生活の質（QOL）が高い**・**社会への貢献**を合わせて考え、**本人の主観的な幸福感**を大切にする（「長生きだけが目的」は×） |
| アンチエイジング | いつまでも若い心と体を保とうとする（加齢に抵抗する）考え方。エイジズムとは別のもの |
| **プロダクティブ・エイジング** | **バトラー**が提唱。高齢者も社会に貢献する存在。**セルフケア**も生産的な活動に含む |
| アクティブ・エイジング | WHOが提唱。健康・参加・安全の機会を最大にして、年をとっても生活の質を高める |
| 活動理論 | 活動を続けるほど幸福 |
| 離脱理論 | 社会から少しずつ離れるのが自然 |
| 継続性理論 | それまでの生き方・役割・習慣を**続けること**で老いに適応する |
| **社会情動的選択理論** | カーステンセンが提唱。残りの時間を意識すると、**親しい人との関係を選んで大切に**する |

- 老性自覚：「年をとった」と感じること。きっかけには、白髪・体力の衰え・病気などの**体の内側の変化**（内的要因）と、定年・孫の誕生・友人との死別・「おじいちゃん」と呼ばれるなどの**周りの変化**（外的要因）がある。感じる時期には個人差がある
- 住み慣れた地域で満足して暮らす人が、息子に同居を勧められる → **住み慣れた環境や仲間を失うことへの不安**

### 意欲が低下した高齢者の動機づけ

| ○ 動機づけが強まる | × |
|---|---|
| **具体的に何をすればよいか**がわかる | 何をすればよいかがあいまい |
| **本人が興味のある**目標 | 他人が決めた目標・他人が高い目標を掲げる |
| **小さな目標の達成を積み重ねる** | 最初から大きな目標だけを目指す |
| **自分にもできそう**と思える目標 | できそうにない高すぎる目標 |

内発的動機づけ（興味から）と外発的動機づけ（ほうび・指示から）の違いは → [マズローの欲求・適応機制・記憶のしくみ](../kokoro-01-yokkyuu/)

## ③ 喪失体験・悲嘆・死の受容過程

### 喪失が重なる（複合喪失）

- 高齢期には、仕事や役割・配偶者や友人・健康・収入などを**続けて失いやすい**。これらが重なることを**複合喪失**といいます
- 入院・入所・転居などの**環境の変化**は、大きな心の負担になります。支援では、その人の**生活歴**を大切にします
- 心と体は**影響し合います**。入院による環境の変化が精神症状のきっかけになったり、うつで食欲が落ちて脱水や肺炎につながったりすることがあります

### 喪失と悲嘆

| ○ | × |
|---|---|
| 夫の死の後「眠れない」・横になってばかり → きっかけは**喪失体験** | せん妄・老性自覚 |
| **十分に悲しむ**ことが悲嘆を乗り越えるのに有効 | 悲嘆は心身に影響しない／誰でも同じように進む |
| 回復には**生活の立て直し**への対処も必要 | 悲嘆過程は病的なもの |
| 遺族への心理的ケアは**緩和ケアに含まれる** | — |

- **緩和ケア**：重い病気の人と家族の、体と心のつらさを和らげるケア。遺族へのケアも含みます
- 大切な人を亡くしたあとには、眠れない・疲れやすい・食欲が落ちる、悲しみ・怒り・気分の落ち込み、故人の姿を探す、故人の声が聞こえる気がする、などが起こります。これは**自然な反応（正常な悲嘆）**で、「喪失 → 悲嘆 → 回復」と時間をかけて和らいでいきます
- 日常生活に支障が出るほど長く続くときは、**複雑性悲嘆**（病的な悲嘆）として専門職につなぎます。配偶者との死別は、特にストレスが大きい出来事です

### ストローブとシュトの二重過程モデル

| 喪失志向 | 回復志向 |
|---|---|
| 亡くした人に向き合う。**悲しい気持ちを語る**、思い出す | 新しい生活に向き合う。旧友との交流・サークル・ボランティア・新しい役割 |

→ この2つを**行ったり来たり**しながら回復していく。揺れ動くことは、むしろ自然な対処です。

**コーピング**：ストレスを軽くするためにとる行動や考え方のこと。

### キューブラー・ロスの死の受容過程

| 段階 | 例 | 言い換え（選択肢での書かれ方） |
|---|---|---|
| ① 否認 | 「自分が死ぬはずがない」 | ショックから自分を守るため、事実を打ち消す |
| ② **怒り** | 「**どうして私だけが**がんにならなければならないのか」 | 周りの人に怒りを向ける（訪問介護員に「もう来なくていい」） |
| ③ **取り引き** | 「**つらい治療を我慢するので助けてほしい**」 | 神や仏に祈る・奇跡を願う。「〜するから助けて」 |
| ④ 抑うつ | 「もう助からない」と絶望する | 死が避けられないと知り、**さまざまな喪失感**を抱いて落ち込む |
| ⑤ 受容 | 安らかに死を受け入れる | 静かに死を受け入れ、心が穏やかになる |

> 全員がこの順番どおりに進むわけではありません。段階を**行ったり来たり**したり、重なったりします（「必ず順番に進む」は×）。

### 受容・悲嘆のモデルの見分け方

似た「段階」のモデルがいくつもあります。**誰の、何についての話か**で見分けます。

| モデル | 誰の何を表すか | 段階・考え方 |
|---|---|---|
| キューブラー・ロス | **死にゆく本人**が死を受け入れる過程 | 否認 → 怒り → 取り引き → 抑うつ → 受容 |
| 上田敏 | **障害を負った本人**の受容 | ショック → 否認 → 混乱 → 解決への努力 → 受容 |
| 認知症の人の家族 | **介護する家族**の受け止め | 戸惑い・否定 → 混乱・怒り・拒絶 → 割り切り・あきらめ → 受容（→ [家族支援](../ninchishocare-03-kazoku/)） |
| ボウルビィ | **愛する人を亡くした人**の悲嘆 | 無感覚 → 思慕と探求 → 混乱と絶望 → 再建 |
| ストローブとシュト | 死別のあとの**対処のしかた** | 喪失志向と回復志向を行き来する |

- 「怒り」はキューブラー・ロスにも、上田敏の混乱期にもあります。問題文が誰についての話かを確かめます

### 老年期うつ病

喪失体験が重なる高齢期は、うつ病が起こりやすい時期です。

| ○ 老年期うつ病の特徴 | × |
|---|---|
| 抑うつ気分より、**頭痛・腰痛・だるさなど体の訴え**が目立つ（仮面うつ病） | 気分の落ち込みを必ず強く訴える |
| もの忘れなど**認知症に似た症状**が出る（仮性認知症） | 認知症と見分ける必要はない |
| 自殺を図ると**亡くなる率が高い**。回復しかけの時期も自殺のサインに注意 | 高齢者の自殺は少ない |
| **安易に励まさない**。休養と受診につなぐ | 「がんばって」と励ます |
| きっかけは環境の変化・喪失体験のほか、**脳の病気・パーキンソン病・糖尿病などの体の病気**もある。50〜60歳代の初老期にも起こりやすい | 原因は気持ちの問題だけ |
| 若い人より**長引きやすく、再発しやすい**。**認知症の危険因子**にもなる | 一度治れば再発しない |
| 気分の落ち込みより、すぐ泣く・怒るなど、**感情を抑えにくい形**で出ることがある | — |
