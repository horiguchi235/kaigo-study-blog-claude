計画には「**全体の計画**」と「**事業所ごとの計画**」の2階建てがあります。**全体の計画に沿って事業所の計画をつくる**、が基本ルールです。

**この記事のポイント**

1. 介護保険の全体の計画＝**ケアプラン（居宅サービス計画）**…**介護支援専門員**。
2. 障害福祉の全体の計画＝**サービス等利用計画**…**相談支援専門員**。
3. 訪問介護の計画＝**訪問介護計画**…**サービス提供責任者**。
4. 障害福祉の事業所の計画＝**個別支援計画**…**サービス管理責任者**（児童は児童発達支援管理責任者）。
5. どの計画も**本人の同意**が必要。全体の計画が変われば事業所の計画も見直す。

---

## ① 2階建てで見る

| | 介護保険（在宅） | 介護保険（施設） | 障害福祉 |
|---|---|---|---|
| **全体の計画**（1階） | **居宅サービス計画（ケアプラン）** | **施設サービス計画** | **サービス等利用計画** |
| つくる人 | **介護支援専門員**（居宅介護支援事業所） | 施設の**介護支援専門員** | **相談支援専門員**（特定相談支援事業所） |
| 要支援の人 | **介護予防サービス計画**…**地域包括支援センター**（2024年からは指定を受けた居宅介護支援事業所も） | — | — |
| **事業所の計画**（2階） | 訪問介護計画・通所介護計画など | （施設サービス計画に沿った介護計画） | **個別支援計画** |
| つくる人 | 訪問介護＝**サービス提供責任者**、通所介護＝管理者（生活相談員など） | 介護職などチーム | **サービス管理責任者** |
| 会議 | **サービス担当者会議**（ケアマネが開く） | サービス担当者会議 | サービス担当者会議（相談支援専門員が開く）・個別支援会議 |

> <strong>介護過程の「介護計画」</strong>は、介護福祉職が介護過程（アセスメント→計画→実施→評価）で立てる計画。ケアプランの目標に沿って、日々の具体的な介護の方法を決めます。つまり「ケアプラン → 訪問介護計画など → 介護計画」と、上の計画に沿って下の計画をつくります。

**ほかにもある「計画とつくる人」**

| 場面 | 計画 | つくる人 |
|---|---|---|
| 要支援の人 | **介護予防支援**（介護予防サービス計画）＝予防給付のサービスを使う人／**介護予防ケアマネジメント**＝総合事業のサービスだけを使う人 | どちらも中心は**地域包括支援センター** |
| グループホーム | 認知症対応型共同生活介護計画 | **計画作成担当者** |
| 小規模多機能型居宅介護 | ケアプランと小規模多機能型居宅介護計画 | 事業所の**介護支援専門員**（計画作成担当者） |
| 障害児 | **障害児支援利用計画**（全体の計画） | 障害児相談支援事業所の**相談支援専門員** |
| 障害児 | 児童発達支援などの**個別支援計画**（事業所の計画） | **児童発達支援管理責任者** |
| 本人・家族が自分で | **セルフケアプラン**（自己作成のケアプラン） | 本人・家族が作成し、市町村に届け出る |

## ② 似ている職種

| 職種 | 制度 | いる所 | 主な仕事 |
|---|---|---|---|
| **介護支援専門員（ケアマネ）** | 介護保険 | 居宅介護支援事業所・施設 | ケアプラン作成、サービス調整、**給付管理**、担当者会議の開催 |
| **主任介護支援専門員** | 介護保険 | 地域包括支援センターなど | ケアマネへの助言・指導、地域づくり |
| **相談支援専門員** | 障害福祉 | 相談支援事業所 | **サービス等利用計画**の作成、モニタリング |
| **サービス提供責任者** | 介護保険・障害福祉 | 訪問介護事業所 | **訪問介護計画**の作成、ヘルパーの指導・調整 |
| **サービス管理責任者** | 障害福祉 | 障害福祉サービス事業所 | **個別支援計画**の作成、支援の管理 |
| **生活相談員** | 介護保険など | 特養・デイサービスなど | 入所・利用の相談、家族や関係機関との連絡調整 |
| **支援相談員** | 介護保険 | 老健 | 入所・退所の相談、在宅復帰の調整 |
| **生活支援員**（障害福祉） | 障害福祉 | 障害者支援施設・生活介護などの事業所 | 入浴・排泄・食事など日常生活の支援 |
| **生活支援員**（日常生活自立支援事業） | 社会福祉法 | 社会福祉協議会 | 専門員がつくった支援計画に沿って、お金の出し入れなどを援助（比較⑤） |

---

## ③ 計画づくりの共通ルール

1. **本人（家族）の意向**を聞き、アセスメントをもとに作る
2. **原案を説明し、本人の同意**を得て交付する（サービス担当者会議で話し合っていても、本人の同意は省略できない）
3. **全体の計画に沿って**事業所の計画を作る（逆ではない）
4. 実施後は**モニタリング**し、状態が変われば見直す

## ひっかけパターン集

| 選択肢の表現 | なぜ× |
|---|---|
| 訪問介護計画はケアマネがつくる | **サービス提供責任者** |
| サービス等利用計画はサービス管理責任者がつくる | **相談支援専門員** |
| 訪問介護計画をもとにケアプランをつくる | **ケアプランに沿って**訪問介護計画をつくる |
| サービス担当者会議はサービス提供責任者が主催 | **ケアマネ**が主催 |
| 要支援者の計画は必ず居宅介護支援事業所がつくる | 中心は**地域包括支援センター**（介護予防支援） |
| グループホームの計画はサービス提供責任者がつくる | **計画作成担当者** |
