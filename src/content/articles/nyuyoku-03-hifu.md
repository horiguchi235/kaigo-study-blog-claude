**この記事のポイント**

1. 皮膚の表面は**弱酸性**、バリアになるのは表皮のいちばん外側の**角質層**。
2. 乾燥肌・かゆみには「**こすらない・弱酸性の石けん・入浴後すぐ保湿・爪を短く**」。
3. 爪切りは「**入浴後・少しずつ・白い部分を1mm残す・やすりで整える**」。巻き爪や炎症は**切らずに報告**。

## ① 皮膚のしくみ

皮膚は外側から **表皮 → 真皮 → 皮下組織** の3層です。

| 層 | 中身 |
|---|---|
| 表皮（厚さ約0.2mm） | 外から**角質層**（バリア）→顆粒層→有棘層→**基底層**（新しい細胞をつくる）の4層 |
| 真皮 | 皮脂腺・汗腺・血管・神経 |
| 皮下組織 | 脂肪 |

| ○ 正しい | × よく出る誤り |
|---|---|
| 皮膚の表面は**弱酸性** | 弱アルカリ性 |
| 外界と接するのは**表皮** | 真皮に角質層がある |
| バリア機能をもつのは**角質層** | 基底層が最表面 |
| 気づかないうちに皮膚と呼吸から失う水分＝**不感蒸泄**は成人で1日**約900mL**（皮膚から約600mL、呼吸から約300mL） | — |
| 皮膚の表面には常在菌がいる | 表面は無菌 |
| ビタミン**D**の産生にかかわる | ビタミンB |
| 体臭の原因は**アポクリン腺**（わき・陰部にある） | エクリン腺が体臭の原因 |
| **エクリン腺**は全身にあり、においのない汗（99％が水）が蒸発するとき熱を奪って**体温を下げる** | — |
| 高齢になると皮脂が**減り**、汗をかきにくく暑さも感じにくい | 皮脂が増える |

## ② 皮膚トラブル

| 病気 | 原因 | ポイント |
|---|---|---|
| **白癬**（水虫） | **真菌（カビ）** | カビは湿気で増えるので、足の指の間を**よく乾かす** |
| **疥癬** | **ヒゼンダニ** | 強いかゆみ、**指の間に線状の発疹**。集団生活で最も注意 |
| 帯状疱疹 | ウイルス | 体の片側に帯状の水疱と痛み。水疱がつぶれていなければ入浴できる（温めると痛みが和らぐ） |
| 皮脂欠乏性湿疹・老人性皮膚掻痒症 | 皮膚の乾燥 | 高齢者に**多い**。すね・背中に多い |
| **褥瘡**（床ずれ） | 圧迫による血流障害 | 好発部位は**仙骨部** |

<fig name="jokusou">

- 褥瘡は骨の出っぱった部分の**圧迫**だけでなく、**皮膚のずれや摩擦**、**湿った皮膚**でもできる。排泄物はすぐ除き、シーツの**しわ**や縫い目が肌に当たらないようにする
- 入浴で清潔に保つのも治療の一部。こすらず周りをやさしく洗う（マッサージは×）

### 乾燥肌・かゆみがある人の入浴

| ○ | × |
|---|---|
| **こすらない**ように洗う | ブラシやナイロンタオルでこする |
| **弱酸性**の石けん | アルカリ性の石けん |
| 入浴後、**皮膚が乾ききる前に**保湿剤を塗る | 十分に乾いてから塗る |
| ぬるめのお湯（37〜39℃） | 42℃以上の熱いお湯／硫黄を含む入浴剤（皮膚を刺激する） |
| 利用者の**爪を短く切る**（かき傷防止、第31回） | かくと軽快する |

### 状態別の洗い方

- 人工透析をしている人 → **柔らかいタオル**で洗う（シャントのある腕・皮膚が弱い）
- 糖尿病の人 → 足の傷に気づきにくいので、**足（指の間・足の裏）を特に観察**する
- むくみ（浮腫）のある部位 → 押しつけない

> 「乾かす」と「湿らせる」の区別：**水虫（カビ）はよく乾かす**、**傷（感染していないもの）は乾かさず湿潤環境**のほうが早く治ります。

## ③ 爪のしくみと爪切り

### 爪のしくみ

- 主成分は**タンパク質**（ケラチン）。1日に約0.1mm伸びる
- 健康な爪は**薄いピンク色**（下の**爪床**＝爪がのっている皮膚の血管が透けて見える）。根元の白い**爪半月**はできたばかりの部分で、まだ角質化が進んでいない
- **さじ状爪**（スプーンのように反る）→ **鉄欠乏性貧血**
- ばち状指 → 心臓や肺の病気、青紫色の爪 → チアノーゼ

### 爪切りの手順

| ○ | × |
|---|---|
| **入浴後**など、爪が柔らかいときに切る | 乾燥させてから切る／入浴前に切る |
| **少しずつ**切る。まっすぐ横に切ったあと、両端の角を**少しだけ落とす**（スクエアオフ） | 一度にまっすぐ切る／両端を深く切り込む（巻き爪の原因） |
| 白い部分を**1mmくらい残す** | 白い部分を残さない |
| 切ったあと**やすりで滑らかに**する | — |
| 巻き爪・腫れ・炎症があれば**切らずに報告** | 絆創膏や家の軟膏で対処する |

> **介護福祉職ができる条件（医行為ではない行為）**
> - 爪切り：爪や周りの皮膚に**異常がなく**、**糖尿病などの専門的な管理が必要ない**人。それ以外は**看護師**などへ
> - 耳垢：入口付近の見える耳あかを取る。**耳垢塞栓（詰まった耳あか）**の除去は医療職
> - くわしくは[医療的ケアの制度と呼吸・消化のしくみ](../iryoucare-01-seido/)

## ④ 耳・目・ひげ・義歯

| 部位 | ○ | × |
|---|---|---|
| 耳 | まず**耳垢の状態を観察**する。乾いた耳垢は綿棒で**湿らせてから**、**入口から約1cm**まで。成人は耳たぶ（耳介）を**後ろ上**に引くと見やすい | ピンセット、鼓膜に近い奥まで、毎日の耳かき、耳垢塞栓を自分で取る、耳を上前方に引く |
| 目 | **目頭から目尻**へ拭く。目やには下まぶたを軽く引いて瞬きを促す | 目尻から目頭 |
| 鼻 | 鼻毛は**抜かずに切る** | 抜く |
| ひげ（電気かみそり） | 皮膚に**直角**に当てる、皮膚を伸ばして剃る | 強く押し当てる |
| 義歯 | 流水で義歯用ブラシ、**水につけて**保管 | 熱湯で消毒、歯磨剤（傷がつく）、乾燥させる |
| 口腔ケア（ベッド上） | **ガーグルベースン**を使う | — |
| 洗顔（ベッド上） | 温かいタオル | 冷水で絞ったタオル |
| 洗髪（浴室） | お湯で洗う（ドライシャンプーは入浴できないとき） | — |

> 整容（身だしなみ）は見た目だけでなく、**生活意欲を高める**ことにつながります（化粧を勧めるなど）。歯みがきは**歯だけでなく歯ぐき・舌**も清掃します。

## ひっかけパターン集（皮膚・整容で「ほぼ×」）

| 選択肢の表現 | なぜ× |
|---|---|
| 皮膚の表面は弱アルカリ性 | 弱酸性 |
| 乾燥肌をアルカリ性石けん・熱い湯で洗う | 皮脂を奪い、乾燥が悪化する |
| 保湿剤は十分乾いてから | 湿り気が残るうちに塗る |
| 爪の白い部分を残さず切る | 深爪・巻き爪の原因 |
| 耳垢をピンセットで取る／奥まで綿棒 | 耳を傷つける。医療職へ |
| 加齢臭は水で洗えば落ちる | 原因のノネナールは皮脂が酸化してできる。皮脂の多い首・耳の後ろ・胸・背中をよく洗い、こまめに着替える |
