**結論を3行で**

1. 皮膚の表面は**弱酸性**、バリアになるのは表皮のいちばん外側の**角質層**。
2. 乾燥肌・かゆみには「**こすらない・弱酸性の石けん・入浴後すぐ保湿・爪を短く**」。
3. 爪切りは「**入浴後・少しずつ・白い部分を1mm残す・やすりで整える**」。巻き爪や炎症は**切らずに報告**。

## ① 皮膚のしくみ【こころとからだのしくみ】

```
外側
 表皮 … 角質層（いちばん外側・バリア機能）〜 基底層（いちばん内側・新しい細胞をつくる）
 真皮 … 皮脂腺・汗腺・血管・神経
 皮下組織 … 脂肪
内側
```

| ○ 正しい | × よく出る誤り |
|---|---|
| 皮膚の表面は**弱酸性** | 弱アルカリ性 |
| 外界と接するのは**表皮** | 真皮に角質層がある |
| バリア機能をもつのは**角質層** | 基底層が最表面 |
| 不感蒸泄は1日**約500〜600mL** | — |
| 皮膚の表面には常在菌がいる | 表面は無菌 |
| ビタミン**D**の産生にかかわる | ビタミンB |
| 体臭の原因は**アポクリン腺**（エクリン腺は体温調節の汗） | エクリン腺が体臭の原因 |
| 高齢になると皮脂が**減る** | 皮脂が増える |

## ② 皮膚トラブル【こころとからだのしくみ／生活支援技術】

| 病気 | 原因 | ポイント |
|---|---|---|
| **白癬**（水虫） | **真菌（カビ）** | 足の指の間をよく乾かす |
| **疥癬** | **ヒゼンダニ** | 強いかゆみ、**指の間に線状の発疹**。集団生活で最も注意（第30回） |
| 帯状疱疹 | ウイルス | 体の片側に帯状の水疱と痛み |
| 皮脂欠乏性湿疹・老人性掻痒症 | 皮膚の乾燥 | 高齢者に**多い**。すね・背中に多い |
| **褥瘡** | 圧迫による血流障害 | 好発部位は**仙骨部**（第35回） |

### 乾燥肌・かゆみがある人の入浴

| ○ | × |
|---|---|
| **こすらない**ように洗う（第31回） | ブラシやナイロンタオルでこする |
| **弱酸性**の石けん（第25回） | アルカリ性の石けん |
| 入浴後、**皮膚が乾ききる前に**保湿剤を塗る | 十分に乾いてから塗る |
| ぬるめのお湯 | 42℃以上の熱いお湯／硫黄を含む入浴剤 |
| 利用者の**爪を短く切る**（かき傷防止、第31回） | かくと軽快する |

### 状態別の洗い方（第33回）

- 人工透析をしている人 → **柔らかいタオル**で洗う（シャントのある腕・皮膚が弱い）
- 褥瘡 → こすらず、周りをやさしく洗う
- 糖尿病の人 → 足の傷に気づきにくいので、**足（指の間・足の裏）を特に観察**する（第30回）
- むくみ（浮腫）のある部位 → 押しつけない

> 傷（感染していないもの）は、乾かすより**湿潤環境**のほうが早く治ります（第29回）。

<details>
<summary>✏️ 解いてみよう（第30回・事例）</summary>

ショートステイ初日、84歳の男性の腋窩と腹部に赤い丘疹と小水疱があり、強いかゆみを訴えている。手指の間には灰白色の線が見られる。集団生活で最も注意すべき皮膚疾患はどれ？

1. 皮脂欠乏性湿疹
2. 疥癬
3. 白癬
4. 蕁麻疹
5. 帯状疱疹

<details class="answer">
<summary>正解を見る</summary>

**正解：2**　「強いかゆみ」と「指の間の線（疥癬トンネル）」が疥癬のサインです。ダニが人から人へうつるので、施設では特に注意が必要です。
</details>
</details>

## ③ 爪のしくみと爪切り【こころとからだのしくみ／生活支援技術】

### 爪のしくみ

- 主成分は**タンパク質**（ケラチン）（第36回）。1日に約0.1mm伸びる
- **さじ状爪**（スプーンのように反る）→ **鉄欠乏性貧血**（第32回）
- ばち状指 → 心臓や肺の病気、青紫色の爪 → チアノーゼ

### 爪切りの手順

| ○ | × |
|---|---|
| **入浴後**など、爪が柔らかいときに切る | 乾燥させてから切る／入浴前に切る |
| **少しずつ**切る | 一度にまっすぐ切る |
| 白い部分を**1mmくらい残す**（第29回） | 白い部分を残さない |
| 切ったあと**やすりで滑らかに**する（第36回） | — |
| 巻き爪・腫れ・炎症があれば**切らずに報告**（第35回） | 絆創膏や家の軟膏で対処する |

> 爪や周りの皮膚に異常がある場合や、**糖尿病などで専門的な管理が必要な人**の爪切りは、介護福祉職ではなく**看護師**などが行います（第32回）。

## ④ 耳・目・ひげ・義歯【生活支援技術】

| 部位 | ○ | × |
|---|---|---|
| 耳 | まず**耳垢の状態を観察**する（第34回）。乾いた耳垢は綿棒で**湿らせてから**、**入口付近だけ** | ピンセット、奥（中耳・内耳）まで、毎日の耳かき、耳垢塞栓を自分で取る |
| 目 | **目頭から目尻**へ拭く | 目尻から目頭 |
| ひげ（電気かみそり） | 皮膚に**直角**に当てる、皮膚を伸ばして剃る | 強く押し当てる |
| 義歯 | 流水で義歯用ブラシ、**水につけて**保管 | 熱湯で消毒、歯磨剤（傷がつく）、乾燥させる |
| 口腔ケア（ベッド上） | **ガーグルベースン**を使う | — |
| 洗顔（ベッド上） | 温かいタオル | 冷水で絞ったタオル |
| 洗髪（浴室） | お湯で洗う（ドライシャンプーは入浴できないとき） | — |

<details>
<summary>✏️ 解いてみよう（第35回・事例）</summary>

一人暮らしの82歳の男性から「足の爪が伸びたので切ってほしい」と頼まれた。両足の親指の爪が伸びて両端が皮膚に食い込み、赤くなって熱をもっている。訪問介護員の対応として最も適切なものはどれ？

1. 親指に絆創膏を巻く
2. 家にある軟膏を親指に塗る
3. 蒸しタオルで爪を軟らかくしてから切る
4. 伸びている部分に爪やすりをかける
5. 爪は切らずに、親指の状態をサービス提供責任者に報告する

<details class="answer">
<summary>正解を見る</summary>

**正解：5**　赤み・熱感は炎症のサインです。爪や周りの皮膚に異常がある場合、介護福祉職は切らずに報告し、医療職につなぎます。
</details>
</details>

## ひっかけパターン集（皮膚・整容で「ほぼ×」）

| 選択肢の表現 | なぜ× |

| 皮膚の表面は弱アルカリ性 | 弱酸性 |
