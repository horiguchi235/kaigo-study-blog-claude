**この記事のポイント**

1. 皮膚の表面は**弱酸性**、バリアになるのは表皮のいちばん外側の**角質層**。
2. 乾燥肌・かゆみには「**こすらない・弱酸性の石けん・入浴後すぐ保湿・爪を短く**」。
3. 爪切りは「**入浴後・少しずつ・白い部分を1mm残す・やすりで整える**」。巻き爪や炎症は**切らずに報告**。

## ① 皮膚のしくみ

```
外側
 表皮 … 角質層（いちばん外側・バリア機能）〜 基底層（いちばん内側・新しい細胞をつくる）
 真皮 … 皮脂腺・汗腺・血管・神経
 皮下組織 … 脂肪
内側
```

| ○ 正しい | × よく出る誤り |
|---|---|
| 皮膚の表面は**弱酸性** | 弱アルカリ性 |
| 外界と接するのは**表皮** | 真皮に角質層がある |
| バリア機能をもつのは**角質層** | 基底層が最表面 |
| 不感蒸泄は1日**約500〜600mL** | — |
| 皮膚の表面には常在菌がいる | 表面は無菌 |
| ビタミン**D**の産生にかかわる | ビタミンB |
| 体臭の原因は**アポクリン腺**（エクリン腺は体温調節の汗） | エクリン腺が体臭の原因 |
| 高齢になると皮脂が**減る** | 皮脂が増える |

## ② 皮膚トラブル

| 病気 | 原因 | ポイント |
|---|---|---|
| **白癬**（水虫） | **真菌（カビ）** | 足の指の間をよく乾かす |
| **疥癬** | **ヒゼンダニ** | 強いかゆみ、**指の間に線状の発疹**。集団生活で最も注意 |
| 帯状疱疹 | ウイルス | 体の片側に帯状の水疱と痛み |
| 皮脂欠乏性湿疹・老人性掻痒症 | 皮膚の乾燥 | 高齢者に**多い**。すね・背中に多い |
| **褥瘡** | 圧迫による血流障害 | 好発部位は**仙骨部** |

<fig name="jokusou">

### 乾燥肌・かゆみがある人の入浴

| ○ | × |
|---|---|
| **こすらない**ように洗う | ブラシやナイロンタオルでこする |
| **弱酸性**の石けん | アルカリ性の石けん |
| 入浴後、**皮膚が乾ききる前に**保湿剤を塗る | 十分に乾いてから塗る |
| ぬるめのお湯 | 42℃以上の熱いお湯／硫黄を含む入浴剤 |
| 利用者の**爪を短く切る**（かき傷防止、第31回） | かくと軽快する |

### 状態別の洗い方

- 人工透析をしている人 → **柔らかいタオル**で洗う（シャントのある腕・皮膚が弱い）
- 褥瘡 → こすらず、周りをやさしく洗う
- 糖尿病の人 → 足の傷に気づきにくいので、**足（指の間・足の裏）を特に観察**する
- むくみ（浮腫）のある部位 → 押しつけない

> 傷（感染していないもの）は、乾かすより**湿潤環境**のほうが早く治ります。

## ③ 爪のしくみと爪切り

### 爪のしくみ

- 主成分は**タンパク質**（ケラチン）。1日に約0.1mm伸びる
- **さじ状爪**（スプーンのように反る）→ **鉄欠乏性貧血**
- ばち状指 → 心臓や肺の病気、青紫色の爪 → チアノーゼ

### 爪切りの手順

| ○ | × |
|---|---|
| **入浴後**など、爪が柔らかいときに切る | 乾燥させてから切る／入浴前に切る |
| **少しずつ**切る | 一度にまっすぐ切る |
| 白い部分を**1mmくらい残す** | 白い部分を残さない |
| 切ったあと**やすりで滑らかに**する | — |
| 巻き爪・腫れ・炎症があれば**切らずに報告** | 絆創膏や家の軟膏で対処する |

> 爪や周りの皮膚に異常がある場合や、**糖尿病などで専門的な管理が必要な人**の爪切りは、介護福祉職ではなく**看護師**などが行います。

## ④ 耳・目・ひげ・義歯

| 部位 | ○ | × |
|---|---|---|
| 耳 | まず**耳垢の状態を観察**する。乾いた耳垢は綿棒で**湿らせてから**、**入口付近だけ** | ピンセット、奥（中耳・内耳）まで、毎日の耳かき、耳垢塞栓を自分で取る |
| 目 | **目頭から目尻**へ拭く | 目尻から目頭 |
| ひげ（電気かみそり） | 皮膚に**直角**に当てる、皮膚を伸ばして剃る | 強く押し当てる |
| 義歯 | 流水で義歯用ブラシ、**水につけて**保管 | 熱湯で消毒、歯磨剤（傷がつく）、乾燥させる |

| 洗顔（ベッド上） | 温かいタオル | 冷水で絞ったタオル |
| 洗髪（浴室） | お湯で洗う（ドライシャンプーは入浴できないとき） | — |

## ⑤ 汗・におい・皮膚の病気と整容

- **褥瘡**は骨の出っぱった部分の圧迫だけでなく、**皮膚のずれや摩擦**でもできる。湿った皮膚もできやすいので排泄物はすぐ除き清潔に。**枕カバーやシーツの縫い目・しわが肌に当たらない**ようにする。
- **汗**：全身にある**エクリン腺**の汗は**99％が水**。汗が蒸発するときに熱を奪って**体温を下げる**。皮膚や呼吸から気づかずに失う水分＝**不感蒸泄**（成人で1日約900mL）。高齢者は汗をかきにくく暑さも感じにくい。
- **整容**は身だしなみだけでなく**生活意欲を高める**（化粧を勧めるなど）。歯みがきは**歯だけでなく歯ぐき・舌**も清掃する。
- **汗腺**：エクリン腺（全身・においのない汗で体温を下げる）とアポクリン腺（わき・陰部・においの元）。
- **加齢臭**の原因物質は**ノネナール**（水に溶けるので、濡れタオルで拭く・こまめに着替える）。
- **老人性皮膚掻痒症**：湯はぬるめ（37〜39℃）、**弱酸性の石けん**でこすらず洗い、**硫黄入りの入浴剤は避け**、拭いたらすぐ**保湿剤**。
- **帯状疱疹**は水疱がつぶれていなければ入浴可（温めると痛みが和らぐ）。**褥瘡**は入浴で清潔に保つのも治療の一部（マッサージや湿布は×）。
- 耳あかの掃除は綿棒を**入口から約1cm**まで。**鼻毛は抜かずに切る**。目やには**下まぶたを引いて瞬き**を促す。

## ひっかけパターン集（皮膚・整容で「ほぼ×」）

| 選択肢の表現 | なぜ× |
|---|---|
| 皮膚の表面は弱アルカリ性 | 弱酸性 |
| 乾燥肌をアルカリ性石けん・熱い湯で洗う | 皮脂を奪い、乾燥が悪化する |
| 保湿剤は十分乾いてから | 湿り気が残るうちに塗る |
| 爪の白い部分を残さず切る | 深爪・巻き爪の原因 |
| 耳垢をピンセットで取る／奥まで綿棒 | 耳を傷つける。医療職へ |
