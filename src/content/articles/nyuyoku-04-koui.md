**この記事のポイント**

1. 着脱の原則は「**脱健着患**」：脱ぐときは**健側**（麻痺のない側）から、着るときは**患側**（麻痺のある側）から。
2. 認知症・失行の人には、**代わりに着せない**。印をつける・動作を見せる・順番に声をかける。
3. 靴は「**かかとがある・足の甲を覆う・つま先に0.5〜1cmの余裕**」。

## ① 片麻痺の人の着脱

**脱健着患**（だっけんちゃっかん）

| | 順番 | 理由 |
|---|---|---|
| 脱ぐとき | **健側**から脱ぐ → 最後に患側 | 健側が自由になり、患側を無理に曲げずに済む |
| 着るとき | **患側**から着る → 最後に健側 | 動かしにくい患側に先に通しておく |

<fig name="step-dakken">

**前あきの上着（右片麻痺の場合）**
- 着るとき：**右袖を肩までしっかり**通してから、左袖を通す
- 脱ぐとき：<strong>左（健側）</strong>の肩を下げて、左袖から腕を抜く

**ズボン**も同じ：はくときは**患側の足から**通し、脱ぐときは健側から。下肢の筋力が弱い人は**座って**行う。

**拘縮（関節がかたまって動きにくい状態）がある腕に袖を通すとき**
- 着替えの前に関節を**ゆっくり**動かしておく
- 肘や手首は**下から支える**（上からつかむ・指先に力を入れるは×）

> 服の形は「誰が着るか」で変わります。片麻痺の人が**自分で**着脱するなら、伸縮性とゆとりのある**かぶり式**が着やすいこともあります。一方、拘縮や肩の痛みがあって**介助で**着替えるときは、腕を大きく上げずに済む**前開き**が基本です（第34回）。小さいボタン・ひも・伸縮性のないズボンは×です。

## ② 障害・症状に応じた更衣の支援

| 状態 | ○ 正解 | × |
|---|---|---|
| **着衣失行**（脳の損傷で、手足は動くのに服の着方そのものが分からなくなる。高次脳機能障害の一つ） | **左右や上下がわかるように衣類に印**をつける | 全手順を一度に口頭で説明／方法を毎回変える |
| **実行機能障害**（手順を組み立てられない。認知症の中核症状の一つ） | **隣で着る動作を見せる**、**着る順番に合わせて一つずつ**声をかける | 衣類をまとめて渡す／職員が代わりに着せる |
| 認知症で季節外れの服を着ている | 「**汗をかいていますね。上着を脱ぎませんか**」と働きかける | 鏡を見せて間違いを指摘／「今は夏ですよ」 |
| 手指の細かい動作が難しい | **マグネット式ボタン** | — |
| 頸髄損傷（C6まで残存＝手首は動くが指は動かしにくい） | **靴下にループ**をつけて指を引っかける | — |
| 下肢の筋力低下 | **座って**更衣する | 立位で更衣 |

### 生活の中の衣服

- **昼と夜で着替える**と生活のリズムが整う
- 衣服は**介護のしやすさより本人の好み**で、**本人が選ぶ**（気候に合わせて支援者が選ぶは×）
- 衣服の役割：保温・皮膚の保護・身だしなみ・**自己表現**

### ICFで見る身じたくの目的

<fig name="icf">

ICF（国際生活機能分類）は、生活のしかたを3つの面で見ます。**心身機能・身体構造**＝体や心の働き、**活動**＝身の回りのことをする（セルフケアなど）、**参加**＝社会や人とのかかわり。身じたくでは「**体温を調整する**」が**心身機能・身体構造**、「セルフケア」が活動、「自己表現・人間関係」が参加です。

## ③ 衣服と靴の選び方

### 保温

- 衣類の間に**薄手の衣類を重ねて**着る（空気の層ができる、第30回）
- きつい服・袖幅の大きい服は熱が逃げる
- 体と服の間の温度・湿度＝**衣服気候**。快適なのはおよそ温度32℃前後・湿度50％前後。肌着は**吸湿性・通気性**のよいものを

### 衣服の素材

| 素材 | 長所 | 短所 |
|---|---|---|
| 綿 | **吸湿性**がよく、洗濯に強い | しわになりやすい |
| 毛・絹 | 保温性（毛）、なめらか（絹） | **虫**やアルカリに弱い |
| ポリエステル | しわになりにくく乾きやすい | 吸湿性が低く、静電気が起きやすい |
| アクリル | 軽く暖かい | 毛玉ができやすい |
| ナイロン | 丈夫 | 熱に弱い |

化学繊維は火に弱い（溶ける）ので、調理のときなどに注意します。洗い方は[洗濯・しみ抜き・掃除・ノロウイルス](../sumai-03-sentaku/)へ。

### 転びにくい靴

| ○ | × |
|---|---|
| **足背（足の甲）をしっかり覆う** | かかとのない脱ぎやすい靴（スリッパ） |
| つま先に**0.5〜1cm**の余裕 | ぴったり・指が固定される |
| つま先が少し上がっている | つま先が床に近い |
| 軽い・靴底に適度な厚みと溝 | 重い・底が薄く硬い・溝が浅い |

> 靴下の**滑り止め**は、すり足の高齢者では床や靴の中で引っかかって**つまずく**原因になることがあり、第36回では×でした。

## ④ 寝たままの着替え・和式寝衣

- 左片麻痺の人を寝たまま着替えるとき：介助者は<strong>健側（右）</strong>に立ち、新しい上着は<strong>患側（左）</strong>に置いておく（脱健着患の順で動けるように）。
- **和式寝衣**（浴衣型の寝間着）の交換：新しい寝衣の**背縫いを背骨（脊柱）に合わせる**。袖は**肩→肘→手**の順に抜く。
- 前の合わせは**右前**：**右の身頃を先に体に当て（下）、左の身頃をその上に重ねる**。相手から見ると、えりが「y」の字になります。亡くなった人だけ逆の**左前**にします（[終末期の介護・家族支援・死後のケア](../mitori-02-kaigo/)）。
- 腰紐は**横で結ぶ**（背中で結ぶと圧迫されて褥瘡の原因）。

## ひっかけパターン集（更衣で「ほぼ×」）

| 選択肢の表現 | なぜ× |
|---|---|
| 片麻痺の人が患側から脱ぐ | 脱ぐのは健側から |
| 患側の袖を肘までだけ通す | 肩まで通さないと健側が通らない |
| 間違いを鏡で見せて指摘する | 自尊心を傷つける |
| 職員が衣服を選ぶ・まとめて渡す | 自己決定と残存能力を奪う |
| スリッパ・かかとのない靴 | 脱げて転倒する |
| 和式寝衣を左前に合わせる | 生きている人は右前（左前は死後） |
