名前が似ている「審査会」「委員会」は、<strong>「行政の決定に不満」なのか「サービスの中身に不満」なのか</strong>で見分けます。

**この記事のポイント**

1. **介護認定審査会**（市町村）＝要介護度を**判定する**ところ（二次判定）。
2. **介護保険審査会**（都道府県）＝認定や保険料など**市町村の決定（処分）への不服申立て**。
3. **国保連**＝介護保険サービスの**質への苦情**、介護報酬の審査・支払い。
4. **運営適正化委員会**（都道府県社協）＝**福祉サービス全般の苦情解決**と日常生活自立支援事業の監視。
5. 介護保険サービスの苦情は、まず**事業所**（苦情受付担当者）へ → 解決しなければ**市町村**や**国保連**へ。事業所には苦情解決の体制（受付担当・責任者・**第三者委員**）がある。

---

## ① 一覧表

先に言葉をそろえます。

- **処分**：市町村などの行政が決めたこと（要介護度の認定、保険料の額、障害福祉サービスの支給決定など）
- **審査請求**：その決定を「見直してほしい」と申し立てること（不服申立て）
- **あっせん**：間に入って、話し合いで解決できるように取り持つこと

| 機関 | 置かれる所 | 何をする？ |
|---|---|---|
| **介護認定審査会** | **市町村** | 認定調査・主治医意見書をもとに要介護度を**二次判定** |
| **介護保険審査会** | **都道府県** | 要介護認定・保険料など<strong>保険者（市町村）の処分への審査請求（不服申立て）</strong> |
| **市町村**（保険者） | 市町村 | 介護保険サービスの**苦情のいちばん身近な窓口**。事業所への調査・指導も行う |
| <strong>国民健康保険団体連合会（国保連）</strong> | 各都道府県 | 介護保険サービスの**質に関する苦情の受付・調査・指導助言**（市町村で解決しにくいものなど）、介護報酬の審査・支払い |
| **運営適正化委員会** | **都道府県社会福祉協議会** | **福祉サービスの利用者からの苦情の解決**（相談・助言・あっせん）、日常生活自立支援事業の運営監視 |
| **市町村審査会** | 市町村 | 障害支援区分の判定 |
| **障害者介護給付費等不服審査会** | 都道府県（任意設置） | 障害支援区分・支給決定などへの不服を審理する（**審査請求先は都道府県知事**） |
| **地域包括支援センター運営協議会** | 市町村 | センターの公正・中立な運営を確認 |

---

## ② 苦情はどこへ？（流れ）

1. まず**事業所の苦情受付担当者**・苦情解決責任者・**第三者委員**へ（社会福祉法で事業者の努力義務）
2. 解決しなければ、次の窓口へ

| | 介護保険のサービス | 障害福祉のサービス |
|---|---|---|
| サービスの中身への苦情 | **市町村**や**国保連**（国民健康保険団体連合会） | 市町村、**運営適正化委員会**（都道府県社協） |
| 行政の決定（処分）への不服 | 要介護認定・保険料など → **介護保険審査会**（都道府県）に審査請求 | 障害支援区分・支給決定など → **都道府県知事**に審査請求（障害者介護給付費等不服審査会が審理） |
| 期限 | 決定を知った日の翌日から**3か月以内** | 決定を知った日の翌日から3か月以内 |

> 介護保険のサービスでも、福祉サービスとして運営適正化委員会に相談することはできます。試験では「**介護保険の苦情＝まず事業所 → 解決しなければ市町村や国保連**」「**福祉サービス全般の苦情＝運営適正化委員会**」の組み合わせで覚えます。

---

## ③ サービスを外からチェックするしくみ

苦情の窓口とは別に、サービスの質を外から見るしくみがあります。

| しくみ | 根拠・実施 | 中身 |
|---|---|---|
| **福祉サービス第三者評価** | 社会福祉法（**任意で受ける**） | 第三者の評価機関が、事業所のサービスの質を評価して公表 |
| **介護サービス情報の公表** | 介護保険法（**都道府県**） | 介護サービス事業所は、サービスの内容や運営の情報を都道府県に**報告する義務**があり、インターネットで公表される |
| **外部評価** | 介護保険法（グループホーム） | グループホームが外部の評価機関の評価を受ける。運営推進会議での評価で代えることもできる |
| **運営推進会議** | 地域密着型サービスの事業所 | 利用者・家族・地域住民・市町村職員などとサービスを評価し、透明性を高める |

## ひっかけパターン集

| 選択肢の表現 | なぜ× |
|---|---|
| 介護保険審査会は要介護度を判定する | 判定は**介護認定審査会**。審査会は**不服申立て** |
| 介護保険審査会は市町村に置かれる | **都道府県** |
| 運営適正化委員会は市町村社協に置かれる | **都道府県社協** |
| 介護保険審査会は事業所の誇大広告を審査する | 扱うのは**行政処分への不服** |
| サービスの質の苦情は介護保険審査会へ | まず事業所 → 解決しなければ**市町村**や**国保連** |
| 福祉サービス第三者評価はすべての事業所に義務づけられている | 第三者評価は**任意**。報告が義務なのは介護サービス情報の公表 |
