**この記事のポイント**

1. 尿失禁は「**どこで困っているか**」で4タイプに分かれる。表を1枚覚えれば、しくみの問題も対応の問題も解ける。
2. 認知症の人の失禁（機能性尿失禁）は、**トイレの場所・時間・環境を整える**のが正解。
3. 「**水分を控える**」「**おむつにする**」は、排泄の問題ではほぼ必ず不正解。

## ① 正常な尿と、異常のサイン

まずは「正常」を知ることから始めます。異常は、正常との違いとして出題されます。

**尿の通り道**：腎臓で血液がこされて尿ができる → **尿管** → **膀胱**にたまる（ためられるのは約500mL。多くは200〜500mLほどたまると尿意を感じる）→ **尿道**から出る。

- 尿道の長さは**男性16〜18cm、女性3〜4cm**。女性は短くまっすぐなので、細菌が入りやすい
- 男性は膀胱の下にある**前立腺**が年とともに大きくなり、尿の通り道を押して尿が出にくくなる。尿が出にくい人には、水分をとってもらい、下半身を冷やさないようにする
- 排尿・排便の調節には**自律神経**がかかわっている

| 項目 | 正常 | 異常のサイン |
|---|---|---|
| 色・見た目 | 淡黄色〜淡黄褐色で**透明** | 白く濁る（膀胱炎などの感染）、赤色（血尿：尿路結石・腫瘍・腎臓の病気など） |
| におい | 排尿直後は**ほぼ無臭** | 直後からアンモニア臭・強い腐ったにおい（膀胱炎などの感染症を疑う） |
| 性質 | **弱酸性** | — |
| 成分 | たんぱく・糖はほぼ出ない | 尿糖（糖尿病）、尿たんぱく（腎臓病） |
| 量 | 1日 約1,000〜1,500mL（1,000〜2,000mLとする資料もある）。1回200〜500mL | **多尿**＝1日3,000mL以上（糖尿病、尿崩症＝尿を濃くするホルモンが足りない病気など）、**乏尿**＝400mL以下、**無尿**＝100mL以下（乏尿・無尿は脱水・腎不全・尿路結石など） |
| 回数 | 日中4〜7回程度（1日4〜8回くらいとする資料もある） | **頻尿**＝日中8回以上、**夜間頻尿**＝夜2回以上（転倒の原因に）、**尿閉**＝膀胱に尿があるのに出せない |

**よく出る一言**

- 多尿の原因 → **糖尿病**（尿に出た糖が水を引き込み、尿量が増える）。**脱水では尿は減る**ので、多尿の原因ではない
- 膀胱炎の代表的な症状 → **排尿時痛**（発熱はふつう出ない。熱が出たら腎盂腎炎を疑う）。**腎盂腎炎**＝膀胱の細菌が腎臓まで上がって起こる感染で、高い熱が出る
- 女性に尿路感染症が多い理由 → **尿道が短く（約4cm）、まっすぐだから**。男性は加齢で**前立腺肥大**が起こり、尿の勢いが落ちる
- 尿は排泄直後は無菌。時間がたつと細菌がアンモニアをつくって臭くなる

> 便のかたさを記録する**ブリストル便性状スケール**は、[排泄①「便秘の種類と自然排便の介助」](../haisetsu-01-benpi/)の④にまとめています。1〜7の7段階で、**3〜5が普通便（正常）の範囲**です。

### 尿路感染症と予防

尿の通り道（腎臓・尿管・膀胱・尿道）に細菌が入って起こる感染症です。

| 種類 | 主な症状 |
|---|---|
| **膀胱炎** | 排尿時の痛み・頻尿・尿の濁り（ふつう熱は出ない） |
| **腎盂腎炎** | 腎臓まで広がったもの。**高い熱**・寒気・吐き気 |

- **高齢者・女性**に多い。高齢者では、**尿失禁が最初のサイン**になることもある
- 原因：男性は**前立腺肥大症**、女性は閉経後に尿道の粘膜が弱ること。男女ともに、**おむつの長時間使用**や**膀胱留置カテーテル**
- 予防：尿意があればトイレへ行く、陰部は**前から後ろへ**拭く、**十分な水分**をとる、蓄尿バッグは**膀胱より低く**置く（陰部洗浄は [排泄③](../haisetsu-03-kaijo/)、留置カテーテルは [排泄④](../haisetsu-04-iryouteki/)）

## ② 尿失禁の4タイプ

ここがこの記事の核心です。**15年で6問**出ており、事例問題でも頻出です。

| タイプ | ひとことで | 典型的な場面 | 主な原因・多い人 | 対応 |
|---|---|---|---|---|
| **腹圧性** | お腹に力が入ると漏れる | 咳・くしゃみ・重い物を持つ | 骨盤底筋群の筋力低下（**女性**・出産経験・加齢） | 骨盤底筋訓練 |
| **切迫性** | 急に強い尿意、我慢できない | トイレに行く途中で漏れる | 尿を**ためる**機能の障害（過活動膀胱・脳血管障害） | 膀胱訓練・受診 |
| **溢流性** | 尿を出しきれず、膀胱にたまった尿があふれて漏れる | 少しずつダラダラ漏れる・残尿 | 尿を**出す**機能の障害（**前立腺肥大症**＝男性） | 受診（導尿など） |
| **機能性** | 膀胱は正常、でも間に合わない | トイレの場所がわからない・歩くのが遅い | **認知症**・運動機能の低下 | 誘導・環境整備（→③へ） |

- **骨盤底筋群**＝骨盤の底でハンモックのように膀胱・子宮・直腸を支える筋肉。ゆるむと、お腹に力が入ったときに尿道を締めきれない
- **過活動膀胱**＝膀胱が勝手に縮み、急に強い尿意が起こる状態
- **膀胱訓練**＝尿意を少しがまんして、トイレの間隔を少しずつ延ばす練習
- **導尿**＝細い管を尿道から膀胱に入れて尿を出すこと

**覚え方のコツ**：「どこで困っているか」で分けると混乱しません。

- 筋肉（骨盤底）が弱い → 腹圧性
- 膀胱が**ためられない** → 切迫性
- 膀胱から**出せない** → 溢流性
- 膀胱も筋肉も正常、**脳や足**の問題 → 機能性

> 4タイプのほかに選択肢で出てくる用語：**反射性尿失禁**＝脊髄損傷などで尿意を感じられず、反射的に漏れるもの。**心因性頻尿**＝緊張や不安でトイレが近くなるもの（失禁ではない）。

### 過去問で確認

**第33回** 認知機能は正常で杖歩行の83歳女性。咳やくしゃみで尿が漏れるので、外出を控えるようになった。どのタイプか。
→ **腹圧性尿失禁**。「咳・くしゃみ」と「女性」がそろったら腹圧性です。第29回にも同じ事例が出ており、そこでは原因として「**骨盤底筋群の機能低下**」が正解でした。

**第32回** グループホームで暮らすアルツハイマー型認知症の80歳男性。「トイレに行きたい」とホーム内を歩き回ったあとで失禁する。
→ **機能性尿失禁**。尿意はあるのに、トイレの場所がわからず間に合わないケースです。

**第25回** 「急に強い尿意を感じて我慢できない」原因は何か。
→ **尿をためる機能の障害**。「出す機能の障害」（溢流性の原因）とのひっかけに注意してください。

## ③ 機能性尿失禁・認知症の人の排泄ケア

②で学んだ「機能性＝膀胱は正常、トイレにたどり着けない」がわかっていれば、正解はすべて「**たどり着けるように整える**」になります。

| 困っていること | 正解になる対応 |
|---|---|
| トイレの場所がわからない | 入口に「**トイレ**」と書いた紙を貼る |
| 夜、トイレ以外で排尿してしまう | トイレの**照明をつけ、ドアを開けておく** |
| 間に合わない | **早めのトイレ誘導**、本人の**排泄パターン**に合わせて誘導 |
| 汚れた衣類をタンスに隠す | 責めずに、汚れ物を**入れておける場所をつくる** |
| 尿意を言葉で伝えられない | そわそわする・立ち上がる・ズボンを触るなどの**サイン**を見つけて誘導する |
| トイレ以外の場所で排泄してしまう | **いつ・どこで**排泄したかを記録し、その前に誘導する |
| 服の脱ぎ方がわからず、着たまま排泄してしまう | ウエストがゴムのズボンなど、**脱ぎ着しやすい服**を用意する |

**よく出る不正解**：骨盤底筋訓練（腹圧性の対策）／膀胱訓練（切迫性の対策）／おむつに替える／水分を減らす／ほかの利用者と**同じ時間に**一斉に誘導する

→ **排泄パターンに合わせてトイレに誘導**する。「吸収量の多いパッドにする」「水分を控える」は誤りです。

## ④ 排泄ケアの心理的配慮・おむつの考え方

排泄はもっとも人に見られたくない行為です。この章の問題は「**本人の気持ちを守る選択肢**」を選べば正解できます。

- 失禁したら、周囲に気づかれないよう**さりげなくトイレへ誘導して交換**する（「尿のにおいがしますよ」と言うのは×）
- 失禁後にトイレが近くなった人には、まず**不安に感じていることを聴く**
- おむつは「家族が楽だから」で使わない。**尿意があるならトイレへ**。おむつを使い続けると、尿路感染症や自立度の低下につながる
- 家族への助言は「**本人の羞恥心に気を配りましょう**」
- 尿量が変わらないのに回数だけ増えた → 不安による頻尿（**心因性頻尿**）を疑い、まず気持ちを聴く
