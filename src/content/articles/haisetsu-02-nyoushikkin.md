**この記事のポイント**

1. 尿失禁は「**どこで困っているか**」で4タイプに分かれる。表を1枚覚えれば、しくみの問題も対応の問題も解ける。
2. 認知症の人の失禁（機能性尿失禁）は、**トイレの場所・時間・環境を整える**のが正解。
3. 「**水分を控える**」「**おむつにする**」は、排泄の問題ではほぼ必ず不正解。

## ① 正常な尿と、異常のサイン【こころとからだのしくみ】

まずは「正常」を知ることから始めます。異常は、正常との違いとして出題されます。

| 項目 | 正常 | 異常のサイン |
|---|---|---|
| 色・見た目 | 淡黄色〜淡黄褐色で**透明** | 濁り（感染）、赤色（血尿） |
| におい | 排尿直後は**ほぼ無臭** | 直後からアンモニア臭（膀胱炎など） |
| 性質 | **弱酸性** | — |
| 成分 | たんぱく・糖はほぼ出ない | 尿糖（糖尿病）、尿たんぱく（腎臓病） |
| 量 | 1日 約1,000〜1,500mL | **多尿＝糖尿病**、乏尿・無尿 |

**よく出る一言**

- 多尿の原因 → **糖尿病**（尿に出た糖が水を引き込み、尿量が増える）
- 膀胱炎の代表的な症状 → **排尿時痛**（発熱はふつう出ない。熱が出たら腎盂腎炎を疑う）
- 女性に尿路感染症が多い理由 → **尿道が短く、まっすぐだから**

> 便の性状もここで押さえます。**ブリストル便性状スケール**では、3〜5（やや硬い便・普通便・やや軟らかい便）が「普通便」の範囲です。1〜2は便秘寄り、6〜7（泥状便・水様便）は下痢寄りです。

## ② 尿失禁の4タイプ【こころとからだのしくみ】

ここがこの記事の核心です。**15年で6問**出ており、事例問題でも頻出です。

| タイプ | ひとことで | 典型的な場面 | 主な原因・多い人 | 対応 |
|---|---|---|---|---|
| **腹圧性** | お腹に力が入ると漏れる | 咳・くしゃみ・重い物を持つ | 骨盤底筋群の筋力低下（**女性**・出産経験・加齢） | 骨盤底筋訓練 |
| **切迫性** | 急に強い尿意、我慢できない | トイレに行く途中で漏れる | 尿を**ためる**機能の障害（過活動膀胱・脳血管障害） | 膀胱訓練・受診 |
| **溢流性** | 出したいのに出ず、あふれて漏れる | 少しずつダラダラ漏れる・残尿 | 尿を**出す**機能の障害（**前立腺肥大症**＝男性） | 受診（導尿など） |
| **機能性** | 膀胱は正常、でも間に合わない | トイレの場所がわからない・歩くのが遅い | **認知症**・運動機能の低下 | 誘導・環境整備（→③へ） |

**覚え方のコツ**：「どこで困っているか」で分けると混乱しません。

- 筋肉（骨盤底）が弱い → 腹圧性
- 膀胱が**ためられない** → 切迫性
- 膀胱から**出せない** → 溢流性
- 膀胱も筋肉も正常、**脳や足**の問題 → 機能性

> 選択肢で出てくるほかの用語：**反射性尿失禁**＝脊髄損傷などで尿意を感じられず、反射的に漏れるもの。**心因性頻尿**＝緊張や不安でトイレが近くなるもの（失禁ではない）。

### 過去問で確認

**第33回** 認知機能は正常で杖歩行の83歳女性。咳やくしゃみで尿が漏れるので、外出を控えるようになった。どのタイプか。
→ **腹圧性尿失禁**。「咳・くしゃみ」と「女性」がそろったら腹圧性です。第29回にも同じ事例が出ており、そこでは原因として「**骨盤底筋群の機能低下**」が正解でした。

**第32回** グループホームで暮らすアルツハイマー型認知症の80歳男性。「トイレに行きたい」とホーム内を歩き回ったあとで失禁する。
→ **機能性尿失禁**。尿意はあるのに、トイレの場所がわからず間に合わないケースです。

**第25回** 「急に強い尿意を感じて我慢できない」原因は何か。
→ **尿をためる機能の障害**。「出す機能の障害」（溢流性の原因）とのひっかけに注意してください。

## ③ 機能性尿失禁・認知症の人の排泄ケア【生活支援技術】

②で学んだ「機能性＝膀胱は正常、トイレにたどり着けない」がわかっていれば、正解はすべて「**たどり着けるように整える**」になります。

| 困っていること | 正解になる対応 |
|---|---|
| トイレの場所がわからない | 入口に「**トイレ**」と書いた紙を貼る |
| 夜、トイレ以外で排尿してしまう | トイレの**照明をつけ、ドアを開けておく** |
| 間に合わない | **早めのトイレ誘導**、本人の**排泄パターン**に合わせて誘導 |
| 汚れた衣類をタンスに隠す | 責めずに、汚れ物を**入れておける場所をつくる** |

**よく出る不正解**：骨盤底筋訓練（腹圧性の対策）／膀胱訓練（切迫性の対策）／おむつに替える／水分を減らす／ほかの利用者と**同じ時間に**一斉に誘導する

### 過去問で確認

**第38回** 認知機能の低下で、トイレ以外の場所で排泄するようになったグループホームの85歳男性。
→ トイレの出入口に「**トイレ**」と書いた紙を貼る。「骨盤底筋訓練」は腹圧性の対策なので誤りです。

**第34回** 夜間、トイレではない場所で排尿してしまう機能性尿失禁の利用者。
→ トイレの**照明をつけて、ドアを開けておく**。

**第24回** パッドを自分で交換している軽度認知症の人の陰部に、発赤が見つかった。
→ **排泄パターンに合わせてトイレに誘導**する。「吸収量の多いパッドにする」「水分を控える」は誤りです。

## ④ 排泄ケアの心理的配慮・おむつの考え方【生活支援技術】

排泄はもっとも人に見られたくない行為です。この章の問題は「**本人の気持ちを守る選択肢**」を選べば正解できます。

- 失禁したら、周囲に気づかれないよう**さりげなくトイレへ誘導して交換**する（「尿のにおいがしますよ」と言うのは×）
- 失禁後にトイレが近くなった人には、まず**不安に感じていることを聴く**
- おむつは「家族が楽だから」で使わない。**尿意があるならトイレへ**。おむつを使い続けると、尿路感染症や自立度の低下につながる
- 家族への助言は「**本人の羞恥心に気を配りましょう**」

### 過去問で確認

**第35回** 「排泄は最期まで人の世話にならない」と言っていた女性が、失禁をきっかけにトイレの近くで過ごすようになり、日中の排尿回数が増えた（水分量・尿量は変わらない）。
→ **排泄について不安を感じていないかを聞く**。尿量が変わらず回数だけ増えているので、不安による頻尿が疑われます。水分制限や薬の相談は、最初の対応ではありません。

**第36回** 尿意があるのに、夫の介護負担を減らすため終日おむつを使い、尿路感染症を繰り返していた認知症の女性が施設に入所した。
→ **おむつを使わずにトイレへ誘導**する。おむつ自体が感染の原因になっていた、という読み解きがポイントです。

## ⑤ 尿・便の量と回数のめやす

- **尿量の異常**：**無尿**＝1日100mL以下／**乏尿**＝1日400mL以下／**多尿**＝1日3000mL以上（尿量は**1日全体**で判断）。**頻尿**＝回数が多い／**尿閉**＝膀胱に尿があるのに出せない。
- **尿失禁の5タイプ**：腹圧性（せき・くしゃみで漏れる、女性に多い）／切迫性（急な強い尿意）／**溢流性（尿が出しきれず、尿意がないまま少しずつあふれる）**／機能性（移動や認知の問題で間に合わない）／反射性（脊髄の障害などで尿意がなく反射で出る）。
- **便の観察**（色・形・かたさ・回数・血の混入）は健康状態を知る大事な目安。いつもとの違いを記録・報告。
- **高齢者の肺炎**は、熱やせきが目立たず「なんとなく元気がない」など**非特異的な症状**で始まることがある。
- **感染性廃棄物のバイオハザードマーク**：**赤＝液状・泥状（血液など）**／**橙＝固形（血のついたガーゼなど）**／**黄＝鋭利なもの（注射針など）**の3色。
- 男性生殖器：精巣＝精子と男性ホルモン／前立腺＝精液の成分を分泌（高齢男性は前立腺肥大症に注意）。
- **尿の量**：1日1,000〜2,000mL。**乏尿＝400mL以下**、**無尿＝100mL以下**、**多尿＝3,000mL以上**。
- 正常な尿は**排泄直後は無菌で弱酸性**。時間がたつと細菌がアンモニアをつくって臭くなる。白く濁る＝膀胱炎、赤い＝結石・腫瘍など。
- **頻尿**＝日中8回以上、**夜間頻尿**＝夜2回以上（転倒の原因に）。
- 女性は**尿道が短く（3〜4cm）まっすぐ**なので尿路感染症が起こりやすい。男性は**前立腺肥大**で尿の勢いが落ちる。
- **嵌入便**＝直腸に固い便が詰まり、その脇から**水様便がもれ続ける**状態。下痢と間違えやすい。

## ひっかけパターン集（排泄の問題で「ほぼ×」）

| 選択肢の表現 | なぜ× |
|---|---|
| 水分摂取を控える | 脱水・便秘・尿路感染症を招く |
| おむつ（リハビリパンツ）を使用する | 自立を妨げ、尿路感染症の原因になる。尿意があるならトイレへ |
| ほかの利用者と同じ時間に誘導する | 排泄パターンは人それぞれ |
| 失禁を本人や周りに指摘する | 羞恥心・自尊心を傷つける |
| 骨盤底筋訓練（機能性尿失禁の人に） | 腹圧性の対策。タイプの取り違え |
