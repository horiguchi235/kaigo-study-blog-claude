**この記事のポイント**

1. 1gあたりのエネルギーが最大なのは**脂質**。低栄養のサインは「**1か月に3%以上の体重減少**」。指標に**血圧は入らない**。
2. 脱水のサインは「**活動性の低下・皮膚をつまむと戻らない・尿が少なく濃い**」。勧めるのは**経口補水液**、むせる人には**ゼリー**。
3. 腎不全は**たんぱく質制限**、透析は**カリウム制限で野菜はゆでこぼす**。COPD・逆流性食道炎は**少量ずつ回数を分けて**。

## ① 栄養素と低栄養【こころとからだのしくみ／生活支援技術】

| 栄養素 | 試験に出る働き |
|---|---|
| **三大栄養素** | **炭水化物（糖質）・脂質・たんぱく質**。水分・ビタミン・ミネラルは入らない |
| **脂質** | **1gあたりのエネルギーが最大**（約9kcal）。**ホルモンの原料** |
| **たんぱく質** | 筋肉・**酵素**の材料。最大のエネルギー源ではない |
| **ナトリウム** | **血圧の調節** |
| カリウム | 血圧を**下げる**方向に働く。骨の形成ではない |
| ビタミンD | **カルシウムの吸収**を助ける |
| ビタミンB1 | **糖質をエネルギーに変える** |
| ビタミンA・D・E・K | **脂溶性**（Aは水溶性、は×） |

- 栄養素の大部分を吸収するのは**小腸**
- 必要エネルギー量＝基礎代謝量×活動係数×ストレス係数。第29回は**約1,200kcal**

### 低栄養

| ○ 低栄養の指標・サイン | × |
|---|---|
| 食事摂取量・**BMI**・**体重減少率**・**血清アルブミン値** | **血圧値** |
| **1か月に3%以上**の体重減少 → PEMを疑う | BMI25以上（肥満）・低血圧・声がれ |
| **偏りのある食べ方**をする | 唾液が増える・食べこぼしが減る・体重が増える |
| お茶漬けやうどんで済ませる・疲れやすい → **主菜**（肉・魚・卵・大豆）を勧める | 主食を勧める |

## ⑤ 五大栄養素・ビタミンとミネラル・塩分と脱水

<fig name="suibun">

- **BMI**＝体重(kg)÷身長(m)÷身長(m)。18.5未満がやせ、25以上が肥満の目安。**栄養アセスメント**：身体計測（身長・体重・体重減少率）／**生理・生化学検査（血液検査など）**／食事調査（面接・質問紙）。
- **エネルギー**：糖質・たんぱく質＝**1gあたり4kcal**、脂質＝**9kcal**。**食物繊維はビタミンではない**（消化されにくい成分で整腸作用）。
- **ビタミン**：A＝目・皮膚粘膜（レバー・緑黄色野菜）／**D＝カルシウムの吸収（魚・日光）**／**K＝血液を固める（納豆・小松菜）**／B1＝糖質の代謝（不足で脚気）／E＝抗酸化。
- **脱水の種類**：**高張性**＝水分が多く失われる（のどが渇く）／**低張性**＝ナトリウムが多く失われる（汗のあとの水だけの補給などで起こる、だるさ・意識障害）／等張性。体重の<strong>2〜3％</strong>の水分が失われるとのどの渇きが出る。
- **骨粗鬆症の予防**：カルシウム・**ビタミンD**・たんぱく質、日光浴、**骨に適度な負荷をかける運動**（負荷を減らすのは×）、禁煙。閉経後の女性に多い。
- **食物アレルギー**の症状で最も多いのは**皮膚症状（じんましん）**。複数の臓器に症状が出る**アナフィラキシー**は救急対応。
- **貧血を起こす病気**：慢性腎臓病（エリスロポエチン低下）・悪性貧血（ビタミンB12）・関節リウマチ・がんなど。**脂質異常症は貧血の原因ではない**。
- **腎臓病・透析**：絶対安静にする必要はなく、病状に合わせて活動する。**血液透析**は腕の動脈と静脈をつないだ**シャント**を使う（シャント側の腕で**血圧測定・採血をしない**、圧迫しない）。**透析をした日は入浴を控える**（針を刺した部分の感染・出血予防）。**腹膜透析**は自宅でできる。
- 筋肉の働き＝体を動かす・姿勢保持・**熱をつくる**・代謝（皮膚の保護は皮膚の役割）。
- **五大栄養素**：炭水化物・脂質・たんぱく質（三大栄養素）＋**ミネラル（無機質）・ビタミン**。たんぱく質を構成するアミノ酸のうち、体内でつくれない**必須アミノ酸は9種類**。
- **ビタミン不足で起こる病気**：A＝夜盲症、D＝骨軟化症・骨粗鬆症、K＝血液が固まりにくい、**B1＝脚気**、B12・葉酸＝巨赤芽球性貧血、ナイアシン＝ペラグラ、**C＝壊血病**。水溶性ビタミン（B群・C）は体にためられないので**毎日とる**。
- **ミネラル**：カルシウム不足→骨粗鬆症、鉄不足→**鉄欠乏性貧血**、**亜鉛不足→味覚障害**（カキ・レバー・ナッツ）。
- **低栄養**のめやす：血清アルブミン値**3.5g/dL以下**。食欲が落ちた高齢者には、季節を感じる食材や盛りつけの工夫も。
- **食塩**の目標量：男性**7.5g未満**・女性**6.5g未満**。減塩には、だし・酸味・香味野菜・香辛料を使う。
- **脱水予防**：スポーツドリンク・**経口補水液**・ゼリー・果物・汁物。**アルコールやコーヒーは利尿作用**があるので水分補給には向かない。
- 食生活の言葉：**中食**（総菜・弁当を家で食べる）、**個食**（同じ食卓で別々のものを食べる）、**孤食**（ひとりで食べる）。
