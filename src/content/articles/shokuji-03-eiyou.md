**結論を3行で**

1. 1gあたりのエネルギーが最大なのは**脂質**。低栄養のサインは「**1か月に3%以上の体重減少**」。指標に**血圧は入らない**。
2. 脱水のサインは「**活動性の低下・皮膚をつまむと戻らない・尿が少なく濃い**」。勧めるのは**経口補水液**、むせる人には**ゼリー**。
3. 腎不全は**たんぱく質制限**、透析は**カリウム制限で野菜はゆでこぼす**。COPD・逆流性食道炎は**少量ずつ回数を分けて**。

## ① 栄養素と低栄養【こころとからだのしくみ／生活支援技術】

| 栄養素 | 試験に出る働き |
|---|---|
| **三大栄養素** | **炭水化物（糖質）・脂質・たんぱく質**（第34回）。水分・ビタミン・ミネラルは入らない |
| **脂質** | **1gあたりのエネルギーが最大**（約9kcal）（第28回）。**ホルモンの原料**（第26回） |
| **たんぱく質** | 筋肉・**酵素**の材料（第30回）。最大のエネルギー源ではない |
| **ナトリウム** | **血圧の調節**（第33回） |
| カリウム | 血圧を**下げる**方向に働く。骨の形成ではない |
| ビタミンD | **カルシウムの吸収**を助ける |
| ビタミンB1 | **糖質をエネルギーに変える** |
| ビタミンA・D・E・K | **脂溶性**（Aは水溶性、は×） |

- 栄養素の大部分を吸収するのは**小腸**（第37回）
- 必要エネルギー量＝基礎代謝量×活動係数×ストレス係数。第29回は**約1,200kcal**

### 低栄養

| ○ 低栄養の指標・サイン | × |
|---|---|
| 食事摂取量・**BMI**・**体重減少率**・**血清アルブミン値**（第24回） | **血圧値** |
| **1か月に3%以上**の体重減少 → PEMを疑う（第31回） | BMI25以上（肥満）・低血圧・声がれ |
| **偏りのある食べ方**をする（第38回） | 唾液が増える・食べこぼしが減る・体重が増える |
| お茶漬けやうどんで済ませる・疲れやすい → **主菜**（肉・魚・卵・大豆）を勧める（第32回） | 主食を勧める |

<details>
<summary>✏️ 解いてみよう（第31回）</summary>

たんぱく質・エネルギー低栄養状態（PEM）が疑われる状況として、最も適切なものはどれ？

1. 要介護度が改善した
2. 1か月に3%以上の体重減少があった
3. BMIが25.0以上になった
4. 低血圧症状が現れた
5. 声がかれるようになった

<details class="answer">
<summary>正解を見る</summary>

**正解：2**　短い期間での体重減少は、低栄養のもっとも分かりやすいサインです。BMI25以上は肥満の基準です。
</details>
</details>

## ② 脱水と水分補給【こころとからだのしくみ／生活支援技術】

| ○ 脱水のサイン | × |
|---|---|
| **活動性の低下**（ぼんやりする）（第28回） | 浮腫・多尿・皮膚の湿潤・低体温 |
| 手の甲の皮膚をつまむと**形が残る** | — |
| **尿量が少なく、色が濃い**、唇の乾燥 | — |

| 場面 | ○ 勧めるもの | × |
|---|---|---|
| 脱水ぎみの一人暮らしの人（第28回） | **経口補水液** | 温めた牛乳・冷たいお茶・ジュース |
| 誤嚥歴があり脱水（第27回） | おやつに**ゼリー** | 散歩・入浴・コーヒー |
| 誤嚥しやすい人の脱水予防 | **水分の形状**を確認（第35回） | — |
| 脱水予防に適さない食品 | — | **ビール**（利尿作用）（第24回） |
| 熱中症対策・**汗が多い** | **塩分を含んだ飲み物**（第37回） | のどが渇いてから飲む／起床時は控える |
| **下痢** | **白湯**（第38回） | 牛乳・炭酸水・コーヒー・冷水 |

<details>
<summary>✏️ 解いてみよう（第38回）</summary>

下痢をしている利用者の水分補給として、最も適切なものはどれ？

1. 白湯
2. 牛乳
3. 炭酸水
4. コーヒー
5. 冷水

<details class="answer">
<summary>正解を見る</summary>

**正解：1**　腸を刺激しない、体温に近い温度の飲み物を選びます。牛乳・炭酸・カフェイン・冷たいものは腸を刺激して下痢を悪化させます。
</details>
</details>

## ③ 病気に応じた食事【こころとからだのしくみ／生活支援技術】

| 病気 | ○ 正解 | × よく出る不正解 |
|---|---|---|
| **慢性腎不全・尿毒症** | **たんぱく質制限**＝**肉や魚を控える**（第26・27回）。栄養管理が必須（第25回） | 砂糖を控える／みそ汁を毎食 |
| **血液透析** | **ゆでこぼした野菜**（カリウムを減らす）（第30・36回） | 生野菜・塩分・水分・乳製品・肉や魚を多く |
| 高血圧 | 塩分は**1日6g未満**が目標 | 10g以下 |
| **骨粗鬆症** | **豆類**・乳製品（カルシウム・ビタミンD/K）（第30回） | — |
| 糖尿病 | 1日のエネルギーを**3食に均等に** | 朝食に半分 |
| **COPD** | **1回量を減らし回数を増やす**（第33回） | 芋類・炭酸飲料（お腹が張り息苦しい） |
| **逆流性食道炎** | **少量ずつ回数を分ける**（第35回） | 脂肪・酸味の強い果物・前かがみ・食後すぐ横になる |
| **弛緩性便秘** | **ごぼうの煮物**（食物繊維）（第29回） | おかゆ・ゆで卵・白身魚 |

### 胃ろう

| ○ | × |
|---|---|
| **ボタン型**は自己抜去しにくい（第25回） | 開腹手術が必要（実際は内視鏡）／一生使う |
| **経口摂取も併用できる**（第31回） | 口から食べられなくなる |
| カテーテルは**定期交換** | 交換不要／ろう孔周囲のびらんは放置／抜けても1時間で閉じる |

<details>
<summary>✏️ 解いてみよう（第36回）</summary>

血液透析を受けている利用者への食事の介護として、最も適切なものはどれ？

1. 塩分の多い食品をとるよう勧める
2. ゆでこぼした野菜をとるよう勧める
3. 乳製品を多くとるよう勧める
4. 水分を多くとるよう勧める
5. 魚や肉の料理を多くとるよう勧める

<details class="answer">
<summary>正解を見る</summary>

**正解：2**　透析の人はカリウムがたまりやすく、不整脈の危険があります。野菜はゆでてお湯を捨てると、カリウムが減らせます。塩分・水分は控えます。
</details>
</details>

## ④ 加齢変化に合わせた食事・行事食・配膳【生活支援技術】

| 体の変化 | ○ 正解 | × よく出る不正解 |
|---|---|---|
| 腸の蠕動運動の低下 | **食物繊維**（根菜類）・**乳酸菌**（第26・29・31回） | — |
| 味覚の低下 | だし・香りで工夫 | 調味料・塩分・糖分を増やす |
| 唾液分泌の低下 | 汁物・あんかけ | パンを主食に |
| 咀嚼力の低下 | 軟らかく調理 | 肉料理を控える／麺類中心 |
| 口渇感の低下 | こまめに水分を勧める | 酸味のある味付け |

- 行事食：**土用の丑の日＝うなぎ**（第30回）。お節料理は正月、柏餅・ちまきは端午の節句、七草粥は1月7日
- 和食の配膳（右利き）：**主食（ご飯）は左手前、汁物は右手前、主菜は右奥、副菜は左奥か中央**（第29回）
