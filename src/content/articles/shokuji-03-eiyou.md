**この記事のポイント**

1. 1gあたりのエネルギーが最大なのは**脂質**。低栄養のサインは「**1か月に3%以上の体重減少**」。指標に**血圧は入らない**。
2. 脱水のサインは「**活動性の低下・皮膚をつまむと戻らない・尿が少なく濃い**」。勧めるのは**経口補水液**、むせる人には**ゼリー**。
3. 腎不全は**たんぱく質制限**、透析は**カリウム制限で野菜はゆでこぼす**。COPD・逆流性食道炎は**少量ずつ回数を分けて**。

## ① 栄養素と低栄養【こころとからだのしくみ／生活支援技術】

| 栄養素 | 試験に出る働き |
|---|---|
| **三大栄養素** | **炭水化物（糖質）・脂質・たんぱく質**。水分・ビタミン・ミネラルは入らない |
| **脂質** | **1gあたりのエネルギーが最大**（約9kcal）。**ホルモンの原料** |
| **たんぱく質** | 筋肉・**酵素**の材料。最大のエネルギー源ではない |
| **ナトリウム** | **血圧の調節** |
| カリウム | 血圧を**下げる**方向に働く。骨の形成ではない |
| ビタミンD | **カルシウムの吸収**を助ける |
| ビタミンB1 | **糖質をエネルギーに変える** |
| ビタミンA・D・E・K | **脂溶性**（Aは水溶性、は×） |

- 栄養素の大部分を吸収するのは**小腸**
- 必要エネルギー量＝基礎代謝量×活動係数×ストレス係数。第29回は**約1,200kcal**

### 低栄養

| ○ 低栄養の指標・サイン | × |
|---|---|
| 食事摂取量・**BMI**・**体重減少率**・**血清アルブミン値** | **血圧値** |
| **1か月に3%以上**の体重減少 → PEMを疑う | BMI25以上（肥満）・低血圧・声がれ |
| **偏りのある食べ方**をする | 唾液が増える・食べこぼしが減る・体重が増える |
| お茶漬けやうどんで済ませる・疲れやすい → **主菜**（肉・魚・卵・大豆）を勧める | 主食を勧める |

## ③ 病気に応じた食事【こころとからだのしくみ／生活支援技術】

| 病気 | ○ 正解 | × よく出る不正解 |
|---|---|---|
| **慢性腎不全・尿毒症** | **たんぱく質制限**＝**肉や魚を控える**。栄養管理が必須 | 砂糖を控える／みそ汁を毎食 |
| **血液透析** | **ゆでこぼした野菜**（カリウムを減らす） | 生野菜・塩分・水分・乳製品・肉や魚を多く |
| 高血圧 | 塩分は**1日6g未満**が目標 | 10g以下 |
| **骨粗鬆症** | **豆類**・乳製品（カルシウム・ビタミンD/K） | — |
| 糖尿病 | 1日のエネルギーを**3食に均等に** | 朝食に半分 |
| **COPD** | **1回量を減らし回数を増やす** | 芋類・炭酸飲料（お腹が張り息苦しい） |
| **逆流性食道炎** | **少量ずつ回数を分ける** | 脂肪・酸味の強い果物・前かがみ・食後すぐ横になる |
| **弛緩性便秘** | **ごぼうの煮物**（食物繊維） | おかゆ・ゆで卵・白身魚 |

### 胃ろう

| ○ | × |
|---|---|
| **ボタン型**は自己抜去しにくい | 開腹手術が必要（実際は内視鏡）／一生使う |
| **経口摂取も併用できる** | 口から食べられなくなる |
| カテーテルは**定期交換** | 交換不要／ろう孔周囲のびらんは放置／抜けても1時間で閉じる |

逆流性食道炎の症状がある利用者への助言として、最も適切なものはどれ？

1. 脂肪の多い食品を勧める
2. 酸味の強い果物を勧める
3. 1日の食事を何回かに分けて少しずつ食べるよう勧める
4. 食事中は腹圧がかかる前かがみの姿勢を勧める

## ④ 加齢変化に合わせた食事・行事食・配膳【生活支援技術】

| 体の変化 | ○ 正解 | × よく出る不正解 |
|---|---|---|
| 腸の蠕動運動の低下 | **食物繊維**（根菜類）・**乳酸菌** | — |
| 味覚の低下 | だし・香りで工夫 | 調味料・塩分・糖分を増やす |
| 唾液分泌の低下 | 汁物・あんかけ | パンを主食に |
| 咀嚼力の低下 | 軟らかく調理 | 肉料理を控える／麺類中心 |
| 口渇感の低下 | こまめに水分を勧める | 酸味のある味付け |

- 行事食：**土用の丑の日＝うなぎ**。お節料理は正月、柏餅・ちまきは端午の節句、七草粥は1月7日
- 和食の配膳（右利き）：**主食（ご飯）は左手前、汁物は右手前、主菜は右奥、副菜は左奥か中央**
