**この記事のポイント**

1. 1gあたりのエネルギーが最大なのは**脂質**。低栄養のサインは「**1か月に3%以上の体重減少**」。指標に**血圧は入らない**。
2. 脱水のサインは「**活動性の低下・皮膚をつまむと戻らない・尿が少なく濃い**」。勧めるのは**経口補水液**、むせる人には**ゼリー**。
3. 透析前の慢性腎不全は**たんぱく質制限**、血液透析は**カリウム制限で野菜はゆでこぼす**（たんぱく質は不足しないよう適量）。COPD（慢性閉塞性肺疾患）・逆流性食道炎は**少量ずつ回数を分けて**。

## ① 栄養素と低栄養

| 栄養素 | 試験に出る働き |
|---|---|
| **三大栄養素** | **炭水化物（糖質）・脂質・たんぱく質**。水分・ビタミン・ミネラルは入らない（ビタミン・ミネラルを加えると**五大栄養素**） |
| **脂質** | **1gあたりのエネルギーが最大**（約9kcal。糖質・たんぱく質は約4kcal）。**ホルモンの原料** |
| **たんぱく質** | 筋肉・**酵素**の材料。最大のエネルギー源ではない。体内でつくれない**必須アミノ酸は9種類** |
| **ナトリウム** | **血圧の調節** |
| カリウム | 血圧を**下げる**方向に働く。骨の形成ではない |
| ビタミンD | **カルシウムの吸収**を助ける |
| ビタミンB1 | **糖質をエネルギーに変える** |
| ビタミンA・D・E・K | **脂溶性**（Aは水溶性、は×）。水溶性（B群・C）は体にためられないので毎日とる |
| 食物繊維 | ビタミンではない。消化されにくい成分で、**整腸作用** |

- 栄養素の大部分を吸収するのは**小腸**
- 必要エネルギー量＝基礎代謝量×活動係数×ストレス係数で計算します

### ビタミン・ミネラルが不足すると

| 栄養素 | 多い食品 | 不足で起こる病気 |
|---|---|---|
| ビタミンA | レバー・緑黄色野菜 | 夜盲症（暗いところで見えにくい） |
| ビタミンD | 魚・きのこ（日光で体内でもつくられる） | 骨軟化症・骨粗鬆症 |
| ビタミンK | 納豆・小松菜 | 血液が固まりにくい |
| **ビタミンB1** | 豚肉・玄米 | **脚気** |
| ビタミンB12・葉酸 | レバー・貝・緑の野菜 | 巨赤芽球性貧血 |
| **ビタミンC** | 果物・野菜 | **壊血病**（出血しやすい） |
| カルシウム | 乳製品・小魚・豆類 | 骨粗鬆症 |
| 鉄 | レバー・赤身の肉・ほうれん草 | **鉄欠乏性貧血** |
| **亜鉛** | カキ・レバー・ナッツ | **味覚障害** |

### 低栄養

**PEM**（たんぱく質・エネルギー低栄養状態）＝たんぱく質とエネルギーがともに足りない、高齢者に多い低栄養です。**血清アルブミン**は血液中のたんぱく質の一種で、**3.5g/dL以下**が低栄養のめやすです。**BMI**＝体重(kg)÷身長(m)÷身長(m)で、18.5未満がやせ、25以上が肥満のめやすです。

| ○ 低栄養の指標・サイン | × |
|---|---|
| 食事摂取量・**BMI**・**体重減少率**・**血清アルブミン値** | **血圧値** |
| **1か月に3%以上**の体重減少 → PEMを疑う | BMI25以上（肥満）・低血圧・声がれ |
| **偏りのある食べ方**をする | 唾液が増える・食べこぼしが減る・体重が増える |
| お茶漬けやうどんで済ませる・疲れやすい → **主菜**（肉・魚・卵・大豆）を勧める | 主食を勧める |

## ② 脱水と水分補給

<fig name="suibun">

成人の1日の水分の出入り（めやす）は、入る量と出る量がほぼ同じ**約2,500mL**です。

| 入る水分 | 量 | 出る水分 | 量 |
|---|---|---|---|
| 飲み水 | 1,200mL | 尿・便 | 1,600mL |
| 食べ物の水分 | 1,000mL | **不感蒸泄**（皮膚や呼吸から気づかないうちに出る。汗は含まない） | 900mL |
| **代謝水**（栄養素が体内で燃えるときにできる水） | 300mL | | |

高齢者は、体の水分量がもともと少ない・**のどの渇きを感じにくい**・腎臓で尿を濃くする力が落ちる・トイレを気にして水分を控える、などの理由で脱水になりやすくなります。体重の2〜3％の水分が失われると、のどの渇きが出ます。

| ○ 脱水のサイン | × |
|---|---|
| **活動性の低下**（ぼんやりする） | 浮腫・多尿・皮膚の湿潤・低体温（どれも水分が多いときの様子で、脱水とは逆） |
| 手の甲の皮膚をつまむと**形が残る** | — |
| **尿量が少なく、色が濃い**、唇の乾燥 | — |

| 場面 | ○ 勧めるもの | × |
|---|---|---|
| 脱水ぎみの一人暮らしの人 | **経口補水液** | 温めた牛乳・冷たいお茶・ジュース |
| 誤嚥歴があり脱水 | おやつに**ゼリー** | 散歩・入浴・コーヒー |
| 誤嚥しやすい人の脱水予防 | **水分の形状**を確認 | — |
| 脱水予防に適さない食品 | — | **ビール**（利尿作用） |
| 熱中症対策・**汗が多い** | **塩分を含んだ飲み物** | のどが渇いてから飲む／起床時は控える |
| **下痢** | **白湯** | 牛乳・炭酸水・コーヒー・冷水 |

- アルコールやコーヒーは**利尿作用**があるので、水分補給には向きません

### 脱水の種類

| 種類 | 何が失われる | 特徴 |
|---|---|---|
| **高張性脱水** | 水分が多く失われる | **のどが強く渇く**。発熱・汗・水分不足で |
| **低張性脱水** | ナトリウムが多く失われる | のどの渇きは少なく、だるさ・頭痛・意識障害。汗をかいたあと水だけ補給したときなど |
| 等張性脱水 | 水分とナトリウムが同じように失われる | 下痢・嘔吐・出血など |

## ③ 病気に応じた食事

| 病気 | ○ 正解 | × よく出る不正解 |
|---|---|---|
| **慢性腎不全（透析前）・尿毒症** | **たんぱく質制限**＝**肉や魚を控える**。栄養管理が必須 | 砂糖を控える／みそ汁を毎食 |
| **血液透析** | **ゆでこぼした野菜**（カリウムを減らす）。たんぱく質は不足しないよう**適量** | 生野菜・塩分・水分・乳製品（リンが多い）・肉や魚を多く |
| 高血圧 | 塩分は**1日6g未満**が治療の目標（高血圧治療ガイドライン2019） | 10g以下 |
| **骨粗鬆症** | **豆類**・乳製品（カルシウム・ビタミンD/K・たんぱく質）、日光浴、**骨に適度な負荷をかける運動** | 運動の負荷を減らす |
| 糖尿病 | 1日のエネルギーを**3食に均等に** | 朝食に半分 |
| **COPD**（慢性閉塞性肺疾患。たばこなどで息を吐きにくくなる肺の病気） | **1回量を減らし回数を増やす** | 芋類・炭酸飲料（お腹が張り息苦しい） |
| **逆流性食道炎** | **少量ずつ回数を分ける** | 脂肪・酸味の強い果物・前かがみ・食後すぐ横になる |
| **弛緩性便秘** | **ごぼうの煮物**（食物繊維） | おかゆ・ゆで卵・白身魚 |

- 食塩の6g未満は高血圧の人の治療目標です。一般の人の目標量は**男性7.5g未満・女性6.5g未満**（日本人の食事摂取基準2025年版）。減塩には、だし・酸味・香味野菜・香辛料を使います
- 血液透析は、腕の動脈と静脈をつないだ**シャント**を使います。シャント側の腕で**血圧測定・採血をしない**、圧迫しない
- 食物アレルギーの症状で最も多いのは**皮膚症状（じんましん）**。複数の臓器に症状が出る**アナフィラキシー**は救急対応です

### 胃ろう

胃ろう＝おなかの皮膚から胃まで通した穴（**ろう孔**）に管を入れ、栄養剤を注入する方法です。

| ○ | × |
|---|---|
| **ボタン型**（おなかの表面に小さなボタン状の器具が出ているタイプ）は自己抜去しにくい | 開腹手術が必要（実際は内視鏡）／一生使う |
| **経口摂取も併用できる** | 口から食べられなくなる |
| カテーテルは**定期交換** | 交換不要／ろう孔周囲のびらん（皮膚のただれ）は放置 |
| 抜けたら**すぐ看護師に連絡**する（時間がたつとろう孔が縮んで閉じてしまう） | 抜けてもしばらく様子を見る |

## ④ 加齢変化に合わせた食事・行事食・配膳

| 体の変化 | ○ 正解 | × よく出る不正解 |
|---|---|---|
| 腸の蠕動運動の低下 | **食物繊維**（根菜類）・**乳酸菌** | — |
| 味覚の低下 | だし・香りで工夫 | 調味料・塩分・糖分を増やす |
| 唾液分泌の低下 | 汁物・あんかけ | パンを主食に |
| 咀嚼力の低下 | 軟らかく調理 | 肉料理を控える／麺類中心 |
| 口渇感の低下 | こまめに水分を勧める | 酸味のある味付け |

- 食生活の言葉：**中食**（総菜・弁当を家で食べる）、**個食**（同じ食卓で別々のものを食べる）、**孤食**（ひとりで食べる）

### 嚥下調整食ととろみ

飲み込みにくい人には、かたさ・まとまりを調整した**嚥下調整食**を出します。日本摂食嚥下リハビリテーション学会の分類では、ゼリー状のもの（コード0・1）から、ペースト状（コード2）、舌でつぶせるやわらかさ（コード3）、歯ぐきでつぶせるやわらかさ（コード4）へと段階が上がります。飲み物のとろみは**薄い・中間・濃い**の3段階で、むせやすいほど濃くします。
