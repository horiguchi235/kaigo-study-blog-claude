**この記事のポイント**

1. 対象は**18歳以上**の身体・知的・精神（**発達障害・高次脳機能障害を含む**）・**難病**。**65歳以上も含む**。
2. 手続きは「**市町村に支給申請 → 認定調査 → 市町村審査会で障害支援区分 → 支給決定**」。負担は**応能負担**。
3. **同行援護＝視覚障害**、**行動援護＝知的・精神で危険を避けられない人**、**重度訪問介護は外出の介護も含む**。

## ① 障害者総合支援法の成り立ち・対象・改正【社会の理解】

| 年 | できごと |
|---|---|
| 2003年 | 支援費制度（措置から契約へ） |
| **2006年** | **障害者自立支援法**：**障害の種別を問わず**サービスを**一元化**。就労支援も含む |
| **2013年** | **障害者総合支援法**：対象に**難病患者等**を追加 |
| **2018年施行**（2016年改正） | **自立生活援助**・**就労定着支援**の創設、共生型サービス |

### 障害者の定義

| ○ | × |
|---|---|
| **18歳以上**（18歳未満は障害児） | 20歳以上・65歳未満 |
| **65歳以上の障害者も含む** | — |
| **発達障害・高次脳機能障害・双極性障害**も含む（精神障害） | 発達障害・難病・依存症は除く |
| **難病患者**も含む | — |

## ② 利用の手続き・障害支援区分・負担・関係機関【社会の理解／障害の理解】

### 利用の流れ

1. **市町村の窓口に支給申請**（最初の手続き）
2. 認定調査（市町村）＋医師意見書
3. **市町村審査会**で**障害支援区分**を審査・判定。**家族の意見を聴くことができる**
4. サービス等利用計画案（**相談支援専門員**が作成）
5. 支給決定 → 事業所と契約 → 利用

| ○ | × |
|---|---|
| 居宅介護を使うには**障害支援区分の認定**が必要 | 身体障害者更生相談所の医学的判定・すぐ契約・ケアマネに伝える |
| 生活介護を使うために**障害支援区分の認定** | 要介護認定・保護の要否判定 |
| 利用者負担は**応能負担**（**負担能力に応じて**） | 応益負担（サービス量に応じて）・定率・全額 |
| 財源は**税**（公費） | 社会保険方式 |

### 関係する機関

| 機関 | 役割 |
|---|---|
| 市町村 | 支給決定、障害支援区分の認定、**地域生活支援事業**の実施 |
| 市町村審査会 | 障害支援区分の**審査・判定** |
| **都道府県** | 事業者の**指定**、**身体障害者更生相談所の設置義務** |
| 身体障害者更生相談所 | 補装具などの**医学的・心理的判定** |
| **協議会** | **地方公共団体**が設置。地域の**支援体制の課題を情報共有**し、**地域の実情に応じた支援体制の整備を協議**。当事者・家族も参加 |
| 基幹相談支援センター | 市町村が設置できる相談の中核 |
| 指定障害福祉サービス事業者 | **サービスの質の評価**を行い**向上に努める**。指定は**6年ごと**に更新 |

### 地域移行の相談

精神科病院に10年入院している人が地域で暮らしたいと申し出た → 地域相談支援の職員は**地域の情報を提供しながら本人の希望を確認**する。苦労を説明する・いきなり計画を作る・地域移行後のモニタリング不要は×。

## ③ 障害福祉サービスの種類【社会の理解／障害の理解】

### 自立支援給付

| 区分 | 主なサービス |
|---|---|
| **介護給付** | **居宅介護**、**重度訪問介護**、**同行援護**、**行動援護**、重度障害者等包括支援、**短期入所**、療養介護、**生活介護**、施設入所支援 |
| **訓練等給付** | 自立訓練、就労移行支援、就労継続支援（A型・B型）、**就労定着支援**、**自立生活援助**、**共同生活援助（グループホーム）** |
| そのほか | 自立支援医療、**補装具**、相談支援 |

### 移動・外出の支援

| サービス | 対象・内容 |
|---|---|
| **同行援護** | **視覚障害**で移動が難しい人の外出（代読・代筆も） |
| **行動援護** | **知的・精神障害**で**危険を回避できない**人の外出 |
| **重度訪問介護** | 重度の肢体不自由・知的・精神の人。**入浴・食事などの介護に加え外出時の移動中の介護も**。入院中も支援できる |
| **移動支援** | **地域生活支援事業**（市町村）。円滑に外出できるよう**移動を支援** |

### そのほかのポイント

- 障害支援区分3でも使えるサービス：**短期入所**（区分1以上）。療養介護・重度訪問介護・重度障害者等包括支援・行動援護は区分の条件がより重い
- グループホームで暮らし、**一人暮らしをしたい** → **自立生活援助**
- **補装具**：**車いす・電動車いす**、義肢、装具、補聴器、白杖など。特殊寝台・点字器・たん吸引器・ストーマ装具は**日常生活用具**、手すり・スロープは住宅改修

### 共生型サービス（2018年）

- 介護保険と障害福祉の**両方の指定**を受けやすくする仕組み。対象は**通所介護**・訪問介護・短期入所など
- 障害者が65歳になっても、**同じ事業所のサービスを使い続けられる**

### 障害児支援

| ○ | × |
|---|---|
| **保育所等訪問支援**＝保育所などを訪問し、集団生活に適応できるよう専門的な支援 | 療育手帳が必要 |
| 放課後等デイサービスは**児童福祉法** | 子ども・子育て支援法 |
| 障害児通所支援には**障害児支援利用計画**が必要 | 計画は不要 |
| 障害児入所支援は**都道府県** | すべての市町村 |

障害者総合支援法の移動に関する支援の説明として、最も適切なものはどれ？

1. 移動支援には、介護給付費が支給される

## ひっかけパターン集（総合支援法で「ほぼ×」）

| 選択肢の表現 | なぜ× |
|---|---|
| 障害者は20歳以上・65歳未満 | 18歳以上（65歳以上も含む） |
| 難病・発達障害は対象外 | 対象 |
| 区分の判定は都道府県・身体障害者更生相談所 | 市町村審査会 |
| 利用者負担は応益負担 | 応能負担 |
| 行動援護＝視覚障害、同行援護＝知的障害 | 逆 |
| 移動支援＝介護給付・国が実施 | 地域生活支援事業・市町村 |
