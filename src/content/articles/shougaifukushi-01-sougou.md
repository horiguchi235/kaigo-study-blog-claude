**この記事のポイント**

1. 対象は**18歳以上**の身体・知的・精神（**発達障害・高次脳機能障害を含む**）・**難病**。**65歳以上も含む**（18歳未満は障害児として児童福祉法などのサービスを使う）。
2. 手続きは「**市町村に支給申請 → 認定調査 → 市町村審査会で障害支援区分 → サービス等利用計画案 → 支給決定**」。負担は**応能負担**。
3. **同行援護＝視覚障害**、**行動援護＝知的・精神で危険を避けられない人**、**重度訪問介護は外出の介護も含む**。

## ① 障害者総合支援法の成り立ち・対象・改正

| 年 | できごと |
|---|---|
| 2003年 | **支援費制度**（措置から契約へ） |
| **2005年成立・2006年施行** | **障害者自立支援法**：**障害の種別を問わず**サービスを**一元化**。就労支援も含む。当初の負担は<strong>応益負担（原則1割）</strong>で、2010年改正で**応能負担**に |
| **2012年成立・2013年施行** | **障害者総合支援法**（自立支援法を改称）：対象に**難病患者等**を追加 |
| 2014年施行 | 障害程度区分を**障害支援区分**に変更、ケアホームを**グループホームに一元化**、**重度訪問介護の対象を重度の知的・精神障害者にも拡大** |
| **2016年改正（2018年施行）** | **自立生活援助**・**就労定着支援**の創設、**共生型サービス** |
| 2022年改正（**2024年4月施行**） | グループホームで**一人暮らしを希望する人への支援**（退去後の相談も）を明記、**基幹相談支援センター**の設置を市町村の**努力義務**に |
| 2024年度 報酬改定 | **重度訪問介護の入院中の利用**を区分6から**区分4以上**に拡大 |
| 2025年10月 | **就労選択支援**の開始（2022年改正） |

### 障害者の定義

| ○ | × |
|---|---|
| **18歳以上**（18歳未満は障害児。障害児も児童福祉法のサービスと、居宅介護などの総合支援法のサービスを使える） | 20歳以上・65歳未満 |
| **65歳以上の障害者も含む** | 65歳で対象外になる |
| **発達障害・高次脳機能障害**も精神障害として含む（過去問では双極性障害も問われた） | 発達障害・依存症は除く |
| **難病患者**も含む | 難病は除く |

## ② 利用の手続き・障害支援区分・負担・関係機関

### 利用の流れ

1. **市町村の窓口に支給申請**（最初の手続き）
2. 認定調査（市町村）＋医師意見書
3. **市町村審査会**で**障害支援区分**（非該当・**区分1（軽い）〜区分6（重い）**）を審査・判定。**家族の意見を聴くことができる**
4. サービス等利用計画案（**相談支援専門員**が作成）
5. 支給決定 → サービス担当者会議（**本人も参加**。ここで計画を確定させる）→ 事業所と契約 → 利用 → モニタリング（支給決定の後も、計画相談で見直しを続ける）

> 介護保険はケアプランが**認定の後**ですが、障害福祉は**計画案が支給決定より前**です。訓練等給付は原則として**障害支援区分の認定がいりません**。

| ○ | × |
|---|---|
| 居宅介護を使うには**障害支援区分の認定**が必要 | 身体障害者更生相談所の医学的判定・すぐ契約・ケアマネに伝える |
| 生活介護を使うために**障害支援区分の認定** | 要介護認定・保護の要否判定 |
| 利用者負担は**応能負担**（**負担能力に応じて**。所得に応じた月の上限あり） | 応益負担（サービス量に応じて）・定率・全額 |
| 財源は**税**（公費） | 社会保険方式 |

### 国・都道府県・市町村の役割

| 国 | 都道府県 | 市町村 |
|---|---|---|
| 障害福祉計画の**基本指針**を決める、制度全体の体制を整える | 事業者の**指定**・取消し、自立支援医療（精神通院医療は都道府県・指定都市）、専門的な相談、支給決定などへの**不服の審査請求**を受ける | **支給申請の受付・支給決定**、**市町村審査会**を置く、**地域生活支援事業**、虐待の防止と早期発見 |

- **障害福祉計画**は、国の基本指針にそって**都道府県と市町村がつくる義務**があります（任意ではありません）。サービスの見込み量と提供の体制を決める計画で、つくるときは協議会の意見を聴くよう努めます
- 障害福祉計画は**利用者負担の額を決めるものではありません**。負担は、所得に応じた**月の上限**で決まります
- 事業者への支払いの事務は、**国保連**に任せることができます

### 関係する機関

| 機関 | 役割 |
|---|---|
| 市町村 | 支給決定、障害支援区分の認定、**地域生活支援事業**の実施 |
| 市町村審査会 | 障害支援区分の**審査・判定** |
| **都道府県** | 事業者の**指定**、**身体障害者更生相談所の設置義務**。専門性の高い地域生活支援事業 |
| 身体障害者更生相談所 | 補装具などの**医学的・心理的判定** |
| **協議会** | **地方公共団体**（都道府県・市町村）が置くよう**努める**（努力義務。国が置くものではない）。地域の**支援体制の課題を情報共有**し、**地域の実情に応じた支援体制の整備を協議**。当事者・家族も参加 |
| 基幹相談支援センター | 地域の相談支援の中核。市町村は設置に**努める**（2024年4月から努力義務） |
| 発達障害者支援センター | 都道府県知事（指定都市は市長）が指定。本人・家族の相談、発達支援・就労支援 |
| 指定障害福祉サービス事業者 | **サービスの質の評価**を行い**向上に努める**。指定は**6年ごと**に更新 |

**障害を判定する機関**（取り違えに注意）

| 機関 | 何を判定する？ |
|---|---|
| **身体障害者更生相談所**（都道府県に設置義務） | 補装具・更生医療などの医学的な判定 |
| 知的障害者更生相談所 | **18歳以上**の知的障害の判定（療育手帳） |
| 児童相談所 | **18歳未満**の子どもの判定（療育手帳） |
| 精神保健福祉センター | 精神障害者保健福祉手帳の判定、こころの健康の相談 |

> **障害支援区分**を決めるのは、上のどれでもなく**市町村審査会**（市町村が認定）です。計画をつくる人（相談支援専門員・サービス管理責任者・児童発達支援管理責任者）の違いは[計画とつくる人の違い](../hikaku-10-keikaku/)で整理しています。

## ③ 障害福祉サービスの種類

### サービスの全体像

| 区分 | サービス | ひとことで | 必要な障害支援区分（めやす） |
|---|---|---|---|
| **介護給付** | 居宅介護（ホームヘルプ） | 自宅での入浴・排泄・食事・家事 | 区分1以上 |
| | **重度訪問介護** | 重度の肢体不自由・知的・精神障害の人の**長時間の総合支援（外出時の移動中も）** | **区分4以上** |
| | **同行援護** | **視覚障害**の人の外出に付き添い、代読・代筆などの情報提供・移動支援 | **区分認定は不要**（身体介護を伴う場合は区分2以上） |
| | **行動援護** | **知的・精神障害**で行動上の危険がある人の外出・危険回避 | **区分3以上** |
| | 重度障害者等包括支援 | 最重度の人に複数のサービスを包括的に | 区分6 |
| | **短期入所**（ショートステイ） | 施設に短期間泊まる | 区分1以上 |
| | **療養介護** | 医療と常時介護が必要な人（病院で日中の機能訓練・療養上の管理） | 区分6など |
| | **生活介護** | 常時介護が必要な人の**日中**の介護と創作・生産活動 | 区分3以上（50歳以上は2以上） |
| | 施設入所支援 | 施設での**夜間・休日**の介護 | 区分4以上（50歳以上は3以上） |
| **訓練等給付** | 自立訓練（機能訓練・生活訓練） | 自立した生活のための訓練（期間限定） | 原則不要 |
| | **就労選択支援**（2025年10月〜） | 本人の希望や能力に合う働き方を一緒に選ぶ | 原則不要 |
| | 就労移行支援 | 一般就労に向けた訓練（原則2年） | 原則不要 |
| | 就労継続支援A型／B型 | A型＝**雇用契約あり**／B型＝**雇用契約なし**（工賃） | 原則不要 |
| | **就労定着支援** | 就職後の定着を支える | 原則不要 |
| | **自立生活援助** | 施設やグループホームから一人暮らしに移った人を**定期訪問・随時相談**で支える（原則1年） | 原則不要 |
| | **共同生活援助（グループホーム）** | 共同生活の住まいでの相談・介護。一人暮らしへの移行も支援 | 原則不要 |
| **相談支援** | 計画相談支援／地域相談支援（地域移行支援・地域定着支援） | サービス等利用計画の作成など | — |
| **自立支援医療** | **育成医療**（18歳未満の身体障害児）・**更生医療**（18歳以上の身体障害者）・**精神通院医療**（年齢を問わない） | 医療費の負担を軽く | — |
| **補装具** | 車いす・電動車いす・義肢・装具・補聴器・白杖など | 体の機能を補う用具 | — |
| **地域生活支援事業**（市町村） | **移動支援**・意思疎通支援・**日常生活用具**給付・地域活動支援センターなど | 地域の実情に合わせて（給付ではない） | — |

- **自立支援医療**も**応能負担**です（原則1割で、所得に応じた月の上限がある。所得が一定以上の人は原則対象外）
- **補装具**は、買う・直す（一部は借りる）費用が出ます。所得に応じた月の上限があり、生活保護や住民税非課税の人は**無料**。自立支援医療・補装具も、障害福祉サービスと同じ**自立支援給付**です
- 市町村が**必ず行う**地域生活支援事業：障害への理解を広げる研修・啓発、相談支援、成年後見制度の利用支援、**意思疎通支援**（手話通訳・要約筆記）、日常生活用具の給付・貸与、手話奉仕員の養成、**移動支援**、**地域活動支援センター**など。都道府県は、専門性の高い意思疎通支援者の養成など、広い地域にかかわる事業を行います

### 移動・外出の支援

| サービス | 対象・内容 |
|---|---|
| **同行援護** | **視覚障害**で移動が難しい人の外出（代読・代筆も）。覚え方：**同**行＝**目**の代わりに**同**じ道を歩く |
| **行動援護** | **知的・精神障害**で**危険を回避できない**人の外出。覚え方：**行動**上の危険を避ける |
| **重度訪問介護** | 重度の肢体不自由・知的・精神の人。**入浴・食事などの介護に加え外出時の移動中の介護も**。入院前から使っている**区分4以上**の人は、**入院中も**意思疎通の支援などに使える（2024年4月から。それまでは区分6） |
| **移動支援** | **地域生活支援事業**（市町村）。円滑に外出できるよう**移動を支援**。介護給付ではない |

### そのほかのポイント

- グループホームで暮らし、**一人暮らしをしたい** → **自立生活援助**
- **地域活動支援センター**＝市町村の地域生活支援事業。障害のある人が通って、**創作的活動や生産活動**をし、地域の人と交流する場です。雇用契約はなく、仕事に向けた訓練（就労移行支援）でも、働いて収入を得る場（就労継続支援）でもありません。「日中の居場所や交流がほしい」人に合います
- **障害者支援施設**＝**夜は施設入所支援**、**昼は生活介護**（または自立訓練・就労移行支援）を組み合わせて暮らす入所施設。事例で「施設入所支援と一緒に使うサービス」「施設で創作的活動」と出たら**生活介護**です。入所にも障害支援区分の認定（市町村に申請）が必要です
- 補装具と間違えやすいもの：特殊寝台・点字器・たん吸引器・ストーマ装具は**日常生活用具**、手すり・スロープは住宅改修

### 65歳になったら・共生型サービス

- **介護保険優先の原則**：障害福祉サービスを使っていた人も、65歳になって**介護保険に同じようなサービスがあれば介護保険が優先**。同行援護・行動援護・就労系など**介護保険にないサービスは続けて使える**
- **共生型サービス**（2018年〜）：介護保険と障害福祉の**両方の指定**を受けやすくする仕組み。対象は**通所介護**・訪問介護・短期入所など。65歳になっても**同じ事業所のサービスを使い続けられる**
- **新高額障害福祉サービス等給付費**（2018年〜）：65歳まで長く障害福祉サービスを使ってきた低所得の人が、介護保険の同じ種類のサービスに移ったとき、介護保険の利用者負担を**払い戻す**

### 障害児支援

障害のある子ども（18歳未満）のサービスは、**2012年から児童福祉法にまとめられました**。

| 種類 | サービス | 実施する所 |
|---|---|---|
| **障害児通所支援** | **児童発達支援**（主に小学校に入る前の子）・**放課後等デイサービス**・保育所等訪問支援・居宅訪問型児童発達支援 | **市町村** |
| **障害児入所支援** | 福祉型障害児入所施設・**医療型**障害児入所施設（医療も行う） | **都道府県** |

- **放課後等デイサービス**＝学校に通う子が、**放課後**や**夏休みなどの休み**に通い、生活の力をつけたり、人と交流したりする。原則**18歳になるまで（高校卒業まで）**使え、必要なら20歳まで延長できる
- 居宅介護・短期入所・同行援護・行動援護などは、障害児も総合支援法で使えます。手帳がなくても、医師の意見書などで必要と認められれば利用できます
- 計画をつくる人：障害児支援利用計画＝相談支援専門員、事業所の個別支援計画＝児童発達支援管理責任者（くわしくは[計画とつくる人の違い](../hikaku-10-keikaku/)）

| ○ | × |
|---|---|
| **保育所等訪問支援**＝保育所などを訪問し、集団生活に適応できるよう専門的な支援 | 療育手帳が必要 |
| 放課後等デイサービスは**児童福祉法** | 子ども・子育て支援法 |
| 障害児通所支援には**障害児支援利用計画**が必要 | 計画は不要 |
| 障害児入所支援は**都道府県** | すべての市町村 |
