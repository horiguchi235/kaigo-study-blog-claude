| こころとからだのしくみ | 13問 | ①循環器・血液 ②症状と疾患の観察 |

**結論を3行で**

1. **肺動脈には静脈血**、**肺静脈・左心房・左心室には動脈血**。酸素を運ぶのは**赤血球**。
2. インスリン使用中に**食事が減って、動悸・冷や汗・ふわふわ＝低血糖**（すぐ医療職へ）。**高血糖＝のどが渇く**。
3. **喉をつかむしぐさ＝窒息**、**爪が白く厚い＝白癬**、糖尿病の人は**足の指**を観察。

## ① 循環器・血液のしくみ【こころとからだのしくみ】

### 血液の流れ

**体循環**：左心室 → **大動脈** → 全身 → **大静脈** → 右心房
**肺循環**：右心室 → **肺動脈（静脈血）** → 肺 → **肺静脈（動脈血）** → 左心房

| ○ | × |
|---|---|
| **肺動脈には静脈血**が流れる（第30・38回） | 左心室から出た血液は大静脈へ |
| **左心房**には動脈血（第25回） | 右心室・右心房・三尖弁・肺動脈に動脈血 |
| 静脈血＝**酸素が少ない**血液 | 酸素を多く含む |
| **静脈**に逆流を防ぐ**弁**がある | 末梢動脈に弁 |
| 拍動を触れるのは**動脈**（手首の橈骨動脈など） | 下肢の静脈で拍動 |
| リンパ管には**リンパ液** | リンパ管に血液 |
| 心臓は**自律神経**が支配 | 体性神経が支配 |

### 血液の成分（第24回）

| 成分 | 働き |
|---|---|
| **赤血球** | **酸素を運ぶ**（ヘモグロビン） |
| 白血球（リンパ球など） | 免疫・感染から守る |
| 血小板 | 止血 |
| 血漿 | 栄養・ホルモン・二酸化炭素などを運ぶ |

### 心拍数（第26回）

**睡眠で減少**。精神的緊張・怒り・体温上昇・激しい運動では**増加**。

## ② 症状と疾患の観察【こころとからだのしくみ】

| 見られる様子 | ○ 考えられる状態 |
|---|---|
| インスリン療法中、風邪で食事が半分、顔色が悪く「胸がどきどき、ふわふわ」、額に汗（第31回） | **低血糖** → **ただちに医療職へ** |
| コントロール不良の糖尿病の高血糖（第34回） | **口渇**（多飲・多尿）。振戦・発汗・動悸は低血糖 |
| 糖尿病の人の身支度で観察する部位（第27回） | **足趾（足の指）**：傷・壊疽に気づきにくい |
| かきこむように食べる人が唐揚げを口に入れて**喉をつかみ**苦しそう（第36回） | **窒息**（チョークサイン） |
| **爪の白濁・肥厚**（第29回） | **白癬**（爪白癬） |
| 皮膚の黄染 | 肝臓・胆道の病気（黄疸） |
| 長期臥床（第24回） | **肺炎**（沈下性肺炎）、褥瘡、筋萎縮 |
| 「通帳を長男の嫁が持っていった」と繰り返す（第33回） | **もの盗られ妄想** |
| 歯周病の症状（第37回） | **歯周ポケットの形成**、歯ぐきの腫れ・出血（歯のくぼみ・エナメル質の侵食はむし歯） |

<details>
<summary>✏️ 解いてみよう（第31回）</summary>

糖尿病でインスリン療法中の75歳。2日前から風邪で食事量が半分になっていたが、インスリン注射は続けていた。朝、顔色が悪く「胸がどきどきして、ふわふわする」と話し、額に汗をかいている。ただちに医療職に相談すべき状態はどれ？

1. 発熱
2. 脱水
3. 低血糖
4. 貧血
5. 意識障害

<details class="answer">
<summary>正解を見る</summary>

**正解：3**　食事が減ったのにインスリンを同じ量使うと血糖が下がりすぎます。動悸・冷や汗・ふらつきは低血糖の典型的なサインです。
</details>
</details>

<details>
<summary>✏️ 解いてみよう（第38回）</summary>

循環器系のしくみとして、正しいものはどれ？

1. 心臓は体性神経が支配している
2. 肺動脈には静脈血が流れている
3. 左心室から出た血液は大静脈へ流れる
4. リンパ管には血液が流れている
5. 静脈血とは酸素を多く含む血液である

<details class="answer">
<summary>正解を見る</summary>

**正解：2**　肺動脈は「心臓から肺へ向かう血管」なので、全身から戻った酸素の少ない静脈血が流れます。
</details>
</details>
