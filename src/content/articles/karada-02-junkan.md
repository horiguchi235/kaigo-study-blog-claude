**この記事のポイント**

1. **肺動脈には静脈血**、**肺静脈・左心房・左心室には動脈血**。酸素を運ぶのは**赤血球**。
2. インスリン使用中に**食事が減って、動悸・冷や汗・ふわふわ＝低血糖**（すぐ医療職へ）。**高血糖＝のどが渇く**。
3. **喉をつかむしぐさ＝窒息**、**爪が白く厚い＝白癬**、糖尿病の人は**足の指**を観察。

## ① 循環器・血液のしくみ【こころとからだのしくみ】

### 血液の流れ

**体循環**：左心室 → **大動脈** → 全身 → **大静脈** → 右心房
**肺循環**：右心室 → **肺動脈（静脈血）** → 肺 → **肺静脈（動脈血）** → 左心房

<fig name="shinzou">

| ○ | × |
|---|---|
| **肺動脈には静脈血**が流れる | 左心室から出た血液は大静脈へ |
| **左心房**には動脈血 | 右心室・右心房・三尖弁・肺動脈に動脈血 |
| 静脈血＝**酸素が少ない**血液 | 酸素を多く含む |
| **静脈**に逆流を防ぐ**弁**がある | 末梢動脈に弁 |
| 拍動を触れるのは**動脈**（手首の橈骨動脈など） | 下肢の静脈で拍動 |
| リンパ管には**リンパ液** | リンパ管に血液 |
| 心臓は**自律神経**が支配 | 体性神経が支配 |

### 血液の成分

| 成分 | 働き |
|---|---|
| **赤血球** | **酸素を運ぶ**（ヘモグロビン） |
| 白血球（リンパ球など） | 免疫・感染から守る |
| 血小板 | 止血 |
| 血漿 | 栄養・ホルモン・二酸化炭素などを運ぶ |

### 心拍数

**睡眠で減少**。精神的緊張・怒り・体温上昇・激しい運動では**増加**。

## ③ 血液・免疫・爪から分かること

- **血液の成分**：**血漿**（液体、血液の約55％）／**赤血球**＝ヘモグロビンで酸素を運ぶ（寿命約120日）／**白血球**＝免疫・異物の処理／**血小板**＝止血（**寿命約7〜10日**）。**フィブリノーゲン**＝血漿のたんぱく質で**血液を固める**（異物を攻撃するのは白血球）。
- 血球は**骨髄（赤色骨髄）**でつくられる。
- **糖尿病**＝インスリンの作用不足で高血糖。症状＝**口渇・多飲・多尿・だるさ**。**三大合併症＝網膜症・腎症・神経障害**。**動脈硬化の危険因子**で、心筋梗塞・脳梗塞のリスクを高める。足の傷が壊疽になりやすい。
- 心拍数は1分間に60〜80回ほど。**肺動脈には静脈血、肺静脈には動脈血**が流れる（名前と中身が逆）。
- 血液は体重の約**7〜8％**。**血球45％・血漿55％**。体液は体重の約**60％**（高齢者は少ない）。
- **リンパ球**：B細胞＝抗体をつくる、T細胞＝免疫の司令塔。高齢になるとT細胞の働きが弱まり、感染症にかかりやすくなる。
- **爪の色と病気**：青紫＝心臓・呼吸の悪化、全体に白い＝貧血・肝臓病・低栄養、白く濁って厚い＝爪白癬。**巻き爪・陥入爪**の原因は深爪（切りすぎ）。
- 血圧のめやす：WHOの正常は130/80未満、**高血圧＝140/90以上**。
