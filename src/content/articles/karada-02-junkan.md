**この記事のポイント**

1. **肺動脈には静脈血**、**肺静脈・左心房・左心室には動脈血**。酸素を運ぶのは**赤血球**。
2. インスリン使用中に**食事が減って、動悸・冷や汗・ふわふわ＝低血糖**（すぐ医療職へ）。**高血糖＝のどが渇く**。
3. **喉をつかむしぐさ＝窒息**、**爪が白く厚い＝白癬**、糖尿病の人は**足の指**を観察。

## ① 循環器・血液のしくみ

### 血液の流れ

はじめに、2つの別々の基準をおさえます。

| 言葉 | 何で決まる？ |
|---|---|
| 動脈／静脈 | **血管の向き**。心臓から出ていく血管＝動脈、心臓へ戻る血管＝静脈 |
| 動脈血／静脈血 | **血液の中身**。酸素が多い血液＝動脈血、酸素が少ない血液＝静脈血 |

基準が違うので、肺へ向かう**肺動脈**（心臓から出る）には、全身から戻った酸素の少ない**静脈血**が流れます。「名前と中身が逆」になるのは肺動脈・肺静脈だけです。

**体循環**：左心室 → **大動脈** → 全身 → **大静脈** → 右心房
**肺循環**：右心室 → **肺動脈（静脈血）** → 肺 → **肺静脈（動脈血）** → 左心房

<fig name="shinzou">

| ○ | × |
|---|---|
| **肺動脈には静脈血**が流れる | 左心室から出た血液は大静脈へ |
| **左心房**には動脈血 | 右心室・右心房・三尖弁（右心房と右心室の間の弁）・肺動脈に動脈血 |
| 静脈血＝**酸素が少ない**血液 | 酸素を多く含む |
| **静脈**に逆流を防ぐ**弁**がある（心臓の4つの部屋の出入口にも、血液を逆流させない扉＝弁がある） | 末梢動脈に弁 |
| 拍動を触れるのは**動脈**（手首の橈骨動脈など） | 下肢の静脈で拍動 |
| リンパ管には**リンパ液** | リンパ管に血液 |
| 心臓は**自律神経**が支配 | 体性神経（自分の意思で体を動かす神経）が支配 |

### 血液の成分

| 成分 | 働き |
|---|---|
| **赤血球** | **酸素を運ぶ**（ヘモグロビン）。寿命約120日 |
| 白血球（リンパ球など） | 免疫・感染から守る。リンパ球のB細胞＝抗体をつくる、T細胞＝免疫の司令塔（高齢になると働きが弱まり、感染症にかかりやすい） |
| 血小板 | 止血。寿命約7〜10日 |
| 血漿 | 血液の約55％の液体部分。栄養・ホルモン・二酸化炭素などを運ぶ。血漿のたんぱく質**フィブリノーゲン**は血液を固める |

- 血液は体重の約**7〜8％**。血球は<strong>骨髄（赤色骨髄）</strong>でつくられる。体液は体重の約60％（高齢者は少ない）

### 心拍数・バイタルサインのめやす

心拍数は**睡眠で減少**。精神的緊張・怒り・体温上昇・激しい運動では**増加**。

| 項目 | 成人のめやす |
|---|---|
| 脈拍（心拍数） | 安静時 1分間に**60〜100回** |
| 呼吸 | 1分間に12〜20回 |
| 体温（わきの下） | 36〜37℃ |
| 血圧 | 正常＝120/80mmHg未満、**高血圧＝140/90mmHg以上**（日本高血圧学会 高血圧治療ガイドライン2019） |

## ② 症状と疾患の観察

からだの部位ごとに、「この様子ならこの状態」を結びつけます。

### 血糖の異常（糖尿病）

**糖尿病**＝インスリンの作用不足で血糖が高くなる病気。三大合併症は**網膜症・腎症・神経障害**で、動脈硬化を進め心筋梗塞・脳梗塞のリスクも高めます。

| 比べる点 | 低血糖 | 高血糖 |
|---|---|---|
| 起こりやすい場面 | インスリンや薬を使っているのに、**食事が減った**・運動が多かった | コントロール不良の糖尿病 |
| サイン | **冷や汗・動悸・手のふるえ**・ふわふわ・顔色が悪い。進むと意識障害 | **口渇・多飲・多尿**・だるさ |
| 対応 | **ただちに医療職へ**。指示に従いブドウ糖や砂糖を含む飲み物をとってもらう。意識がはっきりしない・飲み込めないときは口に入れない | 医療職へ報告 |

| 見られる様子 | ○ 考えられる状態 |
|---|---|
| インスリン療法中、風邪で食事が半分、顔色が悪く「胸がどきどき、ふわふわ」、額に汗 | **低血糖** → **ただちに医療職へ** |
| コントロール不良の糖尿病の高血糖 | **口渇**（多飲・多尿）。振戦・発汗・動悸は低血糖 |

### 足・皮膚・爪

| 見られる様子 | ○ 考えられる状態 |
|---|---|
| 糖尿病の人の身支度で観察する部位 | **足趾（足の指）**：感覚が鈍く、傷や壊疽（組織が死んで黒くなる）に気づきにくい |
| **爪の白濁・肥厚** | **白癬**（爪白癬。水虫の菌が爪に入ったもの） |
| 皮膚や白目の黄染（黄色くなる） | 肝臓・胆道の病気（黄疸） |

- 爪の色：青紫＝心臓・呼吸の悪化、全体に白い＝貧血・肝臓病・低栄養、白く濁って厚い＝爪白癬。巻き爪・陥入爪の原因は深爪（切りすぎ）

### のど・口

| 見られる様子 | ○ 考えられる状態 |
|---|---|
| かきこむように食べる人が唐揚げを口に入れて**喉をつかみ**苦しそう | **窒息**（チョークサイン）→ 背部叩打法・腹部突き上げ法 |
| 歯周病の症状 | **歯周ポケットの形成**、歯ぐきの腫れ・出血（歯のくぼみ・エナメル質の侵食はむし歯） |

### そのほか

| 見られる様子 | ○ 考えられる状態 |
|---|---|
| 長期臥床 | **肺炎**（沈下性肺炎＝寝たままで肺の背中側に痰がたまって起こる）、褥瘡、筋萎縮 |
| 「通帳を長男の嫁が持っていった」と繰り返す | **もの盗られ妄想**（認知症の行動・心理症状。くわしくは[認知症①](../ninchisho-01-shoujou/)） |

## ひっかけパターン集（循環・症状で「ほぼ×」）

| 選択肢の表現 | なぜ× |
|---|---|
| 肺動脈には動脈血 | 静脈血 |
| 動脈に逆流防止の弁 | 静脈にある |
| 酸素を運ぶのは血漿・白血球 | 赤血球 |
| 睡眠で心拍数増加 | 減少 |
| 高血糖で冷や汗・動悸 | それは低血糖。高血糖は口渇 |
| 爪の白濁は糖尿病 | 白癬 |
| 低血糖で意識がない人に砂糖水を飲ませる | 窒息の危険。口に入れず医療職・救急へ |
