**この記事のポイント**

1. **社会福祉法人＝認可・評議員会必置・財務諸表を公表・収益事業もできる**。地域福祉を進める団体は**社会福祉協議会**。
2. **NPO法人＝認証・保健医療福祉の活動が最多・収益事業もできる**。共同募金は**都道府県単位**。
3. ボランティアは**自発性**、セルフヘルプグループは**患者会・断酒会**、民生委員は**厚生労働大臣が委嘱**。

## ① 社会福祉法人・社協・NPO法人・共同募金

**言葉**：**認可**＝行政が中身を審査して「つくってよい」と認めること（社会福祉法人）。**認証**＝書類が法律の条件に合っているかを行政が確かめて、設立を認めること（NPO法人。認可より手続きがかんたん）。**所轄庁**＝その法人を担当する役所。

### 社会福祉法人

| ○ | × |
|---|---|
| 設立は所轄庁（**市長・知事・厚生労働大臣**）の**認可** | 内閣府が所轄／認可は不要（届出だけでよい） |
| **評議員会は必ず置く**（理事会・監事も） | 任意 |
| 透明性のため**財務諸表を公表** | 公表の義務はない |
| 社会福祉事業に支障のない範囲で**公益事業・収益事業もできる** | 収益事業は禁止 |
| **解散・合併もできる** | 禁止 |
| 監事は理事・職員を**兼ねられない** | 兼ねられる |

**社会福祉法人が行う3つの事業**

| 事業 | 中身・例 |
|---|---|
| **社会福祉事業**（本来の事業） | **第一種**＝特養・障害者支援施設などの**入所施設**や共同募金。利用する人への影響が大きいので、原則として国・自治体・社会福祉法人が行う。**第二種**＝訪問介護・通所介護・保育所など、在宅や通いのサービス |
| **公益事業** | 社会福祉に関係のある、公益のための事業。例：家族介護者のための**無料の介護教室や交流の場**、ケアマネジャーの事業 |
| **収益事業** | もうけを社会福祉事業などにあてるための事業。例：駐車場・貸しビル |

- 2016年の法改正で、無料や低い料金で地域の困りごとに取り組む「**地域における公益的な取組**」が、社会福祉法人の責務になりました

### 社会福祉協議会

**社会福祉法**に基づき、都道府県・市町村で**地域福祉の推進**を図る団体。ボランティアセンター、日常生活自立支援事業、生活福祉資金の貸付などを行います。福祉サービスの苦情を解決する**運営適正化委員会**は、**都道府県社会福祉協議会**に置かれます（市町村社協ではない）。

社協は、公共性の高い**民間の非営利団体**です。訪問介護・通所介護などの事業も行い、高齢者の見守りネットワークづくりや、住民の福祉活動をまとめる**地域福祉活動計画**づくりにも取り組みます。

### NPO法人（特定非営利活動法人）

| ○ | × |
|---|---|
| **特定非営利活動促進法**に基づく、**都道府県知事（指定都市の市長）の認証** | 社会福祉法に基づく／市町村が認証 |
| 活動分野は**保健・医療・福祉の増進**が最多 | 社会教育が最多 |
| 本来の活動に支障がなければ**収益事業もできる**（利益は分配しない） | 収益は禁止 |
| **認定NPO法人は税制上の優遇**を受けられる | — |
| 災害救援も対象 | 宗教・政治活動を主な目的にできる |

### その他の団体・歴史

| 用語 | 中身 |
|---|---|
| **共同募金** | **社会福祉法**に定められた**第一種社会福祉事業**。**都道府県共同募金会**が**都道府県単位**で行う寄附金の募集（赤い羽根）。地域福祉の推進のため |
| NGO | **非政府組織**。国際協力など国境をこえた活動が中心（NPO＝**非営利組織**とは言葉の意味が違う） |
| コミュニティビジネス | **住民が主体**となり地域課題をビジネスの手法で解決（市町村主体は×） |
| **セツルメント** | 19世紀後半、**貧困地域に住み込み**、調査・教育・生活援助を行う（トインビー・ホール） |

## ② ボランティア・セルフヘルプグループ・民生委員

| ○ | × |
|---|---|
| ボランティアの特徴は**自発性・自主性**（ほかに無償性・公益性） | 個人に限定・福祉に限定・自己満足を重視 |
| 無償性が原則だが、交通費などの実費程度を受け取る**有償ボランティア**もある | 無償に限定 |

| 民生委員は**児童委員を兼ねる** | 児童委員の兼務は禁止 |

## ④ 相談窓口の使い分けと連携

### 困りごと → 相談先

| 困りごと | 相談先 |
|---|---|
| お金に困った・生活保護 | **福祉事務所**（都道府県と市は設置義務、町村は任意） |
| 高齢者の介護・総合相談・虐待 | **地域包括支援センター**（介護保険法） |
| 障害福祉サービスの利用計画 | 相談支援事業所（**相談支援専門員**） |
| 生活福祉資金の貸付・日常生活自立支援事業・ボランティア | **社会福祉協議会**（社会福祉法） |
| 福祉サービスへの苦情（事業所との話し合いで解決しない） | **運営適正化委員会**（都道府県社協） |
| 介護保険サービスへの苦情 | まず事業所 → 解決しなければ**市町村**や**国保連**（国民健康保険団体連合会） |
| 要介護認定への不服 | **介護保険審査会**（都道府県） |
| 悪質商法などの消費者被害 | **消費生活センター** |
| 成年後見の申立て | **家庭裁判所** |
| 失業給付・仕事探し | **ハローワーク** |
| 労働条件・労災 | **労働基準監督署** |
| 感染症・精神保健・難病 | **保健所**（地域保健法） |
| 子どもの虐待・一時保護 | **児童相談所** |

**福祉事務所と社会福祉の行政機関**

- 福祉事務所は、都道府県と市（特別区）は必ず置きます（町村は任意）。**市の福祉事務所**は福祉六法のすべてを担当します（六法の一覧は[「〇〇センター」と相談窓口の違い](../hikaku-07-center/)）
- **都道府県の福祉事務所**は、福祉事務所のない町村の地域を受け持ち、**生活保護法・児童福祉法・母子及び父子並びに寡婦福祉法の3つ**を担当します
- ほかの行政機関：児童相談所・身体障害者更生相談所・知的障害者更生相談所・女性相談支援センター（もとの婦人相談所）
- **社会福祉協議会やNPO法人は行政機関ではなく、民間の団体**です

### 誰に相談する？（事例）

| 場面 | ○ 正解 |
|---|---|
| 孫の世話でデイサービスに通えなくなったと管理者に相談 | **担当のケアマネジャーに再調整を依頼** |
| 発達障害のある38歳の息子が、認知症が疑われる65歳の母と暮らし続けたい | **地域包括支援センター**で介護保険サービスの情報を得る |

### 連携の3つのレベル

| レベル | 中身 |
|---|---|
| 個人レベル | 担当者どうしの連絡・相談 |
| 組織間レベル | 「こういうときはこう連携する」という機関どうしの取り決め |
| 制度レベル | 制度として位置づけられた連携 |
