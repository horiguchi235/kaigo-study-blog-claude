**この記事のポイント**

1. **社会福祉法人＝認可・評議員会必置・財務諸表を公表・収益事業もできる**。地域福祉を進める団体は**社会福祉協議会**。
2. **NPO法人＝認証・保健医療福祉の活動が最多・収益事業もできる**。共同募金は**都道府県単位**。
3. ボランティアは**自発性**、セルフヘルプグループは**患者会・断酒会**、民生委員は**厚生労働大臣が委嘱**。

## ① 社会福祉法人・社協・NPO法人・共同募金【社会の理解】

### 社会福祉法人

| ○ | × |
|---|---|
| 設立は所轄庁（**市長・知事・厚生労働大臣**）の**認可** | 内閣府が所轄／認可は不要／知事が大臣に届出 |
| **評議員会は必ず置く** | 任意 |
| 透明性のため**財務諸表を公表** | — |
| 社会福祉事業に支障のない範囲で**公益事業・収益事業もできる** | 収益事業は禁止 |
| **解散・合併もできる** | 禁止 |
| 監事は理事・職員を**兼ねられない** | 兼ねられる |

### 社会福祉協議会

**社会福祉法**に基づき、都道府県・市町村で**地域福祉の推進**を図る団体。ボランティアセンター、日常生活自立支援事業、生活福祉資金の貸付などを行います。

### NPO法人（特定非営利活動法人）

| ○ | × |
|---|---|
| **特定非営利活動促進法**に基づく、**都道府県知事（指定都市の市長）の認証** | 社会福祉法に基づく／市町村が認証 |
| 活動分野は**保健・医療・福祉の増進**が最多 | 社会教育が最多 |
| 本来の活動に支障がなければ**収益事業もできる** | 収益は禁止 |
| **認定NPO法人は税制上の優遇**を受けられる | — |
| 災害救援も対象 | 宗教・政治活動が主目的の団体は× |

### その他の団体・歴史

| 用語 | 中身 |
|---|---|
| **共同募金** | **都道府県単位**で行う寄附金の募集。地域福祉の推進のため |
| NGO | 国際的な活動をする非政府組織（NPOと逆にしたひっかけに注意） |
| コミュニティビジネス | **住民が主体**となり地域課題をビジネスで解決（市町村主体は×） |
| **セツルメント** | 19世紀後半、**貧困地域に住み込み**、調査・教育・生活援助を行う（トインビー・ホール） |

## ② ボランティア・セルフヘルプグループ・民生委員【社会の理解】

| ○ | × |
|---|---|
| ボランティアの特徴は**自発性・自主性**（ほかに無償性・公益性） | 無償に限定・個人に限定・福祉に限定・自己満足を重視 |
| **セルフヘルプグループ＝患者会・断酒会** | 町内会・学生自治会・専門職団体・傾聴ボランティア・子ども食堂 |
| 民生委員は**都道府県知事の推薦で厚生労働大臣が委嘱** | 知事や市町村長・社協会長が委嘱 |
| 民生委員は**児童委員を兼ねる** | 児童委員の兼務は禁止 |

## ③ 専門職の業務・相談先・地域社会【社会の理解】

### 専門職の業務

| 職種 | ○ 業務 |
|---|---|
| **言語聴覚士** | **聴覚検査・言語訓練・嚥下訓練** |
| 作業療法士 | 手芸・工作・家事などの作業訓練 |
| 理学療法士 | 基本動作の訓練・物理療法 |
| **介護福祉士** | **訪問介護の提供**など |
| 介護支援専門員 | ケアプランの作成・調整 |
| 精神保健福祉士 | 精神障害者の社会復帰の相談援助（心理検査は公認心理師など） |

### 誰に相談する？

| 場面 | ○ 正解 |
|---|---|
| 孫の世話でデイサービスに通えなくなったと管理者に相談 | **担当のケアマネジャーに再調整を依頼** |
| 発達障害のある38歳の息子が、認知症が疑われる65歳の母と暮らし続けたい | **地域包括支援センター**で介護保険サービスの情報を得る |

### 地域社会・権利

| ○ | × |
|---|---|
| 住民の意見を施策に反映する**パブリックコメント** | 過疎は緩和、限界集落は都市部だけ、待機児童は解消 |
| 市町村に住所があれば**外国籍でもサービスを受ける権利**がある | 選挙・条例制定請求・監査請求・議会解散請求は日本国民のみ |
| **障害者のための国際シンボルマーク**＝障害者が**利用できる建物・施設**であることを示す | 車いす利用者だけ／車への表示義務 |

<summary>✏️ 過去問を解いてみよう（第35回：社会の理解）</summary>

発達障害のある息子（38歳）が、統合失調症で最近認知症が疑われる母（65歳）と、これからも2人で暮らしたいと相談支援事業所に相談した。助言として最も適切なものはどれ？

1. 地域包括支援センターで介護保険サービスの情報を得るよう勧める
2. 正社員になれるようハローワークへ行くよう勧める
3. 息子の発達障害の治療を勧める
4. 母親に特別養護老人ホームを紹介する
5. 母親に精神科病院への入院を勧める

<details class="answer">
<summary>正解を見る</summary>

**正解：1**　母親は65歳で認知症が疑われるので、高齢者の総合相談窓口＝**地域包括支援センター**につなぐのが適切。「2人で暮らしたい」という希望を尊重します。
</details>
