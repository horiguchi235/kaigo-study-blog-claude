## ① ケアマネジメントとサービス担当者会議

**ケアマネジメント**＝利用者のニーズと、さまざまなサービスや地域の資源を結びつけ、計画的に支援するしくみ。中心になるのは**介護支援専門員**（**ケアマネジャー**、略してケアマネ）です。

### ケアマネジメントの流れ

**インテーク**（最初の相談・受付）→ **アセスメント**（利用者・家族に**面接**して行う）→ ケアプラン原案 → **サービス担当者会議** → 利用者の**同意**・交付 → サービスの実施 → **モニタリング**（実施状況と効果の確認）→ 評価（必要なら再アセスメント）

| ○ | × |
|---|---|
| 利用者や家族も**ケアプランづくりに関わる** | 関われない |
| 家族も担当者会議のメンバー | 家族は含まない |
| ケアプランを民生委員に知らせる義務はない | — |

- ケアプランは**期間を区切って**つくり（永久ではない）、介護保険のサービス（**フォーマル**）だけでなく家族・近所・ボランティアなど（**インフォーマル**）の支えも組み込む。自己負担額も考える。
- 居宅のケアプラン作成費（居宅介護支援）は**全額保険給付**で、利用者負担はない。
- **ケアマネジメントの終結**：課題が本人の力で解決できる、本人も合意している、今後課題が出ても本人が対応できる、が確認できたとき。

### サービス担当者会議

| ○ | × |
|---|---|
| 招集は**ケアマネジャー**の職務 | 社協が主催 |
| **利用者と家族の参加が基本** | 利用者を匿名にする |
| 目的は**ケアプランの内容を共有・検討**すること | 職員の実践力の向上 |
| 場所・頻度は**状況に応じて**（自宅が望ましいが義務ではない） | 自宅で開催が義務・月1回以上が義務 |

> <strong>「月1回」が決まっているのはどっち？</strong>　月1回以上と決まっているのは**モニタリング**（居宅介護支援では、ケアマネが少なくとも**月1回、自宅を訪問**して面接）。**サービス担当者会議には頻度の決まりはありません**。なお2024年度から、条件を満たせばモニタリングはテレビ電話等でもよく、訪問は**2か月に1回**でもよくなりました。

**会議の種類**

| 会議 | 開く人／目的 |
|---|---|
| **サービス担当者会議** | **ケアマネジャー**が招集。利用者・家族・サービス事業者で**個別のケアプラン**を検討 |
| **運営推進会議** | 地域密着型サービスの**事業所**が開く。利用者・家族・地域住民・市町村職員などとサービスを評価し、**透明性**を確保 |
| カンファレンス（ケース会議） | 事業所・施設の中で、利用者の支援の方針を職員どうしで話し合う |

会議は情報共有の場であると同時に**問題解決の場**。決めるときは多数決ではなく、本人の希望と根拠から合意します。

### サービス提供責任者・サービス管理責任者

名前が似ているので、**どの制度の誰か**で区別します（くわしくは [計画とつくる人の違い](../hikaku-10-keikaku/)）。

- **サービス提供責任者**（略して**サ責**）＝介護保険の**訪問介護事業所**で、ケアプランに沿って**訪問介護計画**をつくる人
- **サービス管理責任者**（略して**サビ管**）＝**障害福祉サービス**の事業所で、**個別支援計画**をつくる人

| 場面 | ○ 正解 |
|---|---|
| ケアマネとの連携でのサ責の役割 | **居宅サービス計画に基づいて訪問介護計画**を作る（計画の変更・会議招集・他サービスのモニタリングはケアマネ） |
| 認知症の父の近所トラブルで住民が警察に苦情 | **ケアマネに連絡**し、**見守り活動をする近所の人の協力**を得る |
| 片麻痺の人が「浴槽から立ち上がるのがつらい」 | 本人の力を生かせる**入浴補助用具**（**特定福祉用具販売**） |
| タオルにこだわりのある知的障害者が店で自分で選びたい | **行動援護**（サービス管理責任者が助言） |

**選択肢に出るサービスの意味**
- **特定福祉用具販売**＝入浴補助用具・腰掛便座など、貸すのになじまない用具を**購入**する費用が出る（介護保険）
- **行動援護**＝**知的障害・精神障害**で行動に著しい困難がある人の外出時の危険回避などを支援（障害福祉）
- **同行援護**＝**視覚障害**のある人の外出に同行して支援（障害福祉）
- **自立生活援助**＝施設やグループホームから**一人暮らしに移った人**を定期的な訪問で支える（障害福祉）

## ② 多職種連携・チームアプローチ

**多職種連携の目的**は、**多様な専門的視点から本人のニーズを考え**、生活目標を支えること。連携先は施設内だけでなく、家族・地域・医療にも広がります。

| ○ | × |
|---|---|
| **複数の専門職が共通の目標に向かって協働**し課題を解決 | 専門職が利用者に代わって決める／当事者の支え合い（セルフヘルプ） |
| メンバーの**役割分担を明確に** | 情報はメンバー間でも秘密／医師が方針を決める／家族がメンバーを指名 |
| **利用者もチームの一員** | 利用者を外す |
| ケアの方向性の**情報を共有**して課題を解決 | 医師が中心／民生委員やボランティアを除く／要介護度の改善を最優先 |

### 誰に相談する？

| 場面 | ○ 職種 |
|---|---|
| 施設サービス計画の作成 | **介護支援専門員** |
| 栄養ケア・マネジメント | **管理栄養士** |
| 療養上の世話・診療の補助 | **看護師** |
| 寝たきりの人の**仙骨部に発赤** | **看護師** |
| 食事で咳込む人の**嚥下機能の評価** | **言語聴覚士**（言葉・聞こえ・嚥下の訓練） |
| 車いすで食事中に姿勢が崩れる | 理学療法士・作業療法士 |
| 在宅復帰前に**自宅の玄関の段差を確認** | **作業療法士**（理学療法士も） |
| 義歯の作成 | **歯科医師・歯科技工士**（歯科衛生士ではない） |
| 車いすの貸与 | 福祉用具専門相談員 |

- 略語：**PT**＝理学療法士、**OT**＝作業療法士、**ST**＝言語聴覚士。
- 資格の区別：**業務独占**（資格がないとその仕事ができない：医師・看護師など）と**名称独占**（資格がないとその名前を名乗れない：介護福祉士・社会福祉士・PT・OT・ST・管理栄養士など）。介護支援専門員は都道府県の試験と実務研修を経て登録する**公的資格**（国家資格ではない）で、介護支援専門員証の有効期間は**5年**（更新研修あり）。

### 利用者ニーズの代弁

夜中に職員を呼んで「何でもない」と言う利用者が、理由を話してくれた。**本人の了解を得て**その意味を会議で他の職員に伝えた ＝ **利用者ニーズの代弁**。

> 別の場面：ショートステイ初日、忙しい夕方に「わたしはここにいていいの」と何度も聞く認知症の人 → まず「**ここにいてくださっていいですよ**」。忙しくても、くり返す質問の奥にある**不安を受け止めて安心を伝える**のが先です（説明や用事の後回しにしない）。

## ③ 人材育成・組織とリーダーシップ

**スーパービジョン**＝経験のある上司や先輩（スーパーバイザー）が、職員（スーパーバイジー）を支え、育てる関わり。3つの機能があります。

| 機能 | 中身 |
|---|---|
| **支持的** | 気持ちを受け止めて**支える** |
| 教育的 | 知識や技術を**教える** |
| 管理的 | 業務や職員の配置を**管理する** |

| 用語 | 意味・試験の正解 |
|---|---|
| **OJT** | 職場で仕事をしながらの指導。**先輩職員が移乗の介護に同行して指導** |
| Off-JT | 職場外の研修（外部研修） |
| SDS | 自己啓発（専門書・資格取得） |
| **支持的スーパービジョン** | 落ち込む新人に**上司が気持ちの理解に努めつつ状況を確認** |
| **キャリアパス** | 介護福祉職として**必要な能力や経験を明確に**する（成長の道すじ） |
| チームマネジメント | 目標を決め、人・物・情報などの資源を効果的に使うしくみを整える |
| **組織図** | 施設全体の**指揮命令系統**を把握する |
| **コンプライアンス** | **法令遵守** |
| **フォロワーシップ** | リーダーを支える力。リーダーが「新人の笑顔が少ない」と言ったら、まず**リーダーが気になっていることを詳しく聞く** |
| **集団凝集性** | チームのまとまり。個別目標の共有には**担当以外のメンバーもカンファレンスに参加** |
| PDCAサイクル | Plan（計画）→ Do（実行）→ Check（評価）→ <strong>Action（改善）</strong>。第35回では「来客用の駐車スペースを確保する」が Action |

**集団の心理で×になる選択肢**（チームのまとまりではなく、少数意見を抑える方向に働くもの）
- 集団規範＝集団の中で「こうすべき」とされる暗黙のルール（管理職が注意して押しつけても目標の共有にはならない）
- 同調（同調行動）＝周りに合わせて自分の意見を変えること
- 集団圧力＝多数派が少数派に、合わせるよう働きかける力
- 内集団バイアス＝自分の属する集団を、ほかの集団より高く評価する偏り
