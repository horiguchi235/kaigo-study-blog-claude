**この記事のポイント**

1. サービス担当者会議は**ケアマネジャーが招集**し、**利用者と家族の参加が基本**。
2. チームアプローチは「**複数の専門職が共通の目標に向かって協働**」。**役割分担を明確**に、医師中心でも専門職だけでもない。
3. **OJT＝職場で先輩が同行して教える**、**支持的スーパービジョン＝気持ちを受け止めて支える**、**コンプライアンス＝法令遵守**。

## ① ケアマネジメントとサービス担当者会議【介護の基本】

### ケアマネジメントの流れ

インテーク → **アセスメント**（利用者・家族に**面接**して行う）→ ケアプラン原案 → **サービス担当者会議** → 実施 → **モニタリング**（**月1回以上**訪問・記録）→ 評価

| ○ | × |
|---|---|
| 利用者や家族も**ケアプランづくりに関わる** | 関われない |
| 家族も担当者会議のメンバー | 家族は含まない |
| ケアプランを民生委員に知らせる義務はない | — |

### サービス担当者会議

| ○ | × |
|---|---|
| 招集は**ケアマネジャー**の職務 | 社協が主催 |
| **利用者と家族の参加が基本** | 利用者を匿名にする |
| 目的は**ケアプランの内容を共有・検討**すること | 職員の実践力の向上 |
| 場所・頻度は**状況に応じて**（自宅が望ましいが義務ではない） | 自宅で開催が義務・月1回以上が義務 |

### サービス提供責任者・サービス管理責任者

| 場面 | ○ 正解 |
|---|---|
| ケアマネとの連携でのサ責の役割 | **居宅サービス計画に基づいて訪問介護計画**を作る（計画の変更・会議招集・他サービスのモニタリングはケアマネ） |
| 認知症の父の近所トラブルで住民が警察に苦情 | **ケアマネに連絡**し、**見守り活動をする近所の人の協力**を得る |
| 片麻痺の人が「浴槽から立ち上がるのがつらい」 | 本人の力を生かせる**入浴補助用具**（**特定福祉用具販売**） |
| タオルにこだわりのある知的障害者が店で自分で選びたい | **行動援護**（サービス管理責任者が助言） |

<details>
<summary>✏️ 過去問を解いてみよう（第38回：介護の基本）</summary>

知的障害のあるAさん（51歳）はグループホームで暮らし、なじみの店で自分が選んだタオルしか使わない。これまで両親と買いに行っていたが、両親が高齢で行けなくなった。「いつもの店で本人に選ばせてほしい」と相談されたサービス管理責任者の助言として最も適切なものはどれ？

1. 移動が不安なので同行援護を勧める
2. 身体機能の維持のため自立訓練（機能訓練）を勧める
3. 一人で外出できるよう自発的活動支援を勧める
4. 自立した生活のため自立生活援助を勧める
5. 本人が買い物に行けるよう行動援護を勧める

<details class="answer">
<summary>正解を見る</summary>

**正解：5**　知的障害で外出時の支援が必要＝**行動援護**。同行援護は**視覚障害**の人向けです。
</details>
</details>

<details>
<summary>✏️ 過去問を解いてみよう（第36回：介護の基本）</summary>

左片麻痺のBさん（61歳、要介護3）は妻の介助で毎日自宅で入浴しているが、「浴槽から立ち上がるのがつらくなってきた」と相談した。サービス提供責任者の対応として最も適切なものはどれ？

1. 一人で入浴できるよう自立生活援助を勧める
2. 浴室を広くする改築に住宅改修費を使うよう勧める
3. 妻の負担が減るよう行動援護を勧める
4. 本人の力を生かせるよう特定福祉用具販売で入浴補助用具を勧める
5. 入浴を続けられるようデイサービスを勧める

<details class="answer">
<summary>正解を見る</summary>

**正解：4**　浴槽台・入浴用いすなどは**特定福祉用具販売**（購入）。住宅改修は手すり・段差解消などで、浴室の拡張は対象外です。
</details>
</details>

## ② 多職種連携・チームアプローチ【介護の基本／人間関係とコミュニケーション／生活支援技術】

| ○ | × |
|---|---|
| **複数の専門職が共通の目標に向かって協働**し課題を解決 | 専門職が利用者に代わって決める／当事者の支え合い（セルフヘルプ） |
| メンバーの**役割分担を明確に** | 情報はメンバー間でも秘密／医師が方針を決める／家族がメンバーを指名 |
| **利用者もチームの一員** | 利用者を外す |
| ケアの方向性の**情報を共有**して課題を解決 | 医師が中心／民生委員やボランティアを除く／要介護度の改善を最優先 |

### 誰に相談する？

| 場面 | ○ 職種 |
|---|---|
| 施設サービス計画の作成 | **介護支援専門員** |
| 栄養ケア・マネジメント | **管理栄養士** |
| 療養上の世話・診療の補助 | **看護師** |
| 寝たきりの人の**仙骨部に発赤** | **看護師** |
| 食事で咳込む人の**嚥下機能の評価** | **言語聴覚士** |
| 車いすで食事中に姿勢が崩れる | 理学療法士・作業療法士 |
| 在宅復帰前に**自宅の玄関の段差を確認** | **作業療法士**（理学療法士も） |
| 義歯の作成 | 歯科医師（歯科衛生士ではない） |
| 車いすの貸与 | 福祉用具専門相談員 |

### 利用者ニーズの代弁

夜中に職員を呼んで「何でもない」と言う利用者が、理由を話してくれた。**本人の了解を得て**その意味を会議で他の職員に伝えた ＝ **利用者ニーズの代弁**。

> ショートステイ初日、忙しい夕方に「わたしはここにいていいの」と何度も聞く認知症の人 → まず「**ここにいてくださっていいですよ**」。

チームアプローチについて、適切なものはどれ？

1. 介護職が利用者のもとへ出向いて相談・支援する
2. 障害者が地域の資源を使って共生社会を目指す

## ③ 人材育成・組織とリーダーシップ【人間関係とコミュニケーション】

| 用語 | 意味・試験の正解 |
|---|---|
| **OJT** | 職場で仕事をしながらの指導。**先輩職員が移乗の介護に同行して指導** |
| Off-JT | 職場外の研修（外部研修） |
| SDS | 自己啓発（専門書・資格取得） |
| **支持的スーパービジョン** | 落ち込む新人に**上司が気持ちの理解に努めつつ状況を確認** |
| **キャリアパス** | 介護福祉職として**必要な能力や経験を明確に**する |
| **組織図** | 施設全体の**指揮命令系統**を把握する |
| **コンプライアンス** | **法令遵守** |
| **フォロワーシップ** | リーダーを支える力。リーダーが「新人の笑顔が少ない」と言ったら、まず**リーダーが気になっていることを詳しく聞く** |
| **集団凝集性** | チームのまとまり。個別目標の共有には**担当以外のメンバーもカンファレンスに参加** |
| — | 集団圧力・同調行動・内集団バイアスの強化は× |
