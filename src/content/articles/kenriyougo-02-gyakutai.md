**この記事のポイント**

1. 虐待は**5類型**（身体的・介護等放棄・心理的・性的・経済的）。気づいたら**上司に報告し市町村に通報**。**通報する人は事実を確かめなくてよい**（確認するのは市町村）。通報は**守秘義務違反にならない**。
2. 身体拘束の例外は**切迫性・非代替性・一時性の3つすべて**を満たすとき。**組織で判断し、説明し、記録**する。
3. 障害者虐待防止法は<strong>使用者（雇い主）</strong>による虐待も対象。**著しい暴言・拒絶的な対応＝心理的虐待**。

---

本人の権利が侵害される場面には、**虐待**、**差別や偏見**、**悪質商法や詐欺**などがあります。虐待は、知識の不足や人間関係のもつれから、**本人に悪気がないまま**起こることもあります。

**セルフ・ネグレクト**（自己放任）＝本人が自分で食事・入浴・受診などをしなくなり、ごみがたまった家などで健康や安全が損なわれる状態です。法律の虐待の5類型には入りませんが、放っておくと命にかかわるので、**地域包括支援センター**につないで支えます。

## ① 高齢者虐待防止法と対応

### 法律のポイント

正式な名前は「高齢者虐待の防止、**高齢者の養護者に対する支援**等に関する法律」です（2005年成立・2006年施行）。虐待を防ぐだけでなく、介護疲れなどで追いつめられた**養護者（家族）を支える**ことも目的です（相談・助言、ショートステイで負担を軽くするなど）。家族を責めるのではなく、**家族ごと支える**視点が大切です。

| ○ | × |
|---|---|
| 高齢者＝**65歳以上** | 60歳以上 |
| 対象は**養護者**（家で世話をしている家族・親族など）と**養介護施設従事者等**（老人福祉法・介護保険法の施設・事業所で働く職員。病院の職員は入らない）による虐待 | 養護者＝施設従事者／施設サービス利用者だけが対象／病院も対象 |
| 類型は**5つ**（下の表） | 3つ |
| 通報先は**市町村** | 施設長に通報／警察署長が認定 |
| 通報する人は**虐待の事実確認は不要**（「思われる」段階でよい）。通報を受けた**市町村**が安全確認と事実確認をする | 通報する前に事実確認が必要 |
| 虐待を受けた**本人も届け出られる** | — |
| 立入調査で警察の援助は**必要に応じて** | 警察官の同行が義務 |

### 通報は義務？努力義務？

| 見つけた人・場面 | 通報 |
|---|---|
| 施設の職員が、**自分の施設**で虐待を受けたと思われる高齢者を見つけた | **義務** |
| 養護者による虐待で、高齢者の**生命・身体に重大な危険**が生じている | **義務** |
| 上記以外（重大な危険とまではいえない家庭内の虐待など） | 努力義務 |

### 虐待の5類型

| 類型 | 例 |
|---|---|
| 身体的虐待 | たたく・つねる、不必要な身体拘束 |
| **介護等放棄**（ネグレクト） | おむつを替えない、食事を与えない、必要な受診をさせない |
| **心理的虐待** | 怒鳴る・無視する・侮辱する |
| 性的虐待 | 排泄の失敗を罰として下半身を裸にする、わいせつな行為 |
| **経済的虐待** | 年金や預金を本人に渡さない・勝手に使う |

障害者虐待防止法では介護等放棄を「**放棄・放置**」と呼びます。**児童虐待は4類型**（身体・性的・心理・ネグレクト）で、経済的虐待がありません。

### 虐待を見つけたら

| 場面 | ○ 正解 | × |
|---|---|---|
| 長男が日中不在で、食べかすが散乱し便がおむつからはみ出す状態が続く | **事業所の責任者に報告し、市町村に通報** | 訪問時間を減らす・守秘義務で黙る・まず警察 |
| 「長男にどなられて怖い、言わないで」、体に複数のあざ | **虐待を疑い、上司に報告し、市町村に通報** | 本人の気持ちを優先して何もしない・長男を呼んで確認 |
| 「親族が勝手にお金を使い込んでいるらしい」 | **地域包括支援センターに相談** | 親族に事実を確認する |

### 調査結果（高齢者虐待調査）

2024年度 高齢者虐待調査（厚生労働省）より：

- 養護者による虐待：種類は**身体的虐待**が最多。被虐待者は**虐待者とのみ同居**が最多。虐待者の続柄は**息子**が最多→夫→娘
- 被虐待者は**後期高齢者**・女性が多い
- 施設従事者による虐待の要因で最も多いのは、職員の虐待・権利擁護・身体拘束に関する**知識・意識の不足**
順位で整理すると次のとおりです（2024年度調査）。

| | 養護者による虐待 | 施設従事者による虐待 |
|---|---|---|
| 種類の順 | **身体的**→心理的→介護等放棄→経済的 | **身体的**→心理的→介護等放棄 |
| 主な原因 | 本人側：**認知症の症状**／虐待者側：**介護疲れ・介護ストレス** | **知識・意識の不足**→倫理観・理念の欠如→ストレス・感情コントロール |
| 被虐待者 | 女性が約4分の3。年齢は**80〜84歳**が最多。深刻度は最も軽い段階が最多 | 被虐待者の約2割は身体拘束をともなう |
| 同居・家族の形 | 同居の状況：**虐待者とのみ同居**が最多／家族の形：**未婚の子と同居**が最多（別の集計） | 施設の種類：**特別養護老人ホーム**が最多 |
| 相談・通報した人 | **警察**が最多、次いで介護支援専門員 | **その施設の職員**が最多 |

- 地域の虐待防止ネットワークの中心は**地域包括支援センター**。権利侵害に気づいたら介護職ひとりで抱えず、センターの社会福祉士などとチームで対応する

## ② 身体拘束

身体拘束は介護保険の施設などで**原則禁止**です。国は2001年に「**身体拘束ゼロへの手引き**」で禁止の対象となる11の行為を示し、2024年3月にその考え方を引き継いだ「**身体拘束廃止・防止の手引き**」に改訂しました（対象を施設だけでなく在宅の事業所や家族にも広げた）。

### 身体拘束にあたる行為（手引きの11項目）

<photo name="kenriyougo-02__kousoku-yougu" caption="身体拘束にあたる用具の例。①ベッドを**柵で4方向とも囲む**、②車いすの**Y字型抑制帯**、③指を動かせない**ミトン型の手袋**、④自分で脱げない**つなぎ服**（背中側から見た図。ファスナーが背中にある）。">

- 徘徊・転落を防ぐため、車いす・いす・ベッドに体や手足を**ひもなどで縛る**（3項目）
- 自分で降りられないよう、**ベッドを柵（サイドレール）で囲む**
- チューブを抜かないよう手足を縛る／**ミトン型の手袋**をつける
- ずり落ち・立ち上がりを防ぐため、**Y字型抑制帯・腰ベルト・車いすテーブル**をつける
- 立ち上がる力のある人に、**立ち上がれないいす**を使う
- 脱衣やおむつはずしを防ぐため、**つなぎ服（介護衣）**を着せる
- 行動を落ち着かせるため、**向精神薬を過剰に**飲ませる
- 自分で開けられない部屋に**隔離**する

身体拘束の弊害は、**身体的**（筋力低下・褥瘡・食欲低下・転倒）、**精神的**（尊厳の侵害・認知症の進行・家族の罪悪感）、**社会的**（施設への不信・職員の士気低下）の3つです。

### やむを得ず行う場合

| ○ | × |
|---|---|
| **切迫性**（命や体に危険がせまる）・**非代替性**（ほかに方法がない）・**一時性**（一時的）の**3要件すべて** | 2要件・「永続性」 |
| **組織として**判断（委員会など） | 職員1人の判断／家族の承諾書があればよい |
| 本人・家族に**そのつど**説明 | 事前説明があれば省略できる |
| **態様・時間・心身の状況・理由を記録**し、できるだけ早く解除する | 保険者に毎回報告する義務 |

「ほかに方法がない（非代替性）」と言うには、**先に代わりの方法を試している**ことが必要です。

| 心配なこと | 拘束の代わりに試す工夫 |
|---|---|
| ベッドから落ちる | 低いベッドにする・床にマットを敷く・センサーで知らせる |
| 一人で立ち上がって転ぶ | 立ち上がる理由（トイレ・不安など）を探し、時間を決めてトイレに誘う |
| チューブを抜いてしまう | かゆみや違和感を医療職と相談し、目に入りにくい位置に固定する |

> 本人の同意なくおむつをつけることは、手引きの11項目には入っていません。ただし、必要のないおむつは尊厳を傷つける**不適切なケア**です。

### 2024年度の介護報酬改定で強まったこと

- **虐待防止措置**（委員会の開催・指針の整備・研修・担当者の設置）は、2024年4月から**ほぼすべての介護サービス**で義務。行っていないと報酬が減る（**高齢者虐待防止措置未実施減算**）
- **身体拘束廃止未実施減算**が、施設に加えて**短期入所系・多機能系**にも広がった（減算の適用は2025年4月から）。訪問系・通所系でも、身体拘束の原則禁止と、やむを得ず行ったときの記録が基準に入った
- 施設などの**身体拘束適正化委員会**は**3か月に1回以上**開く

## ③ 障害者虐待防止法

2011年成立・2012年施行です（高齢者虐待防止法は2005年成立・2006年施行）。

| ○ | × |
|---|---|
| 対象は**養護者・障害者福祉施設従事者等・使用者（雇い主）** | 使用者による虐待は対象外 |
| 類型は高齢者と同じ**5つ**（介護等放棄は「放棄・放置」） | 3種類 |
| **著しい暴言・著しく拒絶的な対応＝心理的虐待** | 身体的虐待 |
| 発見した施設従事者が通報しても**守秘義務違反にならない** | — |
| **医療機関の管理者**は虐待防止の措置を講じる | — |
| 養護者による虐待の通報先は**市町村** | 都道府県 |
| 身体的虐待には「**正当な理由のない身体拘束**」も入る | — |
| 放棄・放置には「同居人や**ほかの利用者による虐待を放っておく**こと」も入る | — |
| 心理的虐待には「**不当な差別的言動**」も入る | — |

**障害者虐待の傾向**（厚生労働省の調査）：養護者による虐待は**身体的虐待**が最多で、被虐待者の障害は**知的障害**が最多、虐待者は**父**が最多です。施設従事者による虐待も**身体的虐待**が最多で、虐待した職員の職種は**生活支援員**が最多です。

### 高齢者虐待防止法と障害者虐待防止法の違い

| | 高齢者虐待防止法 | 障害者虐待防止法 |
|---|---|---|
| 対象となる虐待 | 養護者・養介護施設従事者等 | 養護者・障害者福祉施設従事者等・**使用者** |
| 通報先 | 市町村 | 市町村（**使用者による虐待は市町村または都道府県**） |
| 通報の義務 | 生命・身体に重大な危険があるとき・自分の施設で見つけたときは義務、それ以外は努力義務 | 虐待を受けたと思われる障害者を見つけた人は**通報義務** |

### 事例

| 場面 | ○ |
|---|---|
| 就労中の知的障害者が「上司から虐待を受けている」 | **勤務先のある市町村に通報**（または都道府県） |
| こだわりの強い自閉症の人が雑誌の処分でパニックに | 「**読みたい雑誌はとっておきましょう**」（本人の思いを尊重） |

「障害者虐待防止法」における、障害者に対する著しい暴言が当てはまる障害者虐待の類型として、最も適切なものを1つ選びなさい。
