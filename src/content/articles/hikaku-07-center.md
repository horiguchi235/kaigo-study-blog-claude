事例問題で「誰に・どこに相談するのが適切か」はとても多く出ます。<strong>対象（高齢者？障害者？子ども？お金？）</strong>と**根拠法**で整理しましょう。

**この記事のポイント**

1. 高齢者の総合相談＝**地域包括支援センター**（介護保険法・市町村）。
2. 障害者の相談の中核＝**基幹相談支援センター**（障害者総合支援法・市町村）。
3. 障害者の日中の居場所・創作活動＝**地域活動支援センター**。
4. 発達障害＝**発達障害者支援センター**、精神保健＝**精神保健福祉センター**（どちらも都道府県）。
5. 契約・悪質商法＝**消費生活センター**、生活に困ったら＝**福祉事務所**、仕事＝**ハローワーク**。

## ① 「センター」一覧

| センター | 根拠法 | 設置 | 主な役割 |
|---|---|---|---|
| **地域包括支援センター** | 介護保険法 | **市町村**（委託可） | 高齢者の**総合相談・権利擁護・介護予防ケアマネジメント**・包括的継続的ケアマネジメント支援、**地域ケア会議**。**保健師・社会福祉士・主任ケアマネ** |
| **基幹相談支援センター** | 障害者総合支援法 | **市町村**（努力義務） | 障害のある人の**相談支援の中核**、相談支援事業所への助言、権利擁護・虐待防止、地域移行の推進 |
| **地域活動支援センター** | 障害者総合支援法（地域生活支援事業） | 市町村 | **創作的活動・生産活動**、社会との交流の場 |
| **発達障害者支援センター** | **発達障害者支援法** | **都道府県・指定都市** | 発達障害の本人・家族の相談、発達支援・**就労支援**、普及啓発 |
| **精神保健福祉センター** | **精神保健福祉法** | **都道府県・指定都市** | 精神保健の**専門的な相談**、精神医療審査会の事務、精神障害者保健福祉手帳・自立支援医療（精神通院）の判定 |
| **認知症疾患医療センター** | （国の事業） | 都道府県・指定都市が指定 | 認知症の**鑑別診断**、専門医療相談、地域の医療・介護との連携 |
| **障害者就業・生活支援センター**（なかぽつ） | 障害者雇用促進法 | 都道府県知事が指定 | 障害者の**就業面と生活面の一体的な支援** |
| **地域障害者職業センター** | 障害者雇用促進法 | 高齢・障害・求職者雇用支援機構 | 職業評価、**ジョブコーチ**支援 |
| **地域生活定着支援センター** | （国の事業） | 都道府県 | **刑務所などを出る高齢者・障害者**の福祉サービスへのつなぎ |
| **消費生活センター** | 消費者安全法 | 都道府県（市町村は努力義務） | **契約・悪質商法**などの消費者トラブルの相談（消費者ホットライン188） |
| **市町村保健センター** | 地域保健法 | 市町村 | 住民に身近な**健康相談・健診・保健指導** |
| **地域子育て支援拠点・こども家庭センター** | 児童福祉法など | 市町村 | 子育ての相談、妊産婦・子どもの一体的支援 |

## ② 「センター」以外の重要な窓口

| 窓口 | 根拠法・設置 | 役割 |
|---|---|---|
| **福祉事務所** | 社会福祉法・都道府県と市（町村は任意） | **生活保護**・福祉六法の窓口、生活困窮者支援 |
| **保健所** | 地域保健法・都道府県・指定都市・中核市など | **感染症（結核など）・精神保健・食品衛生**など専門的な保健 |
| **児童相談所** | 児童福祉法・都道府県・指定都市 | 児童の相談、**一時保護**、療育手帳の判定（18歳未満） |
| **身体障害者更生相談所** | 身体障害者福祉法・**都道府県（必置）** | 身体障害の専門相談、**補装具の判定** |
| **知的障害者更生相談所** | 知的障害者福祉法・都道府県（必置） | 知的障害の専門相談・判定（18歳以上の療育手帳） |
| **社会福祉協議会** | 社会福祉法 | **地域福祉の推進**、日常生活自立支援事業、生活福祉資金の貸付、ボランティアセンター |
| **ハローワーク** | 職業安定法など・国 | 職業紹介、**雇用保険の手続き** |
| **労働基準監督署** | 労働基準法など・国 | 労働条件の監督、**労災保険** |

## ③ 事例で迷ったら

1. 65歳以上、介護や生活全般のことを相談したい → **地域包括支援センター**
2. 65歳未満の障害のある人、どのサービスを使えばいいか → **相談支援事業所**・**基幹相談支援センター**
3. 大人の発達障害（ADHDなど）の生活や仕事の悩み → **発達障害者支援センター**
4. お金がなく生活できない → **福祉事務所**（生活保護・生活困窮者支援）
5. 電話勧誘で高い契約をしてしまった → **消費生活センター**
6. 認知症かどうか詳しく調べたい → **認知症疾患医療センター**（かかりつけ医から紹介）
7. 結核になった、公費負担の申請 → **保健所**

## ひっかけパターン集

| 選択肢の表現 | なぜ× |
|---|---|
| 地域包括支援センターは障害者総合支援法に基づく | **介護保険法** |
| 基幹相談支援センターは都道府県が設置 | **市町村** |
| 精神保健福祉センターは市町村に必置 | **都道府県・指定都市** |
| 補装具の判定は地域活動支援センターが行う | **身体障害者更生相談所** |
| 発達障害者支援センターは子どもだけが対象 | **年齢を問わない** |
