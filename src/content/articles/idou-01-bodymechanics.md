**この記事のポイント**

1. ボディメカニクスは「**広く・低く・近く・ねじらず・大きな筋肉で・小さくまとめる**」。
2. 側臥位へは「**向く側に枕を寄せる → 腕を組む → 膝を立てる → 膝・肩の順に倒す**」。膝を立てるのが**トルクの原理**。
3. 筋肉は「**曲げる＝二頭筋・伸ばす＝三頭筋（肘）**」、立つ筋肉（抗重力筋）は**大腿四頭筋・大殿筋**。

## ① ボディメカニクスとノーリフティングケア【生活支援技術／こころとからだのしくみ】

| ○ 原則 | × よく出る誤り |
|---|---|
| **支持基底面を広く**とる（足を開く） | 狭くとる |
| **重心を低く**する（膝を曲げる） | 重心を高くする |
| 利用者に**近づく**（重心を近づける） | 重心を遠ざける |
| **体をねじらず、足先を移動する方向に向ける** | 腰がねじれた姿勢 |
| 腕だけでなく**大きな筋群**（脚・体幹）を使う | 指先や腕の力を使う |
| 利用者を**小さくまとめ**、ベッドとの**接地面を狭く**する | 背部が接する面積を広くする／摩擦面を大きく |
| 持ち上げずに**水平に引く**、てこの原理を使う | 両肘をベッドにつける |

### トルクの原理と力点

- 仰臥位 → 側臥位では**利用者の膝を立てる**と、小さな力で回転できる（トルクの原理）
- 手を当てる力点は**肩と膝**

### 全介助でベッドから車いすへ

車いすに移るときは「**重心を安定させて、車いすへ足先と体を向ける**」。手首で持ち上げる・前腕で真上に引き上げる・かかとを浮かせる、は×。

### ノーリフティングケア

**抱え上げない・引きずらない**介護。**スライディングボード**などの福祉用具を使う。抱え上げて端座位にする・抱きかかえて移乗は×。回転移動盤は**立位がとれる人**向けです。

> 立位で静止している人の重心線が前後・左右に動いたときの「ふらつく方向」を図で問う問題もあります。重心が移った方向にふらつきます。

## ② 体位・体位変換・良肢位【生活支援技術／こころとからだのしくみ】

<fig name="taii-ne">

<fig name="taii-oki">

| 場面 | ○ 正解 | × |
|---|---|---|
| 右片麻痺の人を仰臥位 → **左側臥位** | **枕を左側（向く側）に寄せる**、腕を組む、膝を立てる | 左へ水平移動・腕は体に沿わせる・下肢を伸ばす・肩と膝を同時に倒す |
| 喘息で咳が続き苦しい | **起座位**：オーバーベッドテーブルに枕を置いて**上半身を伏せる** | 腹臥位・枕を重ねる |
| 仰臥位 → 半座位（ファーラー位）の背上げ**前** | **臀部をベッドの曲がる位置に合わせる** | 足がフットボードに付くまで移動・ベッドを最も低くする |
| 左片麻痺の人が夜「背中が重くて眠れない」 | **右側臥位（健側が下）**にして**クッションを抱いてもらう** | 両膝の下にクッション |

<fig name="step-taiihenkan">

- 背上げ・背下げのあとは**背抜き（圧抜き）**をして、ずれと圧迫を除きます
- **良肢位**＝関節が動かなくなっても**ADLに最も支障が少ない姿勢**。肘は約90度に曲げ、足首はつま先が上（0度）。クッションを使って保つ

## ③ 骨・筋・関節と骨折【こころとからだのしくみ】

### 関節を動かす筋肉

| 動き | 主に働く筋肉 |
|---|---|
| 肘を**曲げる** | **上腕二頭筋** |
| 肘を**伸ばす** | **上腕三頭筋** |
| 肩を横に上げる（外転） | **三角筋** |
| 股関節を曲げる | **腸腰筋** |
| 股関節を伸ばす | 大殿筋 |
| 膝を伸ばす | **大腿四頭筋** |
| 膝を曲げる | 大腿二頭筋（ハムストリングス） |
| 足首を下に（底屈） | **下腿三頭筋** |
| 足首を上に（背屈） | **前脛骨筋** |

<fig name="kinniku">

**抗重力筋**（立位を保つ筋肉）：**大腿四頭筋**、**大殿筋**、下腿三頭筋、脊柱起立筋など。

### 骨

| ○ | × |
|---|---|
| 骨には**たんぱく質**（コラーゲン）が含まれる | Caは老化で増える |
| **骨芽細胞がつくり、破骨細胞が壊す** | 骨芽細胞が壊す |
| **負荷（運動）**で強くなる | 負荷で弱くなる |
| **日光浴**でビタミンDがつくられ、Ca吸収を助ける | ビタミンA・Eで吸収促進／日光を避ける |

### 高齢者の転倒骨折

- 多いのは**大腿骨頸部**・**脊椎圧迫**・**橈骨遠位端**（手首）・**上腕骨近位端**（肩）。**骨盤骨折は少ない**
- **大腿骨頸部骨折**：転倒で起こることが多く、**手術**をして**早期にリハビリ**を始める。寝たきりの原因になりやすい

## ひっかけパターン集（ボディメカニクス・体位で「ほぼ×」）

| 選択肢の表現 | なぜ× |
|---|---|
| 支持基底面を狭く・重心を高く | 不安定になる |
| 腕の力・指先の力で持ち上げる | 大きな筋群を使う |
| ベッドとの接地面を広くする | 摩擦が増える |
| 肩と膝を同時に倒す | 膝 → 肩の順 |
| 喘息で腹臥位にする | 起座位が楽 |
| 骨は負荷で弱くなる・日光を避ける | 運動と日光浴で強くなる |
