**この記事のポイント**

1. ボディメカニクスは「**広く・低く・近く・ねじらず・大きな筋肉で・小さくまとめる**」。
2. 側臥位へは「**向く側と反対側へ水平移動 → 向く側に枕を寄せる → 腕を組む → 膝を立てる → 介護者は向く側に立ち、膝・肩の順に手前（介護者のいる側）へ倒す**」。膝を立てるのが**トルクの原理**。
3. 筋肉は「**曲げる＝二頭筋・伸ばす＝三頭筋（肘）**」、立つ筋肉（抗重力筋）は**大腿四頭筋・大殿筋**。

## ① ボディメカニクスとノーリフティングケア

ボディメカニクス＝体の骨・筋肉・関節の動きを力学的に使い、少ない力で安全に介護する技術。まず用語をおさえます。

| 用語 | 意味 |
|---|---|
| 支持基底面 | 体を支えている床の面積（立っているときは両足で囲まれた範囲。杖をつくと広がる） |
| 重心 | 体の重さが集まる中心点（立位ではおへその少し下あたり） |
| 重心線 | 重心から真下に下ろした線。支持基底面の中に入っていれば安定し、外へ出るとその方向へふらつく・倒れる |
| トルク | 物を回転させる力。支点から遠いところを押すほど小さな力で回る（ドアの取っ手が蝶番から遠くにあるのと同じ） |

| ○ 原則 | × よく出る誤り |
|---|---|
| **支持基底面を広く**とる（足を前後左右に開く。倒れにくくなる） | 狭くとる |
| **重心を低く**する（膝を曲げて腰を落とす。安定する） | 重心を高くする |
| 利用者に**近づく**（互いの重心を近づけると、少ない力ですむ） | 重心を遠ざける |
| **体をねじらず、足先を移動する方向に向ける**（腰痛を防ぐ） | 腰がねじれた姿勢 |
| 腕だけでなく**大きな筋群**（脚・体幹）を使う（疲れにくい） | 指先や腕の力を使う |
| 利用者を**小さくまとめ**、ベッドとの**接地面を狭く**する（摩擦が減る） | 背部が接する面積を広くする／摩擦面を大きく |
| 持ち上げずに**水平に引く**、てこの原理を使う | 両肘をベッドにつける |

> 立位で静止している人の重心線が前後・左右に動いたときの「ふらつく方向」を図で問う問題もあります。重心線が移った方向（支持基底面から外れる側）にふらつきます。

### トルクの原理と力点

- 仰臥位 → 側臥位では**利用者の膝を立てる**と、小さな力で回転できる（トルクの原理）。膝を高く立てるほど、支点（ベッドに接する体の軸）から力点が遠くなるため
- 手を当てる力点は**肩と膝**

### 全介助でベッドから車いすへ

車いすに移るときは「**介護者の重心を安定させて、車いすへ足先と体を向ける**」。手首で持ち上げる・前腕で真上に引き上げる（腰を痛める）、介護者がかかとを浮かせる（足裏全体で床を踏みしめないと重心が不安定になる）、は×。

### ノーリフティングケア

**抱え上げない・引きずらない**介護。**スライディングボード**（座ったまま滑らせて移る板）やリフトなどの福祉用具を使う。抱え上げて端座位にする・抱きかかえて移乗は×。回転移動盤（立ったまま体の向きを変える円盤）は**立位がとれる人**向けです。

- 自分の体で確かめよう：肘を曲げると力こぶ（**上腕二頭筋**）が固くなり、いすから立ち上がると太ももの前（**大腿四頭筋**）が固くなります。大きな筋肉を使う感覚を体で確かめると覚えやすくなります

## ② 体位・体位変換・良肢位

<fig name="taii-ne">

### 体位の名前と角度

| 体位 | 角度・形 | よく使う場面 |
|---|---|---|
| ファーラー位（半座位） | 上半身を約45度起こす（食事のときは45〜60度） | 食事・会話・息苦しいとき |
| セミファーラー位 | 上半身を約15〜30度起こす | 休息・経管栄養のあと・軽い息苦しさ |
| 起座位 | 上半身を起こし、オーバーベッドテーブルの枕に**伏せる** | 喘息・心不全で呼吸が苦しいとき |

息苦しいとき：セミファーラー位＝15〜30度、ファーラー位（半座位）＝45度前後。息苦しさが強いほど上半身を高くします（さらに強いときは起座位）。

### 仰臥位から側臥位へ（右片麻痺の人を左側臥位に）

<fig name="step-taiihenkan">

1. 向く側と反対側（右）へ体を**水平移動**しておく（横向きになったとき、体がベッドの中央に来るように）
2. **枕を向く側（左）に寄せる**
3. 腕を胸の上で組む（体を小さくまとめる）
4. 膝を高く立てる
5. 介護者は**向く側（左）に立つ**
6. **膝 → 肩の順**に、介護者のいる側（手前）へ倒す

×になる選択肢：向く側（左）へ水平移動する、腕を体に沿わせる、下肢を伸ばしたまま、肩と膝を同時に倒す。

### 場面ごとの体位

| 場面 | ○ 正解 | × |
|---|---|---|
| 喘息で咳が続き苦しい | **起座位**：オーバーベッドテーブルに枕を置いて**上半身を伏せる** | 腹臥位・枕を重ねる |
| 仰臥位 → 半座位（ファーラー位）の背上げ**前** | **臀部をベッドの曲がる位置に合わせる** | 足がフットボードに付くまで移動・ベッドを最も低くする |
| 左片麻痺の人が夜「背中が重くて眠れない」 | <strong>右側臥位（健側が下）</strong>にして**クッションを抱いてもらう** | 両膝の下にクッション |

- 背上げ・背下げのあとは<strong>背抜き（圧抜き）</strong>をして、背中を一度マットレスから離し、ずれと圧迫を除きます
- **良肢位**＝関節が動かなくなっても**ADLに最も支障が少ない姿勢**。肘は約90度に曲げ、手は軽くボールを握る形、膝は軽く曲げ（約10度）、足首はつま先が上（0度）。クッションを使って保つ
- 褥瘡（床ずれ）ができやすい部位：仰臥位＝**仙骨部**（お尻の真ん中の骨）・かかと・後頭部・肩甲骨部、側臥位＝**大転子部**（太もものつけ根の外側の出っぱり）・耳・肩・くるぶし、座位＝坐骨部（お尻の下の骨）
- **体位ドレナージ**＝重力を利用して痰を動かす方法。痰がたまっている部位を上にした姿勢をとる。医療職の指示で行う

## ③ 骨・筋・関節と骨折

### 関節を動かす筋肉

| 動き | 主に働く筋肉 | どこにある？ |
|---|---|---|
| 肘を**曲げる** | **上腕二頭筋** | 二の腕の前（力こぶ） |
| 肘を**伸ばす** | **上腕三頭筋** | 二の腕の後ろ |
| 肩を横に上げる（外転） | **三角筋** | 肩の丸み |
| 股関節を曲げる | **腸腰筋** | おなかの奥（背骨と太ももをつなぐ） |
| 股関節を伸ばす | 大殿筋 | お尻 |
| 膝を伸ばす | **大腿四頭筋** | 太ももの前 |
| 膝を曲げる | 大腿二頭筋（ハムストリングス） | 太ももの後ろ |
| 足首を下に（底屈） | **下腿三頭筋** | ふくらはぎ |
| 足首を上に（背屈） | **前脛骨筋** | すねの前 |

<fig name="kinniku">

**抗重力筋**（立位を保つ筋肉）：**大腿四頭筋**、**大殿筋**、下腿三頭筋、脊柱起立筋など。介護予防の筋力運動は、健康状態を確認し**弱い負荷から少しずつ上げる**（強い負荷から始めない）。

### 関節の種類

| 関節 | 場所と動き |
|---|---|
| 蝶番関節 | **肘・膝**。ドアの蝶番のように曲げ伸ばしだけ |
| 球関節 | **肩・股関節**。いろいろな方向に動く |
| 車軸関節 | 首（第1・第2頸椎）・前腕。回転する |
| 鞍関節 | 親指のつけ根 |

### 骨

| ○ | × |
|---|---|
| 骨には**たんぱく質**（コラーゲン）が含まれる | Caは老化で増える |
| **骨芽細胞がつくり、破骨細胞が壊す** | 骨芽細胞が壊す |
| <strong>負荷（運動）</strong>で強くなる | 負荷で弱くなる |
| **日光浴**でビタミンDがつくられ、Ca吸収を助ける | ビタミンA・Eで吸収促進／日光を避ける |

- 骨の役割：体を支える・動かす・臓器を守る・**血をつくる（骨髄）**・カルシウムをためる。寝たきりになると骨からカルシウムが溶け出す
- 筋肉の種類：**骨格筋＝随意筋**（自分の意思で動かせる）、**平滑筋**（内臓・血管）と**心筋＝不随意筋**
- 前腕は**橈骨＝親指側**・尺骨＝小指側、下腿は脛骨＝内側（太い）・腓骨＝外側

### 高齢者の転倒骨折

- 多いのは**大腿骨頸部**・**脊椎圧迫**・**橈骨遠位端**（手首）・**上腕骨近位端**（肩）。**骨盤骨折は少ない**
- **大腿骨頸部骨折**：転倒で起こることが多く、**手術**をして**早期にリハビリ**を始める。寝たきりの原因になりやすい

## ひっかけパターン集（ボディメカニクス・体位で「ほぼ×」）

| 選択肢の表現 | なぜ× |
|---|---|
| 支持基底面を狭く・重心を高く | 不安定になる |
| 腕の力・指先の力で持ち上げる | 大きな筋群を使う |
| ベッドとの接地面を広くする | 摩擦が増える |
| 肩と膝を同時に倒す | 膝 → 肩の順 |
| 側臥位にする前に、向く側へ水平移動する | 反対側へ寄せておく（ベッドの中央で横向きになるように） |
| 喘息で腹臥位にする | 起座位が楽 |
| 介護予防の筋力運動は強い負荷から | 弱い負荷から少しずつ |
| 骨は負荷で弱くなる・日光を避ける | 運動と日光浴で強くなる |
