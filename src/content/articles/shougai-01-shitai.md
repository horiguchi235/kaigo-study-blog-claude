**この記事のポイント**

1. **脳血管障害＝片麻痺**、**頸髄損傷＝四肢麻痺**、**腰髄（胸髄）損傷＝対麻痺**。
2. 関節リウマチは「**小さな関節に負担をかけない**」：補高便座・ループ付きタオル・長柄のくし・荷物は腕にかける。
3. 呼吸器の障害は「**息を止めない・胸を圧迫しない・ゆっくり**」：洋式便器、前開きの服、湯は胸の下まで。

## ① 肢体不自由

身体障害者手帳をもつ人のうち、いちばん多いのが**肢体不自由**（約38%）、次が**内部障害**（約33%）です（2022年 生活のしづらさなどに関する調査）。

### 麻痺の種類と原因

| 麻痺 | 原因になる病気・けが |
|---|---|
| **片麻痺**（体の片側） | **脳血管障害**（脳梗塞・脳出血）。**言語障害**を伴うことも |
| **四肢麻痺**（両手両足。体幹の麻痺を伴うことも） | **頸髄損傷** |
| **対麻痺**（両足） | **胸髄・腰髄損傷** |
| 単麻痺（手足の1本） | 末梢神経損傷など |

> 右手でT字杖を使い、左足に短下肢装具をつけている → 左側の手足がまひした**片麻痺**。杖は健側の手で持ち、装具は患側の足につけます。

### 脊髄損傷のレベルとできること

表の記号は、背骨の中の脊髄のどの高さが傷ついたかを表します。**C＝頸髄**（首）、**T＝胸髄**、**L＝腰髄**。数字が小さいほど上で、**上で傷つくほど麻痺の範囲が広く**なります。

| 損傷レベル | できること |
|---|---|
| C1〜C3 | 人工呼吸器が必要なことも。電動車いす（あご操作） |
| C4 | 首を動かし、肩をすくめる。電動車いす |
| C5 | ひじを曲げられる。電動車いす（平地は工夫した手動車いすも） |
| **C6** | **手首を反らせる** → **自助具**を使って食事・書字。ハンドリムを工夫した車いす |
| **C7** | ひじを伸ばせる → **プッシュアップ**ができる |
| 胸髄・腰髄 | 上肢は自由。**車いすでADL（日常生活動作）自立**。腰髄は長下肢装具で歩行も |

#### 「どこまで感じられるか」も高さで決まる

「**第6頸髄節まで機能残存**」は、**C6までは働いていて、それより下が障害されている**という意味です。傷ついた高さより下の皮膚は、**感覚がない（または鈍い）**ので、熱さや痛みに気づけません。

| 高さのめやす | 体の場所（感覚が残る下の境目） |
|---|---|
| C4 | 首・肩の上のあたり |
| C6 | 腕の親指側 |
| T4 | 乳首の高さ |
| T10 | へその高さ |
| L1 | 足のつけ根 |

> 頸髄損傷（C6まで残存）の人の入浴で湯温を確かめてもらうなら、**感覚が残っている首まわり・肩など上の部分**で。胸・お腹・太ももに湯をかけても熱さを感じられず、やけどに気づけません。**介護職も必ず自分で湯温を確かめます**。

- 車いす生活の対麻痺の人の褥瘡は**坐骨結節部**（お尻の下の骨）に起こりやすい
- 感覚もまひするので、**やけど・けが・褥瘡**に気づきにくい。**排尿・排便障害**もある
- **体温調節障害**：汗をかけず、熱がこもる**うつ熱**になりやすい（冷房・濡れタオルで冷やす）
- **起立性低血圧**：血圧の調節がうまくいかない。車いすで症状が出たら、**車いすを後ろに倒して頭を低くする**
- **自律神経過反射**：主に**第6胸髄より上**の損傷で起こる。膀胱に尿がたまる・便秘などの刺激で、**急に血圧が上がり、頭痛・顔のほてり・発汗**が出る。命にかかわるので、**上体を起こし**、導尿や排便の確認など**原因を取り除き**、すぐ看護師・医師に連絡

### そのほか

- **脳性麻痺**（生まれる前後に脳が傷ついて起こる運動の障害）の型：**痙直型**（筋肉がつっぱる。**最も多い**）・**アテトーゼ型**（不随意運動型：自分の意思と関係なく体が動く。言語障害を伴いやすい）・**強剛型**（固縮型：筋肉がかたく関節の動く範囲が制限される）・**失調型**（バランスがとりにくい）・混合型
  - 定義：**受胎から生後4週以内**に起きた脳の損傷による、**進行しない**運動と姿勢の障害。原因は出産時の仮死、生後の脳炎・髄膜炎など。言語障害を伴うことが多い
  - **二次障害**：もとの障害は進まないのに、長年の体の使い方で新しい障害が加わること。**アテトーゼ型**は首が不随意に動き続けるため、中年期に**頸椎症性脊髄症**（首の骨で脊髄が圧迫され、手足のしびれ・痛み・手が使いにくくなる）が起こりやすい。「食後に首が痛い・手がしびれる」はそのサイン。痙直型は関節の拘縮・股関節脱臼・側弯（背骨が横に曲がる）が起こりやすい
  - アテトーゼ型で発音は難しいが言葉は理解できる人の意思伝達 → **携帯用会話補助装置**（[失語症・構音障害の人とのコミュニケーション](../shougaicomm-01-gengo/)）
- **腓骨神経麻痺**：足首が垂れる（下垂足）→ **短下肢装具**。脳卒中のリハビリ初期には、膝折れを防ぐため**長下肢装具**を使うことがある
- 片麻痺の人が自分でこぐ車いす：**健側の足底が床につく座面の高さ**（片手片足でこぐ）

## ② 関節リウマチの関節保護

<photo name="shougai-01__kansetsu-hogo" caption="関節を守る道具。左から**補高便座**（立ち座りで膝や股関節への負担を減らす）、**ループ付きタオル**（手指で強く握らずに背中を洗える）、**長柄のくし**（肩やひじを大きく上げずに髪をとかせる）。">

関節リウマチは、<strong>小さな関節（手指・手首）</strong>から左右対称に炎症が起こり、**朝のこわばり**・変形が進む**自己免疫**の病気（病気のしくみは [骨・パーキンソン病・排泄・皮膚・こころの病気](../byouki-03-hone/)）。この記事では、試験に出る**関節に負担をかけない**生活の工夫を覚えます。

| ○ | × |
|---|---|
| 便器に**補高便座**をのせる（立ち上がりやすく） | 低いいす |
| 体を洗うときは**ループ付きタオル** | — |
| **柄の長いくし**（肩やひじを大きく動かさずにすむ） | — |
| コップは**両手で**持つ | 片手で持つ |
| 荷物は**前腕や肩**にかける | 指先で持つ・持ち手を握る |
| ドアの取っ手は**レバー式** | 丸いノブ（ひねる動作） |
| 寝るときは**低い枕**、**膝を伸ばして** | 高い枕・膝を曲げて寝る（拘縮のもと） |

> 手首に痛みがある人の杖は**プラットホームクラッチ**（前腕で支える）。→ 移動②「片麻痺の立ち上がり・移乗・杖歩行」

## ③ 内部障害

身体障害者手帳の内部障害は **7種類**：**心臓・腎臓・呼吸器・膀胱または直腸・小腸・HIVによる免疫・肝臓**。

内部障害に共通するのは、**外から見てわかりにくい**ことです。周りの理解を得にくく、それがストレスや抑うつにつながりやすいので、本人の訴えをていねいに聴きます。

### 病気と治療の組合せ

| 病気 | 必要になることがある治療・器具 |
|---|---|
| **大腸がん** | **消化管ストーマ**（人工肛門） |
| 膀胱がん | 尿路ストーマ（人工膀胱） |
| **慢性腎不全** | **透析** |
| **COPD**（慢性閉塞性肺疾患） | **在宅酸素療法** |
| 不整脈（徐脈） | **ペースメーカー**（装着者も手帳の対象） |
| 心臓弁膜症 | 人工弁（手術後は血を固まりにくくする薬で**出血しやすい**） |

### 生活の工夫

| 障害 | ○ | × |
|---|---|---|
| **呼吸器機能障害** | **洋式便器**（いきみや前かがみが少ない）、**前開きの服**、湯は**胸より下**、食事は**少量を回数多く**（お腹がふくれると苦しい）、**ゆっくり**動く。COPDでは**口すぼめ呼吸** | かぶりの服・肩までつかる・食事回数を減らす・すばやく歩く |
| 在宅酸素療法 | 火気厳禁・禁煙。**酸素の量は医師の指示どおり**。停電・外出時の備えと緊急連絡先を確認 | 息苦しいときに自分で酸素量を増やす |
| **心臓機能障害** | **息切れ・呼吸困難**が出やすい。**塩分制限**（水分・動物性脂肪も控えめに）。外出は体調に合わせて可。ストレスも負担になる。**寒さで発作が起きやすい**ので冬の脱衣所・トイレを暖める、入浴は**ぬるめの湯で長湯しない**、排便で**いきまない**（便秘を防ぐ）。ペースメーカーの人は医師の指示に従う | 外出を避けるべき・塩分制限不要 |
| 腎臓機能障害 | **血液透析**＝通院して**週3回・1回4時間程度**、**腹膜透析（CAPD）**＝自宅で1日数回バッグ交換。**カリウム・水分・塩分**を制限 | 水分を多くとる |
| 肝臓機能障害 | 肝炎・肝硬変などで肝臓の働きが落ちた状態。**自覚症状が出にくい**ので、だるさ・むくみ・**黄疸**（皮膚や白目が黄色くなる）に気づいたら早めの受診を勧める。肝硬変は肝臓がんになりやすい | — |
| ぼうこう・直腸機能障害（ストーマ） | 回腸ストーマの便は**水様で量が多い**、S状結腸ストーマの便は**固め**。ためておく機能がないので装具（パウチ）を使う | — |
| **HIV**（免疫機能障害） | 免疫が落ちて**日和見感染症**（ふだんは問題にならない弱い菌で発症）を起こしやすい。**肛門周囲を清潔**に（びらん予防）、口腔ケアをしっかり、**生ものは避ける** | 他人の皮膚に触れない（日常の接触では感染しない）・日光を避ける |

**呼吸器機能障害の補足**

- 息苦しいときは、あお向けより**上体を起こして前かがみにもたれる姿勢（起座位）**が楽です。
- **口すぼめ呼吸**：鼻から吸って、口をすぼめて「ふーっ」とゆっくり吐く。気道が広がり、息を吐きやすくなります。
- 環境：かぜなど気道の感染を防ぐ、ほこりを取る、温度・湿度を整える、室内は禁煙、強い香りを避ける。COPDのいちばんの原因は**喫煙**です。食事は少量を回数多く、カロリーは十分に。

**腎臓機能障害の補足**

- **急性腎不全**＝急に腎臓が働かなくなる（回復することもある）。**慢性腎不全**＝数か月〜数年かけて少しずつ低下し、元には戻らない。腎機能が正常の**15％ほど**まで下がると**末期腎不全**で、**透析か腎移植**が必要になります。
- **透析**＝腎臓の代わりに、血液から余分な水分や老廃物を取り除く治療。腹膜透析（CAPD＝連続携行式腹膜透析）は、お腹に入れた管から透析液を出し入れする方法で、通院は月1〜2回。**管の出口の感染**に注意します。
- 食事はたんぱく質の制限が加わることもあります。薬が体に残りやすく、副作用が強く出ることがあります。

**HIVとエイズのちがい**

- **HIV**はウイルスの名前です。HIVに感染して免疫が落ち、国が定める日和見感染症などの病気を発症した状態が**エイズ**（後天性免疫不全症候群）。HIVに感染していても、エイズを発症していない人は多くいます。
- 感染経路は**血液・性行為・母子感染**（母乳を含む）。握手・入浴・食器の共用など**日常の接触ではうつりません**。介護では**標準予防策**（血液・体液に触れるときは手袋、手洗い）で、ほかの利用者と同じように対応します。

## ひっかけパターン集（身体障害で「ほぼ×」）

| 選択肢の表現 | なぜ× |
|---|---|
| 腰髄損傷で四肢麻痺 | 四肢麻痺は頸髄、腰髄は対麻痺 |
| 対麻痺の褥瘡は背部・頭部 | 座っている時間が長く坐骨結節部 |
| リウマチの人に低いいす・丸いノブ | 関節に負担 |
| 呼吸器障害で肩まで湯につかる | 水圧で胸が圧迫される |
| ペースメーカーは手帳の対象外 | 心臓機能障害として対象 |
| HIVの人の皮膚に触れない | 日常の接触ではうつらない |
| 在宅酸素の量は息苦しさに合わせて自分で調整 | 医師の指示どおり |
| 自律神経過反射は様子を見る | 急な高血圧で危険。原因（尿・便）を取り除き、すぐ連絡 |
