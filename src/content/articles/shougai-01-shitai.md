**この記事のポイント**

1. **脳血管障害＝片麻痺**、**頸髄損傷＝四肢麻痺**、**腰髄（胸髄）損傷＝対麻痺**。
2. 関節リウマチは「**小さな関節に負担をかけない**」：補高便座・ループ付きタオル・長柄のくし・荷物は腕にかける。
3. 呼吸器の障害は「**息を止めない・胸を圧迫しない・ゆっくり**」：洋式便器、前開きの服、湯は胸の下まで。

## ① 肢体不自由【障害の理解】

### 麻痺の種類と原因

| 麻痺 | 原因になる病気・けが |
|---|---|
| **片麻痺**（体の片側） | **脳血管障害**（脳梗塞・脳出血）。**言語障害**を伴うことも |
| **四肢麻痺**（両手両足） | **頸髄損傷** |
| **対麻痺**（両足） | **胸髄・腰髄損傷** |
| 単麻痺（手足の1本） | 末梢神経損傷など |

> 右手でT字杖を使い、左足に短下肢装具をつけている → 左側の手足がまひした**片麻痺**。杖は健側の手で持ち、装具は患側の足につけます。

### 脊髄損傷のレベルとできること

| 損傷レベル | できること |
|---|---|
| C1〜C3 | 人工呼吸器が必要なことも。電動車いす（あご操作） |
| C4 | 首と肩をすくめる。電動車いす |
| C5〜C6 | ひじを曲げられる。ハンドリムを工夫した車いす |
| **C7** | ひじを伸ばせる → **プッシュアップ**ができる |
| 胸髄・腰髄 | 上肢は自由。**車いすでADL自立**。腰髄は長下肢装具で歩行も |

- 車いす生活の対麻痺の人の褥瘡は**坐骨結節部**（お尻の下の骨）に起こりやすい
- 感覚もまひするので、**やけど・けが・褥瘡**に気づきにくい。**排尿・排便障害**、**体温調節障害**も

### そのほか

- **脳性麻痺**：**痙直型**（つっぱる）・**アテトーゼ型（不随意運動型）**・失調型などに分類
- **腓骨神経麻痺**：足首が垂れる（下垂足）→ **短下肢装具**
- 片麻痺の人が自分でこぐ車いす：**健側の足底が床につく座面の高さ**（片手片足でこぐ）

## ② 関節リウマチの関節保護【障害の理解】

関節リウマチは、**小さな関節（手指・手首）**から炎症が起こり、**朝のこわばり**・変形が進む病気。**関節に負担をかけない**生活の工夫が出ます。

| ○ | × |
|---|---|
| 便器に**補高便座**をのせる（立ち上がりやすく） | 低いいす |
| 体を洗うときは**ループ付きタオル** | — |
| **柄の長いくし**（肩やひじを大きく動かさずにすむ） | — |
| コップは**両手で**持つ | 片手で持つ |
| 荷物は**前腕や肩**にかける | 指先で持つ・持ち手を握る |
| ドアの取っ手は**レバー式** | 丸いノブ（ひねる動作） |
| 寝るときは**低い枕**、**膝を伸ばして** | 高い枕・膝を曲げて寝る（拘縮のもと） |

> 手首に痛みがある人の杖は**プラットホームクラッチ**（前腕で支える）。→ 移動②「片麻痺の立ち上がり・移乗・杖歩行」

## ③ 内部障害【障害の理解】

身体障害者手帳の内部障害は **7種類**：**心臓・腎臓・呼吸器・膀胱または直腸・小腸・HIVによる免疫・肝臓**。

### 病気と治療の組合せ

| 病気 | 必要になることがある治療・器具 |
|---|---|
| **大腸がん** | **消化管ストーマ**（人工肛門） |
| 膀胱がん | 尿路ストーマ（人工膀胱） |
| **慢性腎不全** | **透析** |
| **COPD**（慢性閉塞性肺疾患） | **在宅酸素療法** |
| 不整脈（徐脈） | **ペースメーカー**（装着者も手帳の対象） |

### 生活の工夫

| 障害 | ○ | × |
|---|---|---|
| **呼吸器機能障害** | **洋式便器**（いきみや前かがみが少ない）、**前開きの服**、湯は**胸より下**、食事は**少量を回数多く**、**ゆっくり**動く | かぶりの服・肩までつかる・食事回数を減らす・すばやく歩く |
| **心臓機能障害** | **息切れ・呼吸困難**が出やすい。**塩分制限**。外出は体調に合わせて可。ストレスも負担になる | 外出を避けるべき・塩分制限不要 |
| **HIV**（免疫機能障害） | **肛門周囲を清潔**に（びらん予防）、口腔ケアをしっかり、**生ものは避ける** | 他人の皮膚に触れない（日常の接触では感染しない）・日光を避ける |

## ＋α もう一歩：実務者研修レベルで覚えたいこと

過去問にはまだ出ていないけれど、実務者研修の確認テストでよく問われる、関連して覚えておきたい知識です。

- **麻痺の種類**：単麻痺＝手足の1本／**片麻痺**＝体の左右どちらか半分／**対麻痺**＝両足／**四肢麻痺**＝両手両足（**体幹の麻痺を伴う**こともある）。**頸髄損傷＝四肢麻痺**、胸髄・腰髄損傷＝対麻痺。
- **脊髄損傷**の人は血圧の調節もうまくいかず**起立性低血圧**を起こしやすい。車いすで低血圧の症状が出たら、**車いすを後ろに倒して頭を低くする**。
- **脳性麻痺の型**：**痙直型**＝筋緊張が強く手足が突っ張る／**アテトーゼ型**＝自分の意思と関係なく体が動く（不随意運動）／失調型＝バランスが取りにくい／**強直型**＝筋肉がかたく**関節の動く範囲が制限**される。
- 脳卒中のリハビリ初期には、膝折れを防ぐため**長下肢装具**を使うことがある。
- **COPD（慢性閉塞性肺疾患）**＝主に**喫煙**で長い間気道がふさがる病気の総称（肺気腫・慢性気管支炎）。息切れ・せき・痰。**口すぼめ呼吸**、食事は**少量ずつ数回に分ける**（お腹がふくれると苦しい）。
- **在宅酸素療法**：火気厳禁・禁煙、**酸素の量は医師の指示どおり**（自己判断で変えない）、**緊急時の連絡体制**や停電・外出時の備えを確認。
- 2016年の調査で、身体障害の中では**肢体不自由（下肢）**の人数が最も多い。

## 📘 もう一歩先へ：過去問にはまだ出ていない重要ポイント

過去問ではまだ問われていないものの、テキストで重要語として扱われ、今後出題されてもおかしくない関連知識です。過去問の論点とセットで押さえておくと、初めて見る選択肢にも対応できます。

- **脊髄損傷**の高さと麻痺：**頸髄＝四肢麻痺**、胸髄・腰髄＝下肢の対麻痺。体温調節ができず**うつ熱**になりやすい（冷房・濡れタオル）、**起立性低血圧**、膀胱に尿がたまる・便秘などで急に血圧が上がる**自律神経過反射**に注意。
- **脳性麻痺**の型：**痙直型が最多**（筋肉がつっぱる）、**アテトーゼ型**（自分の意思と関係なく体が動く・言語障害を伴いやすい）、失調型（バランスがとれない）。
- **心臓機能障害**：人工弁の手術後は血を固まりにくくする薬で**出血しやすい**。
- **腎臓機能障害**：**血液透析**＝週2〜3回通院、**腹膜透析（CAPD）**＝自宅で1日数回バッグ交換。透析では**カリウム・水分・塩分**を制限。
- **ストーマ**：回腸ストーマは便が**水様で量が多い**、S状結腸ストーマは便が**固い**。体内にためておく機能がないので装具（パウチ）が必要。
- **HIV/エイズ**：免疫が落ちて**日和見感染症**（ふだんは問題にならない菌で発症）。日常の接触ではうつらない。
