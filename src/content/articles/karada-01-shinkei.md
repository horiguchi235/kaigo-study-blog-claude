## ① 脳と神経

### 神経のしくみの全体像

- 神経は、**中枢神経**（脳と脊髄）と、そこから全身にのびる**末梢神経**に分かれる
- 末梢神経は、自分の意思で体を動かしたり感覚を伝えたりする**体性神経**と、意思と関係なく内臓を調整する**自律神経**からなる
- 脳は**大脳・間脳（視床・視床下部）・脳幹（中脳・橋・延髄）・小脳**でできていて、成人で約1300g。脊髄は背骨の中を通り、上は延髄につながる
- 大脳の運動野は**体の反対側**の筋肉を動かす。だから**右の脳**に脳梗塞が起こると**左半身**がまひする（左片麻痺）
- 扁桃体や海馬は、大脳の奥の**大脳辺縁系**にあり、情動や記憶にかかわる

### 大脳の機能局在

大脳は**前頭葉・頭頂葉・側頭葉・後頭葉の4つ**に分かれ（顔のほう＝前が前頭葉、てっぺんが頭頂葉、耳の上の横が側頭葉、後ろが後頭葉）、場所ごとに受け持つ働きが決まっています（**機能局在**）。表面（皮質）は灰白質、内部（髄質）は白質です。

| 部位 | 主な働き | 傷むと |
|---|---|---|
| **前頭葉** | **運動野**、運動性言語野（**ブローカ野**）、思考・意欲 | ブローカ野：言葉は理解できるが、なめらかに話せない（**運動性失語**） |
| **頭頂葉** | **体性感覚野**（皮膚の痛み・温度・触覚を感じとる場所） | — |
| **側頭葉** | **聴覚野**、感覚性言語野（**ウェルニッケ野**）、記憶 | ウェルニッケ野：すらすら話せるが、言葉の理解が難しい（**感覚性失語**） |
| **後頭葉** | **視覚野** | — |

## ② 自律神経・内分泌・臓器

### ホメオスタシス（体の状態を一定に保つ働き）

体の内側の状態（体温・血圧・水分など）を一定に保つ働きを**ホメオスタシス（恒常性）**といいます。**視床下部**が、**自律神経・内分泌（ホルモン）・免疫**の3つを使って調整します。暑いと汗をかき、皮膚の血管が広がって熱を逃がします。寒いと体がふるえて熱をつくります。体温は成人で36〜37℃くらいで、子どもは高め、高齢者は低めです。こころとからだはつながっていて、強いストレスが続くと副腎皮質ホルモンが出すぎて免疫が落ち、かぜなどにかかりやすくなります。

### 交感神経と副交感神経

| 作用 | 交感神経（活動・緊張） | 副交感神経（休息・リラックス） |
|---|---|---|
| 心拍数 | **増加** | 減少 |
| 血管 | **収縮**→血圧上昇 | 拡張 |
| 瞳孔 | **散大** | 縮小 |
| 気道 | 拡張 | 収縮 |
| 消化 | 抑制 | **促進** |
| 唾液 | 少量のねばねばした唾液 | さらさらの唾液を多く出す |
| 発汗 | **促進** | — |
| 膀胱 | ゆるむ（尿をためる） | 縮む（**排尿**を促す） |
| 血糖 | 上昇 | — |
| 呼吸 | 速くなる | 穏やかになる |
| 筋肉 | 緊張する | ゆるむ |

### ホルモン（内分泌）

ホルモンは決まった器官でごく少量つくられ、血液にのって離れた器官に働きます。

| 分泌するところ | ホルモン | 働き |
|---|---|---|
| 松果体 | メラトニン | 眠りを誘う |
| 下垂体前葉 | 成長ホルモン | 体の成長・修復 |
| 下垂体後葉 | バソプレシン | 尿を減らす（抗利尿） |
| 下垂体後葉 | オキシトシン | 子宮を縮める |
| 甲状腺 | 甲状腺ホルモン | 代謝を高める |
| 副腎髄質 | アドレナリン | 心拍・血圧・血糖を上げる |
| 副腎皮質 | コルチゾール | ストレスに対応する |
| 副腎皮質 | アルドステロン | 尿にカリウムを出す（体に塩分と水をためる） |
| 性腺 | エストロゲン・プロゲステロン・アンドロゲン | 女性らしさ・男性らしさ、妊娠にかかわる |
| 胸腺 | — | 免疫のリンパ球（T細胞）を育てる |
| **膵臓**（ランゲルハンス島のβ細胞） | **インスリン** | **血糖を下げる** |
| 膵臓（α細胞） | グルカゴン | 血糖を上げる |

- 血糖を**下げる**ホルモンは**インスリンだけ**。**上げる**ホルモンはグルカゴン・アドレナリン・コルチゾールなど**複数**ある
- 女性は40歳代半ばから更年期に入り、閉経とともにホルモンのバランスが変わって体調をくずしやすい

### 臓器の働き

| 臓器 | ○ 働き | × |

| **膵臓** | **ランゲルハンス島**から**インスリン**（血糖を下げる） | 副腎がインスリン |

- **蠕動運動**＝胃や腸が波のように動いて、中身を先へ送る動き
- 呼吸のしくみ：空気は**鼻腔 → 咽頭 → 喉頭 → 気管 → 気管支 → 肺**と進む（鼻腔は喉頭に直接つながらず、咽頭を通る）。息を吸う・はくのは、**横隔膜**と肋骨の間の筋肉が縮んだりゆるんだりして肺がふくらみ縮むから。肺で空気と血液の間で酸素と二酸化炭素を交換するのが**外呼吸**、血液と体の細胞の間で交換するのが**内呼吸**。呼吸のリズムは**延髄と橋**が無意識に刻んでいる
- 肺は右3葉・左2葉。<strong>右の気管支は左より太く・短く、垂直に近い（まっすぐ下に向かう）</strong>ので、誤嚥した物は右肺に入りやすい

## ③ 感覚器・発音

感覚器は、**眼（視覚）・耳（聴覚と平衡）・鼻（嗅覚）・舌（味覚）・皮膚（触覚・圧覚・痛覚・温度感覚）**の5つです。関節や筋肉の位置や動きを感じる感覚は**深部感覚**といいます。眼球は、まぶた・結膜・涙に守られています。

### 眼

| 病気・変化 | ポイント |
|---|---|
| **白内障** | **水晶体が白く濁る**。まぶしい・かすむ |
| 緑内障 | **視神経が傷み、視野が欠ける**。眼圧の上昇が主な原因の1つ（眼圧が正常でも起こる）。急に眼圧が上がると眼の痛み・頭痛も |
| 加齢黄斑変性症 | **見たい中心がゆがむ・暗くなる** |
| 糖尿病性網膜症 | 網膜の出血、失明の原因に |
| **流行性角結膜炎** | **結膜の充血**・目やに。**感染力が強い** |
| 老化 | **明暗に順応する時間が長くなる**、近くが見えにくい、ピント調節が遅い、水晶体は黄色く濁る、涙は減る |

<fig name="me">

- 目のしくみ：光は**角膜 → 瞳孔 → 水晶体 → 硝子体 → 網膜**と進み、**視神経**で脳へ。**虹彩**＝瞳孔の大きさを変えて光の量を調節／**水晶体**＝ピントを合わせる（カメラのレンズ）／**網膜**＝光を受けて神経の信号に変える（フィルム）。網膜の中心が**黄斑**（加齢黄斑変性で傷む）、緑内障で傷むのは**視神経**
- 視野の障害：**求心性視野狭窄**＝**中心は見えるが周りが見えない**（網膜色素変性症など）／中心暗点＝中心が見えない／半盲＝視野の左右どちらかが欠ける

### 耳・鼻・発音

<fig name="mimi">

- 耳のしくみ：音は**耳介 → 外耳道 → 鼓膜 → 耳小骨（中耳）→ 蝸牛（内耳）→ 脳**と伝わる。**蝸牛＝音を感じとる**、**三半規管・前庭＝体の傾き・回転（平衡）**。外耳・中耳の障害は**伝音性難聴**、内耳より奥の障害は**感音性難聴**（老人性難聴）

| **鼻毛は塵や埃を除去**。鼻腔は毛細血管が多く、加湿・加温する | 嗅細胞は外鼻孔（鼻の穴の入口）にある（実際は鼻腔の上部）／鼻腔は喉頭に直接つながる（実際は咽頭を経由） |
