**この記事のポイント**

1. 大脳は「**前頭葉＝運動**」「**頭頂葉＝皮膚感覚**」「**側頭葉＝聴覚**」「**後頭葉＝視覚**」。**扁桃体＝情動、海馬＝記憶、延髄＝呼吸**。
2. **交感神経＝戦う体（心拍↑・血管収縮・瞳孔散大・消化↓）**、**副交感神経＝休む体（消化↑）**。
3. **白内障＝水晶体の濁り**、中耳の耳小骨＝**ツチ骨・キヌタ骨・アブミ骨**。

## ① 脳と神経【こころとからだのしくみ】

### 大脳の機能局在

| 部位 | 主な働き |
|---|---|
| **前頭葉** | **運動野**、運動性言語野（**ブローカ野**）、思考・意欲 |
| **頭頂葉** | **体性感覚野（皮膚の痛み・温度・触覚）** |
| **側頭葉** | **聴覚野**、感覚性言語野（**ウェルニッケ野**）、記憶 |
| **後頭葉** | **視覚野** |

### そのほかの脳の部位

| 部位 | 働き |
|---|---|
| **扁桃体** | **恐怖・不安・喜びなどの情動** |
| **海馬** | **記憶**（新しいことを覚える）。視覚ではない |
| **小脳** | **体の平衡・運動の調整** |
| **延髄** | **呼吸中枢**、心臓の中枢、嚥下 |
| 視床下部 | 体温・食欲・自律神経の中枢 |
| 下垂体 | ホルモン分泌の司令塔 |

### 脳神経・神経細胞

| ○ | × |
|---|---|
| **三叉神経＝顔の感覚** | 顔面神経（表情筋・味覚）、嗅神経（におい）、舌下神経（舌の運動） |
| **セロトニンは神経伝達物質**。ドーパミン・アセチルコリンも | — |
| **グリア細胞（神経膠細胞）が神経細胞を支える** | 神経細胞がグリア細胞を支える／グリア細胞が情報伝達 |
| 脳の機能停止の徴候＝**瞳孔散大・対光反射の消失** | 呼吸不全・心停止・尿失禁 |

## ② 自律神経・内分泌・臓器【こころとからだのしくみ】

| 作用 | 交感神経（活動・緊張） | 副交感神経（休息・リラックス） |
|---|---|---|
| 心拍数 | **増加** | 減少 |
| 血管 | **収縮**→血圧上昇 | 拡張 |
| 瞳孔 | **散大** | 縮小 |
| 気道 | 拡張 | 収縮 |
| 消化 | 抑制 | **促進** |
| 血糖 | 上昇 | — |

### 臓器の働き

| 臓器 | ○ 働き | × |
|---|---|---|
| **膵臓** | **ランゲルハンス島**から**インスリン**（血糖を下げる） | 副腎がインスリン |
| **肝臓** | **グリコーゲンの貯蔵**、解毒、胆汁を作る | — |
| 腎臓 | 尿を作る・**尿の濃縮** | 膀胱が尿を濃縮 |
| 肺 | **ガス交換** | 心臓がガス交換 |

## ③ 感覚器・発音【こころとからだのしくみ】

### 眼

| 病気・変化 | ポイント |
|---|---|
| **白内障** | **水晶体が白く濁る**。まぶしい・かすむ |
| 緑内障 | **眼圧が上がり視野が狭くなる**。眼の痛み・頭痛も |
| 加齢黄斑変性症 | **見たい中心がゆがむ・暗くなる** |
| 糖尿病性網膜症 | 網膜の出血、失明の原因に |
| **流行性角結膜炎** | **結膜の充血**・目やに。**感染力が強い** |
| 老化 | **明暗に順応する時間が長くなる**、近くが見えにくい、ピント調節が遅い、水晶体は黄色く濁る、涙は減る |
