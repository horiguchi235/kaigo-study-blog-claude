**結論を3行で**

1. **ビタミンD＝干ししいたけ・魚**、**ビタミンK＝納豆**。調味料は「**さ・し・す・せ・そ**」（砂糖が先）。
2. 食中毒は「**つけない・増やさない・やっつける**」。**常温保存のカレー＝ウエルシュ菌**。作り置きは**浅い容器で急冷**。
3. **可処分所得＝実収入 − 非消費支出（税・社会保険料）**。エンゲル係数は**食料費**の割合。

## ① 調理と食品【生活支援技術】

| 項目 | ○ 正解 |
|---|---|
| **ビタミンD**が多い | **干ししいたけ**（第25回）、魚 |
| **ビタミンK**が多い（骨粗鬆症予防） | **納豆**（第28回）、緑黄色野菜 |
| 凝固 | **寒天は常温で固まる**（第27回）。ゼラチンは**沸騰させない**（50〜60℃で溶かし冷蔵で固める）。片栗粉は**水で溶いて**から加える |
| 調味料の順番 | **砂糖は塩より先**に入れる（分子が大きく浸透しにくいため）（第37回）。**さ（砂糖）し（塩）す（酢）せ（しょうゆ）そ（みそ）**。みそは香りが飛ぶので**最後** |
| 食品の保存 | **りんご**は**ビニール袋で密封**して冷蔵（エチレンガスで他の野菜が傷むのを防ぐ）（第37回）。**賞味期限**＝おいしく食べられる期限（切れてもすぐ捨てなくてよい）、**消費期限**＝安全に食べられる期限（傷みやすい弁当など） |
| 慢性腎不全 | **レモンや香辛料**で**減塩**（第34回）。たんぱく質を控える。エネルギーは油や砂糖で補う |

## ② 食品衛生・食中毒【生活支援技術】

| ○ | × |
|---|---|
| 生の肉を切った包丁・まな板は**すぐ洗って熱湯**（第30回） | 熱湯だけで洗い流す（たんぱく質が固まる）→ まず洗剤で洗う |
| 包丁は**刃と持ち手の境目**も洗浄・消毒（第31回） | 布巾は流水で洗うだけ／スポンジに泡を残す |
| 作り置きは**広く浅い容器ですばやく冷ます**（第33回） | 常温で保存 |
| 再加熱は**中心部75℃で1分以上**（ノロウイルスは85〜90℃で90秒以上） | 50℃・60℃で1分 |
| 生鮮食品は**買物の最後**に買う、冷蔵庫は**7割程度**まで | 最初に買う／すき間なく詰める |
| 解凍したら**使い切る** | 再冷凍 |

**菌と原因食品**

| 菌 | 特徴 |
|---|---|
| **ウエルシュ菌** | **カレー・シチューを常温で保存**し翌日加熱 → 熱に強い芽胞が生き残る（第32回） |
| 腸炎ビブリオ | 魚介類。**真水に弱い**（塩水で洗うは×） |
| カンピロバクター | 鶏肉の生・加熱不足 |
| サルモネラ菌 | 卵 |
| 黄色ブドウ球菌 | 手指の傷 → おにぎり。毒素は熱に強い |

<details>
<summary>✏️ 解いてみよう（第32回）</summary>

肉入りのカレーを常温で保存し、翌日加熱したときの食中毒で、最も注意すべき原因菌はどれ？

1. ウエルシュ菌
2. カンピロバクター
3. サルモネラ菌
4. 腸炎ビブリオ
5. 黄色ブドウ球菌

<details class="answer">
<summary>正解を見る</summary>

**正解：1**　ウエルシュ菌は加熱しても死なない「芽胞」をつくり、冷めていく途中で増えます。大鍋で作った煮込み料理は、小分けにして早く冷まします。
</details>

## ④ 家計【生活支援技術】

```
可処分所得 ＝ 実収入 − 非消費支出（税金・社会保険料）
```

- 実収入12万円・非消費支出2万円 → **可処分所得10万円**（第29回）。消費支出14万円との差は貯蓄の取り崩し
- 高齢単身無職世帯：主な収入は**公的年金**。**消費支出が可処分所得を上回る**（不足分は貯蓄から）（第27回）
- **エンゲル係数**＝消費支出に占める**食料費**の割合 → 相談されたら**食料費の内容を一緒に考える**（第30回）
