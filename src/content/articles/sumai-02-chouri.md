**この記事のポイント**

1. **ビタミンD＝干ししいたけ・魚**、**ビタミンK＝納豆**。調味料は「**さ・し・す・せ・そ**」（砂糖が先）。
2. 食中毒は「**つけない・増やさない・やっつける**」。**常温保存のカレー＝ウエルシュ菌**。作り置きは**浅い容器で急冷**。
3. **可処分所得＝実収入 − 非消費支出（税・社会保険料）**。エンゲル係数は**食料費**の割合。

## ① 調理と食品【生活支援技術】

| 項目 | ○ 正解 |
|---|---|
| **ビタミンD**が多い | **干ししいたけ**、魚 |
| **ビタミンK**が多い（骨粗鬆症予防） | **納豆**、緑黄色野菜 |
| 凝固 | **寒天は常温で固まる**。ゼラチンは**沸騰させない**（50〜60℃で溶かし冷蔵で固める）。片栗粉は**水で溶いて**から加える |
| 調味料の順番 | **砂糖は塩より先**に入れる（分子が大きく浸透しにくいため）。**さ（砂糖）し（塩）す（酢）せ（しょうゆ）そ（みそ）**。みそは香りが飛ぶので**最後** |
| 食品の保存 | **りんご**は**ビニール袋で密封**して冷蔵（エチレンガスで他の野菜が傷むのを防ぐ）。**賞味期限**＝おいしく食べられる期限（切れてもすぐ捨てなくてよい）、**消費期限**＝安全に食べられる期限（傷みやすい弁当など） |
| 慢性腎不全 | **レモンや香辛料**で**減塩**。たんぱく質を控える。エネルギーは油や砂糖で補う |

基本調味料の効果や使い方として、適切なものはどれ？

1. 砂糖は塩より先に入れると甘みがしみこみやすい
2. 塩はうま味を増し照りを出す
3. 酢は水分を引き出し保存性を高める
4. しょうゆはくさみを抜き肉をやわらかくする
5. みそは最初に入れると香りが逃げない

<details class="answer">
<summary>正解を見る</summary>

**正解：1**　**さしすせそ（砂糖→塩→酢→しょうゆ→みそ）**。砂糖は分子が大きくしみこみにくいので先に。香りの立つしょうゆ・みそは**最後**です。
</details>

食品の保存として、最も適切なものはどれ？

1. 賞味期限切れの未開封の缶詰はすぐ捨てる

4. りんごを冷蔵庫に入れるときはビニール袋に入れて密封する

## ② 食品衛生・食中毒【生活支援技術】

| ○ | × |
|---|---|
| 生の肉を切った包丁・まな板は**すぐ洗って熱湯** | 熱湯だけで洗い流す（たんぱく質が固まる）→ まず洗剤で洗う |
| 包丁は**刃と持ち手の境目**も洗浄・消毒 | 布巾は流水で洗うだけ／スポンジに泡を残す |
| 作り置きは**広く浅い容器ですばやく冷ます** | 常温で保存 |
| 再加熱は**中心部75℃で1分以上**（ノロウイルスは85〜90℃で90秒以上） | 50℃・60℃で1分 |
| 生鮮食品は**買物の最後**に買う、冷蔵庫は**7割程度**まで | 最初に買う／すき間なく詰める |
| 解凍したら**使い切る** | 再冷凍 |

**菌と原因食品**

| 菌 | 特徴 |
|---|---|
| **ウエルシュ菌** | **カレー・シチューを常温で保存**し翌日加熱 → 熱に強い芽胞が生き残る |
| 腸炎ビブリオ | 魚介類。**真水に弱い**（塩水で洗うは×） |
| カンピロバクター | 鶏肉の生・加熱不足 |
| サルモネラ菌 | 卵 |
| 黄色ブドウ球菌 | 手指の傷 → おにぎり。毒素は熱に強い |

## ④ 家計【生活支援技術】

```
可処分所得 ＝ 実収入 − 非消費支出（税金・社会保険料）
```

- 実収入12万円・非消費支出2万円 → **可処分所得10万円**。消費支出14万円との差は貯蓄の取り崩し
- 高齢単身無職世帯：主な収入は**公的年金**。**消費支出が可処分所得を上回る**（不足分は貯蓄から）
- **エンゲル係数**＝消費支出に占める**食料費**の割合 → 相談されたら**食料費の内容を一緒に考える**

## ＋α もう一歩：実務者研修レベルで覚えたいこと

過去問にはまだ出ていないけれど、実務者研修の確認テストでよく問われる、関連して覚えておきたい知識です。

- **右麻痺の人の調理訓練**：左手への**利き手交換**、食材を固定する**釘付きまな板**、ピーラーなど片手で使える道具。**リーチャー**は離れた軽い物をつかむ道具で、**鍋を持つのには使わない**。
- **ゼラチンと寒天**：ゼラチン＝**動物性のたんぱく質**、冷やすと固まり温めると溶ける、**沸騰させると固まる力が落ちる**／寒天＝**海藻**由来、常温でも固まる。
- **冷蔵庫は詰め込みすぎない（容量の70％程度）**、扉の開け閉めは短く。冷凍しても劣化は進むので長く放置しない。

## 📘 もう一歩先へ：過去問にはまだ出ていない重要ポイント

過去問ではまだ問われていないものの、テキストで重要語として扱われ、今後出題されてもおかしくない関連知識です。過去問の論点とセットで押さえておくと、初めて見る選択肢にも対応できます。

- **下ごしらえ**：じゃがいもの芽には毒（**ソラニン**）があるので取る、れんこんは酢水、ごぼうは水であく抜き、アサリ・ハマグリは約3％の塩水で砂抜き。
- **とろみ・固める材料**：でんぷん（片栗粉など）、**寒天**（海藻が原料・常温で固まる）、**ゼラチン**（動物の骨や皮が原料・冷やして固める・口の中で溶けやすい）。
- **かゆの水の量**：全がゆ＝米の約5倍、七分がゆ＝7倍、五分がゆ＝10倍、三分がゆ＝20倍。ふつうの炊飯は**米の重量の1.5倍・容量の1.2倍**。
- **賞味期限**＝おいしく食べられる期限（品質の劣化がゆるやかなもの）、**消費期限**＝安全に食べられる期限（劣化が早いもの）。一度解凍したものは再冷凍しない。
- **クーリング・オフ**：訪問販売・電話勧誘・エステや語学教室など＝**8日**、マルチ商法・内職商法（モニター商法）＝**20日**。**書面**（はがき・内容証明郵便）で行う。**通信販売は対象外**（返品は特約しだい）。
