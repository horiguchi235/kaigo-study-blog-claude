**この記事のポイント**

1. **ビタミンD＝干ししいたけ・魚**、**ビタミンK＝納豆**。調味料は「**さ・し・す・せ・そ**」（砂糖が先）。
2. 食中毒は「**つけない・増やさない・やっつける**」。**常温保存のカレー＝ウエルシュ菌**。作り置きは**浅い容器で急冷**。
3. **可処分所得＝実収入 − 非消費支出（税・社会保険料）**。エンゲル係数は**食料費**の割合。

## ① 調理と食品

| 項目 | ○ 正解 |
|---|---|
| **ビタミンD**が多い | **干ししいたけ**、魚 |
| **ビタミンK**が多い（骨粗鬆症予防） | **納豆**、緑黄色野菜。血液を固まりにくくする薬（**ワルファリン**）を飲んでいる人は、薬が効きにくくなるので**納豆を避ける** |
| とろみ | 片栗粉などのでんぷんは**水で溶いて**から加える |
| 調味料の順番 | **砂糖は塩より先**に入れる（分子が大きく浸透しにくいため）。**さ（砂糖）し（塩）す（酢）せ（しょうゆ）そ（みそ）**。みそは香りが飛ぶので**最後** |
| 食品の保存 | **りんご**は**ビニール袋で密封**して冷蔵（エチレンガスで他の野菜が傷むのを防ぐ）。一度解凍したものは**再冷凍しない**。常温で置いた肉入りカレーは**ウエルシュ菌**に注意（→②） |
| 期限表示 | **賞味期限**＝おいしく食べられる期限（劣化がゆるやかな缶詰・ウインナーなど。切れてもすぐ捨てなくてよい）、**消費期限**＝安全に食べられる期限（弁当など傷みやすい物） |
| 下ごしらえ | じゃがいもの芽は毒（**ソラニン**）があるので取る。れんこんは酢水、ごぼうは水であく抜き。アサリ・ハマグリは約3％の塩水で砂抜き |
| かゆの水の量 | 全がゆ＝米の約5倍、七分がゆ＝7倍、五分がゆ＝10倍、三分がゆ＝20倍（ふつうの炊飯は米の重量の1.5倍・容量の1.2倍） |

### 寒天とゼラチン

| | 寒天 | ゼラチン |
|---|---|---|
| 原料 | **海藻** | 動物の骨や皮（**たんぱく質**） |
| 固まる温度 | **常温で固まる** | **冷蔵**で固まる |
| 溶かし方 | 煮溶かす | **沸騰させない**（50〜60℃で溶かす。沸騰させると固まる力が落ちる） |
| 口の中 | 溶けない | 体温で**溶けやすい** |

## ② 食品衛生・食中毒

食中毒予防の3原則は「**つけない**（洗う・分ける）・**増やさない**（冷やす・早く食べる）・**やっつける**（加熱・消毒）」です。

| ○ | × |
|---|---|
| 【つけない】生の肉を切った包丁・まな板は**すぐ洗剤で洗ってから熱湯** | 熱湯だけで洗い流す（たんぱく質が固まってこびりつく） |
| 【つけない】包丁は**刃と持ち手の境目**も洗浄・消毒 | 布巾は流水で洗うだけ／スポンジに泡を残す |
| 【増やさない】作り置きは**広く浅い容器ですばやく冷ます** | 常温で保存 |
| 【増やさない】生鮮食品は**買物の最後**に買う、冷蔵庫は**7割程度**まで（冷気が回るように）、扉の開け閉めは短く | 最初に買う／すき間なく詰める |
| 【増やさない】解凍したら**使い切る** | 再冷凍 |
| 【やっつける】再加熱は**中心部75℃で1分以上**（ノロウイルスのおそれがあれば**85〜90℃で90秒以上**） | 50℃・60℃で1分 |

**菌・ウイルスと原因食品**

**芽胞**（がほう）＝一部の菌がつくる、熱や乾燥に強い殻のような形。加熱しても生き残り、冷めると増えます。

| 菌・ウイルス | 主な原因食品 | 予防・特徴 | 熱に強いか |
|---|---|---|---|
| **ウエルシュ菌** | **カレー・シチューを常温で保存**し翌日加熱 | 浅い容器で急冷し冷蔵 | **強い**（芽胞） |
| 腸炎ビブリオ | 魚介類 | **真水に弱い**（塩水で洗うは×） | 弱い |
| カンピロバクター | 鶏肉の生・加熱不足 | 中心まで加熱 | 弱い |
| サルモネラ菌 | 卵 | 加熱、卵は冷蔵 | 弱い |
| 腸管出血性大腸菌（**O157**） | 牛肉（ひき肉）の加熱不足 | 中心部75℃で1分以上 | 弱い |
| 黄色ブドウ球菌 | 手指の傷 → おにぎり | 傷のある手で調理しない | **毒素は強い** |
| ボツリヌス菌 | 真空パック・缶詰・**はちみつ** | **はちみつは1歳未満の乳児に与えない** | **強い**（芽胞） |
| **ノロウイルス** | **二枚貝**（カキなど）、感染者の手から | 85〜90℃で90秒以上 | — |

## ③ 障害や状態に合わせた調理・買物の支援

| 状態 | ○ 正解 | × |
|---|---|---|
| 揚げ物をガスコンロで作る人（防火） | **袖口を絞った衣類**を着る | 材料をコンロの周りに置く／鍋から離れる／強火／火災警報器を床近くに |
| **弱視** | よく使う調理器具は**いつも同じ場所**に収納。まな板は食材と**違う色** | ガイドヘルパーに任せる／包丁を手前に置く |
| **関節リウマチ** | テーブルは<strong>手のひらの付け根（手掌基部）</strong>で拭く。**お湯**で洗う、両手で持つ | 指先でふたを開ける／片手で持つ／早朝に掃除（朝はこわばりが強い） |
| 膝が悪いが**自分で食材を選んで作りたい** | **シルバーカー** | 買物代行・ネットスーパー（本人の希望に合わない）・電動車いす |
| **右麻痺**の人の調理 | 左手への**利き手交換**、食材を固定する**釘付きまな板**、片手で使えるピーラー | リーチャー（離れた**軽い物**をつかむ道具）で鍋を持つ |
| **慢性腎不全** | **レモンや香辛料**で**減塩**。たんぱく質を控え、エネルギーは油や砂糖で補う。カリウムを減らすため野菜は**ゆでこぼす** | 肉や魚を多め・生野菜のサラダ |

## ④ 家計

| 用語 | 意味 |
|---|---|
| **実収入** | 年金・給料など、世帯に入ってくる収入 |
| **非消費支出** | 自由に使えない支出＝**税金・社会保険料** |
| **可処分所得** | 実収入 − 非消費支出＝**自由に使えるお金** |
| **消費支出** | 生活費（食料・住居・光熱水道・医療など） |
| **エンゲル係数** | 消費支出に占める**食料費**の割合 |

**例**：年金などの実収入が月12万円、税・社会保険料（非消費支出）が2万円 → 可処分所得は**10万円**。生活費（消費支出）が14万円かかったら、足りない**4万円は貯蓄を取り崩す**ことになります。

- 高齢単身無職世帯：主な収入は**公的年金**。**消費支出が可処分所得を上回る**（不足分は貯蓄から）
- エンゲル係数が高いと相談されたら、**食料費の内容を一緒に考える**

## ⑤ クーリング・オフ

訪問販売などで契約した後、一定の期間内なら**理由を問わず無条件で契約を解除できる**しくみです。

| 取引 | 期間 |
|---|---|
| 訪問販売・電話勧誘販売・特定継続的役務提供（エステ・語学教室など）・**訪問購入**（業者が家に来て物を買い取る） | **8日** |
| 連鎖販売取引（マルチ商法）・業務提供誘引販売取引（内職・モニター商法） | **20日** |
| 通信販売（ネット・カタログ） | **対象外**（返品できるかは事業者の返品特約しだい） |

- 通知は**書面**（はがき・内容証明郵便など）のほか、2022年6月から**電子メールなどの電磁的記録**でもできる。証拠が残るよう、はがきはコピー、メールは画面を保存しておく
