どちらも「判断能力が不十分な人」を支えますが、**日常生活自立支援事業＝身近なお金の管理を手伝う（契約が理解できる人）**、**成年後見制度＝法律上の代理で財産と権利を守る**、と考えると区別できます。

**この記事のポイント**

1. 成年後見＝**民法**（家庭裁判所）、日常生活自立支援事業＝**社会福祉法**（社会福祉協議会）。
2. 日常生活自立支援事業は**本人が契約内容を理解できる**ことが条件。理解できなければ成年後見へ。
3. 成年後見人は**契約の代理・取消し**ができる。日常生活自立支援事業には**代理権・取消権はない**。
4. 法定後見は判断能力の程度で **後見（欠く）・保佐（著しく不十分）・補助（不十分）**。
5. **任意後見**は判断能力があるうちに**公正証書**で契約し、**任意後見監督人**が選ばれて始まる。

---

## ① 2つを比べる

| | 成年後見制度 | 日常生活自立支援事業 |
|---|---|---|
| 根拠 | **民法**（任意後見は任意後見契約に関する法律）／2000年〜 | **社会福祉法**（福祉サービス利用援助事業）／1999年に地域福祉権利擁護事業として開始、2007年に改称 |
| 対象 | 認知症・知的障害・精神障害などで**判断能力が不十分**な人 | 判断能力が不十分だが、**事業の契約内容は理解できる**人 |
| 申込み先 | **家庭裁判所**に申立て（本人・配偶者・**4親等内の親族**・**市町村長**など） | **市町村社会福祉協議会**に相談・**本人が契約** |
| 実施・担い手 | 家庭裁判所が選ぶ**成年後見人等**（親族・弁護士・司法書士・社会福祉士・法人・**市民後見人**） | 実施主体は**都道府県・指定都市社協**。**専門員**が計画をつくり、**生活支援員**が援助 |
| できること | **財産管理**（預貯金・不動産）と**身上保護**（介護・施設の契約など）。**代理権・取消権**（後見・保佐・補助で範囲が違う） | **福祉サービスの利用援助**、**日常的な金銭管理**（年金の受け取り・公共料金や家賃の支払い・預金の出し入れ）、**書類の預かり**（通帳・印鑑・証書） |
| できないこと | 介護そのもの（事実行為）、**医療行為の同意**、結婚・養子縁組など身分行為 | 不動産の売買などの大きな財産管理、契約の取消し |
| 費用 | 申立て費用＋後見人への**報酬**（家庭裁判所が決める） | 1回あたり数百〜千数百円程度の**利用料**（生活保護受給者は無料の地域が多い） |
| 監督 | **家庭裁判所**・後見監督人 | **運営適正化委員会**（都道府県社協）・契約締結審査会 |

## ② 法定後見の3類型

| | 後見 | 保佐 | 補助 |
|---|---|---|---|
| 判断能力 | **欠く**のが通常の状態 | **著しく不十分** | **不十分** |
| 支える人 | 成年後見人 | 保佐人 | 補助人 |
| 代理権 | 財産に関するすべての法律行為 | 申立てで決めた行為 | 申立てで決めた行為 |
| 同意権・取消権 | 日用品の購入など日常生活の行為を**除き**取消せる | 借金・不動産の売買など**重要な行為**（民法13条） | 申立てで決めた一部の行為 |
| 本人の同意 | 不要 | 代理権の付与には必要 | **申立てそのものに本人の同意が必要** |

**任意後見**：本人が判断能力のあるうちに、将来の後見人（任意後見受任者）と**公正証書で契約**。判断能力が落ちたら家庭裁判所が**任意後見監督人**を選び、そこから始まる。任意後見人には**取消権はない**。

---

## ③ どちらを使う？（事例の考え方）

1. **お金の出し入れや公共料金の払い忘れが心配**、でも**本人が契約を理解できる** → **日常生活自立支援事業**
2. **悪質商法で高額な契約をしてしまう**、契約を**取り消す**必要がある → **成年後見制度**（保佐・補助などで取消権）
3. **施設入所の契約や不動産の売却**が必要、本人の判断が難しい → **成年後見制度**
4. 身寄りがなく申立てる親族がいない → **市町村長申立て**（成年後見制度利用支援事業で費用の助成も）

| 日常生活自立支援事業の申込みは家庭裁判所 | **市町村社協**。家庭裁判所は成年後見 |

| 法人は成年後見人になれない | **なれる** |
| 任意後見は家庭裁判所が後見人を選ぶ | 後見人は**本人が契約で選ぶ**。家裁は監督人を選ぶ |
