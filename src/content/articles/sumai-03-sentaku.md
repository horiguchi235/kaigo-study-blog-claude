**この記事のポイント**

1. **塩素系漂白剤は白い綿・麻・ポリエステル**（除菌もできる）。**ウール・絹は液体の酸素系（粉末は×）、色柄物は酸素系**。
2. 洗濯表示：**桶の下の線1本＝弱い、2本＝非常に弱い**、数字は**上限温度**。四角の中の**横線＝平干し**、左上の**斜線＝日陰**。
3. ノロウイルスの嘔吐物は**マスク・手袋をつけ、取り除いてから次亜塩素酸ナトリウム**。アルコールは効きにくい。

## ① 洗濯・漂白・しみ抜き

### 漂白剤

| 種類 | 使える素材 | ポイント |
|---|---|---|
| **塩素系**（次亜塩素酸ナトリウム） | **白い綿・麻・ポリエステル・アクリル** | 漂白力が強く**除菌効果**がある。色柄物・ウール・絹・ナイロン・アセテートは×。手指の消毒には使わない、熱湯で薄めない |
| **酸素系**（液体） | **ウール・絹**（水洗いできるもの）、**色柄物** | **弱酸性**なので動物性の繊維も傷めにくい。綿の柄物シャツにも |
| 酸素系（粉末） | 白物・色柄物（ウール・絹は×） | **弱アルカリ性**なのでウール・絹を傷める |
| 還元系 | 白物 | 酸素系・塩素系で落ちない**黄ばみ・鉄さび**に |

<photo name="sumai-03__hyouhakuzai" caption="漂白剤の使い分け。上（青いキャップ）＝白い綿・麻・ポリエステル→塩素系、中（緑のキャップ）＝色柄物・ウール・絹→酸素系。下：塩素系＋酸性洗剤は有毒ガス。">

> 塩素系漂白剤と**酸性の洗剤**（トイレ用など）を混ぜると**有毒な塩素ガス**が出ます（「まぜるな危険」）。

### 洗い方の基本

| ○ | × |
|---|---|
| **ほころび・破れは修理してから**洗う | — |
| ファスナー・面ファスナーは**閉めて**洗う | 開けたまま／はずしたまま |
| 色移りを防ぐため**色の濃い物・薄い物を分ける** | 素材の違いで分ける |
| 血液など**たんぱく質の汚れは水**で（熱で固まる） | 高温で洗う |
| 絹・ウールは**中性洗剤**（綿・麻・合成繊維は石けん・弱アルカリ性洗剤） | 弱アルカリ性洗剤 |
| 洗剤は**表示どおりの適量**（汚れを落とすのは界面活性剤） | 多いほどよく落ちる |
| 淡い色の物には**蛍光増白剤なし** | 蛍光増白剤入り |
| ドライクリーニング（水ではなく**溶剤**で洗う）は**油溶性**の汚れ向き。水洗いで縮む・型くずれする衣類に | 汗など水溶性の汚れ向き |

### しみ抜き

しみ抜きは**洗濯の前に**。しみの下に布を当て、**外側から中心へ**たたきます（こすると広がる）。

| しみの種類 | 例 | 処理 |
|---|---|---|
| 水溶性 | しょうゆ・コーヒー・果汁 | **水**でたたく → 洗剤 |
| 油性 | **チョコレート・バター・口紅** | **ベンジン** → 洗剤 |
| 水と油が混ざったもの | ドレッシング・カレー | **台所用洗剤** |
| たんぱく質 | 血液 | **水**（お湯は固まるので×） |

## ② 洗濯表示

| 記号 | 意味 |
|---|---|
| 桶に**30**、下に**線1本** | 液温**30℃を上限**に、洗濯機で**弱い**洗濯 |
| 桶の下に線2本 | 非常に弱い洗濯 |
| 桶に手 | 手洗い |
| 四角の中に縦線 | つり干し |
| 四角の中に**横線** | **平干し** |
| 四角の**左上に斜線** | **日陰**で干す |
| 四角に横線＋左上に斜線 | **日陰で平干し** |
| 四角の中に丸 | タンブル乾燥（乾燥機）ができる。×印があれば不可 |
| 三角 | 漂白剤が使える（斜線入りの三角＝酸素系のみ、×印＝漂白不可） |
| アイロン型の中の点 | アイロンの温度（点が多いほど高温） |
| 丸の中にP・F | ドライクリーニング（Wはウエットクリーニング） |

> 洗濯表示は**2016年12月**から国際規格に合わせた今の記号になりました。旧表示：シャツ型に斜線 → **日陰のつり干し**。

## ③ 衣類の保管・裁縫・掃除

### 保管と防虫剤

- 防虫剤は**衣類の上**に置く（成分は空気より重く、上から下へ広がる）。**湿気を取ってから**しまう。ドライクリーニングのビニールは**外して**保管
- **絹製品はタンスの上段**に（湿気が少ない）
- 種類がわからない防虫剤を補充するなら**ピレスロイド系**（**ほかの防虫剤と併用しても**溶けたりしみたりしない）。しょうのう・ナフタリン・パラジクロルベンゼンは**混ぜて使えない**
- 汚れのひどい衣類も**本人に確認せず捨てない**

### 裁縫

ズボンの裾上げで表から縫い目が目立たない → **まつり縫い**。

### 掃除

| ○ | × |
|---|---|
| **畳は目に沿って**拭く・掃く | — |
| **喘息**の人の家：掃除機をかける**前に吸着率の高いモップ**でほこりを取る。掃除機は**ゆっくり**動かす | 掃除機をすばやく動かす |
| **高い所から低い所へ**、**奥から出入口へ** | 低い所から／出入口から奥へ |
| 窓ガラスは**濡れ雑巾 → 乾いた雑巾** | 最初に乾いた雑巾 |
| 布団のダニの死骸やフンは**掃除機で吸い取る**（アレルギーの原因） | 干す・たたくだけ（取れない） |
| 汚れに合わせて洗剤を選ぶ：**水あかは酸性**洗剤、**油汚れはアルカリ性**洗剤、こびりつきはクレンザー（研磨） | — |
| カビ取り剤は**換気**しながら | 窓を閉める |

## ④ ノロウイルスの嘔吐物処理

| ○ | × |
|---|---|
| <strong>マスク・手袋（・エプロン）</strong>を着用して処理 | — |
| 嘔吐物を**外側から内側へ**静かに拭き取ってから、**次亜塩素酸ナトリウム**で消毒 | アルコールを噴霧（ノロウイルスには効きにくい） |
| 次亜塩素酸ナトリウムの濃度は、**嘔吐物・便のついた所は0.1％**、ドアノブ・手すりなどは**0.02％**（家庭用の塩素系漂白剤を薄めて作る） | 濃度を気にせず使う |
| 拭き取ったペーパーは**ビニール袋に密閉**して捨てる | ごみ箱にそのまま捨てる |
| **乾燥させない**（ウイルスが舞い上がる） | 乾燥後に処理する |
| ノロウイルスで汚れたシーツ・衣類は汚物を落としてから、**85℃で1分以上の熱水洗濯**か、**次亜塩素酸ナトリウムにつけて**消毒 | 40℃の湯で洗濯・強くもみ洗い |
| 食品の加熱は**中心部85〜90℃で90秒以上** | 中心50℃で1分 |

> 手指や物の消毒に使う**ベンザルコニウム塩化物**など（第四級アンモニウム塩）も、ノロウイルスには効きにくい消毒薬です。

ノロウイルス（Norovirus）による感染症の予防のための介護福祉職の対応として、最も適切なものを1つ選びなさい。

1. 食品は、中心部温度50℃で1分間加熱する。
2. 嘔吐物（おうとぶつ）は、乾燥後に処理をする。
3. マスクと手袋を着用して、嘔吐物（おうとぶつ）を処理する。
4. 手すりの消毒は、エタノール消毒液を使用する。
5. 嘔吐物（おうとぶつ）のついたシーツは、洗濯機で水洗いする。

<p class="q-src">出典：第35回 介護福祉士国家試験（生活支援技術）</p>

<details class="answer">
<summary>正解を見る</summary>

**正解：3**　**手袋・マスク・エプロン**をつけて、**乾く前に**処理（乾くと舞い上がる）。消毒は**次亜塩素酸ナトリウム**、加熱は**85〜90℃で90秒以上**です。4のエタノールはノロウイルスに効きにくく、5の水洗いでは消毒にならない（85℃で1分以上の熱水洗濯か次亜塩素酸ナトリウム）ので×です。

## ひっかけパターン集（洗濯・掃除で「ほぼ×」）

| 選択肢の表現 | なぜ× |
|---|---|
| ウール・絹・色柄物に塩素系漂白剤 | 傷む・色が抜ける |
| 血液を高温で洗う | たんぱく質が固まる |
| 数字は「以上」の温度 | 上限温度 |
| 防虫剤を衣類の下に | 上に置く |
| 掃除は低い所から・出入口から奥へ | 高い所から・奥から |
| 嘔吐物にアルコール | 次亜塩素酸ナトリウム |
| 塩素系漂白剤と酸性洗剤を一緒に使う | 有毒な塩素ガスが出る |
