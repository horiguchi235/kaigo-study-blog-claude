**この記事のポイント**

1. **塩素系漂白剤は白い綿・麻・ポリエステル**（除菌もできる）。**ウール・絹・色柄物は酸素系**。
2. 洗濯表示：**桶の下の線1本＝弱い、2本＝非常に弱い**、数字は**上限温度**。四角の中の**横線＝平干し**、左上の**斜線＝日陰**。
3. ノロウイルスの嘔吐物は**マスク・手袋をつけ、取り除いてから次亜塩素酸ナトリウム**。アルコールは効きにくい。

## ① 洗濯・漂白・しみ抜き【生活支援技術】

### 漂白剤

| 種類 | 使える素材 | ポイント |
|---|---|---|
| **塩素系**（次亜塩素酸ナトリウム） | **白い綿・麻・ポリエステル・アクリル** | 漂白力が強く**除菌効果**がある。色柄物・ウール・絹・ナイロン・アセテートは×。手指の消毒には使わない、熱湯で薄めない |
| **酸素系**（液体） | **ウール・絹**（水洗いできるもの）、**色柄物** | 綿の柄物シャツにも |
| 酸素系（粉末） | 白物・色柄物（ウール・絹は×） | 弱アルカリ性 |

### 洗い方の基本

| ○ | × |
|---|---|
| **ほころび・破れは修理してから**洗う | — |
| ファスナー・面ファスナーは**閉めて**洗う | 開けたまま／はずしたまま |
| 色移りを防ぐため**色の濃い物・薄い物を分ける** | 素材の違いで分ける |
| 血液など**たんぱく質の汚れは水**で（熱で固まる） | 高温で洗う |
| 絹・ウールは**中性洗剤** | 弱アルカリ性洗剤 |
| 洗剤は**適量**（多くても落ちは変わらない） | 多いほどよく落ちる |
| 淡い色の物には**蛍光増白剤なし** | 蛍光増白剤入り |
| ドライクリーニングは**油溶性**の汚れ向き | 水溶性向き |

### しみ抜き

| しみ | 処理 |
|---|---|
| **チョコレート・バター・口紅**（油性） | **ベンジン**や**洗剤を浸み込ませ、布の上に置いて叩く** |
| しょうゆ・コーヒー・果汁（水溶性） | 水で叩く → 洗剤 |
| 血液 | **水**（お湯は×） |

## ② 洗濯表示【生活支援技術】

| 記号 | 意味 |
|---|---|
| 桶に**30**、下に**線1本** | 液温**30℃を上限**に、洗濯機で**弱い**洗濯 |
| 桶の下に線2本 | 非常に弱い洗濯 |
| 桶に手 | 手洗い |
| 四角の中に縦線 | つり干し |
| 四角の中に**横線** | **平干し** |
| 四角の**左上に斜線** | **日陰**で干す |
| 四角に横線＋左上に斜線 | **日陰で平干し** |

> 旧表示：シャツ型に斜線 → **日陰のつり干し**。

## ③ 衣類の保管・裁縫・掃除【生活支援技術】

### 保管と防虫剤

- 防虫剤は**衣類の上**に置く（成分は空気より重く、上から下へ広がる）。**湿気を取ってから**しまう。ドライクリーニングのビニールは**外して**保管
- **絹製品はタンスの上段**に（湿気が少ない）
- 種類がわからない防虫剤を補充するなら**ピレスロイド系**（**ほかの防虫剤と併用しても**溶けたりしみたりしない）。しょうのう・ナフタリン・パラジクロルベンゼンは**混ぜて使えない**
- 汚れのひどい衣類も**本人に確認せず捨てない**

### 裁縫

ズボンの裾上げで表から縫い目が目立たない → **まつり縫い**。

### 掃除

| ○ | × |
|---|---|
| **畳は目に沿って**拭く・掃く | — |
| **喘息**の人の家：掃除機をかける**前に吸着率の高いモップ**でほこりを取る。掃除機は**ゆっくり**動かす | 掃除機をすばやく動かす |
| **高い所から低い所へ**、**奥から出入口へ** | 低い所から／出入口から奥へ |
| 窓ガラスは**濡れ雑巾 → 乾いた雑巾** | 最初に乾いた雑巾 |
| カビ取り剤は**換気**しながら | 窓を閉める |

## ④ ノロウイルスの嘔吐物処理【生活支援技術】

| ○ | × |
|---|---|
| **マスク・手袋（・エプロン）**を着用して処理 | — |
| 嘔吐物を**取り除いてから**、**次亜塩素酸ナトリウム溶液**につける | アルコールを噴霧（効きにくい） |
| 拭き取ったペーパーは**ビニール袋に密閉**して捨てる | ごみ箱にそのまま捨てる |
| **乾燥させない**（ウイルスが舞い上がる） | 乾燥後に処理する |
| 加熱は**85〜90℃で90秒以上** | 中心50℃で1分・40℃の湯で洗濯・強くもみ洗い |

## ＋α もう一歩：実務者研修レベルで覚えたいこと

過去問にはまだ出ていないけれど、実務者研修の確認テストでよく問われる、関連して覚えておきたい知識です。

- **ドライクリーニング**＝水ではなく**溶剤**で洗う方法。水洗いで型くずれ・縮みやすい衣類に向く。
- **洗剤は多ければよく落ちる、ではない**（適量を守る）。洗剤の**界面活性剤**が汚れを落とす。毛・絹は**中性洗剤**。
- **掃除の洗剤**：クレンザー＝研磨で落とす／**酸性洗剤＝水あか**などに／**アルカリ性洗剤＝油汚れ**に。**塩素系漂白剤と酸性洗剤を混ぜると有毒な塩素ガス**が出る（「まぜるな危険」）。
- 消毒薬：**第四級アンモニウム塩**＝ベンザルコニウム塩化物・ベンゼトニウム塩化物（「第五級」はない）。
