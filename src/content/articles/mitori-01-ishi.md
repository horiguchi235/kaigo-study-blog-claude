**この記事のポイント**

1. **リビングウィル＝終末期の希望を書面に**、**尊厳死＝延命せず自然な最期**、**ACP＝家族や医療・介護職とくり返し話し合う**。
2. 意思確認は「**方針を伝えて確認 → 書面に残す → 気持ちは変わるので何度でも**」。決めるのは**本人**。
3. 死の直前は「**尿が減る・手足が冷たい・喉がゴロゴロ・下顎呼吸**」。**死斑・死後硬直・角膜の混濁は死後**。

## ① 終末期の用語・意思確認・ACP

### 用語

| 用語 | 意味 |
|---|---|
| **尊厳死** | **延命目的の治療をせず**、自然な最期を迎える |
| 積極的安楽死 | 薬物などで**意図的に死期を早める**（日本では認められていない） |
| 脳死 | 脳幹を含む脳全体の機能が止まった状態（**自発呼吸はない**） |
| 植物状態 | 意識はないが、脳幹は働いていて**自発呼吸がある** |
| 緩和ケア | 病気の早い時期から、体と心の**苦痛をやわらげる**ケア（終末期だけのものではない） |
| DNAR | 心臓や呼吸が止まったときに**心肺蘇生をしない**という、本人の意思にもとづく指示 |
| グリーフケア | 死別による**悲嘆への支援** |
| インフォームドコンセント | 十分な説明を受けたうえでの同意 |
| ターミナルケア | 終末期のケア |

### リビングウィル・事前指示・ACPの違い

| | 何をするか | 形 |
|---|---|---|
| **事前指示**（アドバンス・ディレクティブ） | 判断できなくなったときに備え、受けたい・受けたくない医療や、代わりに決める人を**前もって示しておく** | 口頭・書面（書面にしたものが**事前指示書**） |
| **リビングウィル** | 事前指示のうち、終末期に**延命治療などを望むかどうかを書いた文書** | **書面** |
| **ACP**（アドバンス・ケア・プランニング＝**人生会議**） | 本人・家族・医療介護職が、医療だけでなく**これからの生活**について**くり返し話し合う** | **話し合いのプロセス**（内容は記録に残す） |

書面に残したもの（リビングウィル・事前指示書）は、ACPの話し合いの中で何度でも見直します。

### 施設での意思確認

| ○ | × |
|---|---|
| **終末期の介護方針を伝えて**意思確認する | 90歳を超えれば確認不要 |
| 確認した内容は**書面に**する | 介護職間で口頭で共有 |
| 気持ちが変わったら**今の意思**を尊重 | 入所時の意思を優先して変えない |
| 本人の意思と**家族の意向も**確認する | 本人が言えれば家族は確認しない／家族の意向を優先 |
| 医療処置の範囲の説明は**主に医師**（看護職が補足する） | 介護職が説明する／意思確認できなければ医師に任せる |

### アドバンス・ケア・プランニング（ACP）

厚生労働省の「人生の最終段階における医療・ケアの決定プロセスに関するガイドライン」（2018年改訂）で重視。**年齢に関係なく**、元気なうちから始めます。

○「**今後の生活について、家族や医療・介護職員と一緒に、その都度話し合っていきましょう**」

× 家族が代わりに決める／食べられなくなったら介護職員に相談／意思が伝えられなくなったら成年後見

**ガイドラインの決め方の順番**

1. 本人の意思が確認できる → **本人**と医療・ケアチームが話し合い、本人の意思決定を基本に決める
2. 確認できない → **家族等が本人の意思を推定**できれば、その推定意思を尊重する
3. 推定もできない → 本人にとって**何が最善か**を家族等とチームで話し合う（家族等がいなければチームで判断）

> 誤嚥性肺炎をくり返し終末期が近い人 → 最優先で確認するのは「**経口摂取に対する本人の意向**」。

## ② キューブラー・ロスの死の受容過程

| 段階 | 例 |
|---|---|
| 第1段階 **否認** | 「**診断は何かの間違いだ**」 |
| 第2段階 **怒り** | 「なぜ私だけが」 |
| 第3段階 取り引き | 「財産を全部使ってもいいから治したい」 |
| 第4段階 **抑うつ** | **死は避けられないと知り、さまざまな喪失感を抱く** |
| 第5段階 受容 | 「死は自然なことだから受け入れよう」 |

- 覚え方：頭の字をとって「**否・怒・取・抑・受**」
- **全員が順番どおりに進むわけではない**。段階を行き来したり、とばしたりすることもあります
- 第4段階は「**抑うつ**」（「そううつ」ではない）。悲観・卑屈・悟り・平安は段階の名前ではありません

## ③ 死が近づいたときと死後のからだの変化

| ○ 死の直前に見られる | × 死後に見られる |
|---|---|
| **尿量の減少** | **死斑**（死後**20〜30分ごろ**から） |
| 手足が**冷たく**なる、**チアノーゼ**（唇や爪が紫色になる） | **死後硬直**（死後**2〜3時間ごろ**から） |
| **浮腫**が出やすい | **角膜の混濁** |
| 喉の**ゴロゴロ**（**死前喘鳴**：のどにたまった分泌物の音） | 関節・筋肉の硬直 |
| **下顎呼吸**、呼吸のリズムが**不規則**（チェーンストークス呼吸） | — |
| 意識の低下・傾眠 | — |

**死が近いときの呼吸**

- **チェーンストークス呼吸**：無呼吸（数十秒）→ 浅い呼吸 → 深く大きな呼吸 → 浅い呼吸 → 無呼吸…をくり返す
- **下顎呼吸**：あごを動かしてする呼吸。死が非常に近いサイン
- 鼻翼呼吸・肩呼吸：苦しいときの努力呼吸
- 体温が急に上がるのは典型的な変化ではない

**死亡の判断は医師**が行います。目安は**死の三徴候**＝心臓の停止・呼吸の停止・**瞳孔が開き光に反応しない**。介護職は変化を記録して医療職に報告します。

### 観察と連絡

- **モルヒネ**を使っている人 → **呼吸**を観察（呼吸抑制の副作用。ほかに便秘・吐き気・眠気）
- 死が極めて近い人の看取りに必要な情報 → **呼吸の状態**
- 自宅で看取ると合意した人が**急変** → まず**かかりつけ医**に相談。警察・消防は×
- 最期を迎えたい場所の希望は**自宅が最も多い**（自宅43.8％、医療機関41.6％。2022年度 人生の最終段階における医療・ケアに関する意識調査、治る見込みがなく1年以内に死に至ると考えた場合）。実際に亡くなる場所は病院が多い

## ひっかけパターン集（終末期の基礎で「ほぼ×」）

| 選択肢の表現 | なぜ× |
|---|---|
| 尊厳死＝薬で死期を早める | それは積極的安楽死 |
| 脳死＝自発呼吸は保たれている | 自発呼吸はない（それは植物状態） |
| 意思確認は入所時に1回だけ | 気持ちは変わる。くり返し確認 |
| ACP＝家族が代わりに決める | 本人を中心に一緒に話し合う |
| 死の直前に尿量が増える・手足が温かい | 減る・冷たくなる |
| 死斑は死後8〜12時間から | 20〜30分ごろから |
| 死の受容は必ず5段階の順に進む | 行き来したり、とばしたりする |
| 本人の意思が確認できないときは介護職が決める | 家族等が推定 → 最善をチームと家族で話し合う |
