**この記事のポイント**

1. **リビングウィル＝終末期の希望を書面に**、**尊厳死＝延命せず自然な最期**、**ACP＝家族や医療・介護職とくり返し話し合う**。
2. 意思確認は「**方針を伝えて確認 → 書面に残す → 気持ちは変わるので何度でも**」。決めるのは**本人**。
3. 死の直前は「**尿が減る・手足が冷たい・喉がゴロゴロ・下顎呼吸**」。**死斑・死後硬直・角膜の混濁は死後**。

## ① 終末期の用語・意思確認・ACP【こころとからだのしくみ／生活支援技術】

### 用語

| 用語 | 意味 |
|---|---|
| **リビングウィル** | 終末期に**自分が望むケアをあらかじめ書面**に示しておくこと |
| **事前指示書** | 意思疎通が難しくなったときのために、**希望する医療ケアを記した書類** |
| **尊厳死** | **延命目的の治療をせず**、自然な最期を迎える |
| 積極的安楽死 | 薬物などで**意図的に死期を早める** |
| 脳死 | 脳幹を含む脳全体の機能が止まった状態（**自発呼吸はない**） |
| グリーフケア | 死別による**悲嘆への支援** |
| インフォームドコンセント | 十分な説明を受けたうえでの同意 |
| ターミナルケア | 終末期のケア |

### 施設での意思確認

| ○ | × |
|---|---|
| **終末期の介護方針を伝えて**意思確認する | 90歳を超えれば確認不要 |
| 確認した内容は**書面に**する | 介護職間で口頭で共有 |
| 気持ちが変わったら**今の意思**を尊重 | 入所時の意思を優先して変えない |
| 本人の意思と**家族の意向も**確認する | 本人が言えれば家族は確認しない／家族の意向を優先 |
| 医療処置の範囲の説明は**医師** | 介護職が説明する／意思確認できなければ医師に任せる |

### アドバンス・ケア・プランニング（ACP）

「人生の最終段階における医療・ケアの決定プロセスに関するガイドライン」（2018年改訂）で重視。

○「**今後の生活について、家族や医療・介護職員と一緒に、その都度話し合っていきましょう**」

× 家族が代わりに決める／食べられなくなったら介護職員に相談／意思が伝えられなくなったら成年後見

> 誤嚥性肺炎をくり返し終末期が近い人 → 最優先で確認するのは「**経口摂取に対する本人の意向**」。

## ② キューブラー・ロスの死の受容過程【こころとからだのしくみ】

| 段階 | 例 |
|---|---|
| 第1段階 **否認** | 「**診断は何かの間違いだ**」 |
| 第2段階 **怒り** | 「なぜ私だけが」 |
| 第3段階 取り引き | 「財産を全部使ってもいいから治したい」 |
| 第4段階 **抑うつ** | **死は避けられないと知り、さまざまな喪失感を抱く** |
| 第5段階 受容 | 「死は自然なことだから受け入れよう」 |

> 悲観・卑屈・悟り・平安は段階の名前ではありません。

## ③ 死が近づいたときと死後のからだの変化【こころとからだのしくみ】

| ○ 死の直前に見られる | × 死後に見られる |
|---|---|
| **尿量の減少** | **死斑**（死後**20〜30分**から） |
| 手足が**冷たく**なる、**チアノーゼ** | **死後硬直**（死後**2〜3時間**から） |
| **浮腫**が出やすい | **角膜の混濁** |
| 喉の**ゴロゴロ**（**死前喘鳴**） | 関節・筋肉の硬直 |
| **下顎呼吸**、呼吸のリズムが**不規則**（チェーンストークス呼吸） | — |
| 意識の低下・傾眠 | — |

### 観察と連絡

- **モルヒネ**を使っている人 → **呼吸**を観察（呼吸抑制の副作用）
- 死が極めて近い人の看取りに必要な情報 → **呼吸の状態**
- 自宅で看取ると合意した人が**急変** → まず**かかりつけ医**に相談。警察・消防は×
