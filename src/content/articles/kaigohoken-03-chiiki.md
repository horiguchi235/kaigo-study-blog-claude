**この記事のポイント**

1. **自助＝自分で、互助＝住民の支え合い、共助＝社会保険、公助＝税（生活保護など）**。
2. 地域ケア会議は**個別ケースの検討から地域課題を見つける**場。開くのは**地域包括支援センター**や市町村。
3. サ高住は**高齢者住まい法**の住宅で、**安否確認と生活相談**が必須。介護は**必要に応じて外部の介護保険サービス**を使う。

## ① 地域包括ケアと地域包括支援センター

### 地域包括ケアシステムとは

- 高齢者が要介護になっても住み慣れた地域で暮らし続けられるよう、**住まい・医療・介護・予防・生活支援**を一体的に届けるしくみ
- 範囲は**日常生活圏域**＝おおむね**30分以内**に必要なサービスが届く範囲（目安は**中学校区**）
- 団塊の世代がすべて75歳以上になる**2025年**をめどに構築が進められ、いまは**2040年**に向けて深めていく段階

### 自助・互助・共助・公助

| | 中身 | 試験の例 |
|---|---|---|
| **自助** | 自分のことを**自分でする**、市場サービスの購入 | 時間がかかっても**身の回りのことを自分でやる** |
| **互助** | **住民どうしの支え合い**・ボランティア（費用負担が制度化されていない） | 散歩仲間が声をかけあう |
| **共助** | **社会保険**（介護保険・医療保険）のように**保険料で支え合う制度** | 介護保険サービスの利用 |
| **公助** | **税**による公的支援。**自助・互助・共助で対応できない**生活困窮などに対応 | 生活保護・虐待対応・市の福祉サービス |

> 「互助＝社会保険」「共助＝近隣住民の支え合い」は入れ替えのひっかけ。

### 地域ケア会議

| ○ | × |
|---|---|
| **個別ケースの課題分析**を通して**地域課題を把握** | ケアプランの作成／介護認定の審査判定／介護保険事業計画の策定 |
| **地域課題の発見・地域づくり・資源開発**の機能 | 社協に設置義務／第三者評価 |
| 市町村や**地域包括支援センター**が開く。2015年から介護保険法で市町村の**努力義務** | 利用者・家族の参加が義務 |
| 「閉じこもりがちな人が増えて、民生委員だけでは見守れない」→ **地域ケア会議で関係者と地域課題を話し合う** | 本人が来るのを待つ／民生委員の関わりを制限する |

**地域ケア会議の5つの機能**：①個別課題の解決 → ②**ネットワーク構築** → ③地域課題の発見 → ④地域づくり・資源開発 → ⑤政策形成。個人への支援と、それを支える地域の基盤づくりを**同時に進める**。

### 地域包括支援センター

- 設置：**市町村**（社会福祉法人などへの委託も可）。おおむね中学校区（日常生活圏域）ごと
- 職員：**保健師**（経験のある看護師でも可）・**社会福祉士**・**主任介護支援専門員**の3職種。第1号被保険者3,000〜6,000人ごとに各1人が原則。2024年4月から、市町村の判断で**複数のセンターの職員を合わせて3職種をそろえる**こともできる
- 業務：**総合相談支援**、**権利擁護**（成年後見の活用・虐待対応・消費者被害の防止）、**包括的・継続的ケアマネジメント支援**、**介護予防ケアマネジメント**、**地域ケア会議の開催**
- 2024年4月から：**居宅介護支援事業所も介護予防支援（要支援者のケアプラン）の指定**を受けられる。総合相談支援の一部を居宅介護支援事業所などに**委託**できる
- 中立性を保つため、市町村ごとに**運営協議会**がある
- ×：施設サービスのケアプラン作成、成年後見の申請（申立ては本人・親族・市町村長）、介護認定審査会の設置、地域密着型事業者の指導監督

### 地域支援事業の3本柱（市町村が行う）

| 事業 | 中身 |
|---|---|
| **介護予防・日常生活支援総合事業** | 要支援者などの訪問型・通所型サービス、一般介護予防（2017年4月から全市町村） |
| **包括的支援事業** | 総合相談・権利擁護・ケアマネジメント支援・在宅医療介護連携・認知症総合支援・生活支援体制整備など |
| 任意事業 | 家族介護支援など、市町村が地域の実情に応じて行う |

### 地域のネットワークづくり

認知症の人の徘徊で苦情が出ている地域の会議では、**事例を共有**し、**ボランティア養成**・**町内会への理解の広がり**・**地域包括支援センターとの協力**を提案する。**スーパーマーケットを除く**のは×（地域の店も大切な見守りの担い手）。

## ② 高齢者の住まい

| 住まい | 根拠法・入り方 | 特徴 |
|---|---|---|
| **サービス付き高齢者向け住宅（サ高住）** | **高齢者住まい法**。**契約** | **状況把握（安否確認）と生活相談**が必須。原則**25㎡以上**。食事・介護の提供は義務ではなく、介護は**外部の介護保険サービスを必要に応じて利用**。夫婦でも入居可 |
| **有料老人ホーム** | **老人福祉法**。契約 | **介護・食事・家事・健康管理のいずれか1つ以上**を提供。**自立の人**も入居可。**介護付**＝ホームの職員が介護（特定施設入居者生活介護の指定を受けたもの）／**住宅型**＝外部の介護サービスを使う |
| 軽費老人ホーム | 老人福祉法。契約 | 低額で入居。**A型＝食事付き**、**ケアハウス**＝食事付きで介護は外部サービス（特定施設の指定を受ければ内部）。都市型は定員20人以下 |
| **養護老人ホーム** | 老人福祉法。**市町村の措置** | 環境上・経済的理由で在宅生活が難しい人。介護は外部サービスか特定施設 |
| グループホーム | 介護保険（地域密着型）。契約 | **認知症**の人の共同生活。介護は事業所の職員 |

> 要支援1で自炊を楽しむ人が、膝が悪く公営住宅の階段がつらくなった → **サービス付き高齢者向け住宅**。介護付有料老人ホームや養護老人ホームは状況に合いません。

## ひっかけパターン集（地域・住まいで「ほぼ×」）

| 選択肢の表現 | なぜ× |
|---|---|
| 互助＝社会保険・共助＝近所の支え合い | 逆 |
| 地域ケア会議でケアプランを作る・認定する | 地域課題の発見の場 |
| 地域包括支援センターが施設のケアプランを作る | 施設のケアマネが作る |
| 地域包括支援センターは介護福祉士の配置が必須 | 保健師・社会福祉士・主任ケアマネの3職種 |
| サ高住は食事・介護の提供が義務 | 義務は安否確認と生活相談 |
| サ高住は単身者のみ・措置で入居 | 夫婦も可、契約 |
| 有料老人ホームは自立の人は入れない | 入居できる |
