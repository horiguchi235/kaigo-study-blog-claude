**この記事のポイント**

1. **アドボカシー＝言い出しにくい本人の思いをくみ取り、代弁して実現に向けて働きかける**こと。
2. 成年後見は**家庭裁判所**が後見人を選ぶ。**法定後見＝判断能力が落ちてから**、**任意後見＝元気なうちに本人が選んで契約**。
3. **日常生活自立支援事業＝社会福祉協議会**が、**本人と契約**して**福祉サービスの利用援助**と**公共料金の支払いなどの日常的な金銭管理**を手伝う。不動産などの財産管理や施設の契約は成年後見。

| ○ アドボカシーの視点 | × |

| **希望を言い出しにくい利用者の意思をくみ取り、実現に向けて働きかける** | 説明して同意を得る（インフォームドコンセント）・他職種に助言を求める（連携） |

## ② 成年後見制度と日常生活自立支援事業

### 成年後見制度

| | **法定後見** | **任意後見** |
|---|---|---|
| 使うとき | 判断能力が**すでに不十分** | 判断能力が**あるうちに**将来に備える |
| 後見人を決める人 | **家庭裁判所**が選任 | **本人が選んで**、**公正証書**で契約（任意後見契約に関する法律） |
| 始まるとき | 家庭裁判所の審判で | 判断能力が落ちたら、家庭裁判所が**任意後見監督人**を選んでスタート |
| 類型 | **後見・保佐・補助の3類型** | — |

#### 法定後見の3類型

判断能力が低いほど、支える人の権限が大きくなります。

| | 補助 | 保佐 | 後見 |
|---|---|---|---|
| 判断能力 | **不十分** | **著しく不十分** | **欠けている**のが通常（ほとんどない） |
| 支える人 | 補助人 | 保佐人 | 成年後見人 |
| 支える人の権限 | 申立てで決めた一部の行為の同意権・取消権・代理権 | 借金・不動産の売買など**重要な行為**の同意権・取消権（代理権は申立てで決めた行為） | 財産に関する行為の**代理権**と**取消権**（日用品の購入などは本人ができる） |
| 申立てに本人の同意 | **必要** | 不要 | 不要 |

同意権＝本人がする契約に同意する権限、取消権＝本人が同意なくした契約を取り消せる権限、代理権＝本人に代わって契約する権限です。

**ことばの確認**：審判＝家庭裁判所が申立てを調べて決めること。支えられる本人は、類型ごとに**成年被後見人・被保佐人・被補助人**と呼びます。後見人などの仕事をチェックする人を**監督人**といいます。

**どの類型になる？（イメージ）**

| 類型 | こんな人 |
|---|---|
| 補助 | ふだんの買い物はできるが、高い契約やリフォームを決めるのは不安 |
| 保佐 | 日常の買い物はなんとかできるが、借金や家の売り買いなど大事なことは一人で決められない |
| 後見 | 日用品の買い物も難しく、お金の管理をほとんどまかせる必要がある |

#### 法定後見のポイント

| ○ | × |
|---|---|
| 申立て先は**家庭裁判所** | 都道府県・福祉事務所・市町村 |
| 申立てできるのは本人・配偶者・**4親等内の親族**（いとこまで。おい・めいは3親等）・検察官・**市町村長**など | 本人と配偶者だけ／本人か4親等内の親族だけ／市町村長は請求できない |
| **法人**も後見人になれる（任意後見人も同じ）。地域住民が担う**市民後見人**の養成も進んでいる | 法人は選任できない |
| **判断能力が十分な人には後見人をつけられない**。高齢者に限らず、知的障害・精神障害などのある**若い成人も使える**（未成年は通常、親権者が代わりを務める） | 65歳未満は使えない |
| 後見人の仕事は**財産管理**と**身上保護**（介護サービスや施設入所の契約などの手配。自分で介護するのではない） | 介護を行う／本人の葬儀を行う義務 |
| 後見人は本人の心身の状態や生活に配慮する（**身上配慮義務**） | — |
| 本人の住む家（居住用不動産）を売るには**家庭裁判所の許可**が必要 | 後見人の判断だけで売れる |
| 手術などの**医療同意はできない** | 後見人が医療行為に同意する |

親等の数え方は [高齢者の年齢の決まり・人口・世帯と家族](../jinkou-01-setai/) の「民法の親族」で扱います。制度の利用を進めるため、2016年に**成年後見制度利用促進法**ができました。

#### 統計（2024年 成年後見関係事件の概況）

- 申立てが最も多い類型は**後見**
- 申立人は**市区町村長**が最多（約24%）、次いで本人、本人の子
- 申立ての動機は**預貯金等の管理・解約**が最多
- 後見人等は**親族以外が約8割**。職種では**司法書士**→弁護士→社会福祉士の順

成年後見制度は見直しが進んでいます（くわしくは [成年後見制度と日常生活自立支援事業の違い](../hikaku-05-kouken-nichijou/)）。施行まではこの記事の3類型の制度が使われ、第39回試験も今の制度で考えます。

### 日常生活自立支援事業

| ○ | × |
|---|---|
| 実施主体は**都道府県・指定都市の社会福祉協議会**、窓口は**市区町村社協** | 家庭裁判所・国民生活センター |
| **専門員**（初期相談・支援計画・契約）と**生活支援員**（実際の支援） | — |
| **福祉サービスの利用援助**、**公共料金の支払い**・預金の払い戻しなどの日常的な金銭管理、書類の預かり | 公共料金は対象外 |
| 福祉サービスの**苦情解決制度の利用**の手伝い、住民票の届出などの**行政の手続き**の手伝いも行う | — |
| 対象は認知症高齢者・知的障害者・精神障害者など | 認知症高齢者に限る |
| 本人が**契約内容を理解できる**ことが必要（専門員が「契約締結判定ガイドライン」で確認し、判断に迷うときは**契約締結審査会**で審査）。理解できなければ成年後見制度を検討 | 判断能力は審査しない |
| 成年後見人などが本人に代わって契約することもできる（**成年後見と同時に使える**） | 成年後見を使っている人は利用できない |
| **運営適正化委員会**（都道府県社協に置かれる）が事業をチェックし、福祉サービスの**苦情**も扱う | — |
| 契約前の相談は**無料**。利用料は実施主体が決める（訪問1回あたり平均約1,200円。生活保護世帯は無料） | — |

### どちらを使う？

| 状況 | ○ |
|---|---|
| 一人暮らしでアパートを所有、認知症が進み**家賃の管理ができない** | **成年後見制度**の活用を**ケアマネジャーに提案** |
| 公共料金の支払いがうまくできない一人暮らし | 日常生活自立支援事業（社会福祉協議会へ） |

2つの制度の細かい比較は [成年後見制度と日常生活自立支援事業の違い](../hikaku-05-kouken-nichijou/) にまとめています。
