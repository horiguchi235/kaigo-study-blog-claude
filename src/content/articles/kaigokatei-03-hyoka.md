**この記事のポイント**

1. 実施では、**利用者の反応や変化を観察**し、**客観的に記録**する。支援内容は**説明して同意**を得る。
2. 評価の基準は**短期目標**。「**目標の達成度**」を見て、うまくいかなければ**再アセスメント**へ戻る。
3. チームの中心は**利用者**。介護福祉職の役割は、**生活の変化や本人・家族の思いをチームに伝える**こと。

## ① 介護計画の実施

| ○ | × |
|---|---|
| **利用者の反応や変化を観察**する | 計画をこなすこと自体を目的にする |
| 実施した状況を**その都度、客観的に記録**する | 評価日にまとめて記録する |
| 支援内容を**説明して同意**を得る | 変更内容の説明を省略する |
| 他職種へは**随時**報告する | 目標の達成後にまとめて報告する |
| チームで計画を統一して実施する | 実施内容を個々の介護福祉職に任せる |
| 継続するかどうかは目標と利用者の反応で判断する | 介護福祉職が満足するまで続ける |

- **実施の3つの視点**：**自立支援**（できることは本人が行う）・**安全と安心**・**快適さ**。
- 記録の目的は、ケアの継続・評価・チームでの連携・職員の学びなど。研究機関に個人情報を渡すことは目的ではない（研究に使うなら同意や匿名化が必要）。

**よく出る不正解**：介護福祉職の価値観・満足度で判断する／介護福祉職の経験を積むことが目的

## ② 評価・モニタリング・再アセスメント

| 用語 | 意味 |
|---|---|
| **モニタリング** | 計画どおりに実施できているか、効果が出ているかを**点検**する |
| **評価** | **目標の達成状況**を確かめる |
| **再アセスメント** | 状況が変わったときや目標が達成できないときに、もう一度情報を集めて課題を見直す |

> **モニタリングは2つの場面で出てきます**。どちらも「実施状況と効果の確認」ですが、主体が違います。介護過程のモニタリングは、**介護福祉職**が自分たちの介護計画について行うもの。ケアマネジメントのモニタリングは、**介護支援専門員**がケアプラン全体について行い、居宅では原則**月1回以上**の訪問が決まっています（[ケアマネジメント・多職種連携・人材育成](../team-01-renkei/)）。

**評価のルール**

- 評価の基準は**短期目標**。最も優先する評価項目は「**短期目標の達成度**」
- **支援の実施状況の情報を整理**して評価する。計画したのに実施しなかったことも評価する
- **利用者の満足度**や反応も踏まえる。評価の結果は**利用者本人に伝える**
- 評価基準と評価日は**計画を立てるときに**決めておく（実施後・実施中に決めるのは×）
- 生活状況が変わったら、**予定の評価日を待たずに**見直す
- 目標を達成していても評価する。**他の利用者と比べない**
- 評価はチームから情報を集めて行い、責任をもつのは**介護計画を立てた介護福祉職**（サービス担当者会議はケアプランを話し合う場で、介護計画を評価する場ではない。相談支援専門員は障害福祉のサービス等利用計画の担当）

### 評価のあとの分かれ道

| 評価の結果 | 次にすること |
|---|---|
| 目標を達成した | 計画を続ける、または終了して次の目標へ |
| 達成したが、続けるのが難しい（負担が大きいなど） | 計画（支援内容）を修正する |
| 達成できなかった | 原因を探り、計画を修正するか**再アセスメント**へ |
| 途中で状態が大きく変わった | 評価日を待たずに**再アセスメント** |

> 事例では、本人が「大丈夫です」と言っているからといって、満足していると決めつけるのは×です。表情（涙など）や、家族・近所の人からの情報も合わせて評価し、必要なら計画を見直します（第28回）。

## ③ チームアプローチ・カンファレンス・会議

### チームアプローチの原則

- チームの中心は**利用者**
- チームで**目的を共有**し、**情報交換して生活課題を明確にする**
- ボランティアや家族もチームの一員になれる。メンバーは固定ではない
- 介護福祉職の役割は、**生活状況の変化の情報を提供**すること、**本人と家族の思いを報告**すること（利用者の思いを代わりに伝える<strong>代弁（アドボカシー）</strong>）
- 本人が自分で決められるよう、選ぶために必要な情報をわかりやすく伝える（**意思決定支援**）。くわしくは[自己決定・意思決定支援の事例問題](../songen-03-jirei/)

### 会議と、それぞれの役割

| 会議・場面 | ポイント |
|---|---|
| **カンファレンス** | 計画の修正などを、**職員の間で共通認識をもつ**ために行う |
| **サービス担当者会議**（介護保険） | 主催は**介護支援専門員**。ケアプラン原案を話し合い、会議のあとに**本人の同意**を得て交付する。訪問介護の**サービス提供責任者**（サ責）は、**訪問介護計画の作成に必要な情報を確認**する |
| サービス担当者会議（障害福祉） | 事業所の**サービス管理責任者**は、自分が作る**個別支援計画の取り組みを報告**する |

障害福祉では、全体の計画（**サービス等利用計画**）は**相談支援専門員**、事業所の計画（**個別支援計画**）は**サービス管理責任者**がつくります（[ケアプラン・サービス等利用計画・個別支援計画…計画とつくる人の違い](../hikaku-10-keikaku/)）。

**ケアマネジメントの流れ**：インテーク（最初の相談・受付）→ アセスメント → ケアプラン原案 → サービス担当者会議 → 同意・交付 → 実施 → モニタリング → 評価（終結）。何度会議をしても、計画やその変更には**必ず本人の同意**が必要です。くわしくは[ケアマネジメント・多職種連携・人材育成](../team-01-renkei/)で扱います。

### 事例研究

- 目的：**介護過程から介護実践を振り返る**こと
- 倫理的配慮：研究内容を**説明して同意**を得る、**個人が特定されないように**する、引用元を示す、事実を拡大解釈しない

| 医療職がチームを主導する／ボランティアは入れない | 中心は利用者。メンバーは柔軟に |
