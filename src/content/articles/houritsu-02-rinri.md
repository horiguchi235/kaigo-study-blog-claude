## ① 職業倫理・求められる介護福祉士像

### 日本介護福祉士会の倫理綱領

日本介護福祉士会（介護福祉士の職能団体、1994年設立）が**1995年**に宣言しました。7項目のうち、★は過去問で問われたものです。

| 項目 | 中身 |
|---|---|
| 利用者本位、自立支援 ★ | 利用者の意思と価値観を尊重し、自立を支える |
| 専門的サービスの提供 | 知識・技術を磨き、自らの実践に責任をもつ |
| プライバシーの保護 ★ | 業務で知った個人の情報を守る |
| 総合的サービスの提供と積極的な連携・協力 | 保健医療福祉の関係者と連携する |
| 利用者ニーズの代弁 | 言い出しにくい利用者の思いを代弁する（アドボカシー。本人主体で、支援者の思いに置きかえない） |
| 地域福祉の推進 ★ | 地域住民と協力し、介護への理解を広げる |
| 後継者の育成 ★ | 指導力を高め、次の世代の人材を育てる |

### 倫理的な対応

| 場面 | ○ | × |
|---|---|---|
| 他の利用者の病状を聞かれた | **話さない** | 教えてしまう |
| 職員同士の打ち合わせ | 利用者や来訪者に聞こえない場所で行う | 廊下で打ち合わせる |
| 個人情報を使うとき | 扱いを**説明して同意を得る** | 説明せずに使う |
| ケアの方針 | **利用者の価値観**を尊重し、**個別**のケア | 画一的に実践／介護福祉士の価値観を優先 |
| 技術が伴わないこと・医行為を求められた | **行わない** | 要望を最優先に実施 |
| おむつ交換 | ドアやカーテンを閉める | 個室のドアを開けたまま行う |
| 介護の最中 | 利用者に向き合う | 携帯電話で話しながら介護 |
| 転落した利用者 | 状態を観察し、すぐに報告する | 「大丈夫」と言われたのでそのまま寝かせる |
| 落ち着かない利用者 | 理由を探り、関わり方を工夫する | 腰ベルトで固定・部屋から出さない（身体拘束） |

倫理に反する行動は、自分では気づかないこともあります。上司などから**定期的にスーパービジョン**（実践を振り返り、助言を受けること）を受けて確認します。関連する用語：**アカウンタビリティ**＝説明責任、**コンプライアンス**＝法令遵守。

### 家族の意見が割れたとき

胃ろうをめぐって妻と長男が口論している → 「**Aさん自身は、どのようにお考えなのでしょうか**」（本人の意思を確かめる）。「医師に従う」「妻の気持ちが優先」は×。

### 求められる介護福祉士像（2017年）

- **介護職の中で中核的な役割**を担う
- 身体的・心理的・社会的支援を**バランスよく**展開

## ② 個人情報の保護

### 個人情報保護法

| ○ | × |
|---|---|
| 対象は**生存する個人**の情報。亡くなった人の情報は法律の対象外だが、介護・医療の現場ではガイダンスにより**同じように安全管理する** | 亡くなった人の情報は自由に扱える |
| **映像・顔写真・音声、電磁的記録**も個人情報 | 映像・電子データは含まない |
| **マイナンバー**や顔・指紋のデータなどの**個人識別符号**も個人情報 | — |
| 病歴・障害などは**要配慮個人情報**で、取得するときも原則本人の同意が必要 | — |
| 町内会など**規模の小さい団体**も個人情報取扱事業者になる | 5,000人以下の名簿なら対象外 |
| 第三者への提供は**原則本人の同意が必要** | 自治会長は同意なしで入手できる |
| 実習生には、施設の責任で**必要な範囲で**生活歴などを伝えられる（秘密保持を約束させる） | 一切教えられない／実習生が記録を自由に閲覧してよい |
| **民間の保険会社**からの問い合わせに答える義務はない | 同意なしで答えてよい |
| 本人からの開示請求でも**例外的に開示しないこと**がある | いかなる場合も開示 |

### 同意なしで第三者に提供できる4つの例外

| 例外 | 介護の場面の例 |
|---|---|
| **法令に基づく**場合 | 高齢者虐待防止法による**虐待の通報** |
| **人の生命・身体・財産**を守るために必要で、本人の同意を得にくい場合 | 意識を失った利用者の情報を**救急隊員に伝える** |
| 公衆衛生の向上・児童の健全な育成のために特に必要で、同意を得にくい場合 | 感染症の集団発生時の保健所への協力 |
| 国や自治体の事務に協力する必要がある場合 | 行政の調査への協力 |

### 同意がいる？いらない？

| 同意**不要** | 同意**必要** |
|---|---|
| 意識消失・けいれんの利用者の情報を**救急隊員に提供**（命を守るため） | 行事の写真を**広報誌に使う** |
| **同一事業所内**のカンファレンス（匿名化も不要） | **転居先の施設**への提供、**サービス担当者会議**での提供（事前に文書で同意） |
| 虐待の**通報**（法令に基づく） | 保険会社からの問い合わせ、実習生の閲覧 |

### 施設での安全管理

| ○ | × |
|---|---|
| **生活歴などはルールに従って職員間で共有** | 個人ファイルを机の上に置いたまま |
| **個人情報保護の研修を定期的に**開催 | パスワードを全員で共有 |
| **苦情対応の体制を掲示板などで周知** | 不要な情報は復元できるように破棄 |
| 書類は**シュレッダー**など復元できない方法で破棄 | 新聞紙と一緒に捨てる |
| 守秘義務は**採用時に書面で**確認 | 退職時に提示 |
| 私用スマートフォンの持ち込みに**ルール** | 制限しない／休憩室に監視カメラ |
| 家庭内の出来事・会話も必要な情報は記録 | 情報に含まれないので記録しない |
