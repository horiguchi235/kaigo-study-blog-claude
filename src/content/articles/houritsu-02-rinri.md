**この記事のポイント**

1. 倫理の基本は**利用者本位・秘密保持・後継者の育成・地域との連携**。家族の意見が割れたら「**ご本人はどうお考えでしょう**」。
2. 個人情報の第三者提供は**原則本人の同意が必要**。**救急搬送など命に関わるときは同意不要**。
3. 施設では**研修を定期的に**、**苦情対応の窓口を掲示**、捨てるときは**復元できないように**。

## ① 職業倫理・求められる介護福祉士像【介護の基本／人間の尊厳と自立】

### 倫理的な対応

| ○ | × |
|---|---|
| 他の利用者の病状を聞かれても**話さない** | — |
| 個人情報の扱いを**説明して同意を得る** | 廊下で職員同士が打ち合わせ |
| 質の高い介護のため**後継者を育成**する | 地域住民との連携は不要 |
| **利用者の価値観**を尊重、**個別**のケア | 画一的に実践／介護福祉士の価値観を優先 |
| 技術が伴わないことは**行わない**、医行為は求められてもしない | 要望を最優先に実施 |
| — | おむつ交換で個室のドアを開ける／携帯で話しながら介護／転落後「大丈夫」で寝かせる／腰ベルト・部屋から出さない（身体拘束） |

### 家族の意見が割れたとき

胃ろうをめぐって妻と長男が口論している → 「**Aさん自身は、どのようにお考えなのでしょうか**」（本人の意思を確かめる）。「医師に従う」「妻の気持ちが優先」は×。

### 求められる介護福祉士像（2017年）

- **介護職の中で中核的な役割**を担う
- 身体的・心理的・社会的支援を**バランスよく**展開
- **自律的に介護過程を展開**できる（他律的は×）
- 本人や家族の暮らしを支える（家族が望む生活が最優先ではない）、地域や社会のニーズに対応

### EPA介護福祉士候補者

インドネシア（2008年度〜）・フィリピン・ベトナムの**3か国**。候補者の在留は原則4年。**介護福祉士の資格を取り、介護業務に従事する限り日本に在留できる**。

## ② 個人情報の保護【介護の基本／社会の理解】

### 個人情報保護法

| ○ | × |
|---|---|
| **映像・顔写真・音声、電磁的記録**も個人情報 | 映像・電子データは含まない |
| **マイナンバーなどの個人識別符号**も個人情報 | — |
| 第三者への提供は**原則本人の同意が必要** | 自治会長は同意なしで入手できる |
| 実習生には**必要な範囲で**生活歴などを伝えられる | 一切教えられない |
| 本人からの開示請求でも**例外的に開示しないこと**がある | いかなる場合も開示 |

### 同意がいる？いらない？

| 同意**不要** | 同意**必要** |
|---|---|
| 意識消失・けいれんの利用者の情報を**救急隊員に提供**（命を守るため） | 行事の写真を**広報誌に使う** |
| **同一事業所内**のカンファレンス（匿名化も不要） | **転居先の施設**への提供、**サービス担当者会議**での提供（事前に文書で同意） |
| — | 保険会社からの問い合わせ、実習生の閲覧 |

### 施設での安全管理

| ○ | × |
|---|---|
| **生活歴などはルールに従って職員間で共有** | 個人ファイルを机の上に置いたまま |
| **個人情報保護の研修を定期的に**開催 | パスワードを全員で共有 |
| **苦情対応の体制を掲示板などで周知** | 不要な情報は復元できるように破棄 |
| 書類は**シュレッダー**など復元できない方法で破棄 | 新聞紙と一緒に捨てる |
| 守秘義務は**採用時に書面で**確認 | 退職時に提示 |
| 私用スマートフォンの持ち込みに**ルール** | 制限しない／休憩室に監視カメラ |
| 家庭内の出来事・会話も必要な情報は記録 | 情報に含まれないので記録しない |

### 消費者被害

認知症の一人暮らしの父が**高額な投資信託の電話勧誘**で悩んでいる → **消費生活センター**に相談（クーリング・オフなど）。
