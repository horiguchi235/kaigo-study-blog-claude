**この記事のポイント**

1. 保険者は**市町村（特別区）**。第1号は**65歳以上**、第2号は**40〜64歳の医療保険加入者**。
2. 財源は**公費（税）50％＋保険料50％（第1号・第2号）**。利用者負担は**1〜3割**。
3. 申請も区分変更も**市町村**へ。不服申立ては**都道府県の介護保険審査会**、サービスへの苦情は**事業所 → 国保連**。

## ① 保険者・被保険者・財源・目的

### 誰が運営し、誰が入るか

<fig name="kaigohoken">

| | 第1号被保険者 | 第2号被保険者 |
|---|---|---|
| 対象 | **65歳以上** | **40〜64歳の医療保険加入者** |
| 保険料の徴収 | **市町村**（年金から天引きが中心） | **医療保険の保険料と一緒に**徴収 |
| 保険料の額 | **市町村ごとに異なる** | 医療保険者ごとに計算 |
| サービスを使える条件 | 要介護・要支援になった | **特定疾病**（末期がん・認知症・脳血管疾患など16種類）が原因 |

- **保険者**＝**市町村及び特別区**。保険者の役割は**保険給付の事務**・保険料の徴収・認定など
- 加入は**強制**（任意ではない）。住所のある市町村の被保険者になる
- 他の市町村の施設に入所して住所を移しても、**もとの市町村**の被保険者のまま（**住所地特例**）

### 国・都道府県・市町村の役割分担

| 国 | 都道府県 | 市町村 |
|---|---|---|
| 要介護認定の**基準**を決める | **介護保険審査会**を置く | **保険者**、認定、保険料の徴収 |
| 介護報酬を決める | **施設・居宅サービス**の事業者を指定 | **地域密着型サービス**の事業者を指定 |
| — | ケアマネジャーの登録 | 地域包括支援センターを設置 |

### 財源

```
公費（税）50％ ＝ 国25％・都道府県12.5％・市町村12.5％（施設は国20％・都道府県17.5％）
保険料  50％ ＝ 第1号保険料（約23％）＋ 第2号保険料（約27％）
```

「現役世代からの支援金」は後期高齢者医療制度の財源で、介護保険ではありません。

### 介護保険法の目的・理念

- 第1条：要介護者などが**尊厳を保持**し、**能力に応じ自立した日常生活**を営めるよう保険給付を行う
- **国民の共同連帯**の理念
- 保険給付は**介護給付・予防給付・市町村特別給付**の3種類。提供主体は社会福祉法人に限らない（株式会社・NPOも可）

## ② 要介護認定と利用の流れ・契約・苦情

### 利用の流れ

1. **市町村に申請**（地域包括支援センターなどが代行可）。**区分変更**の申請も<strong>保険者（市町村）</strong>へ
2. 認定調査＋**主治医の意見書**（必要）
3. 一次判定（コンピュータ）→ 二次判定（**介護認定審査会**＝市町村に設置）
4. **市町村が本人に結果を通知**
5. **ケアプラン作成**（原則として**認定の後**）→ 契約 → 利用

| ○ | × |
|---|---|
| 保険給付には**支給限度額**がある | 65歳未満は対象外（第2号は特定疾病で使える） |
| 新規認定の有効期間は**原則6か月** | 原則3か月 |
| 福祉用具貸与は**要介護度に応じて**品目が決まる | 要介護3以上だけ |
| 認定前でも**地域包括支援センターに相談**できる | 相談の前に認定が必要 |

### 契約

**重要事項説明書**を渡してサービス内容を説明し、**同意を得てから**、**利用者と**契約書を取り交わす。契約後に説明する・郵送だけ・隣人が署名する、は×。

### 苦情と不服

| 不満の中身 | 相談先 |
|---|---|
| サービスや職員の対応 | まず**事業所の苦情窓口** → 解決しなければ**国民健康保険団体連合会（国保連）**・市町村 |
| **要介護認定**や保険料の決定 | **介護保険審査会**（都道府県）に審査請求 |
| 日常生活自立支援事業・福祉サービス全般 | 運営適正化委員会（都道府県社協） |

> 利用者負担が払えずサービスを断りたいと相談された訪問介護員は、自分で判断せず**担当のケアマネジャーに検討を依頼**します。

## ③ 制度改正の流れ

| 年 | 主な内容 |
|---|---|
| 1997年成立・**2000年施行** | 介護保険スタート |
| **2005年改正**（2006年施行） | **介護予防重視**（新予防給付）、**地域包括支援センター**・**地域密着型サービス**の創設、施設の食費・居住費を自己負担に |
| 2011年改正（2012年施行） | **定期巡回・随時対応型訪問介護看護**、複合型サービス（現・看護小規模多機能）、**地域包括ケア**の推進 |
| **2014年改正**（2015年施行） | 特養の新規入所は**原則要介護3以上**、一定以上所得者は**2割負担**、予防給付の訪問介護・通所介護を**市町村の総合事業**へ |
| **2017年改正**（2018年施行） | **介護医療院**の創設、**3割負担**の導入、**共生型サービス** |

## ④ 国・都道府県・市町村の役割と保険料のしくみ

- **被保険者**：第1号＝**市町村に住所がある65歳以上**（生活保護を受けていても第1号）／第2号＝40〜64歳の**医療保険加入者**。**救護施設などの適用除外施設**に入ると資格を失う。被保険者証は**市町村**が交付。
- **要介護認定の流れ**：申請（市町村）→**認定調査＋主治医意見書**→一次判定（コンピュータ）→**介護認定審査会で二次判定**→市町村が認定。効力は**申請日にさかのぼる**。要介護状態＝介護が必要な状態が**原則6か月以上**続く見込み。
- **有効期間**：**新規・区分変更＝原則6か月**（3〜12か月）、**更新＝原則12か月**（3〜48か月）。認定の取り消しは**市町村**。
- **市町村の役割**：保険者として認定・給付・保険料（第1号）・**地域支援事業**・地域包括支援センター・地域密着型サービスの指定・**市町村介護保険事業計画（3年1期）**。
- **都道府県の役割**：市町村の支援、**財政安定化基金**、**介護保険審査会（不服申立て）**、**介護支援専門員の登録**、**介護サービス情報の公表**、居宅・施設サービスの指定、**介護保険事業支援計画**。
- **国の役割**：制度の枠組み、要介護認定の基準・介護報酬の決定、**基本指針**（厚生労働大臣）。
- **財源（公費の内訳）**：居宅給付費＝**国25％・都道府県12.5％・市町村12.5％**／施設等給付費＝**国20％・都道府県17.5％・市町村12.5％**。保険料は第1号23％・第2号27％（2024〜2026年度）。
- **苦情・不服**：認定などの処分への不服＝**介護保険審査会（都道府県）**／サービスの質への苦情＝**国民健康保険団体連合会（国保連）**。
- **住所地特例**：施設に入所して住所を移しても、**もとの市町村**の被保険者のままでいる仕組み（施設のある市町村の負担が偏らないように）。
- **第1号保険料**：年金が年18万円以上なら年金から天引き（**特別徴収**）、それ以外は納付書（**普通徴収**、コンビニ払いも可）。**第2号**は医療保険者が医療保険料と一緒に集める。
- **保険料を滞納**すると：償還払い（いったん全額払う）→保険給付の一時差し止め→滞納保険料との相殺、と段階的に制限される。
- **生活保護受給者**も介護保険が優先。自己負担分は**介護扶助**、保険料は**生活扶助**で出る。
- 国の役割＝**基準づくり**（介護報酬・要介護認定基準など）と定率の国庫負担。都道府県＝**財政安定化基金**、**介護保険審査会**（不服申立て）、事業者の指定。市町村＝**保険者**、認定、地域支援事業、介護保険事業計画（第1号保険料を決める）。
- **国保連**（国民健康保険団体連合会）＝介護報酬の審査・支払と**苦情処理**。
- 介護保険制度の主な改正：2005年（予防重視・地域包括支援センター・地域密着型）／2011年（地域包括ケア・定期巡回）／2014年（予防訪問・通所を総合事業へ、特養は原則要介護3以上、2割負担）／2017年（3割負担・介護医療院・共生型サービス）／2023年（介護情報基盤、居宅介護支援事業所も介護予防支援の指定を受けられる）。
