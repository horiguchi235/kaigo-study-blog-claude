**結論を3行で**

1. 保険者は**市町村（特別区）**。第1号は**65歳以上**、第2号は**40〜64歳の医療保険加入者**。
2. 財源は**公費（税）50％＋保険料50％（第1号・第2号）**。利用者負担は**1〜3割**。
3. 申請も区分変更も**市町村**へ。不服申立ては**都道府県の介護保険審査会**、サービスへの苦情は**事業所 → 国保連**。

## ① 保険者・被保険者・財源・目的【社会の理解】

### 誰が運営し、誰が入るか

<fig name="kaigohoken">

| | 第1号被保険者 | 第2号被保険者 |
|---|---|---|
| 対象 | **65歳以上**（第32回） | **40〜64歳の医療保険加入者**（第27回） |
| 保険料の徴収 | **市町村**（年金から天引きが中心） | **医療保険の保険料と一緒に**徴収 |
| 保険料の額 | **市町村ごとに異なる** | 医療保険者ごとに計算 |
| サービスを使える条件 | 要介護・要支援になった | **特定疾病**（末期がん・認知症・脳血管疾患など16種類）が原因 |

- **保険者**＝**市町村及び特別区**（第28・33回）。保険者の役割は**保険給付の事務**・保険料の徴収・認定など（第29回）
- 加入は**強制**（任意ではない）。住所のある市町村の被保険者になる
- 他の市町村の施設に入所して住所を移しても、**もとの市町村**の被保険者のまま（**住所地特例**）

### 国・都道府県・市町村の役割分担

| 国 | 都道府県 | 市町村 |
|---|---|---|
| 要介護認定の**基準**を決める | **介護保険審査会**を置く（第25回） | **保険者**、認定、保険料の徴収 |
| 介護報酬を決める | **施設・居宅サービス**の事業者を指定 | **地域密着型サービス**の事業者を指定 |
| — | ケアマネジャーの登録 | 地域包括支援センターを設置 |

### 財源（第34・37回）

```
公費（税）50％ ＝ 国25％・都道府県12.5％・市町村12.5％（施設は国20％・都道府県17.5％）
保険料  50％ ＝ 第1号保険料（約23％）＋ 第2号保険料（約27％）
```

「現役世代からの支援金」は後期高齢者医療制度の財源で、介護保険ではありません。

### 介護保険法の目的・理念

- 第1条：要介護者などが**尊厳を保持**し、**能力に応じ自立した日常生活**を営めるよう保険給付を行う（第30回）
- **国民の共同連帯**の理念（第26回）
- 保険給付は**介護給付・予防給付・市町村特別給付**の3種類。提供主体は社会福祉法人に限らない（株式会社・NPOも可）

介護保険制度に関する記述として、正しいものはどれ？

1. 第1号被保険者の保険料は、都道府県が徴収する
2. 第1号被保険者の保険料は、全国一律である
3. 第2号被保険者の保険料は、年金保険の保険料と合わせて徴収される
4. 財源には、第1号被保険者の保険料と第2号被保険者の保険料が含まれる
5. 利用者負担割合は、一律1割である

**正解：4**　1は市町村、2は市町村ごとに違う、3は医療保険の保険料と合わせて、5は所得に応じて1〜3割です。

## ② 要介護認定と利用の流れ・契約・苦情【社会の理解】

### 利用の流れ

1. **市町村に申請**（地域包括支援センターなどが代行可）。**区分変更**の申請も**保険者（市町村）**へ（第35回）
2. 認定調査＋**主治医の意見書**（必要）
3. 一次判定（コンピュータ）→ 二次判定（**介護認定審査会**＝市町村に設置）
4. **市町村が本人に結果を通知**（第26回）
5. **ケアプラン作成**（原則として**認定の後**）（第33回）→ 契約 → 利用

| ○ | × |
|---|---|
| 保険給付には**支給限度額**がある（第38回） | 65歳未満は対象外（第2号は特定疾病で使える） |
| 新規認定の有効期間は**原則6か月** | 原則3か月 |
| 福祉用具貸与は**要介護度に応じて**品目が決まる | 要介護3以上だけ |
| 認定前でも**地域包括支援センターに相談**できる | 相談の前に認定が必要 |

### 契約（第28回）

**重要事項説明書**を渡してサービス内容を説明し、**同意を得てから**、**利用者と**契約書を取り交わす。契約後に説明する・郵送だけ・隣人が署名する、は×。

### 苦情と不服（第31回）

| 不満の中身 | 相談先 |
|---|---|
| サービスや職員の対応 | まず**事業所の苦情窓口** → 解決しなければ**国民健康保険団体連合会（国保連）**・市町村 |
| **要介護認定**や保険料の決定 | **介護保険審査会**（都道府県）に審査請求 |
| 日常生活自立支援事業・福祉サービス全般 | 運営適正化委員会（都道府県社協） |

> 利用者負担が払えずサービスを断りたいと相談された訪問介護員は、自分で判断せず**担当のケアマネジャーに検討を依頼**します（第30回）。

## ③ 制度改正の流れ【社会の理解】

| 年 | 主な内容 |
|---|---|
| 1997年成立・**2000年施行** | 介護保険スタート |
| **2005年改正**（2006年施行） | **介護予防重視**（新予防給付）、**地域包括支援センター**・**地域密着型サービス**の創設、施設の食費・居住費を自己負担に（第25・27回） |
| 2011年改正（2012年施行） | **定期巡回・随時対応型訪問介護看護**、複合型サービス（現・看護小規模多機能）、**地域包括ケア**の推進 |
| **2014年改正**（2015年施行） | 特養の新規入所は**原則要介護3以上**（第28回）、一定以上所得者は**2割負担**、予防給付の訪問介護・通所介護を**市町村の総合事業**へ |
| **2017年改正**（2018年施行） | **介護医療院**の創設（第31回）、**3割負担**の導入（第31回）、**共生型サービス** |

<details>
<summary>✏️ 解いてみよう（第28回）</summary>

2015年4月に施行された介護保険制度の改正内容として、正しいものはどれ？

1. 低所得者の保険料負担を引き上げた
2. 介護老人福祉施設の新規入所者を原則として要介護3以上にした
3. 予防給付の訪問介護・通所介護を都道府県の事業に移した
4. 施設の食費・居住費を補う補足給付の対象者を広げた
5. 一定以上の所得のある人の自己負担を3割にした

<details class="answer">
<summary>正解を見る</summary>

**正解：2**　3は「市町村の」総合事業へ、4は資産要件を加えて対象を絞った、5の3割は2018年施行です（2015年は2割負担の導入）。1は逆で、低所得者の負担は軽くしました。
</details>
