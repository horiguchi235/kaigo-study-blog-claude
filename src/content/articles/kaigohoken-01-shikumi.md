**この記事のポイント**

1. 保険者は**市町村（特別区）**。第1号は**65歳以上**、第2号は**40〜64歳の医療保険に加入している人**。
2. 財源は**公費（税）50％＋保険料50％（第1号・第2号）**。利用者負担は**1〜3割**。
3. 申請も区分変更も**市町村**へ。不服申立ては**都道府県の介護保険審査会**、サービスへの苦情は**まず事業所 → 解決しなければ市町村や国保連**。

## ① 保険者・被保険者・財源・目的

### 誰が運営し、誰が入るか

<fig name="kaigohoken">

お金とサービスの流れ：①被保険者が保険者（市町村）に**保険料**を払う → ②**認定を申請**し → ③**要介護認定**を受ける → ④⑤事業者からサービスを受け、**利用料（1〜3割）**を事業者に払う → ⑥事業者は残り（**7〜9割**）を**国保連**に請求 → ⑦国保連が審査し、保険者のお金から事業者に支払う。

言葉：**国保連**＝国民健康保険団体連合会（事業者の請求を審査して支払い、サービスへの**苦情処理**も行う）／**介護報酬**＝サービスの値段（国が決める）／**特別区**＝東京23区。

| | 第1号被保険者 | 第2号被保険者 |
|---|---|---|
| 対象 | **市町村に住所がある65歳以上**（生活保護を受けていても第1号） | **40〜64歳の医療保険に加入している人** |
| 保険料の徴収 | **市町村**（年金から天引きが中心） | **医療保険の保険料と一緒に**医療保険者が徴収 |
| 保険料の額 | **市町村ごとに異なる** | 医療保険者ごとに計算 |
| サービスを使える条件 | 要介護・要支援になった | **特定疾病**（老化が原因とされる16種類の病気）が原因 |

**特定疾病（16種類）**：がん（末期）／関節リウマチ／筋萎縮性側索硬化症（ALS）／後縦靱帯骨化症／骨折を伴う骨粗鬆症／初老期における認知症／進行性核上性麻痺・大脳皮質基底核変性症・パーキンソン病／脊髄小脳変性症／脊柱管狭窄症／早老症／多系統萎縮症／糖尿病性神経障害・腎症・網膜症／脳血管疾患／閉塞性動脈硬化症／慢性閉塞性肺疾患（COPD）／両側の膝関節または股関節の著しい変形を伴う変形性関節症

- **保険者**＝**市町村及び特別区**。保険者の役割は**保険給付の事務**・保険料の徴収・認定・被保険者証の交付など。小さな市町村は、いくつか集まって**広域連合**や一部事務組合をつくり、保険者になることもあります
- 加入は**強制**（任意ではない）。住所のある市町村の被保険者になる。**救護施設などの適用除外施設**に入ると被保険者でなくなる
- 他の市町村の施設に入所して住所を移しても、**もとの市町村**の被保険者のまま（**住所地特例**。施設の多い市町村に負担が偏らないため）

### 国・都道府県・市町村の役割分担

| 国 | 都道府県 | 市町村 |
|---|---|---|
| 要介護認定の**基準**を決める | **介護保険審査会**を置く | **保険者**、認定、第1号保険料の徴収 |
| 介護報酬を決める | **施設・居宅サービス**の事業者を指定 | **地域密着型サービス**の事業者を指定 |
| **基本指針**（厚生労働大臣）・定率の国庫負担 | **財政安定化基金**（市町村の財政が赤字にならないよう貸付・交付） | **地域支援事業**の実施・地域包括支援センターを設置 |
| — | **介護支援専門員の登録**・**介護サービス情報の公表** | — |
| — | **介護保険事業支援計画**（3年1期） | **介護保険事業計画**（3年1期。第1号保険料を決める） |

**国保連（国民健康保険団体連合会）の仕事**：都道府県ごとに1つあります。

- 介護報酬の請求を**審査して支払う**（総合事業の分も。審査は介護給付費審査委員会が行う）
- サービスへの**苦情を受け付けて調べ**、事業者に指導・助言する
- 交通事故など、ほかの人（第三者）が原因でかかった介護の費用を、加害者に請求する事務

**事業者の指定と指導**：事業者は、人員・設備・運営の基準を満たして指定を受けます。指定は**6年ごとに更新**です。基準を守らないときは、**勧告 → 公表 → 命令**の順で正され、悪質なら指定の取消しや効力の停止になります。

### 財源

```
公費（税）50％ ＝ 国25％・都道府県12.5％・市町村12.5％（施設等は国20％・都道府県17.5％・市町村12.5％）
保険料  50％ ＝ 第1号保険料（23％）＋ 第2号保険料（27％）（2024〜2026年度）
```

「現役世代からの支援金」は後期高齢者医療制度の財源で、介護保険ではありません。

### 保険料の集め方と滞納

| 集め方 | 中身 |
|---|---|
| **特別徴収**（第1号） | 年金が**年18万円以上**なら**年金から天引き** |
| **普通徴収**（第1号） | それ以外は納付書で納める（コンビニ払いも可） |
| 第2号 | 医療保険者が医療保険料と一緒に集める |

- **保険料を滞納**すると段階的に制限：いったん全額払う**償還払い**（あとで保険給付分が戻る）→ 保険給付の**一時差し止め** → 滞納保険料との相殺。時効で納められなくなった期間があると（**2年以上の滞納**）、自己負担が**3割（3割の人は4割）に引き上げ**られる
- **生活保護受給者**：65歳以上は介護保険が優先し、自己負担分は**介護扶助**、保険料は**生活扶助**で出る。40〜64歳で医療保険に入っていない人は第2号にならず、介護サービスは**介護扶助**で受ける

### 介護保険法の目的・理念

- 第1条：要介護者などが**尊厳を保持**し、**能力に応じ自立した日常生活**を営めるよう保険給付を行う
- **国民の共同連帯**の理念
- 保険給付は**介護給付・予防給付・市町村特別給付**の3種類。提供主体は社会福祉法人に限らない（株式会社・NPOも可）

## ② 要介護認定と利用の流れ・契約・苦情

### 要介護度の区分

| 区分 | 使える給付 |
|---|---|
| **要支援1・2**（介護予防が必要） | **予防給付**（介護予防サービス）と**総合事業**。施設サービスは使えない |
| **要介護1〜5**（数字が大きいほど重い） | **介護給付**（居宅・地域密着型・施設サービス）。特養の新規入所は**原則要介護3以上** |
| 非該当（自立） | 保険給付はない。市町村の総合事業などを利用 |

### 利用の流れ

1. **市町村に申請**（地域包括支援センターなどが代行可）。状態が変わったときの**区分変更**（有効期間の途中で要介護度を見直すこと）の申請も<strong>保険者（市町村）</strong>へ
2. 認定調査＋**主治医の意見書**（必要）
3. 一次判定（コンピュータ）→ 二次判定（**介護認定審査会**＝市町村に設置）
4. **市町村が本人に結果を通知**。結果は申請から**原則30日以内**（調査が遅れるときなどは延長を知らせる）。申請して2週間で結果が来なくても、珍しいことではありません。認定の効力は**申請日にさかのぼる**
5. **ケアプラン作成**（原則として**認定の後**）→ 契約 → 利用

- 急いでいるときは、結果が出る前でも**暫定のケアプラン**をつくってサービスを使い始められます（効力が申請日にさかのぼるため）。ただし「非該当（自立）」になると、使った分は**全額自己負担**になるおそれがあります
- 2割・3割負担になるのは、**65歳以上（第1号）で一定以上の所得がある人**だけです。**第2号被保険者（40〜64歳）は所得に関係なく1割**。第2号の保険料は医療保険と一緒に集めるので、年金からの天引き（特別徴収）にはなりません

- 要介護状態＝介護が必要な状態が**原則6か月以上**続く見込みのこと
- 在宅サービスには要介護度ごとに、保険で使える1か月の上限額（**支給限度額**）がある

| ○ | × |
|---|---|
| 保険給付には**支給限度額**がある | 支給限度額はない |
| 40〜64歳（第2号）も**特定疾病**（16種類）が原因で要介護・要支援になったら保険給付を受けられる | 65歳未満は対象外 |
| 新規・区分変更の有効期間は**原則6か月**（3〜12か月）、更新は**原則12か月**（3〜48か月） | 新規は原則3か月 |
| 福祉用具貸与は**要介護度に応じて**品目が決まる | 要介護3以上だけ |
| 一部の福祉用具（固定用スロープ・歩行器・単点杖・多点杖）は**貸与か購入かを選べる**（2024年4月から） | すべて貸与のみ |
| 認定前でも**地域包括支援センターに相談**できる | 相談の前に認定が必要 |

### 契約

**重要事項説明書**を渡してサービス内容を説明し、**同意を得てから**、**利用者と**契約書を取り交わす。契約後に説明する・郵送だけ・隣人が署名する、は×。

### 苦情と不服

| 不満の中身 | 相談先 |
|---|---|
| サービスや職員の対応 | まず**事業所の苦情窓口** → 解決しなければ**市町村**や**国保連（国民健康保険団体連合会）** |
| **要介護認定**や保険料の決定 | **介護保険審査会**（都道府県）に審査請求 |
| 日常生活自立支援事業・福祉サービス全般 | 運営適正化委員会（都道府県社協） |

> 利用者負担が払えずサービスを断りたいと相談された訪問介護員は、自分で判断せず**担当のケアマネジャーに検討を依頼**します。

## ③ 制度改正の流れ

### 介護保険ができるまで

- **1963年 老人福祉法**で**特別養護老人ホーム**ができました。入所できるのは「**65歳以上**で、からだや精神の著しい障害のため**常に介護が必要**で、家で介護を受けるのが難しい人」。経済的に困っている人のための施設は**養護老人ホーム**です。当時は、行政が入所を決める**措置**でした
- 高齢化で介護が必要な人が増え、介護の期間も長くなり、家族だけでは支えきれなくなりました。そこで**2000年に介護保険**が始まりました
- 介護保険のねらい（5つ）：①介護を社会全体で支える（**介護の社会化**）②**措置から契約へ**（利用者がサービスを選ぶ）③保健・医療・福祉に分かれていたサービスを1つの制度にまとめる ④株式会社・NPOなども参入し、競争で質を上げる ⑤**ケアマネジメント**を取り入れる
- 介護保険法は、おおむね**3年ごと**に見直されています（事業計画も3年1期）

| 年 | 主な内容 |
|---|---|
| 1997年成立・**2000年施行** | 介護保険スタート |
| **2005年改正**（2006年施行） | 法の目的（第1条）に「**尊厳の保持**」が加わる、**介護予防重視**（新予防給付）、**地域包括支援センター**・**地域密着型サービス**の創設、施設の食費・居住費を自己負担に |
| 2011年改正（2012年施行） | **定期巡回・随時対応型訪問介護看護**、複合型サービス（現・看護小規模多機能）、**地域包括ケア**の推進 |
| **2014年改正**（2015年施行） | 特養の新規入所は**原則要介護3以上**、一定以上所得者は**2割負担**、予防給付の訪問介護・通所介護を**市町村の総合事業**へ |
| **2017年改正**（2018年施行） | **介護医療院**の創設、**3割負担**の導入、**共生型サービス** |
| 2020年改正（2021年施行） | 地域共生社会の実現（**重層的支援体制整備事業**）、医療・介護のデータ基盤の整備 |
| 2023年改正（2024年施行） | **居宅介護支援事業所も介護予防支援の指定**を受けられる、地域包括支援センターの総合相談の一部委託、介護情報基盤の整備、事業者の**財務状況の報告**を義務づけ国が分析・公表（見える化）、都道府県が事業所の**生産性向上**を進める（努力義務）、**看護小規模多機能型居宅介護**の「通い」「泊まり」でも看護を行えることを明確化 |

### 2024年度の介護報酬改定で義務・減算になったこと

| 項目 | 中身 |
|---|---|
| **高齢者虐待防止の措置** | 委員会・指針・研修・担当者を置く。していないと報酬が減る（2024年4月から） |
| **業務継続計画（BCP）** | 感染症と災害のBCPの策定が**義務**（2024年4月から。未策定は減算） |
| **身体拘束等の適正化** | 委員会・指針・研修。短期入所・多機能系サービスにも広げた（2025年4月から未実施は減算） |
| **認知症介護基礎研修** | 医療・福祉の資格をもたない介護職員に受講を義務づけ（2024年4月に経過措置が終了） |
| 処遇改善加算の一本化 | 3つの加算を「介護職員等処遇改善加算」にまとめた（2024年6月から） |
