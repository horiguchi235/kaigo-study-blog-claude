**この記事のポイント**

1. **合理的配慮**は**障害者権利条約**で初めて国際条約に。<strong>「私たちのことを、私たち抜きに決めないで」</strong>のもとで作られた。
2. 差別解消法は**障害者基本法の理念を具体化**し、**共生社会**をめざす。**手帳の有無は問わず**、**過重な負担にならない範囲で一人ひとりに合わせて**配慮する。
3. 消費者被害は、まず**本人に経緯を聞き、契約内容を一緒に確認**。相談先は**消費生活センター**。**通信販売はクーリング・オフできない**。

## ① 障害者権利条約・障害者基本法・障害者差別解消法

### 年表で見る流れ

| 年 | できごと |
|---|---|
| 1975年 | 国連で**障害者の権利宣言** |
| 1981年 | **国際障害者年**（テーマは「完全参加と平等」） |
| 1990年 | アメリカで**ADA**（障害をもつアメリカ人法） |
| 2006年 | 国連で**障害者権利条約**を採択（日本は2007年に署名） |
| 2011年 | **障害者基本法の改正**（社会的障壁の除去・合理的配慮） |
| 2013年 | **障害者差別解消法**の成立（2016年4月施行） |
| 2014年 | 日本が障害者権利条約を**批准** |
| 2024年4月 | 改正差別解消法の施行で、**事業者の合理的配慮も義務**に |

それより前の人権の歴史（1948年の世界人権宣言など）は [アドボカシー・成年後見制度・日常生活自立支援事業](../kenriyougo-01-kouken/) で扱います。

### 障害者権利条約

- <strong>「Nothing about us without us（私たちのことを、私たち抜きに決めないで）」</strong>のもと、障害者が作成段階から関わった
- **合理的配慮**を国際条約で**初めて**取り上げた
- 日本は**2014年に批准**。そのための国内法の整備として<strong>障害者基本法の改正（2011年）</strong>で**社会的障壁の除去**を規定

### 障害者基本法

**社会的障壁**＝障害のある人の暮らしをさまたげる、**社会の側にあるもの**です。段差などの**物**、使いにくい**制度**、「前例がない」などの**慣習**、偏見などの**考え方（観念）**の4つがあります。

| ○ | × |
|---|---|
| **政府は障害者基本計画を策定**しなければならない | 障害者が自助努力で社会的障壁を解消する |
| 障害者政策委員会は**国（内閣府）**に置く | 障害者政策委員会は都道府県に置く（都道府県には別に審議会などの合議制の機関を置く） |
| 差別の禁止の条文は**残っている** | 差別解消法の制定で削除された |
| 防災・防犯の施策も規定 | 記述はない |

### 障害者差別解消法

| ○ | × |
|---|---|
| **障害者基本法の基本理念**を具体的に実施するため | 障害者総合支援法の理念のもと |
| **共生社会**の実現をめざす | — |
| 対象は**手帳の有無を問わず**、障害や社会的障壁で生活に制限を受ける人 | 身体障害者手帳を持つ人に限る |
| 行政機関等と事業者に**不当な差別的取扱いを禁止** | 事業者は努力義務 |
| **合理的配慮**：行政機関は**法的義務**。事業者も**2024年4月から義務**（それまでは努力義務） | 事業者は今も努力義務 |
| 合理的配慮は**過重な負担にならない範囲**で、**一人ひとりに合わせて** | 負担の大小に関係なく／全員に同じ配慮 |
| 合理的配慮は、障害者からの**申し出（意思の表明）**を受けて行政・事業者が提供する | 障害者が合理的配慮の提供に努める |
| 差別行為そのものへの**罰則はない**（国から報告を求められて応じない・うその報告をした事業者には**過料**がある） | 差別行為に罰則規定がある |
| 障害者差別解消支援地域協議会は**組織できる**（任意） | 市町村に設置義務・民間事業者だけで組織 |
| 雇用の分野の差別禁止・合理的配慮は**障害者雇用促進法**で定める | — |

### 不当な差別的取扱いと合理的配慮

| | 不当な差別的取扱い | 合理的配慮 |
|---|---|---|
| 中身 | 障害を理由に、サービスを**断る・制限する・条件をつける** | 困りごとに合わせて、やり方を**調整・変更する** |
| 法律での扱い | **禁止** | **提供する義務**（過重な負担にならない範囲） |
| 例 | 盲導犬を連れた人の入店を断る／介助者がいないと利用させない | 資料をわかりやすい言葉に直す／口頭の説明を書面で渡す |

### 合理的配慮の具体例

| ○ 合理的配慮にあたる | × |
|---|---|
| 知的障害者の申し出を受け、**会議資料をわかりやすい言葉に直して事前に説明** | 手帳の提示を求める・手話通訳と一緒に来るよう求める・介助者同伴を求める・診断書を求める |
| 聴覚障害の学生の筆記試験で、**口頭の説明を書面で渡す** | 時間延長・文字拡大・問題を読み上げる（**この事例＝聴覚障害の困りごと**には合わない。視覚障害なら配慮になりうる） |
| 障害の特性に応じた**休憩時間の調整** | — |
| 車いすの人に陳列棚の商品を**取って見せる** | 口頭で説明するだけ |
| 盲導犬と一緒に入店してもらう | 犬を店外に（不当な差別的取扱い） |

盲導犬・介助犬・聴導犬をまとめて**身体障害者補助犬**といいます。**身体障害者補助犬法**により、公共施設・交通機関・お店などは、補助犬を連れた人の受け入れを原則として**断ってはいけません**。

## ② 消費者被害とクーリング・オフ

障害を理由とする差別も、だまされて結ばされた契約も、どちらも本人の**権利が侵害されている**状態です。②では、高齢者や認知症の人が巻き込まれやすい消費者被害を扱います。

### 消費者を守る法律

| 法律 | 中身 |
|---|---|
| **特定商取引法** | 訪問販売・電話勧誘・通信販売などのルール。**クーリング・オフ**を定める |
| **消費者契約法** | うそを言われた（誤認）・帰ってくれない（困惑）などで結んだ契約を**取り消せる** |

クーリング・オフ＝期間内なら**理由なしで解除**、消費者契約法＝うそや居座りなどで結ばされた契約を**取り消す**、と区別します。

### 相談先の違い

| 機関 | 役割 |
|---|---|
| **消費生活センター** | 都道府県・市区町村にある**身近な相談窓口**。相談員が助言し、事業者との話し合いを手伝う。電話**188**でつながる |
| 国民生活センター | 国の独立行政法人。全国の情報を集めて注意をよびかけ、各地の消費生活センターを支える |

どちらも**本人に代わって契約を解除する機関ではありません**（解除や取消しをするのは本人や後見人）。**家庭裁判所**は成年後見の申立て先で、消費者トラブルの相談先ではありません。

### クーリング・オフ

契約書面を受け取った日から数えた期間内なら、理由なしで契約を解除できます。通知は書面のほか、**2022年6月から電子メールなどでもできる**ようになりました。

| 取引 | 期間 |
|---|---|
| **訪問販売**・電話勧誘販売 | **8日間** |
| 訪問購入 | 8日間 |
| 特定継続的役務提供（エステ・語学教室など） | 8日間 |
| マルチ商法（連鎖販売取引） | 20日間 |
| 業務提供誘引販売（内職商法など） | 20日間 |
| **通信販売**（テレビショッピング・ネット通販） | **できない**（返品は事業者のルールによる） |
| 店舗での購入 | できない |

- 期間は**法律で決められた書面を受け取った日**から数える。書面をもらっていない・内容に不備があるときは、期間を過ぎても解除できる
- 訪問販売の**リフォーム工事**も対象。「工事が終わったらどんな場合も解除できない」は×
- 通知は書面や電子メールなど**記録が残る方法**で（電話・口頭は避ける）
- 訪問販売には、路上で呼び止めて店に連れて行く**キャッチセールス**、電話などで呼び出す**アポイントメントセールス**も含まれる
- 通信販売はクーリング・オフできないが、返品のルールが広告に書かれていないときは、商品を受け取ってから**8日以内なら返品できる**

### 悪質商法と助言

| 商法 | ○ 助言 |
|---|---|
| **送りつけ商法** | 注文していない商品は**受け取りを断る**。受け取ってしまっても代金は払わず、**2021年7月から直ちに処分してよい** |
| 点検商法 | **業者を家に入れない** |
| かたり商法 | 市役所や消防署などから来たように見せかけて売りつける。**その場で買わず**、本当にその機関の人か確かめる |
| 訪問購入 | 家に来て貴金属などを無理に買い取る。**8日間はクーリング・オフ**できる |
| 催眠商法 | 会場には行かない |
| 利殖商法 | 「元本保証」でも信用しない |
| 振り込め詐欺（オレオレ詐欺、「お金が戻る」とATMへ行かせる**還付金詐欺**、うその電話やメールなど） | **電話の相手を確かめ**、**一人で対処しない**。家族や警察に相談 |

### 消費者被害にあった利用者への対応

| 場面 | ○ 正解 | × |
|---|---|---|
| 訪問販売で高価な寝具を買った認知症の人の家族 | **クーリング・オフで解除できる**ことを伝える | 他者と関わらないよう助言・施設入所・自己破産 |
| 着物を買った母のことで娘が「すぐにクーリング・オフを」 | まず**本人に買うようになった経緯を確認** | 部屋を探す・業者に連絡・浪費だと説明 |
| 認知症の人の契約書を見つけた | サービス提供責任者が**消費生活センター**に相談 | 家庭裁判所・行政書士 |
| テレビショッピングの健康食品が毎月届く | 「**契約内容を一緒に確認しましょう**」 | すぐ処分・クーリング・オフ（通信販売は不可） |
| 健康食品が山積み、「お金が足りない」 | 「**お金の使い方について、一緒に考えてみませんか**」 | 鍵付き引き出しでヘルパーが管理・近所の人に財布を預ける |

困ったときは<strong>消費者ホットライン「188（いやや）」</strong>から最寄りの消費生活センターへつながります。お金の管理に不安が続くときは、日常生活自立支援事業や成年後見制度も検討します。
