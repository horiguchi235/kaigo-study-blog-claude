**この記事のポイント**

1. **合理的配慮**は**障害者権利条約**で初めて国際条約に。**「私たち抜きに私たちのことを決めるな」**のもとで作られた。
2. 差別解消法は**障害者基本法の理念を具体化**し、**共生社会**をめざす。**手帳の有無は問わず**、**過重な負担にならない範囲で一人ひとりに合わせて**配慮する。
3. 消費者被害は、まず**本人に経緯を聞き、契約内容を一緒に確認**。相談先は**消費生活センター**。**通信販売はクーリング・オフできない**。

## ① 障害者権利条約・障害者基本法・障害者差別解消法【社会の理解／障害の理解】

### 障害者権利条約

- **「Nothing about us without us（私たち抜きに私たちのことを決めるな）」**のもと、障害者が作成段階から関わった
- **合理的配慮**を国際条約で**初めて**取り上げた
- 日本は**2014年に批准**。そのための国内法の整備として**障害者基本法の改正（2011年）**で**社会的障壁の除去**を規定

### 障害者基本法

| ○ | × |
|---|---|
| **政府は障害者基本計画を策定**しなければならない | 障害者が自助努力で社会的障壁を解消する |
| **国**に障害者政策委員会 | 都道府県に設置義務 |
| 差別の禁止の条文は**残っている** | 差別解消法の制定で削除された |
| 防災・防犯の施策も規定 | 記述はない |

### 障害者差別解消法

| ○ | × |
|---|---|
| **障害者基本法の基本理念**を具体的に実施するため | 障害者総合支援法の理念のもと |
| **共生社会**の実現をめざす | — |
| 対象は**手帳の有無を問わず**、障害や社会的障壁で生活に制限を受ける人 | 身体障害者手帳を持つ人に限る |
| 行政機関等と事業者に**不当な差別的取扱いを禁止** | — |
| **合理的配慮**：行政機関は**法的義務**。事業者も**2024年4月から義務** | — |
| 合理的配慮は**過重な負担にならない範囲**で、**一人ひとりに合わせて** | 負担の大小に関係なく／全員に同じ配慮 |
| 個人の差別行為への**罰則はない** | 罰則規定がある |
| 障害者差別解消支援地域協議会は**組織できる**（任意） | 市町村に設置義務・民間事業者だけで組織 |
| — | 障害者が合理的配慮の提供に努める |

### 合理的配慮の具体例

| ○ 合理的配慮にあたる | × |
|---|---|
| 知的障害者の申し出を受け、**会議資料をわかりやすい言葉に直して事前に説明** | 手帳の提示を求める・手話通訳と一緒に来るよう求める・介助者同伴を求める・診断書を求める |
| 聴覚障害の学生の筆記試験で、**口頭の説明を書面で渡す** | 時間延長・文字拡大・問題を読み上げる（聴覚障害に合わない） |
| 障害の特性に応じた**休憩時間の調整** | — |
| 車いすの人に陳列棚の商品を**取って見せる** | 口頭で説明するだけ |
| 盲導犬と一緒に入店してもらう | 犬を店外に |

## ② 消費者被害とクーリング・オフ【生活支援技術／介護の基本】

### クーリング・オフ

| 取引 | 期間 |
|---|---|
| **訪問販売**・電話勧誘販売 | **8日間** |
| 訪問購入 | 8日間 |
| マルチ商法 | 20日間 |
| **通信販売** | **できない**（返品は事業者のルールによる） |
| 店舗での購入 | できない |

### 悪質商法と助言

| 商法 | ○ 助言 |
|---|---|
| **送りつけ商法** | 注文していない商品は**断り、受け取らない** |
| 点検商法 | **業者を家に入れない** |
| 催眠商法 | 会場には行かない |
| 利殖商法 | 「元本保証」でも信用しない |
| 振り込め詐欺 | **一人で対処しない**、家族や警察に相談 |

### 消費者被害にあった利用者への対応

| 場面 | ○ 正解 | × |
|---|---|---|
| 訪問販売で高価な寝具を買った認知症の人の家族 | **クーリング・オフで解除できる**ことを伝える | 他者と関わらないよう助言・施設入所・自己破産 |
| 着物を買った母のことで娘が「すぐにクーリング・オフを」 | まず**本人に買うようになった経緯を確認** | 部屋を探す・業者に連絡・浪費だと説明 |
| 認知症の人の契約書を見つけた | サービス提供責任者が**消費生活センター**に相談 | 家庭裁判所・行政書士 |
| テレビショッピングの健康食品が毎月届く | 「**契約内容を一緒に確認しましょう**」 | すぐ処分・クーリング・オフ（通信販売は不可） |
| 健康食品が山積み、「お金が足りない」 | 「**お金の使い方について、一緒に考えてみませんか**」 | 鍵付き引き出しでヘルパーが管理・近所の人に財布を預ける |

## ③ 障害者権利条約と消費者を守る法律

- **人権・障害者の権利の年表**：**1948年 世界人権宣言**（すべての人民と国が達成すべき共通の基準）→1975年 障害者の権利宣言→**1981年 国際障害者年（完全参加と平等）**→1990年 アメリカで**ADA（障害をもつアメリカ人法）**→**2006年 国連で障害者権利条約を採択**→**2014年 日本が批准**。
- **障害者権利条約**（2006年国連採択）で初めて「**合理的配慮**」が定められた。スローガンは「**私たちのことを私たち抜きに決めないで**」。日本は2007年署名、2014年批准。
- **消費者契約法**＝うそを言われた（誤認）・帰ってくれない（困惑）などで結んだ契約を**取り消せる**。**特定商取引法**＝訪問販売・電話勧誘・通信販売などのルール（クーリング・オフを含む）。
- 困ったときは**消費者ホットライン「188（いやや）」**から最寄りの消費生活センターへ。
- 差別や偏見、悪質商法、**情報が十分に伝えられないこと**も権利侵害になりうる。
