**結論を3行で**

1. **合理的配慮**は**障害者権利条約**で初めて国際条約に。**「私たち抜きに私たちのことを決めるな」**のもとで作られた。
2. 差別解消法は**障害者基本法の理念を具体化**し、**共生社会**をめざす。**手帳の有無は問わず**、**過重な負担にならない範囲で一人ひとりに合わせて**配慮する。
3. 消費者被害は、まず**本人に経緯を聞き、契約内容を一緒に確認**。相談先は**消費生活センター**。**通信販売はクーリング・オフできない**。

## ① 障害者権利条約・障害者基本法・障害者差別解消法【社会の理解／障害の理解】

### 障害者権利条約

- **「Nothing about us without us（私たち抜きに私たちのことを決めるな）」**のもと、障害者が作成段階から関わった（第33回）
- **合理的配慮**を国際条約で**初めて**取り上げた（第28回）
- 日本は**2014年に批准**。そのための国内法の整備として**障害者基本法の改正（2011年）**で**社会的障壁の除去**を規定（第35回）

### 障害者基本法（第28回）

| ○ | × |
|---|---|
| **政府は障害者基本計画を策定**しなければならない | 障害者が自助努力で社会的障壁を解消する |
| **国**に障害者政策委員会 | 都道府県に設置義務 |
| 差別の禁止の条文は**残っている** | 差別解消法の制定で削除された |
| 防災・防犯の施策も規定 | 記述はない |

### 障害者差別解消法

| ○ | × |
|---|---|
| **障害者基本法の基本理念**を具体的に実施するため（第27・36回） | 障害者総合支援法の理念のもと |
| **共生社会**の実現をめざす（第32回） | — |
| 対象は**手帳の有無を問わず**、障害や社会的障壁で生活に制限を受ける人 | 身体障害者手帳を持つ人に限る |
| 行政機関等と事業者に**不当な差別的取扱いを禁止**（第29回） | — |
| **合理的配慮**：行政機関は**法的義務**（第27回）。事業者も**2024年4月から義務** | — |
| 合理的配慮は**過重な負担にならない範囲**で、**一人ひとりに合わせて** | 負担の大小に関係なく／全員に同じ配慮 |
| 個人の差別行為への**罰則はない** | 罰則規定がある |
| 障害者差別解消支援地域協議会は**組織できる**（任意） | 市町村に設置義務・民間事業者だけで組織 |
| — | 障害者が合理的配慮の提供に努める |

### 合理的配慮の具体例

| ○ 合理的配慮にあたる | × |
|---|---|
| 知的障害者の申し出を受け、**会議資料をわかりやすい言葉に直して事前に説明**（第30・37回） | 手帳の提示を求める・手話通訳と一緒に来るよう求める・介助者同伴を求める・診断書を求める |
| 聴覚障害の学生の筆記試験で、**口頭の説明を書面で渡す**（第35回） | 時間延長・文字拡大・問題を読み上げる（聴覚障害に合わない） |
| 障害の特性に応じた**休憩時間の調整**（第36回） | — |
| 車いすの人に陳列棚の商品を**取って見せる** | 口頭で説明するだけ |
| 盲導犬と一緒に入店してもらう | 犬を店外に |

障害者差別解消法の合理的配慮に沿った対応として、最も適切なものはどれ？

1. 車いすの人から棚の商品を見せてほしいと言われ、口頭で説明した
2. 聴覚障害者の手話の注文がわからず、人気のメニューを出した
3. 盲導犬を連れた視覚障害者に、犬を店に入れないよう頼んだ
4. 人の多い所は不安だと言う精神障害者に、帰宅してもらった
5. 知的障害者の申し出で、会議の資料をわかりやすい言葉に直し、事前に口頭で説明した

<details class="answer">
<summary>正解を見る</summary>

**正解：5**　本人の申し出に応じて、参加を妨げている壁を取り除いています。1〜4は本人の希望に応えておらず、3・4は不当な差別的取扱いにもあたります。
</details>

## ② 消費者被害とクーリング・オフ【生活支援技術／介護の基本】

### クーリング・オフ

| 取引 | 期間 |
|---|---|
| **訪問販売**・電話勧誘販売 | **8日間** |
| 訪問購入 | 8日間 |
| マルチ商法 | 20日間 |
| **通信販売** | **できない**（返品は事業者のルールによる）（第26回） |
| 店舗での購入 | できない |

### 悪質商法と助言（第28回）

| 商法 | ○ 助言 |
|---|---|
| **送りつけ商法** | 注文していない商品は**断り、受け取らない** |
| 点検商法 | **業者を家に入れない** |
| 催眠商法 | 会場には行かない |
| 利殖商法 | 「元本保証」でも信用しない |
| 振り込め詐欺 | **一人で対処しない**、家族や警察に相談 |

### 消費者被害にあった利用者への対応

| 場面 | ○ 正解 | × |
|---|---|---|
| 訪問販売で高価な寝具を買った認知症の人の家族（第30回） | **クーリング・オフで解除できる**ことを伝える | 他者と関わらないよう助言・施設入所・自己破産 |
| 着物を買った母のことで娘が「すぐにクーリング・オフを」（第27回） | まず**本人に買うようになった経緯を確認** | 部屋を探す・業者に連絡・浪費だと説明 |
| 認知症の人の契約書を見つけた（第32回） | サービス提供責任者が**消費生活センター**に相談 | 家庭裁判所・行政書士 |
| テレビショッピングの健康食品が毎月届く（第36回） | 「**契約内容を一緒に確認しましょう**」 | すぐ処分・クーリング・オフ（通信販売は不可） |
| 健康食品が山積み、「お金が足りない」（第38回） | 「**お金の使い方について、一緒に考えてみませんか**」 | 鍵付き引き出しでヘルパーが管理・近所の人に財布を預ける |
