**この記事のポイント**

1. 入浴の作用は**温熱・静水圧・浮力**の3つ。「静水圧＝むくみが減る」「浮力＝体が軽い・関節を動かしやすい」をセットで覚える。
2. **中温浴（38〜41℃）＝リラックス**（副交感神経）、**高温浴（42℃以上）＝興奮**（交感神経・血圧上昇）。正反対になる。
3. 事故を防ぐ3原則は「**温度差を小さく**」「**急に立ち上がらない**」「**食直後・空腹時は避ける**」。

## ① 入浴の3つの作用と湯温

| 作用 | 体に起きること | 試験での正解例 | 注意点 |
|---|---|---|---|
| **温熱作用** | 血管が広がり血行がよくなる、筋肉がほぐれる | 血行促進・筋肉の緊張をほぐす | 長く入ると疲れる・のぼせる |
| **静水圧作用** | 水の圧力で体が締めつけられる | **下肢のむくみが軽減**する | 心臓に戻る血液が増えて**心臓に負担**、胸やお腹が押されて**呼吸にも負担** |
| **浮力作用** | 首までつかると体重が**約1/10**に感じられる | 「**からだが軽く感じる**」、**浴槽内で関節運動を促す** | 体が浮いて**姿勢が不安定**になり、転倒しやすい |

> 静水圧は心臓への負担になるので、心臓病の人は**半身浴**（水位は**みぞおち**まで＝心臓より下）にします（→②）。このほか、気持ちが落ち着く**精神的な作用**（リラックス）もあります。

### 中温浴と高温浴は「正反対」

| | 中温浴（38〜41℃） | 高温浴（42℃以上） |
|---|---|---|
| 自律神経 | **副交感神経**が優位（リラックス） | **交感神経**が優位（興奮） |
| 血圧 | 下がる | **上がる** |
| 筋肉 | ゆるむ | **収縮する** |
| 胃腸 | **消化機能が高まる** | 腸の動きが**抑えられる** |
| 腎臓 | **働きが促進**される | 抑えられる |

**覚え方**：交感神経は「戦う・逃げる」ときの神経、副交感神経は「休む・食べる・出す」ときの神経。中温浴は副交感神経側、高温浴は交感神経側です。高齢者が熱いお湯を好むときは、**血圧が上がる**ことを説明します。

### 体温（入浴前の体調確認に）

- 体温調節の中枢は脳の**視床下部**
- 体温は**早朝に最も低く**、夕方に高い。腋窩温（わきの下で測る体温）は口腔温より**低い**
- 第33回：エアコンのない夏の部屋で、**厚手の布団**をかけて寝ていて38.5℃ → 原因は**布団**（うつ熱＝熱が体にこもって体温が上がること。病気の発熱とは別）

## ② 安全な入浴と、状態に応じた入浴

### 入浴事故を防ぐ基本

温まると血管が広がって血圧が下がっているので、**急に立つと脳への血液が減り**、立ちくらみや失神（脳貧血）を起こします。逆に、寒い脱衣室から熱い湯に入ると**血圧が急に上下**します。これが**ヒートショック**です。

| ○ | × |
|---|---|
| 浴室・脱衣室と居室の**温度差を小さく**する（脱衣室も22℃前後に暖める） | 湯温を高めにする／冬だけ気をつければよい |
| 浴槽からは**ゆっくり**立ち上がる | 声をかけて急に立ってもらう（**血圧が下がり**ふらつく） |
| **食直後と空腹時**の入浴は避ける | 食後すぐ入浴する |
| 入浴前に**排泄**と体調の確認をすませる | — |
| 入浴前後に**水分補給**をする | 水分を控える（汗で脱水になる） |
| 湯温は**介護福祉職が先に**肌で確かめ、次に利用者に確かめてもらう | 利用者が先に確かめる |
| かけ湯は**手足の先（心臓から遠い所）から** | 体の中心（胸・肩）からかける |
| 湯につかるのは**短め**（長湯をしない） | 長く温まるほどよい |
| 入浴前の血圧が普段より高ければ**入浴を見合わせる**（医療職に相談） | 自覚症状がなければ入浴を勧める |

> 家庭内の不慮の事故死では、入浴に関係するものが**多い**です。ヒートショックは**冬**、**入浴中から入浴後**に起こりやすく、高血圧の人ほど注意が必要です。

### 状態に応じた入浴

| 状態 | ○ 正解 | × |
|---|---|---|
| 心疾患・高血圧 | **半身浴**（水位は**みぞおち**まで）、長湯しない | 肩まで・43℃以上・20分 |
| 血液透析 | **透析直後の入浴は控える**（針を刺した所からの出血・感染、血圧低下のおそれ） | 透析直後に入浴 |
| ペースメーカー（心臓のリズムを整える機械を胸に埋め込む） | 普通に入浴できる（**電気風呂は避ける**） | シャワー浴に限る |
| 胃ろう（お腹から胃に通した管で栄養をとる） | 入浴できる | 入浴を控える |
| 消化管ストーマ（お腹につくった便の出口） | **装具を外しても**入浴できる（湯は体内に入らない）。排泄の多い食後1時間以内は避ける | — |
| 在宅酸素療法（家で酸素を吸う治療） | **鼻カニューレ（鼻に当てる酸素の管）をつけたまま** | 外して入浴 |

## ③ 浴槽内で具合が悪くなったとき・入浴方法の選び方

- **浴槽内で意識がもうろうとしたら**：顔が湯につからないよう**あごを上げて支え**、**浴槽の栓を抜いて水位を下げ**、応援を呼ぶ。呼吸に異常があれば救急要請。
- **シャワー浴**は体力の消耗が少ない一方、温まりにくい。浴後はすぐ拭く（水分が残ると気化熱で冷える）。
- 寝たまま入浴するのは**特殊浴槽（ストレッチャー浴）**、座れる人は**リフト浴**（手順は[入浴介助・部分浴・清拭・洗髪の手順](../nyuyoku-02-kaijo/)）。
