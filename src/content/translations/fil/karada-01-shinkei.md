**Mahahalagang punto ng artikulong ito**

1. Cerebrum: “**frontal lobe = paggalaw**”, “**parietal lobe = pandama ng balat**”, “**temporal lobe = pandinig**”, “**occipital lobe = paningin**” (前頭葉・頭頂葉・側頭葉・後頭葉). **Amygdala = emosyon, hippocampus = alaala, medulla = paghinga** (扁桃体・海馬・延髄).
2. **Sympathetic nerves = katawang handang lumaban (tibok ng puso ↑, kumikitid ang ugat, lumalaki ang pupil, pagtunaw ↓)**; **parasympathetic nerves = katawang nagpapahinga (pagtunaw ↑)** (交感神経・副交感神経).
3. **Katarata = paglabo ng lens** (白内障＝水晶体の濁り). Ang ossicles ng gitnang tainga = **malleus, incus, stapes** (ツチ骨・キヌタ骨・アブミ骨).

## ① Utak at nerbiyos

### Paghahati ng gawain ng cerebrum (大脳の機能局在)

| Bahagi | Pangunahing gawain |
|---|---|
| **Frontal lobe** (前頭葉) | **Motor area** (運動野), motor speech area (**Broca's area**, ブローカ野), pag-iisip at motibasyon |
| **Parietal lobe** (頭頂葉) | **Somatosensory area (sakit, temperatura at hipo sa balat)** (体性感覚野) |
| **Temporal lobe** (側頭葉) | **Auditory area** (聴覚野), sensory speech area (**Wernicke's area**, ウェルニッケ野), alaala |
| **Occipital lobe** (後頭葉) | **Visual area** (視覚野) |

<fig name="nou" caption="Ang utak kung titingnan mula sa kaliwa (nasa kaliwa ang mukha). **Frontal lobe = paggalaw, motibasyon, Broca's area (pagsasalita)**, **parietal lobe = pandama ng balat**, **temporal lobe = pandinig, Wernicke's area (pag-unawa)**, **occipital lobe = paningin**. **Cerebellum = balanse**, **medulla = sentro ng paghinga**. Tandaan din ang **hippocampus = alaala** at **amygdala = emosyon** na nasa loob ng utak.">

### Iba pang bahagi ng utak

| Bahagi | Gawain |
|---|---|
| **Amygdala** (扁桃体) | **Emosyon tulad ng takot, pagkabalisa at saya** (情動) |
| **Hippocampus** (海馬) | **Alaala** (pag-alala ng bagong bagay). Hindi paningin |
| **Cerebellum** (小脳) | **Balanse ng katawan at pag-aayos ng galaw** |
| **Medulla oblongata** (延髄) | **Sentro ng paghinga** (呼吸中枢), sentro ng puso, paglunok |
| Hypothalamus (視床下部) | Sentro ng temperatura ng katawan, gana sa pagkain at autonomic nerves |
| Pituitary gland (下垂体) | Control tower ng paglabas ng hormone |

## ② Autonomic nerves, hormone at mga organ

| Epekto | Sympathetic (aktibo, tensyonado) 交感神経 | Parasympathetic (pahinga, relaks) 副交感神経 |
|---|---|---|
| Tibok ng puso | **Tumataas** | Bumababa |
| Ugat ng dugo | **Kumikitid** → tumataas ang presyon | Lumuluwag |
| Pupil | **Lumalaki** (散大) | Lumiliit (縮小) |
| Daanan ng hangin | Lumuluwag | Kumikitid |
| Pagtunaw | Pinipigilan | **Pinabibilis** |
| Asukal sa dugo | Tumataas | — |

### Gawain ng mga organ

| Organ | ○ Gawain | × |
|---|---|---|
| **Pancreas** (膵臓) | **Insulin** mula sa **islets of Langerhans** (nagpapababa ng asukal sa dugo) | Adrenal glands ang gumagawa ng insulin |
| **Atay** (肝臓) | **Nag-iimbak ng glycogen**, nag-aalis ng lason, gumagawa ng apdo | — |
| Bato (腎臓) | Gumagawa ng ihi at **nagpapakonsentra ng ihi** | Pantog ang nagpapakonsentra ng ihi |
| Baga (肺) | **Palitan ng gas** | Puso ang nagpapalitan ng gas |

## ③ Mga pandama at pagbigkas

### Mata

| Sakit / pagbabago | Punto |
|---|---|
| **Katarata** (白内障) | **Lumalabo at pumuputi ang lens** (水晶体). Nasisilaw at malabo ang tingin |
| Glaucoma (緑内障) | **Tumataas ang presyon sa mata at kumikitid ang nakikita** (眼圧・視野). Maaari ring sumakit ang mata at ulo |
| Age-related macular degeneration (加齢黄斑変性症) | **Baluktot o madilim ang gitna ng gustong tingnan** |
| Diabetic retinopathy (糖尿病性網膜症) | Pagdurugo sa retina; sanhi ng pagkabulag |
| **Epidemic keratoconjunctivitis** (流行性角結膜炎) | **Pamumula ng mata** (結膜の充血) at muta. **Napakadaling makahawa** |
| Pagtanda | **Mas matagal masanay sa liwanag at dilim**, mahirap makakita ng malapit, mabagal mag-focus, nagiging madilaw ang lens, kumokonti ang luha |

<fig name="me" caption="Ang mata kung titingnan mula sa gilid (pumapasok ang liwanag mula sa kaliwa). Dumadaan ang liwanag sa **cornea → pupil → lens → vitreous body → retina** (角膜 → 瞳孔 → 水晶体 → 硝子体 → 網膜). **Katarata = malabong lens**, **glaucoma = nasisira ang optic nerve, halimbawa dahil sa presyon sa mata, kaya nawawala ang bahagi ng nakikita**, **age-related macular degeneration = nasisira ang gitna ng retina (macula) kaya baluktot o mahirap makita ang gitna**.">

### Tainga, ilong at pagbigkas

<fig name="mimi" caption="Hiwa ng kanang tainga kung titingnan mula sa harap. Dumadaan ang tunog sa **auricle → ear canal → eardrum → ossicles (gitnang tainga) → cochlea (panloob na tainga) → utak**. **Conductive hearing loss (伝音性難聴) = problema sa panlabas o gitnang tainga** (madaling makatulong ang hearing aid). **Sensorineural hearing loss (感音性難聴, kasama ang dahil sa edad) = problema sa panloob na tainga o lampas pa**; unang nahihirapang marinig ang **matataas na tunog**. **Semicircular canals at vestibule = balanse**.">

| ○ | × |
|---|---|
| Ang **ossicles** (耳小骨) ng gitnang tainga = **malleus, incus, stapes** (ツチ骨・キヌタ骨・アブミ骨) | Sphenoid, frontal at cheek bone (mga buto ng ulo) |
| **Inaalis ng balahibo sa ilong ang alikabok**. Maraming capillary ang nasal cavity (鼻腔) at pinaiinit at pinababasa nito ang hangin | Nasa butas ng ilong ang mga selula ng pang-amoy (talagang nasa itaas ng nasal cavity) / direktang konektado ang nasal cavity sa larynx (talagang dumadaan sa pharynx) |
| **Kung hindi maisara nang maayos ang labi**, nagiging malabo ang pagbigkas | Pagdami ng laway, aktibong galaw ng dila, maayos na pustiso |

## ④ Utak, hormone, buto at kalamnan, paghinga

- **Paano gumagana ang mata**: **iris** (虹彩) = binabago ang laki ng pupil para ayusin ang dami ng liwanag / **lens** (水晶体) = nagfo-focus / **retina** (網膜) = tumatanggap ng liwanag at ginagawa itong senyales ng nerbiyos. **Glaucoma** (緑内障) = sakit na sumisira sa optic nerve; ang **pagtaas ng presyon sa mata** ay isa sa mga sanhi (nawawala ang bahagi ng nakikita).
- **Problema sa nakikita**: **concentric narrowing ng visual field** (求心性視野狭窄) = **nakikita ang gitna pero hindi ang paligid** (hal. retinitis pigmentosa, 網膜色素変性症) / central scotoma (中心暗点) = hindi nakikita ang gitna / hemianopia (半盲) = nawawala ang kaliwa o kanang kalahati ng nakikita.
- Nahahati ang **cerebrum** sa **4 na lobe: frontal, parietal, temporal at occipital**. Ang ibabaw (cortex) = grey matter; ang loob (medulla) = white matter. **Cerebellum** = balanse at pag-aayos ng galaw / **brainstem** (脳幹: midbrain, pons, medulla) = paghinga at sirkulasyon / **hypothalamus** = temperatura ng katawan, gana at autonomic nerves.
- Mga 1,300 g ang bigat ng utak. **Medulla = sentro ng paghinga at sirkulasyon** (“nasa cerebellum ang sentro ng paghinga” ay ×). **Cerebellum = balanse at pag-aayos ng galaw** (kapag nasira, nagkakaroon ng ataxia, 運動失調). **Hippocampus = alaala**.
- Hormone: **pineal body → melatonin** (nagpapaantok), **posterior pituitary → vasopressin** (nagpapabawas ng ihi = antidiuretic), **thyroid → nagpapataas ng metabolismo**, **adrenal medulla → adrenaline** (nagpapataas ng tibok ng puso, presyon at asukal sa dugo), **adrenal cortex → cortisol** (humaharap sa stress), **β cells ng pancreas → insulin** (nagpapababa ng asukal sa dugo), α cells → glucagon (nagpapataas).
- Gawain ng buto: sumusuporta, nagpoprotekta, gumagalaw, **gumagawa ng dugo (bone marrow, 骨髄)**, **nag-iimbak ng calcium**. Kapag laging nakahiga, natutunaw palabas ng buto ang calcium.
- Kalamnan: **skeletal muscle = voluntary muscle** (骨格筋＝随意筋); **smooth muscle** (lamang-loob, ugat ng dugo) at **kalamnan ng puso = involuntary muscle** (不随意筋).
- **Konektado sa pharynx** ang gitnang tainga sa pamamagitan ng Eustachian tube (耳管), kaya madaling mauwi sa impeksyon sa gitnang tainga (中耳炎) ang sipon.
- **Mas malapad, mas maikli at mas matarik ang kanang bronchus kaysa sa kaliwa** → madaling pumasok sa kanang baga ang nalunok na bagay. 3 lobe ang kanang baga at 2 ang kaliwa.

## Mga pattern ng bitag (halos laging ×)

| Pananalita sa pagpipilian | Bakit × |
|---|---|
| Nasa cerebellum o cerebrum ang sentro ng paghinga | Nasa medulla |
| Nasa parietal lobe ang motor area | Frontal lobe |
| Ang hippocampus ay para sa paningin | Alaala. Ang paningin ay sa occipital lobe |
| Facial nerve ang pandama ng mukha | Trigeminal nerve |
| Pinabibilis ng sympathetic ang pagtunaw / pinaliliit ang pupil | Epekto iyon ng parasympathetic |
| Lumalabo ang vitreous body o retina sa katarata | Ang lens |
