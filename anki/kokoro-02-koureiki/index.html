この記事のポイント

  1. 流動性知能（新しい問題を解く）は加齢で下がりやすく、結晶性知能（経験・知識）は保たれる。
  2. ライチャードの5類型は事例で出る：満足＝円熟型、若さにこだわり世話を拒む＝装甲（自己防衛）型。
  3. キューブラー・ロスは「否認 → 怒り → 取り引き → 抑うつ → 受容」。「なぜ私が」＝怒り、「我慢するので助けて」＝取り引き。

② エイジング理論・エイジズム・高齢期の適応

用語意味
エイジズム高齢を理由にした偏見や差別。例：「年をとると頑固になる」
サクセスフル・エイジング老いの変化に工夫して適応し、よく生きる。例：難聴があるので補聴器をつけてパソコン教室へ。長生き・生活の質（QOL）が高い・社会への貢献を合わせて考え、本人の主観的な幸福感を大切にする（「長生きだけが目的」は×）
アンチエイジングいつまでも若い心と体を保とうとする（加齢に抵抗する）考え方。エイジズムとは別のもの
プロダクティブ・エイジングバトラーが提唱。高齢者も社会に貢献する存在。セルフケアも生産的な活動に含む
アクティブ・エイジングWHOが提唱。健康・参加・安全の機会を最大にして、年をとっても生活の質を高める
活動理論活動を続けるほど幸福
離脱理論社会から少しずつ離れるのが自然
継続性理論それまでの生き方・役割・習慣を続けることで老いに適応する
社会情動的選択理論カーステンセンが提唱。残りの時間を意識すると、親しい人との関係を選んで大切にする

喪失志向回復志向

キューブラー・ロスの死の受容過程

段階例言い換え（選択肢での書かれ方）
① 否認「自分が死ぬはずがない」ショックから自分を守るため、事実を打ち消す
② 怒り「どうして私だけががんにならなければならないのか」周りの人に怒りを向ける（訪問介護員に「もう来なくていい」）
③ 取り引き「つらい治療を我慢するので助けてほしい」神や仏に祈る・奇跡を願う。「〜するから助けて」
④ 抑うつ「もう助からない」と絶望する死が避けられないと知り、さまざまな喪失感を抱いて落ち込む
⑤ 受容安らかに死を受け入れる静かに死を受け入れ、心が穏やかになる

受容・悲嘆のモデルの見分け方

モデル誰の何を表すか段階・考え方
キューブラー・ロス死にゆく本人が死を受け入れる過程否認 → 怒り → 取り引き → 抑うつ → 受容
上田敏障害を負った本人の受容ショック → 否認 → 混乱 → 解決への努力 → 受容
認知症の人の家族介護する家族の受け止め戸惑い・否定 → 混乱・怒り・拒絶 → 割り切り・あきらめ → 受容（→ 家族支援）
ボウルビィ愛する人を亡くした人の悲嘆無感覚 → 思慕と探求 → 混乱と絶望 → 再建
ストローブとシュト死別のあとの対処のしかた喪失志向と回復志向を行き来する

老年期うつ病

○ 老年期うつ病の特徴×
抑うつ気分より、頭痛・腰痛・だるさなど体の訴えが目立つ（仮面うつ病）気分の落ち込みを必ず強く訴える
もの忘れなど認知症に似た症状が出る（仮性認知症）認知症と見分ける必要はない
自殺を図ると亡くなる率が高い。回復しかけの時期も自殺のサインに注意高齢者の自殺は少ない
安易に励まさない。休養と受診につなぐ「がんばって」と励ます
きっかけは環境の変化・喪失体験のほか、脳の病気・パーキンソン病・糖尿病などの体の病気もある。50〜60歳代の初老期にも起こりやすい原因は気持ちの問題だけ
若い人より長引きやすく、再発しやすい。認知症の危険因子にもなる一度治れば再発しない
気分の落ち込みより、すぐ泣く・怒るなど、感情を抑えにくい形で出ることがある—
