① 報告・申し送り・苦情

報告・連絡・相談（報連相）

中身
報告指示された仕事の結果や経過を、指示した人に伝える
連絡関係する人に事実や予定を知らせる。簡潔に。日中だけでなく夜間や緊急時に誰へどの方法で連絡するかを前もって確かめておく
相談判断に迷うときに意見を求める。目的をはっきりさせ、資料と自分なりの考えを準備し、結果も報告する

報告では、いつ・どこで・誰が・何を・なぜ・どのように（5W1H）を落とさないようにします。

報告のルール

○×
結論を述べてから経過を説明詳しい状況から話す
指示を受けた業務は指示者に報告指示者以外にだけ伝える
時間がかかるときは途中で報告完了後にまとめて
事実を具体的に、推測は推測として抽象的な言葉／推測を事実として
事故・苦情・緊急のときは上司の都合を待たずすぐタイミングは上司に合わせる／軽微な事故は後日
記録したことも口頭で報告書けば口頭は不要

何を先に報告する？　迷ったら、命や病状の悪化にかかわる変化を優先します。

状態優先して伝える変化
心不全体重の増加・むくみ・息切れ（体に水がたまったサイン）
脱水・下痢が続く意識の状態・尿の量
糖尿病冷や汗・ふるえ（低血糖）

いつもとの違いは、「体重が先週より2kg増えた」のように数値や具体的な様子で伝えます。病気ごとのサインは → 心臓・糖尿病・肺炎・脱水

判断は言ってよい？　「事実→判断」の順で分ける

報告で×になるのは、事実の代わりに判断だけを言うことです。見たまま・聞いたままの事実を先に伝え、自分の判断は「〜と思います」と分けて添えるのは○です。

解釈・判断だけの言い方（×）見たままの言い方（○）
「もの盗られ妄想があります」「『財布を盗まれた』と言って、ベッドの周りを歩き回っていました」
「少しだけ吐きました。かわいそうでした」「本日朝6時に、少量の胃液を嘔吐しました」
「認知機能が低下しました」「今朝は、いつもできている歯みがきの手順がわからない様子でした」

報告の話し方の例：「Aさんが転倒しました（結論）。10時ごろ、トイレから戻る途中に廊下でしりもちをつきました（経過）。右の腰を痛がっていますが、出血はありません（状態）。念のため看護師に見てもらうのがよいと思います（自分の判断）。」

第35回：コミュニケーション技術

Eさん（87歳、女性、要介護3）は、介護老人福祉施設に入所していて、認知症（dementia）がある。ある日、担当のF介護福祉職がEさんの居室を訪問すると、Eさんは、イライラした様子で、「私の財布が盗まれた」と言ってベッドの周りをうろうろしていた。一緒に探すと、タンスの引き出しの奥から財布が見つかった。

F介護福祉職は、Eさんのケアカンファレンス（care conference）に出席して、この出来事について情報共有することにした。

Eさんの状況に関する報告として、最も適切なものを1つ選びなさい。

  1. 「Eさんの認知機能が低下しました」
  2. 「Eさんは、誰かに怒っていました」
  3. 「Eさんには、もの盗られ妄想があります」
  4. 「Eさんは、財布が見つかって、安心していると思います」
  5. 「Eさんは、財布が盗まれたと言って、ベッドの周りをうろうろしていました」

出典：第35回 介護福祉士国家試験（コミュニケーション技術）

② カンファレンス・事例検討・ブレインストーミング

会議・話し合いの種類

名前誰が開く・何のため
申し送り勤務の交代で、ケアの継続性を保つ
ケアカンファレンス施設などで、利用者のケアを関係者が話し合う（計画の立案・修正・評価。スーパービジョンの場にもなる）
事例検討（会）事例の課題をチームで共有し、解決策を見いだす（外部で行うときは匿名化）
サービス担当者会議介護支援専門員が招集し、ケアプラン（原案）を本人・家族・サービス担当者で検討する。開く場所が病院でも、ケアマネが在宅サービスを検討するために集めればこれ
退院前カンファレンス入院先の病院が中心になり、退院後の生活に向けて病院の職員と在宅の支援者が情報を共有する
地域ケア会議地域包括支援センターや市町村が開き、個別のケースから地域の課題を見つける
  • インフォーマルなサポート＝家族・近所・ボランティアなど、制度によらない支え。カンファレンスで検討する内容は、これに限りません。

カンファレンスへの参加

カンファレンス（ケアカンファレンス）は、利用者の支援について関係者が集まって話し合う会議です。利用者本人・家族が参加することもあります。

チームには、介護職どうしのチームと、医師・看護師・リハビリ職・管理栄養士などとの多職種チームがあります。多職種チームでの介護福祉職は、利用者の毎日の生活をいちばんよく知る専門職として、日常の様子を伝え、生活の視点から意見を出す役割を担います。だから「医師や施設長に合わせる」は×です。

○×
各職種の専門性を理解して参加経験年数の長い人に従う／自分の思いにこだわる
意見の不一致があっても議論して合意点を見いだす施設長・医師・多数意見に合わせる／多数決
利用者本人の参加を促し、意向をケア方針に反映本人抜きで決める
少数意見も大事にし、根拠をもって意見を言う対立を避けて他職種に反論しない／介護職への批判中心

上の表のほかに出る×（理由つき）は、ひっかけパターン集にまとめました。

用語は「使う」？「避ける」？

  • 記録：利用者・家族も読み、職種もさまざまなので、誰でもわかる言葉で書く（専門用語や略語は避ける）。
  • チーム内の話し合い：専門用語を使うときは、意味をチームでそろえて使う（記録や言葉で確かめ合う）。

事例検討・チーム

  • 事例検討の目的＝チームで事例の課題を共有し、解決策を見いだす
  • リーダーは指示だけでなく、メンバーの経験に応じて裁量を認める。リーダーシップとフォロワーシップはケアマネジメント・多職種連携・人材育成で扱います。
  • カンファレンスは、先輩などから助言・指導を受けるスーパービジョンの機会にもなる。
  • スーパービジョン＝同じ職場の熟練者（スーパーバイザー）が、経験の浅い職員を管理・教育・支持の面から支える。コンサルテーション＝ほかの分野の専門家（医師・作業療法士・弁護士など）に専門的な助言を求めること。助言を受けた側が、自分の判断で取り入れます。

ブレインストーミングの4原則

ブレインストーミング＝アイデアを自由にたくさん出し合う会議の方法です。

原則中身
批判禁止他人の意見をその場で判断・批判しない
自由奔放奇抜な意見も歓迎
質より量数多くの意見を出す
結合・便乗他人の意見を参考にして発展させる
