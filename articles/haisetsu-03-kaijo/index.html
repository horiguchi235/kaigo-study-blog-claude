この記事のポイント

  1. ポータブルトイレは健側に置き、前かがみで座ってもらう。
  2. 陰部は前から後ろへ（尿道口 → 肛門）。湯はぬるま湯、おむつは汚れを内側に丸める。
  3. 排泄の問題は「転ばせない」「感染させない」「恥ずかしい思いをさせない」の3つで判断する。

手順の暗記に見えますが、ほとんどの正解は上の3つの視点から導けます。迷ったら「この選択肢は転倒・感染・羞恥のどれかを防いでいるか」を考えてみてください。

① トイレ・ポータブルトイレでの介助

場面○ 正解× よく出る不正解
置く場所健側に置く（健側の手足で移乗できる）患側に置く
座り方前かがみで、足の裏を床につける背もたれに寄りかかる
移乗した直後座位が安定しているか確認する確認せずにその場を離れる
終わったら立ち上がる前に、下着・ズボンを大腿部まで上げておく立ち上がってから全部上げる
排泄中声をかけてもらえるようにして、そばを離れる後ろに立って待つ
床防水シートなど滑りにくいもの新聞紙を敷く（滑る）
片付け排泄物はそのつど処理する1日分まとめて片付ける
夜間に間に合わない人夜間だけポータブルトイレを使う一日中リハビリパンツ／水分を減らす

理由とセットで覚える

  • 立ち上がる前に衣類を上げておく → 立っている時間が短くなり、転倒を防げる
  • 前かがみ → 腹圧がかかって出しやすく、座位も安定する

第37回：生活支援技術

ポータブルトイレを使うときの介護として、最も適切なものはどれ？

  1. 下に新聞紙を敷く
  2. ベッドに寝た状態でズボンや下着をおろす
  3. 前かがみになって座ってもらう
  4. 終わるまでポータブルトイレの後ろに立って待つ
  5. 排泄後の陰部の清拭はベッドの上で行う
正解を見る

正解：3　前かがみの姿勢は腹圧がかかりやすく排便しやすい。待つときは見えない位置で、終わったら呼んでもらいます。

第36回：生活支援技術

夜間、自宅のトイレに間に合わず失敗してしまう高齢者への助言として、最も適切なものはどれ？

  1. 水分を減らすよう勧める
  2. 1日中リハビリパンツを使うよう勧める
  3. 睡眠薬を飲むよう勧める
  4. 泌尿器科の受診を勧める
  5. 夜間はポータブルトイレを使うよう勧める
正解を見る

正解：5　「間に合わない」ならトイレまでの距離を縮める＝夜間はベッドのそばにポータブルトイレ。

② 差し込み便器・尿器・おむつ・陰部洗浄

差し込み便器・尿器

  • 使う前に便器を温めておく（冷たいと便意が引っ込む）
  • 両膝を立てて腰を上げてもらい、肛門が便器の中央に来るように当てる（仙骨部をふちに当てるのは×：痛み・褥瘡の原因）
  • 便器の中にトイレットペーパーを敷く（音とはね返りを防ぐ）。男性は尿器も一緒に準備する
  • 当てたら、上半身を起こす（ベッドを水平にするのは×：腹圧がかからない）
  • 排泄中は一人にして、終わったら呼んでもらう

おむつ交換

  • 排泄の有無は、手袋をして確認する（素手で触れるのは×）
  • 外したおむつは、汚れを内側に丸めて片付ける
  • 他の利用者がいる場所で「おむつを替えますよ」と言わない
  • 尿取りパッドを何枚も重ねない（ムレ・皮膚トラブルの原因）
  • 汚れた手袋は、衣類を整える前に外す

陰部洗浄・清拭

  • 湯はぬるま湯（温度は介護者の前腕の内側で確認する）
  • 女性は前から後ろへ：尿道口 → 肛門（逆にすると大腸菌が尿道に入り、尿路感染の原因になる）
  • 石けんは毎回は使わない。こすらず、やさしく洗う
  • 排便がなくても、殿部の清拭は省略しない
✏️ 過去問を解いてみよう（第35回：生活支援技術）

女性のおむつ交換で行う陰部洗浄の基本として、最も適切なものはどれ？

  1. 湯の温度は介護職の手のひらで確かめる
  2. 交換のたびに石けんで洗う
  3. タオルでこすり取るように洗う
  4. 尿道口から洗い、最後に肛門部を洗う
  5. 洗ったあとは蒸しタオルで拭く
正解を見る

正解：4　前（尿道口）から後ろ（肛門）へ。大腸菌が尿道に入るのを防ぎます。湯温は手首の内側などで確認し、こすらず押さえ拭きします。

④ ポータブルトイレ・差し込み便器・尿器・おむつの使い方

  • ポータブルトイレ：足の裏を床につけ、少し前かがみにすると腹圧がかけやすい。片麻痺の人は健側の力を生かして移乗。
  • 差し込み便器（男性）：排便のときは尿も出やすいので、尿器も一緒に用意する。
  • 差し込み便器（女性）：尿が飛び散らないよう、トイレットペーパーを陰部に当てる。
  • ベッド上の排泄も、できる範囲で上半身を起こすと出しやすい。露出は最小限に、保温とプライバシーに配慮。
  • ポータブルトイレは片麻痺の人ならベッドの健側の足元に置き、座ったとき足底が床につく高さ。種類＝プラスチック製（軽い）・木製いす型（安定・蹴込みあり）・コモード型（高さ調節・掃除しやすい）。移乗時に動かないよう滑り止めマット。
  • 差し込み便器：トイレットペーパーを敷いて跳ね返りを防ぎ、肛門が便器の中央にくるように。ベッドの上体を上げると腹圧がかけやすい。男性は尿器も用意、女性はペーパーを恥骨部から垂らして尿の飛び散りを防ぐ。
  • 尿器：男性は側臥位、女性は仰臥位で膝を閉じ、受尿口を陰部に密着。
  • 紙おむつ：テープは上は下向き・下は上向きに留め、おなかとの間は指2本分、鼠径部は締めすぎない。布おむつは女性は後ろ側、男性は前側を厚く。
