この記事のポイント

  1. ポータブルトイレは健側に置き、前かがみで座ってもらう。
  2. 陰部は前から後ろへ（尿道口 → 肛門）。湯はぬるま湯、おむつは汚れを内側に丸める。
  3. 排泄の問題は、本人が「転ばずに」「清潔に（感染せずに）」「恥ずかしい思いをせずに」排泄できるか、の3つで判断する。

手順の暗記に見えますが、ほとんどの正解は上の3つの視点から導けます。迷ったら「この選択肢は転倒・感染・羞恥のどれかを防いでいるか」を考えてみてください。

① トイレ・ポータブルトイレでの介助

介護保険で住まいや用具をそろえる方法は3つあります。工事が必要なもの＝住宅改修、借りるもの＝福祉用具貸与、肌に触れるので買うもの＝特定福祉用具販売（ポータブルトイレ・腰掛け便座など）。くわしくは③で整理します。

  • 前かがみ → 腹圧がかかって出しやすく、座位も安定する

ポータブルトイレの種類：プラスチック製（軽くて動かしやすい）、木製いす型（安定する。足を後ろに引ける蹴込みのあるものは立ち上がりやすい）、コモード型（いす型で高さを調節でき、掃除しやすい）。

第37回：生活支援技術

次の記述のうち、ポータブルトイレを使用するときの排泄の介護として、最も適切なものを1つ選びなさい。

  1. ポータブルトイレの下に新聞紙を敷く。
  2. ベッドで臥床（がしょう）している状態で、ズボンや下着をおろす。
  3. ポータブルトイレには、前かがみになって座ってもらう。
  4. 排泄（はいせつ）が終わるまで、ポータブルトイレの後ろに立って待つ。
  5. 排泄後（はいせつご）の陰部の清拭は、ベッドの上で行う。

出典：第37回 介護福祉士国家試験（生活支援技術）

正解を見る

正解：3　前かがみの姿勢は腹圧がかかりやすく排便しやすい。待つときは見えない位置で、終わったら呼んでもらいます。1の新聞紙は滑りやすく、2の衣類は、ポータブルトイレの前で立ったときにおろすのが基本（寝たままでは本人ができることを使えない）、5の清拭はポータブルトイレに座ったまま行うほうが移乗の回数が減ります。

第36回：生活支援技術

夜間、自宅のトイレでの排泄（はいせつ）が間に合わずに失敗してしまう高齢者への介護福祉職の助言として、最も適切なものを1つ選びなさい。

  1. 水分摂取量を減らすように勧める。
  2. 終日、リハビリパンツを使用するように勧める。
  3. 睡眠薬を服用するように勧める。
  4. 泌尿器科を受診するように勧める。
  5. 夜間は、ポータブルトイレを使用するように勧める。

出典：第36回 介護福祉士国家試験（生活支援技術）

正解を見る

正解：5　「間に合わない」ならトイレまでの距離を縮める＝夜間はベッドのそばにポータブルトイレ。水分を減らすと脱水に、終日のリハビリパンツや睡眠薬は自立を妨げ、原因（距離）の解決になりません。

② 差し込み便器・尿器・おむつ・陰部洗浄

差し込み便器・尿器

  • 使う前に便器を温めておく（冷たいと便意が引っ込む）
  • 両膝を立てて腰を上げてもらい、肛門が便器の中央に来るように当てる（仙骨部〔お尻の中央の平たい骨のあたり〕をふちに当てるのは×：痛み・褥瘡の原因）
  • 便器の中にトイレットペーパーを敷く（音とはね返りを防ぐ）。男性は排便のとき尿も出やすいので尿器も一緒に準備する。女性は尿が飛び散らないよう、トイレットペーパーを恥骨部（下腹部のいちばん下）から陰部に垂らしておく
  • 当てたら、上半身を起こす（ベッドを水平にするのは×：腹圧がかからない）
  • 排泄中は一人にして、終わったら呼んでもらう。露出は最小限にし、保温する
  • 尿器：男性は側臥位でも使える。女性は仰臥位で膝を閉じ、受尿口を陰部に密着させる

おむつの選び方

  • おむつは尿意・便意がない場合に使うのが基本です。使っていても、おむつを外せないかを考え続けます
  • 布おむつ＝湿気をよく吸い、ゴミが出ないが、洗濯の手間がかかり、濡れると不快。紙おむつ＝水をよく吸い、種類が多く衛生的だが、ゴミが出て費用がかかる
  • 体型・動ける程度・尿量で選び、昼と夜で使い分けてもかまいません。紙おむつはおむつカバーから1〜2cm内側にセットします
  • 汚れや蒸れで皮膚がふやける（浸軟）と、皮膚のバリアが弱まり、かぶれや感染が起こりやすくなります。陰部に赤みがあれば、こすらず押さえ拭きし、医療職に相談して用具や介助の方法を見直します

おむつ交換

  • 排泄の有無は、手袋をして確認する（素手で触れるのは×）
  • 外したおむつは、汚れを内側に丸めて片付ける
  • 他の利用者がいる場所で「おむつを替えますよ」と言わない
  • 尿取りパッドを何枚も重ねない（ムレ・皮膚トラブルの原因）
  • 汚れた手袋は、衣類を整える前に外す
  • 紙おむつのテープは、上のテープは下向き・下のテープは上向きに留める（脚のつけ根に沿ってすき間ができにくい）。おなかとの間は指2本分のゆとり、鼠径部（太もものつけ根の内側）は締めすぎない
  • 布おむつは、尿が流れる側を厚くする：女性は後ろ側、男性は前側

陰部洗浄・清拭

  • 湯はぬるま湯（温度は介護者の前腕の内側で確認する。手のひらは熱さに鈍いので確認に向かない）
  • 女性は前から後ろへ：尿道口 → 肛門（逆にすると大腸菌が尿道に入り、尿路感染の原因になる）。会陰（えいん）＝陰部と肛門の間の部分で、「前から後ろへ」「尿道口→肛門」「会陰から肛門へ」はすべて同じ向きのことです
  • 石けんは毎回は使わない。こすらず、やさしく洗う
  • 排便がなくても、殿部の清拭は省略しない

女性利用者のおむつ交換をするときに行う陰部洗浄の基本に関する次の記述のうち、最も適切なものを1つ選びなさい。

  1. 湯温は、介護福祉職の手のひらで確認する。
  2. おむつを交換するたびに、石鹸（せっけん）を使って洗う。
  3. タオルで汚れをこすり取るように洗う。
  4. 尿道口から洗い、最後に肛門部（こうもんぶ）を洗う。
  5. 洗浄後は、蒸しタオルで水分を拭き取る。

出典：第35回 介護福祉士国家試験（生活支援技術）

正解を見る

正解：4　前（尿道口）から後ろ（肛門）へ。大腸菌が尿道に入るのを防ぎます。湯温は前腕の内側で確認し、こすらず押さえ拭きします。

体の状態に合わせたトイレの工夫

  • 関節リウマチなどで股関節が深く曲がらない人には、便座を高くする補高便座（または電動昇降便座）で立ち座りを楽にします（障害の特性①「肢体不自由・関節リウマチ・内部障害」）
  • 肩や肘を大きく動かせない人には、トイレットペーパーなどを、座ったまま腕を大きく上げ下げせずに手が届く位置に置きます。めやすは、座ったときの太もものつけ根くらいの高さの斜め前。高すぎても（肩・二の腕の高さ）低すぎても（すねの高さ）関節に負担がかかります（第25回）
  • 温水洗浄便座は陰部や肛門を清潔に保ちやすいですが、使い方を説明し、使いこなせるまで見守ります
  • ベッドの横に取り付けるスイングアーム介助バーは、つかまってポータブルトイレへ移りやすくします
