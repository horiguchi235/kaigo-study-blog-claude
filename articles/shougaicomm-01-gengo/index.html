この記事のポイント

  1. 運動性失語＝わかるけど言葉が出ない → 「はい・いいえ」で答えられる質問、絵や写真を指さし、言葉を推測して確かめる。
  2. 感覚性失語＝言葉の理解が難しい → 「あした、散歩」のように短い言葉で、身ぶり・表情・実物も添えて。
  3. 構音障害＝発音だけが難しい（理解は保たれる） → 聞き取れないところはもう一度言ってもらう、短い言葉でゆっくり。五十音表・携帯用会話補助装置も。

① 失語症の人とのコミュニケーション

言葉の障害の分け方：音声障害（声そのものが出ない。喉頭を取った人は人工喉頭や食道発声を使う）・構音障害（声は出るが発音がうまくできない）・失語症（脳の言語中枢の障害。高次脳機能障害の一つ）の3つに分かれます。

まず全体像：言葉の障害は「どこが難しいか」で関わり方が変わります（聴覚障害はくわしくは 視覚障害・聴覚障害・盲ろうの人とのコミュニケーション）。

言葉の理解話すこと五十音表・筆談有効な手段大きな声
運動性失語ほぼ保たれる言葉が出ない使いにくい閉じられた質問・絵や写真の指さし効果なし（聞こえは正常）
感覚性失語難しい話せるが意味が通りにくい使いにくい短い言葉・身ぶり・実物効果なし（聞こえは正常）
構音障害保たれる発音が難しい使える聞き返し・五十音表・携帯用会話補助装置不要
難聴保たれる話せる使える（筆談）補聴器・筆談・手話・口の形を見せる耳元の大声は×、低めの声でゆっくり

失語症＝脳の言語をつかさどる部分（言語野）が傷ついて、「聞く・話す・読む・書く」が難しくなる障害。脳梗塞などの後遺症で起こります。

2つのタイプ

ブローカ野（前頭葉）＝話す、ウェルニッケ野（側頭葉）＝聞いてわかる、と脳の場所とセットで覚えます。

タイプ状態関わり方 ○
運動性失語（ブローカ失語）言葉の理解はできるが、話そうとしても言葉が出ない・たどたどしい「はい」「いいえ」で答えられる質問（閉じられた質問）、絵や写真など視覚的な情報、いくつかの絵から指さし
感覚性失語（ウェルニッケ失語）流暢に話せるが言葉の理解が難しい。言い間違いが多く、意味の通らない言葉（ジャルゴン）になることも短い言葉で区切って伝え、身ぶり・表情・実物も添える

場面で覚える

場面○ 正解×
（運動性失語）「お茶、いや、違う、お、お…」ともどかしそう「何か飲みたいのですね。お水ですか？」と推測して確認言い直しを求める・五十音表を渡す
（感覚性失語）「あしたは晴れですね。あしたの午後散歩に行きましょう」が伝わらない「あした、散歩」と短く同じ文を大きな声で繰り返す
（文章の理解が難しい）「お風呂は今日ではなくあしたですよ」が伝わらない「お風呂、あした」文字で詳しく書く
  • 失語症の人に五十音表・ひらがなの筆談は使いにくい（文字の理解や思い出すことも難しくなるため）。タイプで使い分けます：
    • 運動性失語：言葉は理解できるので、絵や写真を指さしてもらうのが有効。
    • 感覚性失語：絵カードを見ても何を聞かれているのかの理解が難しいので、絵カード・五十音表より身ぶり・表情・実物など言葉以外の手がかりで。言葉を復唱させない。
    • 全失語：聞く・話す・読む・書くのすべてが難しい。表情・身ぶり・実物で、はい・いいえを確かめる。
  • 聞こえは悪くないので、耳元で大声を出しても伝わりやすくはならない。手話も有効ではない（手話も言語なので）。
  • 言い間違いを訂正しない。ゆっくり待ち、うまく伝わったら一緒に喜ぶ。
  • 接し方：静かで落ち着ける場所で話す／疲れやすいので小休止をはさむ／言葉が出なくても子ども扱いしない／共通の話題をつくる。
  • 言葉の中枢は多くの人で左の脳にあるので、右片麻痺の人は失語症を伴うことがあります（左片麻痺では半側空間無視が多い）。事例に「右片麻痺・話は理解できる」とあれば運動性失語を考え、閉じられた質問を選びます。

Eさん（70歳、女性）は、脳梗塞（cerebral infarction）の後遺症で言語に障害がある。

発語はできるが、話したいことをうまく言葉に言い表せない。

聴覚機能に問題はなく、日常会話で使用する単語はだいたい理解できるが、単語がつながる文章になるとうまく理解できない。

ある日、Eさんに介護福祉職が、「お風呂は、今日ではなくあしたですよ」と伝えると、Eさんはしばらく黙って考え、理解できない様子だった。

このとき、Eさんへの介護福祉職の対応として、最も適切なものを1つ選びなさい。

  1. 「何がわからないのか教えてください」と質問する。
  2. 「お風呂、あした」と短い言葉で伝える。
  3. 「今日、お風呂に入りたいのですね」と確かめる。
  4. 「あしたがお風呂の日で、今日は違いますよ」と言い換える。
  5. 「お・ふ・ろ・は・あ・し・た」と1音ずつ言葉を区切って伝える。

出典：第36回 介護福祉士国家試験（コミュニケーション技術）

正解を見る

正解：2　失語症の人には短く、なじみのある言葉で、1つずつ。1音ずつ区切るとかえって意味がつかめません。Eさんは「文章になると理解しにくい」ので、理解の障害への関わり方（感覚性失語と同じく短く区切る）を選びます。

② 構音障害・その他の場面

構音障害＝口・舌・のどの麻痺などで発音がうまくできない。言葉の理解や文字は保たれる。

○×
聞き取れないところはもう一度言ってもらう聞き取れなくてもわかったふりをする
「おいうをあえあい」→「お肉を食べたい、ですか？」と、くみ取った言葉で返して確認正しい発音で言い直させる
発音が苦手なので短い言葉でゆっくり話してもらう意味の理解に支障があると判断／会話や訓練を中止
食事中はメニューを説明する程度の声かけにとどめる（むせやすいので）食事中にたくさん質問する
五十音表・筆談・携帯用会話補助装置も使える（理解は保たれるので）—

意思疎通支援用具

アテトーゼ型脳性麻痺（手足や体が意思と関係なく動いてしまうタイプ）で発音が難しいが聞き取りはできる → 携帯用会話補助装置（文字を入力して音声や表示で伝える）。人工喉頭（喉頭摘出後）・点字器（視覚障害）・助聴器（聴覚障害）は対象が違います。

用具どんな人に障害者総合支援法での区分
携帯用会話補助装置発音が難しいが、文字を入力できる人日常生活用具
重度障害者用意思伝達装置ALSなどで話すことも書くこともできない人（まばたきやわずかな動きで文字を選ぶ）補装具
五十音表・文字盤構音障害など、文字の理解が保たれている人（道具・自作）
透明文字盤話すことも書くこともできないが、目は動かせる人（ALSなど）。透明な板に五十音を書き、介護者が板をはさんで本人と向かい合い、本人が見つめる文字を視線の重なりで読み取る（道具・自作）

ALSでは、話す → 筆談 → 透明文字盤 → 重度障害者用意思伝達装置と、進行に合わせて手段を早めに準備していきます。

第37回：コミュニケーション技術

構音障害のあるBさんは、現在発語訓練を実施中である。ある日、介護福祉職に対して、「おあんで、あつがおごれた」と訴えた。介護福祉職は、Bさんの発語をうまく聞き取れず、「もう一度、言ってください」と伝えた。Bさんは、自身の発語で会話を続けようとしているが、介護福祉職には、その内容を十分に理解することができなかった。

このときの、Bさんに対する介護福祉職の判断として、最も適切なものを1つ選びなさい。

  1. Bさんは言葉の意味の理解に支障があるため、会話の継続は困難である。
  2. 発音が苦手なため、短い言葉でゆっくり話してもらう必要がある。
  3. 話す意欲があるため、開かれた質問が有効である。
  4. 発語訓練の効果がみられないため、訓練を中止する必要がある。
  5. Bさんの言葉が聞き取れないため、会話を中断する必要がある。

出典：第37回 介護福祉士国家試験（コミュニケーション技術）

正解を見る

正解：2　構音障害は言葉の理解は保たれ、発音だけが難しい。短く・ゆっくり話してもらい、閉じられた質問で確かめます。

〔事例〕

Kさん（83歳、女性、要介護3）は、10年前の脳出血（cerebral hemorrhage）による後遺症で高次脳機能障害（higher brain dysfunction）がある。感情のコントロールが難しく、興奮すると大声をあげて怒りだす。現在は、訪問介護（ホームヘルプサービス）を利用しながら、自宅で長男（60歳）と二人暮らしをしている。

長男は、会社を3年前に早期退職し、Kさんの介護に専念してきた。顔色が悪く、介護による疲労を訴えているが、「介護を続けて、母を自宅で看取りたい」と強く希望している。別居している長女は、長男の様子を心配して、「母親の施設入所の手続きを進めたい」という意向を示している。

訪問介護員（ホームヘルパー）が、興奮しているときのKさんとコミュニケーションをとるための方法として、最も適切なものを1つ選びなさい。

  1. 興奮している理由を詳しく聞く。
  2. 興奮することはよくないと説明する。
  3. 冷静になるように説得する。
  4. 事前に作成しておいた日課表に沿って活動してもらう。
  5. 場所を移動して話題を変える。

出典：第34回 介護福祉士国家試験（コミュニケーション技術）

正解を見る

正解：5　興奮しているときは説明・説得は逆効果。場所や話題を変えて気分を切りかえるのが有効です。
