この記事のポイント

  1. 運動性失語＝わかるけど言葉が出ない → 「はい・いいえ」で答えられる質問、絵や写真を指さし、言葉を推測して確かめる。
  2. 感覚性失語＝言葉の理解が難しい → 「あした、散歩」のように短い言葉で、身ぶりも添えて。
  3. 構音障害＝発音だけが難しい（理解は保たれる） → 聞き取れないところはもう一度言ってもらう、短い言葉でゆっくり。五十音表・携帯用会話補助装置も。

① 失語症の人とのコミュニケーション

2つのタイプ

タイプ状態関わり方 ○
運動性失語（ブローカ失語）言葉の理解はできるが、話そうとしても言葉が出ない・たどたどしい「はい」「いいえ」で答えられる質問（閉じた質問）、絵や写真など視覚的な情報、いくつかの絵から指さし
感覚性失語（ウェルニッケ失語）話せるが言葉の理解が難しい、言い間違い多い短い言葉で区切って伝える、身ぶり・実物を示す

場面で覚える

場面○ 正解×
「お茶、いや、違う、お、お…」ともどかしそう「何か飲みたいのですね。お水ですか？」と推測して確認言い直しを求める・五十音表を渡す
「あしたは晴れですね。あしたの午後散歩に行きましょう」が伝わらない「あした、散歩」と短く同じ文を大きな声で繰り返す
「お風呂は今日ではなくあしたですよ」が伝わらない「お風呂、あした」文字で詳しく書く

失語症の人に五十音表・文字盤は使いにくい（文字の理解も難しくなるため）。それよりも絵・写真・実物が有効です。

✏️ 過去問を解いてみよう（第36回：コミュニケーション技術）

脳梗塞の後遺症で言葉に障害があるEさん。話せるが言いたいことを言葉にできず、単語はわかるが文章になると理解しにくい。「お風呂は今日ではなくあしたですよ」と伝えると、考え込んでわからない様子だった。対応として最も適切なものはどれ？

  1. 「何がわからないのか教えてください」と聞く
  2. 「お風呂、あした」と短い言葉で伝える
  3. 「今日お風呂に入りたいのですね」と確かめる
  4. 「あしたがお風呂の日で、今日は違いますよ」と言い換える
  5. 「お・ふ・ろ・は・あ・し・た」と1音ずつ区切る
正解を見る

正解：2　失語症の人には短く、なじみのある言葉で、1つずつ。1音ずつ区切るとかえって意味がつかめません。

② 構音障害・その他の場面

構音障害＝口・舌・のどの麻痺などで発音がうまくできない。言葉の理解や文字は保たれる。

○×
聞き取れないところはもう一度言ってもらう聞き取れなくてもわかったふりをする
「おいうをあえあい」→「おにく」と聞き取れた通りに繰り返して確認正しい発音で言い直させる
発音が苦手なので短い言葉でゆっくり話してもらう意味の理解に支障があると判断／会話や訓練を中止
食事中はメニューを説明する程度の声かけにとどめる（むせやすいので）食事中にたくさん質問する
五十音表・筆談・携帯用会話補助装置も使える—

意思疎通支援用具

アテトーゼ型脳性麻痺で発音が難しいが聞き取りはできる → 携帯用会話補助装置（文字を入力して音声や表示で伝える）。人工喉頭（喉頭摘出後）・点字器（視覚障害）・助聴器（聴覚障害）は対象が違います。

場面○ 正解

高次脳機能障害の人が興奮しているとき場所を移動して話題を変える（理由を詳しく聞く・説得するは×）

第37回：生活支援技術

アテトーゼ型脳性麻痺のCさんは、手足や体が意思と関係なく動き、指先の細かい動きは難しい。はっきり発音できないが、聞き取りはできる。Cさんが使う情報・意思疎通支援用具として最も適切なものはどれ？

  1. 福祉電話
  2. 携帯用会話補助装置
  3. 人工喉頭
  4. 助聴器
  5. 点字器
正解を見る

正解：2　発音しにくい人が文字や音声で伝えられる携帯用会話補助装置。人工喉頭は喉頭を摘出した人向けです。

第37回：コミュニケーション技術

構音障害があり発語訓練中のBさんが「おあんで、あつがおごれた」と訴えた。聞き取れず「もう一度」と頼んだが、内容を十分に理解できなかった。介護福祉職の判断として最も適切なものはどれ？

  1. 言葉の意味の理解に支障があり会話は難しい
  2. 発音が苦手なので、短い言葉でゆっくり話してもらう
  3. 話す意欲があるので開かれた質問が有効
  4. 訓練の効果がないので中止する
  5. 聞き取れないので会話をやめる
正解を見る

正解：2　構音障害は言葉の理解は保たれ、発音だけが難しい。短く・ゆっくり話してもらい、閉じられた質問で確かめます。

第34回：コミュニケーション技術

高次脳機能障害で感情のコントロールが難しく、興奮すると大声で怒り出すKさん。興奮しているときのコミュニケーションの方法として、最も適切なものはどれ？

  1. 興奮している理由を詳しく聞く
  2. 興奮はよくないと説明する
  3. 冷静になるよう説得する
  4. 事前に作った日課表どおりに活動してもらう
  5. 場所を移して話題を変える
正解を見る

正解：5　興奮しているときは説明・説得は逆効果。場所や話題を変えて気分を切りかえるのが有効です。

③ 失語症の種類と伝え方の工夫

  • 難聴の種類：伝音難聴＝外耳・中耳の障害（補聴器が効きやすい）／感音難聴＝内耳・聴神経の障害（老人性難聴は主にこちら）。
  • 失語症の種類：運動性失語（ブローカ失語）＝言葉の理解はわりと保たれるが話すのが難しい／感覚性失語（ウェルニッケ失語）＝話せるが言葉の理解が難しい。
  • 発語が難しい人にはコミュニケーションエイド（意思伝達装置）が有効。
  • 運動性失語（ブローカ）＝言葉の理解は保たれるが話せない→閉じられた質問・絵や写真。感覚性失語（ウェルニッケ）＝流暢に話すが意味が通らない（ジャルゴン）、理解も難しい→身ぶり・表情など非言語を活用。
  • 失語症では五十音表やひらがなの筆談はかえって難しいことが多い（文字の理解・想起も障害されるため）。聞こえは悪くないので耳元で大声を出さない。手話も有効ではない。
  • 伝え方：短い文で文節を区切る（「明日、散歩」）、ゆっくり待つ、言い間違いを訂正しない、うまく伝わったら一緒に喜ぶ。
  • 構音障害（話す筋肉の麻痺）は言葉の理解は保たれるので、五十音表・筆談・コミュニケーションエイドが使える。
