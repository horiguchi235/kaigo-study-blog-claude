  2. 意思確認は「方針を伝えて確認 → 書面に残す → 気持ちは変わるので何度でも」。決めるのは本人。
  3. 死の直前は「尿が減る・手足が冷たい・喉がゴロゴロ・下顎呼吸」。死斑・死後硬直・角膜の混濁は死後。

① 終末期の用語・意思確認・ACP

用語

用語意味
リビングウィル終末期に自分が望むケアをあらかじめ書面に示しておくこと
事前指示書意思疎通が難しくなったときのために、希望する医療ケアを記した書類
尊厳死延命目的の治療をせず、自然な最期を迎える
積極的安楽死薬物などで意図的に死期を早める
脳死脳幹を含む脳全体の機能が止まった状態（自発呼吸はない）
グリーフケア死別による悲嘆への支援
インフォームドコンセント十分な説明を受けたうえでの同意
ターミナルケア終末期のケア

施設での意思確認

○×
終末期の介護方針を伝えて意思確認する90歳を超えれば確認不要
確認した内容は書面にする介護職間で口頭で共有
気持ちが変わったら今の意思を尊重入所時の意思を優先して変えない
本人の意思と家族の意向も確認する本人が言えれば家族は確認しない／家族の意向を優先
医療処置の範囲の説明は医師介護職が説明する／意思確認できなければ医師に任せる

アドバンス・ケア・プランニング（ACP）

「人生の最終段階における医療・ケアの決定プロセスに関するガイドライン」（2018年改訂）で重視。

○「今後の生活について、家族や医療・介護職員と一緒に、その都度話し合っていきましょう」

× 家族が代わりに決める／食べられなくなったら介護職員に相談／意思が伝えられなくなったら成年後見

誤嚥性肺炎をくり返し終末期が近い人 → 最優先で確認するのは「経口摂取に対する本人の意向」。

第36回：生活支援技術

誤嚥性肺炎で入退院をくり返し、終末期が近いと言われているMさん（98歳、要介護5）。介護福祉職が確認すべき最も優先度の高いものはどれ？

  1. 主治医の今後の見通し
  2. 誤嚥性肺炎のときの入院先
  3. 口から食べることについての本人の意向
  4. 口から食べることについての家族の意向
  5. 延命治療についての家族の希望
正解を見る

正解：3　最優先は本人の意思。家族の意向や医師の見通しも大切ですが、まず本人がどう過ごしたいかを確かめます。

第34回：こころとからだのしくみ

夫を自宅で看取ったBさんは、死期が迫ったら延命目的の治療は受けず、自然な最期を迎えたいと願っている。この死を表す言葉はどれ？

  1. 脳死
  2. 突然死
  3. 尊厳死
  4. 積極的安楽死
  5. 心臓死
正解を見る

正解：3　延命治療をせず自然な死を迎える＝尊厳死。薬などで死期を早めるのが積極的安楽死（日本では認められていない）です。

② キューブラー・ロスの死の受容過程

段階例
第1段階 否認「診断は何かの間違いだ」
第2段階 怒り「なぜ私だけが」
第3段階 取り引き「財産を全部使ってもいいから治したい」
第4段階 抑うつ死は避けられないと知り、さまざまな喪失感を抱く
第5段階 受容「死は自然なことだから受け入れよう」

悲観・卑屈・悟り・平安は段階の名前ではありません。

第38回：こころとからだのしくみ

キューブラー・ロスの死の受容過程で、「抑うつ」は第何段階？

  1. 第1段階
  2. 第2段階
  3. 第3段階
  4. 第4段階
  5. 第5段階
正解を見る

正解：4　否認→怒り→取り引き→抑うつ→受容。抑うつは第4段階です。

第37回：生活支援技術

キューブラー・ロスの死の受容過程で、「死は避けられないと知り、さまざまな喪失感を抱く段階」はどれ？

  1. 否認
  2. 怒り
  3. 取り引き
  4. 抑うつ
  5. 受容
正解を見る

④ 苦痛のとらえ方と意思決定（ACP・事前指示）

  • 全人的苦痛（トータルペイン）＝身体的・精神的・社会的・スピリチュアルな苦痛。本人・家族と多職種のチームで支える。
  • モルヒネは痛みを和らげるが、便秘・吐き気・眠気・呼吸抑制などの副作用への対策が大切。
  • 最期を迎えたい場所の希望は自宅が最も多い（子どもの家ではない）。実際に亡くなる場所は病院が多い。
  • 死の受容過程の第4段階は「抑うつ」（「そううつ」ではない）。段階の順番や進み方は人によって違う。
  • 死が近いときの呼吸：チェーンストークス呼吸＝無呼吸（数十秒）→浅い呼吸→深く大きな呼吸→浅い呼吸→無呼吸…をくり返す／下顎呼吸＝あごを動かしてする呼吸（死が非常に近い）／鼻翼呼吸・肩呼吸＝努力呼吸。ほかに手足の冷え・チアノーゼ・死前喘鳴。体温が急上昇するのは典型的ではない。
  • 死亡の判断は医師。介護職は変化を記録して医療職に報告する。
  • ACP（アドバンス・ケア・プランニング＝人生会議）：年齢に関係なく、病気のことだけでなくこれからの生活について、本人・家族・医療介護職がくり返し話し合う。気持ちが変わったら今の意思を尊重し、話し合った内容は記録に残す。医療処置の範囲の説明は医師・看護職の役割。
  • アドバンス・ディレクティブ（事前指示）＝判断力があるうちに、受けたい・受けたくない医療を示しておくこと。リビングウィルはその書面版。
  • 国の「人生の最終段階における医療・ケアの決定プロセスに関するガイドライン」が基本。
  • 死の三徴候：心臓の停止・呼吸の停止・瞳孔が開き光に反応しない。
