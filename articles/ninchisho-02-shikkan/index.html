この記事のポイント

  1. 疾患ごとの「顔」を1つずつ：アルツハイマー＝もの盗られ妄想、レビー＝幻視とパーキンソン症状、前頭側頭＝人格変化・常同行動、血管性＝感情失禁・段階的悪化、クロイツフェルト・ヤコブ病（CJD）＝急速進行。
  2. 事例問題は「頭を打って1〜3か月後」＝慢性硬膜下血腫、「歩行障害・尿失禁・物忘れ」＝正常圧水頭症。どちらも治療で改善する。
  3. 原因で多い順はアルツハイマー型 → 血管性。

原因疾患の割合と分類

  • 割合（2013年の都市部の調査）：アルツハイマー型 67.6％、血管性 19.5％、レビー小体型 4.3％（パーキンソン病による認知症を含む）、混合型 3.3％、前頭側頭型 1.0％ など。上位3つを「三大認知症」と呼びます
  • 原因による分け方：
    • 脳の神経細胞が変性して減るもの：アルツハイマー型・レビー小体型・前頭側頭型
    • 脳血管疾患：脳梗塞・脳出血
    • 外傷：慢性硬膜下血腫・頭部外傷の後遺症
    • 感染：クロイツフェルト・ヤコブ病・髄膜炎・梅毒・エイズ
    • 内分泌・代謝：甲状腺機能低下症・ビタミンB12不足
    • 中毒：アルコール
    • 腫瘍：脳腫瘍
    • その他：正常圧水頭症
  • 治療で改善が期待できるのは、慢性硬膜下血腫・甲状腺機能低下症・正常圧水頭症の一部など（→ ④）

① アルツハイマー型認知症

脳の変化：アミロイドβがたまってできる「老人斑」と、神経細胞の中にできる糸くずのような「神経原線維変化」が増え、神経細胞が減って脳が縮みます。記憶の中心の海馬から始まり、側頭葉・頭頂葉、やがて前頭葉へ広がります。体を動かすはたらきは末期まで比較的保たれます。

  • 巣症状＝脳の傷んだ場所のはたらきが失われて起こる症状（失語・失行・失認・失計算）。アルツハイマー型でも見られます
  • 遂行機能障害は、記憶障害とならんで初期から出ます（料理・家計が難しくなる理由）
  • 取り繕い＝できないことを隠すように、もっともらしい返事でその場を合わせること。アルツハイマー型でよく見られます

FAST（アルツハイマー型の進み具合を7段階で見る物差し）：料理・家計・買い物が難しいのはFAST 4＝軽度、季節や場面に合った服を選べず介助が必要になるとFAST 5＝中等度。

進行による変化

アルツハイマー型は、おおむね8年（3〜20年と幅がある）かけて進みます。

時期（FAST）本人の様子
1〜31＝正常、2＝年相応の物忘れ、3＝境界（仕事の複雑な作業でつまずく）
軽度（FAST 4）近時記憶障害・もの盗られ妄想・不安や抑うつ。料理・家計・買い物（IADL）が難しい
中等度（FAST 5）見当識障害が進み、迷子・帰宅願望。服を選べない、入浴に説得が必要
やや高度（FAST 6）着替え・入浴に介助が必要。トイレの水を流し忘れる、尿失禁 → 便失禁
高度（FAST 7）話せる言葉が数語 → 1語。歩けない → 座っていられない → 笑えない。最後は寝たきり
  • BPSDは中等度で目立ちやすく、重度になると言葉と活動が減り、どの型でもアパシー（無関心）が前に出ます。そのため、妄想や探し歩きなどは、重度になると目立たなくなることが多いです
  • 認知症高齢者の日常生活自立度の Ⅳ（頻繁に支障があり、常に介護が必要）は、この重度の時期にあたります（→ 若年性認知症・評価スケール・薬・予防）
  • 亡くなる原因は、肺炎などの感染症や心不全が多いです

第38回：認知症の理解

次の記述のうち、アルツハイマー型認知症（dementia of the Alzheimer’s type）の説明として、最も適切なものを1つ選びなさい。

  1. 古い記憶から障害され、徐々に新しい記憶も障害される。
  2. 認知機能が変動することが特徴的である。
  3. ADL（Activities of Daily Living：日常生活動作）の障害は、重度期以降に認められる。
  4. 見当識障害は、中期以降に認められる。
  5. 記憶障害は、初期から認められる。

出典：第38回 介護福祉士国家試験（認知症の理解）

正解を見る

正解：5　新しい記憶（近時記憶）から初期に障害されます。認知機能の変動はレビー小体型の特徴です。

次の記述のうち、アルツハイマー型認知症（dementia of the Alzheimerʼs type）の特徴として、適切なものを1つ選びなさい。

第35回：認知症の理解

アルツハイマー型認知症（dementia of the Alzheimerʼs type）の、もの盗られ妄想に関する次の記述のうち、最も適切なものを1つ選びなさい。

  1. 説明をすれば自身の考えの誤りに気づくことが多い。
  2. 本人の不安から生じることが多い。
  3. 現実に存在しない人が犯人とされる。
  4. 主に幻視が原因である。
  5. 症状の予防には抗精神病薬が有効である。

出典：第35回 介護福祉士国家試験（認知症の理解）

正解を見る

正解：2　記憶障害と不安が背景。犯人にされるのは身近な介護者が多く、否定せず一緒に探します。

② レビー小体型認知症

  • レビー小体＝神経細胞の中にできる、異常なたんぱく質（αシヌクレイン）のかたまりです
  • 脳幹にたまると、ドーパミンをつくる神経細胞が減り、パーキンソン病と同じ手足のふるえ（振戦）・筋肉のこわばり・小刻み歩行・前かがみの姿勢が出ます。大脳にたまると、幻視や認知の変動が出ます
  • 治療：認知機能にはドネペジル、パーキンソン症状にはレボドパなどの抗パーキンソン病薬。抗精神病薬にはとても敏感で、少量でも動けなくなる・飲み込めなくなることがあります
  • 立ちくらみ（起立性低血圧）による失神、便秘など自律神経の症状もあるので、転倒に注意します
○ よく出る症状× 出ない・誤り
鮮明で具体的な幻視（「窓のそばに知らない人が立っている」）幻視はあいまい
パーキンソン症状：最初の一歩が出にくく小刻みに歩く、動作が遅く転倒しやすい運動機能障害は見られない
認知機能・症状の日内変動初期からの人格変化
自律神経症状＝起立性低血圧幻聴・意味性失語・食欲増加
レム睡眠行動障害（夢を見ている浅い眠り＝レム睡眠のときに、大声を出したり手足を動かしたりする）ノンレム睡眠
誤嚥性肺炎の合併が多い脳梗塞が原因・初発が記憶障害
幻視は部屋を明るくすると消えることがある抗精神病薬が多く使われる（薬に過敏で副作用が出やすい）

幻視への対応：ふりかけを「アリがたかっている」と言う → 普通のご飯に取り替えて勧める。「アリはいません」と否定するのは×。

第38回：認知症の理解

次のうち、レビー小体型認知症（dementia with Lewy bodies）の症状として、最も適切なものを1つ選びなさい。

  1. ノンレム睡眠行動障害による大声
  2. 自律神経症状による起立性低血圧（orthostatic hypotension）
  3. 聴覚認知機能の障害による幻聴
  4. 側頭葉の萎縮による意味性失語
  5. 嚥下機能（えんげきのう）の促進による食欲増加

出典：第38回 介護福祉士国家試験（認知症の理解）

正解を見る

正解：2　レビー小体型は幻視・パーキンソン症状・認知の変動・レム睡眠行動障害・自律神経症状（起立性低血圧・便秘）。

第36回：認知症の理解

レビー小体型認知症（dementia with Lewy bodies）にみられる歩行障害として、最も適切なものを1つ選びなさい。

  1. しばらく歩くと足に痛みを感じて、休みながら歩く。
  2. 最初の一歩が踏み出しにくく、小刻みに歩く。
  3. 動きがぎこちなく、酔っぱらったように歩く。
  4. 下肢は伸展し、つま先を引きずるように歩く。
  5. 歩くごとに骨盤が傾き、腰を左右に振って歩く。

出典：第36回 介護福祉士国家試験（認知症の理解）

正解を見る

正解：2　パーキンソン症状によるすくみ足・小刻み歩行。1は間欠性跛行（しばらく歩くと足が痛み・しびれ、休むとまた歩ける。脊柱管狭窄症など）、3は小脳性の歩行（足を広げてふらふら歩く。小脳の障害）です。

第34回：認知症の理解

レビー小体型認知症（dementia with Lewy bodies）の幻視の特徴に関する次の記述のうち、最も適切なものを1つ選びなさい。

  1. 幻視の内容はあいまいではっきりしない。
  2. 睡眠中でも幻視が生じる。
  3. 本人は説明されても幻視という認識ができない。
  4. 薄暗い部屋を明るくすると幻視が消えることがある。
  5. 抗精神病薬による治療が行われることが多い。

出典：第34回 介護福祉士国家試験（認知症の理解）

正解を見る

正解：4　幻視ははっきり具体的。照明を明るくするなど環境で減ることがあり、抗精神病薬は副作用が出やすく慎重に使います。

③ 前頭側頭型・血管性・クロイツフェルト・ヤコブ病

前頭側頭型認知症

  • 社会のルールや常識がわからなくなる、常同行動（同じ時間に同じ行動）
  • 65歳未満の初老期に発症することが多い。見当識や道順の記憶は保たれ、迷子になりにくい
  • 決まった物ばかり食べる・甘い物を好むなど、食べ方が変わる
  • 脱抑制＝その場にふさわしくない行動を抑えられないこと（万引き・無断で物を取る）
  • 側頭葉の萎縮が強いと、物の名前や言葉の意味がわからなくなる（意味性失語）。これは前頭側頭型の症状で、レビー小体型ではない
  • 原因に効く薬はない。対応：常同行動は止めるのではなく、本人と周囲が納得できる生活習慣にする（生活のリズムに組み込む）
  • ×の選択肢：「物忘れの自覚」「幻視」「急速な進行」「エピソード記憶障害が初期から」

血管性認知症

  • 脳梗塞・脳出血が原因。男性に多く、階段状に悪化
  • 記憶障害にムラがある（まだら認知症）、感情失禁、病識があることが多い
  • 初期にめまいを自覚することがある
  • 危険因子：メタボリックシンドローム・高血圧・糖尿病などの生活習慣病
  • ×：「女性に多い」「ゆっくり少しずつ進行」「人格変化が多い」「85歳以上に多い」
  • 型：大きな脳梗塞・脳出血の発作の直後から起こる型と、小さな脳梗塞をくり返して段階的に進む型（多発性脳梗塞による認知症）がある。後者は本人も気づかないうちに進み、頭が重い・めまい・もの忘れから始まることが多い

アルツハイマー型と血管性で、早見表にない違い

アルツハイマー型血管性
多い年齢70歳以上60〜70歳代
初期の自覚ほとんどない（病識がない）頭が重い・頭痛・めまい・もの忘れ（病識があり、抑うつになりやすい）
神経症状末期まで少ない片麻痺・言語障害などが初期から
人格比較的保たれ、進むと変化比較的保たれる
治療の中心抗認知症薬・薬を使わないケア高血圧・糖尿病などの管理で再発を防ぐ（原因を治す薬はない）

クロイツフェルト・ヤコブ病

  • プリオン病。進行が速く、1年以内の死亡例も多い
  • 50〜60歳代に多く、症状が出てから半年〜1年ほどで寝たきり・死亡に至ることが多い。BSE（牛海綿状脳症）の牛から感染した例（変異型）もある。治療法はない
  • ×：有病率1万人に1人（実際は約100万人に1人）、緩やかに進行、致死率は低い、不随意運動を伴わない

④ 治療で改善が期待できる認知症

慢性硬膜下血腫正常圧水頭症
きっかけ頭部の打撲（転倒など）。抗凝固薬の使用もリスクはっきりしない
発症打撲から1〜3か月後に物忘れ・ふらつき・麻痺—
症状物忘れ・歩行障害・片麻痺歩行障害・尿失禁・認知障害の3つ
診断頭部CT頭部CT・MRI
治療外科的手術（血腫を取り除く）シャント手術（たまった脳脊髄液を管でおなかなどに流す）

「早期発見で改善が可能」・「外科的手術で治療が可能」と聞かれたら、この2つから選びます。

脳は外側から硬膜・くも膜・軟膜の3枚の膜に包まれています。慢性硬膜下血腫は、いちばん外の硬膜の下に少しずつ血がたまり、脳を押す病気です。

そのほか、治療で改善が期待できるもの：甲状腺機能低下症、ビタミンB12不足。アルコール多飲などによるビタミンB1不足はウェルニッケ脳症を起こし、記憶障害と作話（記憶の穴を作り話でうめる）が目立つコルサコフ症候群に進むことがあります。

慢性硬膜下血腫（chronic subdural hematoma）に関する次の記述のうち、最も適切なものを1つ選びなさい。

  1. 運動機能障害が起こることは非常に少ない。
  2. 頭蓋骨骨折を伴い発症する。
  3. 抗凝固薬の使用はリスクとなる。
  4. 転倒の後、2～3日で発症することが多い。
  5. 保存的治療が第一選択である。
