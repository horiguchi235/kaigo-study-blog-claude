この記事のポイント

  1. 家族は一緒に利用者を支えるパートナー。まずこれまでの頑張りをねぎらい、体験を共感的に聴く。
  2. 利用者と家族の意向が違うときは、それぞれの意見を聞き、家族とは別に話す機会も設ける。どちらかを説得するのは×。
  3. 自己覚知＝自分の感情の動きとその背景に気づくこと。

① 家族との関係づくり

○ 正解× よく出る不正解
協働するパートナーとして接する介護は全面的に任せてもらう
介護の体験を共感的に聴く介護技術を教える／（関係づくりの最初の段階で）当事者の会・家族会を勧める
家で介護をしている家族（試験では夫）の頑張りを認めながら、介護の状況を聴くおむつ交換の方法を指導する／限界を自覚させる

家族のようすだけで家族を理解したと思わない家族と利用者の希望は同じと考える

「家族」とひとまとめにしない：利用者への思いは、配偶者・息子・娘など家族の一人ひとりで違います。家族どうしの関係（仲がよい・疎遠・介護をめぐって対立している など）もさまざまです。まず家族間の関係をつかみ、その人の個性や生き方に合わせて対応を変えます。家族の努力は肯定的に認め、ねぎらいの言葉をかけます。

第38回：コミュニケーション技術

次の記述のうち、利用者の家族との関係づくりにおける介護福祉職の基本姿勢として、最も適切なものを1つ選びなさい。

  1. お互いの緊張が解けるまでじっと待つ。
  2. 介護福祉職のペースで話を進める。
  3. 利用者の意向よりも家族の意向を優先する。
  4. 家族への連絡は最小限にする。
  5. 利用者支援で協働するパートナーとして接する。

出典：第38回 介護福祉士国家試験（コミュニケーション技術）

正解を見る

正解：5　家族は協働するパートナー。ただし本人の意向を後回しにするわけではありません（3は×）。1の「じっと待つ」だけでは関係は進まず、2の職員のペースや4の連絡を減らすのも、協働とは反対です。

第36回：コミュニケーション技術

利用者の家族との信頼関係の構築を目的としたコミュニケーションとして、最も適切なものを1つ選びなさい。

  1. 家族に介護技術を教える。
  2. 家族に介護をしている当事者の会に参加することを提案する。
  3. 家族から介護の体験を共感的に聴く。
  4. 家族に介護を続ける強い気持ちがあるかを質問する。
  5. 家族に介護保険が使える範囲を説明する。

出典：第36回 介護福祉士国家試験（コミュニケーション技術）

正解を見る

正解：3　まずは家族のこれまでの介護体験を共感的に聴く。技術指導や制度説明は信頼関係ができてからです。2の当事者の会も役に立つ場ですが、信頼関係をつくる最初の対応ではありません。4の「強い気持ちがあるか」の質問は、家族を試すようで負担になります。

第35回：コミュニケーション技術

利用者の家族と信頼関係を形成するための留意点として、最も適切なものを1つ選びなさい。

  1. 家族の希望を優先する。
  2. 話し合いの機会を丁寧にもつ。
  3. 一度形成した信頼関係は、変わらずに継続すると考える。
  4. 家族に対して、「こうすれば良い」と指示を出す。
  5. 介護は全面的に介護福祉職に任せてもらう。

出典：第35回 介護福祉士国家試験（コミュニケーション技術）

正解を見る

正解：2　信頼関係は話し合いを重ねて育て、続けるもの。一度できたら終わりではありません。

第34回：コミュニケーション技術

次の事例を読んで、問いに答えなさい。

〔事例〕

Kさん（83歳、女性、要介護3）は、10年前の脳出血（cerebral hemorrhage）による後遺症で高次脳機能障害（higher brain dysfunction）がある。感情のコントロールが難しく、興奮すると大声をあげて怒りだす。現在は、訪問介護（ホームヘルプサービス）を利用しながら、自宅で長男（60歳）と二人暮らしをしている。

長男は、会社を3年前に早期退職し、Kさんの介護に専念してきた。顔色が悪く、介護による疲労を訴えているが、「介護を続けて、母を自宅で看取りたい」と強く希望している。別居している長女は、長男の様子を心配して、「母親の施設入所の手続きを進めたい」という意向を示している。

長男に対する訪問介護員（ホームヘルパー）の対応として、最も適切なものを1つ選びなさい。

  1. 長男自身の意向を変える必要はないと励ます。
  2. Kさん本人の意向が不明なため、長男の希望は通らないと伝える。
  3. これまでの介護をねぎらい、自宅での看取りを希望する理由を尋ねる。
  4. 自宅での生活を継続するのは限界だと説明する。
  5. 長女の言うように、施設入所の手続きを進めることが正しいと伝える。

出典：第34回 介護福祉士国家試験（コミュニケーション技術）

正解を見る

正解：3　どちらかの味方をせず、まずねぎらい、思いの背景を聴く。そのうえで休息やサービスの調整を考えます。（高次脳機能障害＝脳の損傷で記憶・注意・感情のコントロールなどが難しくなる障害。病名がわからなくても解ける問題です）

③ 自己覚知と対人関係の心理

「自己〇〇」は名前が似ているので、セットで区別します（第37回はこの区別を問う問題）。

用語意味
自己覚知自分の感情の動きとその背景を洞察する。自分の価値観や癖を知り、利用者への影響をコントロールする
自己開示自分のことを相手に話す。目的はよい関係づくり。量・深さ・タイミング・相手・状況を考えて行う（自分をよく見せるためではない）
自己同一性（アイデンティティ）自分とは何かという認識をもつこと
自己決定利用者が自分のことを自分で決めること（バイステックの7原則の1つ）
自我「私」として考え・感じ・行動をまとめる心の働き（表に出ない意識のことではない。それは無意識）
自己愛自分を大切に思い、愛する気持ち（他人と区別して自分を意識すること、ではない）
自己中心性ほかの人の立場から物事を見ることが難しいこと（自分の行動をコントロールすること、ではない。それは自己統制）
転移利用者が、過去の重要な人に向けた感情を援助者に向ける。例：亡き父に向けていた甘えや反発を、担当職員に向ける
逆転移援助者が、利用者に無意識の感情を向ける。例：亡くなった祖母に似た利用者に、無意識に頻繁に関わる
役割葛藤複数の役割の期待にはさまれて悩む。例：仕事と介護の両立に悩む家族介護者
ストレッサー／コーピングストレッサー＝ストレスの原因になるできごと。コーピング＝ストレスへの対処のしかた。原因そのものを解決しようとする問題焦点型と、気持ちを落ち着かせる情動焦点型がある
問題焦点型コーピングストレスの原因に働きかけて解決しようとする。気分転換・音楽・考え方を変えるのは情動焦点型

自己覚知の方法：自分の記録や関わりのふり返り、スーパービジョン（上司・先輩からの助言）、同僚からのフィードバック。逆転移のような無意識の感情に気づくためにも、自己覚知が必要です。

職員自身のストレス：新人職員が利用者の言葉に傷つき眠れなくなった → まず上司や同僚に悩みを話して助言を受ける。上司・同僚・家族など周りの人からの助けや助言をソーシャルサポートといい、眠れないなど強いストレス反応が出たら、まずこれを使います。

PDCAサイクル（組織の業務改善）は → ケアマネジメント・多職種連携・人材育成 の③で扱います。

第38回：人間関係とコミュニケーション

新人職員のAさん（20歳）は、子どもの頃からの夢だった介護福祉職になり、がんばって働いていた。ただ、介護の技術をもっと学ぶ必要があるといつも感じていた。ある日、利用者Bさんに、「Aさんじゃダメだ、別の人を呼んで」と言われて、ショックを受けた。悩むうちに利用者とかかわりたくないと感じるようになり、眠れなくなってしまった。

次の記述のうち、このような状況にあるAさんが、ストレスを取り除くためにまず行うべき対処方法として、最も適切なものを1つ選びなさい。

  1. つらさから逃げず、学びが足りないことを自覚する。
  2. 介護の技術がうまくなるために、全力で取り組む。
  3. 眠れるように、毎晩飲酒する。
  4. 上司や同僚などに悩みを話して、助言を受ける。
  5. 介護福祉職には向かないと判断して、転職する。

出典：第38回 介護福祉士国家試験（人間関係とコミュニケーション）

正解を見る

正解：4　不眠などのストレス反応が出ているときは、ひとりで抱えず上司・同僚に相談（ソーシャルサポート）するのが先です。1・2はひとりでがんばり続ける対処で、眠れないほどのストレスがあるときにまず行うことではありません。3の飲酒、5のすぐの転職も×。

第37回：人間関係とコミュニケーション

人間関係と心理に関する次の記述のうち、適切なものを1つ選びなさい。

  1. 自己愛とは、自分という存在を、他人と区別して意識することである。
  2. 自己同一性の確立とは、自分とは何かという認識をもつことである。
  3. 自我とは、日常行動に影響を与える、表面化していない意識のことである。
  4. 自己覚知とは、コミュニケーションにおいて自分について話すことである。
  5. 自己中心性とは、自分の意思で自分の行動をコントロールすることである。

出典：第37回 介護福祉士国家試験（人間関係とコミュニケーション）

正解を見る

正解：2　自己同一性（アイデンティティ）＝「自分は何者か」の認識。自分について話すのは自己開示、自己覚知は自分の価値観や感情に気づくことです。

  4. 好きな音楽を聴いてリラックスする。
