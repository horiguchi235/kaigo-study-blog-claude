この記事の論点と出題数（過去5年）

  • 利用者主体・個別性・生活歴を尊重した生活支援 7問

この記事のポイント

  1. 生活の主人公は利用者。生活時間・生活習慣・生活歴はその人独自のもので、施設や介護者の都合に合わせない。
  2. 迷ったら、本人の意向を確かめたうえで「今までどおり」を選ぶ。畳に布団、夜の入浴、好みの切り方――本人の暮らし方を続けられる選択肢が正解（本人が変えたいと望むなら、それに沿う）。
  3. 見守り的援助＝介護者が代わりにやるのではなく、声をかけて一緒に行うこと。

① 生活支援の基本視点

「生活」とは何か：生活は食事・排泄・睡眠だけではありません。衣服、会話、性、余暇、仕事、家計、住まい、恋愛・結婚、子育て、葬儀、信仰なども含みます。生活は次の5つの面からみます。

面中身
身体・心（精神）の面体の健康・気持ち
家事の面掃除・洗濯・調理・買物・お金の出し入れ
経済の面収入・支出
文化の面その人らしさが出る部分。生きる意欲につながる
社会の面介護が必要になっても社会とかかわる

性や信仰も「その人の生活」の一部なので、「考えなくてよい」という選択肢は×です。

○ 正解になる視点× よく出る不正解
利用者の意思を尊重し、十分に情報を伝えて本人が選ぶ介護者の意向を優先する／チームで決めたプログラムを押しつける
生活モデル（暮らし全体をみる）・ICFの視点医学モデル（できない所を治す）・ICIDH（ICFの前の国際障害分類）の視点
専門的な知識に基づき、生活歴も理解して支援する知識より経験を重視する
生活は余暇や人とのつながりも含み、生活時間はその人独自生活は食事・排泄・睡眠の3つだけ
利用者の価値観を尊重し、信頼関係を築く支援者の価値観・規則を優先する
利用者の全体像をとらえ、持てる力を生かすできないことを代わりに行うことに重点
一人ひとりに合わせた個別ケア集団ケアを優先する

よく出る一言：「1人で生活行為ができることを目的にする」「すべて自分一人でできるようにする」「いつもそばに付き添い、何でも積極的にやるよう促す」は×です。目的はその人らしい生活であって、何でも一人でできることではありません。本人のできる力と必要な支援を組み合わせ、ペースを尊重します。

言葉で伝えにくい人の意思：一人ひとりの意思を大切にする根拠は、憲法13条「すべて国民は、個人として尊重される」です。失語症などで話すことが難しい人には、表情・うなずき・指さしなど言葉以外のサインから意思をくみとり、本人が選べる方法を用意します（第28回：運動性失語の人に「左手で食べたいものを示してもらう」が正解。メニューの説明を省く・混ぜて口に運ぶは×）。

ICF・生活モデルの考え方は ICF（国際生活機能分類）の見分け方 で詳しく扱います。

第34回：介護の基本

個別性のとらえ方

  • 生活習慣は、その人が生活してきた環境から理解する
  • 年齢から生きてきた時代を考えて体験談を聞く。性別・家族構成・所得・障害特性で決めつけない
  • その人らしい生活のために最優先で把握する情報は、これまでの生活環境と生活習慣
  • 「その人らしさ」をつくるもの＝価値観・生活習慣・これまでの体験・地域性・時代背景。同じ病気・同じ要介護度でも支援は人によって変わる
  • 個別ケアには2つの意味がある：その人の体や障害に合わせた「個別の介護技術」と、その人の人生の歩みをふまえた「個別の生活支援」
  • 生活歴や人間関係をつかむ図：エコマップ＝利用者や家族を取り巻くさまざまな人・機関との関係を線でつないだ図。ジェノグラム（家族図）＝家族の構成（3世代ほど）を記号で表した図。入れ替えに注意

プライバシー・羞恥心

  • 羞恥心に配慮した介護を行う
  • 愛称で呼ばない。多床室ではカーテンを閉める。入室時はノックと声かけ

第37回：介護の基本

Bさん（68歳、女性、要介護1）は、ヨーロッパで生まれ育ち、50歳のときに日本人と結婚した。65歳で夫と共に日本で暮らすようになったが、日本語は十分に理解できない。半年前に、脳梗塞（cerebral infarction）を起こし、利き手に麻痺（まひ）があり、立ち上がりも不安定である。現在は、介護老人保健施設に入所し、在宅復帰へ向けたリハビリテーションを行っている。Bさんはこれまでの生活様式を守り、自宅で自分のペースで食事ができるようになりたいと希望している。

次の記述のうち、Bさんへの介護福祉職の対応として、最も適切なものを1つ選びなさい。

  1. 入所中は母語を使わずに、日本語を話すように伝える。
  2. 居室の床に布団を敷いて、寝起きができるようにする。
  3. 自分で食事ができるように、自助具の使用状況を確認する。
  4. ほかの利用者と同じ時間に食べ終えるように伝える。
  5. 日本の生活に合わせるように、余暇活動の内容は介護福祉職が判断する。

出典：第37回 介護福祉士国家試験（介護の基本）

正解を見る

正解：3　本人の目標（自分で食べたい）と文化を尊重し、できる力を支えるのが正解。母語の禁止や生活様式の押しつけは×です。

③ 入所・転居のときの配慮

環境が大きく変わるときは、なじみのもの・なじみの人が心の支えになります。

  • 施設入所の負担を減らす → 早くなじみの職員ができるようにする。家族の訪問を控える・新しい家具・施設の時間に合わせるは×
  • 息子夫婦の家へ引っ越す認知症の人の部屋 → 思い出の小物や写真を飾る
  • 入居して戸惑っている人 → 入居前の生活の様子を聞く。日課を伝える・役割を職員が決めるは×

④ 見守り的援助と生活援助

訪問介護のサービスは、次の3つに分けて考えます。

区分中身例
身体介護体に直接ふれる介護＋本人と一緒に行う家事（見守り的援助）入浴・排泄・食事の介助、一緒にごみを分別する
生活援助本人に代わって行う家事掃除・洗濯・調理・買物の代行
対象外本人の日常生活の援助にあたらないもの家族の分の洗濯・調理、大掃除、窓ふき、庭の手入れ、ペットの世話、服の作り直し

見守り的援助＝利用者の自立と重度化防止のために、一緒に行う・声をかける・そばで確認する支援で、身体介護に区分されます。服薬時に飲むよう促し、そばで確認するのも見守り的援助です。

○ 見守り的援助× 単なる代行（生活援助）
ごみの分別ができるように声をかけるその場で介護者がごみを分別する
冷蔵庫の中を本人と一緒に整理する冷蔵庫を介護者が整理・期限切れを捨てる
洗濯物を一緒に干す・たたむテレビを見ている横で介護者が洗濯物を干す

家事の支援：片麻痺でも「家事は無理だから介護者がやる」は×。片手で使える自助具や手順の工夫でできることを生かします。家事のアセスメントでは心身機能・生活歴・希望・環境・家族の分担を把握し、清潔さより本人の生活習慣や価値観を尊重します。

買物代行のルール：リストどおりに買う（安くても多く買わない）、おつり・レシートは一緒に確認、冷蔵庫の中を勝手に捨てない、本人が調理するなら調理しにくい食材がないか確認する。

第38回：生活支援技術

Aさん（82歳、女性、要介護1）は、訪問介護（ホームヘルプサービス）を週1回利用し、生活援助を受けながら、自宅で一人暮らしをしている。調理はAさん本人が行うなど、できることは自分で行いたいと思っている。ある日、訪問介護員（ホームヘルパー）はAさんから買物リストを渡されて、近くのスーパーで食材を購入してきた。

次の記述のうち、Aさんへの生活援助における訪問介護員（ホームヘルパー）の対応として、最も適切なものを1つ選びなさい。

  1. 依頼された食材が安かったので、リストに書かれた数より多く購入した。
  2. おつりとレシート、購入した食材の確認を、Aさんにすべて任せた。
  3. 冷蔵庫を開けたとき、賞味期限切れの食材があったため廃棄した。
  4. 買物リストは、次から訪問介護員（ホームヘルパー）が書くことを提案した。
  5. 購入した食材で調理しにくいものがないか、Aさんに確認した。

出典：第38回 介護福祉士国家試験（生活支援技術）

正解を見る

正解：5　本人が自分で調理できるように確認・相談するのが適切。勝手に多く買う・捨てる・リストを代わりに書くのは本人の意思に反します。おつり等は一緒に確認します。

⑤ 利用者主体を支える制度

  • 措置から契約へ：以前は行政がサービスの内容や行き先を決める「措置」制度だった。2000年の介護保険の開始と社会福祉法への改正で、利用者がサービスを選んで事業者と契約するしくみになった。
  • 選ぶための情報：事業者は介護サービス情報の公表制度で事業所の情報を公表する義務がある。
  • インフォームド・コンセント＝十分な説明を受け、理解したうえで本人が同意・選択すること。説明するだけ、同意書をとるだけでは不十分。

制度のくわしい内容は 介護保険のサービスの種類と事業所 で扱います。
