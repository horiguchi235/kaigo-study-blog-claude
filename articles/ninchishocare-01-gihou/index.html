認知症の理解8問

この記事の論点と出題数（過去5年）

  • パーソン・センタード・ケアと意思決定支援 3問
  • 非薬物療法・ケア技法（RO・回想法・バリデーション・ユマニチュード） 5問

この記事のポイント

  1. 認知症ケアの軸はその人らしさ（パーソン・センタード・ケア）と本人の意思決定。BPSDを「なくす」こと自体は目的ではない。
  2. 日付・季節・場所を伝える＝リアリティ・オリエンテーション、昔の写真・音楽＝回想法。
  3. ユマニチュードは「見る・話す・触れる・立つ」。バリデーションはミラーリング・カリブレーションで動きや感情に合わせる。

① 認知症ケアの考え方

考え方・ツール○ 正しい説明× よく出る誤り
パーソン・センタード・ケア（キットウッド）認知症の人の「その人らしさ」を支えるBPSDをなくす／特別な存在として保護する／マニュアルをつくる
ひもときシート言動の背景要因を分析して本人を理解するツール。評価的理解 → 分析的理解（8つの視点）→ 共感的理解の順。介護者の視点から本人の視点へ切り替える最初に分析的理解／介護者側の視点でとらえる
認知症ライフサポートモデル本人の自己決定を支える。多職種が共通の目標をもつ職種ごとに目標設定／終末期の介入モデル／施設入所を促す
意思決定支援ガイドライン（2018年）身振りや表情の変化も意思表示として読み取る。支援者は職種を限らない。意思は変わるので繰り返し確認家族の意思を支援する／一度決めたら最後まで同じ／看取り期から開始
グループホームのケアなじみの関係、力を発揮できる場面、家庭的な環境、地域との交流BPSDの治療に焦点を当てる

胃ろうをつくるかどうか（重度の認知症）：主治医・家族・後見人が単独で決めるのではなく、本人の意向や価値観を把握し、本人にとっての最善を関係者で判断する。

第37回：認知症の理解

「認知症の人の日常生活・社会生活における意思決定支援ガイドライン」（2018年）で示された意思決定支援として、最も適切なものはどれ？

  1. 認知症の人の家族の意思を支援すること
  2. 支援者は特定の職種に限られる
  3. 一度決めたら最後まで同じ内容で支援する
  4. 看取りの場面になってから支援を始める
  5. 身振りや表情の変化も意思表示として読み取る努力を最大限に行う
正解を見る

正解：5　言葉にならない表情・しぐさも意思表示として受け止めます。支援者は家族・地域の人も含み、意思は変わってよいものです。

第35回：認知症の理解

認知症ライフサポートモデルについて、最も適切なものはどれ？

  1. 各職種がそれぞれ目標を立てる
  2. 終末期に行う介入モデル
  3. 認知症の人本人の自己決定を支える
  4. 生活を介護サービスに任せるプランをつくる
  5. 施設入所を促す
正解を見る

正解：3　本人主体・自己決定の支援、多職種で目標を共有し、早期から終末期まで継続して支えるモデルです。

第34回：認知症の理解

認知症ケアの「ひもときシート」について、最も適切なものはどれ？

  1. 最初に分析的理解を行う
  2. 言動を介護者の視点でとらえる
  3. 言動の背景要因を分析して本人を理解するツール
  4. 評価的理解では潜在的なニーズを重視する
  5. 共感的理解では8つの要因で言動を分析する
正解を見る

正解：3　評価的理解→分析的理解（8つの要因）→共感的理解の順で、介護者の視点から本人の視点へ切りかえるツールです。

② ケアの技法・非薬物療法

技法中身試験の見分け方
リアリティ・オリエンテーション（RO）現実の感覚を確かめ、見当識に働きかける日付・季節・天気・場所を会話の中で伝える。ホワイトボードに日付と季節の絵を描き「今日は6月22日」と伝える
回想法昔の写真・音楽・道具を使って記憶を活性化豊かな情動をもたらす。楽しい思い出の手がかりを準備し、同じ場所で行う
ライフレビュー人生を振り返り、意味づける回想法と混同しやすい
バリデーション認知症の人の体験している現実を共感して受け入れる技法：ミラーリング（動きを鏡のように合わせる）・カリブレーション（感情に合わせる）、センタリング（介護者が精神を集中）、リフレージング（言葉を繰り返す）、レミニシング（思い出話）
ユマニチュード4つの柱「見る・話す・触れる・立つ」立つ＝立位をとる機会をつくる
タッチング肩や背中から優しくゆっくり触れる—

ユマニチュードの4つの柱

③ 環境づくりとリアリティ・オリエンテーション

  • リアリティ・オリエンテーション（現実見当識訓練）＝名前・日付・場所などの基本的な情報をくり返し伝えて現実の認識を高める。
  • そのほかの非薬物療法：回想法（昔の経験を語る）／音楽療法（音楽で感情や交流を支える）／動作法（体の動きや緊張に働きかける）。どれも本人の力と好みに合わせ、訂正を押しつけない。
  • 認知症の人の環境づくり：刺激の量と質を調整（騒がしすぎず、なさすぎず）、トイレなどの目印は目の高さに、危険なものは目に入らない工夫。
  • なじみの関係（グループホームなど）となじみの物が安心につながる。施設入所時は使い慣れた家具を持ち込むとリロケーションダメージを和らげられる。
  • 24時間リアリティ・オリエンテーション＝日常の会話の中で日付・場所・季節をさりげなく伝え続ける方法。
