① 家族支援とレスパイトケア

レスパイトケア

○×
介護を担う家族に休息を提供する利用者の安静・介護職の休息・経済的負担の軽減
家族が休んでいる間も、障害者が自分らしく過ごせるように家族は自宅で休まなければならない／旅行は認められない／宿泊に限る
痰の吸引で家族が眠れない → レスパイトケアの利用仕事を辞める・吸引の講習・流動食にする
  • レスパイトには、ヘルパーなどが家に来て家族と交代する形（在宅派遣型）と、本人が施設に短期間泊まる・日中だけ通う形（ショートステイ型）があり、組み合わせることもあります。だから「宿泊に限る」は×。
  • 障害福祉で使えるレスパイト：短期入所（ショートステイ）、市町村の地域生活支援事業の日中一時支援など。制度のサービスだけでなく、家族会・相談・地域の活動など制度外の支えも組み合わせる。

家族への関わり

家族も、障害を受け入れていく当事者です。家族それぞれの生活と、家族全体の両方を見ます。家族の考えをはっきり聞き、経済面・住まいなどの環境面・気持ちの面を理解します。本人と家族の意向が違うときも、どちらか一方で決めず、本人・家族と一緒に支援を考えます。

場面○ 正解
脳性麻痺の息子を介護する母親が腰痛母親の介護方法を尊重しながら、腰の負担が軽い方法を提案
夫が脳梗塞で障害が残り、将来が不安な妻不安に寄り添い、今の課題を一緒に整理する

家族の世話を日常的に担う子ども・若者をヤングケアラーといいます（→ 介護の実態と社会資源）。

（自立支援）協議会

障害者総合支援法での名前は「協議会」ですが、自治体では「自立支援協議会」と呼ぶことが多いため、かっこ付きで書かれます。

  • 地域の関係者が集まり、個別の事例から地域の課題を共有する
  • 市内にサービス事業所がない → 地域の社会資源の開発
  • 協議会は、地方公共団体（都道府県・市町村）が置くよう努めるものとされています（努力義務）。
  • 2024年4月施行の改正で：協議会の参加者に守秘義務ができ、協議会は関係機関に情報の提供を求められるようになった／基幹相談支援センターの設置と、緊急時の受け入れや地域移行を支える地域生活支援拠点等の整備が、市町村の努力義務になった（→ 障害者総合支援法のしくみとサービス）。

第36回：障害の理解

Dさん（36歳、女性、療育手帳所持）は、一人暮らしをしながら地域の作業所に通っている。

身の回りのことはほとんど自分でできるが、お金の計算、特に計画的にお金を使うのが苦手だった。

そこで、社会福祉協議会の生活支援員と一緒に銀行へ行って、1週間ごとにお金をおろして生活するようになった。

小遣い帳に記録をするようにアドバイスを受けて、お金を計画的に使うことができるようになった。

次のうち、Dさんが活用した支援を実施する事業として、最も適切なものを1つ選びなさい。

  1. 障害者相談支援事業
  2. 自立生活援助事業
  3. 日常生活自立支援事業
  4. 成年後見制度利用支援事業
  5. 日常生活用具給付等事業

出典：第36回 介護福祉士国家試験（障害の理解）

正解を見る

正解：3　社協の生活支援員による日常的な金銭管理の支援＝日常生活自立支援事業。
