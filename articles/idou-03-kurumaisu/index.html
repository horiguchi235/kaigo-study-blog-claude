この記事のポイント

  1. 車いすで「下る」ときは後ろ向き（段差も急な坂も）。段差を上がるときは前輪を上げる。
  2. 視覚障害者の誘導は「肘の少し上を握ってもらい、半歩前を歩く」。狭い道は介護者が前、階段は手前で止まって声かけ。
  3. パーキンソン病は小刻み歩行・すくみ足 → 一度足を引いてから歩き出す。

① 車いすの介助

場面○ 正解× よく出る不正解
出発前足がフットサポートにのっているか確認—
段差を上がるティッピングレバーを踏んで前輪を上げ、段にのせてから後輪を押し上げるキャスターを斜めに向ける
段差を下りる後ろ向きで後輪から前輪から下りる
急な上り坂押し戻されないよう、ゆっくりしっかり押すすばやく進む
急な下り坂後ろ向きで進む前向きで進む
砂利道前輪を上げて進む後輪を持ち上げる
踏切前輪を上げ、駆動輪でレールを越える駆動輪を上げる
エレベーター正面からまっすぐ入る—
速さ歩くよりゆっくり歩行速度より速く

外出・散歩

  • 施設から車いすで外出するときに最優先：外出先の経路情報を集める（段差・トイレ・エレベーター）
  • 散歩中は顔色や表情を確認する。行き先は本人と決め、靴も用意する

脊髄損傷のレベルと車いす

第6胸髄（Th6）損傷：上肢は使えるが体幹の支えが弱い → 腰部までのバックサポートの車いすで自分でこげる。ヘッドサポートやハンドリムのない車いすは、もっと高い位置（頸髄）の損傷向けです。

✏️ 過去問を解いてみよう（第36回：生活支援技術）

標準型車いすでの移動の介護として、適切なものはどれ？

  1. 急な上り坂はすばやく進む
  2. 急な下り坂は前向きで進む
  3. 踏切は駆動輪を上げて進む
  4. エレベーターには正面からまっすぐ進む
  5. 段差を降りるときは前輪から降りる
正解を見る

正解：4　エレベーターは正面からまっすぐ（溝に前輪がはまらないように）。急な下り坂・段差を降りるときは後ろ向き、踏切は前輪（キャスター）を上げて進みます。

第38回：生活支援技術

視覚障害者の歩行誘導として、最も適切なものはどれ？

  1. 利用者の半歩後ろで背中を支えて歩く
  2. 白杖に触れながら歩く
  3. 狭い通路では利用者の後ろを歩く
  4. 階段の前でいったん止まって声をかける
  5. 利用者が握っている腕を振って歩く
正解を見る

正解：4　階段や段差の手前で止まり、上りか下りかを伝える。介護者は半歩前を歩き、狭い通路では前に立ちます。

第34回：生活支援技術

視覚障害のある利用者の外出に同行するときの支援として、最も適切なものはどれ？

  1. トイレを使うときは、中の様子を伝える
  2. 階段では利用者の手首を握って誘導する
  3. 狭い場所では利用者の後ろに立って誘導する
  4. タクシーには支援者が先に乗る
  5. 駅ではエレベーターよりエスカレーターを勧める
正解を見る

正解：1　トイレの便器・ペーパー・水を流すボタンの位置などを伝えます。利用者に介護者のひじの上を軽く持ってもらい、タクシーは利用者が先に乗ります。

④ 車いす・歩行補助具の扱いと視覚障害者の誘導

  • 車いすの各部：ハンドリム＝自分でこぐときに回す輪／バックサポート＝背もたれ／アームサポート＝肘置き（外せるタイプは移乗が楽）／フットサポート＝足のせ／ティッピングバー＝段差で前輪を上げるとき足で踏む。
  • 出発前にタイヤの空気・ブレーキを点検。移乗するときはブレーキをかけ、フットサポートを上げる。動かす前には必ず声をかける。
  • 急な下り坂は後ろ向きで、グリップをしっかり握ってゆっくり。エレベーターは正面から乗り、中の広さによって向きを考える（いつも後ろ向き、ではない）。
  • 視覚障害者の誘導：本人に介護者の肘の少し上を持ってもらい、介護者は半歩前。狭い所は一列になり介護者が前。段差・方向は先に伝える。
  • 視覚障害者の衣類選び：色・柄・しみや汚れも具体的に伝え、選ぶのは本人。触ってわかる目印や、決まった収納場所の工夫。
  • 自分で買い物に行けない人にも、選ぶ楽しみを残す支援を（品物・おつり・レシートを一緒に確認）。
  • 間欠性跛行＝歩くと足が痛み、休むと楽になる。原因は閉塞性動脈硬化症（血管性）や腰部脊柱管狭窄症（神経性、前かがみで楽になる）。
  • 車いすの段差：上がるときはティッピングレバーを踏んでキャスタを上げ、段に乗せてから後輪を押し上げる。下りるときは後ろ向きで後輪から。
  • 急な下り坂は後ろ向き、上り坂は前向きで足を開いてしっかり押す。砂利道や踏切はキャスタを上げて進む。エレベーターは正面からまっすぐ乗る。使う前にタイヤの空気圧とブレーキを点検。
  • 視覚障害者の誘導：利用者に介助者の肘の少し上を持ってもらい半歩前を歩く。バス・電車は介助者が先に乗り、先に降りる。狭い道は一列で。離れるときは柱や壁に触れられる場所で。
  • 歩行補助具：歩行器（杖より安定、四輪型・二輪型・固定型）、シルバーカー（自分で歩けるが足腰が弱い人向け、休むときに座れる）。
