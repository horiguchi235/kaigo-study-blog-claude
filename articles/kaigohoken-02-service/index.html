居宅サービスは何をしてくれる？

名前だけでは中身がわかりにくいので、「訪問・通い・泊まり・用具」に分けて見ておきましょう。

分類サービス何をしてくれる？
訪問訪問入浴介護浴槽を積んだ車で家に来て、入浴を介助する
訪問訪問看護・訪問リハビリテーション主治医が必要と認めた人の家に、看護師や理学療法士・作業療法士・言語聴覚士が行く
訪問居宅療養管理指導通院が難しい人の家に、医師・歯科医師・薬剤師・管理栄養士・歯科衛生士などが行き、療養の管理と指導をする
通い通所介護（デイサービス）日帰りで、入浴・食事・排泄の介護や機能訓練をする。家族の介護の負担を軽くする目的もある
通い通所リハビリテーション（デイケア）老健・病院・診療所などで、医師の管理のもとリハビリをする
通い地域密着型通所介護定員18人以下の小さなデイサービス（市町村が指定）
通い療養通所介護難病や末期がんなど、医療が必要な重い人のためのデイサービス
泊まり短期入所生活介護（ショートステイ）特養などに短い期間泊まり、日常の介護を受ける
泊まり短期入所療養介護老健・介護医療院などに泊まり、看護や医学的な管理も受ける
用具福祉用具貸与／特定福祉用具販売貸与＝借りる。肌にふれて貸し借りに向かない入浴・排泄の用具（簡易浴槽・腰掛便座など）は買う。一部の用具は貸与か購入かを選べる（くわしくは住環境・住宅改修・福祉用具）
  • 泊まりのサービスは、家族の旅行・冠婚葬祭・休息（レスパイト）のときにも使います
  • 福祉用具の購入費は年10万円まで、住宅改修費は原則20万円まで。どちらも原則償還払い（いったん全額払い、あとで保険の分が戻る）
  • 夜間対応型訪問介護は、夜間に定期巡回と、通報による随時訪問をするサービス。日中も含めて24時間、介護と看護を行うのが定期巡回・随時対応型訪問介護看護です（1つの事業所で行う一体型と、訪問看護事業所と組む連携型がある）

要支援の人が使えるサービス

サービス要支援1・2の人は？
訪問介護・通所介護市町村の総合事業（訪問型・通所型サービス）で使う
訪問看護・通所リハ・短期入所・福祉用具貸与・住宅改修など「介護予防〇〇」として予防給付で使える
小規模多機能型居宅介護・認知症対応型通所介護介護予防版があり使える
グループホーム（認知症対応型共同生活介護）要支援2から使える（要支援1は×）
定期巡回・夜間対応型訪問介護・看護小規模多機能使えない（要介護者のみ）
施設サービス・地域密着型特養・地域密着型特定施設使えない

地域密着型サービスのポイント

サービス○×
小規模多機能型居宅介護通いを中心に訪問・泊まりを組み合わせ、登録した人の在宅生活を支える。2006年に創設2012年に始まった（正しくは2006年）／長期の宿泊が目的／管理者は医師でなければならない
看護小規模多機能型居宅介護看護と介護を一体的に提供。2012年創設の「複合型サービス」が2015年に改称居宅サービス／長期宿泊／都道府県域
定期巡回・随時対応型訪問介護看護日中・夜間を通じて、定期訪問と随時訪問。要介護者が対象要支援者も使える／緊急時対応なし／都道府県が指定
認知症対応型通所介護利用者は原則その市町村の住民。グループホームの共用スペースなどを使う共用型もある65歳以上に限る／家族の送迎が原則
  • 地域密着型サービスでは、事業所が地域に開かれるよう運営推進会議（利用者・家族・市町村職員・地域住民の代表など）を開く。定期巡回・随時対応型は「介護・医療連携推進会議」。夜間対応型訪問介護だけは、この会議を置く決まりがありません

介護予防・日常生活支援総合事業（総合事業）

  • 市町村の地域支援事業の一つ。第一号訪問事業（訪問型サービス）・第一号通所事業（通所型サービス）など
  • 「日中話し相手がいなくて寂しい」要支援1の一人暮らし → 通所型サービス（総合事業）
  • 要支援者が自宅で安全に移動したい → 介護予防住宅改修（これは総合事業ではなく予防給付）。夜間対応型訪問介護（要介護のみ）・小規模多機能（カラオケ目的）は×

訪問介護の「身体介護」と「生活援助」

区分中身・例
身体介護利用者の体に直接触れる介助（入浴・排泄・食事など）、通院の付き添い、利用者と一緒に家事をする自立生活支援のための見守り的援助
生活援助一人暮らしなどで本人が家事をできないときに、本人の代わりに行う掃除・洗濯・調理・買い物、薬の受け取り（処方された薬を薬局でもらってくる）
生活等に関する相談・助言訪問介護として行える

訪問介護の対象外になるもの

対象外の例理由
庭の草むしり・植木の水やり・ペットの世話本人の日常生活に直接必要ではない
家族の部屋の掃除・家族の食事づくり利用者本人への援助ではない
外食への同行・趣味の外出日常生活に必要な外出（通院など）ではない
理美容・通帳と印鑑の預かり・クレジットカードでの買物代行専門職の仕事や、金銭トラブルにつながる管理は訪問介護の範囲外
訪問日以外の安否確認サービスは計画で決めた訪問時に行う
利用者がいないときの家事（洗濯物の取り込みなど）利用者本人への援助として行うもの
大掃除・窓ふき・家具の移動・壁紙の張替えふだんの家事をこえている
来客の接待（お茶出しなど）利用者本人の生活に直接必要ではない

事業所に決められていること

  • 正当な理由がないのに、サービスの提供を断ってはいけない（提供拒否の禁止）
  • 通所介護計画・訪問介護計画などの個別計画をつくることは義務。利用者に説明して同意を得る
  • 火事や地震などに備えた非常災害対策（計画づくりと、定期的な避難訓練）も義務
  • 通所介護は、ほかのサービスと組み合わせて使うことを条件にしていない

第38回：介護の基本

次の記述のうち、介護保険制度における一人暮らしの要支援者を支えるサービスの内容として、適切なものを1つ選びなさい。

  1. 夜間を安心して過ごすために、夜間対応型訪問介護を利用する。
  2. 自宅で安全に移動するために、介護予防住宅改修を利用する。
  3. 趣味のカラオケに行くために、小規模多機能型居宅介護を利用する。
  4. 身元保証や死後の財産処分のために、高齢者等終身サポート事業を利用する。
  5. 金銭管理のために、日常生活自立支援事業を利用する。

出典：第38回 介護福祉士国家試験（介護の基本）

正解を見る

正解：2　住宅改修は要支援も対象。夜間対応型訪問介護は要介護のみ、4・5は介護保険のサービスではありません。

第37回：社会の理解

次の記述のうち、定期巡回・随時対応型訪問介護看護の説明として、正しいものを1つ選びなさい。

  1. 利用定員は、9人以下と定められている。
  2. 日中・夜間を通じて、提供するサービスである。
  3. 認知症対応型共同生活介護（認知症高齢者グループホーム）に入居する利用者に対して、機能訓練を行うサービスである。
  4. 通い、泊まり、看護の3種類の組合せによるサービスである。
  5. 都道府県が事業者の指定、指導、監督を行うサービスである。

出典：第37回 介護福祉士国家試験（社会の理解）

正解を見る

正解：2　24時間（日中・夜間とも）、定期訪問と通報への随時対応を介護・看護一体で行う地域密着型サービス（市町村が指定）。4は看護小規模多機能型居宅介護です。

第37回：社会の理解

Bさん（85歳、男性、要支援1）は、自宅で一人暮らしをしている。最近、物忘れが多くなり、1か月前から地域支援事業の訪問型サービスを利用するようになった。ある日、Bさんが、「これからも自宅で生活したいが、日中、話し相手がいなくて寂しい」と介護福祉職に話した。

次のうち、Bさんに介護福祉職が勧めるサービスとして、最も適切なものを1つ選びなさい。

  1. 認知症対応型共同生活介護（認知症高齢者グループホーム）
  2. 介護老人福祉施設
  3. 第一号通所事業（通所型サービス）
  4. 夜間対応型訪問介護
  5. 居宅療養管理指導

出典：第37回 介護福祉士国家試験（社会の理解）

正解を見る

正解：3　要支援者が通って人と交流できるのは総合事業の通所型サービス。グループホームは要支援2から、特養は原則要介護3以上です。

第37回：介護の基本

次の記述のうち、介護保険制度における訪問介護員（ホームヘルパー）が行うサービス内容として、最も適切なものを1つ選びなさい。

  1. 利用者が大切にしている庭の植木に、水やりをする。
  2. 利用者が長年飼っている猫のペットフードを、購入してくる。
  3. 掃き掃除をする習慣のある利用者と一緒に、寝室をほうきで掃除する。
  4. 利用者と一緒に、近所のラーメン屋に行く。
  5. 利用者のクレジットカードを預かって、買物を代行する。

出典：第37回 介護福祉士国家試験（介護の基本）

正解を見る

正解：3　一緒に行う自立生活支援のための見守り的援助は身体介護。庭の手入れ・ペットの世話など本人の日常生活に直接必要でないことは対象外です。

第36回：社会の理解

次のうち、介護保険法に基づき、都道府県・指定都市・中核市が指定（許可）、監督を行うサービスとして、正しいものを1つ選びなさい。

  1. 地域密着型介護サービス
  2. 居宅介護支援
  3. 施設サービス
  4. 夜間対応型訪問介護
  5. 介護予防支援

出典：第36回 介護福祉士国家試験（社会の理解）

正解を見る

正解：3　施設サービス・居宅サービスは都道府県等。地域密着型・居宅介護支援・介護予防支援は市町村が指定します。

費用を軽くする制度

制度中身
高額介護サービス費1か月の自己負担に上限を設け、超えた分を払い戻す
高額医療・高額介護合算療養費医療と介護の自己負担を1年分合わせて上限を超えた分を払い戻す
特定入所者介護サービス費低所得の人の施設の食費・居住費を軽くする（預貯金が一定以上なら対象外）
  • 特定入所者介護サービス費は、試験では「補足給付」とも呼ばれます。対象は住民税非課税の世帯や生活保護の人で、預貯金が一定額をこえると対象外です（2015年から）
  • 要介護度で変わるのは、サービスの費用（介護報酬）です。グループホームや施設の介護費は、要介護度ごとに1日の額が決まっています。保険料（所得の段階で決まる）・負担割合（所得で決まる）・食費・居住費（施設との契約）は、要介護度では変わりません

② 介護保険施設・ユニットケア・グループホーム

施設特徴
介護老人福祉施設（特養）要介護認定が必要（第2号被保険者も同じ）。新規入所は原則要介護3以上（要介護1・2でも、認知症などでやむを得ない事情があれば特例入所できる）。根拠は老人福祉法・介護保険法。1963年の老人福祉法で創設
介護老人保健施設（老健）在宅復帰をめざすリハビリ中心。医師・看護師・リハビリ職など医療職との連携が欠かせない
介護医療院長期療養と生活の場。都道府県知事が許可。レクリエーション行事にも努める
軽費老人ホーム低額で入居。都市型は定員20人以下

ユニットケア

○×
1ユニットは原則おおむね10人以下（15人を超えない）20名程度／4人部屋
ユニットの担当職員を一定期間固定（なじみの関係）日ごとに職員を入れ替える
共同生活室で入所者同士の関係を築く居室で食事／交流はユニット内に限定
家族や友人が気軽に宿泊できる配慮施設が決めた時間内に食べ終える／施設内で生活を完結

ユニットケアは、一緒に暮らす人のまとまり（生活単位）と、職員がケアを受け持つまとまり（介護単位）を同じにするやり方です。

  • よい点：個室でプライバシーが守られる、少人数でなじみの関係ができる、家族が訪ねやすい
  • 課題：個室のぶん居住費の負担が大きい。少ない職員で働くので、職員どうしで情報を共有する場を意識してつくる。ほかのユニットとの交流も大切

グループホーム・施設での関わり

  • グループホーム＝認知症の人が5〜9人のユニットで家庭的に暮らす。教育ではなく、本人の多様な活動を大切にする
  • なじみのある人や店との関係を継続する。同じ日課・過去の状態の把握を優先・車いす移動を勧める、は×
  • 入所後すぐ「退所したい」と訴える → 思いを受け止め、発言の背景を確認

③ 介護保険の専門職

職種役割
介護支援専門員（ケアマネジャー）居宅サービス計画（ケアプラン）を作成、サービス担当者会議を開く。特養に配置義務。介護支援専門員証の有効期間は5年（更新には研修が必要）
