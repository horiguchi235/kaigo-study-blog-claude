① 傾聴・共感・受容

用語正しい意味よく出る誤り
傾聴相手の言葉を妨げずに、じっくり聴く。言葉の奥の感情を推察する解決策を提案しながら聴く／客観的事実の把握が目的／沈黙させない
共感相手の立場に立って感情を理解し、それを言葉で伝える自分の感情と区別せず同調する／同情する
受容相手の価値観を尊重し、気持ちや背景をありのまま受け止める言い分に同調する／暴言などの行動もそのまま認める（容認する）

受容は「行動を認めること」ではありません。たとえば暴言そのものはよしとしないまま、「そう言いたくなるほどつらかった」という気持ちや背景を受け止めるのが受容です。

共感の応答（いちばん出る形）

共感は態度（相手の立場で気持ちを理解し、伝える）。それを言葉にする具体的な技法が、③の感情の反射や感情の明確化です。だから「つらい気持ちなのですね」は、共感の応答でもあり、技法名でいえば感情の反射でもあります。

  • 一般化：「皆さん疲れていますよ」
  • 自分の話：「私も疲れているので、よくわかります」
  • すぐに解決策：「施設入所を検討しては」

第34回：人間関係とコミュニケーション

介護福祉職はBさんから、「認知症（dementia）の母の介護がなぜかうまくいかない。深夜に徘徊（はいかい）するので、心身共に疲れてきた」と相談された。介護福祉職は、「落ち込んでいてはダメですよ。元気を出して頑張ってください」とBさんに言った。後日、介護福祉職はBさんに対する自身の発言を振り返り、不適切だったと反省した。

介護福祉職はBさんに対してどのような返答をすればよかったのか、最も適切なものを1つ選びなさい。

  1. 「お母さんに施設へ入所してもらうことを検討してはどうですか」
  2. 「私も疲れているので、よくわかります」
  3. 「認知症（dementia）の方を介護しているご家族は、皆さん疲れていますよ」
  4. 「近所の人に助けてもらえるように、私から言っておきます」
  5. 「お母さんのために頑張ってきたんですね」

出典：第34回 介護福祉士国家試験（人間関係とコミュニケーション）

正解を見る

正解：5　まずはこれまでの苦労や気持ちを受け止める（共感的な応答）。励ましや助言、一般論で片づけるのは後回しです。

第34回：コミュニケーション技術

次の事例を読んで、問いに答えなさい。

〔事例〕

Jさん（75歳、男性）は先天性の全盲である。これまで自宅で自立した生活をしてきたが、最近、心身機能の衰えを感じて、有料老人ホームに入居した。施設での生活にまだ慣れていないので、移動は介護福祉職に誘導してもらっている。

ある日、介護福祉職がJさんを自室まで誘導したときに、「いつも手伝ってもらってすみません。なかなか場所を覚えられなくて。私はここでやっていけるでしょうか」と話してきた。

Jさんの発言への介護福祉職の共感的理解を示す対応として、最も適切なものを1つ選びなさい。

  1. Jさんの発言にうなずく。
  2. Jさんの発言のあと沈黙する。
  3. Jさんの話の内容を短くまとめて伝える。
  4. Jさんの立場に立って感情を推し測り、言葉で表現して伝える。
  5. Jさんの気持ちが前向きになるように、励ましの言葉を伝える。

出典：第34回 介護福祉士国家試験（コミュニケーション技術）

正解を見る

正解：4　共感＝相手の立場で気持ちを感じとり、言葉にして返すこと。うなずきは傾聴、まとめて返すのは要約です。2の沈黙だけでは気持ちを受け止めたことが伝わらず、5の励ましは不安な気持ちを受け止める前に前向きにさせようとするので×。

② バイステックの7原則

アメリカの社会福祉学者バイステックがまとめた、ケースワーク（個別の相談援助）で援助関係をつくるための7つの原則です。主語が利用者か援助者かに注意します。

原則意味（主語）
個別化援助者が、一人ひとりを個人としてとらえる
意図的な感情表出利用者が感情を自由に表現できるようにする（「自分の気持ちを我慢しなくてもいいですよ」）
統制された情緒的関与援助者が自分の感情を自覚・コントロールして関わる
受容援助者が、利用者をありのまま受け止める
非審判的態度援助者の価値観で善悪を判断しない
自己決定利用者が自分で決めることを尊重する
秘密保持援助者が、知り得た情報を守る

第27回のひっかけ：「意図的な感情表出＝介護福祉職の感情表出」「統制された情緒的関与＝利用者の感情をコントロール」はどちらも×。主語を入れ替えています。

③ 質問と応答の技法

技法意味・使う場面
開かれた質問自由に答えられる質問（「どのように」「何が」）。漠然とした考えを明確にする、背景にある理由を知る
閉じられた質問（閉じた質問）「はい」「いいえ」や一語で答えられる質問。例：「この本は好きですか」。事実や意思の確認、話すのが難しい人（運動性失語・疲れているとき）に向く
繰り返し相手の言葉をそのまま返す
言い換え相手の話の内容を自分の言葉で返す
要約話の内容を総合的にまとめて返し、気持ちを整理する
焦点化話の中の大事な点にしぼって返し、そこを深める
感情の反射相手が口にした気持ちを言葉で返す（「つらい気持ちなのですね」）
感情の明確化相手がまだ言葉にできていない気持ちをくみ取って言葉にする
明確化（質問の技法）話がまとまらない・あいまいなとき、何を指しているのかを確かめる質問。気持ちを言葉にする「感情の明確化」とは別もの
直面化相手が自分の感情と行動の矛盾に向き合えるよう投げかける（信頼関係ができていないと傷つける）
自己開示支援に役立つ範囲で自分のことを話す。目的は信頼関係の形成
アサーティブ相手の思いを尊重しながら、自分の意見を率直に伝える。ほかの2タイプ＝非主張的（我慢して言わない）・攻撃的（相手を押さえつける）

同じ発言への返し方のちがい（相手：「家に帰りたいけど、娘に迷惑をかけるのが心配で…」）

技法応答の例
繰り返し「家に帰りたいけど…」（相手の言葉をそのまま返す）
言い換え「自宅に戻りたいけれど、娘さんの負担になるかもしれない、ということですね」（話の内容を自分の言葉で）
感情の反射「娘さんに迷惑をかけるのが心配なのですね」（相手が口にした気持ち＝心配を返す）
感情の明確化「娘さんを大切に思うからこそ、帰りたい気持ちをがまんしているのですね」（まだ言葉にしていない気持ちをくみ取る）
焦点化「娘さんへの遠慮のことを、もう少し聞かせてください」
要約「家に帰りたい気持ちと、娘さんへの遠慮の、両方があるのですね」（話全体をまとめて返す）
明確化「『迷惑』というのは、どんなことを心配されていますか」（あいまいな言葉の中身を確かめる）
直面化「帰りたいとおっしゃる一方で、娘さんからの外泊のお誘いはいつも断っておられますね。どんなお気持ちからでしょう」（言葉と行動の矛盾に向き合ってもらう。信頼関係ができてから使う）

文全体をほぼそのまま「〜のですね」と返しても繰り返しです（第34回）。自分の言葉に置きかえたら言い換え、気持ちだけを取り出したら感情の反射、と見分けます。

ジョハリの窓と自己開示

ジョハリの窓は、自分のことを「自分が知っているか」「他人が知っているか」で4つに分けて、自分を知る・知ってもらう関係を考える枠組みです。

自分が知っている自分が知らない
他人が知っている開放の窓盲点の窓
他人が知らない秘密の窓未知の窓

自己開示をすると「開放の窓」が広がる（狭くする、は×）。

  1. 要約
  2. 承認
  3. 賞賛

第37回：コミュニケーション技術

  3. 話の途中でうなずき、利用者の気持ちに同意した。
  4. 話の内容を総合的にまとめて返し、利用者の気持ちを整理した。

正解：4　要約＝全体をまとめて返し、相手の考えや気持ちを整理する技法です。1は開かれた質問、2は共感、3はうなずき（同意）、5は自己覚知で、どれも要約ではありません。

第34回：コミュニケーション技術

  2. 利用者から苦情を言われたときは、沈黙して我慢する。

  4. 介護福祉職の提案に従うことが利用者の利益になると伝える。

④ 応答の注意点と、避けたい質問

  • 話の内容だけでなく、相手が「いま」感じている気持ちを大切にする。感情を受け止めてもらえないと、本人は「こんな気持ちになってはいけない」と思ってしまうことがある。
  • 感情は言葉・表情・しぐさ・声に表れるが、同じ表情でも意味は1つとは限らない。推測で決めつけず本人に確かめる。
  • 技法は1つに決めず、状況に応じて使い分ける。聴きながら自分の心の動き（感情・価値観）にも気づいておく（自己覚知 → 家族とのコミュニケーションと自己覚知）。
  • 質問の役割：本人が体験や思いを話すきっかけをつくる／介護に必要な情報を得る／まとまらない話をはっきりさせる／話を広げる。
  • 利用者が自分で話を広げられるよう、意識して開かれた質問を使う。閉じられた質問ばかりだと、相手の世界を狭めてしまう。
  • 質問は一度に1つ。答えを急かしたり誘導したりしない。
  • 避けたい質問：
    • 重複する質問：2つのことを同時に聞く。「AですかBですか」と答えを2つにしぼってしまう聞き方も含む
    • 「なぜ？」「どうして？」の多用：問い詰められている・責められている気持ちになる
    • 評価的な質問：聞き手の価値判断を含む質問（例「食事を残すのは、よくないと思いませんか」）
    • 遠まわしの批判になる質問：質問の形でも、責められているように聞こえる（例「お部屋がずいぶん散らかっていますが、片づけはなさらないのですか」）
