  • 経管栄養の手順とトラブル 5問
  • 経管栄養をしている人の生活支援 3問

この記事のポイント

  1. 注入は上半身を30〜45度起こし、液面は胃から約50cm上。速い・冷たい → 下痢、速い・姿勢が低い → 嘔吐。
  2. チューブが抜けていた、嘔吐した → 注入しない（止める）で看護職へ。嘔吐したら顔を横に向けて誤嚥を防ぐ。
  3. 口から食べなくても口腔ケアは必要。胃ろうでも入浴・歩行はできる。

① 経管栄養の手順とトラブル

手順のポイント

場面○ 正解×
準備石けんと流水で手洗い消費期限の新しい物から使う（古い物から）
利用者の所へ運んだら最初に本人確認体位・物品・指示内容の確認（その後）
姿勢上半身を30〜45度起こす（10度では低すぎて嘔吐）仰臥位
高さ栄養剤の液面は胃から50cm程度上—
温度常温〜人肌程度冷蔵庫から出してそのまま（下痢の原因）
注入後白湯を流してチューブ内の栄養剤を洗い流す消毒・水分補給・胃を温めるため
注入後の姿勢しばらく上半身を起こしたまま（逆流予防）すぐに横にする

トラブルと原因

トラブル主な原因
下痢注入速度が速い、栄養剤が冷たい、濃度が濃い、不潔
嘔吐注入速度が速い、姿勢が低い、量が多い
誤嚥性肺炎逆流・嘔吐、口腔内の細菌（経管栄養でも誤嚥は起こる）
呼吸困難チューブが気管に誤って入っている

こんなときどうする

場面○ 正解
経鼻チューブが10cm抜けていた注入しないで看護職に報告。元に戻す・抜く・気泡音で確認・そのまま注入は×
注入中に嘔吐、苦しそう注入を中止して看護職を呼び、誤嚥を防ぐため顔を横に向ける（片付け・換気・酸素は後）
「お腹が張ってきた」顔色・意識は変わらない腹部が圧迫されていないか確認（衣服・姿勢）。様子を見る・仰臥位・速度を上げるは×
嘔気があるとき注入を止めて看護職へ（速度を遅くして続けるは×）

半固形栄養剤

  • 胃ろう向き（経鼻は細くて詰まる）
  • 液状より粘りがある → 食道への逆流を減らす、短時間で注入できる
  • 上半身を起こして注入（仰臥位は×）

第36回：医療的ケア

経管栄養で起こるトラブルとして、最も適切なものはどれ？

  1. チューブの誤挿入で下痢が起こる
  2. 注入が速いと嘔吐が起こる
  3. 温度の調整不良で脱水が起こる
  4. 濃度の間違いで感染が起こる
  5. 注入中の姿勢が悪いと便秘が起こる
正解を見る

正解：2　注入が速い→嘔吐・下痢、誤挿入→誤嚥・肺炎、温度が低い→下痢、姿勢が悪い→逆流・誤嚥。

第36回：医療的ケア

胃ろうで半座位で注入中、半分ほど入ったところで「少しお腹が張ってきた」と言う。意識・顔色に変化はなく、腹痛や吐き気はない。看護職員に相談する前に行う対応として、最も適切なものはどれ？

  1. 吐いていないのでそのまま様子をみる
  2. 仰向けにする
  3. お腹が圧迫されていないか確認する
  4. 注入を速める
  5. 注入を終える
正解を見る

正解：3　まず姿勢や衣類でお腹が圧迫されていないかを確認します。仰向けは逆流の危険があります。

第34回：医療的ケア

半固形タイプの栄養剤の特徴として、最も適切なものはどれ？

  1. 経鼻経管栄養に向いている
  2. 液状タイプと同じ粘り気である
  3. 食道への逆流を減らすことが期待できる
  4. 仰向けで注入する
  5. 注入時間は液状タイプより長い
正解を見る

正解：3　半固形は胃ろう向けで、とろみがあるため逆流や下痢を減らし、短時間で注入できます。

第34回：医療的ケア

経管栄養で、注入後に白湯をチューブに流す理由として、最も適切なものはどれ？

  1. チューブを消毒する
  2. チューブ内の栄養剤を洗い流す
  3. 水分を補給する
  4. 胃を温める
  5. 栄養剤の濃さを調節する
正解を見る

正解：2　チューブに残った栄養剤は腐敗や詰まりの原因になるので、白湯で洗い流します。

ボタン型胃ろうの利用者に介護福祉士が行うケアとして、最も適切なものはどれ？

第35回：医療的ケア

胃ろうの注入開始から15分後、Fさんが嘔吐して苦しそうにしていた。注入を止めて看護職員を呼んだ。来るまでに最も優先すべき対応はどれ？

  1. 部屋の換気をする
  2. ベッドの嘔吐物を片付ける
  3. 酸素吸入を行う
  4. 心臓マッサージを行う
  5. 誤嚥を防ぐため顔を横に向ける
正解を見る

正解：5　最優先は窒息・誤嚥を防ぐこと＝顔を横に向ける。意識はあるので心臓マッサージは不要、酸素吸入は医療職が行います。

③ 経管栄養の種類・栄養剤・トラブルの原因

  • 経管栄養の種類：経鼻経管栄養（鼻から胃へ）／胃ろう（お腹から胃へ）／腸ろう（お腹から腸へ）／間欠的口腔食道経管栄養（注入のときだけ口から食道へチューブを入れる）。胃ろうは苦痛が比較的少なく管理しやすい。
  • 中止して医療職に連絡するとき：呼吸が苦しい・発熱・血圧低下・嘔吐・胃ろう周りからの漏れ・顔色が悪い。漏れたらまず注入を止める。介護職の都合で中止はしない。
  • 滴下が止まったら：チューブの折れ・詰まり・位置のずれを疑い、自己判断で押し込んだり入れ直したりしない（対処は医療職）。
  • 胃ろうの日常管理：周りを洗って清潔・乾燥を保つ。発赤などがあるときの入浴は医療職に確認（発赤だけで一律禁止ではない）。口から食べなくても口腔ケアは必要。
  • 子どもの経管栄養：抱っこなどでチューブが動き漏れることがあるが、固定を工夫してスキンシップは続ける。
  • 在宅の医療管理：在宅酸素療法＝禁煙・火気厳禁（2m以内に火を置かない）／人工呼吸器＝停電や故障に備える／中心静脈栄養＝感染やカテーテルの異常に注意。
  • 経管栄養の種類と特徴：胃ろう＝抜けにくい（交換は数か月ごと）が胃からの逆流が起こりうる、腸ろう＝逆流しにくいがチューブが細く詰まりやすく、速く入れると下痢や血糖の急上昇、経鼻経管＝入れ替えは簡単だが違和感が強く抜けやすい。
  • 栄養剤の区別：医薬品タイプ（医師の処方が必要・医療保険）と食品タイプ（処方不要・自費）。半固形化栄養剤は胃ろう・腸ろうの人に使い、逆流を防ぎ注入時間を短くできる（経鼻経管では使わない）。
  • 下痢の原因：注入が速い、濃度が濃い（高浸透圧）、器具が不潔、栄養剤が冷たい。
  • しゃっくりが始まったら注入を止め、上半身を起こして医療職に連絡。腹部が張ってきたら、まずお腹が圧迫されていないか確認。
  • 注入後は30分〜1時間ほど上半身を起こしたまま（逆流防止）。注入直後の口腔ケアは避ける。
  • 「口から食べたい」と経鼻チューブを抜きたがる人を手袋などで抑えるのは身体拘束。気持ちを受け止め、医師・看護職に伝える。
