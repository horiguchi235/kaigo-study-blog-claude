この記事のポイント

  1. 口腔内・鼻腔内の吸引は咽頭の手前まで（口腔内は口蓋垂に当たらない手前まで、鼻腔内は医師・看護職から指示された長さまで）、気管カニューレ内部はカニューレの先端を越えない。姿勢は上半身を10〜30度起こす。
  2. 取り切れなくても時間を延ばす・圧を上げる・太くする・とどめるは×。呼吸が落ち着いてからもう一度。
  3. 気管カニューレ内部は無菌的に（滅菌精製水）。終わったら人工呼吸器の作動とSpO2を確認。

注意　喀痰吸引・経管栄養は、所定の研修を修了し、医師の指示のもとで行う行為です。この記事の手順は試験の基本としてまとめたもので、実際は研修と勤務先の手順に従ってください。

言葉の意味

  • 陰圧＝吸い込む力が出ている状態。吸引器が陰圧になれば、痰を吸い出せる。
  • 気管切開＝首の前に穴をあけて気管に通じる道をつくること。その穴に入れる管が気管カニューレ。
  • 臥位（がい）＝寝た姿勢。仰臥位＝あおむけ、腹臥位＝うつぶせ。
  • COPD＝慢性閉塞性肺疾患。たばこなどで肺が傷み、息が吐きにくく痰がたまりやすい病気。

位置関係：顔を横から見ると、鼻腔・口腔の奥に咽頭（のど）があり、その下で空気の通り道の喉頭・気管（前）と、食べ物の通り道の食道（後ろ）に分かれます。介護福祉士が吸引できるのは咽頭の手前まで。鼻腔の吸引では、チューブを鼻の穴から上向きではなく、顔に対して水平に、まっすぐ奥へ進めます。

② 口腔内・鼻腔内の吸引

姿勢

  • 姿勢は上半身を10〜30度挙上（少し起こした姿勢）。
  • 頭を低くする・平らなあおむけ（仰臥位）・うつぶせ（腹臥位）・座らせるは×。

いつ吸引するか・吸引の前に見ること

  • 吸引は時間を決めて行うものではなく、痰がたまって本人が苦しいとき・必要なときに行います。「1時間おきに」「就寝後は控える」は×。食後や就寝中でも必要なら行います（試験では「食後の吸引は避ける」は×）。
  • ただし食べた直後は、チューブの刺激で吐きやすいので、姿勢と吐き気に注意します。
  • 吸引が必要になりやすい状態：痰が増えている・咳の力が弱い・痰がかたい。
  • 吸引の前に、口の中の状態と入れ歯（義歯）を確かめます（ぐらついた義歯は、口を開けたときに落ち込むおそれ）。口から吸引したから鼻は不要、とは限りません。

手順の流れ

  1. 医師の指示書を確認し、利用者に説明して同意を得る（毎回）
  2. 実施者が手洗い・手指消毒、使い捨て手袋をつける
  3. カーテンなどでプライバシーに配慮し、姿勢を整える
  4. 物品（吸引器・吸引びんの量・カテーテル・清浄綿〈消毒液をしみこませた使い捨ての綿〉・手袋など）を確認し、吸引器のスイッチを入れて陰圧になること、圧が指示どおりかを確かめる
  5. 圧をかけずにチューブを入れる（鼻腔は粘膜が薄く出血しやすいので、とくにゆっくり）
  6. 圧をかけ、チューブを回しながら、決められた時間内で吸う
  7. 終わったらチューブの外側を清浄綿で拭き、洗浄水を吸って内側を洗う
  8. 利用者の顔色・呼吸・痰の量や色を観察し、報告・記録する

第38回：医療的ケア

Aさん（85歳、男性）は、慢性閉塞性肺疾患（chronic obstructive pulmonary disease）で、介護老人福祉施設に入所している。ある日、Aさんから、「痰（たん）がからんでいて、咳（せき）をしても出せない」という訴えがあった。介護福祉士が呼吸回数を確認すると、1分間に22回で、ゴロゴロという音がしていた。看護職からは、右肺に痰が貯留しやすいという情報提供があった。口腔内吸引（こうくうないきゅういん）をすると、粘性の強い透明な痰が吸引できた。

このとき、介護福祉士が喀痰排出（かくたんはいしゅつ）を促すためにAさんに行う対応として、最も適切なものを1つ選びなさい。

  1. 居室の湿度を30％に保つ。
  2. 水分摂取を控えるように伝える。
  3. 左側を下にした体位を勧める。
  4. 太い吸引チューブに変える。
  5. ベッド上での安静を勧める。

出典：第38回 介護福祉士国家試験（医療的ケア）

正解を見る

正解：3　痰がたまっている側（右）を上にすると重力で痰が動きます（体位ドレナージ）。湿度は50〜60％、水分補給で痰をやわらかくします（1・2は×）。4の太いチューブは、取り切れないときに自分で変えてよいものではなく、5の安静も痰が動きにくくなるので×。

③ 気管カニューレ内部の吸引と人工呼吸器

気管カニューレの構造

  • 気管切開した穴から気管に入れる管（咽頭ではない）。定期的に交換が必要（医療職）
  • カフは下端についた風船で、空気を入れてふくらませる（すき間から分泌物が気管に流れ込むのを防ぐ）
  • サイドチューブから、カフの上にたまった分泌物を吸引できる
  • パイロットバルーン＝カフのふくらみ具合を外から確かめる小さな風船

吸引のときの注意

  • カニューレの先端を越えて入れると、気管の壁を傷つけるほか、迷走神経（心臓の動きをゆっくりにする神経）が刺激されて、心拍が遅くなる・血圧が下がる危険がある。
  • カニューレを抜いて吸引する・20〜30秒吸引する・気管分岐部まで入れる、は×。
  • 吸引中は空気も吸い出すので、指示より長くなったら動脈血酸素飽和度（SpO2）・顔色・呼吸を確認する。

人工呼吸器

  • 気管切開して使う侵襲的（体に管を入れる）なものと、鼻や口のマスクで使う非侵襲的なものがある。
  • 吸引のときはコネクターを外し、終わったら確実につなぎ、人工呼吸器の作動状況を確認する。
  • 停電時の電源を確保しておく。アラームが鳴りやまないときは、すぐ医療職へ。
  • マスク型（非侵襲的）の人に口腔・鼻腔の吸引をするときは、取り決めに沿ってマスクを外し、外している時間が長くならないよう手早く行い、終わったらマスクが確実についているかを確認する。吐くと息の通り道がふさがるので、顔を横に向けた姿勢にしておく。
  • 気管カニューレの人は、人工呼吸器から空気が入ったのを確かめてからコネクターを外し、回路の中の水滴がカニューレに入らないようにする。

第34回：医療的ケア

気管カニューレ内部の喀痰吸引（かくたんきゅういん）で、指示された吸引時間よりも長くなった場合、吸引後に注意すべき項目として、最も適切なものを1つ選びなさい。

  1. 体温
  2. 血糖値
  3. 動脈血酸素飽和度
  4. 痰（たん）の色
  5. 唾液の量

出典：第34回 介護福祉士国家試験（医療的ケア）

正解を見る

正解：3　吸引中は空気も吸い出すので、長くなると低酸素に。SpO2（動脈血酸素飽和度）・顔色・呼吸を確認します。体温・血糖値は吸引時間とは関係が薄く、痰の色・唾液の量は時間が長くなったことによる危険（低酸素）を見る項目ではありません。

物品の管理

○×
吸引びんの中身は70〜80％になる前に捨てるあふれる直前まで使う
洗浄水・消毒液は少なくとも24時間ごとに交換（施設では8時間ごとも）。継ぎ足さず、容器ごと取り換える72時間で交換／継ぎ足して使う
チューブの洗浄は水（気管カニューレは滅菌精製水）アルコールで洗浄
物品は清潔な場所に置く床やベッドに直接置く
清浄綿は1回ごとに捨てる使い回す
  • 吸引チューブの保管は、浸漬法（しんしほう：消毒液につけておく）か、乾燥法（乾かして保管する）。気管カニューレ内部の吸引チューブは、感染予防のため1回ごとの使い捨てがすすめられている。
  • 停電に備えて、手動式・足踏み式の吸引器を予備にすることもある。

本人・家族の気持ちへの対応

  • 吸引は、本人や家族にとって苦痛や不安が大きいものです。気持ちを否定せずに受け止め、療養生活の不安や希望を具体的に聞きます。
  • 強く嫌がるときは、医師・看護職と一緒に説明し、複数でかかわって、本人の気持ちを医療職と共有します。
  • 説明する内容：なぜ必要か・目的と方法・起こりうる危険・ほかの方法があるか・しなかった場合どうなるか。

子どもの吸引・家族

  • 子どもは吸引の必要性を理解できず、怖がって抵抗することが多い。年齢に応じて事前に説明し（プレパレーション）、泣いていたら落ち着くまで待つ。
  • 吸引圧は大人より低く、時間も短く。チューブの長さなどは個別の指示に従う。
  • 在宅では、家族もあらかじめ吸引の操作の練習を受けておくとよい。
