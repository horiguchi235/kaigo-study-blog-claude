  • 片麻痺の起き上がり・立ち上がり・移乗・着脱 7問
  • 杖歩行・階段昇降・歩行の助言 4問
  • 杖・歩行器の種類と選び方 2問

この記事のポイント

  1. 片麻痺の介助は「健側を使ってもらい、介護者は患側に立って守る」。車いすは健側に置く。
  2. 杖は健側に持つ。平地は「杖 → 患側 → 健側」、階段は「上りは健側から、下りは患側から」。
  3. 杖の握りの高さは大転子。握力が弱い人はロフストランドクラッチ、手首が痛い人はプラットホームクラッチ。

① 起き上がり・立ち上がり・移乗

まず最初に：移乗の目的を説明して同意を得る。方法の説明や車いすの準備はその後。

起き上がり（側臥位 → 端座位）

  • 健側を下にした側臥位から、健側の肘を支点に上体を起こしてもらう
  • 患側を下にして起き上がる・介護者が頸部を支えて起こす、は×

立ち上がり

○×
ベッドに浅く座り直す深く腰掛ける
足を引き、前かがみ（前傾）になってから立つ背すじを伸ばして真上に立つ／真上に持ち上げる
介護者は患側に立つ健側に立つ
患側の膝に手を当てて膝折れを防ぐ健側の膝を支える／患側に荷重がかかるように支える
立ったら膝の裏が伸びている（しっかり立てている）か確認—

車いすへの移乗

  • 車いすは健側に、ベッドに対して斜め（20〜30度）に置く
  • フットサポートは上げておく、ブレーキをかける
  • 移るときは前傾姿勢をとってもらい、健側の足を軸に回る

スライディングボード

○×
立位はとれないが座位が保て、上肢が使える人—
ベッドを車いすの座面より少し高くする（高い方から低い方へ滑る）ベッドと車いすの間を大きくあける
アームサポートが外せる車いすを使うアームサポートが固定された車いす
ゆっくり移動する。抜くときは体を少し傾けて抜く臀部を素早く移動／傾けずに抜く

そのほかの場面

場面○ 正解
夜間のポータブルトイレ（右片麻痺・膝関節症）ベッドにスイングアーム介助バーを設置。トイレは健側に、ベッドと同じ高さ
左片麻痺の人が浴槽から立つ右手（健側）で手すりをつかみ、前傾して臀部を浮かす
臥床で前開きの上着を交換（左片麻痺）脱ぐ前に患側（左）の肩口を広げておく。脱健着患
端座位でズボンをはく（左片麻痺）患側の足を健側の大腿にのせてズボンを通す

第38回：生活支援技術

右片麻痺のある利用者を、仰向けから車いすへ移乗する介護として、最も適切なものはどれ？

  1. 右側臥位になって起き上がるよう促す
  2. 端座位になった利用者の左側に立つ
  3. 端座位の利用者の右側に車いすを置く
  4. 車いすのフットサポートは下げておく
  5. 移乗するときは前かがみになるよう促す
正解を見る

正解：5　前傾姿勢で重心が足に乗り、立ち上がりやすくなります。起き上がりは健側（左）を下に、車いすは健側（左）に置き、介護者は麻痺側（右）に立ちます。

第37回：生活支援技術

左片麻痺の利用者を右側臥位から端座位にする介護として、最も適切なものはどれ？

  1. 左手でベッド柵をつかむよう伝える
  2. 右肘を支点にして上体を起こしてもらう
  3. 右脚だけをベッドから下ろす
  4. 首を支えて上体を起こす
  5. 端座位の利用者の右側に立って支える
正解を見る

正解：2　健側（右）の肘→手のひらで体を支えて起き上がる。介護者は倒れやすい麻痺側（左）に立ちます。

第36回：生活支援技術

回復期の左片麻痺の利用者が、ベッドの端座位から立ち上がるときの介護として、最も適切なものはどれ？

  1. 利用者の右側に立つ
  2. ベッドに深く座るよう促す
  3. 背すじを伸ばして真上に立つよう促す
  4. 左側に体重がかかるように支える
  5. 左の膝頭に手を当てて膝折れを防ぐ
正解を見る

正解：5　麻痺側（左）の膝頭を支えて膝折れを防ぐ。浅く座り、前かがみで立ち、体重は健側にかけます。

第36回：生活支援技術

左片麻痺の利用者が端座位でズボンをはくときの介護として、最も適切なものはどれ？

  1. 最初に左の腰を上げて脱ぐよう促す
  2. 右膝を高く上げて脱ぐよう促す

覚え方：「上りは良い足（健側）から天国へ、下りは悪い足（患側）から地獄へ」。

④ 杖の長さ・種類と移乗の位置取り

  • T字杖の長さは、立った姿勢で床から大転子（太もものつけ根の骨の出っぱり）までが目安（肘が軽く曲がる高さ）。
  • 2動作歩行＝杖と麻痺側の足を同時に出す→健側の足／3動作歩行＝杖→麻痺側→健側。
  • 階段：上りは健側から、下りは杖→麻痺側から（「のぼりは良い足から、くだりは悪い足から」）。
  • 病気と福祉用具の組み合わせ：関節リウマチ＝補高便座（立ち座りの負担を軽く）／難聴＝光や振動で知らせる機器／片麻痺の移乗＝スライディングボード。パーキンソン病は手の震えがあるので筆談器は合わない。用具は病名ではなく実際の機能と希望で選ぶ。
  • 杖の長さのめやす：大転子の高さ、握ったとき肘が約150度（軽く曲がる）。杖先は足先の前外側約15cmに置く。
  • 階段：上りは杖→健側→患側、下りは杖→患側→健側。介助者は、上りは患側の斜め後ろ、下りは患側の斜め前（一段下）で支える。
  • 杖の種類：T字杖（最も一般的）、多点杖（3点・4点で安定）、ロフストランドクラッチ（前腕で支える、握力が弱い人）、プラットホームクラッチ（前腕をのせる、関節リウマチなど）、ウォーカーケイン（支持面が広い）。
  • 片麻痺の人のベッドから車いすへの移乗：車いすは健側に置き、ベッドに対して約15〜20度の角度。ベッドの高さを車いすの座面にそろえる。
