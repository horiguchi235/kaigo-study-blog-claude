この記事のポイント

  1. 片麻痺の介助は「健側を使ってもらい、介護者は患側に立って守る」。車いすは健側に置く。
  2. 杖は健側に持つ。平地は「杖 → 患側 → 健側」、階段は「上りは健側から、下りは患側から」。
  3. 杖の握りの高さは大転子（太もものつけ根の外側にある骨の出っぱり）。握力が弱い人はロフストランドクラッチ、手首が痛い人はプラットホームクラッチ。

この記事の前提：健側＝麻痺のない側、患側（麻痺側）＝麻痺のある側。右片麻痺なら健側は左です。

① 起き上がり・立ち上がり・移乗

まず最初に：移乗の目的を説明して同意を得る。方法の説明や車いすの準備はその後。

起き上がり（側臥位 → 端座位）

  • 健側を下にした側臥位から、健側の肘を支点に上体を起こしてもらう
  • 患側を下にして起き上がる・介護者が頸部を支えて起こす、は×

立ち上がり

○×
ベッドに浅く座り直す深く腰掛ける
足を引き、前かがみ（前傾）になってから立つ背すじを伸ばして真上に立つ／真上に持ち上げる
介護者は患側に立つ健側に立つ
患側の膝に手を当てて膝折れ（膝の力が抜けてがくっと曲がること）を防ぐ健側の膝を支える／患側に荷重がかかるように支える
立ったら健側の膝の裏が伸びている（健側でしっかり体重を支えられている）か確認—

膝は「確認するのは健側、手を当てて支えるのは患側」。左片麻痺なら、右膝の裏が伸びているかを確認し、左膝に手を当てます。膝の裏のくぼみを膝窩（しっか）といいます。

車いすへの移乗

  • 車いすは健側に、ベッドに対して斜め（15〜30度程度。テキストにより幅がある）に置く。ベッドの高さは車いすの座面にそろえる
  • フットサポートは上げておく、ブレーキをかける
  • 移るときは前傾姿勢をとってもらい、健側の足を軸に回る。座ったら深く座り直し、フットサポートを下ろして足をのせる

スライディングボード

スライディングボードは、ベッドと車いすの座面の間に渡す板です。立ち上がらず、座ったまま板の上を滑って移ります。

○×
立位はとれないが座位が保て、上肢が使える人—
ベッドを車いすの座面より少し高くする（高い方から低い方へ滑る）ベッドと車いすの間を大きくあける
アームサポートが外せる車いすを使うアームサポートが固定された車いす
ゆっくり移動する。抜くときは体を少し傾けて抜く臀部を素早く移動／傾けずに抜く

片麻痺の原則はどの場面でも同じ

「健側を使ってもらう・患側を守る」は、トイレ・入浴・着替えでも変わりません。

場面○ 正解
夜間のポータブルトイレ（右片麻痺・膝関節症）ベッドにスイングアーム介助バー（ベッドに取り付け、横に開け閉めできる手すり）を設置。トイレは健側に、ベッドとほぼ同じ高さで、座ったとき足底が床につく高さ
左片麻痺の人が浴槽から立つ右手（健側）で手すりをつかみ、前傾して臀部を浮かす
臥床で前開きの上着を交換（左片麻痺）脱ぐ前に患側（左）の肩口を広げておく。脱健着患（脱ぐときは健側から、着るときは患側から）
端座位でズボンをはく（左片麻痺）患側の足を健側の大腿にのせてズボンを通す

② 杖歩行・階段昇降

場面順番・位置
杖を持つ手健側。杖先は足先の前外側（約15cm）につく
3動作歩行杖 → 患側 → 健側（右片麻痺なら「杖、右足、左足」）
2動作歩行杖と患側を同時 → 健側
階段を上る杖 → 健側 → 患側
階段を下りる杖 → 患側 → 健側
手すりで階段手すりは健側でつかむ
溝をまたぐ杖は溝の向こう側に突く → 患側の足からまたぐ → 健側の足。またいだら両足をそろえてから次へ

覚え方：「のぼりは元気な足（健側）から、くだりは麻痺の足（患側）から」。

  • 3動作歩行は2動作歩行より遅いが安定しています。3動作で安定して歩けるようになってから2動作へ進みます
  • バスの乗り降りの段も、階段と同じ足の順です。杖の先には滑り止めのゴムをつけます
  • 一部介助で杖を使い始めた人は、転ぶ怖さや疲れを感じやすいので、左右の足に少しずつ体重を移す練習から始めます

介護者が立つ位置

場面介護者の位置
立ち上がり・移乗患側（膝折れや転倒を防ぐ）
歩行患側のやや後ろ
階段を上る患側の斜め後ろ
階段を下りる患側の斜め前（一段下）

歩行のしくみ

歩行は、片足で体を支えている間（立脚相）に反対の足を前へ振り出し（遊脚相）、これを左右交互にくり返す動きです。重心が高く、一歩ごとに支える面が移るので不安定です。

  • 「麻痺側の立脚相が短い」＝麻痺側で体を支えている時間が短く、そちらへ崩れやすい → 介護者は麻痺側の後方で見守ります
  • 屋外を歩くには、注意力・判断力・道順を覚える力も必要です。歩くことは全身の血のめぐり、心臓や肺の働き、骨と筋肉の維持に役立ちます

歩行の助言・意欲

  • 安定した歩行：後ろ足のつま先で地面を蹴って踏み出す。歩幅は広く、腕を振り、前を見て、かかとから着地
  • 歩行が不安定で意欲が落ちた人：達成できる目標距離を設定し、成功体験を積む。福祉用具を避ける・移動範囲を狭める・本人の希望なしに毎日歩かせる、は×

③ 杖・歩行器の種類と選び方

用具合う人・使い方
杖の高さ握りを大転子の高さに。握ったとき肘を約30度曲げる（肘の内側の角度でいうと約150度）
T字杖歩行が比較的安定している人
多点杖杖先が4本など複数の脚に分かれ、T字杖より安定。片麻痺など歩行が不安定な人
ロフストランドクラッチ（前腕固定型）握りの上に前腕を支えるカフ（輪）が付く。握力が弱い人
プラットホームクラッチ（前腕支持型）手首に負担をかけられない人＝関節リウマチ
松葉杖わきの下近くと握りで体を支える杖。主に足のけがなどで、片足に体重をかけられないときに使う
歩行器杖より安定性が高い
固定式歩行器両手で持ち上げて前に置いて進む。握力があり、数秒立っていられる人
前輪付き歩行器前に車輪があり、持ち上げずに押して進む
交互型歩行器左右のフレームを交互に出す
歩行器型杖（ウォーカーケイン）片麻痺で杖歩行が不安定な人
シルバーカー自立歩行できる人の買い物・休憩用。体重をあずけて支える道具ではない
  • 用具は病名ではなく実際の機能と希望で選びます。例：関節リウマチ＝補高便座（便座を高くして立ち座りの負担を軽く）、難聴＝光や振動で知らせる機器、片麻痺の移乗＝スライディングボード。パーキンソン病は手の震えがあるので筆談器は合いません
  • 施設では、本人が使い慣れた歩行器を優先します。対麻痺（両足の麻痺。胸髄・腰髄の損傷などで起こる）で足を交互に出せない人には、固定式歩行器は合いません
  • 回復していく人では、理学療法士などと連携して、回復に合わせて介助方法を変えます。体の状態が変わったら介護支援専門員に伝え、ケアプランの見直しにつなげます
