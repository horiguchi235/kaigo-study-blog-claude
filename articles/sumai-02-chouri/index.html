項目○ 正解

第37回：生活支援技術

基本調味料の効果や使い方として、適切なものはどれ？

  1. 砂糖は塩より先に入れると甘みがしみこみやすい
  2. 塩はうま味を増し照りを出す
  3. 酢は水分を引き出し保存性を高める
  4. しょうゆはくさみを抜き肉をやわらかくする
  5. みそは最初に入れると香りが逃げない
正解を見る

正解：1　さしすせそ（砂糖→塩→酢→しょうゆ→みそ）。砂糖は分子が大きくしみこみにくいので先に。香りの立つしょうゆ・みそは最後です。

第37回：生活支援技術

食品の保存として、最も適切なものはどれ？

  1. 賞味期限切れの未開封の缶詰はすぐ捨てる
  2. ウインナーには消費期限が書かれている
  3. 前日に作り常温で置いた肉入りカレーは温め直せばよい
  4. りんごを冷蔵庫に入れるときはビニール袋に入れて密封する
  5. 一度解凍した冷凍食品も再冷凍すれば長く保存できる
正解を見る

正解：4　りんごはエチレンガスで他の野菜を傷めるので密封。賞味期限は「おいしさの目安」、ウインナーは賞味期限、常温のカレーはウエルシュ菌に注意です。

弱視で物の区別がつきにくい人の調理と買い物の支援として、最も適切なものはどれ？

  1. 買い物はガイドヘルパーに任せるよう勧める
  2. 硬貨とお札を同じ場所に入れる財布を勧める
  3. 包丁は調理台の手前に置くよう勧める
  4. まな板は食材と同じ色にするよう勧める
  5. よく使う調理器具はいつも同じ場所にしまうよう勧める
正解を見る

正解：5　置き場所を決めると探しやすく安全。まな板は食材と反対の色、包丁は奥に、財布は種類ごとに分けて。

関節リウマチのある人が少ない負担で家事をするための助言として、最も適切なものはどれ？

  1. 掃除は早朝に行う
  2. 食器洗いは水を使う
  3. テーブルは手のひらの付け根で拭く
  4. 瓶のふたは指先で開ける
  5. 洗濯かごは片手で持つ

慢性腎不全の利用者の食材や調理方法として、最も適切なものはどれ？

  1. エネルギーの高い植物油を控える
  2. レモンや香辛料を使い、塩分を控える
  3. 肉や魚を多めにする
  4. 砂糖を控える
  5. 野菜は生のままサラダにする
正解を見る

正解：2　酸味・香辛料で減塩。たんぱく質は制限し、エネルギーは油や砂糖で確保、カリウムを減らすため野菜はゆでこぼします。

④ 家計

可処分所得 ＝ 実収入 − 非消費支出（税金・社会保険料）
  • 実収入12万円・非消費支出2万円 → 可処分所得10万円。消費支出14万円との差は貯蓄の取り崩し
  • 高齢単身無職世帯：主な収入は公的年金。消費支出が可処分所得を上回る（不足分は貯蓄から）
  • エンゲル係数＝消費支出に占める食料費の割合 → 相談されたら食料費の内容を一緒に考える

⑤ 下ごしらえ・かゆ・食品表示・クーリング・オフ

  • 右麻痺の人の調理訓練：左手への利き手交換、食材を固定する釘付きまな板、ピーラーなど片手で使える道具。リーチャーは離れた軽い物をつかむ道具で、鍋を持つのには使わない。
  • ゼラチンと寒天：ゼラチン＝動物性のたんぱく質、冷やすと固まり温めると溶ける、沸騰させると固まる力が落ちる／寒天＝海藻由来、常温でも固まる。
  • 冷蔵庫は詰め込みすぎない（容量の70％程度）、扉の開け閉めは短く。冷凍しても劣化は進むので長く放置しない。
  • 下ごしらえ：じゃがいもの芽には毒（ソラニン）があるので取る、れんこんは酢水、ごぼうは水であく抜き、アサリ・ハマグリは約3％の塩水で砂抜き。
  • とろみ・固める材料：でんぷん（片栗粉など）、寒天（海藻が原料・常温で固まる）、ゼラチン（動物の骨や皮が原料・冷やして固める・口の中で溶けやすい）。
  • かゆの水の量：全がゆ＝米の約5倍、七分がゆ＝7倍、五分がゆ＝10倍、三分がゆ＝20倍。ふつうの炊飯は米の重量の1.5倍・容量の1.2倍。
  • 賞味期限＝おいしく食べられる期限（品質の劣化がゆるやかなもの）、消費期限＝安全に食べられる期限（劣化が早いもの）。一度解凍したものは再冷凍しない。
  • クーリング・オフ：訪問販売・電話勧誘・エステや語学教室など＝8日、マルチ商法・内職商法（モニター商法）＝20日。書面（はがき・内容証明郵便）で行う。通信販売は対象外（返品は特約しだい）。
