① 発達理論

エリクソンの発達段階

段階（目安の年齢）発達課題 ○失敗すると
乳児期（0〜1歳）基本的信頼不信
幼児前期（1〜3歳）自律性（自分をコントロール）恥・疑惑
幼児後期（3〜6歳）自発性（主体性）罪悪感
学童期（6〜12歳）勤勉性劣等感
青年期（12〜20歳）同一性（アイデンティティ）同一性の拡散
成人前期（20〜30歳）親密性孤立
成人期（30〜60歳）生殖性（世代性）停滞
老年期統合絶望

「1歳までに行動のコントロール」「12〜20歳で勤勉性」「30〜60歳で信頼感」はすべて段階がずれた×。

ピアジェの認知発達

段階年齢特徴
感覚運動期0〜2歳見る・触るで世界を知る。対象の永続性
前操作期2〜7歳見立て遊び（積み木を飛行機に）、自己中心性、見た目にとらわれ保存ができない
具体的操作期7〜11歳具体物なら論理的に考えられる。保存の概念の獲得
形式的操作期11歳〜抽象的・仮説的に考えられる

ハヴィガースト・コールバーグ・スキャモン

理論押さえる正解
ハヴィガーストの児童期読み・書き・計算の基礎的技能を発達させる
ハヴィガーストの中年期市民的・社会的責任を果たす。配偶者の死への適応は老年期
コールバーグの道徳性最も高い段階＝人間の権利や平等などの普遍的な倫理に従う。罰の回避・損得・多数意見・権威への服従は低い段階
スキャモンの発育曲線神経系は乳幼児期に急速に発達、生殖器系は12歳ごろから急速に発達。リンパ系は思春期に成人の約2倍

第38回：発達と老化の理解

ハヴィガーストの示す中年期の発達課題にあたるものはどれ？

  1. 良心・道徳心・価値観を育てる
  2. 大人としての市民的・社会的責任を果たす
  3. 満足できる住まいを確保する
  4. 男性・女性としての社会的役割を身につける
  5. 気の合う仲間の集まりを見つける
正解を見る

正解：2　中年期は市民的・社会的責任を果たすこと。1は児童期、4は青年期、3・5は老年期の課題です。

第36回：発達と老化の理解

スキャモンの発達曲線について、適切なものはどれ？

  1. 神経系は4歳ごろから急に発達する
  2. 筋骨格系は4歳ごろから急に発達する
  3. 生殖器系は12歳ごろから急に発達する
  4. 循環器系は20歳ごろから急に発達する
  5. リンパ系は20歳ごろから急に発達する
正解を見る

正解：3　神経型は乳幼児期に早く、生殖型は思春期（12歳ごろ）から急に、リンパ型は思春期に大人の2倍近くまで伸びます。

② 乳幼児の発達・愛着・社会的参照

時期標準的な発達
生後3か月体重が出生時の約2倍。首がすわる
生後6か月ごろ喃語、寝返り
8か月ごろ人見知り
9か月〜1歳指さし、つかまり立ち
1歳ごろ体重約3倍、初語、ひとり歩き
1歳半ごろ語彙が急に増える（語彙爆発）
2歳ごろ二語文

愛着と社会的参照

用語試験の正解
社会的参照見知らぬ人や状況で、養育者の表情を見て行動を決める（父の友人を見て父の顔を見る・視覚的断崖で母の表情を確かめる）
ストレンジ・シチュエーション法の安定型養育者がいないと不安になり、再会すると安心して再び遊ぶ
回避型分離しても泣かず、再会しても避ける
アンビバレント型再会しても怒って抵抗し、なかなか落ち着かない

第37回：発達と老化の理解

子どもの標準的な成長として、適切なものはどれ？

  1. 1歳半〜2歳ごろにハイハイで移動できる
  2. 生後9か月〜1歳ごろに指さしで関心や要求を伝えられる
  3. 語彙爆発は5歳を過ぎてから起きる
  4. 人見知りは2歳を過ぎてから起きる
