この記事のポイント

  1. 虐待は5類型（身体的・介護等放棄・心理的・性的・経済的）。気づいたら上司に報告し市町村に通報。通報する人は事実を確かめなくてよい（確認するのは市町村）。通報は守秘義務違反にならない。
  2. 身体拘束の例外は切迫性・非代替性・一時性の3つすべてを満たすとき。組織で判断し、説明し、記録する。
  3. 障害者虐待防止法は使用者（雇い主）による虐待も対象。著しい暴言・拒絶的な対応＝心理的虐待。

本人の権利が侵害される場面には、虐待、差別や偏見、悪質商法や詐欺などがあります。虐待は、知識の不足や人間関係のもつれから、本人に悪気がないまま起こることもあります。

セルフ・ネグレクト（自己放任）＝本人が自分で食事・入浴・受診などをしなくなり、ごみがたまった家などで健康や安全が損なわれる状態です。法律の虐待の5類型には入りませんが、放っておくと命にかかわるので、地域包括支援センターにつないで支えます。

① 高齢者虐待防止法と対応

法律のポイント

正式な名前は「高齢者虐待の防止、高齢者の養護者に対する支援等に関する法律」です（2005年成立・2006年施行）。虐待を防ぐだけでなく、介護疲れなどで追いつめられた養護者（家族）を支えることも目的です（相談・助言、ショートステイで負担を軽くするなど）。家族を責めるのではなく、家族ごと支える視点が大切です。

○×
高齢者＝65歳以上60歳以上
対象は養護者（家で世話をしている家族・親族など）と養介護施設従事者等（老人福祉法・介護保険法の施設・事業所で働く職員。病院の職員は入らない）による虐待養護者＝施設従事者／施設サービス利用者だけが対象／病院も対象
類型は5つ（下の表）3つ
通報先は市町村施設長に通報／警察署長が認定
通報する人は虐待の事実確認は不要（「思われる」段階でよい）。通報を受けた市町村が安全確認と事実確認をする通報する前に事実確認が必要
虐待を受けた本人も届け出られる—
立入調査で警察の援助は必要に応じて警察官の同行が義務

第35回：社会の理解

「高齢者虐待防止法」に関する次の記述のうち、最も適切なものを1つ選びなさい。

（注）「高齢者虐待防止法」とは、「高齢者虐待の防止、高齢者の養護者に対する支援等に関する法律」のことである。

  1. 虐待が起こる場として、家庭、施設、病院の3つが規定されている。
  2. 対象は、介護保険制度の施設サービス利用者とされている。
  3. 徘徊（はいかい）しないように車いすに固定することは、身体拘束には当たらない。
  4. 虐待を発見した要介護施設従事者には、通報する義務がある。
  5. 虐待の認定は、警察署長が行う。

出典：第35回 介護福祉士国家試験（社会の理解）

正解を見る

正解：4　施設従事者は発見したら通報義務。法律の対象は養護者による虐待と施設従事者等による虐待の2つ（病院は含まない）で、対応の中心は市町村です。徘徊しないよう車いすに固定するのは身体拘束にあたります（②）。

第34回：人間の尊厳と自立

Aさん（80歳、女性、要介護1）は、筋力や理解力の低下がみられ、訪問介護（ホームヘルプサービス）を利用している。訪問介護員（ホームヘルパー）がいない時間帯は、同居している長男（53歳、無職）に頼って生活をしている。長男はAさんの年金で生計を立てていて、ほとんど外出しないで家にいる。

ある時、Aさんは訪問介護員（ホームヘルパー）に、「長男は暴力がひどくてね。この間も殴られて、とても怖かった。長男には言わないでね。あとで何をされるかわからないから」と話した。訪問介護員（ホームヘルパー）は、Aさんのからだに複数のあざがあることを確認した。

訪問介護員（ホームヘルパー）の対応に関する次の記述のうち、最も適切なものを1つ選びなさい。

  1. 長男の虐待を疑い、上司に報告し、市町村に通報する。
  2. 長男の仕事が見つかるようにハローワークを紹介する。
  3. Aさんの気持ちを大切にして何もしない。
  4. すぐに長男を別室に呼び、事実を確認する。
  5. 長男の暴力に気づいたかを近所の人に確認する。

出典：第34回 介護福祉士国家試験（人間の尊厳と自立）

正解を見る

正解：1　虐待が疑われる段階で上司に報告し市町村へ通報。確証は不要で、通報しても守秘義務違反になりません。

② 身体拘束

身体拘束は介護保険の施設などで原則禁止です。国は2001年に「身体拘束ゼロへの手引き」で禁止の対象となる11の行為を示し、2024年3月にその考え方を引き継いだ「身体拘束廃止・防止の手引き」に改訂しました（対象を施設だけでなく在宅の事業所や家族にも広げた）。

身体拘束にあたる行為（手引きの11項目）

  • 徘徊・転落を防ぐため、車いす・いす・ベッドに体や手足をひもなどで縛る（3項目）
  • 自分で降りられないよう、ベッドを柵（サイドレール）で囲む
  • チューブを抜かないよう手足を縛る／ミトン型の手袋をつける
  • ずり落ち・立ち上がりを防ぐため、Y字型抑制帯・腰ベルト・車いすテーブルをつける
  • 立ち上がる力のある人に、立ち上がれないいすを使う
  • 脱衣やおむつはずしを防ぐため、つなぎ服（介護衣）を着せる
  • 行動を落ち着かせるため、向精神薬を過剰に飲ませる
  • 自分で開けられない部屋に隔離する

身体拘束の弊害は、身体的（筋力低下・褥瘡・食欲低下・転倒）、精神的（尊厳の侵害・認知症の進行・家族の罪悪感）、社会的（施設への不信・職員の士気低下）の3つです。

やむを得ず行う場合

○×
切迫性（命や体に危険がせまる）・非代替性（ほかに方法がない）・一時性（一時的）の3要件すべて2要件・「永続性」
組織として判断（委員会など）職員1人の判断／家族の承諾書があればよい
本人・家族にそのつど説明事前説明があれば省略できる
態様・時間・心身の状況・理由を記録し、できるだけ早く解除する保険者に毎回報告する義務

「ほかに方法がない（非代替性）」と言うには、先に代わりの方法を試していることが必要です。

心配なこと拘束の代わりに試す工夫
ベッドから落ちる低いベッドにする・床にマットを敷く・センサーで知らせる
一人で立ち上がって転ぶ立ち上がる理由（トイレ・不安など）を探し、時間を決めてトイレに誘う
チューブを抜いてしまうかゆみや違和感を医療職と相談し、目に入りにくい位置に固定する

本人の同意なくおむつをつけることは、手引きの11項目には入っていません。ただし、必要のないおむつは尊厳を傷つける不適切なケアです。

2024年度の介護報酬改定で強まったこと

  • 虐待防止措置（委員会の開催・指針の整備・研修・担当者の設置）は、2024年4月からほぼすべての介護サービスで義務。行っていないと報酬が減る（高齢者虐待防止措置未実施減算）
  • 身体拘束廃止未実施減算が、施設に加えて短期入所系・多機能系にも広がった（減算の適用は2025年4月から）。訪問系・通所系でも、身体拘束の原則禁止と、やむを得ず行ったときの記録が基準に入った
  • 施設などの身体拘束適正化委員会は3か月に1回以上開く

③ 障害者虐待防止法

2011年成立・2012年施行です（高齢者虐待防止法は2005年成立・2006年施行）。

○×
対象は養護者・障害者福祉施設従事者等・使用者（雇い主）使用者による虐待は対象外
類型は高齢者と同じ5つ（介護等放棄は「放棄・放置」）3種類
著しい暴言・著しく拒絶的な対応＝心理的虐待身体的虐待
発見した施設従事者が通報しても守秘義務違反にならない—
医療機関の管理者は虐待防止の措置を講じる—
養護者による虐待の通報先は市町村都道府県
身体的虐待には「正当な理由のない身体拘束」も入る—
放棄・放置には「同居人やほかの利用者による虐待を放っておくこと」も入る—
心理的虐待には「不当な差別的言動」も入る—

障害者虐待の傾向（厚生労働省の調査）：養護者による虐待は身体的虐待が最多で、被虐待者の障害は知的障害が最多、虐待者は父が最多です。施設従事者による虐待も身体的虐待が最多で、虐待した職員の職種は生活支援員が最多です。

高齢者虐待防止法と障害者虐待防止法の違い

高齢者虐待防止法障害者虐待防止法
対象となる虐待養護者・養介護施設従事者等養護者・障害者福祉施設従事者等・使用者
通報先市町村市町村（使用者による虐待は市町村または都道府県）
通報の義務生命・身体に重大な危険があるとき・自分の施設で見つけたときは義務、それ以外は努力義務虐待を受けたと思われる障害者を見つけた人は通報義務

第38回：社会の理解

障害者虐待防止に関する次の記述のうち、適切なものを1つ選びなさい。

  1. 養護者による虐待が疑われる障害者を発見した場合、都道府県へ通報する義務がある。
  2. 著しく拒絶的な対応は身体的虐待に当てはまる。
  3. 使用者による障害者虐待は含まれない。
  4. 行政職員が障害者福祉施設等に、立ち入り調査を行うことは許されていない。
  5. 虐待を発見した障害者福祉施設従事者が通報した場合、業務上の守秘義務違反にはならない。

出典：第38回 介護福祉士国家試験（社会の理解）

正解を見る

正解：5　通報は守秘義務違反にならない。通報先は市町村、拒絶的な対応は心理的虐待、使用者（職場）による虐待も含まれます。

第35回：障害の理解

「障害者虐待防止法」における、障害者に対する著しい暴言が当てはまる障害者虐待の類型として、最も適切なものを1つ選びなさい。

（注）「障害者虐待防止法」とは、「障害者虐待の防止、障害者の養護者に対する支援等に関する法律」のことである。

  1. 身体的虐待
  2. 放棄・放置
  3. 性的虐待
  4. 心理的虐待
  5. 経済的虐待

出典：第35回 介護福祉士国家試験（障害の理解）

正解：4　暴言・侮辱・無視・拒絶は心理的虐待。5類型＝身体・放棄放置・心理・性的・経済的。
