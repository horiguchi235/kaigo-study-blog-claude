発達と老化の理解7問

この記事の論点と出題数（過去5年）

  • 老化の学説・老年期の発達 2問
  • 老化による身体の変化（循環・運動器・腎泌尿器・嚥下・免疫・睡眠） 2問
  • 老化による感覚・認知機能の変化 3問

この記事のポイント

  1. 生理的老化は誰にでも起こる・遺伝的にプログラムされた・元に戻らない変化。階段で息切れ＝予備力の低下。
  2. 老化で「下がる」もの＝免疫・骨密度・尿の濃縮力・嚥下・メラトニン。「増える」もの＝不整脈・収縮期血圧。
  3. 感覚は高音から聞こえにくい・明るさが多く必要・暗さに慣れにくい・味が薄く感じる。手続き記憶・意味記憶は保たれる。

① 老化の考え方・老化の学説

○×
老性自覚（自分が老いたと感じる）の時期には個人差がある疾病は老性自覚に影響しない／精神機能は一貫して低下
生理的老化＝誰にでも起こり、遺伝的にプログラムされた不可逆的な変化環境で起こる・個人差がない・回復する（それは病的老化の説明に近い）
階段を上ると息切れ＝予備力の低下防衛力・回復力・適応力の低下

老化の学説

学説中身
プログラム説細胞分裂の回数はあらかじめ決まっている
フリーラジカル説活性酸素が細胞を傷つける
エラー破局説DNA・たんぱく質合成の誤りが蓄積
消耗説使ううちにすり減る
老化の免疫説免疫機能の低下
✏️ 過去問を解いてみよう（第36回：発達と老化の理解）

生理的老化について、最も適切なものはどれ？

  1. 環境によって起こる
  2. 訓練で回復できる
  3. 生命活動に有利にはたらく
  4. 人間だけに起こる
  5. 遺伝的にプログラムされている
正解を見る

正解：5　シュトレーラーの4原則：普遍性・内在性（遺伝的にプログラム）・進行性・有害性。誰にでも起こり、元に戻らず、生命に不利にはたらきます。

② 老化によるからだの変化

器官○ 老化の変化×
免疫免疫機能が低下—
皮膚乾燥・弾力低下皮脂が増える
運動器骨密度の低下、筋力低下、関節の可動域が狭まる骨密度は変わらない
循環器不整脈が増える、動脈硬化、収縮期血圧が上がる心拍出量が増える
血液・呼吸貧血になりやすい、肺活量・肺の弾力が低下、残気量は増加—
腎・泌尿器尿の濃縮力が低下（夜間頻尿）、薬が体に残りやすい。前立腺肥大は男性膀胱容量が増える
嚥下喉頭の挙上が不十分、咳反射が弱い、唾液が減る舌骨の位置が上がる
睡眠メラトニンが減る、眠りが浅い、中途覚醒・早朝覚醒、寝つくまでの時間が長いノンレム睡眠の深い眠りが増える

第38回：発達と老化の理解

年をとると階段を上るときに息切れしやすくなる。これに関係する恒常性の機能はどれ？

  1. 予備力
  2. 適応力
  3. 免疫力
  4. 抵抗力
  5. 回復力
正解を見る

正解：1　ふだん使っていない「余力」が予備力。加齢で予備力が減るため、負荷がかかるとすぐ息切れします。

第35回：発達と老化の理解

高齢期の腎臓・泌尿器の変化として、最も適切なものはどれ？

  1. 尿路感染症はとても少ない
  2. 腎盂腎炎の主な症状は頭痛である
  3. 尿を濃くする力が低下する
  4. 前立腺肥大症では尿道が痛む
  5. 薬が体から出ていく時間は短くなる
正解を見る

正解：3　腎機能が落ちると尿の濃縮力が低下し、薬も体に残りやすくなります。腎盂腎炎は発熱・腰背部痛が主です。

第34回：発達と老化の理解

高齢者の睡眠について、適切なものはどれ？

  1. 午前中の遅い時間まで眠ることが多い
  2. 深い睡眠が多い
  3. 睡眠障害を自覚することは少ない
  4. 不眠の原因の1つはメラトニンの減少である
  5. 睡眠時無呼吸症候群は若い人より少ない
正解を見る

正解：4　睡眠ホルモンのメラトニンが減るため、早寝早起き・浅い眠り・中途覚醒が増えます。

③ 感覚・認知機能の変化

感覚

感覚○ 老化の変化×
視覚近くが見えにくい（老眼）、物の識別に必要な照度が高くなる、暗順応に時間がかかる、視野が狭くなる、青と黒・黄と白の区別がつきにくい周辺視野が広くなる

第37回：発達と老化の理解

加齢による感覚機能の変化として、最も適切なものはどれ？

  1. 皮膚の感覚が敏感になる
  2. 高い音が聞こえやすくなる
  3. 暗さに目が慣れるまでの時間が長くなる
  4. 味覚が敏感になる
  5. 嗅覚が敏感になる
正解を見る

正解：3　暗順応が遅くなるので、夜間の廊下やトイレには足元灯を。感覚は全体に鈍くなり、聴力は高音から落ちます。

  4. 流動性知能
  5. 意味記憶

第34回：発達と老化の理解

老化による感覚・認知機能の変化として、最も適切なものはどれ？

  1. 大きな声で話しかけられると、かえって聞こえにくいことがある
  2. 会話しながらの運転のほうが安全になる
  3. 白と黄色より白と赤の区別がつきにくくなる
  4. 低い声より高い声が聞き取りやすくなる
  5. 薄暗い部屋のほうが細かい作業をしやすい
正解を見る

正解：1　老人性難聴は大きすぎる音が響いて割れる（補充現象）ことがあるので、低めの声でゆっくり話します。水晶体が黄ばむため白と黄色が見分けにくくなります。

④ 高齢者の定義・知能と記憶・感覚の変化

  • 記憶の種類：エピソード記憶＝体験した出来事／意味記憶＝言葉の意味・知識・家族の名前や誕生日などの事実／手続き記憶＝体で覚えた技能（自転車など）／展望的記憶＝これからの予定／作業記憶＝情報を一時的に覚えながら処理する。
  • 近時記憶（最近のこと）は落ちやすく、遠隔記憶（昔のこと）は残りやすい。認知症も新しい記憶から障害される。
  • 加齢による体の変化：筋肉量・基礎代謝が落ちて熱をつくりにくい（体温が低め）／暑さ寒さを感じにくい／動脈硬化で末梢の血管抵抗が増え、血流が悪くなる／腎臓の尿の濃縮力が落ち、尿量はむしろ増えやすい／反応時間は長くなる。
  • 老人性難聴のサイン：後ろから声をかけても振り向かない、会話のつじつまが合わない、高い音が聞こえにくい、周りがうるさいと聞き取れない。
  • 高齢者の定義は法律で違う：介護保険法・老人福祉法・高齢者虐待防止法＝65歳以上、高齢者医療確保法＝65〜74歳が前期・75歳以上が後期、道路交通法＝70歳以上で高齢運転者標識（努力義務）、高年齢者雇用安定法＝65歳までの雇用確保が義務、70歳までの就業確保が努力義務。
  • 生理的老化（誰にでも起こる：白髪・老眼）と病的老化（病気が原因で進む：骨粗鬆症など）。
  • 知能：流動性知能（新しいことへの対応・暗記）は早めに低下、結晶性知能（経験・知識・判断力）は60歳代まで伸び、その後ゆるやかに低下。
  • 記憶：意味記憶と手続き記憶は衰えにくく、エピソード記憶は衰えやすい。
  • 感覚：暗さに目が慣れる（暗順応）が特に衰える、青系の色が見分けにくい。聴覚は高い音から聞こえにくくなる（「1時」と「7時」の聞き間違い）。
  • 老年症候群の代表に直接かかわる病気は骨粗鬆症（転倒→骨折→寝たきり）。
