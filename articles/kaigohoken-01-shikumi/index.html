  1. 保険者は市町村（特別区）。第1号は65歳以上、第2号は40〜64歳の医療保険に加入している人。
  2. 財源は公費（税）50％＋保険料50％（第1号・第2号）。利用者負担は1〜3割。

① 保険者・被保険者・財源・目的

誰が運営し、誰が入るか

お金とサービスの流れ：①被保険者が保険者（市町村）に保険料を払う → ②認定を申請し → ③要介護認定を受ける → ④⑤事業者からサービスを受け、利用料（1〜3割）を事業者に払う → ⑥事業者は残り（7〜9割）を国保連に請求 → ⑦国保連が審査し、保険者のお金から事業者に支払う。

言葉：国保連＝国民健康保険団体連合会（事業者の請求を審査して支払い、サービスへの苦情処理も行う）／介護報酬＝サービスの値段（国が決める）／特別区＝東京23区。

  • 保険者＝市町村及び特別区。保険者の役割は保険給付の事務・保険料の徴収・認定・被保険者証の交付など。小さな市町村は、いくつか集まって広域連合や一部事務組合をつくり、保険者になることもあります
  • 加入は強制（任意ではない）。住所のある市町村の被保険者になる。救護施設などの適用除外施設に入ると被保険者でなくなる
  • 他の市町村の施設に入所して住所を移しても、もとの市町村の被保険者のまま（住所地特例。施設の多い市町村に負担が偏らないため）

国保連（国民健康保険団体連合会）の仕事：都道府県ごとに1つあります。

  • 介護報酬の請求を審査して支払う（総合事業の分も。審査は介護給付費審査委員会が行う）
  • サービスへの苦情を受け付けて調べ、事業者に指導・助言する
  • 交通事故など、ほかの人（第三者）が原因でかかった介護の費用を、加害者に請求する事務

事業者の指定と指導：事業者は、人員・設備・運営の基準を満たして指定を受けます。指定は6年ごとに更新です。基準を守らないときは、勧告 → 公表 → 命令の順で正され、悪質なら指定の取消しや効力の停止になります。

財源

公費（税）50％ ＝ 国25％・都道府県12.5％・市町村12.5％（施設等は国20％・都道府県17.5％・市町村12.5％）
保険料  50％ ＝ 第1号保険料（23％）＋ 第2号保険料（27％）（2024〜2026年度）

「現役世代からの支援金」は後期高齢者医療制度の財源で、介護保険ではありません。

保険料の集め方と滞納

集め方中身
特別徴収（第1号）年金が年18万円以上なら年金から天引き
普通徴収（第1号）それ以外は納付書で納める（コンビニ払いも可）
第2号医療保険者が医療保険料と一緒に集める
  • 保険料を滞納すると段階的に制限：いったん全額払う償還払い（あとで保険給付分が戻る）→ 保険給付の一時差し止め → 滞納保険料との相殺。時効で納められなくなった期間があると（2年以上の滞納）、自己負担が3割（3割の人は4割）に引き上げられる
  • 生活保護受給者：65歳以上は介護保険が優先し、自己負担分は介護扶助、保険料は生活扶助で出る。40〜64歳で医療保険に入っていない人は第2号にならず、介護サービスは介護扶助で受ける

介護保険法の目的・理念

  • 第1条：要介護者などが尊厳を保持し、能力に応じ自立した日常生活を営めるよう保険給付を行う
  • 国民の共同連帯の理念
  • 保険給付は介護給付・予防給付・市町村特別給付の3種類。提供主体は社会福祉法人に限らない（株式会社・NPOも可）

② 要介護認定と利用の流れ・契約・苦情

要介護度の区分

区分使える給付
要支援1・2（介護予防が必要）予防給付（介護予防サービス）と総合事業。施設サービスは使えない
要介護1〜5（数字が大きいほど重い）介護給付（居宅・地域密着型・施設サービス）。特養の新規入所は原則要介護3以上
非該当（自立）保険給付はない。市町村の総合事業などを利用

利用の流れ

  1. 市町村に申請（地域包括支援センターなどが代行可）。状態が変わったときの区分変更（有効期間の途中で要介護度を見直すこと）の申請も保険者（市町村）へ
  2. 認定調査＋主治医の意見書（必要）
  3. 一次判定（コンピュータ）→ 二次判定（介護認定審査会＝市町村に設置）
  4. 市町村が本人に結果を通知。結果は申請から原則30日以内（調査が遅れるときなどは延長を知らせる）。申請して2週間で結果が来なくても、珍しいことではありません。認定の効力は申請日にさかのぼる
  5. ケアプラン作成（原則として認定の後）→ 契約 → 利用

  • 急いでいるときは、結果が出る前でも暫定のケアプランをつくってサービスを使い始められます（効力が申請日にさかのぼるため）。ただし「非該当（自立）」になると、使った分は全額自己負担になるおそれがあります

  • 2割・3割負担になるのは、65歳以上（第1号）で一定以上の所得がある人だけです。第2号被保険者（40〜64歳）は所得に関係なく1割。第2号の保険料は医療保険と一緒に集めるので、年金からの天引き（特別徴収）にはなりません

  • 要介護状態＝介護が必要な状態が原則6か月以上続く見込みのこと

  • 在宅サービスには要介護度ごとに、保険で使える1か月の上限額（支給限度額）がある

③ 制度改正の流れ

介護保険ができるまで

  • 1963年 老人福祉法で特別養護老人ホームができました。入所できるのは「65歳以上で、からだや精神の著しい障害のため常に介護が必要で、家で介護を受けるのが難しい人」。経済的に困っている人のための施設は養護老人ホームです。当時は、行政が入所を決める措置でした
  • 高齢化で介護が必要な人が増え、介護の期間も長くなり、家族だけでは支えきれなくなりました。そこで2000年に介護保険が始まりました
  • 介護保険のねらい（5つ）：①介護を社会全体で支える（介護の社会化）②措置から契約へ（利用者がサービスを選ぶ）③保健・医療・福祉に分かれていたサービスを1つの制度にまとめる ④株式会社・NPOなども参入し、競争で質を上げる ⑤ケアマネジメントを取り入れる
  • 介護保険法は、おおむね3年ごとに見直されています（事業計画も3年1期）
年主な内容
1997年成立・2000年施行介護保険スタート

2011年改正（2012年施行）定期巡回・随時対応型訪問介護看護、複合型サービス（現・看護小規模多機能）、地域包括ケアの推進
2014年改正（2015年施行）特養の新規入所は原則要介護3以上、一定以上所得者は2割負担、予防給付の訪問介護・通所介護を市町村の総合事業へ
