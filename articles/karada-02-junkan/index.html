  • 循環器・血液のしくみ 1問
  • 症状と疾患の観察（低血糖・高血糖・窒息・白癬など） 3問

この記事のポイント

  1. 肺動脈には静脈血、肺静脈・左心房・左心室には動脈血。酸素を運ぶのは赤血球。
  2. インスリン使用中に食事が減って、動悸・冷や汗・ふわふわ＝低血糖（すぐ医療職へ）。高血糖＝のどが渇く。
  3. 喉をつかむしぐさ＝窒息、爪が白く厚い＝白癬、糖尿病の人は足の指を観察。

① 循環器・血液のしくみ

血液の流れ

体循環：左心室 → 大動脈 → 全身 → 大静脈 → 右心房 肺循環：右心室 → 肺動脈（静脈血） → 肺 → 肺静脈（動脈血） → 左心房

○×
肺動脈には静脈血が流れる左心室から出た血液は大静脈へ
左心房には動脈血右心室・右心房・三尖弁・肺動脈に動脈血
静脈血＝酸素が少ない血液酸素を多く含む
静脈に逆流を防ぐ弁がある末梢動脈に弁
拍動を触れるのは動脈（手首の橈骨動脈など）下肢の静脈で拍動
リンパ管にはリンパ液リンパ管に血液
心臓は自律神経が支配体性神経が支配

血液の成分

成分働き
赤血球酸素を運ぶ（ヘモグロビン）
白血球（リンパ球など）免疫・感染から守る
血小板止血
血漿栄養・ホルモン・二酸化炭素などを運ぶ

心拍数

睡眠で減少。精神的緊張・怒り・体温上昇・激しい運動では増加。

✏️ 過去問を解いてみよう（第38回：こころとからだのしくみ）

循環器のしくみとして、正しいものはどれ？

  1. 心臓は体性神経が支配する
  2. 肺動脈には静脈血が流れている
  3. 左心室を出た血液は大静脈へ流れる
  4. リンパ管には血液が流れている
  5. 静脈血は酸素を多く含む
正解を見る

正解：2　肺動脈＝静脈血、肺静脈＝動脈血がひっかけポイント。心臓は自律神経が支配し、左心室から出た血液は大動脈へ。

② 症状と疾患の観察

見られる様子○ 考えられる状態
インスリン療法中、風邪で食事が半分、顔色が悪く「胸がどきどき、ふわふわ」、額に汗低血糖 → ただちに医療職へ
コントロール不良の糖尿病の高血糖口渇（多飲・多尿）。振戦・発汗・動悸は低血糖
糖尿病の人の身支度で観察する部位足趾（足の指）：傷・壊疽に気づきにくい
かきこむように食べる人が唐揚げを口に入れて喉をつかみ苦しそう窒息（チョークサイン）
爪の白濁・肥厚白癬（爪白癬）
皮膚の黄染肝臓・胆道の病気（黄疸）
長期臥床肺炎（沈下性肺炎）、褥瘡、筋萎縮
「通帳を長男の嫁が持っていった」と繰り返すもの盗られ妄想
歯周病の症状歯周ポケットの形成、歯ぐきの腫れ・出血（歯のくぼみ・エナメル質の侵食はむし歯）

第37回：こころとからだのしくみ

歯周病の症状として、適切なものはどれ？

  1. 歯にくぼみができる
  2. 歯の硬い組織がやわらかくなる
  3. 歯髄の炎症・痛み
  4. エナメル質が溶ける
  5. 歯周ポケットができる
正解を見る

正解：5　歯ぐきの炎症で歯と歯ぐきの間に歯周ポケットができます。1〜4はむし歯（う蝕）の症状です。

第36回：こころとからだのしくみ

かきこむように食べる癖があり最近むせることが多いGさん。昼食で唐揚げを口に入れたあと、のどをつかむしぐさをして苦しそうになった。起きていることとして最も適切なものはどれ？

  1. 心筋梗塞
  2. じんましん
  3. 誤嚥性肺炎
  4. 食中毒
  5. 窒息
正解を見る

正解：5　のどをつかむしぐさは窒息のサイン（チョークサイン）。すぐに背部叩打法・腹部突き上げ法を行います。

第34回：こころとからだのしくみ

コントロール不良の糖尿病で、高血糖のときにみられる症状はどれ？

  1. ふるえ
  2. 発汗
  3. のどの渇き
  4. 尿が少なくなる
  5. 動悸
正解を見る

正解：3　高血糖＝口渇・多飲・多尿。ふるえ・冷や汗・動悸は低血糖のサインです。

③ 血液・免疫・爪から分かること

  • 血液の成分：血漿（液体、血液の約55％）／赤血球＝ヘモグロビンで酸素を運ぶ（寿命約120日）／白血球＝免疫・異物の処理／血小板＝止血（寿命約7〜10日）。フィブリノーゲン＝血漿のたんぱく質で血液を固める（異物を攻撃するのは白血球）。
  • 血球は骨髄（赤色骨髄）でつくられる。
  • 糖尿病＝インスリンの作用不足で高血糖。症状＝口渇・多飲・多尿・だるさ。三大合併症＝網膜症・腎症・神経障害。動脈硬化の危険因子で、心筋梗塞・脳梗塞のリスクを高める。足の傷が壊疽になりやすい。
  • 心拍数は1分間に60〜80回ほど。肺動脈には静脈血、肺静脈には動脈血が流れる（名前と中身が逆）。
  • 血液は体重の約7〜8％。血球45％・血漿55％。体液は体重の約60％（高齢者は少ない）。
  • リンパ球：B細胞＝抗体をつくる、T細胞＝免疫の司令塔。高齢になるとT細胞の働きが弱まり、感染症にかかりやすくなる。
  • 爪の色と病気：青紫＝心臓・呼吸の悪化、全体に白い＝貧血・肝臓病・低栄養、白く濁って厚い＝爪白癬。巻き爪・陥入爪の原因は深爪（切りすぎ）。
  • 血圧のめやす：WHOの正常は130/80未満、高血圧＝140/90以上。
