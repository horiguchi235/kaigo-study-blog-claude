① 循環器・血液のしくみ

血液の流れ

はじめに、2つの別々の基準をおさえます。

言葉何で決まる？
動脈／静脈血管の向き。心臓から出ていく血管＝動脈、心臓へ戻る血管＝静脈
動脈血／静脈血血液の中身。酸素が多い血液＝動脈血、酸素が少ない血液＝静脈血

基準が違うので、肺へ向かう肺動脈（心臓から出る）には、全身から戻った酸素の少ない静脈血が流れます。「名前と中身が逆」になるのは肺動脈・肺静脈だけです。

体循環：左心室 → 大動脈 → 全身 → 大静脈 → 右心房 肺循環：右心室 → 肺動脈（静脈血） → 肺 → 肺静脈（動脈血） → 左心房

○×
肺動脈には静脈血が流れる左心室から出た血液は大静脈へ
左心房には動脈血右心室・右心房・三尖弁（右心房と右心室の間の弁）・肺動脈に動脈血
静脈血＝酸素が少ない血液酸素を多く含む
静脈に逆流を防ぐ弁がある（心臓の4つの部屋の出入口にも、血液を逆流させない扉＝弁がある）末梢動脈に弁
拍動を触れるのは動脈（手首の橈骨動脈など）下肢の静脈で拍動
リンパ管にはリンパ液リンパ管に血液
心臓は自律神経が支配体性神経（自分の意思で体を動かす神経）が支配

血液の成分

成分働き
赤血球酸素を運ぶ（ヘモグロビン）。寿命約120日
白血球（リンパ球など）免疫・感染から守る。リンパ球のB細胞＝抗体をつくる、T細胞＝免疫の司令塔（高齢になると働きが弱まり、感染症にかかりやすい）
血小板止血。寿命約7〜10日
血漿血液の約55％の液体部分。栄養・ホルモン・二酸化炭素などを運ぶ。血漿のたんぱく質フィブリノーゲンは血液を固める
  • 血液は体重の約7〜8％。血球は骨髄（赤色骨髄）でつくられる。体液は体重の約60％（高齢者は少ない）で、その約3分の2は細胞の中にある
  • 血液は、①酸素と二酸化炭素、②腸から吸収した栄養、③ホルモン、④老廃物や余分な水分（腎臓へ）を運ぶ
  • 貧血のめやすは、ヘモグロビン濃度が男性13g/dL・女性12g/dL以下。高齢になると貧血になりやすい
  • 白血球（好中球など）は細菌を取り込んで処理し、細菌に感染すると増える
  • クレアチニンは筋肉が使われてできる老廃物で、腎臓の働きが落ちると血液中で増える
  • リンパ液はリンパ管を流れ、途中のリンパ節を通って、最後は静脈に注ぐ

心拍数・バイタルサインのめやす

心臓は2つの心房と2つの心室からなり、神経が切れても自分で拍動を続けます（心臓の自動性）。自律神経はその速さを調整しています。1回の拍動で約60〜90mLの血液を送り出します。血圧は血管の中を流れる血液の圧力で、心臓が縮んだときが最高血圧（収縮期血圧）、ゆるんだときが最低血圧（拡張期血圧）です。年齢や動脈硬化で高くなります。

心拍数は睡眠で減少。精神的緊張・怒り・体温上昇・激しい運動では増加。

項目成人のめやす
脈拍（心拍数）安静時 1分間に60〜100回
呼吸1分間に12〜20回
体温（わきの下）36〜37℃
血圧正常＝120/80mmHg未満、高血圧＝140/90mmHg以上（日本高血圧学会 高血圧管理・治療ガイドライン2025）

② 症状と疾患の観察

からだの部位ごとに、「この様子ならこの状態」を結びつけます。

血糖の異常（糖尿病）

糖尿病＝インスリンの作用不足で血糖が高くなる病気。三大合併症は網膜症・腎症・神経障害で、動脈硬化を進め心筋梗塞・脳梗塞のリスクも高めます。

比べる点低血糖高血糖
起こりやすい場面インスリンや薬を使っているのに、食事が減った・運動が多かったコントロール不良の糖尿病
サイン冷や汗・動悸・手のふるえ・ふわふわ・顔色が悪い。進むと意識障害口渇・多飲・多尿・だるさ
対応ただちに医療職へ。指示に従いブドウ糖や砂糖を含む飲み物をとってもらう。意識がはっきりしない・飲み込めないときは口に入れない医療職へ報告
見られる様子○ 考えられる状態
インスリン療法中、風邪で食事が半分、顔色が悪く「胸がどきどき、ふわふわ」、額に汗低血糖 → ただちに医療職へ
コントロール不良の糖尿病の高血糖口渇（多飲・多尿）。振戦・発汗・動悸は低血糖

足・皮膚・爪

見られる様子○ 考えられる状態
糖尿病の人の身支度で観察する部位足趾（足の指）：感覚が鈍く、傷や壊疽（組織が死んで黒くなる）に気づきにくい
爪の白濁・肥厚白癬（爪白癬。水虫の菌が爪に入ったもの）
皮膚や白目の黄染（黄色くなる）肝臓・胆道の病気（黄疸）
  • 爪の色：青紫＝心臓・呼吸の悪化、全体に白い＝貧血・肝臓病・低栄養、白く濁って厚い＝爪白癬。巻き爪・陥入爪の原因は深爪（切りすぎ）

のど・口

見られる様子○ 考えられる状態
かきこむように食べる人が唐揚げを口に入れて喉をつかみ苦しそう窒息（チョークサイン）→ 背部叩打法・腹部突き上げ法
歯周病の症状歯周ポケットの形成、歯ぐきの腫れ・出血（歯のくぼみ・エナメル質の侵食はむし歯）
舌の表面に白っぽい汚れがつく舌苔（口の清潔が保てないと増える）

「通帳を長男の嫁が持っていった」と繰り返すもの盗られ妄想（認知症の行動・心理症状。くわしくは認知症①）

次のうち、歯周病（periodontal disease）の症状として、適切なものを1つ選びなさい。

  1. 歯のくぼみの形成
  2. 歯の硬組織の軟化
  3. 歯髄の炎症・疼痛（とうつう）
  4. 歯のエナメル質の侵蝕（しんしょく）
  5. 歯周ポケットの形成

出典：第37回 介護福祉士国家試験（こころとからだのしくみ）

正解：5　歯ぐきの炎症で歯と歯ぐきの間に歯周ポケットができます。1〜4はむし歯（う蝕）の症状です。

第36回：こころとからだのしくみ

Gさん（79歳、男性）は、介護老人保健施設に入所している。

Gさんは普段から食べ物をかきこむように食べる様子がみられ、最近はむせることが多くなった。

義歯は使用していない。

食事は普通食を摂取している。

ある日の昼食時、唐揚げを口の中に入れたあと、喉をつかむようなしぐさをし、苦しそうな表情になった。

Gさんに起きていることとして、最も適切なものを1つ選びなさい。

  1. 心筋梗塞（myocardial infarction）
  2. 蕁麻疹（じんましん　urticaria）
  3. 誤嚥性肺炎（ごえんせいはいえん　aspiration pneumonia）
  4. 食中毒（foodborne disease）
  5. 窒息（choking）

出典：第36回 介護福祉士国家試験（こころとからだのしくみ）

正解を見る

正解：5　のどをつかむしぐさは窒息のサイン（チョークサイン）。すぐに背部叩打法・腹部突き上げ法を行います。3の誤嚥性肺炎は、食べ物などが気管に入ったあと時間がたってから熱やせきが出る病気で、食べた直後の急な苦しさとは違います。
