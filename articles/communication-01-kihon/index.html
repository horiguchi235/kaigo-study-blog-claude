この記事のポイント

  1. コミュニケーションは双方向。一方的に話す・黙って聞くだけ、のどちらも×。
  2. 初対面では自分から自己紹介し、相手の感情に関心をもつ。距離を急に縮める（愛称・密着・ボディタッチ中心）のは×。
  3. 「大丈夫」と言いながら不安そうな表情 ＝ 言語と非言語が矛盾している。本当の気持ちは非言語に出やすい（決めつけず、本人に確かめる）。

コミュニケーションとは：言葉や表情などを使って、情報や気持ちを伝え合うこと。受け取って応える相手がいて初めて成り立ちます（一方通行は×）。やり取りには、その人の生き方や経験が表れ、人間関係をつくる土台になります。

① 関係づくり（ラポール形成）の基本

ラポール＝利用者と援助者のあいだの信頼関係。安心して話せる関係があってはじめて、本音や希望を聞くことができます。

○ 正解× よく出る不正解
双方向のやり取り（あいづちで相手の発話を引き出す）一方的に話す／聞き手に徹するだけ
初対面では自分から自己紹介する自発的な関わりを控える／詳しすぎる自己紹介
利用者の感情に関心をもつ家族環境を詳しく聞く／「なぜ」をくり返す
表情や行動を観察し、さりげない会話から肩に手を回すなど身体接触を中心にする
利用者の生活史を尊重する介護福祉職の主観を基準にする
利用者の主観的な訴えに耳を傾ける自分の意見と違っても賛同する／感情的に反応する
言葉だけでなく表情やしぐさにも注意理解できない話には沈黙する
自分自身の感情の動きも意識する介護福祉職の価値判断に従ってもらう
言葉が出にくいときは待つ次々に話しかける

×の理由

  • 家族環境を詳しく聞く・「なぜ」をくり返す → 初対面で踏み込みすぎ、問い詰められている感じを与える
  • 身体接触を中心にする → 触れられるのを不快に感じる人もいる。接触は安心にも不快にもなるので、むやみに触れない（言葉が届きにくい重度の認知症の人に、安心を伝える手段として触れるのは別 → 認知症・うつ・精神障害・知的障害の人とのコミュニケーション）
  • 理解できない話には沈黙する → 反応がないと相手は不安になる。わからないときは確かめる

沈黙は○？×？　相手が考えている・言葉を探しているときの沈黙は、大切な時間として待つ（○）。わからないまま黙って反応しない、うなずきもせず聞いているだけ（聞き手に徹するだけ）は、双方向にならないので×。傾聴（傾聴・共感・受容と質問の技法）も、あいづちや表情で「聴いています」を伝えながら聴くことです。

「〇〇ちゃん」と愛称で呼ぶ、孫のような口調で話す、友人のような口調、は親しみではなく尊厳を傷つける対応として必ず×です。

  • 共体験＝同じものを見る・一緒に出かけるなど、体験を共有すること。その後の会話のきっかけになり、関係づくりに役立ちます。

このときの、介護福祉職の対応の意図に当てはまるものとして、最も適切なものを1つ選びなさい。

  2. コミュニケーション能力の評価
  3. 感覚機能の低下への配慮

第35回：人間関係とコミュニケーション

Bさん（80歳、女性）は、介護老人保健施設に入所が決まった。今日はBさんが施設に入所する日であり、C介護福祉職が担当者になった。C介護福祉職は、初対面のBさんとの信頼関係の形成に向けて取り組んだ。

C介護福祉職のBさんへの対応として、最も適切なものを1つ選びなさい。

  1. 自発的な関わりをもつことを控えた。
  2. 真正面に座って面談をした。
  3. 自分から進んで自己紹介をした。
  4. 終始、手を握りながら話をした。
  5. 孫のような口調で語りかけた。

出典：第35回 介護福祉士国家試験（人間関係とコミュニケーション）

正解を見る

正解：3　信頼関係（ラポール）づくりは、自分から名前と役割を伝えることから。1の関わりを控えるのは関係づくりが進まず、2の真正面は緊張させやすく、4の手を握り続けるのは距離を急に縮めすぎ、5のなれなれしい口調は尊厳を損ないます。

② 座り方・距離・聞く姿勢

座り方

座り方特徴
直角法（90度）視線をそらしやすく、緊張しにくい。関係づくりに向く
対面法（正面）視線が合いすぎて緊張しやすい → 机に花瓶など視線を向けられる物を置くとよい

距離と目線

  • 対人距離（ホールの分類）：密接距離＝約45cmまで、個人距離＝約45〜120cm、社会距離＝約120〜360cm、公衆距離＝それ以上。相談は個人距離が目安。身体介護では密接距離に入るので、声をかけて同意を得てから近づく

  • 呼び名の違い：密接距離は「親密距離」、個人距離は「個人的距離」と書かれることもあります（同じもの）。体の距離（物理的距離）は、気持ちの近さ（心理的距離）と連動して伸び縮みします。関係ができていないうちに体だけ近づけると、相手は不快に感じます

  • パーソナルスペース（他人に入られると不快に感じる身のまわりの空間）は、相手との親密度・文化・その人の状態によって変わる（一定ではない、第24回）

  • 相手と視線を合わせられる位置で話す。相手が座っていれば自分も座る。車いすの人には腰を落として目の高さを合わせる（見下ろすと威圧感を与える）

  • 初対面から密着した距離は×。近づけば近づくほど話しやすくなるわけではない

  • 静かで、表情が見える明るい場所で話す（にぎやかな場所・薄暗い場所は×）

聞く姿勢

  • 上半身を少し相手のほうへ傾けて聞く
  • 腕組み・足組み・正面に立って話し続ける・目を見つめ続けるは×
  • 緊張感が伝わるような背筋の伸ばし方も×（リラックスした姿勢で）
  • 聞き上手の基本＝話の腰を折らない・表情豊かに・ほどよいあいづち。相手のペースに合わせる

③ 言語・準言語・非言語メッセージ

種類中身例
言語言葉の内容。話し言葉だけでなく、文字（手紙・メール・筆談）や手話も言語「お風呂は午後3時からです」
準言語声の大きさ・速さ・高さ・抑揚・間大きな声でゆっくり伝える
非言語表情・視線・身振り・姿勢・距離・接触。服装・髪型・身だしなみなどの外見も非言語部屋のドアを指差す、目元の笑顔と大きなうなずき
  • 非言語は、本人も気づかないうちに出ていることが多いもの。自分の表情や態度・身だしなみが相手にどう見えているかも意識します（職員の身だしなみは、利用者や家族との関係にも影響します）。
  • 言葉で伝えるのが難しい人（認知症・失語症・知的障害など）には、非言語が特に大事な手段になります。

準言語は非言語？　準言語は言葉の「中身」ではなく「話し方」なので、広い意味では非言語の一部と説明されることもあります。ただし試験では言語・準言語・非言語を分けて問います。選択肢に並んだら、非言語＝表情・視線・身振り・指さし・うなずき・姿勢・距離・接触、準言語＝声の大きさ・速さ・高さ・抑揚、言語＝話し言葉と文字、と仕分けます。

よく出るパターン

  • 「大丈夫」と不安そうな表情で答えた → 言語メッセージと矛盾する内容を非言語で伝えている
  • マスクで口元が見えないとき → 目元を意識した笑顔と大きなうなずき
  • 「ゆっくり話す」「大きな声」は準言語、「紙に書く」は言語（文字）。非言語と区別する
  • 「大きな声」が正解になるのは、聞き取りにくそうなとき。ただし老人性難聴（高い音から聞こえにくくなる）の人には、大声で声が高くなるとかえって聞き取りにくいので、低めの声でゆっくり・はっきり（→ 視覚障害・聴覚障害・盲ろうの人とのコミュニケーション）

第38回：人間関係とコミュニケーション

Aさんは有料老人ホームに入所したばかりである。ある日、廊下を行ったり来たりしているAさんに、B介護福祉職が声をかけた。Aさんは、「私の部屋はどこですか」と困った様子で答えた。B介護福祉職が、「ここから2つ隣の部屋です」と伝えると、Aさんは、「どこですか」と不安そうな表情で聞いた。B介護福祉職は非言語的コミュニケーションを用いて伝えることにした。

次の記述のうち、B介護福祉職が用いた非言語的コミュニケーションとして、最も適切なものを1つ選びなさい。

  1. ゆっくり話した。
  2. 大きな声で伝えた。
  3. Aさんの部屋の番号を紙に書いて渡した。
  4. Aさんに近づいた。
  5. Aさんの部屋のドアを指差した。

出典：第38回 介護福祉士国家試験（人間関係とコミュニケーション）

正解を見る

正解：5　指さし・身振り・表情が非言語。ゆっくり・大きな声は準言語、紙に書くのは文字なので言語です。4の「近づく」も距離を使った非言語ですが、それだけでは部屋の場所は伝わりません。場所を伝えられる非言語は指さしです。

第36回：人間関係とコミュニケーション

このときの、介護福祉職の準言語を活用した対応として、最も適切なものを1つ選びなさい。

  2. 抑揚をつけずに伝えた。
  3. 大きな声でゆっくり伝えた。
  4. 急かすように伝えた。
  5. 早口で伝えた。

出典：第36回 介護福祉士国家試験（人間関係とコミュニケーション）

正解を見る

第36回：コミュニケーション技術

Cさん（85歳、女性、要介護3）は、介護老人保健施設に入所しており、軽度の難聴がある。

数日前から、職員は感染症対策として日常的にマスクを着用して勤務することになった。

ある日、D介護福祉職がCさんの居室を訪問すると、「孫が絵を描いて送ってくれたの」と笑いながら絵を見せてくれた。

D介護福祉職はCさんの言動に共感的理解を示すために、意図的に非言語コミュニケーションを用いて対応した。

このときのD介護福祉職のCさんへの対応として、最も適切なものを1つ選びなさい。

  1. 「よかったですね」と紙に書いて渡した。
  2. 目元を意識した笑顔を作り、大きくうなずいた。
  3. 「お孫さんの絵が届いて、うれしかったですね」と耳元で話した。
  4. 「私もうれしいです」と、ゆっくり話した。
  5. 「えがとてもじょうずです」と五十音表を用いて伝えた。

出典：第36回 介護福祉士国家試験（コミュニケーション技術）

正解を見る

正解：2　マスクで口元が見えないので、目元の笑顔と大きなうなずきで気持ちを伝えます。紙・言葉・五十音表は言語的手段です。
