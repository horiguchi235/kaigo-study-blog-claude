この記事のポイント

  1. コミュニケーションは双方向。一方的に話す・黙って聞くだけ、のどちらも×。
  2. 初対面では自分から自己紹介し、相手の感情に関心をもつ。距離を急に縮める（愛称・密着・ボディタッチ中心）のは×。
  3. 「大丈夫」と言いながら不安そうな表情 ＝ 言語と非言語が矛盾している。本当の気持ちは非言語に出る。

① 関係づくり（ラポール形成）の基本

○ 正解× よく出る不正解
双方向のやり取り（あいづちで相手の発話を引き出す）一方的に話す／聞き手に徹するだけ
初対面では自分から自己紹介する自発的な関わりを控える／詳しすぎる自己紹介
利用者の感情に関心をもつ家族環境を詳しく聞く／「なぜ」をくり返す
表情や行動を観察し、さりげない会話から肩に手を回すなど身体接触を中心にする
利用者の生活史を尊重する介護福祉職の主観を基準にする
利用者の主観的な訴えに耳を傾ける自分の意見と違っても賛同する／感情的に反応する
言葉だけでなく表情やしぐさにも注意理解できない話には沈黙する
自分自身の感情の動きも意識する介護福祉職の価値判断に従ってもらう
言葉が出にくいときは待つ次々に話しかける

「〇〇ちゃん」と愛称で呼ぶ、孫のような口調で話す、友人のような口調、は親しみではなく尊厳を傷つける対応として必ず×です。

第37回：人間関係とコミュニケーション

入所したばかりで自分のことを話そうとしない利用者に、介護福祉職は一方的にならないよう、あいづちを打ちながら話を引き出すようにした。この対応の意図として、最も適切なものはどれ？

  1. 互いの自己開示
  2. コミュニケーション能力の評価
  3. 感覚機能の低下への配慮
  4. 認知機能の改善
  5. 双方向のやり取り
正解を見る

正解：5　あいづちで相手の発言を促すのは、双方向のやり取りをつくるため。介護職が一方的に話さないことが大切です。

第35回：人間関係とコミュニケーション

初めて会う入所日の利用者と信頼関係をつくるための対応として、最も適切なものはどれ？

  1. 自分から関わるのを控えた
  2. 真正面に座って面談した
  3. 自分から進んで自己紹介をした
  4. ずっと手を握りながら話した
  5. 孫のような口調で話しかけた
正解を見る

正解：3　信頼関係（ラポール）づくりは、自分から名前と役割を伝えることから。真正面は緊張させやすく、なれなれしい口調は尊厳を損ないます。

② 座り方・距離・聞く姿勢

座り方

座り方特徴
直角法（90度）視線をそらしやすく、緊張しにくい。関係づくりに向く
対面法（正面）視線が合いすぎて緊張しやすい → 机に花瓶など視線を向けられる物を置くとよい

距離と目線

  • 相手と視線を合わせられる位置で話す。相手が座っていれば自分も座る
  • パーソナルスペースは相手との親密度によって変わる（一定ではない、第24回）
  • 初対面から密着した距離は×。近づけば近づくほど話しやすくなるわけではない
  • 静かで、表情が見える明るい場所で話す（にぎやかな場所・薄暗い場所は×）

聞く姿勢

  • 上半身を少し相手のほうへ傾けて聞く
  • 腕組み・足組み・正面に立って話し続ける・目を見つめ続けるは×
  • 緊張感が伝わるような背筋の伸ばし方も×（リラックスした姿勢で）
✏️ 過去問を解いてみよう（第34回：コミュニケーション技術）

利用者と話すときの基本的な態度として、最も適切なものはどれ？

  1. 上半身を少し利用者のほうへ傾けて聞く
  2. 利用者の正面に立って話し続ける
  3. 腕を組んで聞く
  4. 利用者の目をずっと見つめる

正解：1　少し前かがみの姿勢は「関心をもって聞いています」というサイン。腕組みや見つめ続けるのは圧迫感を与えます。

③ 言語・準言語・非言語メッセージ

種類中身例
言語言葉の内容「お風呂は午後3時からです」
準言語声の大きさ・速さ・高さ・抑揚大きな声でゆっくり伝える

第36回：コミュニケーション技術

軽い難聴のある利用者が、孫の絵を笑顔で見せてくれた。職員はマスクをしている。共感を非言語で示す対応として、最も適切なものはどれ？

  4. 「私もうれしいです」とゆっくり話した

④ 対人距離と話の聞き方

  • コミュニケーションに障害がある人への支援は、機能の回復を待つのではなく「いま」の意思疎通を支えること。残っている力と本人の希望に合った方法（言葉・身振り・文字・機器）を使い、周りの騒音・照明・距離・姿勢も整える。
  • 自分の思い込み（先入観）は、相手の気持ちを見えにくくする。だから自己覚知が大切。
  • 安心できる距離は、親しさ・文化・その人の状態で変わる。
  • 相手のペースに合わせ、沈黙も大切な時間として待つ。わからないことは確かめる。
  • 対人距離（心の距離と体の距離は連動する）：密接（親密）距離＝約45cmまで、個人距離＝約45〜120cm、社会距離＝約120〜360cm、公衆距離＝それ以上。相談は個人距離が目安。
  • 共体験＝同じものを見る・一緒に出かけるなど体験を共有すること。その後の会話のきっかけにもなる。
  • 準言語＝声の高さ・速さ・抑揚など、言葉に付いてくる非言語の情報。言語より非言語のほうが本音が出やすい。
  • 聞き上手の基本＝話の腰を折らない・表情豊かに・ほどよいあいづち。
  • むやみに体に触れない（接触は安心感にもなるが不快にもなる）。
