この記事のポイント

  1. 塩素系漂白剤は白い綿・麻・ポリエステル（除菌もできる）。ウール・絹・色柄物は酸素系。
  2. 洗濯表示：桶の下の線1本＝弱い、2本＝非常に弱い、数字は上限温度。四角の中の横線＝平干し、左上の斜線＝日陰。
  3. ノロウイルスの嘔吐物はマスク・手袋をつけ、取り除いてから次亜塩素酸ナトリウム。アルコールは効きにくい。

① 洗濯・漂白・しみ抜き

漂白剤

種類使える素材ポイント
塩素系（次亜塩素酸ナトリウム）白い綿・麻・ポリエステル・アクリル漂白力が強く除菌効果がある。色柄物・ウール・絹・ナイロン・アセテートは×。手指の消毒には使わない、熱湯で薄めない
酸素系（液体）ウール・絹（水洗いできるもの）、色柄物綿の柄物シャツにも
酸素系（粉末）白物・色柄物（ウール・絹は×）弱アルカリ性

洗い方の基本

○×
ほころび・破れは修理してから洗う—
ファスナー・面ファスナーは閉めて洗う開けたまま／はずしたまま
色移りを防ぐため色の濃い物・薄い物を分ける素材の違いで分ける
血液などたんぱく質の汚れは水で（熱で固まる）高温で洗う
絹・ウールは中性洗剤弱アルカリ性洗剤
洗剤は適量（多くても落ちは変わらない）多いほどよく落ちる
淡い色の物には蛍光増白剤なし蛍光増白剤入り
ドライクリーニングは油溶性の汚れ向き水溶性向き

しみ抜き

しみ処理
チョコレート・バター・口紅（油性）ベンジンや洗剤を浸み込ませ、布の上に置いて叩く
しょうゆ・コーヒー・果汁（水溶性）水で叩く → 洗剤
血液水（お湯は×）

第38回：生活支援技術

繊維や衣類の性質と洗濯方法として、正しいものはどれ？

  1. 綿の柄物シャツには酸素系漂白剤を使う
  2. ナイロンのレインウエアは脱水時間を長くする
  3. ウールのニットは乾燥機を使う
  4. レーヨンのパジャマはすすぎ時間を長くする
  5. 絹のブラウスには弱アルカリ性洗剤を使う
正解を見る

正解：1　酸素系は柄物にも使える、塩素系は白物だけ。ウール・絹は中性洗剤で、ウールは乾燥機で縮みます。

第34回：生活支援技術

次亜塩素酸ナトリウムが主成分の衣類用漂白剤について、最も適切なものはどれ？

  1. すべての白物に使える
  2. 色柄物の漂白に向いている
  3. 熱湯でうすめて使う
  4. 手指の消毒に向いている
  5. 衣類の除菌効果がある
正解を見る

正解：5　塩素系漂白剤は漂白と除菌ができます。ただし毛・絹・ナイロンなどには使えず、手指の消毒には使いません。

② 洗濯表示

記号意味
桶に30、下に線1本液温30℃を上限に、洗濯機で弱い洗濯
桶の下に線2本非常に弱い洗濯
桶に手手洗い
四角の中に縦線つり干し
四角の中に横線平干し
四角の左上に斜線日陰で干す
四角に横線＋左上に斜線日陰で平干し

旧表示：シャツ型に斜線 → 日陰のつり干し。

③ 衣類の保管・裁縫・掃除

保管と防虫剤

  • 防虫剤は衣類の上に置く（成分は空気より重く、上から下へ広がる）。湿気を取ってからしまう。ドライクリーニングのビニールは外して保管
  • 絹製品はタンスの上段に（湿気が少ない）
  • 種類がわからない防虫剤を補充するならピレスロイド系（ほかの防虫剤と併用しても溶けたりしみたりしない）。しょうのう・ナフタリン・パラジクロルベンゼンは混ぜて使えない
  • 汚れのひどい衣類も本人に確認せず捨てない

裁縫

ズボンの裾上げで表から縫い目が目立たない → まつり縫い。

掃除

○×
畳は目に沿って拭く・掃く—
喘息の人の家：掃除機をかける前に吸着率の高いモップでほこりを取る。掃除機はゆっくり動かす掃除機をすばやく動かす
高い所から低い所へ、奥から出入口へ低い所から／出入口から奥へ
窓ガラスは濡れ雑巾 → 乾いた雑巾最初に乾いた雑巾
カビ取り剤は換気しながら窓を閉める

衣類の保管方法として、適切なものはどれ？

  1. 衣装ケースでは、たたんだ衣類の下に防虫剤を入れる
  2. クリーニング後の衣類はビニールをつけたまま保管する
  3. 汚れのひどい衣類は介護職の判断で捨てる
  4. 湿った衣類はたたんで引き出しにしまう
  5. 絹製品はタンスの上の段に保管する
正解を見る

正解：5　湿気は下にたまるので、湿気に弱い絹は上段に。防虫剤の成分は下に広がるので衣類の上に置き、ビニールは外して湿気を逃がします。

ノロウイルス感染症の予防の対応として、最も適切なものはどれ？

⑤ 洗剤・漂白剤・しみ抜きの使い分け

  • ドライクリーニング＝水ではなく溶剤で洗う方法。水洗いで型くずれ・縮みやすい衣類に向く。
  • 洗剤は多ければよく落ちる、ではない（適量を守る）。洗剤の界面活性剤が汚れを落とす。毛・絹は中性洗剤。
  • 掃除の洗剤：クレンザー＝研磨で落とす／酸性洗剤＝水あかなどに／アルカリ性洗剤＝油汚れに。塩素系漂白剤と酸性洗剤を混ぜると有毒な塩素ガスが出る（「まぜるな危険」）。
  • 消毒薬：第四級アンモニウム塩＝ベンザルコニウム塩化物・ベンゼトニウム塩化物（「第五級」はない）。
  • 洗剤：石けん・弱アルカリ性合成洗剤は綿・麻・合成繊維向き、毛・絹は中性洗剤。量を増やしても汚れはよく落ちない（表示量を守る）。
  • 漂白剤：塩素系（白物の綿・麻など。色柄物・毛・絹には使えない、酸性の洗剤と混ぜない）、酸素系（色柄物にも使える）、還元系（酸化漂白剤で落ちない黄ばみ・鉄さびなどに）。
  • しみ抜きは洗濯前に。しょうゆ・コーヒーなど水溶性は水、ドレッシング・カレーなど水と油が混ざったものは台所用洗剤、口紅・チョコなど油性はベンジン→洗剤。血液は湯で固まるので水で。いずれもしみの外側から中心へたたく。
  • ドライクリーニングは油汚れに強いが、汗など水溶性の汚れは落ちにくい。洗濯表示は2016年12月から国際規格に合わせた新表示。
