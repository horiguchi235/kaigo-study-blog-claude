この記事のポイント

  1. 流動性知能（新しい問題を解く）は加齢で下がりやすく、結晶性知能（経験・知識）は保たれる。
  2. ライチャードの5類型は事例で出る：満足＝円熟型、若さにこだわり世話を拒む＝装甲（自己防衛）型。
  3. キューブラー・ロスは「否認 → 怒り → 取り引き → 抑うつ → 受容」。「なぜ私が」＝怒り、「我慢するので助けて」＝取り引き。

① 知能と老年期の性格類型

知能

流動性知能結晶性知能
中身新しい場面に適応する問題解決能力過去に得た知識や経験を活用して解決する能力
加齢低下しやすい（生理的な老化の影響）高齢でも維持、伸びることも
影響を受けるもの脳の働き教育・文化・経験

ライチャードの老年期の性格（適応）5類型

類型特徴試験の事例
円熟型自分の人生を受け入れ、趣味や交流に積極的で満足多くの趣味と友人、毎日を有意義に
安楽いす（ロッキングチェアー）型他人に依存し、のんびり受け身—
装甲（自己防衛）型老いへの不安を活動で打ち消す。若さにこだわり、人の世話になることを拒む元営業部長、長男の同居の勧めを拒否／元役員、老人クラブ拒否・敬老の記念品に不快・毎日筋トレ・「若々しい」で喜ぶ
憤慨（外罰）型自分の失敗を他人のせいにして攻撃的—
自責（内罰）型自分の人生を失敗と考え自分を責める—

第37回：発達と老化の理解

結晶性知能の説明として、最も適切なものはどれ？

  1. 感覚や運動に基づく知能
  2. 過去に得た知識を生かして問題を解決する能力
  3. 40〜50歳で急に下がる
  4. 知識や文化より生理的な老化の影響を受けやすい
  5. その場で新しい問題を解決する能力
正解を見る

正解：2　結晶性＝経験・知識を生かす力で高齢になっても保たれやすい。新しい問題を解く力は流動性知能です。

第37回：発達と老化の理解

元会社役員のAさん（73歳）は老人クラブへの入会を断り、敬老の日の記念品も受け取らない。体の衰えに強い不安があり毎日筋トレをし、「若々しいですね」と言われると喜ぶ。ライチャードの適応タイプで、Aさんにあたるものはどれ？

  1. 外罰（憤慨）型
  2. 内罰（自責）型
  3. 円熟（成熟）型
  4. 自己防衛（装甲）型
  5. ロッキングチェアー（安楽いす）型
正解を見る

正解：4　老いを認めず、若さや活動にこだわって不安を防ぐのが自己防衛（装甲）型です。

第34回：こころとからだのしくみ

一人暮らしのHさん（75歳）は社会活動に積極的に参加し、多くの趣味をもち、友人関係にも満足している。ライチャードの性格類型で、Hさんにあたるものはどれ？

  1. 自責型
  2. 防衛型（装甲型）
  3. 憤慨型
  4. 円熟型
  5. 依存型（安楽いす型）
正解を見る

正解：4　老いを受け入れ、積極的に社会参加し満足しているのが円熟型。

② エイジング理論・エイジズム・高齢期の適応

用語意味
エイジズム高齢を理由にした偏見や差別。例：「年をとると頑固になる」
サクセスフル・エイジング老いの変化に工夫して適応し、よく生きる。例：難聴があるので補聴器をつけてパソコン教室へ
プロダクティブ・エイジングバトラーが提唱。高齢者も社会に貢献する存在。セルフケアも生産的な活動に含む
活動理論活動を続けるほど幸福
離脱理論社会から少しずつ離れるのが自然
社会情動的選択理論残りの時間を意識すると、親しい人との関係を選んで大切にする
  • 老性自覚：白髪などで「年をとった」と感じること
  • 住み慣れた地域で満足して暮らす人が、息子に同居を迫られる → 住み慣れた環境や仲間を失うことへの不安

④ 性格類型・エイジング・老年期うつ病

  • パーソナリティのとらえ方：類型論＝タイプに分ける（ユング・クレッチマー）／特性論＝いくつもの特性の程度で見る（キャッテル）。
  • 人格検査の3種類：投影法（あいまいな絵などへの反応：ロールシャッハ・バウムテスト）／質問紙法（YG性格検査）／作業法（内田クレペリン検査）。
  • 動機づけ：内発的動機＝興味・楽しさ・達成感から行う／外発的動機＝指示・ほうび・評価のために行う（親に言われてしかたなく掃除する）。
  • 性格は生まれつきだけで決まらず、環境や経験で変化する。老化で感覚は鈍くなる傾向があり、それが心理にも影響する。
  • ライチャードの5類型の別名：安楽椅子型＝ロッキングチェア型（人に頼り、責任から解放されるのを歓迎）、装甲型＝自己防衛型（活動を続けて老いへの不安を抑え込む）、憤慨型＝外罰型、自責型＝内罰型、そして円熟型。
  • アクティブエイジング（WHO）＝健康・参加・安全の機会を最大にして、年をとっても生活の質を高めること。エイジズム＝年齢による差別・偏見。
  • 老化の基準（ストレーラー）：普遍性（誰にでも）・内在性（内から起こる）・進行性（もとに戻らない）・有害性（機能を低下させる）。
  • 老年期うつ病：抑うつ気分より頭痛・腰痛などの体の訴えが目立つ（仮面うつ病）、もの忘れなど認知症に似る（仮性認知症）。安易に励まさない、自殺のサインに注意。
