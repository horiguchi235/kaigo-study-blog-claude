この記事のポイント

  1. 尿失禁は「どこで困っているか」で4タイプに分かれる。表を1枚覚えれば、しくみの問題も対応の問題も解ける。
  2. 認知症の人の失禁（機能性尿失禁）は、トイレの場所・時間・環境を整えるのが正解。
  3. 「水分を控える」「おむつにする」は、排泄の問題ではほぼ必ず不正解。

① 正常な尿と、異常のサイン

まずは「正常」を知ることから始めます。異常は、正常との違いとして出題されます。

項目正常異常のサイン
色・見た目淡黄色〜淡黄褐色で透明濁り（感染）、赤色（血尿）
におい排尿直後はほぼ無臭直後からアンモニア臭（膀胱炎など）
性質弱酸性—
成分たんぱく・糖はほぼ出ない尿糖（糖尿病）、尿たんぱく（腎臓病）
量1日 約1,000〜1,500mL多尿＝糖尿病、乏尿・無尿

よく出る一言

  • 多尿の原因 → 糖尿病（尿に出た糖が水を引き込み、尿量が増える）
  • 膀胱炎の代表的な症状 → 排尿時痛（発熱はふつう出ない。熱が出たら腎盂腎炎を疑う）
  • 女性に尿路感染症が多い理由 → 尿道が短く、まっすぐだから

便の性状もここで押さえます。ブリストル便性状スケールでは、3〜5（やや硬い便・普通便・やや軟らかい便）が「普通便」の範囲です。1〜2は便秘寄り、6〜7（泥状便・水様便）は下痢寄りです。

✏️ 過去問を解いてみよう（2問）
第36回：こころとからだのしくみ

女性が男性より尿路感染症を起こしやすい理由として、最も適切なものはどれ？

  1. 子宮に圧迫される
  2. 尿道が短くまっすぐである
  3. お腹の筋力が弱い
  4. 女性ホルモンの作用がある
  5. 尿道括約筋がゆるんでいる
正解を見る

正解：2　女性の尿道は約4cmと短くまっすぐで、肛門にも近いため細菌が入りやすい。

第34回：こころとからだのしくみ

ブリストル便性状スケールで「普通便」にあたるものはどれ？

  1. 水様便
  2. 硬い便
  3. 泥状便
  4. コロコロ便
  5. やや軟らかい便
正解を見る

正解：5　普通便は4（なめらかなバナナ状）と5（やや軟らかい便）あたり。1〜2は便秘、6〜7は下痢側です。

② 尿失禁の4タイプ

ここがこの記事の核心です。15年で6問出ており、事例問題でも頻出です。

タイプひとことで典型的な場面主な原因・多い人対応
腹圧性お腹に力が入ると漏れる咳・くしゃみ・重い物を持つ骨盤底筋群の筋力低下（女性・出産経験・加齢）骨盤底筋訓練
切迫性急に強い尿意、我慢できないトイレに行く途中で漏れる尿をためる機能の障害（過活動膀胱・脳血管障害）膀胱訓練・受診
溢流性出したいのに出ず、あふれて漏れる少しずつダラダラ漏れる・残尿尿を出す機能の障害（前立腺肥大症＝男性）受診（導尿など）
機能性膀胱は正常、でも間に合わないトイレの場所がわからない・歩くのが遅い認知症・運動機能の低下誘導・環境整備（→③へ）

覚え方のコツ：「どこで困っているか」で分けると混乱しません。

  • 筋肉（骨盤底）が弱い → 腹圧性
  • 膀胱がためられない → 切迫性
  • 膀胱から出せない → 溢流性
  • 膀胱も筋肉も正常、脳や足の問題 → 機能性

選択肢で出てくるほかの用語：反射性尿失禁＝脊髄損傷などで尿意を感じられず、反射的に漏れるもの。心因性頻尿＝緊張や不安でトイレが近くなるもの（失禁ではない）。

過去問で確認

第33回 認知機能は正常で杖歩行の83歳女性。咳やくしゃみで尿が漏れるので、外出を控えるようになった。どのタイプか。 → 腹圧性尿失禁。「咳・くしゃみ」と「女性」がそろったら腹圧性です。第29回にも同じ事例が出ており、そこでは原因として「骨盤底筋群の機能低下」が正解でした。

第32回 グループホームで暮らすアルツハイマー型認知症の80歳男性。「トイレに行きたい」とホーム内を歩き回ったあとで失禁する。 → 機能性尿失禁。尿意はあるのに、トイレの場所がわからず間に合わないケースです。

③ 機能性尿失禁・認知症の人の排泄ケア

②で学んだ「機能性＝膀胱は正常、トイレにたどり着けない」がわかっていれば、正解はすべて「たどり着けるように整える」になります。

④ 排泄ケアの心理的配慮・おむつの考え方

排泄はもっとも人に見られたくない行為です。この章の問題は「本人の気持ちを守る選択肢」を選べば正解できます。

  • 失禁したら、周囲に気づかれないようさりげなくトイレへ誘導して交換する（「尿のにおいがしますよ」と言うのは×）
  • 失禁後にトイレが近くなった人には、まず不安に感じていることを聴く
  • おむつは「家族が楽だから」で使わない。尿意があるならトイレへ。おむつを使い続けると、尿路感染症や自立度の低下につながる
  • 家族への助言は「本人の羞恥心に気を配りましょう」

⑤ 尿・便の量と回数のめやす

  • 尿量の異常：無尿＝1日100mL以下／乏尿＝1日400mL以下／多尿＝1日3000mL以上（尿量は1日全体で判断）。頻尿＝回数が多い／尿閉＝膀胱に尿があるのに出せない。
  • 尿失禁の5タイプ：腹圧性（せき・くしゃみで漏れる、女性に多い）／切迫性（急な強い尿意）／溢流性（尿が出しきれず、尿意がないまま少しずつあふれる）／機能性（移動や認知の問題で間に合わない）／反射性（脊髄の障害などで尿意がなく反射で出る）。
  • 便の観察（色・形・かたさ・回数・血の混入）は健康状態を知る大事な目安。いつもとの違いを記録・報告。
  • 高齢者の肺炎は、熱やせきが目立たず「なんとなく元気がない」など非特異的な症状で始まることがある。
  • 感染性廃棄物のバイオハザードマーク：赤＝液状・泥状（血液など）／橙＝固形（血のついたガーゼなど）／黄＝鋭利なもの（注射針など）の3色。
  • 男性生殖器：精巣＝精子と男性ホルモン／前立腺＝精液の成分を分泌（高齢男性は前立腺肥大症に注意）。
  • 尿の量：1日1,000〜2,000mL。乏尿＝400mL以下、無尿＝100mL以下、多尿＝3,000mL以上。
  • 正常な尿は排泄直後は無菌で弱酸性。時間がたつと細菌がアンモニアをつくって臭くなる。白く濁る＝膀胱炎、赤い＝結石・腫瘍など。
  • 頻尿＝日中8回以上、夜間頻尿＝夜2回以上（転倒の原因に）。
  • 女性は尿道が短く（3〜4cm）まっすぐなので尿路感染症が起こりやすい。男性は前立腺肥大で尿の勢いが落ちる。
  • 嵌入便＝直腸に固い便が詰まり、その脇から水様便がもれ続ける状態。下痢と間違えやすい。
