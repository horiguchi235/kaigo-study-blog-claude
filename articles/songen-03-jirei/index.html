  3. 「安全のため」「家族が言っているから」と本人の意思より優先する選択肢は×。危険は、本人の選択を尊重したうえで減らす工夫をする。

解き方の手順：事例の最後の一文を見る → 型1〜型3のどれかを判定する → ひっかけパターン集の×を消す。病名（ALS・血管性認知症など）がわからなくても、この手順で解けます。

① 型1：不安や迷いには、まず思いを聴く・理由を確かめる

見分け方：事例の最後が「〜と話した」「〜と打ち明けた」「〜と相談した」で終わり、「最初の対応」「応答」を聞かれたらこの型です。

回本人の言葉・状況正解
第38回ALS（全身の筋力が落ちていく病気）の夫。妻は「人工呼吸器をつけてほしい」と夫に言えない「お互いの気持ちを話し合う時間をつくりませんか」

よく出る不正解：施設入所・同居・入院をすぐ提案する／「大丈夫ですよ」と根拠なく安心させる／家族や医師に決めてもらう／「〜しないで」と一方的に指示する

意思は変わってもよいものです。人生の最終段階の医療・ケアについて、本人・家族・支援者がくり返し話し合うことをアドバンス・ケア・プランニング（ACP、人生会議）といいます。施設入所時などに書く「延命治療に関する意思確認書」も、一度書いたあとで変更できます。

意思決定支援とは

判断能力が低下した人も含め、本人が自分で決められるように支えることです。「認知症の人の日常生活・社会生活における意思決定支援ガイドライン」（厚生労働省、2018年）では、次の3段階で考えます。

段階支援の中身
意思形成支援本人が決めるのに必要な情報を、わかる形で伝える
意思表明支援本人が思いを言葉にできるよう、聴く・待つ（家族の前では言いにくいことにも配慮）
意思実現支援本人が決めたことを、チームや社会資源を使って実現する

型1の「まず聴く・理由を確かめる」は、意思表明支援にあたります。

障害のある人については、別に「障害福祉サービス等の提供に係る意思決定支援ガイドライン」（2017年）があります。本人の自己決定を最大限尊重し、それが難しいときは本人の意思を推定し、それでも難しいときの最後の手段として本人にとっての最善の利益を判断する、という順番です。

第38回：人間の尊厳と自立

Aさん（62歳、男性、要介護2）は、2年前に筋萎縮性側索硬化症（amyotrophic lateral sclerosis：ALS）と診断された。妻と自宅で過ごしたいと希望し、訪問介護（ホームヘルプサービス）と訪問看護を利用している。最近、症状が進行し、サービス担当者会議で、Aさんは、「人工呼吸器はつけないで、最期まで自宅で生活したい」と言った。

会議のあと、妻は訪問介護員（ホームヘルパー）に、「夫にはなかなか言えないのですが、一日でも長く一緒にいたいので、私は人工呼吸器をつけてほしいと思っています」と気持ちを伝えた。

次のうち、Aさんの妻に対する訪問介護員（ホームヘルパー）の提案として、最も適切なものを1つ選びなさい。

  1. 「会議で話されていたAさんの意思が大切なので、尊重しませんか」
  2. 「私にはわからないので、医師に決めてもらってはどうですか」
  3. 「Aさんに人工呼吸器をつけてもらったほうがいいですよね」
  4. 「Aさんとお互いの気持ちを話し合う時間をつくりませんか」
  5. 「病院や施設の情報がほしいと介護支援専門員に伝えてはどうですか」

出典：第38回 介護福祉士国家試験（人間の尊厳と自立）

正解を見る

正解：4　本人と家族の思いが違うときは、どちらかに決めつけず話し合える場をつくるのが意思決定支援です。

第37回：人間の尊厳と自立

Aさん（83歳、女性、要介護3）は、脳梗塞（cerebral infarction）の後遺症で左片麻痺（ひだりかたまひ）があり、介護老人福祉施設で生活している。家族から、「できることは自分で行ってほしい」と希望があり、Aさんは自室から食堂まで車いすで自走することを日課としている。

1週間前から、介護福祉士養成施設の学生がAさんのフロアで実習を開始した。数日前からAさんは実習生に、「今日は腕が痛いので、食堂まで車いすを押してください」と依頼するようになった。悩んだ実習生は、実習指導者に相談をした。

実習生に対する実習指導者の最初の助言として、最も適切なものを1つ選びなさい。

  1. 「Aさんの腕は痛くないので、気にしないでください」
  2. 「どのようなときも、Aさん自身で行ってもらうことが必要です」
  3. 「ご家族から自分で行うように、言われています」
  4. 「それは自立につながらないので、車いすを押さないでください」
  5. 「Aさんが依頼する理由を、まず考えてみることが大切です」

出典：第37回 介護福祉士国家試験（人間の尊厳と自立）

正解を見る

正解：5　自立支援は「何でも自分でさせる」ことではありません。痛みや気持ちの変化など、頼む理由をまず確かめることが先です。

第36回：人間の尊厳と自立

週1回介護予防通所リハビリテーションを利用しながら、近所の友人たちとの麻雀（まーじゃん）を楽しみに生活している。

  3. 膝の精密検査を勧める。

第35回：介護の基本

Aさん（85歳、女性、要介護1）は夫と二人暮らしで、訪問介護（ホームヘルプサービス）を利用している。Aさんは認知症（dementia）の進行によって、理解力の低下がみられる。ある日、Aさんが訪問介護員（ホームヘルパー）に、「受けているサービスをほかのものに変更したい」「夫とは仲が悪いので話したくない」と、不安な様子で話した。

意思決定支援を意識した訪問介護員（ホームヘルパー）の対応として、最も適切なものを1つ選びなさい。

  1. Aさんとの話し合いの場に初めから夫に同席してもらった。
  2. Aさんにサービス変更の決断を急ぐように伝えた。
  3. Aさんと話す前に相談内容を夫に話した。
  4. サービスを変更したい理由についてAさんに確認した。
  5. 訪問介護員（ホームヘルパー）がサービス変更をすることを判断した。

出典：第35回 介護福祉士国家試験（介護の基本）

正解を見る

正解：4　認知症があっても、まず本人の意思と理由を確かめるのが意思決定支援。本人の了解なく夫に伝える・同席させるのは×です。

② 型2：生活歴・役割・楽しみを生かす

見分け方：事例に昔の仕事や趣味が書かれていて、今は元気がない・落ち着かない・帰りたがる、という流れならこの型です。帰宅願望のように本人の言葉で終わる事例は、型1（まず気持ちを受け止める）と型2（生活歴をくみ取る）の両方で考えます。

回生活歴・状況正解
第38回元地域の医師。最期まで自宅で暮らしたい「近所の方の力も借りて、この地域で暮らせるように考えましょう」
第37回料理好き。夕方「ご飯の支度をしないと」と帰りたがる職員と一緒に夕食の準備をしてもらう
第35回家を守ってきた人が、夕方「家に帰らないといけない」と訴える「家のことが気になるんですね」と気持ちを受け止める（型1と型2の両方）
第35回「台所を借りて自分でおやつを作りたい」おやつ作りをきっかけに施設生活に楽しみがもてるように
第32回毎朝コーヒーを豆から入れていたが、失敗が増えて自信をなくす夫が「そばにいて一緒にコーヒーを入れる」
第32回美容院・俳句教室が楽しみだったおしゃれをして俳句クラブに参加を勧める（ノーマライゼーション）
第31回茶道の師範。寝ていることが多く、表情が乏しいお茶のたて方を話題にする
第30回「仕事があるから夜に一人で入浴したい」と日中の入浴を拒否働いていた頃の話を詳しく聴く

レクリエーション（生活支援技術）：事例ではなく知識問題で出ますが、「本人の趣味・希望・生活を生かす」という考え方は型2と同じです。

  • レクリエーションは、生活を快適にし、よりよく生きるための支援。基礎生活（食事・睡眠・排泄）・社会生活（仕事・地域活動）・余暇生活（趣味・スポーツ）の3つの領域をつくり直す

  • やり方は個別と集団がある。集団では利用者が役割を担う。要介護の人ではQOLの向上、介護予防では運動機能の向上と生活の活性化をねらう

  • 地域のボランティア・民生委員・専門職と協力し合う（ネットワーキング）

  • 買物や調理など生活に根ざした活動も取り入れる

  • 過去の趣味を取り入れる。地域のボランティアも歓迎。全員参加を強制しない

  • アイスブレーキング：参加者の緊張をほぐす

よく出る不正解：「ここが家ですよ」「仕事はないですよ」と事実で否定する／鍵をかける・薬で落ち着かせる／転倒予防で車いす・居室中心にする／職員がメニューや役割を決める

第35回：介護の基本

Bさん（82歳、女性、要介護2）は、若いときに夫を亡くし、家で仕事をしながら子どもを一人で育てた。夫や子どもと過ごした家の手入れは毎日欠かさず行っていた。数年前に、アルツハイマー型認知症（dementia of the Alzheimerʼs type）と診断され、認知症対応型共同生活介護（認知症高齢者グループホーム）に入居した。夕方になると、「私、家に帰らないといけない」と介護福祉職に何度も訴えている。

Bさんに対する介護福祉職の声かけとして、最も適切なものを1つ選びなさい。

  1. 「仕事はないですよ」
  2. 「ここが家ですよ」
  3. 「外に散歩に行きますか」
  4. 「家のことが気になるんですね」
  5. 「子どもさんが『ここにいてください』と言っていますよ」

出典：第35回 介護福祉士国家試験（介護の基本）

正解を見る

正解：4　帰宅願望は否定・説得せず、まず気持ちを受け止める。生活歴から「家を守ってきた」思いをくみ取ります。3の散歩は気分転換にはなりますが、「家に帰らないといけない」という思いを聞かずに話をそらしているので、最初の声かけとしては×です。

第38回：介護の基本

第37回：介護の基本

Aさん（75歳、女性）は、3か月前に、血管性認知症（vascular dementia）を発症し、軽度の左片麻痺（ひだりかたまひ）で杖歩行（つえほこう）となり、要介護3と認定された。Aさんは、料理が大好きで、娘と一緒に食事を作ることを楽しみに生活していた。1か月前から認知症（dementia）が進行し、ユニット型介護老人福祉施設に入所した。Aさんは夕方になると、「ご飯の支度をしないといけないから帰ります」と言いながら、興奮して歩き回る様子がみられるようになった。

第35回：生活支援技術

Gさん（79歳、女性、要介護3）は、介護老人福祉施設に入所して、3週間が経過した。施設での生活には慣れてきているが、居室でテレビを見て過ごす時間が長くなった。ある時、Gさんが、「気分転換に台所を借りて、自分でおやつを作ってみたい」と介護福祉職に話した。

Gさんのレクリエーション活動の計画作成にあたり、介護福祉職が留意すべきこととして、最も適切なものを1つ選びなさい。

  1. Gさんの居室で行うようにする。
  2. おやつのメニューは、介護福祉職が選ぶ。
  3. 施設のレクリエーション財を優先する。
  4. 集団で行うことを優先する。
  5. おやつ作りをきっかけに、施設生活に楽しみがもてるようにする。

出典：第35回 介護福祉士国家試験（生活支援技術）

正解を見る

正解：5　本人の希望を生かし、施設での生活に楽しみや役割をもてるようにするのがレクリエーションの目的です。

③ 型3：リスクがあっても本人の選択を尊重し、危険を減らす

見分け方：転倒・徘徊・病気の悪化など「危ない」状況が書かれ、本人のしたいことと安全がぶつかる事例です。正解は「やめさせる」ではなく、本人の希望をかなえながら危険を減らす工夫です。
