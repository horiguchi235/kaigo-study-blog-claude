この記事の論点と出題数（過去5年）

  • 事例：思いを聴く・理由を確かめる（意思決定支援） 6問
  • 事例：生活歴・役割・楽しみを生かす支援 6問

この記事のポイント

  1. 利用者が不安や迷いを打ち明けたら、正解は「まず思いを聴く」「理由を確かめる」。提案・説得・励ましは後回し。
  2. 様子が変わった人・落ち込んでいる人には、昔の仕事・趣味・役割を生かす支援が正解。
  3. 「安全のため」「家族が言っているから」と本人の意思より優先する選択肢は×。

① 型1：不安や迷いには、まず思いを聴く・理由を確かめる

見分け方：事例の最後が「〜と話した」「〜と打ち明けた」「〜と相談した」で終わり、「最初の対応」「応答」を聞かれたらこの型です。

回本人の言葉・状況正解
第30回「この家で死にたいと思っていたけど、いつまで二人で暮らせるか…」「何か心配なことがおありなんですね」
第31回骨折後、一人暮らしを続けることが不安と告げた「また転ぶかもしれないと思っているのですか」
第36回「自宅で暮らし続けたいけど、心配なの…」生活に対する思いを聞く
第34回「性同一性障害でも施設に受け入れてもらえるでしょうか」「施設での生活で心配なことは何ですか」
第35回認知症で「サービスを変更したい」「夫とは話したくない」変更したい理由を本人に確認（夫の同席・決断を急がせるは×）
第24回自助具をすすめたが、どうしても家族の介助を受けたいなぜ家族の介助を望むのか理由を聞く
第37回片麻痺の人が実習生に「腕が痛いので車いすを押して」と頼む「依頼する理由を、まず考えてみることが大切です」
第32回延命治療の計画書を作ったが、自宅で静かに過ごしたい気持ちに迷い「意思確認のための話合いは、何度でもできますよ」
第38回ALSの夫。妻は「人工呼吸器をつけてほしい」と夫に言えない「お互いの気持ちを話し合う時間をつくりませんか」

よく出る不正解：施設入所・同居・入院をすぐ提案する／「大丈夫ですよ」と根拠なく安心させる／家族や医師に決めてもらう／「〜しないで」と一方的に指示する

意思は変わってもよいものです。人生の最終段階の医療・ケアについて、本人・家族・支援者がくり返し話し合うことをアドバンス・ケア・プランニング（ACP、人生会議）といいます。

第38回：人間の尊厳と自立

ALSのAさん（62歳）は会議で「人工呼吸器はつけず、最期まで自宅で暮らしたい」と話した。会議のあと妻が「夫には言えないけれど、一日でも長く一緒にいたいので呼吸器をつけてほしい」と訪問介護員に打ち明けた。妻への提案として、最も適切なものはどれ？

  1. 「会議でのAさんの意思を尊重しませんか」
  2. 「わからないので医師に決めてもらいましょう」
  3. 「呼吸器をつけてもらったほうがいいですよね」
  4. 「Aさんとお互いの気持ちを話し合う時間をつくりませんか」
  5. 「病院や施設の情報をケアマネジャーに頼みましょう」
正解を見る

正解：4　本人と家族の思いが違うときは、どちらかに決めつけず話し合える場をつくるのが意思決定支援です。

第37回：人間の尊厳と自立

左片麻痺のAさん（83歳）は、家族の希望もあり食堂まで車いすで自走している。数日前から実習生に「今日は腕が痛いので押してほしい」と頼むようになった。相談を受けた実習指導者の最初の助言として、最も適切なものはどれ？

  1. 「腕は痛くないはずなので気にしないで」
  2. 「どんなときも自分で行ってもらう必要があります」
  3. 「家族から自分でするように言われています」
  4. 「自立につながらないので押さないでください」
  5. 「Aさんが頼む理由を、まず考えてみることが大切です」
正解を見る

正解：5　自立支援は「何でも自分でさせる」ことではありません。痛みや気持ちの変化など、頼む理由をまず確かめることが先です。

第36回：人間の尊厳と自立

一人暮らしのAさん（76歳、要支援1）は、変形性膝関節症と診断され、同じころ麻雀仲間の友人が入院した。「自宅で暮らし続けたいけど、心配なの…」と話すAさんへの対応として、最も適切なものはどれ？

  1. 要介護認定の申請を勧める
  2. 友人のお見舞いを勧める
  3. 膝の精密検査を勧める
  4. 別の趣味の希望を聞く
  5. 生活についての思いを聞く
正解を見る

正解：5　不安を訴える人には、制度や提案より先にどんな思い・困りごとがあるかを聴くのが基本です。

第35回：介護の基本

第35回：介護の基本

夫を早くに亡くし、家で仕事をしながら一人で子どもを育て、家の手入れを欠かさなかったBさん（82歳、アルツハイマー型認知症）。グループホームで夕方になると「家に帰らないと」と何度も訴える。声かけとして最も適切なものはどれ？

  1. 「仕事はないですよ」
  2. 「ここが家ですよ」
  3. 「外へ散歩に行きますか」
  4. 「家のことが気になるんですね」
  5. 「お子さんが『ここにいて』と言っていますよ」
正解を見る

正解：4　帰宅願望は否定・説得せず、まず気持ちを受け止める。生活歴から「家を守ってきた」思いをくみ取ります。

② 型2：生活歴・役割・楽しみを生かす

見分け方：事例に昔の仕事や趣味が書かれていて、今は元気がない・落ち着かない・帰りたがる、という流れならこの型です。

第31回茶道の師範。寝ていることが多く、表情が乏しいお茶のたて方を話題にする
第32回毎朝コーヒーを豆から入れていたが、失敗が増えて自信をなくす夫が「そばにいて一緒にコーヒーを入れる」

  • 買物や調理など生活に根ざした活動も取り入れる
  • 過去の趣味を取り入れる。地域のボランティアも歓迎。全員参加を強制しない
  • アイスブレーキング：参加者の緊張をほぐす

よく出る不正解：「ここが家ですよ」「仕事はないですよ」と事実で否定する／鍵をかける・薬で落ち着かせる／転倒予防で車いす・居室中心にする／職員がメニューや役割を決める
