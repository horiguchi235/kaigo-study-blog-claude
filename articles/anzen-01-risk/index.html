この記事のポイント

  1. 事故予防の基本はヒヤリ・ハットの収集・分析と組織での体制づくり（委員会・研修）。事故が起きたら速やかに家族へ連絡。
  2. 転倒した人には、医療職が来るまでそばで状況と体の様子を把握。自己判断で湿布・飲水・様子見はしない。
  3. 防災は計画を職員で共有、BCP策定は義務。警戒レベル3なら垂直避難。避難所では体を動かして血栓予防。

① リスクマネジメント

ハインリッヒの法則

1件の重大事故の背後に 29件の軽微な事故、300件のヒヤリ・ハットがある（1：29：300）。

→ ヒヤリ・ハットを集めて分析することが事故防止につながる。

よく出る○×

○×
事故が起きる前から体制を整える事故が起きてから検討
生活を制限されるストレスも事故の原因になる社会的活動・飲酒喫煙・お祭り参加を制限
職員に安全の研修を定期的に施設管理者の安全が第一／画一的なサービス
安全対策担当者を置き、事故防止の委員会を定期開催苦情はその場で職員が解決／私物破損は自己判断で弁償
事故が起きたら速やかに家族に連絡損害賠償は市町村／職員名を記録に残さない
小さな事故・インシデントも組織で報告・共有（書面で）個人で対応／口頭のみ／報告後は代表者に一任
事故報告書は職員で共有し再発防止に生かす管理者以外閲覧不可

細心の準備をしても、慣れても、事故は起こりうるという前提で考えます。

✏️ 過去問を解いてみよう（第38回：介護の基本）

特別養護老人ホームのリスクマネジメントとして、最も適切なものはどれ？

  1. 安全対策の担当者を置き、事故予防の委員会を定期的に開く
  2. 家族からの苦情は、介護福祉職がその場で解決する
  3. 利用者の私物を壊したら、介護福祉職の判断で弁償する
  4. 入浴介助中のインシデント報告は、口頭で伝えるだけに統一する
  5. 事故防止のため、地域のお祭りへの参加は控える
正解を見る

正解：1　事故防止は組織で取り組むもの。担当者と委員会を置き、報告は記録に残します。生活を制限するのは×です。

車いすの安全

○×
急な下り坂は後ろ向きで降りる前向きで降りる
点検は定期的に気づいたときだけ
空気圧は適正に（低いとブレーキが利きにくい）空気圧を下げる
—2台同時に押す／ドアを片手で押さえながら押す

パーキンソン病の人

歩き始めはリズムをとれるよう声をかける（「いち、に」）。常に車いす＋ベルト固定、お茶をなみなみ注ぐ、入浴中に浴室を離れるは×。

2010年の内閣府調査では、自宅での転倒場所は「庭」が最多でした。最近の調査では居室・居間が多い結果もあるので、問題文の調査に注意。

✏️ 過去問を解いてみよう（第35回：介護の基本）

利用者の危険を避けるための対応として、最も適切なものはどれ？

  1. スプーンを拾おうと前かがみになった車いすの人を、目で見て確認しただけだった
  2. ふらつきながら廊下を歩く人の横を、黙って通り過ぎた
  3. 食事介助中に姿勢が傾いてきたので、姿勢を直した
  4. 足の筋力が落ちた人が靴下で歩いていたので、スリッパを履いてもらった
  5. フットサポートを下げたまま立とうとした車いすの人に、またいでもらった
正解を見る

正解：3　傾いた姿勢はすぐ直して誤嚥や転落を防ぎます。スリッパは脱げやすく転倒の原因、フットサポートは上げてから立ちます。

施設の防災

第38回：介護の基本

指定避難所での要配慮者への生活支援として、最も適切なものはどれ？

  1. 避難所内の情報提供に、音声やピクトグラム（絵記号）も使う
  2. 二次避難に備えて、避難所内でも土足で過ごしてもらう

介護保険施設の防災対策として、最も適切なものはどれ？

  2. 介護福祉士は防災士の資格取得が義務づけられている
  3. 個別避難計画の作成が施設長に義務づけられている
  4. 飲料水と非常食は1日分の備蓄が義務づけられている

第36回：介護の基本

3階建ての特別養護老人ホームがある地域に、洪水の警戒レベル3が出された。介護福祉職の行動として、最も適切なものはどれ？

  1. 玄関のドアを開けたままにする
  2. 消火器で初期消火する
  3. 上の階へ避難する（垂直避難）よう誘導する
  4. 家族に安否情報を連絡する
  5. 倒れそうな物を固定する
正解を見る

正解：3　警戒レベル3は高齢者等避難。避難に時間のかかる人は避難を始める段階です。浸水に備え、安全な上の階へ避難します。

④ 事故予防の実際（誤薬・外傷・骨折・BCP・熱傷）

  • 体調がいつもと違う（顔色・反応など）と気づいたら、自分で判断せずすぐ医療職に連絡。初動は「安全の確保 → 状態の確認 → 医療職へ連絡」の順。
  • 転倒したら、けががなさそうでもしばらく観察（痛み・意識・あとから出る症状）。
  • 薬の介助は、医師から処方された薬を名前と薬袋を毎回確かめてから渡す（飲み間違い防止）。
  • 防災：施設は定期的に避難訓練を行う。
  • リスクマネジメントは「①事故を予防する ②起きたときに被害を広げない ③原因を分析して再発を防ぐ」の流れで考える。2つだけ対策すれば十分、ということはない。
  • ヒヤリ・ハット＝事故にはならなかったが危なかった出来事／アクシデント＝実際に起きた事故。報告した人を責めず、組織全体で改善する。
  • 安全のためでも、身体拘束や「活動を一律に禁止する」ことに頼らない。
  • 事故防止検討委員会は施設長・医師・看護職・介護職・ケアマネなど多職種で構成し、事故の原因分析と再発防止策の実施・見直しを行う。事故が起きたら市町村と家族に報告し、記録する（記録は2年保存）。
  • 事故の種類で多いのは「転倒・転落」→「誤嚥・誤飲」。家庭内の不慮の事故で亡くなる高齢者は浴槽内での溺死が多い。
  • 誤薬の防止：食前・食後・食間・時間指定の区別、本人確認、食事を食べなかったときの対応は医師・看護職に確認。
  • 消費者被害（高額な布団・健康食品・リフォーム）に気づいたら消費生活センターにつなぎ、クーリング・オフも検討。
  • BCP（業務継続計画）＝災害や感染症のときもサービスを続けるための計画。2024年4月から全事業所で策定・研修・訓練が義務。地域のハザードマップで危険を確認しておく。
  • 外傷の手当て：出血は清潔なガーゼで直接押さえる（直接圧迫止血）、ティッシュは繊維が残るので使わない、ゴム手袋で感染予防。鼻血は前かがみで小鼻をつまむ（上を向かない）。
  • 骨折が疑われるときは動かさずに副子で固定し、腫れていれば冷やして患部を心臓より高く。高齢者は典型的な症状がなくても骨折していることがある。
