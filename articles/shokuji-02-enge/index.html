  • 摂食・嚥下の5期と誤嚥 2問
  • 食事の姿勢と状態に応じた食事介助 13問

この記事のポイント

  1. 5期は「先行期（見て認識）→準備期（かむ）→口腔期（舌で送る）→咽頭期（ごくん）→食道期」。目・認知症の問題は先行期。
  2. 姿勢は「足底を床、深く座って、顎を引く」。テーブルは肘がつく高さ。
  3. 介助は「まず汁物で口を湿らす→ティースプーン1杯→口を閉じる→一口ごとに飲み込み確認」。むせたら咳を続けてもらう。

① 摂食・嚥下の5期と誤嚥

期何が起こる試験のキーワード
先行期食べ物を目で見て認識し、食べ方を判断認知機能・視覚の影響を受ける。唾液分泌が増える
準備期かんで唾液と混ぜ、食塊をつくる食塊形成
口腔期舌で食塊を咽頭へ送る口唇ではなく舌
咽頭期軟口蓋が上がり鼻への道を閉じる → 喉頭蓋が気管にふたをする → 食道へ嚥下反射。一瞬呼吸が止まる（嚥下性無呼吸）
食道期蠕動運動で胃へ不随意運動（自分の意思で動かせない）
  • 誤嚥 ＝ 食べ物が気管に入ること
  • 誤嚥を防ぐ部位 ＝ 喉頭蓋
  • 眼鏡が壊れて食事に時間がかかる、献立を説明したら食べ始めた認知症の人 → どちらも先行期

第38回：こころとからだのしくみ

認知症のAさん（98歳）は、最近、配膳されても食べ始めないことが増えた。職員が献立や食材を説明すると食べ始めた。摂食嚥下の5期のうち、職員が支援した期はどれ？

  1. 先行期
  2. 準備期
  3. 口腔期
  4. 咽頭期
  5. 食道期
正解を見る

正解：1　食べ物を認識し、食べようとする段階が先行期。説明で「これは食べ物だ」とわかるよう支援しました。

第36回：こころとからだのしくみ

食べ物が入って誤嚥が起こる部位はどれ？

  1. 扁桃
  2. 食道
  3. 耳管
  4. 気管
  5. 咽頭
正解を見る

正解：4　誤嚥＝食べ物や唾液が気管に入ること。咽頭は食べ物と空気の共通の通り道です。

② 食事の姿勢と介助の基本

姿勢

○×
足底を床につける（車いすはフットサポートから下ろす）かかとを浮かす
いすに深く座る浅く座る
顎を引く（やや前かがみ）顎を上げる・頭部を後屈・体幹を後ろに傾ける
テーブルは肘がつき腕が自由に動く高さテーブルと体の間を30cm離す
ずり落ち・首が後屈してむせる → まず座位姿勢の調整食事回数・量・食器を先に変える
片麻痺で体が傾く → クッションで姿勢保持全介助にする・臥位で食べる

介助の手順

  1. 介護者は座って、利用者と目線を合わせる（立って介助は×）
  2. 食事が楽しくなる雰囲気をつくる（会話を禁止・大音量のテレビは×）
  3. 最初にお茶や汁物で口を湿らせる
  4. 一口量はティースプーンに軽く1杯。スプーンは舌の中央に置く（奥に入れるは×）
  5. 口に入れたら口唇を閉じるよう声かけ
  6. 一口ごとに飲み込みを確認（2〜3口ごとは×）
  7. 話しかけるのは口に入っていないとき

むせた・様子がおかしいとき

  • むせ込んだ → しっかり咳を続けてもらう。お茶を飲ませる・上を向く・深呼吸は×
  • 箸が止まり、表情がこわばり呼吸が浅い → 医療職に報告しつつ口腔の状況を観察（窒息の確認）

④ 誤嚥しにくい食べ物・温度・窒息への対応

  • 食事のときは頭を後ろにそらさない（頭部後屈は誤嚥しやすい）。あごを軽く引く。
  • 食べ物を刻むだけではまとまりにくくむせやすい。とろみ・ゼリーなどまとまりとなめらかさを調整する。
  • のどに詰まった（窒息）ときは、背部叩打法や腹部突き上げ法（ハイムリック法）で取り除く。
  • 誤嚥のサイン：むせ・ガラガラした湿った声・口の中の食べ残し。
  • 誤嚥しにくい食べ物＝ゼリー・プリン・ヨーグルト・とろみのあるもの・やわらかいもの。誤嚥しやすい＝水・お茶・汁物（さらさら）、パン・カステラ（ぱさぱさ）、もち・のり（くっつく）、酸味の強いもの。きざみ食はかえってむせることがある。
  • 食べ物の温度のめやす：温かいものは60〜65℃、冷たいものは10〜15℃（体温に近いと飲み込む反射が起きにくい）。
  • 食事の姿勢：いすに深く座り足底を床につけ、軽く顎を引く。ベッド上なら背もたれ45〜60度。介助者は座って目の高さを合わせ、スプーンは下から口元へ。
  • 窒息のサイン＝チョークサイン（のどを両手でつかむ）。意識がなくなる前に背部叩打・腹部突き上げ、すぐに応援要請。
  • 仮性球麻痺＝脳血管障害で、延髄そのものは無事なのに飲み込み・発音の障害が出る。
