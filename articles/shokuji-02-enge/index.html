この記事のポイント

  1. 5期は「先行期（見て認識）→準備期（かむ）→口腔期（舌で送る）→咽頭期（ごくん）→食道期」。目・認知症の問題は先行期。
  2. 姿勢は「足底を床、深く座って、顎を引く」。テーブルは肘がつく高さ。
  3. 介助は「まず汁物で口を湿らす→ティースプーン1杯→口を閉じる→一口ごとに飲み込み確認」。むせたら咳を続けてもらう。

① 摂食・嚥下の5期と誤嚥

用語：食塊＝かんで唾液と混ぜ、飲み込める形にまとめたもの。軟口蓋＝上あごの奥のやわらかい部分。嚥下反射＝のどに食べ物が来ると自動で「ごくん」が起こるしくみ。口腔期・咽頭期・食道期の3つをまとめて「嚥下の3期」と呼ぶこともあります。

期何が起こる試験のキーワード
先行期食べ物を目で見て認識し、食べ方を判断認知機能・視覚の影響を受ける。唾液分泌が増える
準備期かんで唾液と混ぜ、食塊をつくる食塊形成
口腔期舌で食塊を咽頭へ送る口唇ではなく舌
咽頭期軟口蓋が上がり鼻への道を閉じる → 喉頭蓋が気管にふたをする → 食道へ嚥下反射。一瞬呼吸が止まる（嚥下性無呼吸）
食道期蠕動運動で胃へ不随意運動（自分の意思で動かせない）
  • 誤嚥 ＝ 食べ物が気管に入ること
  • 誤嚥を防ぐ部位 ＝ 喉頭蓋。のどでは気管が前（首の側）、食道が後ろ（背中側）にあるので、飲み込む瞬間に喉頭蓋がふたをしないと、食べ物が気管に入ってしまう
  • 眼鏡が壊れて食事に時間がかかる、献立を説明したら食べ始めた認知症の人 → どちらも先行期
  • 誤嚥のサイン：むせ・ガラガラした湿った声・口の中の食べ残し。高齢者はむせない誤嚥（不顕性誤嚥）も多く、寝ている間に唾液が気管に入ることもあります。発熱・痰が増える・なんとなく元気がない・食欲が落ちる、は誤嚥性肺炎のサインです
  • 誤嚥を疑う様子：食事に1時間以上かかる、夜間に咳き込む、発熱や肺炎をくり返す、脱水・低栄養がある、飲み込むときにのど仏の動きがはっきりしない、のどがゴロゴロ鳴る
  • 誤嚥の予防：食後すぐ横にならず、しばらく座って過ごす（胃からの逆流を防ぐ）。口の中を清潔に保つ（口腔ケアは誤嚥性肺炎の予防になる）

球麻痺と仮性球麻痺

「球」は脳の延髄のこと。延髄には飲み込みや発音をつかさどる中枢があります。

比べる点球麻痺仮性球麻痺
傷んだ場所延髄そのもの延髄より上（大脳の両側など）。延髄は無事
主な原因延髄の脳梗塞、ALS（筋萎縮性側索硬化症）など脳血管障害のくり返し
症状飲み込み・発音の障害同じく飲み込み・発音の障害
  • 仮性球麻痺では、唇が閉じにくく食べこぼす、よだれが出る、食塊をまとめられず飲み込む反射が遅れる、などが起こります
  • 加齢でも食べる力は落ちます。総入れ歯（総義歯）になると、かむ力は自分の歯のころの3分の1〜6分の1ほどになり、飲み込むまでに時間がかかります
  • うとうとしている（傾眠ぎみの）人は、声をかけてしっかり目を覚ましてから食べてもらいます（先行期の支援）

② 食事の姿勢と介助の基本

姿勢

○×
足底を床につける（車いすはフットサポートから下ろす。踏ん張れて飲み込みやすい）かかとを浮かす
いすに深く座る浅く座る
顎を引く（やや前かがみ）顎を上げる・頭部を後屈・体幹を後ろに傾ける
テーブルは肘がつき腕が自由に動く高さテーブルと体の間を30cm離す
ずり落ち・首が後屈してむせる → まず座位姿勢の調整食事回数・量・食器を先に変える
片麻痺で体が傾く → クッションで姿勢保持全介助にする・臥位で食べる
  • ベッド上で食べるときは、背もたれを45〜60度ほど起こし、顎を軽く引きます。嚥下障害が重い人は、医師や言語聴覚士の指示で30度ほどに起こし、首を前に曲げた姿勢をとることもあります
  • 背上げは、先に膝を上げてずり落ちを防いでから行います。背上げのあとは一度背中をベッドから離してずれを直し（背抜き）、膝の下にクッション、頭の後ろに枕を入れて顎を引いた姿勢にします
  • できるだけベッドから離れ、食堂など食事にふさわしい場所で食べることを優先します
  • 食堂は換気をし、明るい照明に（暗い照明は先行期で食べ物を認識しにくくなる）

介助の手順

  1. 介護者は座って、利用者と目線を合わせる（立って介助は×）
  2. 食事が楽しくなる雰囲気をつくる（会話を禁止・大音量のテレビは×）
  3. 最初にお茶や汁物で口を湿らせる
  4. 一口量はティースプーンに軽く1杯。スプーンは下から口元へ運び、舌の中央に置く（奥に入れるは×）
  5. 口に入れたら口唇を閉じるよう声かけ
  6. 一口ごとに飲み込みを確認（2〜3口ごとは×）
  7. 話しかけるのは口に入っていないとき

むせた・様子がおかしいとき

状態見分け方○ 対応
むせ咳ができる・声が出るしっかり咳を続けてもらう（お茶を飲ませる・上を向く・深呼吸は×）
窒息声も咳も出ない。のどを両手でつかむ（チョークサイン）すぐに応援を呼び、背部叩打法や腹部突き上げ法（ハイムリック法）で取り除く
  • 箸が止まり、表情がこわばり呼吸が浅い → 医療職に報告しつつ口腔の状況を観察（窒息の確認）

③ 状態に応じた食事介助

食事の自助具：太柄スプーン（握る力が弱い人）、首の曲がるスプーン（手首や腕が動きにくくても口に運びやすい）、ふちが立ち上がった皿（すくいやすい）、滑り止めマット（食器が動かない）、取っ手付きの吸い口コップ。自助具は病名ではなく、その人の困りごとに合わせて選びます。

困りごと合う自助具
握る力が弱い柄の太いスプーン
肩・肘・手首が動きにくく口まで運べない（関節リウマチなど）柄の長いスプーン、すくう部分の角度を変えた（曲げた）スプーン
手が震える・すくいにくい縁の高い皿・滑り止めマット
箸が使いにくいバネ付き箸
コップを口まで運べない・不随意運動があるストロー付きコップ

飲み物の道具の違い：吸い口コップ（取っ手付き）＝手に持って少し傾ければ飲める／ストロー付きコップ＝コップを持ち上げずに飲める／吸い飲み＝寝たまま介助者が口に注ぐもの（誤嚥しやすく、自分で飲める人には使わない）。

利用者の状態○ 正解× よく出る不正解

視覚障害クロックポジション（食器の位置を時計の文字盤に見立てて「ご飯は7時、汁物は5時」と伝える）で説明—
左半側空間無視（脳の障害で左側の空間に注意が向かず、見落とす）食べる様子を観察して食器の位置を変える左側にトレーを置く
左同名半盲（両目とも視野の左半分が欠ける）食器は見える側（右寄り）に置き、首を左に向けて確かめるよう声をかける。本人は見えないことを自覚している（半側空間無視は見えていても気づかず、本人の自覚がない）左側に食器を置く
不随意運動がある（アテトーゼ型脳性麻痺など）コップを固定してストロー付きコップで飲む。緊張すると不随意運動が強まるので、リラックスできる環境で自分で食べられるよう支える吸い飲み（首を傾ける必要がある）・重いコップ・全介助
パーキンソン病（手の震え）片側の縁が高い皿上半身を後ろに倒す
前頭側頭型認知症（行動の抑えがきかず、次々口に詰め込む）食器に少量ずつ盛る大きなスプーン・全部並べる
構音障害（発音がうまくできない）食事中の会話は控えめに会話しながら食べるよう勧める
  • アイスマッサージ＝凍らせた綿棒などで、のどの奥を軽く刺激して飲み込む反射を起こしやすくする方法。食前に行います
