この記事のポイント

  1. 1gあたりのエネルギーが最大なのは脂質。低栄養のサインは「1か月に3%以上の体重減少」。指標に血圧は入らない。
  2. 脱水のサインは「活動性の低下・皮膚をつまむと戻らない・尿が少なく濃い」。勧めるのは経口補水液、むせる人にはゼリー。
  3. 腎不全はたんぱく質制限、透析はカリウム制限で野菜はゆでこぼす。COPD・逆流性食道炎は少量ずつ回数を分けて。

① 栄養素と低栄養

栄養素試験に出る働き
三大栄養素炭水化物（糖質）・脂質・たんぱく質。水分・ビタミン・ミネラルは入らない
脂質1gあたりのエネルギーが最大（約9kcal）。ホルモンの原料
たんぱく質筋肉・酵素の材料。最大のエネルギー源ではない
ナトリウム血圧の調節
カリウム血圧を下げる方向に働く。骨の形成ではない
ビタミンDカルシウムの吸収を助ける
ビタミンB1糖質をエネルギーに変える
ビタミンA・D・E・K脂溶性（Aは水溶性、は×）
  • 栄養素の大部分を吸収するのは小腸
  • 必要エネルギー量＝基礎代謝量×活動係数×ストレス係数。第29回は約1,200kcal

低栄養

○ 低栄養の指標・サイン×

お茶漬けやうどんで済ませる・疲れやすい → 主菜（肉・魚・卵・大豆）を勧める主食を勧める

第38回：こころとからだのしくみ

低栄養の高齢者にみられる症状や行動の特徴として、最も適切なものはどれ？

  1. 唾液が増える
  2. 腸の動きが活発になる
  3. 食べこぼしが減る
  4. 偏った食べ方をする
  5. 体重が増える
正解を見る

正解：4　かむ力が落ちるとやわらかい炭水化物に偏りがち。低栄養では体重減少・筋力低下・むくみなどがみられます。

  3. 直腸
  4. 横行結腸
  5. S状結腸
正解を見る

正解：2　栄養素の大部分は小腸で吸収。大腸では主に水分を吸収します。

② 脱水と水分補給

○ 脱水のサイン×
活動性の低下（ぼんやりする）浮腫・多尿・皮膚の湿潤・低体温
手の甲の皮膚をつまむと形が残る—
尿量が少なく、色が濃い、唇の乾燥—
場面○ 勧めるもの×

下痢をしている利用者の水分補給として、最も適切なものはどれ？

  1. 白湯
  2. 牛乳
  3. 炭酸水
  4. コーヒー

  1. のどが渇いてから飲むよう伝える
  2. 水でむせるときはゼリーを控える
  3. 起床時は水分を控えるよう伝える
  4. 食事中の水分は1日の量から除く
  5. 汗が多いときは塩分を含む飲み物を勧める
正解を見る

正解：5　汗で塩分も失われるので、経口補水液などを。高齢者は渇きを感じにくいのでのどが渇く前にこまめに飲みます。

第35回：こころとからだのしくみ

誤嚥しやすい高齢者の脱水予防のために確認することとして、最も優先すべきものはどれ？

  1. 入れ歯の状態
  2. 腕の関節可動域
  3. 睡眠時間
  4. 夜間の咳こみ
  5. とっている水分の形状
正解を見る

正解：5　さらさらの水分はむせやすく、飲む量が減って脱水に。とろみ・ゼリーなど形状を確認して飲める形にします。

第36回：生活支援技術

血液透析を受けている利用者の食事として、最も適切なものはどれ？

  1. 塩分の多い食品を勧める
  2. ゆでこぼした野菜を勧める

第35回：生活支援技術

逆流性食道炎の症状がある利用者への助言として、最も適切なものはどれ？

  1. 脂肪の多い食品を勧める
  2. 酸味の強い果物を勧める
  3. 1日の食事を何回かに分けて少しずつ食べるよう勧める
  4. 食事中は腹圧がかかる前かがみの姿勢を勧める
  5. 食後すぐ仰向けになるよう勧める
正解を見る

正解：3　少量ずつ回数を分けて胃の圧を上げない。脂肪・酸味は胃酸を増やし、食後すぐ横にならない（上半身を起こす）ことも大切です。

⑤ 五大栄養素・ビタミンとミネラル・塩分と脱水

  • BMI＝体重(kg)÷身長(m)÷身長(m)。18.5未満がやせ、25以上が肥満の目安。栄養アセスメント：身体計測（身長・体重・体重減少率）／生理・生化学検査（血液検査など）／食事調査（面接・質問紙）。
  • エネルギー：糖質・たんぱく質＝1gあたり4kcal、脂質＝9kcal。食物繊維はビタミンではない（消化されにくい成分で整腸作用）。
  • ビタミン：A＝目・皮膚粘膜（レバー・緑黄色野菜）／D＝カルシウムの吸収（魚・日光）／K＝血液を固める（納豆・小松菜）／B1＝糖質の代謝（不足で脚気）／E＝抗酸化。
  • 脱水の種類：高張性＝水分が多く失われる（のどが渇く）／低張性＝ナトリウムが多く失われる（汗のあとの水だけの補給などで起こる、だるさ・意識障害）／等張性。体重の2〜3％の水分が失われるとのどの渇きが出る。
  • 骨粗鬆症の予防：カルシウム・ビタミンD・たんぱく質、日光浴、骨に適度な負荷をかける運動（負荷を減らすのは×）、禁煙。閉経後の女性に多い。
  • 食物アレルギーの症状で最も多いのは皮膚症状（じんましん）。複数の臓器に症状が出るアナフィラキシーは救急対応。
  • 貧血を起こす病気：慢性腎臓病（エリスロポエチン低下）・悪性貧血（ビタミンB12）・関節リウマチ・がんなど。脂質異常症は貧血の原因ではない。
  • 腎臓病・透析：絶対安静にする必要はなく、病状に合わせて活動する。血液透析は腕の動脈と静脈をつないだシャントを使う（シャント側の腕で血圧測定・採血をしない、圧迫しない）。透析をした日は入浴を控える（針を刺した部分の感染・出血予防）。腹膜透析は自宅でできる。
  • 筋肉の働き＝体を動かす・姿勢保持・熱をつくる・代謝（皮膚の保護は皮膚の役割）。
  • 五大栄養素：炭水化物・脂質・たんぱく質（三大栄養素）＋ミネラル（無機質）・ビタミン。たんぱく質を構成するアミノ酸のうち、体内でつくれない必須アミノ酸は9種類。
  • ビタミン不足で起こる病気：A＝夜盲症、D＝骨軟化症・骨粗鬆症、K＝血液が固まりにくい、B1＝脚気、B12・葉酸＝巨赤芽球性貧血、ナイアシン＝ペラグラ、C＝壊血病。水溶性ビタミン（B群・C）は体にためられないので毎日とる。
  • ミネラル：カルシウム不足→骨粗鬆症、鉄不足→鉄欠乏性貧血、亜鉛不足→味覚障害（カキ・レバー・ナッツ）。
  • 低栄養のめやす：血清アルブミン値3.5g/dL以下。食欲が落ちた高齢者には、季節を感じる食材や盛りつけの工夫も。
  • 食塩の目標量：男性7.5g未満・女性6.5g未満。減塩には、だし・酸味・香味野菜・香辛料を使う。
  • 脱水予防：スポーツドリンク・経口補水液・ゼリー・果物・汁物。アルコールやコーヒーは利尿作用があるので水分補給には向かない。
  • 食生活の言葉：中食（総菜・弁当を家で食べる）、個食（同じ食卓で別々のものを食べる）、孤食（ひとりで食べる）。
