この記事のポイント

  1. 片麻痺の人は健側から浴槽に入り、出るときは縁やバスボードにいったん座る。
  2. 清拭は末梢から中枢へ、水分はその都度拭く。背部を拭くときは健側を下に。
  3. 洗髪は「すすぐ前に泡をタオルで拭き取る」（3回出題）。

① 浴室での介助

片麻痺の人の浴槽の出入り

場面○×
浴槽に入る健側の足から（健側で湯温を確かめられる）麻痺側から入る
湯につかる手すりや浴槽の縁につかまり、ゆっくり—
浴槽の中足で浴槽の壁を押して姿勢を安定させる後ろに寄りかかって足を伸ばす（体が浮いて沈む）
浴槽から出る浴槽の縁やバスボードにいったん座る真上に立ち上がる（前かがみで立つ）
介護者の位置麻痺側について支える—

用具と環境

  • 移乗台・シャワーチェアーは浴槽の縁と同じ高さにする
  • シャワー用車いすは段差に注意して移動する
  • 入浴用介助ベルトは腰部に装着する
  • 手すりは浴槽の出入りのために水平と垂直の両方をつける
  • 浴室の入口は引き戸が使いやすい（開き戸は×）
  • 第38回：頸髄損傷（C5）で電動車いすを使う人 → 入浴用リフト

シャワー浴・特殊浴槽

  • 湯温は介護福祉職が先に確かめてから利用者に確かめてもらう
  • かけるときは足元（末梢）から
  • 利用者が陰部を洗うときは、背部に立って見守る（プライバシーへの配慮、第34回）
  • 寒いと言われても熱いシャワーはかけない。水分は浴室内で拭いてから脱衣室へ
  • 特殊浴槽（ストレッチャー式）：背部は側臥位にして洗う、固定ベルトはつけたまま、首までつからない

認知症の人の入浴

  • 時間をかければ自分でできる人には、衣服を着る順番に合わせて声をかける。代わりに洗う・着せるは×

第38回：生活支援技術

20歳のときに第5頸髄（C5）を損傷したAさん（55歳）は、電動車いすで自立して暮らしている。入浴は訪問介護員が福祉用具を使って介助している。使っている福祉用具として最も適切なものはどれ？

  1. 移乗台
  2. バスボード
  3. 入浴用リフト
  4. 浴槽用手すり
  5. 滑り止めマット
正解を見る

正解：3　C5損傷では体幹・下肢で体を支えられないため、入浴用リフトでつり上げて移乗します。移乗台・バスボードは座って移れる人向けです。

第37回：生活支援技術

下肢の筋力が低下した人の入浴に適した環境として、最も適切なものはどれ？

  1. 浴室の入口は開き戸にする
  2. 床から浴槽の縁までは20cmにする
  3. 縦に長く浅い洋式の浴槽にする
  4. 浴槽の縁の幅は20cmにする
  5. 出入りのため水平と垂直の手すりをつける
正解を見る

正解：5　垂直の手すり＝立ち座り、水平の手すり＝移動・姿勢保持。浴槽の縁は40cm程度、浴槽は和洋折衷、入口は引き戸がよいです。

第36回：生活支援技術

右片麻痺の利用者が個浴の移乗台に座っている。安全に入浴するための助言として最も適切なものはどれ？

  1. 「右足から浴槽に入りましょう」
  2. 「左膝に手をついてゆっくりつかりましょう」
  3. 「浴槽内では足で浴槽の壁を押して姿勢を安定させましょう」
  4. 「浴槽内では後ろの壁に寄りかかって足を伸ばしましょう」
  5. 「出るときは真上に立ち上がりましょう」
正解を見る

正解：3　浴槽内は足で壁を押して体を安定させます。入るのは健側（左）の足から、出るときは前かがみになって立ちます。

第36回：生活支援技術

身体機能が低下した高齢者がストレッチャー型の特殊浴槽を使うときの留意点として、最も適切なものはどれ？

  1. 2人で洗髪と洗身を同時に行う
  2. 背中を洗うときは横向きにする
  3. 浴槽に入るときは両腕の上から固定ベルトをつける
  4. 首までつかるようにする
  5. つかる時間は20分程度にする
正解を見る

正解：2　背中は側臥位にして洗います。同時に2人で洗うと負担が大きく、ベルトは腕の上から締めず、つかるのは5分程度・肩までです。

④ 清拭・洗髪・足浴の手順と温度

  • ストーマのある人も入浴できる（装具をつけたまま・外して入る方法がある）。
  • シャワー浴も、心臓から遠い足先・手先からお湯をかけてから体を洗う。
  • 洗髪中に気分が悪いと言われたら、中止して医療職に連絡。ベッド上の洗髪にはケリーパッドを使い、指の腹で頭皮を洗う。
  • 清拭のタオルを絞る湯は55〜60℃、室温は24℃前後。拭く順番は顔→上肢→体幹→下肢→殿部・陰部。手足は末梢から中心へ、腹部は「の」の字、顔は目頭から目尻へ、額から顎へは「3」の字を書くように。
  • 女性の陰部は前から後ろへ（尿路感染予防）。殿部は内側から外側へ円を描いて。拭いたらすぐ押さえ拭きで水分を取る。
  • 洗髪：ドライヤーは頭皮から20cm以上離し、同じ場所に3秒以上当てない。シャンプーの泡をタオルで除いてから湯で流す。洗えないときはオイルシャンプー（皮脂やふけが多い人）、ドライシャンプー（水を使わない）。
  • 足浴はぬるめ（37〜39℃）で膝下まで温めると、全身が温まり安眠効果も。終わったら指の間の水分をよく拭く。
