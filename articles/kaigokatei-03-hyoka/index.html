この記事のポイント

  1. 実施では、利用者の反応や変化を観察し、客観的に記録する。支援内容は説明して同意を得る。
  2. 評価の基準は短期目標。「目標の達成度」を見て、うまくいかなければ再アセスメントへ戻る。
  3. チームの中心は利用者。介護福祉職の役割は、生活の変化や本人・家族の思いをチームに伝えること。

① 介護計画の実施

○×
利用者の反応や変化を観察する計画をこなすこと自体を目的にする
実施した状況をその都度、客観的に記録する評価日にまとめて記録する
支援内容を説明して同意を得る変更内容の説明を省略する
他職種へは随時報告する目標の達成後にまとめて報告する
チームで計画を統一して実施する実施内容を個々の介護福祉職に任せる
継続するかどうかは目標と利用者の反応で判断する介護福祉職が満足するまで続ける
  • 実施の3つの視点：自立支援（できることは本人が行う）・安全と安心・快適さ。
  • 記録の目的は、ケアの継続・評価・チームでの連携・職員の学びなど。研究機関に個人情報を渡すことは目的ではない（研究に使うなら同意や匿名化が必要）。

よく出る不正解：介護福祉職の価値観・満足度で判断する／介護福祉職の経験を積むことが目的

② 評価・モニタリング・再アセスメント

用語意味
モニタリング計画どおりに実施できているか、効果が出ているかを点検する
評価目標の達成状況を確かめる
再アセスメント状況が変わったときや目標が達成できないときに、もう一度情報を集めて課題を見直す

モニタリングは2つの場面で出てきます。どちらも「実施状況と効果の確認」ですが、主体が違います。介護過程のモニタリングは、介護福祉職が自分たちの介護計画について行うもの。ケアマネジメントのモニタリングは、介護支援専門員がケアプラン全体について行い、居宅では原則月1回以上の訪問が決まっています（2024年度から、利用者の同意などの条件を満たせば、テレビ電話などで行う月があってもよく、その場合も訪問は少なくとも2か月に1回。ケアマネジメント・多職種連携・人材育成）。

評価で見る4つの点：①計画どおり実施したか ②目標にどこまで届いたか ③支援内容・方法は合っていたか ④新しい課題や、新しくできそうなことは出ていないか。モニタリングでは、これに⑤サービスの質と量に対する利用者・家族の満足度が加わります。

評価のルール

  • 評価の基準は短期目標。最も優先する評価項目は「短期目標の達成度」
  • 支援の実施状況の情報を整理して評価する。計画したのに実施しなかったことも評価する
  • 利用者の満足度や反応も踏まえる。評価の結果は利用者本人に伝える
  • 評価基準と評価日は計画を立てるときに決めておく（実施後・実施中に決めるのは×）
  • 生活状況が変わったら、予定の評価日を待たずに見直す
  • 目標を達成していても評価する。他の利用者と比べない
  • 評価はチームから情報を集めて行い、責任をもつのは介護計画を立てた介護福祉職（サービス担当者会議はケアプランを話し合う場で、介護計画を評価する場ではない。相談支援専門員は障害福祉のサービス等利用計画の担当）

評価のあとの分かれ道

評価の結果次にすること
目標を達成した計画を続ける、または終了して次の目標へ
達成したが、続けるのが難しい（負担が大きいなど）計画（支援内容）を修正する
達成できなかった原因を探り、計画を修正するか再アセスメントへ
途中で状態が大きく変わった評価日を待たずに再アセスメント

計画を修正するのは、「目標に届かなかったとき」と「届いたが続けるのが難しいとき」の2つの場合です。

例の続き（「畑に出たい80歳の女性」の3か月後の評価）

評価の結果次にすること
食堂まで約30mを休まず歩けた日が週5日以上になった目標を達成。次の短期目標を「家の周りを100m歩ける」にする
膝の痛みが強くなり、歩けない日が増えた看護職と一緒に再アセスメントし、痛みの原因と支援内容を見直す

事例では、本人が「大丈夫です」と言っているからといって、満足していると決めつけるのは×です。表情（涙など）や、家族・近所の人からの情報も合わせて評価し、必要なら計画を見直します（第28回）。

③ チームアプローチ・カンファレンス・会議

チームアプローチの原則

  • チームの中心は利用者
  • チームで目的を共有し、情報交換して生活課題を明確にする
  • ボランティアや家族もチームの一員になれる。メンバーは固定ではなく、必要に応じて人数を増減する
  • メンバーは対等な立場で、それぞれの専門の視点から利用者を見る（「どの職種も同じ視点」は×。第24回）
  • 介護福祉職の役割は、生活状況の変化の情報を提供すること、本人と家族の思いを報告すること（利用者の思いを代わりに伝える代弁（アドボカシー））
  • 本人が自分で決められるよう、選ぶために必要な情報をわかりやすく伝える（意思決定支援）。くわしくは自己決定・意思決定支援の事例問題

会議と、それぞれの役割

会議・場面ポイント
カンファレンス計画の修正などを、職員の間で共通認識をもつために行う
サービス担当者会議（介護保険）主催は介護支援専門員。ケアプラン原案を話し合い、会議のあとに本人の同意を得て交付する。訪問介護のサービス提供責任者（サ責）は、訪問介護計画の作成に必要な情報を確認する
サービス担当者会議（障害福祉）事業所のサービス管理責任者は、自分が作る個別支援計画の取り組みを報告する
個別支援会議（障害福祉）サービス管理責任者が開き、事業所の個別支援計画を話し合う会議（サービス担当者会議とは別）
  • ケアカンファレンスは、関係者がよりよいケアのために開く会議の総称で、サービス担当者会議はその一種です。
  • ケアプランは利用者・家族に説明し、文書で利用者の同意を得ることが決められています。

障害福祉では、全体の計画（サービス等利用計画）は相談支援専門員、事業所の計画（個別支援計画）はサービス管理責任者がつくります（ケアプラン・サービス等利用計画・個別支援計画…計画とつくる人の違い）。

ケアマネジメントの流れ：インテーク（最初の相談・受付）→ アセスメント → ケアプラン原案 → サービス担当者会議 → 同意・交付 → 実施 → モニタリング → 評価（終結）。何度会議をしても、計画やその変更には必ず本人の同意が必要です。くわしくはケアマネジメント・多職種連携・人材育成で扱います。

事例研究

  • 目的：介護過程から介護実践を振り返ること
  • 倫理的配慮：研究内容を説明して同意を得る、個人が特定されないようにする、引用元を示す、事実を拡大解釈しない

第35回：介護過程

次の事例を読んで、問題に答えなさい。

〔事例〕

Mさん（35歳、男性、障害支援区分5）は、脳性麻痺（のうせいまひ）（cerebral palsy）による四肢麻痺（ししまひ）で筋緊張がある。日常生活動作は全般に介護が必要であり、電動車いすを使用している。これまで、本人と母親（70歳）の希望で、自宅で二人暮らしを続けてきた。

Mさんは3年前から、重度訪問介護を利用している。軽度の知的障害があるが、自分の意思を介護者と母親に伝えることができる。相談支援専門員が作成したサービス等利用計画の総合目標は、「やりたいことに挑戦し、生活を充実させる」となっている。Mさん自身も、やりたいことを見つけたいと介護福祉職に話していたことから、次の個別支援会議で検討する予定になっていた。

ある日、重度訪問介護の利用時、パラリンピックのテレビ中継を見ていたMさんが、介護福祉職に、「ボール投げるの、おもしろそう」と話した。

いくつかのスポーツクラブを見学後、介護福祉職はMさんから、「このスポーツクラブが近いから、入会前に体験したい」と伝えられた。

Mさんへの介護福祉職の対応に関する次の記述のうち、最も適切なものを1つ選びなさい。

  1. 筋緊張から回復する訓練を行うように伝える。
  2. 母親が決めたスポーツクラブを選ぶように勧める。
  3. スポーツクラブにすぐに入会するように勧める。
  4. 意思決定に必要な情報を提供する。
  5. 相談支援専門員の許可を得るように勧める。

出典：第35回 介護福祉士国家試験（介護過程）

正解を見る

正解：4　本人が自分で決められるよう、体験の方法・費用・移動手段など必要な情報を提供する（意思決定支援）。
