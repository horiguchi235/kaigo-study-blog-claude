この記事のポイント

  1. 便が通る順番は「上行→横行→下行→S状→直腸」。第35回・第38回と連続で出ている。
  2. 自然な排便を促すカギは「朝食後（胃・結腸反射）」と「足を床につけた前かがみの姿勢」。
  3. 便秘はタイプによって対応が逆になる。便が細い・血が混じる便秘は、介助ではなく受診。

① 消化管の順番

口 → 食道 → 胃 → 小腸 → 大腸 → 肛門

部位順番
小腸十二指腸 → 空腸 → 回腸
大腸盲腸 → 上行結腸 → 横行結腸 → 下行結腸 → S状結腸 → 直腸

覚え方：お腹の右下から始まって、時計回りに「の」の字を描きます。右下（盲腸）→ 右を上へ（上行）→ 上を横へ（横行）→ 左を下へ（下行）→ S字に曲がって（S状）→ 直腸。

この「の」の字は、②の腹部マッサージの方向とまったく同じです。セットで覚えましょう。

✏️ 過去問を解いてみよう（2問）
第38回：こころとからだのしくみ

健康な成人で、横行結腸の次に便が通る部位はどれ？

  1. 盲腸
  2. 上行結腸
  3. 下行結腸
  4. S状結腸
  5. 直腸
正解を見る

正解：3　盲腸→上行→横行→下行→S状結腸→直腸。お腹の右下から時計回りに進みます。

第35回：こころとからだのしくみ

健康な成人で、上行結腸の次に内容物が通る部位はどれ？

  1. S状結腸
  2. 回腸
  3. 直腸
  4. 下行結腸
  5. 横行結腸
正解を見る

正解：5　上行結腸の次は横行結腸。回腸は小腸の最後の部分で、盲腸より手前です。

② 排便のしくみと、自然排便を促す介助

しくみ

  1. 食べ物が胃に入ると、大腸がぎゅっと動き出す（胃・結腸反射）。朝食後に最も強く起こる
  2. 便が直腸に届くと、直腸の壁が伸びて「便意」が生まれる（排便反射）
  3. お腹に力を入れ（腹圧）、外肛門括約筋を自分の意思でゆるめて排便する

腸の動きを活発にするのは副交感神経（リラックスしたとき）です。交感神経（緊張したとき）は腸の動きを抑えます。

介助

しくみがわかれば、介助の正解は自然に導けます。

しくみ正解になる介助
胃・結腸反射は朝食後に強い朝食後にトイレへ誘導する／起床後に冷水を飲む（胃への刺激）
腹圧をかけると出やすい便座に座り、足の裏を床につけて前かがみ
腸は運動で動く散歩などの運動
大腸の走行は「の」の字腹部マッサージは上行 → 横行 → 下行の順（時計回り）

よく出る不正解：仰向け（寝た姿勢）で排便する／食後すぐに横になる／マッサージを「下行→横行→上行」（逆回り）で行う／お腹を冷やす／朝食を抜く／食事の量を減らす

「朝食後にトイレ誘導」は、胃・結腸反射、直腸性便秘、便失禁の改善の3問で正解になっています。

第35回：生活支援技術

胃・結腸反射を利用して自然な排便を促す支援として、最も適切なものはどれ？

  1. 歩行を促す
  2. 起きたあとに冷たい水を飲んでもらう
  3. お腹のマッサージをする
  4. 便座に誘導する
  5. 離床時間を増やす
正解を見る

正解：2　胃に飲食物が入ると大腸が動き出すのが胃・結腸反射。起床後の冷水・朝食が引き金になります。

第35回：生活支援技術

便失禁を改善するための対応として、最も適切なものはどれ？

  1. トイレの場所がわからない人にポータブルトイレを置く
  2. 移動に時間がかかる人におむつを使う
  3. 便意がはっきりしない人を、朝食後に時間を決めてトイレへ誘導する
  4. 下剤を飲んでいる人は下剤をやめさせる
  5. 失禁が多い人は食事の量を減らす
正解を見る

正解：3　朝食後は胃・結腸反射で便が出やすいので、時間を決めて誘導します。下剤の中止は医師が判断します。

第34回：生活支援技術

便秘ぎみの高齢者に自然な排便を促す介護として、最も適切なものはどれ？

  1. 朝食を抜くよう勧める
  2. 油を控えるよう勧める
  3. 散歩を勧める
  4. 腰を冷やすよう勧める
  5. 寝る前にトイレに座るよう勧める
正解を見る

正解：3　適度な運動（散歩）で腸の動きがよくなります。朝食・適度な油・温めることも排便を助けます。

③ 便秘の種類と原因

タイプひとことで原因対応
弛緩性大腸の動きが弱い食物繊維・水分・運動の不足、長期臥床（高齢者に多い）食物繊維・水分・運動
直腸性便意を感じにくい便意を我慢する習慣 → 排便反射が鈍る朝食後のトイレ誘導、我慢しない
けいれん性腸が緊張しすぎストレス、過敏性腸症候群（コロコロ便）ストレスを減らす
器質性腸そのものに病気大腸がんなど（便が細い・血が混じる）受診（介助で治すものではない）

薬による便秘：麻薬性鎮痛剤（モルヒネなど）は、腸の動きを止めて便秘を起こします。

✏️ 過去問を解いてみよう（第38回：こころとからだのしくみ）

Aさん（80歳、男性）は半年前から急に便秘になり、今は5日に1回程度。お腹が張り、便が細く、血がつくこともある。対応として最も適切なものはどれ？

  1. 水分をとるよう促す
  2. 食物繊維をとるよう促す
  3. 散歩などの運動を促す
  4. お腹のマッサージをする
  5. 医療機関の受診を促す
正解を見る

正解：5　急に始まった便秘＋細い便＋血便は、大腸がんなどで腸が狭くなる器質性便秘を疑うサイン。まず受診です。

④ 下痢と排泄物の感染対策

  • 下痢便は感染源として扱う
  • 汚れたおむつはビニール袋に入れ、袋の口を固く縛る（腸管出血性大腸菌）
  • 手袋は使い捨て（くり返し使わない）。手洗いは流水と石けんで
  • 下痢が続くと脱水になりやすい → 水分を控えるのは誤り
  • 肛門周りの皮膚は、強くこすらず押さえるように拭く

ノロウイルスにはアルコールが効きにくく、次亜塩素酸ナトリウムで消毒します。詳しくは「感染対策」の記事でまとめます。

⑤ 消化のしくみと便の観察・便秘と下痢への対応

  • 便秘の予防：適度な水分・食物繊維・運動・決まった時間の排便習慣。便意をがまんしない。下剤を自己判断で常用しない。
  • 小腸＝十二指腸・空腸・回腸の3つ。全長約6〜7mで、栄養吸収の中心。大腸は水分の吸収と便の形成。
  • 消化液：唾液のアミラーゼ＝でんぷんを分解／胆汁＝脂肪を乳化（消化酵素は含まない。たんぱく質の分解ではない）。
  • 消化器の病気：胃・十二指腸潰瘍＝ピロリ菌や痛み止め（NSAIDs）が原因／食道静脈瘤＝肝硬変による門脈の圧上昇／腸の憩室＝腸の壁が袋状に飛び出したもので、大腸（結腸）に多い。
  • 便の性状は「ブリストル便形状スケール」（タイプ1＝コロコロ〜7＝水様）で記録すると共有しやすい。タイプ3〜5が普通。
  • 便の色：黒＝胃など上部消化管の出血、赤＝痔・大腸の出血、白っぽい＝胆汁の流れが悪い。
  • 便秘の種類：弛緩性（腸の動きが弱い、高齢者に多い→食物繊維・水分・運動）、けいれん性（ストレス、便秘と下痢をくり返す）、直腸性（便意をがまん→朝食後のトイレ誘導）。モルヒネ・抗コリン薬なども便秘の原因。
  • 腹部マッサージは大腸の走行（上行→横行→下行結腸）に沿って。前かがみの姿勢で腹圧をかける。
  • 下痢のときは脱水予防（白湯や常温のスポーツドリンクを少しずつ）、冷たい飲み物・牛乳・炭酸は避ける。感染症の可能性があるので排泄物は感染源として扱う。

ひっかけパターン集（便秘・排便で「ほぼ×」）

選択肢の表現なぜ×

食後すぐ横になる／仰向けで排便腹圧がかからない
