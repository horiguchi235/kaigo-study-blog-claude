この記事の論点と出題数（過去5年）

  • 入浴の作用（温熱・静水圧・浮力）・湯温の影響・体温調節 4問
  • 入浴の安全（血圧低下・ヒートショック・食事・状態別の入浴） 2問

この記事のポイント

  1. 入浴の作用は温熱・静水圧・浮力の3つ。「静水圧＝むくみが減る」「浮力＝体が軽い・関節を動かしやすい」をセットで覚える。
  2. 中温浴（38〜41℃）＝リラックス（副交感神経）、高温浴（42℃以上）＝興奮（交感神経・血圧上昇）。正反対になる。
  3. 事故を防ぐ3原則は「温度差を小さく」「急に立ち上がらない」「食直後・空腹時は避ける」。

① 入浴の3つの作用と湯温

作用体に起きること試験での正解例注意点
温熱作用血管が広がり血行がよくなる、筋肉がほぐれる血行促進・筋肉の緊張をほぐす長く入ると疲れる・のぼせる
静水圧作用水の圧力で体が締めつけられる下肢のむくみが軽減する心臓に戻る血液が増えて心臓に負担、胸やお腹が押されて呼吸にも負担
浮力作用首までつかると体重が約1/10に感じられる「からだが軽く感じる」、浴槽内で関節運動を促す体が浮いて姿勢が不安定になり、転倒しやすい

静水圧は心臓への負担になるので、心臓病の人は半身浴（水位はみぞおちまで＝心臓より下）にします（→②）。このほか、気持ちが落ち着く精神的な作用（リラックス）もあります。

中温浴と高温浴は「正反対」

中温浴（38〜41℃）高温浴（42℃以上）
自律神経副交感神経が優位（リラックス）交感神経が優位（興奮）
血圧下がる上がる
心臓（心拍）働きがおだやか（心拍は落ち着く）働きが強まり心拍数が増える
脳落ち着く（鎮静・リラックス）興奮する
筋肉ゆるむ収縮する
胃腸消化機能が高まる腸の動きが抑えられる
腎臓働きが促進される抑えられる

覚え方：交感神経は「戦う・逃げる」ときの神経、副交感神経は「休む・食べる・出す」ときの神経。中温浴は副交感神経側、高温浴は交感神経側です。高温浴では心臓がドキドキして血圧も上がると覚えます。高齢者が熱いお湯を好むときは、血圧が上がることを説明します。

体温（入浴前の体調確認に）

  • 体温調節の中枢は脳の視床下部
  • 体温は早朝に最も低く、夕方に高い。腋窩温（わきの下で測る体温）は口腔温より低い
  • 第33回：エアコンのない夏の部屋で、厚手の布団をかけて寝ていて38.5℃ → 原因は布団（うつ熱＝熱が体にこもって体温が上がること。病気の発熱とは別）

  1. 血圧の上昇
  2. 腸蠕動（ちょうぜんどう）の促進

第37回：生活支援技術

次の記述のうち、入浴の作用を生かした、高齢者への入浴の介護として、最も適切なものを1つ選びなさい。

  1. 食事は、入浴直前に摂取する。
  2. 高血圧の人には、42℃以上の湯につかってもらう。
  3. 浴槽の中では、関節運動を促す。
  4. 心疾患（heart disease）のある人には、肩まで湯につかってもらう。
  5. 個浴の浴槽内では、足を浮かせてもらう。

② 安全な入浴と、状態に応じた入浴

入浴事故を防ぐ基本

温まると血管が広がって血圧が下がっているので、急に立つと脳への血液が減り、立ちくらみや失神（脳貧血）を起こします。これを起立性低血圧といいます（寝た姿勢や座った姿勢から急に立ったとき、血圧が下がってふらつくこと）。逆に、寒い脱衣室から熱い湯に入ると血圧が急に上下します。これがヒートショックです。

○×
浴室・脱衣室と居室の温度差を小さくする（脱衣室も22℃前後に暖める）湯温を高めにする／冬だけ気をつければよい
浴槽からはゆっくり立ち上がる声をかけて急に立ってもらう（血圧が下がりふらつく）
食直後と空腹時の入浴は避ける食後すぐ入浴する
入浴前に排泄と体調の確認をすませる—
入浴前後に水分補給をする水分を控える（汗で脱水になる）
湯温は介護福祉職が先に肌で確かめ、次に利用者に確かめてもらう利用者が先に確かめる
かけ湯は手足の先（心臓から遠い所）から体の中心（胸・肩）からかける
湯につかるのは短め（5分程度がめやす。長湯をしない）長く温まるほどよい
浴後はすぐに拭き、水分補給と体調の確認をする自然に乾くまで待つ（体が冷える）
入浴前の血圧が普段より高ければ入浴を見合わせる（医療職に相談）自覚症状がなければ入浴を勧める

家庭内の不慮の事故死では、入浴に関係するものが多いです。ヒートショックは冬、入浴中から入浴後に起こりやすく、高血圧の人ほど注意が必要です。

入浴を避けるとき・入浴できる人

入浴を避ける・医師に確認する状態が安定していれば入浴できる
空腹時・食事の直後・発熱しているとき胃ろう・埋め込み式ペースメーカーがある人
体力の消耗が激しいとき、感染症、終末期 → 医師の指示を受ける尿道カテーテル（膀胱留置カテーテル）・ストーマがある人
高血圧の人が降圧剤を飲んだ直後（血圧が下がりすぎる）全介助の人、褥瘡（床ずれ）がある人

管や装具がある、介助が多い、という理由だけで一律に入浴を禁止しないのがポイントです。

状態○ 正解×
心疾患・高血圧半身浴（水位はみぞおちまで）、長湯しない肩まで・43℃以上・20分
血液透析透析直後の入浴は控える（針を刺した所からの出血・感染、血圧低下のおそれ）透析直後に入浴
ペースメーカー（心臓のリズムを整える機械を胸に埋め込む）普通に入浴できる（電気風呂は避ける）シャワー浴に限る

  1. 体温の上昇
  2. 呼吸数の増加
  3. 心拍数の増加
  4. 動脈血酸素飽和度の低下

第34回：生活支援技術

入浴の介護に関する次の記述のうち、最も適切なものを1つ選びなさい。

  1. 着替えの衣服は、介護福祉職が選択する。
  2. 空腹時の入浴は控える。
  3. 入浴前の水分摂取は控える。
  4. 食後1時間以内に入浴する。
  5. 入浴直前の浴槽の湯は、45℃で保温する。

正解を見る

正解：2　空腹時・食後すぐは避けます。入浴前後に水分補給、着替えは本人が選ぶ、湯温は38〜41℃程度。

③ 浴槽内で具合が悪くなったとき・入浴方法の選び方

  • 浴槽内で意識がもうろうとしたら：顔が湯につからないようあごを上げて支え、浴槽の栓を抜いて水位を下げ、応援を呼ぶ。呼吸に異常があれば救急要請。
  • シャワー浴は体力の消耗が少ない一方、温まりにくい。浴後はすぐ拭く（水分が残ると気化熱で冷える）。
  • 寝たまま入浴するのは特殊浴槽（ストレッチャー浴）、座れる人はリフト浴（手順は入浴介助・部分浴・清拭・洗髪の手順）。
