この記事の論点と出題数（過去5年）

  • 入浴の作用（温熱・静水圧・浮力）・湯温の影響・体温調節 3問
  • 入浴の安全（血圧低下・ヒートショック・食事・状態別の入浴） 2問

この記事のポイント

  1. 入浴の作用は温熱・静水圧・浮力の3つ。「静水圧＝むくみが減る」「浮力＝体が軽い・関節を動かしやすい」をセットで覚える。
  2. 中温浴（38〜41℃）＝リラックス（副交感神経）、高温浴（42℃以上）＝興奮（交感神経・血圧上昇）。正反対になる。
  3. 事故を防ぐ3原則は「温度差を小さく」「急に立ち上がらない」「食直後・空腹時は避ける」。

① 入浴の3つの作用と湯温

作用体に起きること試験での正解例
温熱作用血管が広がり血行がよくなる、筋肉がほぐれる長く入ると疲れる・のぼせる
静水圧作用水の圧力で体が締めつけられる下肢のむくみが軽減する
浮力作用体重が約1/10程度に感じられる「からだが軽く感じる」、浴槽内で関節運動を促す

静水圧は心臓への負担にもなります。だから心臓病の人は半身浴（水位を心臓より下に）にします（→③）。

中温浴と高温浴は「正反対」

中温浴（38〜41℃）高温浴（42℃以上）
自律神経副交感神経が優位（リラックス）交感神経が優位（興奮）
血圧下がる上がる
筋肉ゆるむ収縮する
胃腸消化機能が高まる腸の動きが抑えられる
腎臓働きが促進される抑えられる

覚え方：中温浴は「休む・食べる・出す」が活発になる、高温浴は「戦う」体になる。高齢者が熱いお湯を好むときは、血圧が上がることを説明します。

体温

  • 体温調節の中枢は視床下部
  • 体温は早朝に最も低く、夕方に高い。腋窩温は口腔温より低い
  • 第33回：エアコンのない夏の部屋で、厚手の布団をかけて寝ていて38.5℃ → 原因は布団（うつ熱）

第37回：こころとからだのしくみ

好みや温度の感じ方の低下から熱いお湯を希望する高齢者に、説明すべき高温浴の特徴はどれ？

  1. 血圧が上がる
  2. 腸の動きが活発になる
  3. 腎臓の働きが活発になる
  4. 副交感神経が高まる
  5. 心臓の働きが抑えられる
正解を見る

正解：1　42℃以上の熱いお湯は交感神経が高まり血圧が急に上がる。38〜40℃のぬるめは副交感神経が働きリラックスできます。

第37回：生活支援技術

入浴の作用を生かした高齢者の入浴介護として、最も適切なものはどれ？

  1. 食事は入浴直前にとる
  2. 高血圧の人には42℃以上の湯につかってもらう
  3. 浴槽の中で関節を動かすよう促す
  4. 心疾患のある人には肩までつかってもらう
  5. 浴槽内では足を浮かせてもらう
正解を見る

正解：3　浮力で動かしやすいので浴槽内で関節運動を。心疾患の人は静水圧の負担が少ない半身浴、足は浴槽の壁につけて安定させます。

第36回：こころとからだのしくみ

体重120kgのHさんは入浴のたびに「お湯につかると体が軽く感じて楽になる」と話す。ほかの訴えはない。関係する入浴の作用はどれ？

  1. 静水圧作用
  2. 温熱作用
  3. 清潔作用
  4. 浮力作用
  5. 代謝作用
正解を見る

正解：4　お湯の中では浮力で体重が約1/10に感じられ、関節が動かしやすくなります。

② 安全な入浴と、状態に応じた入浴

入浴事故を防ぐ基本

○×
浴室・脱衣室と居室の温度差を小さくする（ヒートショック予防）湯温を高めにする／冬だけ気をつければよい
浴槽からはゆっくり立ち上がる（急に立つと血圧が下がりふらつく）—
食直後と空腹時の入浴は避ける食後すぐ入浴する
入浴前後に水分補給をする水分を控える
湯温は介護福祉職が先に肌で確かめる肩にお湯をかけて確かめる／利用者が先に確かめる
入浴前の血圧が普段より高ければ入浴を見合わせる（医療職に相談）自覚症状がなければ入浴を勧める

家庭内の不慮の事故死では、入浴に関係するものが多いです。ヒートショックは冬、入浴中から入浴後に起こりやすく、高血圧の人ほど注意が必要です。

第34回：こころとからだのしくみ

長湯が好きなMさん（85歳）が、声をかけられて浴槽から急に立ち上がり、ふらついた。原因として最も適切なものはどれ？

  1. 体温の上昇
  2. 呼吸数の増加
  3. 心拍数の増加
  4. 酸素飽和度の低下
  5. 血圧の低下
正解を見る

正解：5　温まって血管が広がっているところで急に立つと血圧が下がって（起立性低血圧）ふらつきます。ゆっくり立ち上がってもらいましょう。

第34回：生活支援技術

入浴の介護として、最も適切なものはどれ？

  1. 着替えは介護職が選ぶ
  2. 空腹時の入浴は控える
  3. 入浴前の水分補給は控える
  4. 食後1時間以内に入浴する
  5. 直前の浴槽の湯は45℃で保温する
正解を見る

正解：2　空腹時・食後すぐは避けます。入浴前後に水分補給、着替えは本人が選ぶ、湯温は38〜41℃程度。

③ 状態に応じた入浴の注意

  • 入浴の作用は3つ＋α：温熱作用・静水圧作用・浮力作用に加え、精神鎮静作用（リラックスして気持ちが落ち着く）もある。
  • 浮力作用で体が軽くなる一方、バランスが不安定になって転倒しそうになることがある。静水圧は胸やお腹を圧迫して呼吸に負担。
  • 42℃以上の熱いお湯＝交感神経が働き、筋肉が収縮（緊張）し、血圧・心拍が上がる。38〜40℃のぬるめは筋肉がゆるみリラックス。
  • 体が温まると血管が広がり、一時的な脳貧血（立ちくらみ・失神）を起こすことがある。脱衣室との温度差による急な血圧変動＝ヒートショック。
  • 湯温はまず介護職が確かめ、そのあと本人にも確かめてもらう（本人が先、ではない）。かけ湯は手足の先から。
  • 入浴は食前・食直後を避け、前に排泄・体調確認・水分補給。
  • 浴槽内で意識がもうろうとしたら：顔が水につからないようあごを上げて支え、浴槽の栓を抜いて水位を下げ、応援を呼ぶ。呼吸に異常があれば救急要請。
  • 入浴前後の注意：空腹時と食後すぐは避ける、脱衣所と浴室の温度差をなくす（22℃前後）、湯温は介助者の手で確認、湯につかるのは5分程度、入浴後は水分補給。
  • シャワー浴は体力の消耗が少ない一方、温まりにくい。心臓から遠い足もとから湯をかけ、浴後はすぐ拭く（気化熱で冷えるため）。
  • 人工透析をしている人は透析直後の入浴は避ける（針の穴からの感染）。埋込式ペースメーカーは入浴できるが、電気風呂・サウナ・長湯は避ける。
  • ストーマのある人も入浴できる（装具を外しても湯は体内に入らない）。食後1時間以内は排泄が多いので避ける。
  • 寝たまま入浴するのは特殊浴槽（ストレッチャー浴）、座れる人はリフト浴。
