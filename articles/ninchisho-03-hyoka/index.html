この記事のポイント

  1. 若年性認知症＝65歳未満で発症。男性に多く、進行が速く、就労・経済の支援が必要。
  2. 長谷川式（HDS-R）は30点満点で20点以下が認知症の疑い。ただしスケールだけで診断はできない。
  3. 抗認知症薬は進行を遅らせるが止められない。副作用は吐き気・下痢。

第36回：認知症の理解

次の記述のうち、若年性認知症（dementia with early onset）の特徴として、最も適切なものを1つ選びなさい。

  1. 高齢の認知症（dementia）に比べて、症状の進行速度は緩やかなことが多い。
  2. 男性よりも女性の発症者が多い。
  3. 50歳代よりも30歳代の有病率が高い。
  4. 特定健康診査で発見されることが多い。
  5. 高齢の認知症（dementia）に比べて、就労支援が必要になることが多い。

出典：第36回 介護福祉士国家試験（認知症の理解）

正解を見る

正解：5　働き盛りに発症するので就労・経済面の支援が重要。男性に多く、年齢が上がるほど多く、進行が速い傾向です。

第34回：認知症の理解

若年性認知症（dementia with early onset）に関する次の記述のうち、最も適切なものを1つ選びなさい。

  1. 75歳未満に発症する認知症（dementia）である。
  2. 高齢者の認知症（dementia）よりも進行は緩やかである。
  3. 早期発見・早期対応しやすい。
  4. 原因で最も多いのはレビー小体型認知症（dementia with Lewy bodies）である。
  5. 不安や抑うつを伴うことが多い。

出典：第34回 介護福祉士国家試験（認知症の理解）

正解を見る

正解：5　65歳未満で発症。原因の最多はアルツハイマー型、うつ病などと間違われ発見が遅れがちで、不安・抑うつを伴いやすいです。

② 評価スケールと軽度認知障害（MCI）

評価スケールは、大きく2つに分かれます。

  • 質問式（本人に口頭で質問して答えてもらう）：HDS-R（9問）、MMSE（11問。図形の模写・文を書く問題がある）。HDS-Rには図形の模写や書字がないのが見分けどころ
  • 観察式（日常の様子を観察して重さを決める）：FAST、CDR、認知症高齢者の日常生活自立度
  • MMSEの目安は「23点以下」ですが、「24点以下」とする資料もあります
スケール中身よく出るポイント
改訂長谷川式（HDS-R）記憶・見当識・計算などの質問（9問）30点満点・20点以下で認知症の疑い。点が低いほど重い。これだけで診断はできない
MMSE（ミニメンタルステート検査）口頭の質問＋図形の模写・文を書く30点満点・23点以下で疑い。行動観察ではない。歌やダンスの項目はない
FASTアルツハイマー型の進み具合を、生活の様子（ADL）から7段階で見る血管性用ではない
CDR（臨床認知症評価尺度）記憶・見当識・判断など6項目を観察して重症度を見る0.5＝MCI相当、1＝軽度、2＝中等度、3＝重度
画像検査CT・MRI＝脳の萎縮や出血、SPECT＝脳の血流慢性硬膜下血腫を見分けるのは頭部CT

HDS-R・MMSEはスクリーニング（認知症の疑いがある人をふるい分ける検査）で、点数だけでは診断しません。

第38回：認知症の理解

  1. 性格
  2. 居住環境
  3. 人的環境
  4. IADL（Instrumental Activities of Daily Living：手段的日常生活動作）
  5. 社会とのつながり

正解を見る

第34回：認知症の理解

軽度認知障害（mild cognitive impairment）に関する次の記述のうち、最も適切なものを1つ選びなさい。

  1. 本人や家族から記憶低下の訴えがあることが多い。
  2. 診断された人の約半数がその後1年の間に認知症（dementia）になる。
  3. CDR（Clinical Dementia Rating）のスコアが2である。
  4. 日常生活能力が低下している。
  5. 治療には、主に抗認知症薬が用いられる。

出典：第34回 介護福祉士国家試験（認知症の理解）

正解を見る

正解：1　MCIはもの忘れの自覚があるが日常生活は自立。認知症に移行するのは年5〜15％程度で、CDRは0.5です。

③ 薬と予防

抗認知症薬

ドネペジル・ガランタミン・リバスチグミンは、記憶にかかわる物質アセチルコリンを分解する酵素のはたらきを抑えて、脳の中のアセチルコリンを増やす薬です。メマンチンは別のしくみで、神経細胞を過剰な刺激から守ります。

薬対象形・特徴
ドネペジル軽度〜高度。レビー小体型にも使う飲み薬（貼り薬もある）
ガランタミン軽度〜中等度飲み薬
リバスチグミン軽度〜中等度貼り薬（貼付剤）
メマンチン中等度〜高度飲み薬。副作用はめまい・便秘・眠気など
レカネマブ（2023年）・ドナネマブ（2024年）MCI〜軽度のアルツハイマー型点滴。原因物質アミロイドβを取り除く新しい薬。脳のむくみや小さな出血の副作用に注意
○×
進行を遅らせるが、完全には止められない進行を完全に止める
主な副作用は吐き気（悪心）・下痢など消化器症状。手足のふるえ・こわばりなどパーキンソン症状（錐体外路症状）が出ることもある副作用はない
貼り薬（貼付剤）もある貼付剤はない
非薬物療法と併用する。種類によっては併用もある非薬物療法とは併用しない／複数の併用は不可
病期に応じて量を段階的に増やす段階的に減らす
軽度〜高度、レビー小体型にも使われるものがある軽度・高度・若年性・レビーには効かない

BPSDに使う抗精神病薬の副作用

  • 誤嚥のリスクが高くなる（飲み込みが悪くなる）
  • 歩幅が小さくなる・筋肉がこわばる（パーキンソン症状）、ふらつき・転倒

薬どうしの関係

薬はたらき気をつけること
抗認知症薬認知機能の低下をゆるやかにする吐き気・下痢、パーキンソン症状が出ることもある
抗精神病薬幻覚・妄想・興奮をしずめる。ドーパミンのはたらきを抑えるパーキンソン症状（小刻み歩行・こわばり）・飲み込みの悪化・眠気
抗パーキンソン病薬ドーパミンを補う逆に幻覚が出ることがある
睡眠薬・抗不安薬眠り・不安をやわらげるせん妄や転倒の原因になる

→ 「新しい薬が始まったあとの変化」は、医療職へ報告します。

予防とリスク要因

リスクを下げるリスクを上げる
集団での交流活動歯を失うことによる咀嚼機能の低下
運動・十分な睡眠難聴（補聴器を使わない）・高血圧・糖尿病・喫煙・社会的孤立
不飽和脂肪酸（魚など）の摂取飽和脂肪酸の多い食事
補聴器の使用・視力の矯正視力低下の放置・LDLコレステロールが高い

ボランティア活動・身体活動・補聴器の使用は、リスクを下げる側です。最新の知見（2024年 ランセット委員会）では、難聴・高いLDLコレステロール・視力低下・高血圧・糖尿病・喫煙・運動不足・社会的孤立など14の要因を改善すると、認知症の約半分（45％）は予防・先送りできる可能性があるとされています。

第37回：認知症の理解

次のうち、認知症（dementia）のリスクを高める要因として、最も適切なものを1つ選びなさい。

  1. 身体活動
  2. 不飽和脂肪酸の摂取
  3. 歯がなくなることによる咀嚼機能（そしゃくきのう）の低下
  4. 難聴による補聴器の使用
  5. ボランティア活動

出典：第37回 介護福祉士国家試験（認知症の理解）

正解を見る

正解：3　歯を失いかめなくなると脳への刺激が減りリスクが上がります。難聴は危険因子ですが、補聴器の使用はリスクを下げる側です。

第34回：認知症の理解

認知症（dementia）の行動・心理症状（BPSD）に対する抗精神病薬を用いた薬物療法でよくみられる副作用として、最も適切なものを1つ選びなさい。

  1. 歩幅が広くなる。
  2. 誤嚥（ごえん）のリスクが高くなる。
  3. 過剰に活動的になる。
  4. 筋肉の緊張が緩む。
  5. 怒りっぽくなる。

出典：第34回 介護福祉士国家試験（認知症の理解）

正解を見る

正解：2　抗精神病薬は飲み込みが悪くなり誤嚥、小刻み歩行・筋肉のこわばり・眠気などのパーキンソン症状が出ることがあります。
