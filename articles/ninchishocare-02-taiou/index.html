  1. 「私を疑っているんですか」
  2. 「置いた場所を忘れたんですか」
  3. 「心配ですね、一緒に探しませんか」
  4. 「ご飯を食べてから探してはどうですか」
  5. 「ロッカーの上にあるのが見えないんですか」

正解を見る

第34回：認知症の理解

夫から相談を受けた介護福祉職の助言として、最も適切なものを1つ選びなさい。

  1. 「主治医に興奮を抑える薬の相談をしてみてはどうですか」
  2. 「施設入所を検討してはどうですか」
  3. 「Cさんと一緒に探してみてはどうですか」
  4. 「Cさんの希望通り、警察に通報してはどうですか」
  5. 「Cさんに認知症（dementia）であることを説明してはどうですか」

出典：第34回 介護福祉士国家試験（認知症の理解）

正解を見る

正解：3　もの盗られ妄想は否定せず、一緒に探す。本人が見つけられるようさりげなく誘導します。1の薬や2の施設入所は、まず関わり方を見直す前に選ぶものではありません。4の通報は、実際には盗まれていないので適切ではなく、5の病気の説明は本人の不安を強めます。

② 認知症の人に配慮した環境

認知症の人に影響する環境は、次の3つです。

  1. 音・光・物などの物理的な環境
  2. 介護職の関わり方や職場の体制（人的環境）
  3. ほかの利用者との交流
  • 無視される・職員ごとに対応がちがう、は大きなストレスになります。受け入れる態度で、一貫した関わりにします
  • 目印は本人の目の高さに、大きくわかりやすく置きます
  • 居室の変更や入所など、環境の急な変化で混乱することをトランスファーショック（リロケーションダメージ）と呼びます。居室の変更が「家に帰らなければ」という訴えにつながることもあります
○×
部屋やトイレに表示や目印表示を壁と同系色にする
廊下の手すりに色をつけて目立たせる細かい模様の壁紙で統一
使い慣れた道具・なじみの家具や私物を見える所に。施設に入るときは使い慣れた家具を持ち込み、リロケーションダメージ（環境が急に変わることによる混乱）を和らげる新しい便利な道具に変える／家具の配置を毎月変える／私物は見えない所へ
いつも安心感をもってもらえるように接する毎日新しい体験／日中は1人で過ごす
落ち着ける明るさ・音量光の刺激を強く・BGMを大きく
家事などに参加する機会をつくり役割を見つける何もさせずに常に見守る
夫の位牌など本人の大切な物は本人のそばに夫の位牌を息子に預ける（大切な物を本人から離す）
食事は雰囲気も大切に栄養摂取を雰囲気より優先

第38回：認知症の理解

認知症（dementia）の人への環境の配慮に関する次の記述のうち、最も適切なものを1つ選びなさい。

  1. 視覚的認識を容易にするために、廊下の手すりに色をつけて目立つようにする。
  2. 聴覚に影響を与えるために、ピクトグラム（pictogram）を表示する。
  3. 音の選択的聴取の力を高めるために、BGM（background music）の音量を大きくする。
  4. 穏やかに生活するために、居室の光の刺激を強くする。
  5. 落ち着く空間をつくるために、居室を細かい模様の壁紙で統一する。

正解を見る

正解：1　手すり・トイレの扉などは目立つ色に。ピクトグラムは視覚の手がかり、大きな音・強い光・細かい模様は混乱の原因になります。

第34回：認知症の理解

認知症（dementia）の人に配慮した施設の生活環境として、最も適切なものを1つ選びなさい。

  1. いつも安心感をもってもらえるように接する。
  2. 私物は本人の見えないところに片付ける。
  3. 毎日新しい生活体験をしてもらう。
  4. 壁の色と同系色の表示を使用する。
  5. 日中は1人で過ごしてもらう。

出典：第34回 介護福祉士国家試験（認知症の理解）

正解を見る

正解：1　職員の関わりも人的環境。なじみの私物を置き、変化は少なく、表示は目立つ色にします。

③ 行動の背景を探る・見当識の手がかり

  • 入浴を拒むときは、怖さ・遠慮・体調・持ち物の心配など理由を確かめ、「心配事があったんですね。どうしたら安心して入れるか一緒に考えましょう」と本人と一緒に方法を考える。説得・命令・根拠のない「大丈夫」は避ける。
  • 「徘徊」「帰宅願望」は試験や現場で使われる言葉ですが、歩き回る・家に帰りたいと訴える・物を集めるなどの行動には、本人なりの目的や理由があることが多い（不安・役割を果たしたい・トイレを探している など）。ひもときシートなどで背景を整理する。
  • 夕方に落ち着かなくなる夕暮れ症候群には、無理に止めず一緒に歩く・お茶に誘うなど気持ちに寄り添う（症状の説明は → 認知症の中核症状・BPSD・せん妄）。
  • 家族と同居を始めるなど環境が変わるときは、なじみの物を置き、生活習慣を続けられるようにする。照明は光源が直接目に入らない間接照明などがよい。
  • 見当識は「時間→場所→人」の順に失われやすい。カレンダー・時計・名札で手がかりを増やす。
  • 夜中に「会社に行かないと怒られる」と興奮する人には、「休みです」「怒られません」と打ち消すより、本人の世界に合わせて仕事をしていたころの話を聴くと安心につながる（回想の手法を日常の会話で使う）。その日に痛み（帯状疱疹など）があれば、それも落ち着かない原因になる。
  • 急に服を脱ぐときは、暑さ・かゆみ・排泄したい感じなど理由があることが多い。止める・説得する・「恥ずかしい」と言う、はせず、安全とプライバシーを守りながら落ち着くまでそばで見守り、理由を探る（何もしない「無視」とはちがう）。
