  • 更衣と衣服・靴の選び方 4問

この記事のポイント

  1. 着脱の原則は「脱健着患」：脱ぐときは健側から、着るときは患側から。
  2. 認知症・失行の人には、代わりに着せない。印をつける・動作を見せる・順番に声をかける。
  3. 靴は「かかとがある・足の甲を覆う・つま先に0.5〜1cmの余裕」。

① 片麻痺の人の着脱

脱健着患（だっけんちゃっかん）

順番理由
脱ぐとき健側から脱ぐ → 最後に患側健側が自由になり、患側を無理に曲げずに済む
着るとき患側から着る → 最後に健側動かしにくい患側に先に通しておく

前あきの上着（右片麻痺の場合）

  • 着るとき：右袖を肩までしっかり通してから、左袖を通す
  • 脱ぐとき：左（健側）の肩を下げて、左袖から腕を抜く

拘縮がある腕に袖を通すとき

  • 肘や手首は下から支える（上からつかむ・指先に力を入れるは×）
  • 関節はゆっくり動かす

片麻痺の人が自分で着脱しやすいのは、意外にもかぶり式のセーター。小さいボタン・ひも・伸縮性のないズボンは×です。

✏️ 過去問を解いてみよう（2問）
第38回：生活支援技術

右片麻痺の利用者が前開きの上着を着脱するときの説明として、最も適切なものはどれ？

  1. 「脱ぐときは左肩を下げてから、右袖から腕を抜きましょう」
  2. 「脱ぐときは右肩を下げてから、右袖から腕を抜きましょう」
  3. 「襟元を手前にして太ももの上に置きましょう」
  4. 「着るときは右袖を肘まで通してから左袖を通しましょう」
  5. 「着るときは右袖を肩まで通してから左袖を通しましょう」
正解を見る

正解：5　脱健着患：着るときは麻痺側（右）を肩までしっかり通してから健側へ。脱ぐときは健側（左）からです。

第34回：生活支援技術

右片麻痺で右腕が曲がったままかたまっている（屈曲拘縮）Mさんが、最近左肩にも痛みが出て上着の着脱に介護が必要になった。介護として最も適切なものはどれ？

  1. 脱ぐときは右腕から脱ぐ
  2. 右手首に袖を通すとき、指先に力を入れて手首をつかむ
  3. 右肘を伸ばすときはすばやく動かす
  4. 右肘に袖を通すときは前腕を下から支える
  5. かぶり式の服を選ぶ
正解を見る

正解：4　拘縮のある腕は下から支えて、ゆっくり動かします。つかむと痛みの原因に。服は前開き、脱ぐのは健側（左）から。

  • 衣服は本人が選ぶ（気候に合わせて支援者が選ぶは×）

✏️ 過去問を解いてみよう（第38回：生活支援技術）

身じたくの目的のうち、ICFの「心身機能・身体構造」の観点として最も適切なものはどれ？

  1. 体温を調節する
  2. 体を清潔に保つ
  3. セルフケアを行う
  4. 自分を表現する
  5. 周囲との人間関係を調整する
正解を見る

正解：1　体温調節＝体の機能にかかわる観点。セルフケアは「活動」、自己表現や人間関係は「参加」にあたります。

③ 衣服と靴の選び方

保温

  • 衣類の間に薄手の衣類を重ねて着る（空気の層ができる、第30回）
  • きつい服・袖幅の大きい服は熱が逃げる

転びにくい靴

○×
足背（足の甲）をしっかり覆うかかとのない脱ぎやすい靴（スリッパ）
つま先に0.5〜1cmの余裕ぴったり・指が固定される
つま先が少し上がっているつま先が床に近い
軽い・靴底に適度な厚みと溝重い・底が薄く硬い・溝が浅い

靴下の滑り止めは、すり足の高齢者では引っかかってつまずく原因になることがあり、第36回では×でした。

高齢者が靴下・靴を選ぶときの対応として、最も適切なものはどれ？

  1. 靴下は指つきのきついものを勧める
  2. 靴下は足の裏に滑り止めがあるものを勧める
  3. 靴はつま先の高さが低いものを勧める
  4. 靴はかかとのない脱ぎやすいものを勧める
  5. 靴はつま先に0.5〜1cmの余裕があるものを勧める
正解を見る

正解：5　靴はつま先に0.5〜1cmの余裕、つま先が少し上がったもの、かかとを包むものを。靴下の滑り止めは靴の中で滑らず、引っかかりやすいので注意。

④ 着替えの手順と衣服の素材

  • 衣服の役割：保温・皮膚の保護・身だしなみ・自己表現、そして体のまわりに快適な衣服気候（衣服の中の温度・湿度）をつくること。肌着は吸湿性・通気性のよいものを。
  • 衣服は介護のしやすさより、本人の好みと着やすさを優先して選ぶ。
  • 認知症の人に着替えを伝えるときは、わかりやすい言葉で、ひとつずつ簡潔に。
  • 着替えは「脱健着患」。ズボンも患側の足から通す。拘縮がある場合は、着替えの前に関節をゆっくり動かしておく。
  • 左片麻痺の人を寝たまま着替えるとき：介助者は健側（右）に立ち、新しい上着は患側（左）に置いておく。
  • 衣服の素材：綿（吸湿性・洗濯に強い／しわになりやすい）、毛・絹（虫やアルカリに弱い）、ポリエステル（しわになりにくく乾きやすい／吸湿性が低く静電気）、アクリル（毛玉）、ナイロン（熱に弱い）。化学繊維は火に弱い。
  • 昼と夜で着替え、生活のリズムをつくる。
