この記事のポイント

  1. 中核症状＝脳の障害で誰にでも起こる（記憶・見当識・判断・失語・失行・失認・遂行機能）。BPSD（行動・心理症状）＝体調・環境・ケアが重なって起こり、起こる人と起こらない人がいる（歩き回る〈徘徊〉・昼夜逆転・妄想・興奮）。
  2. 迷ったら「脳の障害そのもので、覚える・わかる・段取りする力が落ちたか（中核症状）」「そこに体調・環境・関わりが重なって出た行動や気持ちの変化か（BPSD）」で見分ける。「〜できない・わからない」は中核症状、「歩き回る・眠れない・興奮する」はBPSDのことが多い（目安）。
  3. せん妄＝急に起こり、意識が濁り、1日の中で変動し、夜に多い。原因（薬・発熱・脱水）を探すのが大事。

認知症とは

認知症は病名ではなく、状態の名前です。いったん発達した記憶・判断などの認知機能が、脳の病気によって後から低下し、日常生活や社会生活に支障が出ている状態をいいます。認知症基本法でも、アルツハイマー病などの神経変性疾患や脳血管疾患などによって、日常生活に支障が出るほど認知機能が低下した状態と定めています。

  • 生活に支障が出ていなければ MCI（軽度認知障害）、意識障害があれば せん妄（→ ③）を考えます

① 中核症状

症状意味試験に出た具体例
記憶障害新しいことを覚えられない。初期は近時記憶（数分〜数日前のこと）・エピソード記憶（体験した出来事）10分前の挨拶を覚えていない。食べたことを忘れてご飯をほしがる
見当識障害時間 → 場所 → 人の順にわからなくなる「今いるところはどこですか」と確認する。目の前の夫と自分の関係がわからず「夫が帰ってくるのでお帰りください」と言う（人の見当識障害。顔が見分けられないのではなく、相手と自分の関係がわからない）
失語口や舌の動き・耳の聞こえは正常なのに、話す・聞いて理解する・読み書きなど、言葉の働きが損なわれる。軽度から出ることがある物の名前が出てこない
失行体は動くのに、目的に沿った動作ができない。着衣失行（服の着方がわからない）・構成失行（図形が写せない）・観念失行（道具の使い方がわからない）・観念運動失行（ふだん自然にできる動作が、言われたり、まねをしたりするとできない）洋服をうまく着られない、包丁の使い方がわからない
失認目や耳は正常なのに、何かを認識できない。相貌失認・視空間失認など相貌失認＝顔を見ても誰かわからない（声を聞くとわかる）、皿の模様をおかずと間違える、鏡に映った自分がわからない
視空間認知障害物の位置・距離・形をとらえられない椅子にうまく座れない、図形を写せない
半側空間無視片側（多くは左側）にあるものに気づかない。脳卒中の後遺症で多い配膳された食事の左側を残す
遂行（実行）機能障害計画を立てて段取りをすることができない調理の手順を順序立てて行えない
注意障害注意を保てない・切り替えられない物音が聞こえると食事を中断したままになる
判断力の低下状況に合った判断ができない中核症状の代表
病識の低下自分が病気だという自覚が乏しい「どこも悪くない」と受診を嫌がる
  • 長年の裁縫が短時間でできた → 体で覚えた手続き記憶は残りやすい
  • 記憶は「覚える（記銘）→ とどめる（保持）→ 思い出す（想起）」。認知症では記銘が最初に崩れ、新しい出来事が入りません。進むと昔の記憶も失われ、最後は自分の年齢や名前もわからなくなります
  • 言葉で説明できる記憶（陳述記憶＝エピソード記憶・意味記憶）のうち、エピソード記憶が最初に崩れます。作業記憶＝覚えながら処理する力、展望的記憶＝これからする予定の記憶で、どちらも低下しやすい（くわしくは → マズローの欲求・適応機制・記憶のしくみ）
  • 構音障害は失語とは別で、言葉はわかっているのに口や舌がうまく動かず、発音がはっきりしない状態（→ 失語症・構音障害の人とのコミュニケーション）
  • 試験では、「認知症の症状として通常見られないもの」＝運動失調（手足の動きがうまく協調しない）が正解として出た。運動失調は認知機能の障害（中核症状）ではない。レビー小体型のパーキンソン症状や血管性の麻痺は、原因疾患による神経症状として別に考える

失行と遂行機能障害の見分け

  • 遂行機能障害＝いくつもの工程を計画して段取りする力の障害（調理、お茶を入れる手順、旅行の計画）
  • 事例の見分け方：「1つの道具・1つの動作ができない」なら失行、「手順・計画・段取りが崩れる」なら遂行機能障害
  • 自分がうまくできないことを「ポットが壊れている」と説明するのは、手順がわからなくなった結果と考えます

加齢による物忘れとの違い

加齢の物忘れ認知症の物忘れ
体験の一部を忘れる（夕食の献立）体験全体を忘れる（夕食を食べたこと）
忘れた自覚がある自覚がない
進行しない・生活に支障なし進行する・生活に支障がある

② BPSD（行動・心理症状）と妄想の種類

BPSDは、中核症状に体調・環境・関わり方が重なって起こる症状で、原因を整えると軽くなることがあります。

○ BPSDの例× BPSDではない（中核症状）
徘徊（歩き回る。本人には目的や理由があることが多い）・出口を探して歩き回る親しい人がわからない
昼夜逆転・十分に眠れない言葉を口に出せない／トイレの水を流せない
興奮・暴言・妄想・幻覚・抑うつ・不安計算ができない／計画を立てられない
異食（食べ物でないものを口に入れる）食べたことを忘れる（記憶障害）
夕暮れ症候群（夕方になると落ち着かず「家に帰る」と言う）日付がわからない（見当識障害）

「できない・わからない＝中核症状／歩き回る・眠れない・興奮する＝BPSD」は目安です。迷ったら「脳の障害そのものか（中核症状）、体調・環境・関わりで起こるか（BPSD）」で判断します。たとえば「食べたことを忘れてご飯をほしがる」は記憶障害（中核症状）です。

よく出るポイント

  • 興奮はケアの方法によって起こることがある。徘徊は誰にでも起こるわけではない
  • もの盗られ妄想は記憶障害と関係がある（しまい忘れ → 盗まれた）
  • 感情失禁＝感情を抑えられず、ささいなことで泣いたり笑ったりする。理由もなく急に泣き出し、すぐ笑顔に戻る
  • アパシー（意欲低下）＝感情の起伏がみられない・無関心。「将来に希望がない」「自分を責める」はうつの症状
  • 自分の考えや要求を言葉で伝えられないことがあるので、顔色や表情もよく観察する

BPSDの2つの分け方

分け方例
行動症状歩き回る・興奮・暴言や暴力・ケアへの抵抗・異食・物を集める（収集癖）・便をさわるなどの不潔行為・昼夜逆転・大声
心理症状不安・抑うつ・無気力（アパシー）・何もしない（無為）・幻覚・妄想・不眠・こだわり（強迫症状）
  • 失禁は、尿意はあってもトイレの場所や使い方がわからず、間に合わないことから始まることがあります。排泄の誘導やトイレの目印で減らせます（→ 認知症の人への場面別の対応と環境づくり）

見間違い・幻覚・取り違え・妄想の区別

用語意味例
錯覚そこにある物を、別の物と見間違える傘立ての傘を人だと思う
幻覚そこにない物が見える（幻視）・聞こえる（幻聴）誰もいない窓のそばに人が見える
誤認人や場所を取り違える妻を自分の母親だと思う
妄想ありえないことを強く信じ、説明されても訂正できない盗まれた・浮気している・食事に毒が入っている

→ 「見間違い」なら錯覚、「ないものが見える」なら幻覚、「確信して直らない」なら妄想、と判断します。

妄想の種類

名前中身
もの盗られ妄想自分でしまい忘れた物を「誰かに盗まれた」
嫉妬妄想夫が外出すると「外で女性に会っている」と興奮する
カプグラ症候群家族など身近な人がよく似た偽物と入れ替わっている
幻の同居人家の中に知らない人が住んでいると思う
心気妄想病気がないのに自分は病気だと思い込む

認知症（dementia）の高齢者にみられる、せん妄に関する記述として、適切なものを1つ選びなさい。

  1. 覚醒レベルが重度に低下した状態である。
  2. 症状の変動が少ないことが特徴である。
  3. 夜間よりも日中に生じやすいことが特徴である。
  4. 認知機能障害がみられることはまれである。
  5. 関与する因子を特定することが重要である。

出典：第37回 介護福祉士国家試験（認知症の理解）

正解を見る

正解：5　せん妄は脱水・感染・薬・環境の変化などが引き金。原因を見つけて取り除くことが大切です。意識障害は軽いもので、「重度に下がった状態」ではありません。症状は変動が大きく夜間に多いので2・3は×、注意や見当識などの認知機能障害もみられるので4も×。

第36回：認知症の理解

認知症（dementia）の人にみられる、せん妄に関する次の記述のうち、最も適切なものを1つ選びなさい。

  1. ゆっくりと発症する。
  2. 意識は清明である。
  3. 注意機能は保たれる。
  4. 体調の変化が誘因になる。
  5. 日中に多くみられる。

出典：第36回 介護福祉士国家試験（認知症の理解）

正解を見る

正解：4　せん妄は急に起こり、軽い意識障害があり、夜間に多く、一日の中で変動します。
