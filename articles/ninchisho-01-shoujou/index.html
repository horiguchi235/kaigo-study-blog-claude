認知症の理解10問

この記事の論点と出題数（過去5年）

  • 中核症状（記憶・見当識・失行・失認・遂行機能・注意障害） 4問
  • BPSD（行動・心理症状）と妄想の種類 4問
  • せん妄 2問

この記事のポイント

  1. 中核症状＝脳の障害で誰にでも起こる（記憶・見当識・判断・失行・失認・遂行機能）。BPSD＝環境やケアで起こる人と起こらない人がいる（徘徊・昼夜逆転・妄想・興奮）。
  2. 「〜ができない」は中核症状、「〜してしまう・眠れない」はBPSD、と読むと選択肢を見分けやすい。
  3. せん妄＝急に起こり、意識が濁り、1日の中で変動し、夜に多い。原因（薬・発熱・脱水）を探すのが大事。

① 中核症状

症状意味試験に出た具体例
記憶障害新しいことを覚えられない。初期は近時記憶・エピソード記憶10分前の挨拶を覚えていない
見当識障害時間 → 場所 → 人の順にわからなくなる「今いるところはどこですか」と確認する。夫に「夫が帰ってくるのでお帰りください」
失行体は動くのに、目的に沿った動作ができない洋服をうまく着られない、包丁の使い方がわからない
失認目や耳は正常なのに、何かを認識できない相貌失認＝目の前の家族がわからない、皿の模様をおかずと間違える
遂行（実行）機能障害計画を立てて段取りをすることができない調理の手順を順序立てて行えない
注意障害注意を保てない・切り替えられない物音が聞こえると食事を中断したままになる
判断力の低下状況に合った判断ができない中核症状の代表
  • 長年の裁縫が短時間でできた → 体で覚えた手続き記憶は残りやすい
  • 認知症の症状として通常見られないもの＝運動失調

加齢による物忘れとの違い

加齢の物忘れ認知症の物忘れ
体験の一部を忘れる（夕食の献立）体験全体を忘れる（夕食を食べたこと）
忘れた自覚がある自覚がない
進行しない・生活に支障なし進行する・生活に支障がある

第38回：認知症の理解

認知症の人の遂行機能障害の症状として、最も適切なものはどれ？

  1. 食べたことを忘れてご飯をほしがる
  2. 包丁の使い方を忘れてうまく使えない
  3. 配膳された食事の左側を残す
  4. 調理の手順を順序立てて行えない
  5. 皿の模様をおかずと間違えてすくおうとする
正解を見る

正解：4　計画を立てて順序よく実行できない＝遂行機能障害。1は記憶障害、2は失行、3は半側空間無視、5は失認です。

第36回：認知症の理解

認知機能障害による生活への影響として、最も適切なものはどれ？

  1. 遂行機能障害で自宅がわからない
  2. 記憶障害で出された食事を食べない
  3. 相貌失認で目の前の家族がわからない
  4. 視空間認知障害で今日の日付がわからない
  5. 病識の低下でうつ状態になりやすい
正解を見る

正解：3　相貌失認＝顔を見ても誰かわからない。自宅や日付がわからないのは見当識障害です。

第35回：認知症の理解

見当識障害を確かめる質問として、最も適切なものはどれ？

  1. 「今いるところはどこですか」
  2. 「100から7を順に引いてください」
  3. 「さっき覚えた言葉をもう一度言ってください」
  4. 「この図形を写してください」
  5. 「この紙を左手で取り、半分に折って返してください」
正解を見る

正解：1　見当識＝時間・場所・人がわかる力。2は計算・注意、3は記憶、4は視空間、5は理解・実行の検査です。

第35回：認知症の理解

アルツハイマー型認知症のMさん（88歳）は、日中寝てしまい夜眠れない。長年していた裁縫を勧めると、短時間で雑巾を縫えた。Mさんの裁縫についての記憶はどれ？

  1. 作業記憶
  2. 展望的記憶
  3. 短期記憶
  4. 陳述記憶
  5. 手続き記憶
正解を見る

正解：5　体で覚えた技能は手続き記憶で、認知症になっても残りやすい。生活に生かせる力です。

② BPSD（行動・心理症状）と妄想の種類

○ BPSDの例× BPSDではない（中核症状）
徘徊・出口を探して歩き回る親しい人がわからない
昼夜逆転・十分に眠れない言葉を口に出せない／トイレの水を流せない
興奮・暴言・妄想・幻覚・抑うつ計算ができない／計画を立てられない

よく出るポイント

  • 興奮はケアの方法によって起こることがある。徘徊は誰にでも起こるわけではない
  • もの盗られ妄想は記憶障害と関係がある（しまい忘れ → 盗まれた）
  • 感情失禁＝感情を抑えられず、ささいなことで泣いたり笑ったりする。理由もなく急に泣き出し、すぐ笑顔に戻る
  • アパシー（意欲低下）＝感情の起伏がみられない・無関心。「将来に希望がない」「自分を責める」はうつの症状

④ 中核症状の具体例・MCI・せん妄のきっかけ

  • 中核症状＝記憶障害・見当識障害・判断力の低下・実行（遂行）機能障害・失語・失行・失認／BPSD（周辺症状）＝不安・抑うつ・妄想・幻覚・徘徊・興奮・異食（食べ物でないものを口に入れる）・昼夜逆転など。BPSDは体の不調・環境・関わり方で軽くなる。
  • 物忘れや日付の間違いがあり、夜に一人で廊下を歩き回る＝徘徊（BPSD）。
  • 認知症と間違えやすい病気＝うつ病（意欲・注意・記憶が落ちる）。
  • せん妄＝急に起こる注意・意識の障害で、症状が変動。脳血管障害・感染・脱水・薬・環境の変化が誘因。変化は医療職に報告し、チームで原因を考える。
  • 自分の考えや要求を言葉で伝えられないことがあるので、顔色や表情もよく観察する。
  • 高次脳機能障害の支援：記憶障害＝メモや手がかりで補う（何も手がかりを与えずに待つのは×）／注意障害＝刺激を減らし1つずつ／遂行機能障害＝手順を具体的に示す。
  • 認知症高齢者の推計（2024年公表）：2025年に約472万人、2040年に約584万人（高齢者の約15％）。同じ調査で軽度認知障害（MCI）は2025年に約564万人。原因はアルツハイマー型が約7割、血管性が約2割。
  • 軽度認知障害（MCI）＝年齢相応以上のもの忘れはあるが、日常生活は自立。認知症に移行しやすいので早期の対応が大切。
  • 失行の例：着衣失行（服の着方がわからない）、構成失行（図形が写せない）、観念失行（道具の使い方がわからない）。失認の例：相貌失認（顔がわからない）、視空間失認、鏡に映った自分がわからない。
  • せん妄のきっかけ＝発熱・脱水・感染・薬（睡眠薬など）・環境の変化。急に起こり、夜に悪化（夜間せん妄）。原因を取り除くと改善する。
  • 夕暮れ症候群＝夕方になると落ち着かなくなり「家に帰る」と言う。
