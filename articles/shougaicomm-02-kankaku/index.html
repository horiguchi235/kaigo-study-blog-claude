この記事のポイント

  1. 中途失聴者＝筆談（手話は習得が難しい）。筆談はキーワードで短く。
  2. 老人性難聴は高音域から。正面で向き合い、口元を見てもらい、大声は逆効果。補聴器は聞こえる側の耳に。
  3. 視覚障害者には聴覚・触覚・嗅覚を活用し、見えている情報を整理して言葉で。盲ろう者には触手話。

箱型補聴器のイヤホンは比較的聞こえる側の耳に装着。マイク（本体）に向かって話す。

周囲の人への協力依頼

会話についていけず下を向いてしまう難聴の人のため、同じテーブルの人に → 「話す相手の名前を呼んでから話しかけてほしい」（誰に話しているかがわかる）

✏️ 過去問を解いてみよう（第35回：コミュニケーション技術）

老人性難聴のCさんは、両耳に補聴器をつけ、静かな場所ならなんとか聞き取れる。1対1で話す方法として、最も適切なものはどれ？

  1. 正面で向き合って話す
  2. 高い声で話す
  3. 耳元でできるだけ大きな声で話す
  4. 手話で会話する
  5. 体に触れてから話す
正解を見る

正解：1　正面から、口元と表情が見えるように、低めの声でゆっくり話します。補聴器使用中の大声はかえって聞き取りにくくなります。

第38回：コミュニケーション技術

中途失明のAさんは、食堂の席替えのあと、同じテーブルの利用者同士の会話を自分への話しかけと思って答えたが、反応がなく下を向いてしまった。職員が同じテーブルの利用者に頼んだ内容として最も適切なものはどれ？

  1. 疲れているので部屋で休むよう伝えて
  2. 不安なのでそっと手を握って
  3. Aさんにもわかるよう、相手の名前を呼んでから話しかけて
  4. 混乱するので会話は控えて
  5. 予定がわからないので食事だと教えて
正解を見る

正解：3　見えない人には誰に話しかけているかがわかりません。名前を呼んでから話すことで会話に参加できます。

第37回：障害の理解

視覚障害の特徴と生活支援について、最も適切なものはどれ？

  1. ロービジョンは視覚情報がまったく得られない状態
  2. 中途の視覚障害は先天性より受容しやすい
  3. 白杖には視覚障害があることを周囲に知らせる役目がある
  4. ペットの犬と一緒に外出して補う
  5. ガイドヘルパーは利用できない
正解を見る

正解：3　白杖は安全確認・周囲への周知・情報収集の役目。ロービジョンは見えにくい（弱視）状態、中途障害は受容が難しいことが多く、同行援護が使えます。

網膜色素変性症で夜盲があるGさんが、夕方うす暗い廊下を歩いていた。名乗って声をかけると「びっくりした。見えにくくてわからなかった…」と暗い表情。受容的な対応として最も適切なものはどれ？

第34回：コミュニケーション技術

先天性の全盲で、入居したばかりのJさんが「なかなか場所を覚えられない。ここでやっていけるでしょうか」と不安を話した。不安を軽くする対応として最も適切なものはどれ？

  1. 驚かないよう肩にふれてからあいさつする
  2. 誘導中の声かけは最小限にする
  3. 角を曲がるときは「こちらに」と方向を伝える
  4. トイレや食堂などを一緒に歩きながら確かめる
  5. 食堂の席は好きなところに座るよう伝える
正解を見る

正解：4　実際に一緒に歩いて場所を覚えてもらうのが安心につながります。声かけは先に名乗る、方向は「右へ」など具体的に伝えます。

③ 難聴の種類と聴覚・視覚障害の補助手段

  • 麻痺による構音障害の人は文字の理解が保たれていれば五十音表（文字盤）が使える。失語症の人は文字盤より絵や実物が伝わりやすい。
  • 中途失聴の人は手話を習得していないことが多いので、筆談・要約筆記などを使う。
  • 白内障の人は強い日差しのなかでまぶしく見えにくい（光が散乱する）。照明や文字の大きさを本人の見え方に合わせる。
  • 伝音性難聴（外耳・中耳の障害）は補聴器が効きやすい、感音性難聴（内耳より奥）は音を大きくしても聞き分けにくい（加齢性難聴の多く）。
  • 聴覚障害者のコミュニケーション手段：手話・指文字（固有名詞に）・読話（口の動きを読む）・筆談（中途失聴者に有効）・空書（空中に文字を書く）・音声認識アプリ。中途失聴者は手話の習得に時間がかかる。
  • ロービジョン（弱視）の補助具：拡大鏡・拡大読書器・弱視眼鏡・スマートフォンの音声読み上げ。
  • 視野のめやす：耳側約100度、鼻側・上方約60度、下方約70度。
