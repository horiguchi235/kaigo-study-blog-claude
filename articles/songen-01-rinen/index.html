① 福祉の理念と人物

人物とキーワード

人物キーワード
バンク-ミケルセン（デンマーク）ノーマライゼーションの父（1959年法）
ニィリエ（スウェーデン）ノーマライゼーションの8つの原理
ヴォルフェンスベルガー（アメリカ）ソーシャルロール・バロリゼーション（価値ある社会的役割の獲得）

糸賀一雄「この子らを世の光に」・発達保障
フランクル『夜と霧』・態度価値（命が制限された状況でどんな態度をとるか）
メイヤロフ『ケアの本質』（ケアとは相手の成長・自己実現をたすけること）
リッチモンド『ソーシャル・ケース・ワークとは何か』（ケースワークの母）
キットウッドパーソン・センタード・ケア（認知症ケア）

入れ替えのひっかけが定番です。「ケースワークの7原則」はリッチモンドではなくバイステック、「エーデル改革」は人物の提唱ではなくスウェーデンの高齢者ケア改革です。

理念の違い

理念ひとことで正解になる例
ノーマライゼーション障害があっても普通の生活環境に近づける施設から地域生活への移行、バリアフリー新法、障害者基本計画の理念
ソーシャルインクルージョンすべての人を社会の一員として包み込み、共に支え合う「障害のある人もない人も包摂する社会」
自立生活運動（IL運動）障害者自身の選択による自己決定の尊重介助を受けながらでも地域で自立して暮らす

よく出る不正解：大規模入所施設の整備（ノーマライゼーションと逆）／障害の完治を目指す／機能回復＝自立／「統合」（インクルージョンは「包摂」）

第38回：障害の理解

障害福祉でいう「ソーシャルインクルージョン」の説明として、最も適切なものはどれ？

  1. 障害のある人とない人を統合する社会
  2. 障害のある人を権利侵害から守る社会
  3. 障害のある人の意思決定を支える社会
  4. 障害のある人の最善の利益を考える社会
  5. 障害のある人もない人も包み込む（包摂する）社会
正解を見る

正解：5　ソーシャルインクルージョン＝だれも排除せず、社会の一員として包み込む考え方。1の「統合」はその前段階のインテグレーションです。

第38回：人間の尊厳と自立

社会福祉の理念を広めた人物とその主張の組み合わせとして、適切なものはどれ？

  1. バンク-ミケルセンは「ソーシャルロール・バロリゼーション」を唱えた
  2. ニィリエは「ノーマライゼーションの8つの原理」を唱えた
  3. ヴォルフェンスベルガーは「エーデル改革」を唱えた
  4. リッチモンドは「ケースワークの7原則」を唱えた
  5. エリクソンは「自立生活運動の理念」を唱えた
正解を見る

正解：2　ニィリエ＝8つの原理。ソーシャルロール・バロリゼーションはヴォルフェンスベルガー、ケースワークの7原則はバイステック、エーデル改革はスウェーデンの高齢者ケア改革です。

第34回：人間の尊厳と自立

『ケアの本質』で「人をケアするとは、その人が成長し自己実現するのを助けることである」と述べた人物はだれ？

  1. 神谷美恵子
  2. 糸賀一雄
  3. ナイチンゲール
  4. メイヤロフ
  5. ニィリエ
正解を見る

正解：4　メイヤロフ『ケアの本質』。神谷美恵子は『生きがいについて』、糸賀一雄は「この子らを世の光に」です。

② 自立・自立支援・自己決定・QOL

「自立」の意味

種類正しい説明
精神的自立生活の目標をもち、自らが主体となって物事を進めること
身体的自立自分の身体を使って日常生活を送ること
社会的自立社会の中で役割をもち、参加すること
経済的自立自分の収入や資産で生活を営むこと
  • 自立支援＝自己選択・自己決定を支援すること
  • 介護を受けていても、社会参加できるように支援すること

  2. 精神的自立とは、生活の目標をもち、自分が主体となって物事を進めることである
  3. 社会的自立とは、社会的な役割から離れて自由になることである
  4. 身体的自立とは、介護者の身体的な負担を減らすことである

③ 自立と自律・QOL・エンパワメント

  • 尊厳＝すべての人がもつかけがえのない価値。年齢や障害で変わらない。人はいつも正しい判断ができるわけではなく、判断能力は状態や場面で変わるので支援する。
  • カタカナ用語：アドボカシー＝権利擁護（代弁）／ラポール＝信頼関係／アカウンタビリティ＝説明責任／QOL＝生活の質（バリアフリーの街づくりもQOL向上に役立つ）。
  • ノーマライゼーション＝障害があっても普通の生活条件を保障する考え方。本人を「普通」に近づけるのではなく、生活環境を整える。バンク-ミケルセン（デンマーク）が推進、ニィリエが8つの原理に整理、ヴォルフェンスベルガーは「社会的役割の価値づけ（SRV）」に発展させた。
  • 自立支援は、本人が誇りと責任をもって生活できることを目指す。役割をもつことや動機づけの積み重ねは生活意欲を高める。障害のある人と共に生き、自立を支える姿勢が大切。
  • 「自立」と「自律」の違い：自立＝必要なサービスも使いながら、自分の意思と責任で暮らしを営むこと。自律＝自分で決めたルールに従って自分を律すること（自立の前提になる心の働き）。「援助を受けたら自立ではない」は×。
  • ソーシャル・インクルージョン（社会的包摂）＝誰も排除せず、地域社会の一員として包み込むこと。反対語はソーシャル・エクスクルージョン（社会的排除）。
  • QOLは「生活の質」だけでなく「人生の質」「生命の質」も含む。介護の目標はADL中心からQOL重視へ移ってきた。
  • エンパワメント・アプローチは、アメリカのソロモンが提唱（1976年）。本人が本来もっている力を引き出し、自分で状況を変えていけるよう支える考え方。
