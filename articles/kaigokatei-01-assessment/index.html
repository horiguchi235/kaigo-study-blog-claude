① 介護過程の目的

介護過程とは、介護の目標を実現するための、客観的で科学的な思考と実践の過程です（第26回の正解の言い回し）。「アセスメント → 計画 → 実施 → 評価」をくり返す、根拠のある個別ケアのための考え方で、中心にあるのは、いつも「利用者の望む生活」です。

介護過程の意義（展開すると何ができるか）は4つ

  1. 根拠に基づく介護ができる
  2. 一人ひとりに合った介護ができる
  3. 利用者の自己実現をめざせる
  4. 介護の専門性が高まる

「利用者の望むことをすべて取り入れる」は意義ではありません（要望とニーズは違う → 生活課題・目標・介護計画の立て方）。

背景にある8つの視点：ICFで利用者を全体からとらえる／尊厳を守る／個別ケア／生活と人生の継続性／自立支援／生きがいと役割／多職種での情報共有／根拠と記録。

介護支援専門員（介護保険）や相談支援専門員（障害福祉）がケアマネジメントで決めた方針の中で、介護福祉職が行うのが介護過程です（→ 生活課題・目標・介護計画の立て方 の「ケアプランとの関係」）。

アセスメント（情報収集 → 解釈・関連づけ → 生活課題の明確化）
      ↓
介護計画の立案（目標 → 支援内容）　… 介護過程②
      ↓
実施　… 介護過程③
      ↓
評価　… 介護過程③ →（必要なら再アセスメントへ戻り、くり返す）

② アセスメントと情報収集の原則

アセスメントとは、情報を集め、解釈し、関連づけて、生活課題を明らかにすることです。

○ 正しい情報収集× よく出る不正解
多角的・継続的に集める1つの場面・1つの情報だけで判断する
五感を使って観察する先入観をもって見る
他職種の情報も活用する他職種の記録は使わない
「できること」「やりたいこと」も集める困っていることだけを集める
本人の生活への思いを大切にする家族の要望を中心に聴く
会話はそのまま記録する会話は解釈して記録する
介護福祉の知識を使って解釈する介護福祉職の主観で解釈する
初回面談では目的を意識して聴く用意した質問を次々にする／最初に経済状況を聞く
プライバシーにかかわる話は、ほかの人がいない場所で聞くほかの利用者が同席する場で聞く（第36回）

アセスメントに必要な力＝倫理観・観察力・推測力・判断力（「先入観」は×。第24回）。先入観＝前もって決めつけた見方、偏見＝根拠のないかたよった見方で、どちらも判断をゆがめます。

集めた情報を確かめる5つの視点：①正確な事実か ②必要な事実がそろっているか ③結論を出すのに十分か ④先入観なく集めたか ⑤相手の言葉の意味を正しくつかんだか。

直接的情報と間接的情報

種類中身例
直接的情報介護福祉職が本人から直接得た情報本人との会話、観察した様子
間接的情報家族・他職種・記録などを通して得た情報家族の話、看護記録、ケアプラン

他職種の記録は「間接的情報」です（第34回で「直接的な情報として扱う」が×）。

情報を解釈するときの3つの視点

集めた情報は、次の3つの視点で解釈・関連づけます。生活課題の優先順位（介護過程②）や、事例問題の型2（介護過程④）でも同じ考え方を使います。

視点見るところ
生命の安全健康が悪化しそう・命や安全が脅かされそうな点
生活の安定自立できていない・これまでの生活を続けられていない点
人生の豊かさその人らしく、楽しみや役割をもって暮らせていない点

例：情報から生活課題まで

段階例（80歳の女性）
情報「また畑に出たい」と話す（本人の言葉）。膝の痛みで歩く距離が短くなった。最近は居室で過ごす時間が増えた
解釈歩く機会が減ると筋力が落ち、さらに歩けなくなるおそれがある（生活の安定）。畑仕事はこの人の楽しみ（人生の豊かさ）
関連づけ膝の痛み → 歩かない → 筋力低下 → 畑に出られない、がつながっている
生活課題痛みに配慮しながら歩く力を保ち、畑に出る楽しみを続けられること

ICFで情報を整理する

アセスメントでは、情報をICF（国際生活機能分類）の枠組みで整理する問題も出ます。

構成要素事例での例
心身機能・身体構造片麻痺、人工肛門、物忘れ
活動日常の動作。できる活動（能力）＝訓練などの場面でできること（例：車いすから便座へ移乗できる）と、している活動（実行状況）＝ふだんの生活で実際にしていること、を分けてとらえる
参加趣味の会、仕事、地域の役割
環境因子家族の状況（例：娘の仕事が忙しくなった）、住まい、福祉用具
個人因子年齢、性別、生活歴、性格

ICFそのものの詳しい説明はICF（国際生活機能分類）の見分け方でまとめます。

  • ICFと介護過程の違い：ICF（2001年にWHOが採択）は“生活機能を分類する道具”、介護過程は“その人の課題を解決する手順”で、目的が違います。ICFで全体をとらえると、できないことだけでなく、活動や参加を広げる前向きな計画が立てやすくなります。
  • 古いICIDHとの対応：機能障害 → 心身機能・身体構造、能力障害 → 活動、社会的不利 → 参加。ICFでは背景因子（環境因子・個人因子）が加わりました。
  • 環境因子には「周りの人の態度」も入ります（第31回：レジで「遅い」と言われた）。

状態をみる指標（寝たきり度）

観察は「身体面・心理面（受け止め方）・行動面」の3つから行います。在宅では、生活環境・困りごと・その原因を客観的につかみます。状態を表す指標には、寝たきり度・認知症高齢者の日常生活自立度・FAST（アルツハイマー型認知症の進み方を7段階で表す。→ 若年性認知症・評価スケール・薬・予防）があります。自立度のランクの比較は → 「自立」がつくサービス・制度の違い

事例文には「障害高齢者の日常生活自立度（寝たきり度）A」のように、状態を表す指標が出てきます。アセスメントで、移動や外出の自立度をつかむ目安になります。

寝たきり度は、軽い順に次の4ランクです。

  • J（生活自立）：障害はあるが、ほぼ自立。ひとりで外出できる
  • A（準寝たきり）：家の中はおおむね自立。介助なしには外出しない
  • B（寝たきり）：家の中でも介助が必要。日中もベッド上が中心だが、座位は保てる
  • C（寝たきり）：1日中ベッドの上。排泄・食事・着替えに介助が必要

認知症の人には「認知症高齢者の日常生活自立度」（Ⅰ〜Ⅳ・M）を使います。認知症の評価スケールは若年性認知症・評価スケール・薬・予防で扱います。

③ 主観的情報・客観的情報と記録

情報は「誰から得たか（直接的／間接的）」と「何の情報か（主観的／客観的）」の、2つのものさしで分けられます。

主観的（本人が感じていること）客観的（観察・測定した事実）
直接的（本人から介護福祉職が得た）本人が「膝が痛い」と言った介護福祉職が測った体温
間接的（家族・他職種・記録から）家族が聞いた本人の言葉看護記録の体温
種類中身例
主観的情報利用者本人の発言や訴え（本人が感じていること）「何となく気持ちが悪い」と言った
客観的情報介護福祉職が観察・測定した事実（検査の結果も）タンスに食べこぼしのついた上着が入っていた／体温37.5℃
介護福祉職の解釈・推測事実から考えたこと「帰宅願望から参加を拒否した」

主観的情報＝利用者本人の発言や訴え（本人が感じていること）、客観的情報＝観察・測定した事実。職員の推測・解釈はどちらでもなく、記録では事実と分けて書きます。選択肢で「主観的に記録した」と言うときは、職員の推測が混ざっていることを指すので注意。考え方は介護記録の書き方と情報管理と同じです。

よく出る一言

  • 本人の主観的情報を得る方法 → 本人の考えを聞く（表情から推測するのは×、第27回）
  • 「〜ではないか」「〜だからだと思う」「汚い」「生活しづらそう」は解釈。客観的情報ではない
  • 第33回では、「帰宅願望から、レクリエーションの参加を拒否した」が「主観的に記録したもの」の正解でした。介護福祉職の推測（帰宅願望）が混ざっているからです。「帰宅願望」は職員がつけた言葉で、本人には家に帰りたい理由があることが多いので、本人の言葉と様子をそのまま書きます

記録のルール

  • 事実をありのまま、その日のうちに記録する（鉛筆で書く・数日後にまとめて書くのは×）
  • 介護福祉職が判断した内容も記録する（ただし事実とは分けて書く）
  • 計画どおりに実施した日も記録する
  • 利用者の気持ちを憶測で書かない
  • 5W1H（いつ・どこで・誰が・何を・なぜ・どのように）を意識し、実施の前後の利用者の状態や反応、家族の言動も記録する（「家族の言動は記録しない」は×）
  • 記録者は署名し、鍵のかかる場所で保管する。保存期間などは介護記録の書き方と情報管理へ
