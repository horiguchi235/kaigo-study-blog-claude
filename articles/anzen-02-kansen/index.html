  1. 標準予防策は「汗以外の体液・排泄物・粘膜・傷のある皮膚」を感染の危険ありとして扱う。

スタンダードプリコーション（標準予防策）

感染の危険ありとして扱う ○対象外
血液、唾液・痰などの分泌物、尿・便・嘔吐物、粘膜、傷のある皮膚汗、傷のない皮膚、未使用の物品、経管栄養剤

液体石鹸の方が望ましい固形石鹸を使う

第36回：介護の基本

介護での感染症対策として、最も適切なものはどれ？

  1. 手洗いは液体石けんより固形石けんを使う
  2. 配膳中のくしゃみは、口を押さえた手でそのまま続ける
  3. 嘔吐物の処理は素手で行う
  4. 排泄の介護では、利用者ごとに手袋を交換する
  5. うがい用のコップは共用にする
正解を見る

正解：4　手袋は1人ごと・1ケアごとに交換し、外したあとも手を洗います。石けんは液体、コップは個人用です。

第35回：医療的ケア

消毒と滅菌について、正しいものはどれ？

  1. 消毒は、すべての微生物を死滅させることである
  2. 複数の消毒液を混ぜると効果が高まる
  3. 滅菌物には有効期限がある
  4. 家庭では熱湯で滅菌する
  5. 手指の消毒には次亜塩素酸ナトリウムを使う
正解を見る

正解：3　滅菌＝すべての微生物を除く、消毒＝害のある微生物を減らす。滅菌物は期限と包装の破れを確認して使います。消毒液を混ぜるのは危険です。

② 感染症別の対策

感染症押さえるポイント
ノロウイルス感染性胃腸炎。冬に多い、集団感染しやすい。主に経口感染（嘔吐物の飛沫・乾燥した粉じんも）。嘔吐物・便の処理はマスク・手袋・エプロン、消毒は次亜塩素酸ナトリウム（アルコールは効きにくい）
疥癬ヒゼンダニが皮膚に寄生（マダニは×）。強いかゆみ・皮膚の変化。入浴は最後、衣類・寝具は分けて洗う。角化型（ノルウェー疥癬）は個室
MRSA保菌者がいても接触感染予防策（手洗い・手袋）。レクへの参加制限・全員検査は不要。入浴は最後
結核空気感染（経皮感染は×）。予防は年1回の胸部X線検査、BCG。咳が続く人はマスク
レジオネラ水中で増える菌。循環式浴槽は塩素系薬剤で消毒、加湿器の水は毎日入れ替えてタンクを洗う
日和見感染抵抗力が落ちたときに弱い菌で発症（入院・入所で新たに発症するのは院内感染）

第38回：介護の基本

介護現場でのレジオネラ菌の感染対策として、最も適切なものはどれ？

  1. 感染者の衣類を熱湯で煮沸消毒する
  2. 食品は加熱調理を徹底する
  3. 循環式浴槽は塩素系の薬剤で消毒する
  4. ドアノブを次亜塩素酸ナトリウムで消毒する
  5. 家庭用加湿器のタンクの水は、ためておく
正解を見る

正解：3　レジオネラ菌は水の中で増え、細かい水しぶきを吸い込んで感染します。循環式浴槽の消毒・清掃と、加湿器の水を毎日入れ替えることが対策です。

第37回：介護の基本

結核の予防対策として、最も適切なものはどれ？

  1. 便座のアルコール消毒
  2. 肺炎球菌ワクチンの接種
  3. 紫外線を避けた生活
  4. 年1回の胸部X線検査
  5. 50℃以上の湯でリネン類を洗う
正解を見る

正解：4　結核は主に空気感染。高齢者は症状がはっきりしないことも多いので、定期的な胸部X線検査で早く見つけます。

③ 感染経路・消毒・滅菌の基本

  • 標準予防策（スタンダード・プリコーション）の対象＝すべての人の血液・体液・分泌物・排泄物・傷のある皮膚・粘膜（汗は除く）。
  • 嘔吐物や排泄物に触れるときは必ず手袋。手洗いをすれば手袋はいらない、は×。使った針はリキャップせず専用容器へ。
  • 口腔ケアを充実させると、口の細菌が減り感染症・誤嚥性肺炎の予防になる。
  • 点眼薬などは共有しない。体調不良の職員は早めに報告する。
  • レジオネラ症：汚染された水の細かい水滴（エアロゾル）を吸い込んで感染。ワクチンはないので、浴槽・配管・加湿器の清掃と水の管理で防ぐ（家庭用加湿器は毎日水を全部入れ替えてタンクを洗う、継ぎ足しだけはNG）。
  • 薬剤耐性菌：抗菌薬が効きにくい菌。MRSA＝メチシリン耐性黄色ブドウ球菌、MDRP＝多剤耐性緑膿菌。菌がいても症状がない状態は保菌。対策は手指衛生と標準予防策、抗菌薬の適正使用。
  • 洗浄・消毒・滅菌のちがい：洗浄＝汚れを落とす／消毒＝病原体を減らす／滅菌＝芽胞を含むすべての微生物をなくす。滅菌物は期限・包装の破れ・未開封を確認し、開封したら無菌とはいえない。
  • 消毒薬の種類：アルコール系（エタノール＝手指・皮膚）、ヨウ素系（ポビドンヨード＝皮膚・粘膜。排泄物には使わない）、第四級アンモニウム塩（ベンザルコニウム塩化物など）、アルデヒド系（グルタラール＝器具）。濃度は用途ごとに決められた濃度で使う。
  • 感染対策の3原則：①感染源を取り除く、②感染経路を断つ、③抵抗力を高める。施設では「持ち込まない・持ち出さない・広げない」。
  • スタンダード・プリコーション（標準予防策）：汗を除く血液・体液・分泌物・排泄物・傷のある皮膚・粘膜は、感染のおそれがあるものとして扱う。
  • 手洗いは「1ケア1手洗い」。流水と石けんで15秒以上、親指・指先・手首まで。逆性石けん（塩化ベンザルコニウム）はふつうの石けんと混ぜると効果が落ちる。
  • 消毒と滅菌：消毒＝病原体を減らす・弱める、滅菌＝すべての微生物を取り除く。熱水消毒は80℃で10分。消毒用エタノールは粘膜や傷には使わない（引火にも注意）。次亜塩素酸ナトリウムは金属を腐食させ、酸性の洗剤と混ぜない。
  • 65歳以上はインフルエンザ・新型コロナが定期接種の対象。新型コロナは2023年5月から5類。腸管出血性大腸菌（O157）は75℃で1分以上の加熱で予防。
