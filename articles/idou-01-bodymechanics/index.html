この記事のポイント

  1. ボディメカニクスは「広く・低く・近く・ねじらず・大きな筋肉で・小さくまとめる」。
  2. 側臥位へは「向く側と反対側へ水平移動 → 向く側に枕を寄せる → 腕を組む → 膝を立てる → 介護者は向く側に立ち、膝・肩の順に手前（介護者のいる側）へ倒す」。膝を立てるのがトルクの原理。
  3. 筋肉は「曲げる＝二頭筋・伸ばす＝三頭筋（肘）」、立つ筋肉（抗重力筋）は大腿四頭筋・大殿筋。

① ボディメカニクスとノーリフティングケア

ボディメカニクス＝体の骨・筋肉・関節の動きを力学的に使い、少ない力で安全に介護する技術。まず用語をおさえます。

用語意味
支持基底面体を支えている床の面積（立っているときは両足で囲まれた範囲。杖をつくと広がる）
重心体の重さが集まる中心点（立位ではおへその少し下あたり）
重心線重心から真下に下ろした線。支持基底面の中に入っていれば安定し、外へ出るとその方向へふらつく・倒れる
トルク物を回転させる力。支点から遠いところを押すほど小さな力で回る（ドアの取っ手が蝶番から遠くにあるのと同じ）
○ 原則× よく出る誤り
支持基底面を広くとる（足を前後左右に開く。倒れにくくなる）狭くとる
重心を低くする（膝を曲げて腰を落とす。安定する）重心を高くする
利用者に近づく（互いの重心を近づけると、少ない力ですむ）重心を遠ざける
体をねじらず、足先を移動する方向に向ける（腰痛を防ぐ）腰がねじれた姿勢
腕だけでなく大きな筋群（脚・体幹）を使う（疲れにくい）指先や腕の力を使う
利用者を小さくまとめ、ベッドとの接地面を狭くする（摩擦が減る）背部が接する面積を広くする／摩擦面を大きく
持ち上げずに水平に引く、てこの原理を使う両肘をベッドにつける
押すより手前に引く（力が逃げにくい）遠くへ押し出す
介護者自身の重心を水平に移して利用者を動かす（上下に動かすと腰に負担）腰を上下させて持ち上げる
介護者の骨盤を水平に保つ骨盤が傾いたまま力を入れる

ボディメカニクスは、利用者の安全・安楽だけでなく、介護者の腰痛予防にも役立ちます。

立位で静止している人の重心線が前後・左右に動いたときの「ふらつく方向」を図で問う問題もあります。重心線が移った方向（支持基底面から外れる側）にふらつきます。

トルクの原理と力点

  • 仰臥位 → 側臥位では利用者の膝を立てると、小さな力で回転できる（トルクの原理）。膝を高く立てるほど、支点（ベッドに接する体の軸）から力点が遠くなるため
  • 手を当てる力点は肩と膝

全介助でベッドから車いすへ

車いすに移るときは「介護者の重心を安定させて、車いすへ足先と体を向ける」。手首で持ち上げる・前腕で真上に引き上げる（腰を痛める）、介護者がかかとを浮かせる（足裏全体で床を踏みしめないと重心が不安定になる）、は×。

ノーリフティングケア

抱え上げない・引きずらない介護。スライディングボード（座ったまま滑らせて移る板）やリフトなどの福祉用具を使う。抱え上げて端座位にする・抱きかかえて移乗は×。回転移動盤（立ったまま体の向きを変える円盤）は立位がとれる人向けです。介護者の負担を減らすため、リフトやスライディングシートに加えて、移乗を助ける介護ロボットの活用も進められています。

  • 自分の体で確かめよう：肘を曲げると力こぶ（上腕二頭筋）が固くなり、いすから立ち上がると太ももの前（大腿四頭筋）が固くなります。大きな筋肉を使う感覚を体で確かめると覚えやすくなります

② 体位・体位変換・良肢位

体位の名前と角度

体位角度・形よく使う場面
仰臥位あお向けに寝る—
側臥位横向きに寝る。下になる側の名前で呼ぶ（右が下なら右側臥位）体位変換・褥瘡予防
腹臥位うつぶせに寝る—
長座位脚を前に伸ばして座る—
端座位ベッドの端に座り、足を床につける立ち上がり・移乗の前
ファーラー位（半座位）上半身を約45度起こす（食事のときは45〜60度）食事・会話・息苦しいとき
セミファーラー位上半身を約15〜30度起こす休息・経管栄養のあと・軽い息苦しさ
起座位上半身を起こし、オーバーベッドテーブルの枕に伏せる喘息・心不全で呼吸が苦しいとき

息苦しいとき：セミファーラー位＝15〜30度、ファーラー位（半座位）＝45度前後。息苦しさが強いほど上半身を高くします（さらに強いときは起座位）。

  • 寝た姿勢（臥位）はベッドに接する面が広く、最も安定します（中でも仰臥位は支える面が最も広く、筋肉の緊張も少ない）。座位・立位になるほど重心が高く支える面が狭くなって不安定ですが、目が覚めて活動しやすくなります
  • 体位変換の目的＝同じ姿勢が続くことで起こる筋萎縮・関節拘縮・褥瘡を防ぐこと。前に声をかけて同意を得て、本人ができる部分はしてもらいます
  • 寝返りができるかどうかは、寝たきり度（障害高齢者の日常生活自立度）を判定する目安にもなります
  • 側臥位では下側の腕が体の下敷きにならないようにします。側臥位は意識のない人の回復体位にも使います。腹臥位では顔を横に向けます
  • 側臥位から端座位にするときは、臀部（お尻）を支点にして体を回します

仰臥位から側臥位へ（右片麻痺の人を左側臥位に）

  1. 向く側と反対側（右）へ体を水平移動しておく（横向きになったとき、体がベッドの中央に来るように）
  2. 枕を向く側（左）に寄せる
  3. 腕を胸の上で組む（体を小さくまとめる）
  4. 膝を高く立てる
  5. 介護者は向く側（左）に立つ
  6. 膝 → 肩の順に、介護者のいる側（手前）へ倒す
  7. 腰を後ろに引いて「く」の字にすると安定する。下側の肩を前に引き出して圧迫を防ぎ、背中にクッションを当てて姿勢を保つ

片麻痺の人は、原則として健側を下にした側臥位にします（患側を下にすると圧迫・痛みの原因）。

×になる選択肢：向く側（左）へ水平移動する、腕を体に沿わせる、下肢を伸ばしたまま、肩と膝を同時に倒す。

第38回：生活支援技術

Aさん（83歳、女性、要介護3）は、脳梗塞（cerebral infarction）の後遺症で左片麻痺（ひだりかたまひ）があり、介護老人福祉施設に入所している。ある日の夜間、仰臥位（ぎょうがい）（背臥位（はいがい））で寝ていたAさんが、「背中が重く感じて、眠れない」と介護福祉職に訴えた。

次の記述のうち、介護福祉職がAさんに行う介護として、最も適切なものを1つ選びなさい。

  1. ファーラー位にして、左下肢にクッションを入れる。
  2. 両上肢の下に、クッションを入れる。
  3. 両膝窩部（りょうしつかぶ）に、クッションを入れる。

出典：第38回 介護福祉士国家試験（生活支援技術）

正解を見る

  2. 繊維質の多い食事を勧める。
  3. 日光浴を日課に取り入れる。
  4. 車いすでの移動に変更する。
  5. ビタミンA（vitamin A）の摂取を勧める。
