① 心臓・血圧

心臓は4つの部屋（右心房・右心室・左心房・左心室）に分かれたポンプです。全身から大静脈で右心房に戻った血液は、右心室から肺動脈で肺へ行き、酸素を受け取って肺静脈で左心房へ。左心室から大動脈で全身に送られます。名前と中身が逆で、肺動脈には静脈血（酸素が少ない）、肺静脈には動脈血（酸素が多い）が流れます。

心臓の筋肉に酸素を届ける血管を冠動脈といいます。冠動脈が狭くなるのが狭心症、詰まって心筋が死んでしまう（壊死）のが心筋梗塞です。

病気試験に出る特徴
心筋梗塞冠動脈が詰まり心筋が壊死。冷や汗を伴う激しい胸痛が30分以上、ニトログリセリン（舌の下で溶かす胸痛の薬）が効かない、安静でも治まらない → すぐ救急車。高齢者や糖尿病の人は痛みを訴えないことがある（息苦しさ・吐き気・だるさだけのことも）
狭心症冠動脈が一時的に狭くなる。階段などで胸が痛むが、休むと数分（長くても15分程度）で治まる。ニトログリセリン（舌下）が効く
心房細動心房が細かく不規則に動き、脈が不規則で頻脈になりやすい。心臓にできた血栓が脳に飛ぶと脳梗塞（脳塞栓）。予防の薬（ワルファリンなど血液を固まりにくくする薬）を飲む人は出血しやすいので打撲に注意。高齢になるほど多く、高血圧と関連
心不全心臓のポンプの力が落ちる。息切れ・チアノーゼ（唇や指先が紫色になる）・下肢のむくみ（全身にも）・体重増加・尿量の減少。横になると苦しく、座ると楽（起座呼吸）。夜間の急な呼吸困難も
高血圧診察室で140/90mmHg以上（Ⅰ度）、家庭で測ると135/85mmHg以上。高齢者は収縮期（上）の血圧が高いタイプが多く、原因のはっきりしない本態性高血圧がほとんど。治療は減塩・運動・減量と降圧薬
不整脈脈のリズムや回数が乱れること。脈が遅い（目安：1分間に60回未満）＝徐脈、速い（100回を超える）＝頻脈。急に気を失う・強い息切れ・突然の動悸は危険なサイン。徐脈の治療にペースメーカーを使うことがある
狭心症の種類運動したときに起こるもの（労作性）と、夜間や明け方の安静時に起こるもの（冠動脈のけいれん）がある。狭心症と心筋梗塞をまとめて虚血性心疾患という
動脈硬化自覚症状がほとんどない。脂質異常症・糖尿病・高血圧・喫煙・加齢で進む
心臓弁膜症心臓の弁がうまく開いたり閉じたりせず、血液が逆流・停滞する。高齢者では大動脈弁狭窄症が多く、失神の原因になる

血圧の分類（診察室血圧）：正常＝120/80mmHg未満 → 正常高値 → 高値 → Ⅰ度高血圧＝140/90以上 → Ⅱ度 → Ⅲ度。原因の病気がはっきりしているものは二次性高血圧（本態性と対になる言葉）。高血圧が長く続くと、心臓（心肥大・心不全・心筋梗塞）・脳（脳梗塞・脳出血）・腎臓（腎不全）・目が傷みます。日本高血圧学会の「高血圧管理・治療ガイドライン2025」では、下げる目標が年齢にかかわらず原則130/80mmHg未満とされたので、「高齢者は目標をゆるくする」と言い切らないようにします。

最近、階段を上るときに胸の痛みを感じていたが、しばらく休むと軽快していた。

喉の違和感や嚥下痛（えんげつう）はない。

今朝、朝食後から冷や汗を伴う激しい胸痛が起こり、30分しても軽快しないので、救急車を呼んだ。

Kさんに考えられる状況として、最も適切なものを1つ選びなさい。

  1. 喘息（ぜんそく　bronchial asthma）
  2. 肺炎（pneumonia）
  3. 脳梗塞（cerebral infarction）
  4. 心筋梗塞（myocardial infarction）
  5. 逆流性食道炎（reflux esophagitis）

② 糖尿病・低血糖・甲状腺・生活習慣病

高齢者の糖尿病

糖尿病は、血糖を下げるホルモンインスリンが足りない・効きにくいため、血糖値が高くなる病気です。1型＝インスリンがほとんど出ない（若い人に多く、生活習慣と無関係）、2型＝生活習慣が関係（日本の大多数）。

○×
原因はインスリンの作用不足アミラーゼ（でんぷんを分解する消化酵素）の作用不足が原因
低血糖の自覚症状に乏しい低血糖に気づきやすい
HbA1c（過去1〜2か月の血糖の平均を表す値）の目標は若年者より高め（低血糖を避ける）低めが推奨
のどの渇き（口渇感）を感じにくい口渇感が強い
運動療法は有効運動は避ける
  • 血糖が高いときのサイン：のどの渇き・水をたくさん飲む・尿が多い・だるさ・体重が減る（ふるえ・冷や汗・動悸は低血糖のサイン。比べる表は → 循環・血液のしくみと症状の観察）
  • 三大合併症は「し・め・じ」：神経障害（足のしびれ・感覚が鈍る → 傷や壊疽に気づかない。足の指を観察）、網膜症（視力が落ちる。失明の原因にもなる）、腎症（透析の原因で最も多い）。介護職が気をつけて見るのは、見え方の変化と足の傷です
  • 治療は、食事療法・運動療法・薬（飲み薬・インスリン注射）

低血糖のサイン

ふらふらする・冷や汗・空腹感・動悸・手のふるえ・意識がぼんやり

介護福祉職がまずすることは、すぐ看護師・医師に連絡して血糖を確かめてもらい、指示に従って糖分（ブドウ糖など）をとってもらうことです。意識がはっきりしないときは、口から無理に食べさせません。

場面○ 正解
インスリン治療中、受診が長引き昼食が遅れ「頭がふらふら」・冷や汗すぐに看護師に血糖を測定してもらう
夕方ひどくおなかが空き「ふわふわ」、クッキーで良くなる（腎機能も低下）早めに主治医に相談（薬が効きすぎている可能性）

×の選択肢：すぐにインスリンを打つ（さらに血糖が下がる）／内服薬を飲む／様子を見る／甘いものを禁止する（低血糖のときは糖分が必要）。

体調が悪い日（シックデイ）

  • 糖尿病の人が、発熱・下痢・嘔吐などで食事がとれない日をシックデイといいます。血糖は上がることも下がることもあります
  • インスリンの量や、打つかどうかを、本人や介護職が判断しません。食べられないのにいつもどおり打つと、低血糖になるおそれがあります
  • すぐ看護職・医師に報告し、指示があるまでは、注射も食事も無理に進めません。介護福祉職は量を増やす・減らすの判断はできません
  • 2022年の通知で、在宅などで医師が指示したタイミングでの声かけ・見守り、未使用の注射器などの手渡し、使い終わった注射器の片付け（針を抜いて処分することは除く）、記録などは「医行為でない」とされました。注射そのものは、本人か医療職が行います（→ 医療的ケアの制度と呼吸・消化のしくみ）

そのほか

  • 甲状腺機能低下症（橋本病など）：むくみ（浮腫）・寒がり・無気力・便秘。甲状腺機能亢進症（バセドウ病など）：動悸・発汗・下痢・いらいら・手のふるえ・やせる・眼球突出。どちらも女性に多い
  • 糖尿病の合併症（神経障害・網膜症・腎症）のうち、糖尿病性腎症は慢性腎不全・人工透析の原因で最も多い
  • 高コレステロール血症の予防：食物繊維の多い食品。高血圧の予防はカリウムを多く、骨粗鬆症はビタミンKを多く
  • 更年期障害：性ホルモンが減ることで起こる心と体の不調。女性は閉経の前後にエストロゲンが減り、ほてり・動悸・頭痛・めまい・気分の落ち込みなどが出る。男性も加齢でテストステロンが減って起こることがある。エストロゲンが減ることは骨粗鬆症の原因にもなる（→ 骨・パーキンソン病・排泄・皮膚・こころの病気）

③ 肺炎・誤嚥性肺炎

○×
誤嚥性肺炎を起こしやすい。予防には口腔ケアが有効誤嚥は肺炎の原因にならない
意識障害（ぼんやりする）が出ることもある意識障害になることはない
症状がはっきりしない（微熱・元気がない・食欲低下）初発症状は高熱／37.5℃未満なら肺炎ではない
呼吸数が増える（頻呼吸）呼吸数は減る・頻呼吸はまれ
咳・痰を伴うことが多い。インフルエンザのあとに細菌性肺炎を起こしやすい（予防接種が有効）咳・痰はまれ

事例：脳梗塞の後遺症で食事中によくむせる人が、元気がなく食欲も半分、呼吸数24回/分、37.4℃ → 誤嚥性肺炎。

嚥下障害のサイン：食事のときにむせる。

そのほかの呼吸器の病気

病気ポイント
喘息ダニ・ハウスダスト・たばこなどで気道が狭くなり、ゼーゼー・ヒューヒュー（喘鳴）と息苦しさが発作的に起こる。原因を減らす（掃除・禁煙）
COPD（慢性閉塞性肺疾患）主に喫煙が原因。動いたときの息切れ・咳・痰。息を吐くときは口すぼめ呼吸。風邪などで急に悪くなる（急性増悪）ので感染予防が大切
呼吸不全体に十分な酸素を送れない状態。チアノーゼ・呼吸が速い・脈が速い。慢性の代表がCOPDで、在宅酸素療法を使う（生活の注意は → 肢体不自由・関節リウマチ・内部障害）
肺がん咳・痰・血痰が出るが、その病気だけの特有の症状はない

正解を見る

正解：5　水分が失われると体重が減ります。高齢者は渇きを感じにくく、体内の水分量も少ないため脱水になりやすい。立ちくらみ（血圧低下）や下痢も原因・症状になります。

⑤ 脳血管疾患（脳卒中）

脳の血管が詰まる・破れる病気をまとめて脳血管疾患（脳卒中）といいます。要介護5の原因の第1位です（2022年 国民生活基礎調査）。がん・心疾患・脳血管疾患は三大生活習慣病と呼ばれ、脳血管疾患の危険因子は高血圧・糖尿病・脂質異常症・喫煙です。

病気中身
脳梗塞脳の血管が詰まる。動脈硬化で細い血管が詰まるもの（ラクナ梗塞など）と、心房細動でできた血栓が飛んで詰まるもの（脳塞栓）がある
脳血栓（脳梗塞の1つ）動脈硬化で細くなった血管に血の塊ができる。寝ている間など安静時に起こりやすく、ゆっくり進む
脳塞栓（脳梗塞の1つ）心臓（心房細動など）でできた血の塊が流れてきて詰まる。活動中に突然起こり、急に重くなる
一過性脳虚血発作まひやしびれなどが出て、24時間以内（多くは数分〜数十分）に消える。脳梗塞の前ぶれのことが多いので、消えても医療職に伝える
脳出血脳の中の血管が破れて出血。高血圧が最大の危険因子。活動中に起こりやすい
くも膜下出血主に脳動脈瘤（脳の動脈にできたこぶ）の破裂。突然の激しい頭痛（「バットで殴られたよう」）、吐き気
  • 後遺症として、片麻痺・失語・構音障害・嚥下障害、高次脳機能障害、血管性認知症が残ることがある
