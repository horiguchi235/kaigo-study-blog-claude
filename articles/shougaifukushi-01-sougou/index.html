② 利用の手続き・障害支援区分・負担・関係機関

利用の流れ

  1. 市町村の窓口に支給申請（最初の手続き）
  2. 認定調査（市町村）＋医師意見書
  3. 市町村審査会で障害支援区分（非該当・区分1（軽い）〜区分6（重い））を審査・判定。家族の意見を聴くことができる
  4. サービス等利用計画案（相談支援専門員が作成）
  5. 支給決定 → サービス担当者会議（本人も参加。ここで計画を確定させる）→ 事業所と契約 → 利用 → モニタリング（支給決定の後も、計画相談で見直しを続ける）

介護保険はケアプランが認定の後ですが、障害福祉は計画案が支給決定より前です。訓練等給付は原則として障害支援区分の認定がいりません。

○×
居宅介護を使うには障害支援区分の認定が必要身体障害者更生相談所の医学的判定・すぐ契約・ケアマネに伝える
生活介護を使うために障害支援区分の認定要介護認定・保護の要否判定
利用者負担は応能負担（負担能力に応じて。所得に応じた月の上限あり）応益負担（サービス量に応じて）・定率・全額
財源は税（公費）社会保険方式

国・都道府県・市町村の役割

国都道府県市町村
障害福祉計画の基本指針を決める、制度全体の体制を整える事業者の指定・取消し、自立支援医療（精神通院医療は都道府県・指定都市）、専門的な相談、支給決定などへの不服の審査請求を受ける支給申請の受付・支給決定、市町村審査会を置く、地域生活支援事業、虐待の防止と早期発見
  • 障害福祉計画は、国の基本指針にそって都道府県と市町村がつくる義務があります（任意ではありません）。サービスの見込み量と提供の体制を決める計画で、つくるときは協議会の意見を聴くよう努めます
  • 障害福祉計画は利用者負担の額を決めるものではありません。負担は、所得に応じた月の上限で決まります
  • 事業者への支払いの事務は、国保連に任せることができます

第38回：社会の理解

次の記述のうち、障害者福祉に関係する機関やシステムとして、最も適切なものを1つ選びなさい。

第35回：社会の理解

「障害者総合支援法」の居宅介護を利用したときの利用者負担の考え方として、最も適切なものを1つ選びなさい。

（注）「障害者総合支援法」とは、「障害者の日常生活及び社会生活を総合的に支援するための法律」のことである。

  1. 利用したサービスの種類や量に応じて負担する。
  2. 利用者の負担能力に応じて負担する。
  3. 利用したサービス費用の一定の割合を負担する。
  4. 利用したサービス費用の全額を負担する。
  5. 利用者は負担しない。

正解を見る

正解：2　障害福祉は応能負担（所得に応じた月の上限あり）。介護保険は原則1〜3割の定率負担です。

行動援護知的・精神障害で行動上の危険がある人の外出・危険回避区分3以上

  • 市町村が必ず行う地域生活支援事業：障害への理解を広げる研修・啓発、相談支援、成年後見制度の利用支援、意思疎通支援（手話通訳・要約筆記）、日常生活用具の給付・貸与、手話奉仕員の養成、移動支援、地域活動支援センターなど。都道府県は、専門性の高い意思疎通支援者の養成など、広い地域にかかわる事業を行います

移動・外出の支援

サービス対象・内容
同行援護視覚障害で移動が難しい人の外出（代読・代筆も）。覚え方：同行＝目の代わりに同じ道を歩く
行動援護知的・精神障害で危険を回避できない人の外出。覚え方：行動上の危険を避ける
重度訪問介護重度の肢体不自由・知的・精神の人。入浴・食事などの介護に加え外出時の移動中の介護も。入院前から使っている区分4以上の人は、入院中も意思疎通の支援などに使える（2024年4月から。それまでは区分6）
移動支援地域生活支援事業（市町村）。円滑に外出できるよう移動を支援。介護給付ではない

そのほかのポイント

  • グループホームで暮らし、一人暮らしをしたい → 自立生活援助
  • 地域活動支援センター＝市町村の地域生活支援事業。障害のある人が通って、創作的活動や生産活動をし、地域の人と交流する場です。雇用契約はなく、仕事に向けた訓練（就労移行支援）でも、働いて収入を得る場（就労継続支援）でもありません。「日中の居場所や交流がほしい」人に合います
  • 障害者支援施設＝夜は施設入所支援、昼は生活介護（または自立訓練・就労移行支援）を組み合わせて暮らす入所施設。事例で「施設入所支援と一緒に使うサービス」「施設で創作的活動」と出たら生活介護です。入所にも障害支援区分の認定（市町村に申請）が必要です
  • 補装具と間違えやすいもの：特殊寝台・点字器・たん吸引器・ストーマ装具は日常生活用具、手すり・スロープは住宅改修

65歳になったら・共生型サービス

  • 介護保険優先の原則：障害福祉サービスを使っていた人も、65歳になって介護保険に同じようなサービスがあれば介護保険が優先。同行援護・行動援護・就労系など介護保険にないサービスは続けて使える
  • 共生型サービス（2018年〜）：介護保険と障害福祉の両方の指定を受けやすくする仕組み。対象は通所介護・訪問介護・短期入所など。65歳になっても同じ事業所のサービスを使い続けられる
  • 新高額障害福祉サービス等給付費（2018年〜）：65歳まで長く障害福祉サービスを使ってきた低所得の人が、介護保険の同じ種類のサービスに移ったとき、介護保険の利用者負担を払い戻す
