この記事のポイント

  1. 安眠の3点セットは「朝に日光、日中に適度な運動、入浴は寝る1〜2時間前（足浴も◎）」。
  2. 「夜食・寝酒・カフェイン・長い昼寝・寝だめ・夕食直後に寝る」は×。
  3. 眠れない人には、まずこれまでの睡眠の様子を聞く。睡眠薬を勧める・無理に寝かせるは×。

① 安眠を促す生活習慣

○×
起床後にカーテンを開けて日光を浴びる—
日中に適度な疲労が得られる運動汗をかく運動・強度の高い運動を寝る前や日中に多く
関節リウマチで昼夜逆転 → 午後に温水プールで運動早朝の散歩・朝食を抜く
就寝前に軽いストレッチ—
入浴は就寝の1〜2時間前、ぬるめの湯就寝直前・熱めの湯
足浴で温めてから寝る照明を昼光色の蛍光灯に／短く浅い呼吸
自分なりの入眠儀式（習慣）を大切に入眠への習慣を控える
昼寝は短く（30分以内・15時まで）1時間以上の昼寝
—夕食直後・夜食・緑茶・コーヒー・飲酒・寝だめ
—眠くなくても早く床につく・決まった時刻に目を閉じる

夜勤のある職員の睡眠：夜勤明けの帰宅時はサングラスで日光を避ける（体内時計が朝だと思わないように）。夜勤前の仮眠はとってよい、寝る前のスマホ・寝だめ・食事時間をばらばらにするのは×。

第38回：生活支援技術

よい睡眠のための環境づくりとして、最も適切なものはどれ？

  1. 日中は強い運動を多く取り入れる
  2. 夜食は寝る直前にとる
  3. 入浴は寝る1〜2時間前にする
  4. 眠くなくても決まった時間に目を閉じる
  5. 寝ている間も照明を明るくしておく
正解を見る

正解：3　入浴で上がった体温が下がるころに眠気が来るので就寝1〜2時間前に。眠くなってから寝床に入り、夜は暗くします。

第35回：生活支援技術

寝つきをよくするための助言として、最も適切なものはどれ？

  1. 「足をお湯で温めてから寝ましょう」
  2. 「寝室の照明を昼光色の蛍光灯にしましょう」
  3. 「布団に入ったら短く浅い呼吸をくり返しましょう」
  4. 「寝る前の習慣はやめましょう」
  5. 「寝る前に汗をかく運動をしましょう」
正解を見る

正解：1　足浴で手足から熱が逃げやすくなり寝つきやすくなります。照明は暖色系、ゆっくり深い呼吸、自分なりの入眠儀式も効果的です。

第34回：生活支援技術

夜勤のある職員がよい睡眠をとるための生活習慣として、最も適切なものはどれ？

  1. 夜勤前に仮眠をとらない
  2. 寝る前にスマホでメールを確認する
  3. 朝食と夕食の時間を日によって変える
  4. 夜勤明けの帰宅時はサングラスをかけるなど日光を避ける
  5. 休日に寝だめをする
正解を見る

正解：4　朝の強い光は体を「起きるモード」にするので、夜勤明けは光を避けて眠りやすく。夜勤前の仮眠は有効です。

② 睡眠環境・寝具・ベッドメイキング

寝室の環境

○×
換気して臭気がこもらないようにドアを開けておく
職員同士の会話が響かないように—
湿度は50〜60％、室温は夏25℃前後・冬15〜20℃湿度20％以下・1年中15℃
冷暖房の風が体に直接当たらない直接当てる
夜間は足元灯（杖歩行の人にも）部屋全体が見えるほど明るく
湯たんぽは皮膚に直接触れない（低温やけど）電気毛布をつけっぱなし
寝衣はゆったりした物体に密着した物

寝具

○×
マットレスは適度な硬さ（腰が沈まない）柔らかく沈む物
枕は頸部が前に曲がらない高さ顎が首につくほど高い
寝具は吸湿性・保温性のバランス保湿性を最優先
パーキンソン病の人はベッドに手すり介護者に合わせた高さ・沈むマット・床にクッションマット

畳に布団の利点：転落の心配がない。湿気がこもりやすく、立ち上がりにくく、介護の負担は大きくなります。

ベッドメイキング

○×
シーツの角は対角線の方向に伸ばしてしわを作らない—
シーツの中心線をマットレスの中央に合わせるマットレスの端に合わせる
マットレスの下に入れるときは手のひらを下に—

④ 安眠の環境と昼夜逆転への支援

  • 昼寝は午後の早い時間に30分未満が目安（30〜45分以上の長い昼寝は夜の眠りを妨げる）。
  • 夜になると活動的になる認知症の人には、日中の活動と光で生活リズムを整え、寝間着に着替えるなど「夜だ」とわかる睡眠環境づくりを。
  • 安眠の環境：室温24℃前後（季節で調整）、寝床内（布団の中）は33〜35℃前後、湿度50〜60％。巡回時の足音・話し声・ドアの音に気をつける。
  • 枕は首の角度が約15度上がるくらい、マットレスは硬すぎず柔らかすぎず、寝返りできる広さ。
  • 寝る前のイブニングケア（洗面・歯みがき・清拭や足浴・マッサージ）で眠りへの準備。寝る直前の食事、カフェイン・アルコールは避ける。睡眠薬に頼りすぎない習慣を。
  • 昼夜逆転には、午後〜夕方の散歩・レクリエーションで日中の活動を増やす。不眠を訴える人には、まずつらさに共感する。
